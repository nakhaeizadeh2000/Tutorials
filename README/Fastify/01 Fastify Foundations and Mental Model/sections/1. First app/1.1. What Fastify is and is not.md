**Modern guidance** — the schema lines per route (review-enforced — RUN LIVE via fastify.inject, outputs verified below): *validation declaring* (schemas stating — inputs proving (correctness holding — trust earning (abuse declining — breaches preventing (validation owning — security composing); *serialization filtering* (outputs declaring — undeclared dropping (payloads slimming — bandwidth saving (latency cutting — transfer pricing (contracts bounding — breakage preventing); *speed measuring* (benchmarks running — serializers generating (JSON flying — overhead minimizing (costs pricing — throughput trading (negotiation owning — thresholds gating).

```javascript
// GOOD: schemas powering — validation declaring, serialization filtering, speed following (RUN LIVE: 200 verified).
const fastify = require('fastify')({ logger: false });
fastify.post('/users', {
  schema: {
    body: { type: 'object', required: ['name'], properties: { name: { type: 'string', minLength: 1 } } },
    response: { 201: { type: 'object', properties: { id: { type: 'string' } } } }, // serialization filtering — extras dropping
  },
}, async (req, reply) => reply.code(201).send({ id: 'u7', extra: 'dropped' }));
// inject POST /users {name:'Ada'} → 201 {"id":"u7"} (verified live — extra stripped, validation passing)
```

// ORM rows serialized wholly (internals exposing — payloads ballooning — bandwidth wasting (contracts drifting — clients breaking).

**Performance note** — schema economics: declaring costing schema code (shapes typing — payloads proving (correctness holding — trust earning); filtering saving bandwidth (undeclared dropping — payloads slimming (latency cutting — transfer pricing (contracts bounding — breakage preventing); compiling costing startup codegen (validators generating — serializers optimizing (JSON flying — overhead minimizing (costs pricing — throughput trading); schemaless equivalents costing runtime breakage (clients crashing — incidents extending).
