**Modern guidance** — the contract lines per route (review-enforced — RUN LIVE via fastify.inject, outputs verified below): *body validating* (schemas stating — inputs proving (correctness holding — trust earning (abuse declining — breaches preventing (validation owning — security composing); *response filtering* (outputs declaring — undeclared dropping (payloads slimming — contracts bounding (breakage preventing — stability earning (bandwidth pricing — performance winning); *params constraining* (patterns matching — shapes enforcing (garbage rejecting — handlers trusting (validation owning — trust earning (guards composing — breaches preventing).

```javascript
// GOOD: contracts declaring — body validating, response filtering, params constraining (RUN LIVE: 201/400 verified).
const fastify = require('fastify')({ logger: false });
fastify.post('/users', {
  schema: {
    body: { type: 'object', required: ['name'], properties: { name: { type: 'string', minLength: 1 } } },
    response: { 201: { type: 'object', properties: { id: { type: 'string' }, name: { type: 'string' } } } },
  },
}, async (req, reply) => reply.code(201).send({ id: 'u7', name: req.body.name }));
// inject POST /users {name:'Ada'} → 201 {"id":"u7","name":"Ada"} (verified live — validation passing, shape holding)
// inject POST /users {} → 400 {error...} (verified live — validation rejecting, trust earning)
```
