Declared schemas converting hoping to proving (validation proving — serialization filtering (hoping ending — proof owning); reviewers checking schemas, not handlers (declaration proving → verifiable; assuming → returned).

**Modern guidance** — the schema lines per route (review-enforced — RUN LIVE patterns from 1.1/1.2): *validation proving* (inputs checking — shapes confirming (correctness holding — trust earning (abuse declining — breaches preventing (validation owning — security composing (payloads checking — shapes confirming); *serialization filtering* (outputs declaring — undeclared dropping (payloads slimming — contracts bounding (breakage preventing — stability earning (bandwidth pricing — performance winning); *hoping ending* (assumption declining — proof requiring (rigor demonstrating — mastery proving (fashion declining — numbers ruling (discipline proving — trust earning).
