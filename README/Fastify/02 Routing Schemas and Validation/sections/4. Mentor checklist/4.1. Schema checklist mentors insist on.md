## 1. Every input validates (params/query/body proving — trust earning, never assuming)

**Definition** — the input line on every route: schemas proving all ingress ([1.1 owning validation](<../../sections/1. Input schemas/1.1. **What problem it solves** — the unvalidated trio: *params assuming* (strings equaling never — lookups missing (coercion forgetting — validation missing (trust defaulting — correctness hoping (proof missing — pressure collapsing); *queries trusting* (sorts executing — arrays exploding (injection inviting — bounds missing (abuse hoping — limits hoping (validation absenting — security bleeding); *bodies shallowing* (tops checking — nests trusting (depth ignoring — abuse hiding (validation surfacing — attacks nesting (checks shallowing — trust hoping). Proven inputs converting assumption to proof (params typing — queries bounding (bodies nesting — trust earning); reviewers checking schemas per ingress, not handlers (validation proving → verifiable; trusting → returned).

**Modern guidance** — the input lines per route (review-enforced): *params typing* (coercion owning — strings converting (garbage rejecting — trust earning (surprises ending — clarity buying (discipline owning — magic declining (control retaining — debugging easing); *queries bounding* (objects constraining — arrays limiting (injection declining — trust earning (shapes declaring — surprises ending (contracts stating — trust earning (abuse preventing — security composing); *bodies nesting* (depth validating — recursion bounding (trust earning — completeness proving (bounds owning — hope ending (shapes declaring — correctness holding).

```javascript
// GOOD: inputs proving — params typing, queries bounding, bodies nesting (shapes, gated).
// params: { id: integer } coerced (strings typing — garbage rejecting — trust earning, surprises ending)
// querystring: sort enum + ids maxItems (objects bounding — arrays limiting — injection declining, trust earning)
// body: nested lines validated (depth validating — recursion bounding — trust earning, completeness proving)
```

```javascript
// BAD: inputs assuming — params trusting, queries open, bodies shallow (real failure shape).
// Raw req.params use (strings equaling never — lookups missing — coercion forgetting (validation missing — trust defaulting).
// Unbounded querystrings (sorts executing — arrays exploding — injection inviting (bounds missing — abuse hoping).
// Top-level checks only (nests trusting — depth ignoring — abuse hiding). Type params; bound queries; nest bodies.)
```

**Common confusion** — *"checklists slow reviews (bureaucracy taxing velocity)."* Checklists catching structurally (inputs proving pre-production — design fixing (costs trivial — types owning (fixes cheap — production sparing); production incidents costing (breakage discovering — trust burning — rollbacks rushing (fixes structural — urgency pricing (redesigns hurrying — confidence dipping); reviews accelerating (patterns internalizing — schemas defaulting (discipline habituating — checks instancing (velocity composing — quality enabling). **Performance note** — input economics: typing costing coercion config (strings converting — garbage rejecting (trust earning — surprises ending (discipline owning — magic declining); bounding costing schema checks (objects constraining — arrays limiting (injection declining — trust earning (shapes declaring — surprises ending); nesting costing depth walks (depth validating — recursion bounding (trust earning — completeness proving (bounds owning — hope ending); assumed equivalents costing misses + injection (results vanishing — breaches scheduling). Type cheaply (config — trust); bound always (checks — inputs).

**Mentor note** — teach "schema every ingress — params, query, body" (juniors proving per route design validated inputs on first hearing; unvalidated ingress interrogated ("schema where?" — proof demanding per ingress). **Modern guidance** — the output lines per route (review-enforced): *responses declaring* (fields selecting — payloads shaping (contracts bounding — breakage preventing (stability earning — trust compounding (shapes freezing — surprises ending); *extras dropping* (undeclared stripping — internals hiding (surfaces minimizing — coupling declining (changes freeing — refactors enabling (filtering owning — hygiene proving); *leaks preventing* (secrets omitting — hashes excluding (surfaces minimizing — breaches declining (exposure ending — reconnaissance denying (hygiene owning — discipline proving).
