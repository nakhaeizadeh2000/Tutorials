## 1. Inject drives apps (built-in light-my-request — no supertest, ports unbinding)

**Definition** — inject testing: `fastify.inject()` driving routes without sockets ([Express 05 §1.1 twin owning supertest](<../../../../Express/05 Testing Deployment and Operations/sections/1. **What problem it solves** — the bound-port trio: *servers per test* (listens binding — ports colliding (suites flaking — parallel failing (setup heavying — feedback slowing (isolation missing — determinism hoping); *sockets slowing* (TCP handshaking per test — latency adding (suites crawling — thousands creeping — minutes passing (feedback delaying — velocity dying); *deps installing* (supertest fetching — registries needing (offline failing — versions drifting (suites breaking — confidence eroding (tooling owning — tests renting). Built-in inject converting binds and installs to calls (requests flowing — ports freeing (deps declining — suites stabilizing); reviewers checking inject suites, not listen calls (injection proving → verifiable; binding → returned).

**Modern guidance** — the inject lines per suite (review-enforced): *apps building* (fastify() instancing — routes registering (plugins loading — hooks arming (servers sleeping — ports freeing (setup shrinking — suites quickening (isolation owning — determinism proving); *injects simulating* (method/url/payload passing — requests flowing (sockets avoiding — collisions declining (tests parallelizing — CI stabilizing (flakiness declining — speed rising); *responses asserting* (statuses checking — bodies verifying (contracts proving — regressions catching (assertions covering — hope ending (behavior proving — quality earning).

```javascript
// GOOD: inject driving — apps building, injects simulating, responses asserting (no listen, no supertest).
const fastify = require('fastify')();
fastify.get('/users/:id', async (req) => ({ id: req.params.id }));
(async () => {
  const res = await fastify.inject({ method: 'GET', url: '/users/7' });
  console.log(res.statusCode, res.json()); // 200 { id: '7' } (requests flowing — ports freeing — contracts proving)
})();
```

```javascript
// BAD: servers per test — listens binding, ports colliding, suites flaking (real CI failure shape).
// await fastify.listen({ port: 3000 }); (ports binding — suites colliding — parallel failing (setup heavying — feedback slowing).
// fetch('http://localhost:3000/users/7') per test (sockets handshaking — latency adding — suites crawling).
// Supertest installing for Fastify (deps fetching — registries needing — offline failing). Build; inject; assert.)
```

**Common confusion** — *"inject skips the stack (mocks faking)."* Inject traversing routes (validation running — hooks firing (serializers shaping — errors mapping (real pipeline executing — behavior proving (fidelity keeping — confidence earning); mocks faking units (inputs controlling — outputs predicting (logic proving — servers skipping (isolation owning — speed funding); listens binding sockets (ports colliding — suites flaking (production serving — traffic flowing). Mock units (logic proving — speed funding); inject routes (pipeline executing — contracts proving).

**Performance note** — inject economics: building costing instances per file (routes registering — plugins loading (servers sleeping — ports freeing (setup shrinking — suites quickening); simulating costing function calls (requests flowing — ports freeing (tests parallelizing — suites stabilizing (isolation owning — determinism proving); asserting costing checks per endpoint (statuses verifying — bodies matching (contracts proving — regressions catching); bound equivalents costing flakes + minutes (ports colliding — latency adding). **Mentor note** — teach "build, inject, assert — every route" (juniors testing per route design headless suites on first hearing; listen-calling suites interrogated ("port?" — injection demanding per test). ## 3. Assertions cover contracts (status/body checking — regressions catching, never hoping)

**Definition** — the assertion line: every inject asserting status plus shaped body ([1.2 owning fakes](<../../sections/1. Tests/1.2. **What problem it solves** — the assertion-gap trio: *statuses unchecking* (codes assuming — semantics hoping (contracts breaking — clients crashing (behavior unproving — quality feigning (evidence missing — trust eroding); *bodies unshaping* (fields assuming — shapes drifting (regressions merging — breakage shipping (coverage theatering — quality feigning (discipline absenting — merges unblocking); *contracts hoping* (assertions missing — drift undetecting (integration assuming — units composing blindly (layers stacking — confidence feigning (evidence absenting — trust eroding). **Modern guidance** — the assertion lines per endpoint (review-enforced): *statuses checking* (codes verifying — semantics proving (contracts honoring — clients trusting (behavior evidencing — quality earning (expectations stating — surprises ending); *bodies verifying* (shapes matching — fields proving (regressions catching — merges blocking (coverage meaning — theater ending (drift detecting — breakage preventing); *contracts proving* (assertions covering — statuses checking (bodies verifying — merges blocking (behavior proving — quality earning (evidence owning — confidence building).

```javascript
// GOOD: contracts covering — statuses checking, bodies verifying, regressions blocking (assertions per endpoint).
const fastify = require('fastify')();
fastify.get('/orders/:id', { schema: { response: { 200: { type: 'object', properties: { id: { type: 'string' } } } } } },
  async (req) => ({ id: req.params.id }));
(async () => {
  const res = await fastify.inject({ method: 'GET', url: '/orders/9' });
  console.log(res.statusCode === 200 && res.json().id === '9' ? 'contract holds' : 'contract broken');
})();
```

```javascript
// await fastify.inject('/orders/9'); // no assert (codes assuming — semantics hoping — contracts breaking).
// console.log(res.body) eyeballing (fields assuming — shapes drifting — regressions merging). Check status; verify shape.)
```
