# Fastify track (recommended order, September 2026 era)

High-performance backend framework for huge apps — Fastify from foundations to production: schemas, hooks, plugins, validation, data access, testing, and operations — from zero to hero and beyond (junior to mentor depth). Raw Node.js *runtime* mechanics live in the [Node.js track](<../NodeJS/README.md>); raw *HTTP without frameworks* lives in NodeJS 04; minimal-framework *contrast* lives in the [Express track](<../Express/README.md>). This track assumes working JavaScript + HTTP basics and teaches *Fastify*: what each layer owns, costs, and deserves. Version-sensitive claims are labeled (as of September 2026: Fastify 5.x stable, verified 5.12.5).
