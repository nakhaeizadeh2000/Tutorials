## 9.1. Boundaries: what is covered elsewhere

### 1) **Operator syntax and practical guidance — Language Basics domain**

- Precedence/associativity tables, `+` overload *usage*, arithmetic effects: [02 §3.1](<../../../02 Language Basics/sections/3. Operators/3.1. Arithmetic operators precedence associativity and coercion side effects.md>).
- Equality team policy (`eqeqeq`, sanctioned uses): [02 §3.2](<../../../02 Language Basics/sections/3. Operators/3.2. Equality loose vs strict and when either is safe.md>) — this domain owns the *algorithms*, that one the *policy*.
- Inspection operators (`typeof`/`instanceof` usage patterns): [02 §3.5](<../../../02 Language Basics/sections/3. Operators/3.5. Inspection operators typeof instanceof in delete void spread rest.md>).

### 2) **Number representation and formatting — Numbers, Dates, Math, Temporal domain**

IEEE-754 internals, `Number.EPSILON`, decimal/money strategies, exponential formatting, `-0` handling in display code, Temporal-era guidance. Here we only used precision facts as motivation (e.g., MAX_SAFE_INTEGER collapse).

### 3) **Protocols and metaprogramming — later domains**

- `Symbol.iterator`/async iteration mechanics → Iterables, Generators, and Async Iteration domain.
- `Symbol.toPrimitive`/`Symbol.hasInstance` were introduced as conversion hooks ([2.3](<../2. The conversion algorithms/2.3. ToPrimitive and the valueOf toString and Symbol.toPrimitive dance.md>), [5.1](<../5. The exotic primitives Symbol and BigInt/5.1. Symbol unique property keys beyond strings.md>)); Proxy/Reflect-driven interception and full well-known-symbol catalog → Metaprogramming, Symbols, Proxy, Reflect domain.

### 4) **Data structures and serialization — later domains**

- Why object identity makes `{}` unusable as a key → Collections, Map, Set, and Weak References domain.
- Array `sort()` comparator mechanics beyond the coercion root shown in [7.1](<../7. Common pitfalls to production bugs/7.1. Real production bugs caused by coercion.md>) → Arrays domain.
- JSON round-trips, replacers, BigInt serialization strategies → JSON, Serialization, and Data Exchange domain.

### 5) **Out of track scope**

DOM input values as coercion sources appeared only as examples; browser platform APIs belong to future platform tracks, and TypeScript's compile-time take on these runtime rules belongs to its own track.
