## 8.1. Boundaries: what is covered elsewhere

### 1) **Lexical scope and closure mechanics — Variables, Scope, and Closures**

Declaration scope, hoisting reality, TDZ, scope chains, per-iteration capture, closure patterns, and lifetime/GC belong to [Variables, Scope, and Closures](<../../../04 Variables Scope and Closures/README.md>) ([TDZ](<../../../04 Variables Scope and Closures/sections/1. Declarations and bindings/1.2. Temporal dead zone why early access throws.md>), [hoisting](<../../../04 Variables Scope and Closures/sections/2. Scope and lookup/2.2. Hoisting the reality creation phase not magic.md>), [closures](<../../../04 Variables Scope and Closures/sections/3. Closures/3.1. Closures functions that remember their birth environment.md>)). This domain usesclosures but does not re-teach them — see [4.1](<../4. First-class and execution patterns/4.1. First-class functions callbacks higher-order functions and composition.md>) for first-class usage only.

### 2) **Prototypes, classes, private fields, and constructor internals — Prototypes and Classes (planned 07)**

`prototype` linkage, `class` syntax, `super`, private `#fields`, and `new` allocation/prototype chain live in the Prototypes and Classes domain (textual forward reference). This domain covers `prototype` only as a function-object property and `new` only as a `this`-binding rule ([1.3](<../1. Function forms and the function object/1.3. Methods getters setters and the function object.md>), [3.1](<../3. this binding/3.1. Call-site rules default implicit explicit new and strict mode.md>)).

### 3) **Iterables, generators, async functions — Iterables/Async (planned 10, 13)**

Iterator protocol, `function*`/`yield`, generator state machines, `async`/`await`, and promise executors have dedicated domains. This domain stays with synchronous plain/arrow/method functions — `async` arrow shape mentioned only for syntax parity ([1.2](<../1. Function forms and the function object/1.2. Arrow functions syntax what they lack and when to use each.md>)).

### 4) **Object internals and collections — Objects in Depth / Collections (planned 06, 09)**

Property descriptors, `this` as receiver for accessors, `Map`/`Set`/`WeakMap` keying for memo caches, and related GC notes belong to those domains. This domain's memoize illustration ([Variables §3.3](<../../../04 Variables Scope and Closures/sections/3. Closures/3.3. Closure patterns privacy factories memoization.md>)) stops at the closure shape.

### 5) **Modules and top-level scope — Modules (planned 14)**

`import`/`export`, live bindings, and script vs module top-level scope belong to [Variables §4.1](<../../../04 Variables Scope and Closures/sections/4. Top level scopes scripts modules and eval/4.1. Script vs module top level globalThis and the declarative record.md>) and the planned Modules domain. IIFE ancestry ([4.2](<../4. First-class and execution patterns/4.2. IIFE module ancestry and modern replacements.md>)) is history, not module guidance.

### 6) **Values, coercion, and operator mechanics — Values, Types, and Coercion / Language Basics**

`ToPrimitive`/`ToString`/`ToNumber` coercion, boxing of `this` primitives, falsy filtering, and operator precedence live in [Values, Types, and Coercion](<../../../03 Values Types and Coercion/README.md>) and [Language Basics](<../../../02 Language Basics/README.md>). This domain references them (boxing → [3.1](<../3. this binding/3.1. Call-site rules default implicit explicit new and strict mode.md>), truthiness → [4.1](<../4. First-class and execution patterns/4.1. First-class functions callbacks higher-order functions and composition.md>)).

### 7) **Stop-list for this domain (what not to add here)**

- Do not re-derive scope chains, per-iteration environment, or closure lifetime — link to domain 04.
- Do not teach `class` inheritance, `extends`/`super` dispatch, or private field semantics — link to domain 07.
- Do not teach `Symbol.iterator`, `Generator.prototype`, or `Promise` combinators — link to domains 10/13.
- Do not duplicate `Object.keys/assign/entries` descriptor deep dives — link to domain 06.
