## 4.1. First-class functions: callbacks, higher-order functions, and composition

### 1) **Functions as values**

**Definition** — functions are *first-class values*: they can be passed as arguments, returned from calls, stored in variables/properties, and created inline — no special syntax beyond the forms in [§1](<../1. Function forms and the function object/1.1. Function declarations expressions and hoisting.md>):

```js
// Pass as argument — callback
function repeat(n, action) { for (let i = 0; i < n; i++) action(i); }
repeat(3, (i) => console.log(i)); // 0 1 2

// Return as value — factory / closure (→ [Variables §3.3](<../../../04 Variables Scope and Closures/sections/3. Closures/3.3. Closure patterns privacy factories memoization.md>))
function makeAdder(a) { return (b) => a + b; }
const add3 = makeAdder(3);
console.log(add3(7)); // 10 — closure over a

// Store in a collection — dispatch table (replaces switch)
const ops = {
  add: (a, b) => a + b,
  mul: (a, b) => a * b,
};
console.log(ops.add(2, 3), ops.mul(2, 3)); // 5 6

// Choose at runtime
const pick = Math.random() > 0 ? ops.add : ops.mul;
console.log(typeof pick); // function
```

- *Why it matters* — first-class functions turn control flow inside-out: the caller decides *what* to do, the callee decides *when* — the callback contract that powers `map`/`then`/`setTimeout`.

### 2) **Higher-order functions in the stdlib — mapper vs predicate contracts**

The standard library's HOFs have precise per-element contracts; mismatching them is the top bug source:

```js
// map: (value, index, array) => newValue — one output per input
console.log([1, 2, 3].map((n) => n * 2)); // [ 2, 4, 6 ]

// filter: (value, index, array) => boolean — keeps if truthy (→ [Values §2.4](<../../../03 Values Types and Coercion/sections/2. The conversion algorithms/2.4. ToBoolean the complete falsy list.md>))
console.log([1, 2, 3, 4].filter((n) => n % 2 === 0)); // [ 2, 4 ]

// reduce: (acc, value, index, array) => acc — accumulates (initial value matters)
console.log([1, 2, 3].reduce((acc, n) => acc + n, 0)); // 6
console.log([1, 2, 3].reduce((acc, n) => acc + n));    // 6 — first element as initial acc (danger on empty!)
try { console.log([].reduce((a, n) => a + n)); } catch (e) { console.log(e.name); } // TypeError on empty without init

// sort: (a, b) => negative|0|positive — in-place (→ Numbers domain, textual forward ref)
console.log([3, 1, 2].sort((a, b) => a - b)); // [ 1, 2, 3 ]

// find / some / every — short-circuit predicates
console.log([1, 2, 3].find((n) => n > 1)); // 2
console.log([1, 2, 3].some((n) => n > 2)); // true
console.log([1, 2, 3].every((n) => n > 0)); // true

// Pitfall: passing a method directly drops this (→ [3.1](<../3. this binding/3.1. Call-site rules default implicit explicit new and strict mode.md>))
class Parser {
  prefix = "p:";
  parse(s) { return this.prefix + s; }
}
const parser = new Parser();
console.log(["a", "b"].map((s) => parser.parse(s))); // [ 'p:a', 'p:b' ]
try { console.log(["a", "b"].map(parser.parse)); } catch (e) { console.log(e.name); } // TypeError
console.log(["a", "b"].map(parser.parse.bind(parser))); // [ 'p:a', 'p:b' ]
```

### 3) **Composition and partial application — glue without nesting**

```js
// compose / pipe — left-to-right (pipe) and right-to-left (compose)
const pipe = (...fns) => (x) => fns.reduce((v, f) => f(v), x);
const compose = (...fns) => (x) => fns.reduceRight((v, f) => f(v), x);

const add1  = (n) => n + 1;
const double = (n) => n * 2;
console.log(pipe(add1, double)(5));    // 12 — (5+1)*2
console.log(compose(double, add1)(5)); // 12 — same, reversed order

// Currying vs bind-partial — trade explicit arity vs this parameter
function mul(a, b, c) { return a * b * c; }
const curried = (a) => (b) => (c) => a * b * c;
console.log(curried(2)(3)(4)); // 24

const partial = mul.bind(null, 2);
console.log(partial(3, 4)); // 24 — partial via bind (thisArg ignored, → [3.3](<../3. this binding/3.3. call apply bind and bound functions.md>))

// Point-free style — when it helps vs obfuscates
const toUpper = (s) => s.toUpperCase();
const exclaim = (s) => s + "!";
console.log(pipe(toUpper, exclaim)("hello")); // HELLO!
// But don't point-free away readability — keep intermediate names where they document intent

// Real pipeline — parsing then validating (uses rest/pipe with array HOFs)
const parse = (s) => JSON.parse(s);
const hasPort = (obj) => typeof obj.port === "number";
console.log(pipe(parse, hasPort)('{"port":3000}')); // true
console.log([1, 2, 3].map(pipe(add1, double)));     // [ 4, 6, 8 ]
```

### 4) **Common confusion**

- "`map` with `parseInt` gives `[1, NaN, NaN]`" — `parseInt` receives `(value, index)` where index becomes radix (`parseInt("2",1)` → NaN); wrap it: `.map(s => parseInt(s, 10))`.
- "`reduce` without initial value works on empty arrays" — throws TypeError; always supply initial value unless you can prove non-empty.
- "Passing `obj.method` as callback keeps `this`" — no; receiver is lost at the call site ([3.1](<../3. this binding/3.1. Call-site rules default implicit explicit new and strict mode.md>)); wrap with arrow or bind.
- "Composition is free" — each `pipe` step allocates a closure; for hot loops, write the two-line body directly — clarity beats combinator cleverness.

### 5) **Performance note**

HOFs allocate callbacks; `map`/`filter` allocate new arrays per step. Chaining `.map(...).filter(...).map(...)` makes three passes and three allocations — for large arrays, a single `for` loop or `for-of` with `push` is faster and GC-friendlier. Abstraction is for readability on small/medium data; streaming or single-pass loops win at scale — [measure](<../../../01 Fundamentals and Mental Model/sections/2. How JavaScript executes/2.1. Parse bytecode JIT pipeline and single-threaded execution.md>).

### 6) **Mentor note**

Have juniors implement `map` in 3 lines (`for (let i=0;i<arr.length;i++) out.push(fn(arr[i],i,arr))`) then ask why `arr.map(parseInt)` breaks — the `index → radix` surprise teaches the contract instantly. In review, flag `.map(this.method)` without `bind`/`arrow` and `reduce` without initial value.
