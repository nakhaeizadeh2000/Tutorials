**Stop-list (do not re-teach here; link above):**

- `ToNumber`/`ToString` tables, `ToPrimitive` dance, boxing `new String`/`new Number` wrappers, `Symbol.toPrimitive`.
- String `length` as code units, grapheme clusters, `normalize`, `Intl.Segmenter`, `RegExp` unicode sets.
- `Array` exotic `length`, holes, `TypedArray` `BYTES_PER_ELEMENT`, `SharedArrayBuffer`/`Atomics`.
- `Map`/`Set` ordering, `WeakRef`/`FinalizationRegistry` GC timing, iterator protocol.
- `JSON` `replacer` for `BigInt`, `structuredClone` of `Date`/`Temporal`.

**When to extend this domain vs a neighbor:**

- New `Number`/`Math`/`Date`/`Temporal`/`Intl` APIs (e.g., `Decimal`, `Temporal` stage-4 additions) → here (append leaf or Update ECMAScript index module).
- New coercion, string, collection, or JSON mechanics → neighbor domain; add only a one-line cross-link here.
