## 2.1. Set creation uniqueness SameValueZero and iteration

### 1) **Creation and uniqueness by SameValueZero**

**Definition** — `Set` is the ordered collection of unique values. `new Set(iterable)` inserts each element and deduplicates by SameValueZero (same as `Map` keys — `NaN` deduped, `-0`/`+0` conflated). No literal syntax; spread/`Array.from` round-trip to arrays.

```js
// Creation — no literal
const empty = new Set();
console.log(empty.size); // 0

const nums = new Set([1, 2, 2, 3, NaN, NaN, -0, +0]);
console.log(nums.size); // 4 — { 1, 2, 3, NaN } — -0/+0 collapse, NaNs collapse
console.log([...nums]); // [ 1, 2, 3, NaN ]

// Objects dedupe by identity, not structure
const a = { id: 1 };
const b = { id: 1 };
const objSet = new Set([a, b, a]);
console.log(objSet.size); // 2 — a and b are different identities
console.log(objSet.has(a), objSet.has(b), objSet.has({ id: 1 })); // true true false

// Array dedup via Set — single line, insertion order preserved
const items = ["a", "b", "a", "c", "b"];
const unique = [...new Set(items)];
console.log(unique); // [ 'a', 'b', 'c' ]

// Set.from? — no static from; use new Set(iterable) or Set + spread
console.log(new Set("hello").size); // 4 — iterable "hello" → 'h','e','l','l','o' deduped
```

### 2) **Insertion order and iteration — entries are `[v,v]`**

**Definition** — `Set` iterates in insertion order: `values()` (and `keys()` — alias for `values` for `Map` symmetry), `entries()` yields `[v, v]` pairs, `for-of` yields values directly, `forEach` calls `(value, value, set)`. Re-adding an existing value does **not** move it; delete+re-add moves to end (mirrors `Map`).

```js
// Iteration order = insertion order
const s = new Set(["b", "a", "c"]);
console.log([...s]); // [ 'b', 'a', 'c' ]
console.log([...s.keys()], [...s.values()]); // [ 'b', 'a', 'c' ] [ 'b', 'a', 'c' ] — keys === values
console.log([...s.entries()]); // [ [ 'b','b' ], [ 'a','a' ], [ 'c','c' ] ] — entries duplicates for Map compat

// for-of vs entries vs forEach shape
for (const v of s) console.log(v); // b a c — values directly
s.forEach((v1, v2, set) => console.log(v1 === v2, set === s)); // true true — forEach receives (v, v, set)

// Updating membership does not reorder
s.add("a"); // already present
console.log([...s]); // [ 'b', 'a', 'c' ] — "a" stays

s.delete("a");
s.add("a");
console.log([...s]); // [ 'b', 'c', 'a' ] — moved to end

// Live mutation during iteration — like Map, added after current position may be visited, deleted skips
const s2 = new Set(["a", "b", "c"]);
const seen = [];
for (const v of s2) {
  seen.push(v);
  if (v === "a") s2.add("d");
  if (v === "b") s2.delete("c");
}
console.log(seen); // [ 'a', 'b', 'd' ] — c skipped, d visited
console.log([...s2]); // [ 'a', 'b', 'd' ]
```

### 3) **`has`/`add`/`delete`/`clear`/`size` and value identity**

```js
// add returns this (chainable); has disambiguates presence
const s3 = new Set();
console.log(s3.add(1) === s3); // true — chainable
s3.add(NaN);
console.log(s3.has(NaN), s3.has(-0), s3.has(+0)); // true true true — SameValueZero
console.log(s3.size); // 2

console.log(s3.delete(NaN), s3.size); // true 1
console.log(s3.delete(NaN)); // false — already gone
s3.clear();
console.log(s3.size); // 0

// Identity vs structural equality — same pitfall as Map
const set = new Set();
const o1 = { x: 1 };
const o2 = { x: 1 };
set.add(o1);
console.log(set.has(o1)); // true — same identity
console.log(set.has(o2)); // false — different object despite same shape
console.log(set.has({ x: 1 })); // false — new object

// Set "has NaN" is the fix for Array.includes vs indexOf
console.log([NaN].indexOf(NaN)); // -1 — skipped
console.log([NaN].includes(NaN)); // true — SameValueZero (Array.includes mirrors Set)
console.log(new Set([NaN]).has(NaN)); // true — Set also SameValueZero
```

### 4) **Common confusion**

- "`Set` has `keys` that differ from `values`" — no, `keys()` === `values()` — alias for `Map` API symmetry. `entries()` yields `[v,v]`.
- "Adding an existing member moves it" — no, only delete+re-add moves to end.
- "`Set` deduplicates by `===`" — no, SameValueZero (`NaN` dedupes, `-0/+0` collapse). Predict with `NaN` in review.
- "Objects dedupe by content" — no, by identity. `new Set([{a:1},{a:1}])` size is 2.

### 5) **Performance note**

Membership tests are average O(1). For deduplication and `O(1)` existence checks, `Set` beats `Array.includes` (O(n) scan). For tiny arrays (`n < ~10`) and rare lookups, the array scan can be faster than `Set` construction cost — measure. Iteration allocates an iterator per `for-of`; `forEach` avoids it on some engines. Adding during iteration is supported — same live-list walk as `Map`.
