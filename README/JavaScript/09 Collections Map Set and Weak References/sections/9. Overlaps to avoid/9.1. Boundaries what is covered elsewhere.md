## 9.1. Boundaries: what is covered elsewhere

### 1) **Iterator protocol, `for-of`, generators, and async iteration**

This domain treats `Map`/`Set` iteration only as insertion-order, live-mutation, and SameValueZero deduplication contracts; the protocol (`Symbol.iterator`, `next()`/`done`, iterable vs iterator, `yield`), generator functions, and `for await...of` live in [Iterables, Generators, and Async Iteration](<../../../10 Iterables Generators and Async Iteration/README.md>) (see [iterable protocol](<../../../10 Iterables Generators and Async Iteration/sections/1. Iterable and iterator protocols/1.1. Iterable vs iterator vs array-like and Symbol.iterator.md>) and [generators](<../../../10 Iterables Generators and Async Iteration/sections/3. Generators/3.1. Generator functions yield suspension and the Generator object.md>)). That domain owns custom iterables, `Array.from` as iterator consumer, and generator delegation — here only per-collection tables (see [1.1](<../1. Map deep dive/1.1. Map creation SameValueZero insertion order and iteration.md>) / [2.1](<../2. Set deep dive/2.1. Set creation uniqueness SameValueZero and iteration.md>)).

### 2) **GC internals, heap snapshots, and `structuredClone`/`JSON` serialization**

Heap graph reachability, mark-and-sweep/compact phases, `ArrayBuffer` transfer vs clone, heap-snapshot debugging, and deep GC tuning live in **Memory Management and GC** (domain 18). `JSON.stringify`/`parse` replacer/reviver, `toJSON`, symbol omission, and `structuredClone` belong to **JSON Serialization** (domain 16); `WeakRef`/`FinalizationRegistry` timing nondeterminism is *introduced* here but engine internals/profiling remain there. Array hole→`null` and `BigInt` replacer details also in those domains — here only `Map`→`[...map]` before `JSON`.

### 3) **Object descriptors, prototype chain, class private fields, and branding alternatives**

Data vs accessor descriptors, `getOwnPropertyDescriptor`, `Object.create`/`getPrototypeOf`/`setPrototypeOf`, and `#private` brand checks are owned by **Objects in Depth** (domain 06) ([descriptors](../../../06 Objects in Depth/sections/2. Properties and descriptors/2.1. Data vs accessor descriptors and attribute defaults.md>), [defining](../../../06 Objects in Depth/sections/2. Properties and descriptors/2.2. Defining observing and configuring properties.md>), [creation & prototype wiring](../../../06 Objects in Depth/sections/1. Object creation and literals/1.2. Creation patterns literal Object create and constructors.md)) and **Prototypes and Classes** (domain 07) ([private encapsulation](../../../07 Prototypes and Classes/sections/3. Class syntax/3.3. Private fields and methods brand checks and encapsulation.md>)). `WeakMap`/`WeakSet` private-association patterns in [3.1](../3. Weak collections/3.1. WeakMap ephemeron keys non-iterability and use cases.md) / [3.2](../3. Weak collections/3.2. WeakSet object-only membership and non-iterability.md) contrast with `#private` but do not re-derive descriptor or `super` mechanics.

### 4) **Numbers, `NaN`/`-0` coercion tables, and string/regex/temporal formatting**

`ToNumber`/`ToString`/`ToPropertyKey`, coercion tables, `isNaN` vs `Number.isNaN`, and number formatting/`Temporal` belong to **Values, Types, and Coercion** (domain 03) ([ToString/ToNumber](../../../03 Values Types and Coercion/sections/2. The conversion algorithms/2.2. ToString and ToNumber the exact conversion tables.md>), [ToPrimitive](../../../03 Values Types and Coercion/sections/2. The conversion algorithms/2.3. ToPrimitive and the valueOf toString and Symbol.toPrimitive dance.md>)) and **Numbers, Dates, Math, Temporal** (domain 12). Here only the SameValueZero discipline that derives from `NaN`/`-0` identity; full numeric path stays there.

### 5) **Scope, closures, memoization shape, and `this` binding**

Lexical scope chains, TDZ, closure per-iteration capture, and `this` call-site rules belong to **Variables, Scope, and Closures** (domain 04) ([closures](../../../04 Variables Scope and Closures/sections/3. Closures/3.1. Closures functions that remember their birth environment.md>), [GC pinning](../../../04 Variables Scope and Closures/sections/3. Closures/3.4. Closures and garbage collection what stays alive.md>)) and **Functions Deep Dive** (domain 05). `WeakMap` memoization shape in [3.1](../3. Weak collections/3.1. WeakMap ephemeron keys non-iterability and use cases.md) reuses those but does not re-teach closure capture.

### 6) **Where this domain stops — single source of truth**

- *This domain owns:* `Map`/`Set` creation, SameValueZero, insertion-order + live-mutation, `get`/`set`/`has`/`delete`/`clear`/`size` vs object `ToPropertyKey` trade-offs, dedup/algebra, `WeakMap`/`WeakSet` ephemeron keys (object-only, non-iterable), `WeakRef` `deref()` nondeterminism and single-deref pattern, `FinalizationRegistry` held-value/token/`unregister` and never-for-correctness, Map vs Object vs Set vs Array vs Weak decision/performance matrices.
- *Does not own:* iterator protocol deep dive, heap snapshot/GC internals and `structuredClone` deep semantics, `class`/`super`/`#private` dispatch internals, full `ToPrimitive`/`ToNumber` coercion tables, or scope/closure/`this` mechanics — linked instead of rewritten.
