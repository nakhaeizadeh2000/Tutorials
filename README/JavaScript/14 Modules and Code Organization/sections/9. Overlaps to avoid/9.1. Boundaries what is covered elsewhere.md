## 9.1. Boundaries what is covered elsewhere

### 1) **Scope hoisting and top-level `this` — Variables Scope and Closures; `this` binding rules — Functions Deep Dive**

Module top-level scope mechanics (`globalThis` two-layer vs declarative record, `var` leak in script vs private by default in module), TDZ, and `this === undefined` in modules vs `globalThis` in scripts live in [Variables Scope 4.1](<../../../04 Variables Scope and Closures/sections/4. Top level scopes scripts modules and eval/4.1. Script vs module top level globalThis and the declarative record.md>). This domain only builds on those contracts for ESM/CJS file detection; `call`/`apply`/`bind` and arrow lexical `this` detail remain in [Functions Deep Dive](<../../../05 Functions Deep Dive/README.md>).

### 2) **Top-level `await` blocking and Promise scheduling — Async Event Loop and Promises; async iteration backpressure — Iterables Generators and Async Iteration**

TLA's per-dependent blocking semantics, job vs task ordering, `queueMicrotask`/`nextTick`, and concurrency patterns (sequential vs `Promise.all` vs `race`) live in [Async 5.2](<../../../13 Async Event Loop and Promises/sections/5. Promises core/3.1. Promise states executor thenable assimilation and the job queue.md>). Here we only note that TLA modules block importers during evaluation (3.1) and that dynamic `import()` returns a promise namespace (4.1).

### 3) **JSON stringify/parse replacer/reviver contracts — [JSON Serialization and Data Exchange](<../../../16 JSON Serialization and Data Exchange/README.md>); `Temporal`/`Intl` and `Math` — Numbers Dates Math and Temporal**

`JSON.stringify`/`parse` with `toJSON`/`replacer`/`reviver` ([stringify what drops](<../../../16 JSON Serialization and Data Exchange/sections/2. Stringifying and serialization/2.1. ### 4) **Barrel tree-shaking/minification internals and bundler chunk config — Tooling/Memory domains (when they land); `WeakRef`/`FinalizationRegistry` GC — Collections/Memory**

### 5) **Class/prototype delegation and `super` in modules — Prototypes and Classes; object descriptor and enumeration — Objects in Depth**

Class fields/privates, `extends`/`super` wiring, prototype linkage cost of `setPrototypeOf`, and property descriptor defaults (`writable`/`enumerable`/`configurable`, `Object.keys` vs `Reflect.ownKeys`) live in [Prototypes 3.1](<../../../07 Prototypes and Classes/sections/3. Data vs accessor descriptors and attribute defaults.md>). Modules only re-export classes as bindings — same live-binding rules apply.

### 6) **Strings/RegExp/Intl.Segmenter text processing — Strings and Regular Expressions**

String well-formedness (`isWellFormed`/`toWellFormed`), grapheme segmentation via `Intl.Segmenter`, and `RegExp` unicode flags live in [Strings 1.1](<../../../11 Strings and Regular Expressions/sections/1. String model/1.1. String primitives immutability UTF-16 and well-formedness.md>). Module specifiers are strings but `normalize`/`Segmenter` do not affect resolution (URL-based, not grapheme-based).
