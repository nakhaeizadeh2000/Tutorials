## 6.1. Metaprogramming checklist reflex rules mentors screen for

### 1) **The five reflexes — "what symbol? what trap? invariant-safe? receiver forwarded? cross realm?"**

**Definition** — every metaprogramming code path should trigger one of five checks; mentors screen for them verbatim.

| # | Reflex | When it fires | One-sentence rule |
|---|---|---|---|
| 1 | **What symbol?** | Any protocol customization (`for...of`, `instanceof`, `+`, `concat`, `toString`) | Name the well-known symbol from the table in [1.1](<../1. Symbols deep/1.1. Well-known symbols the protocol hook table.md>) — never a string name |
| 2 | **What trap?** | Any `new Proxy` | List the 13 trap names from [2.1](<../2. Proxy core/2.1. Proxy handler the 13 trap table and forwarding.md>) — `Object.keys` is not a trap |
| 3 | **Invariant-safe?** | Any trap that touches non-configurable/non-extensible target | Echo frozen descriptors truthfully via `Reflect.*` — see [2.2](<../2. Proxy core/2.2. Proxy invariants non-configurable non-extensible and exotic constraints.md>) |
| 4 | **Receiver forwarded?** | Any `get`/`set` trap with accessors or prototype chain | Use `Reflect.get(t,k,receiver)` / `Reflect.set(t,k,v,receiver)` — never `t[k]` — see [3.2](<../3. Reflect core/3.2. Receiver forwarding and correct this.md>) |
| 5 | **Cross realm / registry?** | Any `Symbol.for`/`instanceof`/`isArray` check | `Symbol.for` is global-shared, `Symbol()` is isolated; `instanceof` fails cross-realm — use `Array.isArray` or `WeakSet` brand — see [1.2](<../1. Symbols deep/1.2. Symbol creation description global registry and hidden keys.md>) and [Prototypes 5.1](<../../../07 Prototypes and Classes/sections/5. Type checks and reflection/5.1. instanceof isPrototypeOf Symbol.hasInstance and cross-realm failures.md>) |

```js
// Five reflexes as a checklist — runnable grep-style guard for review
function checkWellKnown(sym){
  const known = [Symbol.iterator, Symbol.asyncIterator, Symbol.hasInstance, Symbol.isConcatSpreadable,
    Symbol.toStringTag, Symbol.toPrimitive, Symbol.species, Symbol.unscopables,
    Symbol.match, Symbol.replace, Symbol.search, Symbol.split, Symbol.hasInstance];
  if (!known.includes(sym)) console.log("reflex 1: unknown well-known?", String(sym));
}
checkWellKnown(Symbol.iterator); // ok

// Reflex 2 — handler trap name typo fails silently (no trap, transparent forwarding)
// Bad: deleteProperty named delete — never called
const badHandler = { delete(t,k){ return true; } }; // typo — should be deleteProperty
const pBad = new Proxy({ a: 1 }, badHandler);
console.log(delete pBad.a, pBad.a); // false? Actually delete fell through to target (since trap name wrong) → deleted

// Reflex 3 — verify via freezing in test
const frozen = Object.freeze({ x: 1 });
const ok = new Proxy(frozen, { get(t,k,r){ return Reflect.get(t,k,r); } });
console.log(ok.x); // 1 — forwarding preserves invariant

// Reflex 4 — identity test
const base = { get self(){ return this; } };
const good = new Proxy(base, { get(t,k,r){ return Reflect.get(t,k,r); } });
console.log(good.self === good); // true — receiver correct

// Reflex 5 — registry isolation
console.log(Symbol("a") === Symbol("a")); // false — isolated
console.log(Symbol.for("a") === Symbol.for("a")); // true — shared
```

### 2) **The review grep list**

**Definition** — six `grep` patterns that catch most metaprogramming bugs pre-commit:

| Pattern | What it finds | Fix |
|---|---|---|
| `Symbol\.for\(.*hasInstance`/`Symbol\.for\(.*iterator` | well-known via registry | Use `Symbol.iterator` constant, not `Symbol.for` |
| `target\[.*\]` inside `get\(.*\)` or `set\(.*\)` | bare `target[key]` losing receiver | Replace with `Reflect.get`/`Reflect.set` with `receiver` |
| `ownKeys.*return.*\[` without `Reflect\.ownKeys` | filtered `ownKeys` missing non-configurable | Forward via `Reflect.ownKeys` then filter only configurable |
| `get\(.*\)\{.*return 999` with frozen target in tests | `get` invariant lie | Return `Reflect.get` value for frozen props |
| `\[Symbol\.toPrimitive\].*return \{\}` | `@@toPrimitive` returning object | Guarantee primitive else throw |
| `revoke.*` without `finally`/`try.*finally` | leaked revocable | Add `try{…}finally{ revoke(); }` |

```js
// Grep-friendly discipline — search your codebase
// Example: prevent bare target[key] in handlers
// rg: `get\s*\(.*\)\s*\{[^}]*\bt\[k\]` -> flag

// Correct template per trap (copy-paste)
const template = {
  get(t,k,r){ return Reflect.get(t,k,r); },
  set(t,k,v,r){ return Reflect.set(t,k,v,r); },
  has(t,k){ return Reflect.has(t,k); },
  deleteProperty(t,k){ return Reflect.deleteProperty(t,k); },
  ownKeys(t){ return Reflect.ownKeys(t); },
  getOwnPropertyDescriptor(t,k){ return Reflect.getOwnPropertyDescriptor(t,k); },
  defineProperty(t,k,d){ return Reflect.defineProperty(t,k,d); },
  getPrototypeOf(t){ return Reflect.getPrototypeOf(t); },
  setPrototypeOf(t,p){ return Reflect.setPrototypeOf(t,p); },
  isExtensible(t){ return Reflect.isExtensible(t); },
  preventExtensions(t){ return Reflect.preventExtensions(t); },
  apply(t,thisArg,args){ return Reflect.apply(t,thisArg,args); },
  construct(t,args,nt){ return Reflect.construct(t,args,nt); }
};
console.log(Object.keys(template).length); // 13 — all traps accounted
```

### 3) **Boundary rule — `Proxy`/`Reflect` never paper over broken invariants; fix the target first**

**Definition** — if `Object.isExtensible(target) === false`, `proxy` cannot pretend extensible; if property is non-configurable, descriptor cannot be hidden. Fix target extensibility/freeze before proxying, not inside traps.

```js
// Fix target, not trap
const t = { id: 1 };
Object.defineProperty(t, "id", { value: 1, configurable: false, writable: false });
try {
  const lying = new Proxy(t, { getOwnPropertyDescriptor(){ return undefined; } });
  Object.getOwnPropertyDescriptor(lying, "id");
} catch(e){ console.log("trap cannot hide non-configurable:", e.name); } // TypeError
// Correct — freeze intent belongs on target lifecycle, not proxy cleverness
const correct = new Proxy(Object.freeze({ id: 1 }), { get(t,k,r){ return Reflect.get(t,k,r); } });
console.log(Object.isFrozen(correct)); // false? Proxy forwarding? Actually Object.isFrozen checks [[IsExtensible]]+configurable — forwards via trap
// To freeze proxy view, freeze the target and let invariants enforce it
```

- **Modern guidance** — keep metaprogramming isolated to API boundaries; never proxy hot inner loops; wrap at module export boundary, not per-instance.

### 4) **Common confusion**

- "`Checklist reflex 5 crosses to JSON`" — `JSON.stringify` skips symbols (see [JSON 2.1](<../../../16 JSON Serialization and Data Exchange/sections/2. Stringifying and serialization/2.1. What JSON.stringify serializes and what it drops.md>)) and `structuredClone` drops them too — symbols are not on the wire.

### 5) **Performance note**

Checklist items are not runtime cost — they are review-time constraints. Enforcing them via `eslint` plugin (`no-target-property-access-in-trap`) catches most invariant/receiver bugs at lint, not at per-access cost.

### 6) **Mentor note**

Hand trainees a one-page table with the five reflexes and the 13 trap names. Run a code-review drill: present a handler with `get(t,k){ return t[k]; }` and `ownKeys(){ return ["a"]; }` on a frozen target — trainees must spot both bugs (receiver + invariant) in under a minute.
