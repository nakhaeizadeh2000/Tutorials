## 4.1. Customizing coercion toPrimitive toStringTag hasInstance and match hooks

### 1) **`@@toPrimitive(hint)` — the string/number/default dispatch**

**Definition** — when coercion needs a primitive, the engine calls `obj[Symbol.toPrimitive](hint)` with `hint` one of `"string"`, `"number"`, `"default"`. `String(obj)` uses `"string"`, `Number(obj)`/`+` with number context uses `"number"`, `+` with string side or template `${obj}` uses `"default"` (legacy `Date` maps `default`→`string`). Return must be a primitive — otherwise `TypeError`.

**What problem it solves / history** — prior to ES2015 coercion relied on two named methods `valueOf`/`toString` with implicit hint ordering (see [Values 2.3](<../../../03 Values Types and Coercion/sections/2. The conversion algorithms/2.3. ToPrimitive and the valueOf toString and Symbol.toPrimitive dance.md>)). `@@toPrimitive` lets an object own the dispatch and disambiguate string vs number contexts explicitly. Added ES2015; stable.

```js
// @@toPrimitive hint dispatch — which coercion triggers which hint
const money = {
  cents: 12345,
  [Symbol.toPrimitive](hint) {
    if (hint === "string") return `$${(this.cents/100).toFixed(2)}`;
    if (hint === "number") return this.cents;
    return this.cents; // default → number (unlike Date which maps default→string)
  }
};
console.log(String(money)); // $123.45 — hint string
console.log(Number(money)); // 12345 — hint number
console.log(money + 0);     // 12345 — hint default → number
console.log(`${money}`);    // $123.45 — template → string
console.log(money + "");    // 12345? Actually + with string coerces via default? default→number then ToString? Check
// + operator with one primitive string does ToPrimitive default then ToString; our default returns number 12345 → "12345"
console.log(money + ""); // "12345" — default→number then concatenation ToString

// Date legacy quirk — default maps to string
console.log(String(new Date(0)).slice(0,4)); // 1970 — Date's @@toPrimitive maps default→string
const plain = { [Symbol.toPrimitive](h){ return h; } };
console.log(plain + ""); // "default"

// Must return primitive — object return throws
const bad = { [Symbol.toPrimitive](){ return {}; } };
try { String(bad); } catch (e) { console.log("non-primitive:", e.name); } // TypeError

// Missing @@toPrimitive falls back to OrdinaryToPrimitive valueOf→toString (see Values 2.3)
const fallback = { valueOf(){ return 7; }, toString(){ return "seven"; } };
console.log(String(fallback), Number(fallback), fallback + ""); // seven 7 7
```

- **Modern guidance** — always handle all three hints branch explicitly; never return an object; for numeric domain objects, make `default`→`number` to avoid surprise `"12345"` vs `"$123.45"` in concatenation.

### 2) **`@@toStringTag` — the `Object.prototype.toString` brand string**

**Definition** — `Object.prototype.toString.call(obj)` returns `"[object " + tag + "]"` where `tag` is `obj[Symbol.toStringTag]` if present and string, else internal `[[Class]]` fallback (`"Object"`/`"Array"` etc.). Tag is looked up via ordinary property access (own or prototype). Non-string tags are ignored.

```js
// @@toStringTag controls the brand string
console.log(Object.prototype.toString.call({})); // [object Object]
console.log(Object.prototype.toString.call([])); // [object Array]
console.log(Object.prototype.toString.call(new Map())); // [object Map]

class Widget { get [Symbol.toStringTag](){ return "Widget"; } }
console.log(Object.prototype.toString.call(new Widget())); // [object Widget]
console.log(new Widget().toString()); // [object Widget] — Object.prototype.toString used

// Built-ins set it on prototype
console.log(Object.prototype.toString.call(Promise.resolve())); // [object Promise]
console.log(Object.getOwnPropertyDescriptor(Map.prototype, Symbol.toStringTag));

// Placement matters — own vs prototype, data vs accessor
const a = { [Symbol.toStringTag]: "A" };
console.log(Object.prototype.toString.call(a)); // [object A]
const b = {};
Object.defineProperty(b, Symbol.toStringTag, { value: 123, writable: true }); // non-string → ignored
console.log(Object.prototype.toString.call(b)); // [object Object]

// Proxy can intercept toStringTag (get trap)
const target = { [Symbol.toStringTag]: "Real" };
const proxy = new Proxy(target, {
  get(t,k,r){ if (k === Symbol.toStringTag) return "ProxyWidget"; return Reflect.get(t,k,r); }
});
console.log(Object.prototype.toString.call(proxy)); // [object ProxyWidget]
```

- **Modern guidance** — use `toStringTag` for diagnosis/logging brand only; not for security checks (attacker can fake). For reliable type checks, prefer `Array.isArray` / brand `WeakSet` (see [Prototypes 5.1](<../../../07 Prototypes and Classes/sections/5. Type checks and reflection/5.1. instanceof isPrototypeOf Symbol.hasInstance and cross-realm failures.md>)).

### 3) **`@@hasInstance` — rewriting `instanceof`**

**Definition** — `x instanceof C` ≡ `C[Symbol.hasInstance](x)` when `C` defines it; else `OrdinaryHasInstance` walks `x`'s prototype chain for `C.prototype`. `@@hasInstance` can be on any object (function or plain), receives the LHS value, must return `boolean`.

```js
// @@hasInstance custom instanceof
class Even { static [Symbol.hasInstance](x){ return typeof x === "number" && x % 2 === 0; } }
console.log(2 instanceof Even, 3 instanceof Even, "hi" instanceof Even); // true false false

// Non-constructor object with @@hasInstance also works with instanceof (LHS any value, RHS needs @@hasInstance)
const OddChecker = { [Symbol.hasInstance](x){ return typeof x === "number" && x % 2 === 1; } };
console.log(3 instanceof OddChecker); // true — RHS need not be function if it has the hook? Actually spec requires function? Check
// In V8, non-function RHS with @@hasInstance still works when accessed via call? Let's test via ordinary call
console.log(OddChecker[Symbol.hasInstance](3)); // true — direct call works; instanceof on non-function may still throw?
try { console.log(3 instanceof OddChecker); } catch (e){ console.log("non-fn instanceof:", e.name, e.message.slice(0,40)); }

// Ordinary fallback — prototype walk
class Base {}
class Child extends Base {}
console.log(new Child() instanceof Base); // true — OrdinaryHasInstance walk
console.log({} instanceof Base); // false

// Primitives — OrdinaryHasInstance returns false; custom @@hasInstance can handle them
function isStringWrapper() {}
isStringWrapper[Symbol.hasInstance] = (v) => typeof v === "string" || v instanceof String;
console.log("hi" instanceof isStringWrapper, new String("hi") instanceof isStringWrapper); // true true
```

- **Modern guidance** — custom `hasInstance` must not assume `x` is object; handle primitives and throw `TypeError` only intentionally. Do not use it to paper over broken inheritance — fix the prototype chain.

### 4) **`@@match`/`@@replace`/`@@search`/`@@split` — customizing `String` pattern dispatch**

**Definition** — `str.match(re)` does not contain RegExp logic; it calls `re[Symbol.match](str)` if present. Same for `replace`, `search`, `split`. This makes `String` methods generic over pattern objects (e.g., glob, case-fold).

```js
// String delegates to pattern's symbol
const glob = {
  [Symbol.match](str){ return str.endsWith(".js") ? [str] : null; },
  [Symbol.replace](str, rep){ return str.endsWith(".js") ? rep : str; }
};
console.log("app.js".match(glob)); // ["app.js"]
console.log("app.js".replace(glob, "out.js")); // out.js
console.log("app.txt".match(glob)); // null

// RegExp's default impl lives at RegExp.prototype[Symbol.match]
console.log(RegExp.prototype[Symbol.match].name);

// Custom search: return index or -1
const ci = {
  needle: "hello",
  [Symbol.search](str){ return str.toLowerCase().indexOf(this.needle); }
};
console.log("HELLO world".search(ci)); // 0 — case-insensitive via custom hook

// Proxy can virtualize match
const proxyRe = new Proxy(/foo/g, {
  get(t,k,r){
    if (k === Symbol.match) return (str) => [`proxy:${str}`];
    return Reflect.get(t,k,r);
  }
});
console.log("foo".match(proxyRe)); // [ 'proxy:foo' ]
```

### 5) **Common confusion**

- "`@@toPrimitive` is called with `hint === 'default'` for `String(obj)`" — no; `String` uses `"string"` and `Number` uses `"number"`; `default` is for `+`, `==`, template via spec's `ToPrimitive` with `preferredType` `default`.
- "`@@toStringTag` must be own property" — no; prototype placement works (built-ins put it on `prototype`); own shadows prototype.
- "`instanceof` requires RHS to be function" — only for OrdinaryHasInstance; with `@@hasInstance` a plain object can serve as RHS (though engines may still require callable RHS — handle `TypeError`).

### 6) **Performance note**

Each customization is a single symbol lookup per operation (`String(obj)` probes `@@toPrimitive` once, `Object.prototype.toString` probes `@@toStringTag` once). Cost identical to ordinary property access. Do not define `@@toPrimitive` per-instance on millions of objects — put it on the prototype.

### 7) **Mentor note**

Require trainees to state the hint trio and the dispatch table from memory. Ask: "What does `obj + ''` call?" Answer: `obj[Symbol.toPrimitive]('default')` if present else `OrdinaryToPrimitive('default')` → `valueOf` first. Flag any `toPrimitive` returning non-primitive (hidden until string coercion in logging path blows up).
