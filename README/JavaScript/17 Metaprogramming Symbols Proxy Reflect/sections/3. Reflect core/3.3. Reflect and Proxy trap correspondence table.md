## 3.3. Reflect and Proxy trap correspondence table

### 1) **One row per internal method — trap, signature, Reflect twin, default**

**Definition** — each of the 13 proxy traps maps 1:1 to a `Reflect.*` static method with identical semantics. Missing trap → engine calls `Reflect.*` identically. Hand-written traps should delegate to their twin unless they intentionally customize behavior.

| Trap | Signature | Reflect twin | Default forwarding |
|---|---|---|---|
| `get` | `(target, prop, receiver)` | `Reflect.get(target, prop, receiver)` | `Reflect.get` |
| `set` | `(target, prop, value, receiver)` | `Reflect.set(target, prop, value, receiver)` | `Reflect.set` |
| `has` | `(target, prop)` | `Reflect.has(target, prop)` | `Reflect.has` |
| `deleteProperty` | `(target, prop)` | `Reflect.deleteProperty(target, prop)` | `Reflect.deleteProperty` |
| `ownKeys` | `(target)` | `Reflect.ownKeys(target)` | `Reflect.ownKeys` |
| `getOwnPropertyDescriptor` | `(target, prop)` | `Reflect.getOwnPropertyDescriptor(target, prop)` | same |
| `defineProperty` | `(target, prop, descriptor)` | `Reflect.defineProperty(target, prop, descriptor)` | same |
| `getPrototypeOf` | `(target)` | `Reflect.getPrototypeOf(target)` | same |
| `setPrototypeOf` | `(target, proto)` | `Reflect.setPrototypeOf(target, proto)` | same |
| `isExtensible` | `(target)` | `Reflect.isExtensible(target)` | same |
| `preventExtensions` | `(target)` | `Reflect.preventExtensions(target)` | same |
| `apply` | `(target, thisArg, args)` | `Reflect.apply(target, thisArg, args)` | `Reflect.apply` — only callable |
| `construct` | `(target, args, newTarget)` | `Reflect.construct(target, args, newTarget)` | `Reflect.construct` — only constructable |

```js
// 1:1 correspondence — handler delegates to Reflect twin
const target = { x: 1, get y() { return this.x * 2; } };
const log = [];
const proxy = new Proxy(target, {
  get(t, k, r) { log.push(`get ${String(k)}`); return Reflect.get(t, k, r); },
  set(t, k, v, r) { log.push(`set ${String(k)}`); return Reflect.set(t, k, v, r); },
  has(t, k) { log.push(`has ${String(k)}`); return Reflect.has(t, k); },
  deleteProperty(t, k) { log.push(`del ${String(k)}`); return Reflect.deleteProperty(t, k); },
  ownKeys(t) { log.push("ownKeys"); return Reflect.ownKeys(t); },
  getOwnPropertyDescriptor(t, k) { log.push(`gopd ${String(k)}`); return Reflect.getOwnPropertyDescriptor(t, k); },
  defineProperty(t, k, d) { log.push(`define ${String(k)}`); return Reflect.defineProperty(t, k, d); },
  getPrototypeOf(t) { log.push("getProto"); return Reflect.getPrototypeOf(t); },
  setPrototypeOf(t, p) { log.push("setProto"); return Reflect.setPrototypeOf(t, p); },
  isExtensible(t) { log.push("isExt"); return Reflect.isExtensible(t); },
  preventExtensions(t) { log.push("prevExt"); return Reflect.preventExtensions(t); },
});
console.log(proxy.y); // get y (+ get x via receiver)
console.log("y" in proxy); // has y
console.log(Reflect.ownKeys(proxy)); // ownKeys
console.log(Object.getOwnPropertyDescriptor(proxy, "x")); // gopd x
Reflect.defineProperty(proxy, "z", { value: 3, writable: true, configurable: true, enumerable: true });
console.log(proxy.z);
console.log(Object.getPrototypeOf(proxy) === Object.prototype); // true → getProto
console.log(Object.isExtensible(proxy)); // true → isExt

// apply / construct twins only when target is function
function Fn(a,b){ this.sum=a+b; }
const withApply = new Proxy(Fn, {
  apply(t, thisArg, args){ return Reflect.apply(t, thisArg, args) * 10; },
  construct(t, args, nt){ const inst = Reflect.construct(t, args, nt); inst.extra = true; return inst; }
});
console.log(withApply(2,3)); // 50 — apply twin
console.log(new withApply(2,3).extra); // true — construct twin

// Template — forward by default, customize only one trap
function loggingProxy(obj) {
  return new Proxy(obj, {
    get(t,k,r){ console.log(`→ get ${String(k)}`); return Reflect.get(t,k,r); }
    // other traps default-forward implicitly — no need to list them
  });
}
console.log(loggingProxy({ a: 1 }).a);
```

### 2) **Arity and return contracts — what each trap must return**

**Definition** — traps have enforced return types; violating throws or signals failure:

- `get` → any value (no constraint except frozen data invariant — see [2.2](<../2. Proxy core/2.2. Proxy invariants non-configurable non-extensible and exotic constraints.md>)).
- `set` / `deleteProperty` / `defineProperty` / `setPrototypeOf` / `preventExtensions` / `isExtensible` → `boolean` (`true` success, `false` soft failure; strict callers throw).
- `has` → `boolean`.
- `ownKeys` → `Array` of strings+symbols (must include non-configurable keys, must not include extra when non-extensible).
- `getOwnPropertyDescriptor` → `property descriptor` object or `undefined` (must be compatible with target when non-configurable).
- `getPrototypeOf` → `object` or `null` (must equal target's proto when non-extensible).
- `apply` → any (target's call result); `construct` → object (must be object).

```js
// Return contract demos — boolean traps vs descriptor traps
const t2 = { a: 1 };
const p2 = new Proxy(t2, {
  set(tr, k, v, recv){ if (k === "a" && typeof v !== "number") return false; return Reflect.set(tr,k,v,recv); },
  deleteProperty(tr,k){ if (k === "a") return false; return Reflect.deleteProperty(tr,k); },
  defineProperty(tr,k,d){ if ("value" in d && d.value === 42) return false; return Reflect.defineProperty(tr,k,d); },
  has(tr,k){ return Reflect.has(tr,k); }, // must be boolean
  ownKeys(tr){ return Reflect.ownKeys(tr); }, // must be array
  getOwnPropertyDescriptor(tr,k){ const d = Reflect.getOwnPropertyDescriptor(tr,k); return d; } // desc or undefined
});
console.log(Reflect.set(p2, "a", "bad")); // false
console.log(Reflect.set(p2, "a", 2), p2.a); // true 2
console.log(Reflect.deleteProperty(p2, "a")); // false — blocked
console.log(Reflect.defineProperty(p2, "b", { value: 42, configurable:true, writable:true, enumerable:true })); // false
console.log(Reflect.defineProperty(p2, "b", { value: 7, configurable:true, writable:true, enumerable:true }), p2.b); // true 7
console.log(Reflect.has(p2, "a")); // true — boolean
console.log(Array.isArray(Reflect.ownKeys(p2))); // true
console.log(typeof Reflect.getOwnPropertyDescriptor(p2, "a")); // object
```

### 3) **Common confusion — `Object.keys` is not a trap**

**Definition** — `Object.keys(obj)` internally calls `[[OwnPropertyKeys]]` (the `ownKeys` trap) then filters to enumerable string keys and sorts integers first. `for...in` additionally walks the prototype chain via `[[GetPrototypeOf]]` and per-level `ownKeys` + enumerable checks. There is no `keys` or `enumerate` trap.

```js
// Object.keys vs ownKeys trap — filtering happens after trap
const base = { a: 1, b: 2 };
base[Symbol("s")] = 3;
Object.defineProperty(base, "hidden", { value: 4, enumerable: false });

const proxyBase = new Proxy(base, {
  ownKeys(t){ console.log("ownKeys called"); return Reflect.ownKeys(t); }
});
console.log(Object.keys(proxyBase)); // ownKeys called → [ 'a','b' ] — strings enumerable only, ints sorted, symbols/hidden filtered
console.log(Object.getOwnPropertyNames(proxyBase)); // ownKeys → [ 'a','b','hidden' ] — all strings
console.log(Object.getOwnPropertySymbols(proxyBase)); // ownKeys → [ Symbol(s) ]
console.log(Reflect.ownKeys(proxyBase)); // ownKeys → full list

// for...in also walks proto chain — each level's ownKeys
const proto = { inherited: 1 };
const child = Object.create(proto); child.own = 2;
const pChild = new Proxy(child, { ownKeys(t){ console.log("child ownKeys"); return Reflect.ownKeys(t); } });
for (const k in pChild) console.log(k); // child ownKeys, plus proto's own via chain walk → own inherited
```

### 4) **Common confusion**

- "`defineProperty` trap receives `value` directly" — no; it receives a *descriptor object* `{value, writable, enumerable, configurable, get, set}` — check `("value" in desc)` not `desc.value` existence via truthiness.
- "`ownKeys` returning extra keys is fine when non-extensible" — no; non-extensible target enforces exact match.
- "`isExtensible` trap can lie to hide freeze" — no; invariant ties it to target (see [2.2](<../2. Proxy core/2.2. Proxy invariants non-configurable non-extensible and exotic constraints.md>)).

### 5) **Performance note**

Each `Reflect.*` twin is a single builtin. Writing `ownKeys(t){ return Reflect.ownKeys(t).filter(...); }` costs one extra array filter allocation — keep filtering minimal on hot `Object.keys` paths.

### 6) **Mentor note**

In review, demand the correspondence table as comments above the handler: `// get → Reflect.get, set → Reflect.set, ...`. Reject any handler that calls `Object.*` where `Reflect.*` belongs (boolean contract mismatch). Quiz: "What must `ownKeys` return type be?" Answer: array of strings/symbols, with invariants — not a filtered boolean.
