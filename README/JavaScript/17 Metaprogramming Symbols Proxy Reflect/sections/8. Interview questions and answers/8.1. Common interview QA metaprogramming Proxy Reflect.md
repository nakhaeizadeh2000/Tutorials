## 8.1. Common interview QA metaprogramming Proxy Reflect

### 1) **The classics with mechanism-level answers**

**Q1 — How many Proxy traps are there, and what is `Object.keys` mapped to?**
`13` traps (see [2.1](<../2. Proxy core/2.1. Proxy handler the 13 trap table and forwarding.md>) and [3.3](<../3. Reflect core/3.3. Reflect and Proxy trap correspondence table.md>)). `Object.keys` is *not* a trap; `ownKeys` is, and `Object.keys` post-filters `ownKeys` for enumerable strings.

**Q2 — What does `Reflect.set` return vs `Object.defineProperty`/`target[key]=value`?**
`Reflect.set`/`Reflect.defineProperty` return `boolean` (`true` success, `false` soft failure); `Object.defineProperty` throws on failure; `target[key]=value` in strict throws, in sloppy silently fails — traps must return boolean, so use `Reflect` (see [3.1](<../3. Reflect core/3.1. Reflect API vs operator and Object equivalents.md>)).

**Q3 — Why must `get`/`set` traps forward `receiver` via `Reflect.get(target, key, receiver)`?**
`receiver` threads the original `this` (the proxy) into accessor `this`. Bare `target[key]` fixes `this` to `target`, breaking membrane `proxy.self === proxy` and leaking mutations — see [3.2](<../3. Reflect core/3.2. Receiver forwarding and correct this.md>).

**Q4 — What invariants can `ownKeys` violate?**
Must include every non-configurable key; if target non-extensible, must return exactly the target's keys (no missing, no extra); `getOwnPropertyDescriptor` must be compatible — see [2.2](<../2. Proxy core/2.2. Proxy invariants non-configurable non-extensible and exotic constraints.md>). Violation throws `TypeError`.

**Q5 — What is `Reflect.ownKeys` vs `Object.keys` vs `Object.getOwnPropertySymbols`?**
`Reflect.ownKeys` = integers → strings → symbols insertion, includes non-enumerable (the truthful listing); `Object.keys` = enumerable strings only; `getOwnPropertySymbols` = all symbols only — see [3.1](<../3. Reflect core/3.1. Reflect API vs operator and Object equivalents.md>) and [1.2](<../1. Symbols deep/1.2. Symbol creation description global registry and hidden keys.md>).

**Q6 — What does `Symbol.for` vs `Symbol()` do?**
`Symbol("x")` fresh per call; `Symbol.for("x")` global canonical (same string → same symbol cross-realm); `Symbol.keyFor` reverses only the global set — see [1.2](<../1. Symbols deep/1.2. Symbol creation description global registry and hidden keys.md>).

**Q7 — Which symbols does `Object.prototype.toString` vs `for...of` vs `instanceof` vs `concat` look up?**
`toString`→`@@toStringTag`, `for...of`→`@@iterator`, `instanceof`→`@@hasInstance`, `concat`→`@@isConcatSpreadable`, coercion→`@@toPrimitive`, derived collections→`@@species`, `with`→`@@unscopables`, `str.match`→`@@match` family — see [1.1](<../1. Symbols deep/1.1. Well-known symbols the protocol hook table.md>).

**Q8 — What must `@@toPrimitive(hint)` return and which hint for `String(x)` vs `x + ""` vs `x + 0`?**
Must return primitive or `TypeError`; `String(x)`→`"string"`, `Number(x)`→`"number"`, `x+""`/`x+0`→`"default"` (Date legacy maps `default`→`"string"`); missing hook falls back to `valueOf`/`toString` per `OrdinaryToPrimitive` — see [4.1](<../4. Metaprogramming customization/4.1. Customizing coercion toPrimitive toStringTag hasInstance and match hooks.md>).

**Q9 — What does `@@species` control?**
Which constructor built-in methods (`map`/`filter`/`slice`/`then`) use for derived objects; default is `this.constructor`; `null` falls back to built-in, non-constructor throws — see [4.2](<../4. Metaprogramming customization/4.2. Species unscopables isConcatSpreadable and subclassing built-ins.md>).

**Q10 — How does `Proxy.revocable` work?**
`Proxy.revocable(target, handler)` → `{proxy, revoke}`; after `revoke()` every trap throws `TypeError`; target direct access still works; `revoke` idempotent; composition requires tracking revokes for membranes — see [5.2](<../5. Security patterns membranes and revocables/5.2. Revocable proxies and security boundaries.md>).

**Q11 — Can `instanceof` be customized on a plain object?**
Yes — add `obj[Symbol.hasInstance](v){ …boolean… }` and `v instanceof obj` calls it; otherwise `OrdinaryHasInstance` walks `v`'s proto chain for `obj.prototype` — see [4.1](<../4. Metaprogramming customization/4.1. Customizing coercion toPrimitive toStringTag hasInstance and match hooks.md>).

**Q12 — Why can't `Symbol("secret")` be private?**
Because `Reflect.ownKeys`/`getOwnPropertySymbols` reveals it. True privacy is `#private` (see [Prototypes 3.3](<../../../07 Prototypes and Classes/sections/3. Class syntax/3.3. Private fields and methods brand checks and encapsulation.md>)) or `WeakMap` branding — see [5.1](<../5. Security patterns membranes and revocables/5.1. Validation observability membranes and private branding.md>).

```js
// Runnable spot checks for grading — interviewer expects these exact traces
// Q3 receiver identity
console.log(new Proxy({ get self(){ return this; } }, { get(t,k,r){ return Reflect.get(t,k,r); } }).self === new Proxy({},{})); // false — different proxies, but self===its-proxy holds
const base = { get self(){ return this; } };
const p = new Proxy(base, { get(t,k,r){ return Reflect.get(t,k,r); } });
console.log(p.self === p); // true → Q3 senior signal
console.log(new Proxy(base, { get(t,k){ return t[k]; } }).self === base); // true → broken signal

// Q4 ownKeys invariant — must not omit non-configurable
const t = {}; Object.defineProperty(t, "id", { value: 1, configurable: false });
const bad = new Proxy(t, { ownKeys(){ return []; } });
try { Reflect.ownKeys(bad); } catch(e){ console.log("Q4:", e.name); } // TypeError

// Q6 registry
console.log(Symbol("a") === Symbol("a"), Symbol.for("a") === Symbol.for("a")); // false true

// Q8 toPrimitive hint dispatch
const o = { [Symbol.toPrimitive](h){ return h; } };
console.log(o + "", String(o), Number(o)); // default string number — Q8 expects "default"/"string"/"number"

// Q10 revocable
const { proxy, revoke } = Proxy.revocable({ a: 1 }, {});
console.log(proxy.a); revoke(); try{ console.log(proxy.a); }catch(e){ console.log("Q10:", e.name); }

// Q1 OwnKeys truth — Reflect.ownKeys includes symbols
const obj = { a: 1, [Symbol("s")]: 2 };
console.log(Reflect.ownKeys(obj).length, Object.keys(obj).length); // 2 1
```

### 2) **What interviewers actually probe for**

Senior: can narrate "trap → `Reflect.*` with `receiver` → invariant" as one sentence; can list 5 well-known symbols from memory and state which syntax triggers each; can explain `Symbol.for` collision vs isolation; can distinguish `species` (construction) from `hasInstance` (test). Mid: recalls trap names but forgets `receiver` or invariant for frozen. Junior: confuses `Object.keys` trap, `target[key]` forwarding, or `Symbol("x") === Symbol("x")`.

### 3) **Grading guidance**

- **Junior signals**: names 3+ well-known symbols correctly; lists 2–3 traps.
- **Mid signals**: maps `Object.keys`→`ownKeys` filter; explains `Reflect.set` boolean vs throw; handles all `@@toPrimitive` hints; distinguishes global vs local registry.
- **Senior signals**: explains receiver forwarding with `self` demo; enumerates 3+ invariant rules; narrates `species` vs `hasInstance` split; designs revocable membrane with `Set<revoke>`.
- **Red flags**: "`Proxy` mutates the target when you set `proxy.x`"; "`Reflect.get` equals `obj[key]`"; "`Object.keys` has a trap"; "`Symbol("a") === Symbol("a")` true"; "`species` changes `instanceof`"; "`JSON.stringify` preserves symbols"; "must use `with` for `unscopables`".
