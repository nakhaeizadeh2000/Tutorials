## 2.1. Proxy handler the 13 trap table and forwarding

### 1) **What `new Proxy(target, handler)` creates — an exotic forwarding object**

**Definition** — `Proxy` creates an exotic object whose internal methods (`[[Get]]`, `[[Set]]`, `[[OwnPropertyKeys]]`, etc.) consult the `handler` trap of that name before falling back to the target's internal method. The target is unchanged; the proxy is a separate object with its own identity (`proxy !== target`, but `Object.prototype.toString` reflects target's tag unless overridden).

**What problem it solves / history** — prior to ES2015 interception required polluting prototypes or wrapping every access manually. Proxies give a per-object virtualization layer: validation, logging, membranes, revocable capabilities, and lazy virtual properties without mutating the target. Added ES2015; stable since.

```js
// Proxy identity — target untouched, proxy distinct
const target = { x: 1 };
const proxy = new Proxy(target, {});
console.log(proxy.x); // 1 — empty handler forwards identically
console.log(proxy === target); // false
console.log(proxy.x === target.x); // true — value forwarded
target.x = 2; console.log(proxy.x); // 2 — live forwarding, not snapshot

// Non-proxy alternative mutates prototype (bad)
const alt = Object.create(target); // inherits, not intercepts owns
console.log(Object.hasOwn(alt, "x")); // false — delegation, not interception
```

- **Modern guidance** — handlers must be plain objects (`null` throws `TypeError: handler must be an object`). Each trap is optional; absence means transparent forwarding.

### 2) **The 13 traps — operator → trap → Reflect twin**

**Definition** — every interceptable internal slot has a named trap. The table is the contract:

| # | Trap | Intercepted operation | Signature | Reflect twin |
|---|---|---|---|---|
| 1 | `get` | `obj[prop]` / `obj.prop` | `(target, prop, receiver)` | `Reflect.get` |
| 2 | `set` | `obj[prop]=val` / `obj.prop=val` | `(target, prop, value, receiver)` | `Reflect.set` |
| 3 | `has` | `prop in obj` | `(target, prop)` | `Reflect.has` |
| 4 | `deleteProperty` | `delete obj[prop]` | `(target, prop)` | `Reflect.deleteProperty` |
| 5 | `ownKeys` | `Object.keys/ownKeys/getOwnPropertyNames/Symbols` | `(target)` | `Reflect.ownKeys` |
| 6 | `getOwnPropertyDescriptor` | `Object.getOwnPropertyDescriptor` | `(target, prop)` | `Reflect.getOwnPropertyDescriptor` |
| 7 | `defineProperty` | `Object.defineProperty` | `(target, prop, descriptor)` | `Reflect.defineProperty` |
| 8 | `getPrototypeOf` | `Object.getPrototypeOf` / `obj.__proto__` | `(target)` | `Reflect.getPrototypeOf` |
| 9 | `setPrototypeOf` | `Object.setPrototypeOf` / `__proto__=` | `(target, proto)` | `Reflect.setPrototypeOf` |
| 10 | `isExtensible` | `Object.isExtensible` | `(target)` | `Reflect.isExtensible` |
| 11 | `preventExtensions` | `Object.preventExtensions` | `(target)` | `Reflect.preventExtensions` |
| 12 | `apply` | `fn(...args)` / `fn.call` | `(target, thisArg, args)` | `Reflect.apply` — only if target callable |
| 13 | `construct` | `new Fn(...args)` | `(target, args, newTarget)` | `Reflect.construct` — only if target constructable |

```js
// Trap table demos — each operator hits its trap
const logs = [];
const t = { a: 1, get b() { return this.a * 2; } };
const p = new Proxy(t, {
  get(tr, k, recv) { logs.push(`get ${String(k)}`); return Reflect.get(tr, k, recv); },
  set(tr, k, v, recv) { logs.push(`set ${String(k)}=${v}`); return Reflect.set(tr, k, v, recv); },
  has(tr, k) { logs.push(`has ${String(k)}`); return Reflect.has(tr, k); },
  deleteProperty(tr, k) { logs.push(`del ${String(k)}`); return Reflect.deleteProperty(tr, k); },
  ownKeys(tr) { logs.push("ownKeys"); return Reflect.ownKeys(tr); },
  getOwnPropertyDescriptor(tr, k) { logs.push(`gopd ${String(k)}`); return Reflect.getOwnPropertyDescriptor(tr, k); },
});
console.log(p.a);          // get a
console.log(p.b);          // get b (getter this is forwarded — see 3.2)
console.log("a" in p);     // has a
p.c = 3;                   // set c=3
delete p.c;                // del c
Object.keys(p);            // ownKeys + gopd per key
console.log(logs.slice(0, 8));

// apply / construct only when target is function
function Fn(x) { this.x = x; }
const fp = new Proxy(Fn, {
  apply(tr, thisArg, args) { console.log("apply", args); return Reflect.apply(tr, thisArg, args); },
  construct(tr, args, newT) { console.log("construct", args); return Reflect.construct(tr, args, newT); },
});
console.log(new fp(5).x); // construct [5] → 5
fp.call(null, 7); // apply [7] — Fn is plain function, callable path

// Non-callable target with apply trap throws at Proxy creation? No — but call throws
const nonFn = {};
try { new Proxy(nonFn, { apply() { return 1; } })(1); } catch (e) { console.log("call non-fn:", e.name); }
```

- **Modern guidance** — name traps exactly (`deleteProperty` not `delete`); `Object.keys` is *not* a trap — `ownKeys` is, and `Object.keys` post-filters `ownKeys` for enumerable strings.

### 3) **Forwarding pattern — `Reflect.get(target, prop, receiver)` preserves `this`**

**Definition** — inside `get`/`set`, bare `target[prop]` reads the target with target as `this`, breaking proxy-chain accessor `this`. Correct forwarding is `Reflect.get(target, prop, receiver)` which threads `receiver` (the original `this` parameter of the `[[Get]]` internal call) through to the getter.

```js
// The receiver-forwarding difference (detailed in 3.2, shown here as trap guidance)
const inner = { get self() { return this; } };
const good = new Proxy(inner, {
  get(tr, k, recv) { return Reflect.get(tr, k, recv); }, // ← correct: getter this is proxy receiver
});
console.log(good.self === good); // true — correct forwarding returns proxy
const bad = new Proxy(inner, {
  get(tr, k) { return tr[k]; }, // broken: getter this is target
});
console.log(bad.self === bad); // false — broken forwarding returns target
console.log(bad.self === inner); // true — leaks target identity
```

### 4) **Common confusion**

- "`Object.keys` has a trap" — no; it calls `[[OwnPropertyKeys]]` (`ownKeys` trap) then filters. `for...in` additionally walks proto chain (not a single trap).
- "`handler` can be `null`" — no; `new Proxy(target, null)` throws `TypeError`.
- "`apply`/`construct` work on plain objects" — no; target must be callable/constructable; otherwise Proxy creation succeeds but invocation throws `TypeError: proxy target is not callable`.
- "`get` fires for prototype walks" — yes; `in` walks chain via `has` repeatedly; `obj[prop]` walks until found, but `get` intercepts only the own `[[Get]]` of the proxy, not inherited lookups bypassing it.

### 5) **Performance note**

Every trapped operation adds one extra function call (the trap) plus the `Reflect.*` forwarding call. On V8, a proxied object is ~2–5× slower per property access than a plain object and may deoptimize inline caches (ICs) for that site. Never wrap hot inner-loop objects with fully-trapped proxies; proxy the outer container or batch operations instead. Empty handler `{}` still allocates a proxy exotic but forwards at near-native speed for untrapped ops (still slower than raw).

### 6) **Mentor note**

Require a one-row-per-trap table in any design doc for a proxy. Quiz: "Which trap fires for `delete`? What must it return?" Answer: `deleteProperty`, must return boolean (`true` success, `false` non-strict failure vs throw in strict). Demand `Reflect.*` forwarding by default; forbid `target[prop]` inside traps except when intentionally shadowing `receiver`.
