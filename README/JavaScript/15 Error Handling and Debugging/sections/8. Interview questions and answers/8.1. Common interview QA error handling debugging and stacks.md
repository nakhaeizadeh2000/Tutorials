## 8.1. Common interview Q&A error handling debugging and stacks

### 1) **The classics with mechanism-level answers**

**Q1 — Why always `throw new Error` not `throw "msg"`?** Thrown strings lose `stack`/`name`/`cause` and break `instanceof Error` guards and reporter grouping; `Error` preserves the throw site and chain.

**Q2 — What does `cause` (ES2022) do vs manual `innerError`?** `new Error(msg,{cause})` is the standard chain; `.cause` reference is enumerable on demand; loggers and `fullStack` walk `while(e=e.cause)` to retain root. Manual `err.innerError` is ad-hoc and not recognized by hosts.

**Q3 — When does `finally` swallow an error?** `try{ throw A } finally{ return B }` or `finally{ throw C }` overrides `A`. Hygiene: `finally` must not `return`/`throw`; use `using`/`SuppressedError` if cleanup throws.

**Q4 — `throw` vs `Promise.reject` vs `async throw`?** Sync `throw` unwinds to `catch`; `Promise.reject` settles async observed via `.catch`/`.await`; `async throw` returns a rejected promise. `try{ promise } catch` without `await` never catches a rejection.

**Q5 — `await` translation?** `await p` suspends; if `p` rejects with `e`, it `throw`s `e` at that line, so `try{ await p } catch(e)` catches; `return await` inside `try` vs `return p` without `await` determines whether `catch` fires (see [4.1](<../4. Async error propagation/4.1. Sync throws vs promise rejections vs async function throws.md>)).

**Q6 — `AggregateError` vs `SuppressedError`?** `AggregateError(errors,msg)` = many peer errors ( `Promise.any` rejection, batch validation ) stores `errors` array. `SuppressedError(error, suppressed)` = exactly two where disposal threw while handling primary — `error` primary, `suppressed` cleanup (via `using`).

**Q7 — How to handle batch failures without losing context?** Do not `await Promise.all` fail-fast if you need all errs — use `allSettled` or attach `cause` per task + throw `AggregateError`. Logging must walk `errors[].stack` + `cause` chains.

**Q8 — What is `unhandledrejection` vs `uncaughtException`?** `unhandledrejection` fires when a promise rejected with no handler by microtask end (browser `window`, Node `process`); `rejectionHandled` fires if later caught. `uncaughtException` is sync `throw` with no `catch`. Node `--unhandled-rejections=strict` turns unhandled into a throw.

**Q9 — What is `Error.stack` and `prepareStackTrace`/`captureStackTrace`?** `stack` is de-facto V8 string `Name: msg\n at fn (file:line:col)`. `captureStackTrace(target, ctor)` trims ctor frames from `target.stack`. `prepareStackTrace` hook receives `CallSite[]` to customize formatting/return objects (V8 only; restore after).

**Q10 — How do `--enable-source-maps` and async stacks interact?** `--enable-source-maps` remaps bundled/minified `dist:1:12345` to original `src:42:7` via `sourceMappingURL`. `--async-stack-traces` (default on) stitches `await` chains; combine both for cross-`await` mapped traces.

```js
// Q1 assert — string throw vs Error
try { throw "x"; } catch(e){ console.log("Q1 string?", e instanceof Error, typeof e.stack); }
try { throw new Error("x"); } catch(e){ console.log("Q1 Error?", e instanceof Error, typeof e.stack); }

// Q3 — finally swallow
function f(){ try { throw new Error("A"); } finally { return "B"; } }
console.log("Q3", f()); // B — A lost

// Q4/Q5 — try without await not catching
async function q5(){
  try { Promise.reject(new Error("r")).catch(()=>{}); } catch(e){ console.log("Q5 never", e); } // not caught — need .catch or await
  try { await Promise.reject(new Error("r2")); } catch(e){ console.log("Q5 caught await", e.message); }
}
q5().catch(()=>{});

// Q6 — AggregateError demo
try { throw new AggregateError([new Error("one")], "many"); } catch(e){ console.log("Q6", e.name, e.errors[0].message); }

// Q9 — captureStackTrace trimming
class Q9Err extends Error { constructor(m,o){ super(m,o); this.name="Q9Err"; if(Error.captureStackTrace) Error.captureStackTrace(this, Q9Err); } }
try { throw new Q9Err("hi"); } catch(e){ console.log("Q9 head", e.stack.split("\n")[0], "trim?", !e.stack.includes("Q9ErrQ9Err")); }

// Q10 — flag names (no runtime)
console.log("Q10 flags: --enable-source-maps --async-stack-traces --trace-warnings");
```

### 2) **What interviewers actually probe for**

Senior probe: narrate `Sync throw → Promise reject → async await` translation with microtask ordering and where `try/catch` must sit; narrate `finally` override + `SuppressedError` via `using`; walk a real `fullStack` that combines `aggregate + cause`. Junior recites `try/catch` folklore; senior shows dispatch by `name`/`code` + realm-safe `Error.isError` + `--enable-source-maps`.

Red-flag answer: "`throw` is like `return` inside `finally` (returns normally)" — it discards the pending throw. "`Promise` rejects are caught by sync `try/catch`" — they are not without `await`. "`AggregateError` is for `using`" — no, `SuppressedError` is. "`stack` is spec" — it is not; it is V8-format.

```js
// Red-flag vs mechanism-level demonstration
function mechanismDemo(){
  // Mechanism — throw synchronously, translate to reject via safeCall
  function safeCall(fn){ try { return Promise.resolve(fn()); } catch(e){ return Promise.reject(e); } }
  safeCall(()=>{ throw new RangeError("bad"); }).catch(e=>console.log("mechanism RangeError", e.name));

  // Mechanism — await stitches vs then loses caller
  (async () => { try { await Promise.reject(new TypeError("t")); } catch(e){ console.log("await TypeError", e.name); } })();

  // Mechanism — cause chain walk
  const low = new Error("low"); const high = new Error("high", { cause: low });
  console.log("chain", high.cause === low, high.stack.split("\n")[0]);
}
mechanismDemo();
```

### 3) **Grading guidance**

| Level | Signals you passed | Red flags |
|-------|--------------------|-----------|
| Junior | always `new Error`, `try/catch`, `throw` vs `return` | throws string/number, empty `catch` |
| Mid | `cause` chain, `finally` hygiene, `await` vs bare promise | `finally{return}`, `try{ promise } catch` missing `await` |
| Senior | `AggregateError`/`SuppressedError`/`using`, `Error.isError`, source-map + async stack flags, `prepareStackTrace` restoration | claims `stack` is spec, conflates `AggregateError`/`SuppressedError`, no handling of `unhandledrejection` |
| Expert/mentor | narrates job queue + `throw` completion vs `reject` settlement + `captureStackTrace` trimming and teaches grep/lint list | cannot diagram `try{throw A}finally{return B}` override |

```js
// Grading helper — tiny Result vs throw exercise:
function parseNumberResult(raw){
  const n = Number(raw);
  return Number.isNaN(n) ? { ok:false, error: new RangeError("not a number") } : { ok:true, value: n };
}
for(const v of ["42","x",42]){
  const r = parseNumberResult(v);
  console.log(v, r.ok ? "ok "+r.value : "err "+r.error.name);
}
// Contrast with throwing version — choose by expected frequency:
function parseNumberThrow(raw){
  const n = Number(raw);
  if(Number.isNaN(n)) throw new RangeError("not a number");
  return n;
}
try { console.log(parseNumberThrow("x")); } catch(e){ console.log("throw", e.name); }
```
