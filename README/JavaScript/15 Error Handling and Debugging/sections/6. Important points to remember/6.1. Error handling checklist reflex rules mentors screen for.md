## 6.1. Error handling checklist reflex rules mentors screen for

### 1) **The five reflexes — always `Error`, always `cause`, handle `finally` return, handle `unhandledrejection`, print stack**

| # | Reflex (question to ask at every site) | What it catches |
|---|----------------------------------------|-----------------|
| 1 | Am I throwing `Error`/`TypeError`/`custom` (not string/number/null)? | lost `stack`/`cause` |
| 2 | Am I preserving `cause` when rethrowing across a boundary? | root cause hidden (`Caused by` missing) |
| 3 | Does my `finally` return/throw and swallow the pending error? | `SuppressedError` needed or remove return |
| 4 | Does every `Promise` have a consumer (`await`/`catch`/`allSettled`)? | `unhandledrejection` orphan |
| 5 | Am I logging `stack` (and chained `cause` stacks) with `--enable-source-maps`? | unmappable minified frames |

```js
// Reflex checklist runnable demo
class AppError extends Error { constructor(m, opts){ super(m, opts); this.name="AppError"; } }

// 1 — always Error:
try { throw "string"; } catch(e){ const n = e instanceof Error ? e : new Error(String(e)); console.log("reflex1:", n instanceof Error); }

// 2 — preserve cause:
try { try { JSON.parse("{bad"); } catch(low){ throw new AppError("parse", { cause: low }); } } catch(e){ console.log("reflex2 cause:", !!e.cause); }

// 3 — finally hygiene (no return):
function hygienic(){ try { return 1; } finally { console.log("reflex3 finally no return — hygienic"); } }
console.log(hygienic());

// 4 — handle all promises:
Promise.reject(new Error("orphan demo")).catch(()=>console.log("reflex4 consumed"));
// 5 — print stack with cause:
try { throw new AppError("top", { cause: new TypeError("low") }); } catch(e){
  console.log("reflex5 stack:", e.stack.split("\n")[0], "cause:", e.cause.stack.split("\n")[0]);
}
```

### 2) **The review grep list**

| Grep / Lint pattern | What it flags |
|---------------------|---------------|
| `throw "` / `throw '` / `throw \d` / `throw null` / `throw {` | non-`Error` throw |
| `new Error\(.*\)` not preceded by `throw` | discarded construction (`new Error` without `throw`) |
| `catch \(` with empty body / `catch \{\}` without comment | swallowing |
| `finally\s*\{[^}]*return` | `finally` return that swallows |
| `catch \(e\)\s*\{[^}]*new Error\(` without `\{cause` | rethrow without cause |
| `Promise\.all\(` without `.catch`/`await` nearby | orphan combinator |
| `\.map\(async` without `Promise\.all`/`allSettled` | orphan promises |
| `console\.log\(.*Error` or `console\.log\(err\)` | raw log without `error`/`stack` |
| `debugger;` in `src/` | leaked debugger (gate or strip) |
| `--enable-source-maps` missing in `node` script of transpiled service | unmappable stacks |

```js
// Grep list quick demo — show patterns matched via regex (illustrative):
const flags = [
  /throw\s+["'`]/, // should be throw new Error
  /new Error\(.*\).*throw/.test ? null : null, // conceptual — real grep is textual
];
console.log("grep flags prepared", flags.length);

// Lint rules that enforce reflexes: no-throw-literal, no-return-await-exception, prefer-promise-reject-errors, require-await, no-debugger
console.log("ESLint: no-throw-literal, prefer-promise-reject-errors, no-debugger, require-await");
```

### 3) **Boundary rule — wrap at module boundary, rethrow unknown, aggregate on fan-out**

**Definition** — at each architectural boundary (controller → service → repo/I/O), decide the error contract: validate inputs here (`TypeError` on misuse), wrap low-level causes with domain errors, expose `AggregateError` for batch endpoints, and expose `cause` chain to logs. Inside a bounded context, rethrow unknowns (`if (!(e instanceof Expected)) throw e`) and aggregate only peers.

| Layer | On `catch` do | Expose to caller |
|-------|---------------|------------------|
| Controller (HTTP) | wrap I/O cause, map to status (`NotFoundError`→404) | `AppError` with `cause` + HTTP code |
| Service | wrap repo cause | domain `ValidationError`/`TaskError` |
| Repo/I/O | throw raw `TypeError`/`ERR_*` | raw, so service can wrap with context |
| Batch (any N tasks) | `AggregateError` + per-item `cause` | `AggregateError.errors` + summary |

```js
// Boundary demo — controller/service/repo layers
class NotFoundError extends Error { constructor(m,o){ super(m,o); this.name="NotFoundError"; this.code="NOT_FOUND"; } }
class ValidationError extends TypeError { constructor(m,o){ super(m,o); this.name="ValidationError"; } }

async function repo(id){
  if(typeof id !== "string") throw new TypeError("id must be string");
  throw Object.assign(new Error("ENOENT"), { code:"ENOENT" });
}
async function service(id){
  try { return await repo(id); } catch(low){
    if(low instanceof TypeError) throw low; // caller bug — propagate unchanged
    throw new NotFoundError(`user ${id} not found`, { cause: low });
  }
}
async function controller(req){
  try { return await service(req.id); }
  catch(e){
    if(e instanceof NotFoundError) console.log("404 NotFound", e.message, "cause", e.cause.code);
    else if(e instanceof ValidationError || e instanceof TypeError) console.log("400 Bad", e.message);
    else console.log("500", e.stack);
    throw e; // preserve for caller/logger
  }
}
controller({ id:"u42" }).catch(()=>{});
controller({ id: 42 }).catch(()=>{}); // TypeError — boundary propagates raw

// Fan-out boundary — AggregateError
async function batchGet(ids){
  const settled = await Promise.allSettled(ids.map(id => service(id).catch(low => { throw new NotFoundError(String(id), { cause: low }); })));
  const errs = settled.filter(x=>x.status==="rejected").map(x=>x.reason);
  if(errs.length) throw new AggregateError(errs, `${errs.length} fetch(s) failed`);
  return settled.filter(x=>x.status==="fulfilled").map(x=>x.value);
}
batchGet(["u1","u2"]).catch(e=>console.log("batch boundary:", e.name, e.errors?.length ?? 0));
console.log("boundary rule — wrap with cause, rethrow unknown, aggregate on fan-out");
```
