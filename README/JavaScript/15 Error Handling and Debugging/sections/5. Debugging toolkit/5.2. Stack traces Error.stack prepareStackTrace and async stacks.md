## 5.2. Stack traces Error.stack prepareStackTrace and async stacks

### 1) **`Error.stack` is V8-format — frames, `at fn (file:line:col)`, and what `cause` stacks do not include**

**Definition** — `Error.stack` is a non-standard (but universal) string: first line `Name: message`, then `at functionName (file:line:col)` per frame, topmost at top. `cause` chains store separate stacks; `AggregateError.errors[*].stack` are separate. Node prints `Caused by:` chains when logging via `console.error`; custom loggers must concatenate.

**Modern guidance** — read top frame as throw site, not `Error` call site if subclassing hides ctor (use `captureStackTrace`). Log `err.stack` not `err.message`.

```js
function c(){ throw new Error("boom"); }
function b(){ c(); }
function a(){ b(); }
try { a(); } catch(e){
  console.log(e.stack.split("\n")[0]); // Error: boom
  console.log(e.stack.split("\n")[1]); // at c (...)
  console.log(e.stack.includes("at a")); // true
}

// cause stacks are separate
const low = new TypeError("bad id");
const high = new Error("load failed", { cause: low });
console.log(high.stack.split("\n")[0], "cause head:", high.cause.stack.split("\n")[0]);
console.log("high stack includes cause?", high.stack.includes("Caused by")); // Node console does, raw string maybe not

// AggregateError per-item stacks
const agg = new AggregateError([new Error("one"), new Error("two")], "batch");
console.log(agg.stack.split("\n")[0]);
console.log(agg.errors[0].stack.split("\n")[0]);

// Helper to print full chain
function fullStack(e){
  let out = e.stack;
  for(let c=e.cause; c; c=c.cause) out += "\nCaused by: " + c.stack;
  if(e instanceof AggregateError) for(const sub of e.errors) out += "\n - " + sub.stack.split("\n")[0];
  return out;
}
console.log(fullStack(high).split("\n").slice(0,3).join("\n"));

// Limit depth — Error.stackTraceLimit defaults 10 in V8
console.log("limit:", Error.stackTraceLimit);
Error.stackTraceLimit = 20;
console.log("raised limit:", Error.stackTraceLimit);
Error.stackTraceLimit = 10; // restore
```

### 2) **Customizing stacks — `Error.captureStackTrace(target, ctor)` and `Error.prepareStackTrace`**

**Definition** — `Error.captureStackTrace(target, constructorOpt)` (V8) attaches `target.stack` excluding frames above `constructorOpt` — trims internal helper frames. `Error.prepareStackTrace = (err, callSites) => ...` is a hook that receives structured `CallSite[]` (objects with `getFileName`/`getLineNumber`/etc.) allowing custom formatting or object returns.

**Modern guidance** — custom errors: `Error.captureStackTrace(this, MyError)` to hide constructor frame; reporters can install `prepareStackTrace` to serialize structured traces (but restore after).

```js
class AppError extends Error {
  constructor(msg, opts){
    super(msg, opts);
    this.name = "AppError";
    if (Error.captureStackTrace) Error.captureStackTrace(this, AppError);
  }
}
function helper(){ throw new AppError("wrapped"); }
function caller(){ helper(); }
try { caller(); } catch(e){
  console.log(e.stack.split("\n")[1]); // at helper or caller? with captureStackTrace, helper trim excludes AppError ctor
  console.log(e.stack.includes("AppError")); // true but ctor frame trimmed
}

// prepareStackTrace — structured
const prev = Error.prepareStackTrace;
Error.prepareStackTrace = (err, callSites) => {
  return {
    header: `${err.name}: ${err.message}`,
    frames: callSites.map(cs => ({ fn: cs.getFunctionName(), file: cs.getFileName(), line: cs.getLineNumber(), col: cs.getColumnNumber() })),
  };
};
try { a(); } catch(e){
  if (Array.isArray(e.stack?.frames) || typeof e.stack === "object") {
    console.log("structured stack header:", e.stack.header);
    console.log("frame 0 fn:", e.stack.frames[0]?.fn ?? e.stack.frames[0]?.file);
  } else console.log("structured not active — V8 only");
}
Error.prepareStackTrace = prev; // restore — global hook affects all stacks

// Guard — SpiderMonkey does not have prepareStackTrace
console.log("prepareStackTrace?", typeof Error.prepareStackTrace);
console.log("captureStackTrace?", typeof Error.captureStackTrace);
```

### 3) **Async stacks — `await` chains stitch stacks with `--async-stack-traces` and `cause`**

**Definition** — sync stacks show only the throw site. `await` suspension stitching (V8 `--async-stack-traces`, default on) links `await` callers across microtasks: `a await b → throw in b` shows `b → a → caller`. Plain `Promise.then` without `await` loses the caller frame. Long async hangs need `cause` to preserve context across `all`.

**Modern guidance** — prefer `await` over `.then` for stack hygiene; Node `--async-stack-traces` on by default. For `Promise.all` fan-out, attach `cause` per task (see [4.2](<../4. Async error propagation/4.2. Unhandled rejections AggregateError in combinators and async stack hygiene.md>)) to retain which input failed.

```js
// await stitching — both frames visible
async function level3(){ throw new Error("deep async"); }
async function level2(){ await level3(); }
async function level1(){ await level2(); }
level1().catch(e=>{
  console.log("async stitched stack includes level2 and level1?");
  console.log(e.stack.includes("level3"), e.stack.includes("level2"), e.stack.includes("level1"));
  console.log(e.stack.split("\n").slice(0,5).join("\n"));
});

// then without await — caller frame often missing:
Promise.resolve().then(()=>{ throw new Error("then throw"); }).catch(e=>{
  console.log("then stack head:", e.stack.split("\n")[0]);
  console.log("then stack includes caller file?", e.stack.includes("5.2"));
});

// Node flag — enable explicitly if trimmed:
// node --async-stack-traces app.js  (default on since Node 12)
// node --enable-source-maps + --async-stack-traces for transpiled (see 5.3)

// cause stitching across parallel tasks
async function parallelTasks(){
  const tasks = [1,2,3].map(async id => {
    try { if(id===2) throw new Error("miss "+id); return id; }
    catch(low){ throw new AppError("task "+id, { cause: low }); }
  });
  try { await Promise.all(tasks); } catch(e){ console.log("parallel cause?", e.cause?.message ?? e.message, typeof e.stack); }
}
parallelTasks().catch(()=>{});

// stackTraceLimit affects async chains too
console.log("async stackTraceLimit:", Error.stackTraceLimit);
```

### 4) **Common confusion**

- "`stack` is spec" — it is not in ECMA-262; format is V8's `at` style, SpiderMonkey similar but not identical. Do not parse `stack` for control flow.
- "`cause.stack` is inside `stack`" — not by default; raw `err.stack` omits `cause`. Node's formatted `console.error(err)` concatenates `Caused by:` chains, but `String(err.stack)` alone does not.
- "`captureStackTrace` is standard" — V8/Node only; JSC/Firefox lack it — guard with `if (Error.captureStackTrace)`.
- "`await` and `.then` stacks are same" — `await` preserves caller via microtask bookkeeping; `.then` without `await` often truncates at the `then` boundary.

### 5) **Performance note**

`prepareStackTrace` returning structured objects avoids string allocation until needed; for error-reporting pipelines that batch, return objects and stringify lazily. Raising `stackTraceLimit` to 100 for deep stacks costs O(n) per thrown error (stringify) — raise temporarily `const prev = Error.stackTraceLimit; Error.stackTraceLimit = 100; throw ...;` then restore.

### 6) **Mentor note**

Have juniors read a 15-frame stack and pinpoint throw site vs caller vs capture-trim point (teach `captureStackTrace` exclusion). In review, require custom errors to call `captureStackTrace` and every `cause`-wrapping `catch` to log the full chain via `fullStack` helper; flag `prepareStackTrace` installs without `prev` restore.
