## 9.1. Boundaries: what is covered elsewhere

### 1) **Iterator protocol, `for-of`, generators, and async iteration**

This domain treats array iteration only as hole-vs-dense and method contracts; the protocol (`Symbol.iterator`, `next()`, iterable vs iterator, `yield`), generator functions, and `for await...of` live in **Iterables, Generators, and Async Iteration** (domain 10). That domain owns `Array.prototype[Symbol.iterator]`, custom iterables, and generator delegation — here only the per-method table (see [2.1](<../2. Holes sparsity and length/2.1. Holes vs undefined sparse arrays and empty slots.md>)).

### 2) **Maps, Sets, WeakMap/WeakRef lifetime, and GC internals**

Ordered key collections and identity-keyed maps (`Map`, `Set`, `WeakMap`, `WeakSet`, `WeakRef`, `FinalizationRegistry`) — including when to prefer `Map` over sparse array indexed by id — belong to [**Collections (Map, Set, Weak References)**](<../../../09 Collections Map Set and Weak References/README.md>) (domain 09) and **Memory Management and GC** (domain 18). Arrays here remain index-ordered; `Set`/`Map` deduplicate and O(1) lookup are out of scope (see [Map creation](../../../09%20Collections%20Map%20Set%20and%20Weak%20References/sections/1.%20Map%20deep%20dive/1.1.%20Map%20creation%20SameValueZero%20insertion%20order%20and%20iteration.md) and [Set creation](../../../09%20Collections%20Map%20Set%20and%20Weak%20References/sections/2.%20Set%20deep%20dive/2.1.%20Set%20creation%20uniqueness%20SameValueZero%20and%20iteration.md>)).

### 3) **String/regex methods, number formatting, `Temporal`, and JSON serialization**

`String` methods, `RegExp`, `Intl`, `Math`, `Number` formatting, `Date`/`Temporal`, and `JSON.stringify`/`parse` (including `JSON.stringify` hole→`null` and `BigInt` replacer) live in **Strings and Regular Expressions** (domain 11), **Numbers, Dates, Math, Temporal** (domain 12), and **JSON Serialization** (domain 16). Array `join`/`toString` only documents `ToString` coercion; full text/temporal formatting is elsewhere.

### 4) **Object descriptor basics, prototype linkage, and class private fields**

Data vs accessor descriptors, `getOwnPropertyDescriptor`, `Object.create`/`getPrototypeOf`/`setPrototypeOf`, and `#private` brand checks are owned by **Objects in Depth** (domain 06) and **Prototypes and Classes** (domain 07). Array exotic `length` invariants reuse those descriptor concepts but add the index contract — refer to Objects §2.1–2.3 for attribute defaults.

### 5) **Functions, scope/closures, and `this` binding**

Arrow `this` lexical capture, closure per-iteration capture, `call`/`apply`/`bind`, and `arguments` handling are owned by **Variables, Scope, and Closures** (domain 04) and **Functions Deep Dive** (domain 05). Array callbacks use `thisArg` but do not re-teach call-site rules.

### 6) **Where this domain stops — single source of truth**

- *This domain owns:* exotic index + `length` invariants, hole vs `undefined`, creation traps (`new Array(n)` vs `Array.of` vs `Array.from`), mutating vs copy-era (`push`/`pop`/`splice`/`fill`/`copyWithin` vs `toReversed`/`toSorted`/`toSpliced`/`with`), searching/testing (`indexOf`/`includes`/`find`/`every`/`some`), slicing/joining (`slice`/`concat`/`join`/`at`/`with`), transforming/ordering (`map`/`filter`/`flat`/`flatMap`/`reduce`/`sort` stability + `compareFn`), and `TypedArray`/`ArrayBuffer`/`DataView` preview.
- *Does not own:* iterator protocol deep dive, `Map`/`Set`/`WeakRef`, string/regex, number/temporal formatting, JSON, full GC, or function/closure mechanics — linked instead of rewritten.
