## 9.1. Boundaries what is covered elsewhere

### 1) **Coercion and boxing — Values, Types, and Coercion; array exotic vs string iteration — Arrays / Iterables**

`String()` coercion, `ToString`/`ToPrimitive`/`ToNumber` tables, falsy list, and wrapper vs primitive boxing (including `Object(Symbol)` vs `new String`) live in [Values, Types, and Coercion](<../../../03 Values Types and Coercion/README.md>) ([ToString table](<../../../03 Values Types and Coercion/sections/2. The conversion algorithms/2.2. ToString and ToNumber the exact conversion tables.md>), [explicit toolbox](<../../../03 Values Types and Coercion/sections/2. The conversion algorithms/2.1. Explicit conversion toolbox Number String Boolean parseInt parseFloat and unary plus.md>), [boxing](<../../../03 Values Types and Coercion/sections/4. Boxing and wrapper objects/4.1. Wrapper objects vs primitives boxing demystified.md>)). This domain treats strings as already-decided primitives and documents methods on them; it does not re-teach `ToString` algorithm.

Array exotic indices and `length` invariants (dense vs holes, copy-era) live in [Arrays](<../../../08 Arrays/README.md>) ([exotic](<../../../08 Arrays/sections/1. Arrays are exotic objects/1.1. What arrays really are the indexed exotic length and Array.isArray.md>) and [holes](<../../../08 Arrays/sections/2. Holes sparsity and length/2.1. Holes vs undefined sparse arrays and empty slots.md>)). String methods that return arrays (`split`, `match`, `matchAll` iteration) crosslink there, but array mutation/copy discipline is not re-taught.

Iterable protocol, `Symbol.iterator`, `for-of`/`spread`/`Array.from` consumers, and generator/ async iteration that iterate strings by code points live in [Iterables, Generators, and Async Iteration](<../../../10 Iterables Generators and Async Iteration/README.md>) ([iterable vs iterator](<../../../10 Iterables Generators and Async Iteration/sections/1. Iterable and iterator protocols/1.1. Iterable vs iterator vs array-like and Symbol.iterator.md>) and [spread/Array.from](<../../../10 Iterables Generators and Async Iteration/sections/2. Consumption for-of spread and interop/2.2. Spread Array.from destructuring and interop with Map Set generators strings.md>)). This domain owns `String.prototype[Symbol.iterator]` and code-point iteration behavior but not the protocol's `return()`/`IteratorClose` mechanics.

### 2) **Number formatting and `Intl.NumberFormat`/`Intl.DateTimeFormat`/`Temporal` — Numbers, Dates, Math, Temporal domain**

Numeric parsing (`parseInt`/`parseFloat` radix, `Number("1_000")` vs `"1_000"` handling), `toFixed`/`toPrecision`, `Intl.NumberFormat`, `Math`, `Date`/`Temporal`, and calendar/locale date-time formatting belong to **Numbers, Dates, Math, and Temporal** (domain 12). String methods `padStart`/`padEnd`/`repeat` here are about string shaping; locale number/date formatting is elsewhere.

### 3) **JSON stringification and `structuredClone` — JSON Serialization domain; `structured` search via collections**

`JSON.stringify`/`parse` (including `undefined`/`BigInt`/replacer handling, hole→`null`, and `toJSON` on `Date`), and `structuredClone` belong to **JSON Serialization and Data Exchange** (domain 16). String `replace` with replacer functions here is regex-local; JSON replacer strategy is not re-taught.

Ordered key collections (`Map`/`Set`/`WeakMap`/`WeakSet`), identity vs stringification for keys, and `RegExp`-based `Map` key filtering belong to [Collections](<../../../09 Collections Map Set and Weak References/README.md>).

### 4) **Functions, scope/closures, and `this` binding; object descriptors and prototype chain**

Arrow `this` lexical capture, closure per-iteration capture, `call`/`apply`/`bind`, and `arguments` handling are owned by [Variables, Scope, and Closures](<../../../04 Variables Scope and Closures/README.md>) and [Functions Deep Dive](<../../../05 Functions Deep Dive/README.md>). String callback `thisArg` (e.g. `replace` with function) does not re-teach call-site rules.

Data vs accessor descriptors, `getOwnPropertyDescriptor`, `Object.create`/`getPrototypeOf`/`setPrototypeOf`, and `#private` brand checks are owned by [Objects in Depth](<../../../06 Objects in Depth/README.md>) and [Prototypes and Classes](<../../../07 Prototypes and Classes/README.md>).

### 5) **Error handling, encoding I/O, and memory/performance deep dives**

`URIError` from `encodeURI` on lone surrogates is mentioned here, but `try/catch`, `Error` subclasses, `using`/`Symbol.dispose`, and `TextEncoder`/`TextDecoder` I/O belong to **Error Handling** (domain 15) and **Memory Management/Performance** (domains 18–19). This domain owns the string check that avoids the throw (`isWellFormed`/`toWellFormed`); the handling policy (retry, sanitize) is there.

### 6) **Where this domain stops — single source of truth**

- *This domain owns:* string primitive immutability, UTF-16 storage and well-formedness (`isWellFormed`/`toWellFormed`), unit vs point vs grapheme distinction (`length`/`codePointAt`/`Segmenter`/`normalize`), all `String.prototype` methods (`includes`/`startsWith`/`endsWith`/`indexOf`/`lastIndexOf`/`search`/`slice`/`substring`/`at`/`charAt`/`codePointAt`/`trim`/`padStart`/`padEnd`/`repeat`/`split`/`toUpperCase`/`toLocaleUpperCase`/`normalize`), template literals/tagged templates/`String.raw`, `RegExp` creation/flags (`g`/`i`/`m`/`s`/`u`/`v`/`y`/`d`)/`lastIndex`/`RegExp.escape`, searching/matching (`match`/`matchAll`/`exec`/`test`/`search`/`split`/`replace`/`replaceAll`), groups/named groups/backreferences/`hasIndices` and replacement `$` patterns/functions, anchors/lookaround/boundaries and unicode flag discipline (`u`/`v` sets `--`/`&&`/`\q{}`, `s`, `y`, `i`, inline `(?i:...)`).

- *Does not own:* coercion algorithm deep dive, array exotic `length`/`holes`, iterator protocol/closing mechanics, `Map`/`Set` identity, number/date temporal formatting, JSON serialization, function/closure/`this`, object descriptors/prototype chain, or error-recovery/encoding I/O and GC internals — linked instead of rewritten.
