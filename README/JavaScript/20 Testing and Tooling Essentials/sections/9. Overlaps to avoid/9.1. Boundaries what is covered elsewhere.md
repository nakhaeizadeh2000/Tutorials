## 9.1. Boundaries what is covered elsewhere

This domain owns *how* vanilla JS gets tested and shipped — `node:test`/`node:assert/strict`/`mock`/`mock.timers`/fake clocks, branch coverage gates, and the lint/format/`package.json`/CI contract. It does not own the runtime contracts those tests verify. Where a topic already has a single source of truth elsewhere, this domain links to it instead of re-teaching it (§5 DRY).

### 1) **Error taxonomy, `throw`/`try`/`cause`/`AggregateError` and async error translation — [Error Handling and Debugging](<../../../15 Error Handling and Debugging/README.md>)**

What lives there: the seven builtin `Error` subtypes, when engines throw `SyntaxError`/`ReferenceError`/`TypeError`/`RangeError`, how `throw` vs `return` propagates, `cause` chaining (`ES2022`), `AggregateError`/`SuppressedError` (`ES2021`/`ES2024`), and `assert.throws`/`rejects` expecting `{ name, message }`. Here only the test-surface: `assert.throws`/`rejects` shape.

Key links: [built-in Error types](<../../../15 Error Handling and Debugging/sections/1. Error taxonomy/1.1. Built-in Error types and when engines throw them.md>) → [cause wrapping](<../../../15 Error Handling and Debugging/sections/3. Defensive patterns/3.1. Cause wrapping context preservation and suppressed errors.md>) → [try/catch/finally mechanics](<../../../15 Error Handling and Debugging/sections/2. Throwing and catching/2.2. try catch finally mechanics rethrow and nesting.md>).

### 2) **Event loop queues (`call stack`, `queueMicrotask`, timers/`nextTick`) and `Promise`/`async` desugaring — [Async Event Loop and Promises](<../../../13 Async Event Loop and Promises/README.md>)**

What lives there: run-to-completion vs micro/macrotask, `queueMicrotask` starvation, `Promise` states/thenable assimilation, combinators `all`/`allSettled`/`any`/`race`/`withResolvers`, `async`/`await` desugaring, and `unhandledRejection`. Here only how to *test* that machinery: orphan `Promise` detection, `assert.rejects`, and `once`+`AbortSignal`.

### 3) **Heap/GC reachability, `WeakRef`/`FinalizationRegistry`, and leak prevention — [Memory Management and GC](<../../../18 Memory Management and GC/README.md>)**

What lives there: heap vs stack, roots/retaining paths, generational/mark-sweep, `WeakMap`/`WeakSet` ephemeron, `WeakRef` resurrection hazards, `FinalizationRegistry` never-for-correctness, and `using`/`Symbol.dispose` discipline. Here only the testing consequence: why a leaked handle and unbounded `Map` cause OOM and how `t.after(() => clearInterval)` prevents it.

### 4) **JIT shapes/IC/polymorphism, clocks/harnesses, and bundle `tree-shaking` — [Performance and JIT Mindset](<../../../19 Performance and JIT Mindset/README.md>)**

What lives there: Ignition/TurboFan/Maglev/Turboshaft tiers, hidden classes/maps, IC `monomorphic`/`polymorphic`/`megamorphic`, `performance.now` vs `hrtime`, microbenchmark traps, and bundle parse cost. Here only the measurement pattern that tests reuse: `performance.now` harness + `globalThis.__sink` retain.

### 5) **ESM/CJS live bindings, `package.json`/`exports` resolution deep dive — [Modules and Code Organization](<../../../14 Modules and Code Organization/README.md>)**

What lives there: `import`/`export` forms, live bindings, circular `ReferenceError` via `mock.module`, `require`/`module.exports` cache, and the full `package.json` `exports`/`imports` map table. Here only the `scripts`/`workspaces`/`engines` contract and the CI wiring; the resolution table itself lives in Modules.

Key links: [module vs script and IIFE ancestry](<../../../14 Modules and Code Organization/sections/1. Module foundations and static imports/1.1. Script vs module and the evolution from IIFEs to ESM.md>) → [specifiers and exports map](<../../../14 Modules and Code Organization/sections/5. CommonJS interop and resolution/5.3. Specifiers package.json exports import maps and organization.md>) → [ESM and CJS interop](<../../../14 Modules and Code Organization/sections/5. CommonJS interop and resolution/5.2. ESM and CJS interop dual packages and migration.md>).

### 6) **`JSON`/`structuredClone` contracts and `Proxy`/`Reflect` metaprogramming — [JSON Serialization and Data Exchange](<../../../16 JSON Serialization and Data Exchange/README.md>) / [Metaprogramming](<../../../17 Metaprogramming Symbols Proxy Reflect/README.md>)**

What lives there: `JSON.stringify`/`parse` omission/circular/`toJSON`/`replacer`/`reviver`, `structuredClone` vs `JSON` clone trade-offs, and `Proxy` 13-trap table / `Reflect` receiver / membranes. Here only as *test-surface objects* (how to `deepStrictEqual` a `Map` or a `DataView`).
