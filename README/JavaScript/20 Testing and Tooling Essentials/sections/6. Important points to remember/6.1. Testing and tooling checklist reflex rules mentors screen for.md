## 6.1. Testing and tooling checklist reflex rules mentors screen for

### 1) **The five reflexes — "pyramid?", "AAA?", "awaited?", "mock restored?", "covered branch?"**

| Reflex | Fires when | Ask | Fix lane |
|---|---|---|---|
| Pyramid | adding a new test or suite | "Is this U/I/E and does it keep U > I > E?" | Move I/O behind a seam / promote to fake → [§1.1](../1. Testing foundations/1.1. Why test the test pyramid economics and what not to test.md) |
| AAA | test longer than 15 lines or has two `assert` groups | "One Act? One behaviour? Name states when/then?" | Split, rename `when … then …`, extract builder → [§1.2](../1. Testing foundations/1.2. Anatomy of a test AAA naming isolation and determinism.md) |
| Awaited | test creates a `Promise`/`setTimeout`/`Emitter` | "Is every async handle `await`ed or `return`ed and guarded by `t.after`?" | `await` + `assert.rejects` + `once` + `AbortSignal.timeout` → [§4.1](../4. Async timing and flake control/4.1. Testing promises async await event emitters and rejections.md) |
| Mock restored | test calls `mock.fn`/`mock.method`/`mock.timers.enable` | "Which `t.after`/`afterEach` restores it so the next test is isolated?" | `t.after(() => mock.restoreAll())` + `(disable ?? reset)` → [§3.2](../3. Mocks and test doubles/3.2. Mocking in Node mock.fn mock.method timers fetch and modules.md) |
| Covered branch | `if`/`?:`/`??`/`catch` added | "Is there a test per branch with a `deepStrictEqual`/`throws` diff?" | Add second branch test, gate `branches 85` → [§5.1](../5. Quality gates and tooling/5.1. Coverage with c8 v8 line branch function thresholds and lies.md) |

```js
// Quick self-check harness — run before claiming a test PR is done
const { performance } = require("node:perf_hooks");
const assert = require("node:assert/strict");

function checkReflex(fn, label) {
  for (let i = 0; i < 200; i++) fn(); // warmup
  const s = performance.now();
  const res = fn();
  const dt = performance.now() - s;
  globalThis.__sink = res; // retain against DCE
  console.log(label, dt < 50 ? "fast" : "slow", String(res).slice(0, 40));
}

function clamp(n, lo, hi) { return Math.min(Math.max(n, lo), hi); }
checkReflex(() => clamp(-2, 0, 10) === 0, "pyramid/unit clamp branch");
checkReflex(() => [1,2,3].includes(2), "AAA simple assert");
console.log("reflex harness ok");

// Mentor question to ask on every PR: "which gate would have caught this bug if it had shipped?"
```

### 2) **The review grep list**

Search these before approving a test/tooling PR (annotate fixes with the leaf that explains it):

- `Math\.random\(\)|Date\.now\(\)|new Date\(\)` without a clock seam — nondeterministic; inject `clock` or enable `mock.timers` ([§1.2](../1. Testing foundations/1.2. Anatomy of a test AAA naming isolation and determinism.md)).
- `setTimeout\(|setInterval\(` in `test/**/*.js` without `mock\.timers` — flake; use fake timers ([§3.2](../3. Mocks and test doubles/3.2. Mocking in Node mock.fn mock.method timers fetch and modules.md)).
- `\.map\(async|\.forEach\(async` — unawaited fan-out; needs `await Promise.all` ([§4.1](../4. Async timing and flake control/4.1. Testing promises async await event emitters and rejections.md)).
- `mock\.fn|mock\.method` without `t\.after|afterEach.*restore|mock\.restoreAll` — mock leak across tests ([§3.2](../3. Mocks and test doubles/3.2. Mocking in Node mock.fn mock.method timers fetch and modules.md)).
- `assert\.ok\(.*===` — diff ergonomics miss; use `equal`/`deepStrictEqual` ([§2.2](../2. Node test runner and assertions/2.2. node assert strict deepStrictEqual throws rejects and assertion ergonomics.md)).
- `throw\s+"|throw\s+42|assert\.throws\(.*\)` without `{ *name` — wrong subtype passes silently; require `{ name, message }` ([§2.2](../2. Node test runner and assertions/2.2. node assert strict deepStrictEqual throws rejects and assertion ergonomics.md)).
- `test\.only|describe\.only` — focused test shipped to `main` blocks full suite ([§2.1](../2. Node test runner and assertions/2.1. node test runner describe it test hooks filtering and test flags.md)).
- `c8 ignore` without a trailing comment reason — coverage lie ([§5.1](../5. Quality gates and tooling/5.1. Coverage with c8 v8 line branch function thresholds and lies.md)).
- `npm install\b` in `\.github/workflows` — should be `npm ci` ([§5.2](../5. Quality gates and tooling/5.2. Linting formatting static analysis ESLint Prettier type checks npm scripts workspaces and CI gates.md)).
- `eqeqeq.*off` / `== null` without comment — coercion gate missed ([§5.2](../5. Quality gates and tooling/5.2. Linting formatting static analysis ESLint Prettier type checks npm scripts workspaces and CI gates.md)).

### 3) **Boundary rule — one behavior per test, restore every mock, gate both lint and coverage**

Never gate correctness on wall-clock timing or on a `setTimeout` padding. One test proves one branch or one interaction; every `mock`/`timer` is restored in `t.after`/`afterEach` so the suite stays isolated; and the CI pipeline gates *both* lint (`eslint`) and branch coverage (`c8 --check-coverage`) — lint without coverage misses logic, coverage without lint misses coercion and floating promises. If `main` stays green only because you retried flakes, the discipline is broken.

### 4) **Mentor note — how to use this table**

Make it a PR template checklist: each row is a checkbox. Demand: which reflex fired, which link (§1.1/§2.2/§3.2/§4.1/§5.1 etc.) explains the fix, and the before/after `node --test` run plus the `c8` branch line. Teach newcomers that test quality is *structural* (seam, AAA, isolation) not *count* (more tests ≠ more safety).
