## 5.1. Coverage with c8 v8 line branch function thresholds and lies

### 1) **How V8 coverage works — `c8` as the `node --experimental-test-coverage` predecessor, Istanbul mapping, and `/* c8 ignore next */`**

**Definition** — V8 instruments each function/branch with a counter. `c8` (Istanbul's V8 reporter) runs `node` with `--v8-coverage`, collects the JSON, and maps counters back to source lines/branches/functions via source maps. Node 22's `node --experimental-test-coverage` (and Node 24 `--test --experimental-test-coverage`) does the same without `c8`. `/* c8 ignore next 3 */` and `/* c8 ignore start/stop */` exclude generated or intentionally unreachable code.

**What problem it solves / history** — coverage answers "which branches never ran," not "which tests are good." `c8` replaced `istanbul`'s transpiled instrumentation (which distorted element kinds and hid real branches) with zero-cost V8-native counters. `c8` is still the gate in CI for Node 22 LTS; Node 24's flag will eventually replace it.

**Modern guidance** — run `c8 --check-coverage --lines 90 --branches 85 --functions 90 -- node --test` (or `node --experimental-test-coverage --test` on Node 24) and fail CI if thresholds miss. Mark unavoidable gaps explicitly: `/* c8 ignore next */` on `if (process.env.NODE_ENV === "test")` debug branch with a comment why.

```js
const assert = require("node:assert/strict");

// What V8 counts: line, branch, function
function clamp(n, lo, hi) {
  if (n < lo) return lo;      // branch A
  if (n > hi) return hi;      // branch B
  return n;                   // branch C (fall-through)
}
assert.equal(clamp(-2, 0, 10), 0); // covers A
assert.equal(clamp(5, 0, 10), 5);  // covers C, but not B — c8 reports branch 66 %

// /* c8 ignore next 3 */ — generated or platform-specific code
// /* c8 ignore next 3 -- node:vm cross-realm demo, not a product branch */
function crossRealmDemo() {
  try { require("node:vm").runInNewContext("throw new Error('x')"); } catch {}
}
crossRealmDemo();

// What c8 stores (simplified)
const fakeCoverage = {
  lines: { total: 4, covered: 3, pct: 75 },
  branches: { total: 3, covered: 2, pct: 66.6 },
  functions: { total: 1, covered: 1, pct: 100 },
};
assert.equal(fakeCoverage.branches.pct < 85, true); // would fail the branch gate
console.log("coverage model ok");
```

**Common confusion** — "`c8` measures test quality." It measures *execution*, not *assertion*. A test that calls `clamp(5,0,10)` without `assert.equal` still counts as "covered."

### 2) **Line vs branch vs function — 100 % line with 0 % branch on a `?:` is still untested; threshold triage (`lines 90`, `branches 85`)**

**Definition** — *line* coverage: was the line executed? *branch* coverage: was each outcome of a decision (`if`/`?:`/`??`/`&&`/`||`/`catch`) taken? *function* coverage: was the function entered? One line can hide two branches: `return a ?? b` is one line but two branches ( `a` nullish vs not).

**Modern guidance** — gate *branch* stricter than line. A common threshold set for a typed JS repo in 2026 is `lines 90 / branches 85 / functions 90 / statements 90`, with per-file deltas not global averages (a global 90 can hide a 40 % file). Single-line ternaries `const v = cond ? a : b` need two tests; `catch (e)` needs a throwing fixture.

```js
const assert = require("node:assert/strict");

// One line, two branches — line 100 % but branch 50 % if you only test one
function pick(a, b, cond) { return cond ? a : b; }
assert.equal(pick(1, 2, true), 1);  // branch true covered
assert.equal(pick(1, 2, false), 2); // branch false covered — need both

// Nullish coalescing — branch when left is null/undefined
function label(name) { return name ?? "anonymous"; }
assert.equal(label("Ada"), "Ada");      // branch: left defined
assert.equal(label(null), "anonymous"); // branch: left nullish — need both
assert.equal(label(undefined), "anonymous");

// Catch branch — uncovered until you throw
function parseQty(s) {
  const n = Number(s);
  if (Number.isNaN(n)) throw new TypeError("nan");
  return n;
}
assert.equal(parseQty("3"), 3); // lines covered, catch not
assert.throws(() => parseQty("hi"), TypeError); // catch branch now covered

// Function coverage — an exported helper that is never imported counts as 0 %
function unusedHelper() { return 1; }
assert.equal(typeof unusedHelper, "function"); // referenced but not called — function 0 %
unusedHelper(); // call it — now function 100 %
console.log("line vs branch ok");
```

**Mentor note** — in review, search for `?:` / `??` / `&&` / `||` on one line and ask "where's the second branch test?" If the answer is "line coverage already 100 %," send it back — line is not branch.

### 3) **Coverage lies — getter that returns a constant can be "covered" without an assertion; uncovered `default` arms and `catch` paths**

**Definition** — a *lie* is a green metric that hides missing verification: calling a function without asserting its result still increments the counter; an empty `default:` in a `switch` that is never hit stays uncounted; a `catch` that swallows `cause` looks covered if you only test the happy path.

**Modern guidance** — two immunizations:
1. **Assertion-aware gate** — require `assert.equal` for every `c8`-counted call (lint via `eslint-plugin-assert` or manual review). A test that calls `clamp` but asserts nothing is a lie.
2. **Explicit `default` throw** — `default: throw new Error(`unknown kind ${kind}`)` forces a branch that must be covered (and produces a useful stack if new input appears).

```js
const assert = require("node:assert/strict");

// Lie 1: covered without asserted — c8 says covered, bug ships
function add(a,b){ return a+b; }
add(1,2); // executed — c8 line covered, but no assert.equal(add(1,2),3)
assert.equal(add(1,2), 3); // need the assert

// Lie 2: uncovered default / catch hides a future branch
function kindOf(v) {
  switch (typeof v) {
    case "string": return "str";
    case "number": return "num";
    default: throw new TypeError(`unknown kind ${typeof v}: ${String(v).slice(0,20)}`);
  }
}
assert.equal(kindOf("hi"), "str");
assert.equal(kindOf(42), "num");
assert.throws(() => kindOf(true), TypeError); // default branch — must test, otherwise c8 branch gap

// Lie 3: catch that swallows cause looks covered without cause check
function load(json) {
  try { return JSON.parse(json); } catch (e) { throw new SyntaxError("bad json", { cause: e }); }
}
assert.deepEqual(load('{"a":1}'), { a: 1 });
try { load("bad"); assert.fail(); } catch (e) {
  assert.equal(e.name, "SyntaxError");
  assert.equal(e.cause instanceof SyntaxError, true); // without this, cause wiring could be broken and c8 still green
}
console.log("coverage lies ok");
```

**Performance note** — `c8` with `--v8-coverage` adds ~5–15 % to test runtime (counter increments per branch). That's the cost of branch truth; don't disable it to shave seconds — see [Performance 3.2](<../../../19 Performance and JIT Mindset/sections/3. Measuring performance correctly/3.2. Microbenchmark traps warmup dead code and variance.md>). Run `c8 --check-coverage` as a separate gate after `node --test` so failures are branch-labeled.
