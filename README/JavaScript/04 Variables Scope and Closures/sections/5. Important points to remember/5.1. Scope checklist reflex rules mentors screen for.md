## 5.1. Scope checklist: reflex rules mentors screen for

### 1) **Three defaults that prevent the bug classes before they exist**

1. **Default `const`, escalate to `let` on demonstrated reassignment, ban `var`** ([1.1](<../1. Declarations and bindings/1.1. var let const mechanics and when each is still defensible.md>)) — enforced by ESLint `prefer-const` + `no-var`, not by memory.
2. **Narrowest scope wins** — declare at last responsible moment, in the innermost block that needs it; small scopes shrink closure environments ([3.4](<../3. Closures/3.4. Closures and garbage collection what stays alive.md>)) and shrink blast radius.
3. **Declare before use, always** — hoisting knowledge is for *reading* legacy code ([2.2](<../2. Scope and lookup/2.2. Hoisting the reality creation phase not magic.md>)), never a license to rely on it; `no-use-before-define` makes the rule mechanical.

### 2) **The five reflex answers**

| Situation | Reflex | Why |
|---|---|---|
| Async callback inside a loop | Check the *loop form*: `for-of`/`for (let)` heads are safe; `while` + outer counter shares one binding | per-iteration capture lives only in loop heads ([3.2](<../3. Closures/3.2. Loops and closures var let and per iteration capture.md>)) |
| Refactor moved a declaration down | Run tests on every executed path; TDZ errors fire at runtime, not parse time | [1.2](<../1. Declarations and bindings/1.2. Temporal dead zone why early access throws.md>) |
| Assignment to a bare name | Treat as implicit-global smell; strict/module code makes it an error | sloppy-mode globals corrupt shared state ([6.1](<../6. Common pitfalls to production bugs/6.1. Real production bugs caused by scoping mistakes.md>)) |
| `setInterval` / listener / cache created | Name its cleanup owner and bound — or justify lifetime | closures pin environments until cleared ([3.4](<../3. Closures/3.4. Closures and garbage collection what stays alive.md>)) |
| Same name in two visible scopes | Justify the shadowing or rename; wide-scope coincidence shadows are bug farms | first-match lookup ([2.1](<../2. Scope and lookup/2.1. Lexical scope and the scope chain how name lookup works.md>)) |

### 3) **What to grep for in code review**

```text
\bvar\b                      → migration candidate; ask why it survived
setInterval\(                → find the paired clearInterval owner
addEventListener\(           → removal strategy or AbortSignal named?
^let |^var |^const .*= \[\]  → module-level MUTABLE state: who writes it, when?
```

- Raw grep supplements, never replaces, lint rules: `no-undef` catches bare-name assignments statically, `prefer-const` finds frozen `let`s — wire both into CI so humans stop doing machine work.

### 4) **The boundary pattern: explicit flow beats ambient reach**

Scope's version of "convert at boundaries": data a function needs should arrive as parameters, not via outward reach into mutable outer bindings:

```js
// ambient reach — correctness depends on invisible outer state:
let discount = 0;
const priceAmbient = (base) => base - discount;
discount = 5;
console.log(priceAmbient(100));        // 95 — but WHY is invisible here

// explicit flow — all inputs visible at the call site:
const priceExplicit = (base, off) => base - off;
console.log(priceExplicit(100, 5));    // 95 — provable
```

- Ambience scales terribly: every reader must simulate the whole file to know what a function sees. Explicit parameters make functions testable in isolation and reorder-safe.
- Legitimate module-level state exists (caches, singletons) — the checklist asks for *ownership and bounds*, not zero.

### 5) **Mentor note**

Screen candidates and reviewers with one prompt: *"here's a loop pushing callbacks — what prints, and which single keyword change fixes it?"* Then follow up with *"what if it were a while loop?"* The second question separates memorized answers from working models ([3.2](<../3. Closures/3.2. Loops and closures var let and per iteration capture.md>)). In team settings, encode this leaf as CI rules; checklists people execute manually rot within a quarter.
