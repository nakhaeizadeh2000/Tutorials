## 8.1. Boundaries: what is covered elsewhere

This domain owns *how bindings live*: declarator contracts, TDZ, scope-chain lookup, hoisting mechanics, closures as environments, and top-level scope rules. It deliberately stops at:

1. **Declaration grammar and operator-level behavior** (identifier naming rules, loop syntax, comma operators) — **Language Basics domain**; this domain covers only the scope/closure consequences, not the syntax tour.
2. **`this` binding and function invocation** (`this` resolution at call sites, bind/call/apply, constructor calls, arrow-function `this` details) — **Functions Deep Dive domain**; here only the scoping fact that variable capture and `this` resolution are independent mechanisms.
3. **import/export semantics** (live-binding exports in depth, circular imports, module resolution, bundling) — [Modules and Code Organization](<../../../14 Modules and Code Organization/README.md>) ([live bindings](<../../../14 Modules and Code Organization/sections/2. Exports and live bindings/2.2. Live bindings why imports are not copies.md>), [circular TDZ](<../../../14 Modules and Code Organization/sections/3. Evaluation and circular dependencies/3.2. Circular dependencies and temporal dead zone across cycles.md>), [resolution](<../../../14 Modules and Code Organization/sections/5. CommonJS interop and resolution/5.3. Specifiers package.json exports import maps and organization.md>)); this domain covers only the top-level *scope* behavior of modules ([4.1](<../4. Top level scopes scripts modules and eval/4.1. Script vs module top level globalThis and the declarative record.md>)).
4. **Deep memory management** (generational GC internals, WeakRef/FinalizationRegistry, heap-tool walkthroughs) — **Memory Management and GC domain**; here only closure-driven retention as observable behavior ([3.4](<../3. Closures/3.4. Closures and garbage collection what stays alive.md>)). Keyed-cache data structures (Map/WeakMap internals) → **Collections, Map, Set, and Weak References domain**.
5. **Class `#private` fields and prototype method sharing** (the class-side alternatives to closure privacy) — **Prototypes and Classes domain**; here only the closure-based pattern and its trade-offs ([3.3](<../3. Closures/3.3. Closure patterns privacy factories memoization.md>)).
6. **Coercion of uninitialized values** (why `undefined + 1` is `NaN`) — **Values, Types, and Coercion domain**; this domain produces the `undefined`, that one explains where it goes.

If you're about to write a hoisting timeline diagram, a `this`-binding table, or a WeakRef tutorial inside this domain — stop; link to the owning neighbor instead.
