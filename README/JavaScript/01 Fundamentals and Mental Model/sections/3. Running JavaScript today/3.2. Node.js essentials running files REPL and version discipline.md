## 3.2. Node.js essentials (running files, REPL, watch mode, version discipline)

### 1) **`node` runs files and a REPL**

```bash
node app.js        # run a file
node               # interactive REPL (REPL allows top-level await)
node --watch app.js  # auto-restart on file changes — tight feedback loop
```

- The REPL is the fastest way to probe language behavior (`typeof null`, operator results); files are where real code lives.
- A minimal runnable program:

```js
// app.js
const name = process.argv[2] ?? "world"; // process = Node host API, not language
console.log(`hello ${name}`);
```

```bash
node app.js          # hello world
node app.js mentor   # hello mentor
```

### 2) **Check the runtime before blaming the language**

Feature availability depends on Node's bundled V8 — know your versions:

- As of **August 2026**: **Node 24** is Active LTS (EOL Apr 2028), **Node 22** Maintenance LTS (EOL Apr 2027), **Node 26** Current (enters LTS Oct 2026). Node 20 reached EOL Apr 30, 2026.
- Discipline: pin engines in `package.json` (`"engines": { "node": ">=24" }`), check with `node --version`, and verify features against *your* line — not against blog posts.

```js
// Feature-detect rather than assume:
console.log(typeof structuredClone === "function"); // true on modern lines
```

### 3) **Module system is chosen by config/extension**

- `.mjs` files, or `.js` inside a package with `"type": "module"` → ESM (`import`/`export`).
- Otherwise `.js` defaults to CommonJS (`require`) for backward compatibility.
- Mixing both systems in one file throws; interop rules are covered once, fully, in the **Modules domain**. For this track's examples: ESM syntax, assumed `"type": "module"`.

### 4) **Common confusion**

- "`process`/`fs`/`Buffer` are JavaScript" — no; Node host APIs. Language built-ins (`JSON`, `Math`, `Map`) work everywhere.
- "The REPL behaves exactly like a file" — mostly, but the REPL wraps evaluation; confirm edge cases in a file.
- Running an ESM-syntax file without module context: `SyntaxError: Cannot use import statement outside a module` — a config error, not a language limit.

### 5) **Mentor note**

Standardize learner environments early: one LTS line (24 era), `--watch` during exercises, and a one-line version check at session start. Most "weird" beginner errors are version or module-system mismatches, not conceptual gaps.
