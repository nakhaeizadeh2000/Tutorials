## 6.1. Boundaries: what is covered elsewhere

This domain teaches grammar and operators at loop/expression level. It deliberately stops at:

1. **Type coercion algorithms** (ToNumber/ToPrimitive/ToString step-by-step, truthiness tables, boxing wrappers, symbol.toPrimitive) — full treatment in **Values, Types, and Coercion domain**; here only the practical coercion *effects* operators produce.
2. **Iteration protocol internals** (`Symbol.iterator`, custom iterables, generator semantics, async iterators) — **Iterables, Generators, and Async Iteration domain**; this domain only covers loop-level consumption.
3. **Property descriptor mechanics** (enumerability/writability/getters, `defineProperty`, key ordering guarantees) — **Objects in Depth domain**; here only observable operator behavior (`in`, `delete`, spread copy level).
4. **Scope/closure consequences of declarations** (`let` vs `var` in loop heads, TDZ) — **Variables, Scope, and Closures domain**.
5. **Array-specific APIs and hole behavior** (`splice` vs `filter` strategies, `length` truncation) — **Arrays domain**; `delete arr[i]` appears here only as an operator effect.

If you're about to write a coercion table, iterator protocol diagram, or property-descriptor deep dive inside this domain — stop; link to the owning neighbor instead.
