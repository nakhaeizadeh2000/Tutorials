## 5.1. Common interview Q&A: syntax, control flow, and operators

### 1) **Q&A**

1. **Q: What does `for...in` do on an array, and why is it wrong?**
   **A:** Yields string keys (`"0"`, `"1"`), walks inherited enumerable properties, and has non-obvious ordering for non-integer keys. Use `for-of` or array methods.

2. **Q: Difference between `==` and `===`? When would you ever use `==`?**
   **A:** `===` compares type and value without conversion; `==` coerces operands first (Abstract Equality Algorithm). Only sanctioned use: `x == null` as null-or-undefined shorthand.

3. **Q: What does `0 || "default"` vs `0 ?? "default"` evaluate to?**
   **A:** `"default"` and `0`. `||` falls back on falsy; `??` only on `null`/`undefined` — the difference that protects valid zero/empty-string values.

4. **Q: Predict: `console.log("5" + 3, "5" - 3)`?**
   **A:** `"53" 2` — `+` concatenates when either operand is a string; `-` forces numeric coercion.

5. **Q: Why does `typeof null` return "object"? How do you check for null correctly?**
   **A:** Frozen implementation artifact from 1995; web compatibility forbids fixing. Check with `x === null`.

6. **Q: What does `delete arr[1]` do to `[1,2,3]`?**
   **A:** Leaves a hole: length stays 3, index 1 reads `undefined`, `1 in arr` is false. Removing elements properly means `splice`/`filter`.

7. **Q: Explain short-circuit evaluation with a real use case.**
   **A:** `&&`/`||` stop evaluating once the result is known and return that operand — used for guards (`user && save()`) and fallbacks (`cache || fetch()`); right side may never run.

8. **Q: `{ ...a, ...b }` — deep or shallow copy? Prove it.**
   **A:** Shallow: nested objects are copied by reference — `copy.nested === a.nested` is `true`. Deep needs `structuredClone` or explicit traversal.

9. **Q: Is `switch` strict or loose when matching cases?**
   **A:** Strict (`===`) semantics — no coercion between case values and the switch expression.

10. **Q: `typeof` returns how many distinct strings? Name the surprising ones.**
    **A:** Eight: `undefined/object/boolean/number/string/function/symbol/bigint`. Surprising: `typeof null === "object"`, arrays report `"object"`, functions get their own tag.

### 2) **Grading guidance (mentor note)**

- Questions 1–4 separate practiced JS developers from framework tourists.
- Listen for *mechanism* ("because booleans coerce to numbers first") not just outcomes in Q4/Q6 — outcome-memorizers guess under pressure.
- Strong follow-up for Q8: "how would you deep-copy safely?" — expect `structuredClone` awareness and serialization-caveat mention (cycles, functions).
