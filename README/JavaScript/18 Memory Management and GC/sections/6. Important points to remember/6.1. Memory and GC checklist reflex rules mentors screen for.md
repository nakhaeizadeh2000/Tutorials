## 6.1. Memory and GC checklist reflex rules mentors screen for

### 1) **The five reflexes — "root · path · edge strength · bound · teardown"**

A reviewer who applies these five questions to every heap-touching line catches >90% of JS memory bugs before they need a snapshot.

| # | Reflex | Trigger | Corrective line |
|---|--------|---------|-----------------|
| 1 | *"What's the root?"* | any graph that survives a scope (`return`, `export`, interval, `queueMicrotask`) | name the host or global holding it (`setInterval` registry, `globalThis.cache`) |
| 2 | *"What's the retaining path?"* | `Map`/`Set`/`Array` captures of request-scoped objects | trace one path `root → Map → entry → payload` |
| 3 | *"Weak or strong?"* | `WeakMap`/`WeakSet`/`WeakRef`/`FinalizationRegistry` use | confirm edge is actually weak (value doesn't reference key; heldValue isn't the target) |
| 4 | *"Bounded or unbounded?"* | every `new Map`/`Set`/`Array` grown from input | assert a cap (FIFO/LRU/TTL/`WeakMap` keyed by object) |
| 5 | *"Explicit teardown?"* | `setInterval`/`setTimeout`/`addEventListener`/`fetch` | demand `clear*`/`AbortSignal`/`close`/`[Symbol.dispose]` line that deterministically cuts it |

```js
// Healthy shape: reachable → bounded → teardown annotated.
const REG = new Map();                      // owner: module — policy: LRU 2
function boundedMemo(k, v) {
  if (REG.size >= 2) REG.delete(REG.keys().next().value);
  REG.set(k, v);                           // retained until delete/clear
  return REG.get(k);
}
boundedMemo("a", { payload: new Array(200).fill(1) });
boundedMemo("b", { payload: new Array(200).fill(2) });
boundedMemo("c", { payload: new Array(200).fill(3) }); // evicts "a" deterministically
console.log(REG.size, REG.has("a")); // 2 false — bounded, no GC needed for correctness

// Host-rooted teardown pattern with AbortSignal as the single composition handle.
function wire(signal, label) {
  const t = setInterval(() => label.length, 1_000_000);
  signal.addEventListener("abort", () => clearInterval(t), { once: true });
}
const ac = new AbortController();
wire(ac.signal, "lease");
ac.abort(); // single line cuts every listener/interval composed under this signal
```

### 2) **Compressed answer table for the whole domain**

| Concept | Deterministic part | Non-deterministic part | Never rely on |
|---------|-------------------|----------------------|---------------|
| Reachability | which edges exist after your line | when mark runs | scope exit freeing alone |
| `WeakMap`/`WeakSet` ephemeron | entry counts as weak, no enumeration | when unreachable entry drops | `size` / iteration |
| `WeakRef.deref()` | may be live now, returns `undefined` when cleared | when it flips after cut | truthiness across `await` |
| `FinalizationRegistry` | registration itself is weak | when/if callback enqueues | for closing files/locks |
| Allocation | rate & survival drive frequency | pause length per incremental slice | micro bench shape thresholds across versions |

### 3) **Greppable review list**

Run these on every memory-sensitive diff and annotate each hit with the matching reflex row:

```js
console.log([`new Map\\(`,
  `\\.set\\(`, `\\.get\\(`, `\\.delete\\(`, `\\.clear\\(`,
  `setInterval\\(|setTimeout\\(`, `clearInterval|clearTimeout`,
  `addEventListener`, `removeEventListener`, `AbortSignal`, `AbortController`,
  `new WeakMap|new WeakSet`, `\\.register\\(`, `FinalizationRegistry`, `WeakRef`,
  `global\\.gc|\\-\\-expose\\-gc`].join("|"));
```

Lint-shaped checklist (map to lint rules where you can): unbounded `Map`/`Set`/`Array` captures without `delete`/`clear`; timer without `clear*/signal`; listener without `signal/remove`; `register(obj, obj)` self-pin; `deref()` reused across `await` without guard; test asserting `deref() === undefined` without retry+forced-GC.
