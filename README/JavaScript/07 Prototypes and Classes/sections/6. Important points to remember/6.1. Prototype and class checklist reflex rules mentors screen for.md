## 6.1. Prototype and class checklist: reflex rules mentors screen for

### 1) **[[Prototype]] vs .prototype vs __proto__ — never conflate**

Three names, three roles:

| Term | What it is | Where it lives | How to observe/mutate |
|------|------------|----------------|------------------------|
| `[[Prototype]]` (slot) | internal link that lookup walks | per object, set at birth | `Object.getPrototypeOf(obj)` / `Object.create` birth / `extends` |
| `.prototype` (property) | template object `new F()` stamps into fresh instances | per function/constructor, writable property | `F.prototype`, `instanceof` walks *current* `F.prototype` |
| `__proto__` (accessor) | legacy getter/setter on `Object.prototype` reflecting `[[Prototype]]` | per object via delegation to `Object.prototype` | `obj.__proto__` or `Object.setPrototypeOf` (slow) |

```js
class Dog { bark() {} }
const d = new Dog();
console.log(Object.getPrototypeOf(d) === Dog.prototype); // true — slot points to template
console.log(Object.getPrototypeOf(Dog) === Function.prototype); // true — constructor's own prototype is Function.prototype
console.log(d.__proto__ === Dog.prototype); // true-ish — accessor reflects slot
console.log(Dog.prototype.isPrototypeOf(d)); // true — isPrototypeOf walks slot via flipped args
console.log(d instanceof Dog); // true — instanceof checks slot contains current Dog.prototype

// Reassignment shows the split
const old = Dog.prototype;
Dog.prototype = { howl() {} };
console.log(Object.getPrototypeOf(d) === old); // true — d still holds old
console.log(d instanceof Dog); // false — instanceof now looks for new template, fails
console.log(Dog.prototype.isPrototypeOf(d)); // false — new template not in d's chain
Dog.prototype = old; // restore confusion for next demos
```

- *Mentor check* — draw `d → Dog.prototype → Object.prototype → null` vs `Dog → Function.prototype → Object.prototype → null` and ask which of `getPrototypeOf(d)`, `d.__proto__`, `Dog.prototype`, `getPrototypeOf(Dog)` each arrow is.

### 2) **new + super() obligations and field order**

Derived class invariant: `super()` first, then `this` parameter.

| Obligation | Check | Failure |
|------------|-------|---------|
| Derived constructor must call `super(...)` before touching `this`/`super` or returning implicitly | `super()` before `this.x =` or `this` parameter use | `ReferenceError: Must call super...` |
| Class must be called with `new` | `new C()` not `C()` | `TypeError: Class constructor cannot be invoked without 'new'` |
| Instance private `#field` reachable only with brand | `this.#field` inside declaring class, or `#field in obj` guard | `TypeError: Cannot read private member...` / `SyntaxError` if written outside |
| Static private distinct per class | `Child` lacks parent's static `#field` brand | `TypeError` on `this.#staticField` when `this === Child` |

```js
class Base { constructor(id) { this.id = id; } }
class Derived extends Base {
  #extra;
  constructor(id, extra) {
    super(id); // must be first — allocates and initializes this
    this.#extra = extra; // now safe
  }
  get extra() { return this.#extra; }
}
console.log(new Derived(1, 2).extra); // 2

// Field order recap: derived instance fields run AFTER super() (→ [3.4](../3.%20Class%20syntax/3.4.%20Static%20members%20static%20blocks%20and%20class%20field%20order.md))
// Instance fields before constructor body, static fields top-to-bottom
```

### 3) **The review grep list**

| Grep pattern | What it catches | Fix |
|--------------|-----------------|-----|
| `\.prototype\s*=\s*\{` or `Object\.setPrototypeOf` / `__proto__\s*=` outside `Object.create` site | prototype reassignment / mutation deopt | keep birth prototype stable; mutate existing template or create fresh constructor |
| `Array\.prototype` / `Object\.prototype` extension | global pollution of all chains | use standalone utility, not prototype augmentation |
| `class.*extends` without `super(` in derived constructor | missing mandatory super | add `super(...args)` before `this` |
| `this\.#` outside class body | private SyntaxError | move inside class or expose via method/`in` guard |
| `method = \(\) =>` shadowing prototype method of same name | instance field shadow bug | rename or use method syntax |
| `instanceof Array` in shared lib | cross-realm fragile | replace with `Array.isArray` |
| `delete\s+.*\.prototype` or `delete.*__proto__` | deopt + brand break | tombstone or map, never delete prototype slots in hot code |

```js
// Review example hits
class Bad1 extends Base { constructor() { this.x = 1; } } // flagged — super() missing
class Bad2 { static #s = 1; static get() { return this.#s; } } // flagged if Child tries Child.get() when Child not branded — see [3.4]
const Bad3 = new Bad2(); // flagged if code later does Bad2.prototype = {} after instances exist
```

### 4) **Decision table for common tasks**

| Task | Reach for | Avoid |
|------|-----------|-------|
| Shared behavior with `instanceof` | `class` / constructor + prototype | factory + `instanceof` polyfill |
| True privacy brand-checked | `#field` + `#field in obj` guard | `_field` or `WeakMap` without brand |
| Orthogonal trait reuse | mixin factory `M(Base) => class extends Base` | deep hierarchy `A extends B extends C` |
| Cross-realm array check | `Array.isArray` | `instanceof Array` |
| Enumerate own data only | `Object.hasOwn` / `keys` | `for-in` (→ [Objects §2.3](../../../06%20Objects%20in%20Depth/sections/2.%20Properties%20and%20descriptors/2.3.%20Enumerability%20enumeration%20order%20and%20for-in%20mechanics.md)) |
| Dictionary keyed by untrusted strings | `Object.create(null)` | `{}` + `'__proto__' in obj` checks |
| One-off data record | literal `{ x, y }` | `new class` with single instance |

### 5) **Mentor checklist (screen in every review)**

- [ ] Every class's `[[Prototype]]` vs `.prototype` vs `__proto__` usage correct.
- [ ] No `setPrototypeOf`/`__proto__=` in hot path; no `.prototype` reassignment after first `new`.
- [ ] Every derived constructor calls `super()` before `this`; no arrow `super` misuse.
- [ ] Private fields declared and accessed only inside declaring class; detached methods preserve `this` brand or fail loud.
- [ ] `instanceof` not used where cross-realm or brand check (`#field in obj`, `Array.isArray`) is correct.
