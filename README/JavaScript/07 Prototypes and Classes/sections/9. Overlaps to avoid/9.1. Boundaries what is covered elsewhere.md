## 9.1. Boundaries: what is covered elsewhere

### 1) **Property descriptors, Object.* utilities, and immutability — Objects in Depth (06)**

`value`/`writable`/`enumerable`/`configurable`, `defineProperty`/`getOwnPropertyDescriptor`/`getOwnPropertyDescriptors`, `Object.assign`/`keys`/`entries`/`Reflect.ownKeys` enumeration order, and `preventExtensions`/`seal`/`freeze` shallow semantics are owned by [Objects in Depth](../../../06 Objects in Depth/README.md) ([descriptors](../../../06 Objects in Depth/sections/2. Properties and descriptors/2.1. Data vs accessor descriptors and attribute defaults.md>), [defining](../../../06 Objects in Depth/sections/2. Properties and descriptors/2.2. Defining observing and configuring properties.md>), [enumerability](../../../06 Objects in Depth/sections/2. Properties and descriptors/2.3. Enumerability enumeration order and for-in mechanics.md>), [utilities](../../../06 Objects in Depth/sections/4. Object utilities and copying/4.1. Assign merging shallow copy and fromEntries.md>), [seal/freeze](../../../06 Objects in Depth/sections/5. Integrity and immutability/5.1. Prevent extensions seal freeze and shallow immutability.md>)). This domain links there for descriptor shapes and does not re-derive them — it focuses on *which* prototype object descriptors live on.

### 2) **this binding rules, arrow lexical this, and call/apply/bind — Functions Deep Dive (05)**

Call-site rules (`default`/`implicit`/`explicit`/`new`), arrow capture, `call`/`apply`/`bind` permanent `this`, and `this` loss in callbacks/timers are owned by [Functions Deep Dive](../../../05 Functions Deep Dive/README.md) ([call-site rules](../../../05 Functions Deep Dive/sections/3. this binding/3.1. Call-site rules default implicit explicit new and strict mode.md>), [arrow](../../../05 Functions Deep Dive/sections/3. this binding/3.2. Arrow lexical this and why callbacks break or heal.md>), [bind](../../../05 Functions Deep Dive/sections/3. this binding/3.3. call apply bind and bound functions.md)). This domain treats `this` as the delegation receiver but does not re-teach binding — it assumes that model and applies it to prototype methods.

### 3) **Declaration scope, hoisting, TDZ, and closure capture — Variables, Scope, and Closures (04)**

Lexical scope chains, `let`/`const`/`var` contracts, TDZ, `CreatePerIterationEnvironment`, and module vs script top-level are owned by [Variables](../../../04 Variables Scope and Closures/README.md) ([TDZ](../../../04 Variables Scope and Closures/sections/1. Declarations and bindings/1.2. Temporal dead zone why early access throws.md>), [hoisting](../../../04 Variables Scope and Closures/sections/2. Scope and lookup/2.2. Hoisting the reality creation phase not magic.md>), [closures](../../../04 Variables Scope and Closures/sections/3. Closures/3.1. Closures functions that remember their birth environment.md>)). Class TDZ and `#field` lexical scope in this domain mirror that terminology but do not re-derive it.

### 4) **Collections, WeakRef/FinalizationRegistry, and identity — Collections / Memory (09, planned 18)**

`Map`/`Set`/`WeakMap`/`WeakSet`/`WeakRef`/`FinalizationRegistry`, object-identity keying vs stringification for `Object` dictionaries, and GC/heap implications of retained prototype graphs are owned by [Collections](../../../09 Collections Map Set and Weak References/README.md) (domain 09) and the upcoming Memory domain (textual forward ref for 18). This domain notes `Map`-vs-object trade-offs on `null`-proto dictionaries but does not teach `Map` APIs or lifetime (see [Map](../../../09 Collections Map Set and Weak References/sections/1. Map deep dive/1.1. Map creation SameValueZero insertion order and iteration.md) and [WeakMap](../../../09 Collections Map Set and Weak References/sections/3. Weak collections/3.1. WeakMap ephemeron keys non-iterability and use cases.md>)).

### 5) **Iterables, generators, async, and JSON/modules — upcoming data and async domains**

`Symbol.iterator`/`Symbol.asyncIterator`, `for-of`, generator `function*`/`yield`, `async`/`await`/`Promise`, `structuredClone`, `JSON` replacer/reviver, and `import`/`export` live bindings belong to upcoming domains (textual refs to 10/13/14/16). Class async methods and generator methods (`*method()`, `async method()`) are mentioned as existing shapes in [3.1](../3. Class syntax/3.1. Class basics declarations hoisting methods accessors and fields.md) but not taught as protocol.

### 6) **Stop-list for this domain (what not to add here)**

- Do not duplicate descriptor definition, `defineProperty` mechanics, or `Object.keys` vs `Reflect.ownKeys` partition — link to 06.
- Do not re-derive `this` call-site binding or arrow capture — link to 05.
- Do not re-derive scope TDZ or closure per-iteration environment — link to 04.
- Do not teach `Map`/`WeakMap` APIs, iterator protocol, or `Promise` combinators — link to 09/10/13.
- Do not teach `JSON` stringify/parse or module import/export — link to 14/16.
