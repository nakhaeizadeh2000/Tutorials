## 4.3. Implicit index access with `^` in object initializers (C# 13+)

### What it enables

1. In **object initializers**, you can index **from the end** using `[^k]` for **single-dimension** collection-like properties.
2. This removes awkward “compute forward index” boilerplate when you want **tail initialization**.

### Correctness

1. The underlying collection must exist and be **sized**—initializer indexing doesn’t magically grow all collection types.
2. **Out-of-range** still throws—validate lengths when building buffers.

### Performance

1. Indexing cost is trivial; **allocation** comes from the collection type and its initializer behavior.
