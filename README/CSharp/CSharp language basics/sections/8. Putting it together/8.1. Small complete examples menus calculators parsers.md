### 1) **Menu-driven console apps with `switch` and loops**
**Goal**
- Demonstrate a simple app structure where:
  - the loop controls *flow*
  - each command is a small function
  - input parsing happens at the boundary (without duplicating parsing rules everywhere)

**Example (end-to-end, runnable)**

```csharp
using System.Globalization;

Run(Console.In, Console.Out);

static void Run(TextReader input, TextWriter output)
{
    while (true)
    {
        output.WriteLine();
        output.WriteLine("1) Add two numbers");
        output.WriteLine("2) Convert Celsius → Fahrenheit");
        output.WriteLine("0) Exit");
        output.Write("Choice: ");

        var choice = input.ReadLine();
        if (choice is null)
            return; // end-of-input (piped input ended)

        switch (choice.Trim())
        {
            case "1":
                AddTwoNumbers(input, output);
                break;

            case "2":
                ConvertTemperature(input, output);
                break;

            case "0":
                return;

            default:
                output.WriteLine("Unknown option.");
                break;
        }
    }
}

static void AddTwoNumbers(TextReader input, TextWriter output)
{
    if (!TryReadInt32(input, output, "a: ", out var a)) return;
    if (!TryReadInt32(input, output, "b: ", out var b)) return;

    output.WriteLine($"Result: {a + b}");
}

static void ConvertTemperature(TextReader input, TextWriter output)
{
    if (!TryReadDouble(input, output, "Celsius: ", out var c)) return;

    var f = (c * 9.0 / 5.0) + 32.0;
    output.WriteLine($"Fahrenheit: {f.ToString("0.##", CultureInfo.CurrentCulture)}");
}

static bool TryReadInt32(TextReader input, TextWriter output, string prompt, out int value)
{
    output.Write(prompt);
    var text = input.ReadLine();

    if (text is null)
    {
        value = default;
        return false;
    }

    if (!int.TryParse(text, NumberStyles.Integer, CultureInfo.CurrentCulture, out value))
    {
        output.WriteLine("Please enter a valid integer.");
        return false;
    }

    return true;
}

static bool TryReadDouble(TextReader input, TextWriter output, string prompt, out double value)
{
    output.Write(prompt);
    var text = input.ReadLine();

    if (text is null)
    {
        value = default;
        return false;
    }

    if (!double.TryParse(text, NumberStyles.Float, CultureInfo.CurrentCulture, out value))
    {
        output.WriteLine("Please enter a valid number.");
        return false;
    }

    return true;
}
```

Mentor notes:
- Passing `TextReader`/`TextWriter` keeps I/O testable and avoids hard-wiring `Console` into your domain logic.
- The `switch` itself is the “routing”. Each case delegates quickly to a focused method.

- Use explicit culture (`CurrentCulture` for humans, `InvariantCulture` for machines).

### 3) **Performance and correctness notes (allocation awareness, avoid repeated parsing, validate once)**
**Correctness**
- Validate at the boundary; keep internal logic typed (e.g., `int`, `double`) rather than passing around raw strings.
- Keep “exit” paths explicit (`return`/`break`) so the app’s flow is easy to audit.

**Performance**
- Console I/O dominates; reduce prints before worrying about micro-optimizations.
- Avoid repeated parsing/formatting: parse once, compute once, print once.
