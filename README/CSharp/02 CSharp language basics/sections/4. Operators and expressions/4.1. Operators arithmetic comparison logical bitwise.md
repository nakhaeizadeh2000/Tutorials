## 4.1. Operators: arithmetic, comparison, logical, bitwise

1. **Precedence and associativity (when parentheses are worth it)**
2. **Short-circuiting (`&&`/`||`) and side effects (avoid hidden work)**
3. **Good to know (integer division, overflow, floating-point equality, bit flags)**

### 1) **Precedence and associativity**
**Rule of thumb**
- If you have to *remember* precedence to read the line correctly, add parentheses.
- Parentheses are “free” compared to bugs and code review time.

**Examples**

```csharp
var x = 10;
var y = 3;

// Integer division happens before the cast? (This is easy to misunderstand)
var wrong = (double)(x / y);  // 3 -> 3.0
var right = (double)x / y;    // 3.333...
```

**Associativity (left-to-right surprises)**

```csharp
var a = 1;
var b = 2;
var c = 3;

var r1 = a - b - c;   // (a - b) - c = -4
var r2 = a - (b - c); // 2
```

### 2) **Short-circuiting and side effects**
**Short-circuiting is a feature**
- `&&` stops when the left side is `false`.
- `||` stops when the left side is `true`.

This is great for **guarding** expensive or unsafe work:

```csharp
string? input = GetInput();

if (!string.IsNullOrWhiteSpace(input) && input.Length >= 3)
{
    Console.WriteLine(input[..3]);
}

static string? GetInput() => "abc";
```

**Mentor warning: don’t hide work in conditions**
- Avoid conditions that *do I/O*, *mutate state*, or *throw* as a normal case.
- Keep conditions “pure” when possible; it makes debugging and performance reasoning much easier.

### 3) **Good to know (the common operator traps)**
**Integer division**
- `5 / 2` is `2` (not `2.5`) when both operands are integers.
- Convert at least one operand to `double`/`decimal` when you need fractional results.

**Overflow**
- Operator behavior and overflow rules are covered in depth in **`3.2`**.

See section `3.2` for the full treatment:
- `README/CSharp/02 CSharp language basics/sections/3. Variables and primitive types/3.2. Primitive types and literals and when overflow matters.md`

**Floating-point equality**
- `double` is approximate. Avoid direct equality for computed values.
- Use tolerances for comparisons.

```csharp
static bool AlmostEqual(double a, double b, double eps = 1e-9)
    => Math.Abs(a - b) <= eps;
```

**Bitwise operators and flags**
- Use bitwise operators (`&`, `|`, `^`, `~`, `<<`, `>>`) for low-level work and flags.
- Prefer `[Flags] enum` to make intent visible.

```csharp
[Flags]
enum FileAccessFlags
{
    None  = 0,
    Read  = 1 << 0,
    Write = 1 << 1,
    Exec  = 1 << 2,
}

var access = FileAccessFlags.Read | FileAccessFlags.Write;
var canWrite = (access & FileAccessFlags.Write) != 0;
```
