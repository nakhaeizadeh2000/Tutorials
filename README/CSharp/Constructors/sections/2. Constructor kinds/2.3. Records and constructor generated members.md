## 2.3. Records, record structs, and constructor-generated members (equality, immutability, and versioning)

### What records generate (and how construction interacts)
- Equality and hashing semantics
- Deconstruction and positional members
- `with` expressions and copying semantics
- Print/`ToString` behavior (diagnostics vs leaking secrets)

### Positional records vs explicit constructors
- When positional syntax is a win
- When explicit constructors improve clarity/invariants
- Versioning implications of adding/removing positional parameters

### Immutability and initialization contracts
- `init` and `required` with records
- Records are not automatically deeply immutable
- Enforcing invariants (constructor vs factory vs `required`)

### Performance notes
- Allocation and copying costs
- Large records and `with` in hot paths
- Record struct trade-offs (copying, boxing, mutability hazards)

### Common pitfalls
- Mutable members break value-like expectations
- Using records for entities with identity (vs value objects)
- Equality surprises with collections/references inside records
