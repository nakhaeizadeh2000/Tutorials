## 1. Every param is coerced and checked (strings typing — injection declining, trust earning)

**Definition** — the param line on every route: coercion + validation ([1.1](<../../sections/1. Params/1.1. Params typing (coercion owning — validation guarding (trust earning — injection declining).

**What problem it solves** — the untyped trio: *comparisons failing* (strings equaling numbers never (lookups missing — results vanishing (types mismatching — queries failing (coercion forgetting — validation missing); *arithmetic corrupting* (strings concatenating — totals wronging (math breaking — prices erring (parsing skipping — checking absenting (validation hoping — correctness breaking); *injection sliding* (params executing raw — queries obeying (abuse inviting — breaches scheduling (allowlisting missing — trust defaulting (validation absenting — security hoping). Coerced params converting strings to types (parsing numbering — validation guarding (trust earning — injection declining); reviewers checking conversions, not assumptions (types owning → verifiable; hoping → returned).

**Modern guidance** — the param lines per route (review-enforced): *numbers parsing* (types owning — comparisons working (lookups hitting — math adding (validation guarding — trust earning (injection declining — security composing); *shapes predicting* (parsers knowing — structures varying (contracts stating — surprises ending (era labeling — behavior dating (docs consulting — assumptions expiring); *injection guarding* (allowlisting bounding — inputs taming (databases protecting — breaches declining (validation owning — security composing (abuse preventing — trust earning).

```javascript
// GOOD: params typing — numbers parsing, shapes predicting, injection guarding (shapes, runnable).
app.get('/items/:id', (req, res) => {
  const id = Number(req.params.id); // numbers parsing — types owning, comparisons working
  if (!Number.isInteger(id) || id <= 0) return res.status(400).json({ error: 'id?' }); // validation guarding
  res.json({ id });
});
```

```javascript
// BAD: params assuming — comparisons failing, arithmetic corrupting, injection sliding (real failure shape).
// users.get(req.params.id); // strings querying — lookups missing (types mismatching — results vanishing).
// db.query(`... ${req.params.id}`); // inputs trusting — injection inviting (allowlist missing — trust defaulting).
// '7' + 1 === '71' (arithmetic concatenating — totals corrupting). Parse; predict; guard.)
```

**Common confusion** — *"checklists slow reviews (bureaucracy taxing velocity)."* Checklists catching structurally (params typing pre-production — design fixing (costs trivial — types owning (fixes cheap — production sparing); production incidents costing (misses corrupting — injections breaching (fixes structural — urgency pricing (redesigns rushing — trust burning); reviews accelerating (patterns internalizing — parsing defaulting (discipline habituating — checks instancing (velocity composing — quality enabling). "Slowing" describing learning curves (checks consciousing — speed recovering); unreviewed describing incidents (failures discovering — velocity destroying). Check structurally (fixes cheap — production sparing); habituate quickly (discipline internalizing — velocity composing).

**Performance note** — param economics: parsing costing conversions (types owning — comparisons working (validation guarding — trust earning); predicting costing parser knowledge (shapes stating — surprises ending (era labeling — behavior dating); guarding costing checks (abuse declining — breaches preventing (validation owning — security composing); untyped equivalents costing misses + corruption + injection (results vanishing — totals wronging — breaches scheduling). Parse cheaply (conversions — types); guard always (checks — trust).

**Mentor note** — teach "strings in, types out — at the route door" (juniors parsing per param design typed handlers on first hearing; raw params interrogated ("typed how?" — coercion demanding per param). Review drill: route without coercion returned automatically (typing structural — checklists enforcing). Parse numbers; guard shapes — param discipline in two habits, reviewed per param.

## 3. Every async path forwards errors (rejections catching — central receiving, never hanging)

**Definition** — the async line on every path: errors forwarding centrally ([3.1](<../../sections/3. Async safety/3.1. **What problem it solves** — the unforwarded trio: *hangs timing out* (awaits throwing (handlers exiting — responses nevering (clients waiting — errors vanishing (failures hiding — debugging haunting (rejections unforwarding — central missing); *joins serializing* (fetches awaiting one-by-one (latency summing — responses slowing (parallelism ignoring — performance hoping (independence missing — concurrency declining); *timeouts missing* (upstreams stalling — awaits pending forever (workers holding — resources leaking (bounds absenting — liveness hoping (discipline missing — exhaustion scheduling). Forwarded async converting hanging to handling (rejections catching — joins gating (timeouts bounding — central receiving); reviewers checking async paths reach central, not hoping (forwarding proving → verifiable; vanishing → returned).

**Modern guidance** — the async lines per path (review-enforced): *rejections trusting* (async throwing — central catching (handlers receiving — recovery structuring (swallowing ending — debugging easing (versions advancing — behavior modernizing (forwarding proving — hangs declining); *joins gating* (tasks racing — results composing (latency minimizing — failures structuring (parallelism exploiting — sequential declining (independence leveraging — concurrency owning); *timeouts bounding* (races limiting — hangs declining (resources freeing — liveness proving (discipline enforcing — exhaustion scheduling never (bounds setting — SLOs guarding).
