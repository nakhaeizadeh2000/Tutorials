**Modern guidance** — the gate lines per release (review-enforced): *tests proving* (suites passing — contracts asserting (regressions catching — merges blocking (quality defending — confidence earning (discipline enforcing — hope ending (evidence owning — pressure surviving); *config gating* (schemas crashing early — deploys blocking (serving proving — correctness starting (chaos preventing — validation owning (degradation declining — failures exiting); *probes answering* (live cheaping — ready deeping (traffic gating — verdicts acting (health evidencing — availability defending (orchestrators deciding — load balancing).

**Mentor note** — teach "red gates stop, green gates ship" (juniors gating per release design quality deploys on first hearing; gateless shipping interrogated ("proof?" — gating demanding per release).
