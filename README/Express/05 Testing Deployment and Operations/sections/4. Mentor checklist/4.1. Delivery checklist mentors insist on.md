## 1. Every handler tests headless (supertest/mocks proving — servers skipping, never binding)

**Definition** — the headless line on every handler: tests proving without listening ([1.1](<../../sections/1. Tests/1.1. **What problem it solves** — the bound-test trio: *servers per suite* (listens binding — ports colliding (suites flaking — parallel failing (setup heavying — feedback slowing (isolation missing — determinism hoping); *logic unproving* (handlers untesting — branches uncovering (regressions shipping — confidence hoping (coverage missing — quality assuming (evidence absenting — trust eroding); *contracts hoping* (assertions missing — statuses unchecking (bodies unshaping — regressions merging (coverage theatering — quality feigning (discipline absenting — merges unblocking). Headless tests converting binds to proof (supertest driving — mocks isolating (contracts asserting — servers skipping); reviewers checking headless suites, not ports (testing proving → verifiable; binding → returned).

**Modern guidance** — the headless lines per handler (review-enforced): *supertest driving* (apps injecting — requests flowing (ports unbinding — servers skipping (sockets avoiding — collisions declining (tests parallelizing — CI stabilizing (isolation owning — determinism proving); *mocks isolating* (req/res faking — units proving (servers skipping — tests running (express unimporting — suites executing (inputs controlling — outputs predicting); *contracts asserting* (status checking — bodies verifying (regressions catching — merges blocking (coverage meaning — theater ending (behavior proving — quality earning).

// supertest(app).get('/x').expect(200) (apps injecting — requests flowing — ports unbinding, servers skipping)
// mock req/res unit tests (inputs controlling — outputs predicting — units proving, servers skipping)

**Common confusion** — *"headless tests miss integration (units insufficient)."* Units proving logic (inputs controlling — outputs predicting (branches covering — regressions catching (isolation owning — speed funding (confidence earning — feedback quickening); integration proving composition (supertest asserting — contracts verifying (drift detecting — wholes proving (layers stacking — confidence completing (reality checking — units composing); headless covering both (mocks isolating — supertest driving (servers skipping — ports freeing (proof composing — hope ending (discipline doubling — quality compounding). "Missing" describing units-only (logic proving — composition assuming); headless describing injection (apps driving — servers skipping). Mock units (req/res faking — logic proving); drive integration (supertest asserting — drift detecting).

**Performance note** — headless economics: driving costing calls (requests flowing — ports freeing (tests parallelizing — suites stabilizing (isolation owning — determinism proving); isolating costing literals (inputs controlling — outputs predicting (units proving — servers skipping (express unimporting — tests running); asserting costing checks (status routing — handling proving (contracts holding — consistency verifying (coverage meaning — theater ending); bound equivalents costing flakes + minutes (ports colliding — latency adding). Drive cheaply (calls — parallelism); isolate always (literals — units).

**Mentor note** — teach "no listen in tests — ever" (juniors injecting per suite design stable tests on first hearing; listening suites interrogated ("port?" — headlessness demanding per test). Parallelize once (suites running concurrently — collisions absent tangible (stability proving — flakiness ending permanently). Drive headless; assert contracts — test discipline in two habits, reviewed per suite.

**Modern guidance** — the gate lines per deploy (review-enforced): *schemas crashing early* (env proving — deploys blocking (serving proving — correctness starting (chaos preventing — validation owning (degradation declining (failures exiting — feedback quickening (discipline proving — trust earning); *pipelines asserting* (CI running — tests executing (contracts proving — quality gating (merges blocking — failures surfacing (discipline enforcing — confidence earning (checks owning — hope ending); *rollouts guarding* (deploys sequencing — health verifying (traffic shifting — errors watching (releases owning — incidents preventing (procedures owning — panic declining (confidence earning — practice demonstrating).

## 3. Every process drains (closes owning — probes answering — improvisation ending)

**Modern guidance** — the drain lines per process (review-enforced): *closes owning* (server stopping — in-flight landing (data preserving — losses preventing (grace honoring — clients completing (shutdown owning — availability sustaining (losses bounding — totals proving); *probes answering* (live cheaping — ready deeping (traffic gating — verdicts acting (health evidencing — availability defending (orchestrators deciding — load balancing (depth pricing — truth telling); *improvisation ending* (procedures owning — panic declining (discipline enforcing — quality stabilizing (practice pricing — confidence earning (evidence owning — hope ending).
