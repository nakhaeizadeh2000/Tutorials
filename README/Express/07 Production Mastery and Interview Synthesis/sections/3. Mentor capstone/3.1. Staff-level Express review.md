## 2. Decisions carry prices (every choice windowed — trade-offs explicit, never vibed)

**Modern guidance** — the pricing lines per decision (review-enforced — capstone, never repetition): *staleness numbering* (bounds stating — rot declining (decisions half-pricing — vibes halving (freshness costing — coupling pricing (numbers ruling — hope ending); *durability numbering* (statements bounding — losses limiting (honesty earning — safety costing (budgets owning — numbers ruling (decisions halving — vibes ending); *availability numbering* (coupling stating — outages bounding (uptime spending — resilience designing (trade-offs owning — judgment proving (decisions completing — vibes absenting).
