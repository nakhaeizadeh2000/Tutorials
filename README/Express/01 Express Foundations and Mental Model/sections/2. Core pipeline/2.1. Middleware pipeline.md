## 2. next passes control (calling forward — hanging declined, double-sending forbidden)

**Definition** — next(): the forward handoff between layers (calling continuing — chains advancing (control passing — layers executing (flow progressing — completion approaching (hanging declining — stalls ending); omitting hanging (responses nevering — clients timing out (requests dangling — resources holding (silence answering — failures hiding (debugging haunting — timeouts blaming); double-calling crashing (headers re-sending — ERR_HTTP_HEADERS_SENT throwing (responses duplicating — handlers racing (sends competing — errors erupting (flow corrupting — completion doubling). Disciplined handoffs converting hangs to flows (next calling — sends returning (chains advancing — completions reaching); reviewers checking every path ends-or-forwards, not hoping (handoff disciplining → verifiable; dangling → returned).

**Modern guidance** — the next lines per middleware (review-enforced): *forward-or-finish* (next() xor res.send (chains advancing — completions reaching (hangs declining — doubles forbidding (flow owning — discipline enforcing (paths ending — clients answering); *return after send* (execution stopping — downstream skipping (sends singling — crashes declining (discipline coding — flow protecting (returns guarding — doubles preventing); *next(err) failing* (errors forwarding — central catching (handlers reaching — recovery structuring (failures surfacing — hiding ending (catching placing — handling owning).

```javascript
// GOOD: handoffs disciplining — forward-or-finishing, returning after send, errors forwarding (complete, runnable).
function guard(req, res, next) {
  if (!req.headers.key) return res.sendStatus(401); // finish + return — downstream skipping, doubles preventing
  next(); // forward — chains advancing, completions approaching, hangs declining
}
function loader(req, res, next) {
  load(req).then((d) => { req.data = d; next(); }, next); // errors forwarding — central catching, hiding ending
}
const express = require('express');
const app = express();
app.use(guard, loader);
app.get('/', (req, res) => res.json({ data: req.data }));
app.listen(3000);
```
