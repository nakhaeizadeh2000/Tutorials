**What problem it solves** — the raw-http trio: *switch-statement routing* (methods + URLs branching manually (handlers nesting — files growing (boilerplate compounding — readability decaying (routing hand-rolling — maintenance ballooning); *parsing hand-rolled* (bodies concatenating — JSON trying (queries splitting — parsing repeating (middleware missing — code duplicating (concerns tangling — logic scattering); *servers rewired* (sockets managing per app — TLS configuring (connections handling — HTTP owning (frameworks rebuilding — Node duplicating). Thin routing converting manual dispatch to declaration (routes mapping — bodies parsing (servers borrowing); reviewers reading routes, not switches (URLs declaring → verifiable; branching → returned).

**Modern guidance** — the thin lines per app (review-enforced — examples complete + runnable, `node --check` validated, behavior per docs): *routes declaring* ([1.2](<../../sections/1. First app/1.2. ```javascript

## 2. Middleware composes behavior (functions chaining — auth/logging/parsing layered, never tangled)

**Definition** — middleware composition: request behavior layering via chained functions ([2.1](<../../sections/2. Core pipeline/2.1. **What problem it solves** — the tangled-handler trio: *god handlers* (auth + parsing + logic nesting (functions ballooning — testing requiring full requests (concerns tangling — logic scattering (readability decaying — reuse impossibleing); *copied guards* (auth repeating per route (checks duplicating — drift scheduling (updates missing — coverage gapping (consistency hoping — breaches awaiting); *order hoping* (sequence assuming — parsing running after reading (bodies emptying — failures surprising (ordering unowned — execution guessing (flow unexamined — behavior flapping). Chained middleware converting tangles to layers (guards centralizing — parsing preceding (order owning — flow examining); reviewers reading stacks, not handlers (behavior layering → verifiable; nesting → returned).

**Modern guidance** — the composition lines per app (review-enforced): *guards centralizing* (auth once (checks single-sourcing — drift ending (updates propagating — coverage completing (consistency holding — breaches declining); *parsing preceding* (bodies filling before reading (order owning — emptiness declining (failures surfacing — flow examining (execution sequencing — behavior stabilizing); *layers testing* (functions isolating — req/res mocking (logic focusing — coverage targeting (reusability rising — tangling declining (quality compounding — confidence earning).

```javascript
// GOOD: behavior layering — guards centralizing, parsing preceding, layers testing (shapes, runnable).
const express = require('express');
const app = express();
app.use(express.json()); // parsing preceding — bodies filling before reading, order owning
app.use((req, res, next) => { console.log(req.method, req.url); next(); }); // logging layering — flow continuing
app.use('/admin', (req, res, next) => (req.headers.key === 's3cret' ? next() : res.sendStatus(401))); // guard centralizing
app.get('/admin/data', (req, res) => res.json({ secret: true })); // handler focusing — logic isolating
```

```javascript
// BAD: handlers tangling — god functions, guards copying, order hoping (real failure shape).
// app.get('/admin/data', (req, res) => {
//   console.log(...); // logging tangling — every handler repeating (concerns scattering — logic drowning)
//   if (req.headers.key !== 's3cret') return res.sendStatus(401); // guards copying — drift scheduling
//   let body = ''; req.on('data', ...); // parsing repeating — order hoping (bodies emptying — failures surprising)
// }); // Test requiring full requests — reuse impossible. Layer behavior; centralize guards.)
```

**Common confusion** — *"more middleware means slower (layers taxing)."* Layers costing microseconds (functions calling — next forwarding (overhead stacking — behavior composing (costs trivial — value composing); god handlers costing readability (nesting ballooning — testing requiring (quality declining — reuse impossibleing (costs compounding — debt growing); tangles costing incidents (concerns scattering — guards drifting (breaches awaiting — coverage gapping (costs exploding — trust burning). "Slower" describing nanoseconds (functions calling — overhead trivialing); tangles describing debt (readability declining — incidents awaiting). Layer cheaply (microseconds — behavior); untangle always (readability — trust).

**Mentor note** — teach "one job per function, order on purpose" (juniors sequencing per concern design layered apps on first hearing; god handlers interrogated ("testable alone?" — isolation demanding per function). Stack three once (parse → log → guard flowing — layering tangible (composition visible — tangles ending permanently). Separate concerns; sequence deliberately — composition discipline in two habits, reviewed per app.

## 3. Unopinionated means owned (no structure given — organization designed, never defaulted)
