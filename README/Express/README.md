# Express track (recommended order, September 2026 era)

Minimal backend framework for huge apps — Express from foundations to production: routing, middleware, errors, validation, data access, testing, and operations — from zero to hero and beyond (junior to mentor depth). Raw Node.js *runtime* mechanics live in the [Node.js track](<../NodeJS/README.md>); raw *HTTP without frameworks* lives in NodeJS 04; data-access *layers* live in the [ORM track](<../ORM/README.md>). This track assumes working JavaScript + HTTP basics and teaches *Express*: what each layer owns, costs, and deserves. Version-sensitive claims are labeled (as of September 2026: Express 5.x stable).
