## 1. Routes unifying (entries owning — paths mapping — versions scoping)

**Definition** — gateway routing: single entries mapping paths to backends with versions (entries owning — front doors (requests receiving — backends hiding (owning proving — scattering declining); paths mapping — routes tabled (prefixes stripping — versions scoping (mapping funding — guessing declining); versions scoping — releases numbering (clients trusting — surprises declining (scoping owning — hoping ending).

**What problem it solves** — the scattered-URL trio: *clients discovering* (services addressing — URLs hardcoding (topologies leaking — refactors breaking (discovering billing — encapsulation declining); *paths unmapping* (routes hoping — backends guessing (contracts missing — calls failing (unmapping charging — reliability declining); *versions unscoped* (releases unmixing — clients breaking (numbers missing — surprises scheduling (unscoping costing — trust eroding). Unified routes converting scattering to owning (entries fronting — paths tabling (versions numbering — guesses ending); reviewers reading route tables per gateway (unifying proving → verifiable; scattering → returned).

**Modern guidance** — the unifying lines per gateway (review-enforced): *entries owning* (front doors — requests receiving (backends hiding — scattering declining (owning proving — exposing refusing (doors funding — topologies hiding); *paths mapping* (routes tabling — prefixes stripping (versions scoping — guessing declining (mapping funding — hoping ending (tables owning — hardcoded declining); *versions scoping* (releases numbering — clients trusting (surprises declining — hoping ending (scoping owning — mixing refusing (clarity earning — archaeology declining).

```typescript
// GOOD: routes unifying — table-driven routing with prefix strips and misses (compiled + run live).
interface Route { // paths mapping — routes tabling, guessing declining
  prefix: string;
  backend: string;
}
function routeOf(routes: Route[], path: string): string {
  const hit = routes.filter((r) => path === r.prefix || path.startsWith(`${r.prefix}/`)).sort((a, b) => b.prefix.length - a.prefix.length)[0]; // entries owning — front doors, scattering declining
  return hit === undefined ? '404' : `${hit.backend}${path.slice(hit.prefix.length) || '/'}`; // versions scoping — releases numbering, hoping ending
}
const routes: Route[] = [
  { prefix: '/v1/orders', backend: 'orders-svc' },
  { prefix: '/v1', backend: 'legacy-svc' },
];
const a = routeOf(routes, '/v1/orders/i1');
const b = routeOf(routes, '/v1/health');
const c = routeOf(routes, '/v9/nope');
console.log(a === 'orders-svc/i1' && b === 'legacy-svc/health' && c === '404' ? 'routes unify' : 'URLs scatter');
```

## 2. Auth centralizing (tokens verifying — scopes enforcing — intrusions declining)

**Definition** — central auth: edge verifying tokens and enforcing scopes (tokens verifying — signatures checking (issuers trusting — expiries enforcing (verifying proving — hoping ending); scopes enforcing — claims requiring (routes declaring — access limiting (enforcing funding — leaking declining); intrusions declining — attackers refusing (breaches preventing — alarms funding (declining owning — hoping ending).

**What problem it solves** — the scattered-auth trio: *services authorizing* (handlers branching — logic scattering (audits missing — consistency failing (authorizing billing — ownership blurring); *tokens unchecking* (signatures hoping — expiries ignoring (forgeries arriving — breaches scheduling (unchecking charging — safety declining); *scopes missing* (routes unscoped — access hoping (claims unchecked — leaks scheduling (missing costing — enforcement bluffing). **Modern guidance** — the centralizing lines per edge (review-enforced): *tokens verifying* (signatures checking — issuers trusting (expiries enforcing — hoping ending (verifying proving — trusting declining (checks owning — forgeries declining); *scopes enforcing* (claims requiring — routes declaring (access limiting — leaking declining (enforcing funding — hoping ending (limits owning — exposure declining); *intrusions declining* (attackers refusing — breaches preventing (alarms funding — hoping ending (declining owning — missing refusing (safety funding — incidents declining).

```typescript
// GOOD: auth centralizing — token verification plus per-route scope checks (compiled + run live).
interface Claims { // tokens verifying — signatures checking, hoping ending
  sub: string;
  scopes: string[];
  exp: number;
}
function verify(raw: string, now: number): Claims | undefined {
  const [sub, scopes, exp] = raw.split('|'); // issuers trusting — expiries enforcing, forgeries declining
  if (sub === undefined || sub.length === 0 || scopes === undefined) return undefined;
  if (Number(exp) <= now) return undefined;
  return { sub, scopes: scopes.split(','), exp: Number(exp) };
}
function allowed(c: Claims | undefined, need: string): boolean {
  return c !== undefined && c.scopes.includes(need); // scopes enforcing — claims requiring, leaking declining
}
const good = verify('ada|items:write|9999999999', 1000);
const stale = verify('ada|items:write|500', 1000);
console.log(allowed(good, 'items:write') && !allowed(good, 'admin') && !allowed(stale, 'items:write') ? 'auth centralizes' : 'services authorize');
```

## 3. Limits throttling (rates capping — bursts queuing — fairness funding)

**Definition** — rate limiting: per-key budgets capping rates with queued bursts (rates capping — calls bounding (budgets owning — floods declining (capping proving — hoping ending); bursts queuing — spikes absorbing (queues draining — rejects bounding (queuing funding — dropping declining); fairness funding — tenants isolating (neighbors protecting — hogs declining (funding owning — starving ending).

**What problem it solves** — the unlimited trio: *calls unbounding* (rates uncapped — floods arriving (servers crushing — legit starving (unbounding billing — policy declining); *bursts dropping* (spikes rejecting — retries stampeding (thundering arriving — outages cascading (dropping charging — absorbing declining); *neighbors hogging* (tenants consuming — quotas missing (fairness absenting — starvation scheduling (hogging billing — isolation declining). Throttled limits converting unbounding to capping (rates bounding — bursts queuing (fairness isolating — floods declining); reviewers finding budgets per key (throttling proving → verifiable; unbounding → returned).

**Modern guidance** — the throttling lines per key (review-enforced): *rates capping* (calls bounding — budgets owning (floods declining — hoping ending (capping proving — unbounding refusing (limits owning — strain declining); *bursts queuing* (spikes absorbing — queues draining (rejects bounding — dropping declining (queuing funding — stampeding refusing (absorption owning — cascade declining); *fairness funding* (tenants isolating — neighbors protecting (hogs declining — starving ending (funding owning — missing refusing (quotas earning — hogging declining).

```typescript
// GOOD: limits throttling — token buckets with burst queues per key (compiled + run live).
class Bucket { // rates capping — calls bounding, hoping ending
  private tokens: number;
  constructor(private readonly cap: number) {
    this.tokens = cap;
  }
  take(n = 1): boolean {
    if (this.tokens < n) return false; // bursts queuing — spikes absorbing, dropping declining
    this.tokens -= n;
    return true;
  }
  refill(n = 1): void {
    this.tokens = Math.min(this.cap, this.tokens + n); // fairness funding — tenants isolating, starving ending
  }
}
const b = new Bucket(2);
const r1 = b.take();
const r2 = b.take();
const r3 = b.take();
b.refill(1);
const r4 = b.take();
console.log(r1 && r2 && !r3 && r4 ? 'limits throttle' : 'calls unbound');
```
