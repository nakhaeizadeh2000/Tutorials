# 1.2. Decision records stating choices

## 1. Records stating (options listing — prices attaching — reversals naming)

**Definition** — decision record: dated choice with options, prices, and reversals (options listing — alternatives stating (rejected naming — reasons owning (listing proving — hiding ending); prices attaching — costs estimating (trade-offs admitting — surprises declining (attaching funding — vibing declining); reversals naming — exits planning (migrations funding — pivots owning (naming proving — fossilizing declining).

**What problem it solves** — the oral-decision trio: *choices evaporating* (decisions discussing — records missing (reasons vanishing — revisits relitigating (evaporating billing — memory relying); *options hiding* (alternatives unlisted — losers unnamed (diligence bluffing — judgment doubting (hiding charging — rigor declining); *prices missing* (costs unstated — reversals unowned (surprises scheduling — pivots dreading (missing costing — agility dying). Stated records converting evaporating to listing (options naming — prices attaching (reversals planning — memory declining); reviewers reading records per decision (stating proving → verifiable; evaporating → returned).

**Modern guidance** — the stating lines per decision (review-enforced): *options listing* (alternatives stating — rejected naming (reasons owning — hiding ending (listing proving — assuming refusing (diligence owning — bluffing declining); *prices attaching* (costs estimating — trade-offs admitting (surprises declining — vibing ending (attaching funding — missing refusing (numbers owning — faith declining); *reversals naming* (exits planning — migrations funding (pivots owning — fossilizing declining (naming proving — hoping ending (outs owning — dread declining).

```typescript
// GOOD: records stating — completeness asserting options, prices, reversals (compiled + run live).
interface Decision { // options listing — alternatives stating, hiding ending
  choice: string;
  options: string[];
  price: number;
  reversal: string;
}
function complete(r: Partial<Decision>): boolean {
  return (
    typeof r.choice === 'string' && r.choice.length > 0 &&
    Array.isArray(r.options) && r.options.length >= 2 && // prices attaching — costs estimating, vibing ending
    typeof r.price === 'number' &&
    typeof r.reversal === 'string' && r.reversal.length > 0 // reversals naming — exits planning, fossilizing declining
  );
}
const full: Partial<Decision> = { choice: 'rest', options: ['rest', 'graphql'], price: 7, reversal: 'gateway-strangle' };
const thin: Partial<Decision> = { choice: 'rest' };
console.log(complete(full) && !complete(thin) ? 'records state' : 'decisions evaporate');
```

```typescript
// BAD: decisions evaporating — choices discussing, options hiding (real oral shape).
// // "We decided in the meeting." (reasons vanishing — revisits relitigating — memory relying).
// // Alternatives unlisted (diligence bluffing — judgment doubting). List options; attach prices; name reversals.)
```

**Common confusion** — *"records are bureaucracy (documents slowing)."* Records stating choices (options listing — prices attaching (reversals naming — memory declining (stating proving — evaporating ending); bureaucracy padding ceremony (forms multiplying — value missing (approvals queuing — ships waiting (padding charging — agility declining). "Bureaucracy" describing ceremony (forms multiplying — value missing); records describing memory (choices stating — reasons owning). State choices (options listing — prices attaching); pad never (forms multiplying — value missing).

**Performance note** — stating economics: listing costing entries (options stating — prices attaching (reversals naming — memory declining); evaporated equivalents costing relitigation (reasons vanishing — decisions rediscussing (time wasting — momentum dying (evaporating billing — memory relying). State cheaply (records — entries); evaporate never (choices — memory).

**Mentor note** — teach "no record, no decision" (juniors stating one record per choice design evaporation-proof judgment on first hearing; unrecorded choices interrogated ("where is the ADR?" — stating demanding per decision). State one choice once (options listing — prices attaching tangible (evaporating ending — stating proving permanently). List alternatives; name exits — stating discipline in three habits, reviewed per decision.

## 2. Choices reviewing (peers approving — dates stating — owners naming)

**Definition** — choice review: peers approving dated, owned records (peers approving — eyes seconding (blindspots catching — groupthink declining (approving proving — soloing ending); dates stating — moments marking (staleness judging — revisits scheduling (stating funding — timeless declining); owners naming — humans answering (accountability owning — diffusion declining (naming proving — orphaning ending).

**What problem it solves** — the solo-decision trio: *choices soloing* (authors deciding — reviewers absenting (blindspots persisting — mistakes compounding (soloing billing — diligence declining); *dates missing* (moments unmarked — staleness unknown (contexts aging — revisits unplanned (missing charging — relevance bluffing); *owners orphaning* (decisions homeless — questions bouncing (accountability absenting — quality diffusing (orphaning costing — pride declining). Reviewed choices converting soloing to approving (peers seconding — dates marking (owners answering — blindspots catching); reviewers approving records per choice (reviewing proving → verifiable; soloing → returned).

**Modern guidance** — the reviewing lines per record (review-enforced): *peers approving* (eyes seconding — blindspots catching (groupthink declining — soloing ending (approving proving — rubber-stamping refusing (diligence owning — haste declining); *dates stating* (moments marking — staleness judging (revisits scheduling — timeless declining (stating funding — aging declining (freshness owning — rot declining); *owners naming* (humans answering — accountability owning (diffusion declining — orphaning ending (naming proving — bouncing refusing (people owning — homelessness ending).

**Common confusion** — *"reviews slow decisions (process throttling)."* Reviews catching blindspots (peers seconding — mistakes preventing (diligence funding — soloing ending (catching proving — throttling declining); throttling blocking value (approvals queuing — ships waiting (process taxing — momentum dying (throttling charging — agility declining). "Throttling" describing ceremony (approvals queuing — value missing); reviews describing diligence (blindspots catching — mistakes preventing). Approve peers (eyes seconding — blindspots catching); throttle never (approvals queuing — value missing).

**Performance note** — reviewing economics: approving costing reviews (peers seconding — dates stating (owners naming — blindspots catching); soloed equivalents costing mistakes (authors deciding — reviewers absenting (blindspots persisting — mistakes compounding). Approve cheaply (peers — reviews); solo never (authors — blindspots).

**Mentor note** — teach "second eyes per decision" (juniors approving one record per peer design solo-proof choices on first hearing; unreviewed choices interrogated ("who seconded?" — reviewing demanding per decision). Review one choice once (peers approving — dates stating tangible (soloing ending — reviewing proving permanently). Second decisions; date moments — reviewing discipline in three habits, reviewed per choice.

## 3. Reversals owning (exits planning — sunsets stating — pivots funding)

**Definition** — reversal ownership: every choice planning exits with sunsets (exits planning — outs designing (migrations funding — pivots owning (planning proving — fossilizing declining); sunsets stating — ends declaring (traffic draining — stranding declining (stating funding — arriving refusing (clarity earning — panic declining); pivots funding — alternatives financing (switches budgeting — dread declining (funding owning — locking ending).

**What problem it solves** — the one-way trio: *doors confusing* (one-ways treating-two-way (reversals assuming — migrations unplanned (confusing billing — pivots missing); *exits unplanning* (outs undesigned — switches unbudgeted (alternatives unfunded — dread funding (unplanning charging — agility dying); *sunsets missing* (ends undeclared — traffic stranding (migrations panicking — trust eroding (missing costing — reliability declining). Owned reversals converting confusing to planning (doors typing — exits designing (sunsets declaring — pivots funding); reviewers typing doors per decision (owning proving → verifiable; confusing → returned).

**Modern guidance** — the owning lines per choice (review-enforced): *exits planning* (outs designing — migrations funding (pivots owning — fossilizing declining (planning proving — hoping ending (designs owning — prayers declining); *sunsets stating* (ends declaring — traffic draining (stranding declining — arriving refusing (stating funding — missing refusing (clarity earning — panic declining); *pivots funding* (alternatives financing — switches budgeting (dread declining — locking ending (funding owning — hoping ending (options keeping — traps declining).

```typescript
// GOOD: reversals owning — door types routing reversibility demands (compiled + run live).
type Door = 'one-way' | 'two-way';
function needsPlan(door: Door, migrated: boolean): boolean { // exits planning — outs designing, fossilizing declining
  if (door === 'two-way') return false;
  return !migrated; // sunsets stating — ends declaring, arriving refusing
}
const a = needsPlan('one-way', false);
const b = needsPlan('one-way', true);
const c = needsPlan('two-way', false); // pivots funding — alternatives financing, locking ending
console.log(a && !b && !c ? 'reversals own' : 'doors confuse');
```

```typescript
// BAD: doors confusing — one-ways treating-two-way, exits unplanning (real one-way shape).

// // No sunset (ends undeclared — traffic stranding). Type doors; plan exits; state sunsets.)
```

**Common confusion** — *"planning exits is pessimism (doubt performing)."* Exits enabling pivots (outs designing — migrations funding (alternatives financing — dread declining (enabling proving — fossilizing declining); pessimism predicting doom (failures forecasting — ships halting (gloom serving — value missing (predicting charging — building declining). "Pessimism" describing gloom (doom forecasting — ships halting); planning describing optionality (exits designing — pivots funding). Plan outs (exits designing — migrations funding); doom never (failures forecasting — ships halting).

**Performance note** — owning economics: planning costing exit designs (outs owning — migrations funding (pivots owning — fossilizing declining); confused equivalents costing traps (one-ways treating-two-way — migrations unplanned (pivots missing — agility dying). Plan cheaply (exits — designs); confuse never (doors — types).

**Mentor note** — teach "type the door first" (juniors owning one exit per choice design trap-proof decisions on first hearing; doorless choices interrogated ("one-way or two-way?" — owning demanding per decision). Own one exit once (outs designing — sunsets stating tangible (confusing ending — owning proving permanently). Design outs; fund pivots — owning discipline in three habits, reviewed per choice.
