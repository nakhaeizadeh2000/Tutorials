# 1.1. Needs matching styles judging trade-offs

## 1. Needs matching (workloads stating — styles fitting — experiences funding)

**Definition** — need matching: workload features scored against styles (workloads stating — realtime flagging (mobility marking — internal scoping (stating proving — assuming ending); styles fitting — REST serving (graphs answering — streams flowing (fitting funding — defaulting declining); experiences funding — clients thriving (latencies bounding — payloads shaping (funding owning — degrading declining).

**What problem it solves** — the default-style trio: *stacks defaulting* (REST assuming — graphs ignoring (streams missing — needs unmatching (defaulting billing — judgment missing); *needs unstating* (workloads undescribed — features unlisted (fits hoping — mismatches hiding (unstating charging — matching declining); *experiences degrading* (mobiles choking — realtime lagging (mismatches billing — users leaving (degrading costing — fit bluffing). Matched needs converting defaulting to stating (workloads describing — styles fitting (experiences funding — mismatches declining); reviewers scoring needs per API (matching proving → verifiable; defaulting → returned).

**Modern guidance** — the matching lines per API (review-enforced): *workloads stating* (realtime flagging — mobility marking (internal scoping — assuming ending (stating proving — defaulting refusing (features owning — hope declining); *styles fitting* (REST serving — graphs answering (streams flowing — defaulting declining (fitting funding — mismatching ending (tools owning — needs meeting); *experiences funding* (clients thriving — latencies bounding (payloads shaping — degrading declining (funding owning — starving refusing (users earning — churn declining).

```typescript
// GOOD: needs matching — feature scores routing workloads to styles (compiled + run live).
type Style = 'rest' | 'graphql' | 'grpc';
function score(needs: { realtime: boolean; mobile: boolean; internal: boolean }): Style {
  let rest = 1;
  let gql = 1;
  let rpc = 1; // workloads stating — realtime flagging, assuming ending
  if (needs.realtime) rpc += 3;
  if (needs.mobile) gql += 3;
  if (needs.internal) rpc += 2;
  if (!needs.realtime && !needs.mobile) rest += 3; // styles fitting — REST serving, defaulting declining
  const best: Array<[Style, number]> = [['rest', rest], ['graphql', gql], ['grpc', rpc]];
  best.sort((a, b) => b[1] - a[1]);
  return best[0][0]; // experiences funding — clients thriving, degrading declining
}
const a = score({ realtime: true, mobile: false, internal: true });
const b = score({ realtime: false, mobile: true, internal: false });
const c = score({ realtime: false, mobile: false, internal: false });
console.log(a === 'grpc' && b === 'graphql' && c === 'rest' ? 'needs match' : 'styles default');
```

"Matrices" describing tools (options scoring — totals ranking); matching describing judgment (needs meeting — experiences funding). ## 2. Trade-offs judging (costs pricing — reversals naming — vibes declining)

**Definition** — trade-off judgment: every style priced with build, operate, and reversal costs (costs pricing — builds estimating (operations funding — reversals naming (pricing proving — vibing declining); reversals naming — exits planning (migrations funding — pivots owning (naming funding — fossilizing declining); vibes declining — feelings refusing (evidence demanding — reasons owning (declining proving — hoping ending).

**What problem it solves** — the unpriced trio: *costs hiding* (builds unstated — operations unowned (bills invisible — surprises scheduling (hiding billing — honesty declining); *reversals missing* (exits unplanned — migrations dreading (decisions fossilizing — pivots missing (missing costing — agility dying); *vibes deciding* (feelings choosing — evidence missing (reasons absenting — judgment bluffing (deciding charging — rigor declining). Judged trade-offs converting hiding to pricing (costs estimating — reversals planning (vibes refusing — evidence demanding); reviewers seeing price tables per style (judging proving → verifiable; hiding → returned).

**Modern guidance** — the judging lines per style (review-enforced): *costs pricing* (builds estimating — operations funding (reversals naming — vibing declining (pricing proving — hiding refusing (numbers owning — surprises declining); *reversals naming* (exits planning — migrations funding (pivots owning — fossilizing declining (naming funding — missing refusing (outs owning — dread declining); *vibes declining* (feelings refusing — evidence demanding (reasons owning — hoping ending (declining proving — bluffing refusing (rigor funding — mood declining).

```typescript
// GOOD: trade-offs judging — total-cost choice across build, operate, and reverse (compiled + run live).
interface Bid { // costs pricing — builds estimating, vibing declining
  style: string;
  build: number;
  operate: number;
  reverse: number;
}
function pick(bids: Bid[]): string {
  let best = bids[0];
  for (const b of bids.slice(1)) {
    if (b.build + b.operate + b.reverse < best.build + best.operate + best.reverse) best = b; // reversals naming — exits planning, fossilizing declining
  }
  return best.style;
}
const winner = pick([
  { style: 'rest', build: 2, operate: 3, reverse: 2 },
  { style: 'graphql', build: 5, operate: 4, reverse: 4 },
  { style: 'grpc', build: 6, operate: 2, reverse: 7 },
]);
console.log(winner === 'rest' ? 'trade-offs judge' : 'vibes decide');
```

## 3. Defaults declining (fashion refusing — reasons demanding — independence keeping)

**Definition** — default decline: no style adopted without measured reasons (fashion refusing — slogans declining (hype resisting — evidence demanding (refusing proving — following ending); reasons demanding — pilots measuring (gains pricing — sunsets stating (demanding funding — vibing declining); independence keeping — teams deciding (contexts weighing — options owning (keeping proving — herding declining).

**What problem it solves** — the hype trio: *fashion following* (slogans reciting — pilots skipping (evidence bluffing — judgment absenting (following billing — independence dying); *reasons missing* (gains unmeasured — sunsets unstated (bets fossilizing — pivots dreading (missing costing — prudence declining); *independence herding* (teams copying — contexts ignoring (options expiring — autonomy dying (herding charging — deciding declining). Declined defaults converting following to reasoning (fashion refusing — reasons demanding (independence keeping — herds thinning); reviewers demanding pilots per adoption (declining proving → verifiable; following → returned).

**Modern guidance** — the declining lines per adoption (review-enforced): *fashion refusing* (slogans declining — hype resisting (evidence demanding — following ending (refusing proving — herding declining (spines owning — crowds declining); *reasons demanding* (pilots measuring — gains pricing (sunsets stating — vibing declining (demanding funding — resuming ending (proof owning — padding declining); *independence keeping* (teams deciding — contexts weighing (options owning — herding declining (keeping proving — stampeding refusing (autonomy earning — groupthink declining).

```typescript
// GOOD: defaults declining — adoptions gated on measured pilots with sunsets (compiled + run live).
interface Bid { // reasons demanding — pilots measuring, vibing declining
  style: string;
  gainPct: number;
  sunsetQ: string;
}
function adopt(bids: Bid[], barPct: number): string[] {
  return bids.filter((b) => b.gainPct >= barPct && b.sunsetQ.length > 0).map((b) => b.style); // fashion refusing — slogans declining, evidence demanding
}
const chosen = adopt(
  [
    { style: 'hype-rpc', gainPct: 3, sunsetQ: '' },
    { style: 'rest', gainPct: 25, sunsetQ: 'Q2' },
  ],
  10,
);
console.log(chosen.join(',') === 'rest' ? 'defaults decline' : 'fashion follows');
```
