# 5.1. Common interview QA API foundations

## 1. Foundations live under pressure (styles, contracts, versions — diagnosed with fixes, priced)

**Definition** — foundation answers: styles differing, contracts preceding, versions scoping — under pressure (diagnosed with fixes — causes naming (understanding proving — reciting declining); priced with trade-offs — costs owning (judgment funding — dogma refusing (pricing earning — honesty proving).

**What problem it solves** — the reciting trio: *styles listing* ("REST, GraphQL, gRPC" naming — needs missing (vocabulary showing — matching absenting (reciting funding — designing declining); *contracts gesturing* ("documented" claiming — shapes unowned (words owning — surprises hiding (gesturing proving — proving declining); *versions handwaving* ("versioned" asserting — breaks unowned (labels owning — coordination missing (handwaving charging — scoping declining). Diagnosed answers converting reciting to matching (causes naming — fixes stating (needs meeting — costs pricing); interviewers hiring matchers, not listers (diagnosing proving → hirable; reciting → passed).

**Modern guidance** — answer shape per foundation question (diagnose → fix → price):

```typescript
// GOOD: "REST vs GraphQL?" — diagnosed with fixes, priced (answer shape).
// Diagnose: one-style defaulting (graphs overfetching — mobiles suffering — needs mismatching).
// Fix: styles differing (resources serving — graphs answering — streams flowing).
// Price: needs matching (experiences funding — defaulting declining — judgment owning).
// Differ styles; match needs — pressure stated, not hoped.)
```

```typescript
// BAD: foundations reciting — vocabulary stating, needs missing (real weak shape).
// "GraphQL is modern REST." (needs mismatching — costs hiding — designing declining).
// "We version with v2 someday." (breaks unowned — surprises scheduling — scoping declining).
// Diagnose causes; state fixes; price needs.)
```

**Common confusion** — *"foundation answers need buzzwords (vocabulary impressing)."* Buzzwords labeling styles (words stating — needs missing (labeling serving — understanding absenting (impressing hoping — hiring declining); answers proving judgment (causes naming — fixes stating (costs pricing — trade-offs owning (proving funding — reciting declining). "Buzzwords" describing vocabulary (styles listing — needs missing); answers describing matching (needs meeting — costs pricing). Diagnose causes (understanding proving — chanting declining); price needs (judgment owning — dogma refusing).

**Performance note** — answer economics: diagnosing costing one cause per question (understanding proving — reciting declining (hirable funding — chanting ending); recited equivalents costing offers (words owning — needs missing (designing declining — hiring passing). Diagnose cheaply (causes — fixes); recite never (buzzwords — passes).

**Mentor note** — drill "diagnose, fix, price" (juniors answering one foundation question per shape design hirable responses on first hearing; vocabulary-only answers interrogated ("which need?" — diagnosing demanding per answer). Shape one answer once (causes naming — fixes stating tangible (reciting ending — designing proving permanently). Diagnose causes; price needs — answering discipline in three habits, reviewed per mock.

## 2. Trade-offs live under pressure (costs, sizes, timings — honesty stated, not hoped)

**Definition** — trade-off answers: costs billing, versions scoping, sunsets announcing — honestly (honesty stating — contexts weighing (judgment owning — dogma refusing (stating funding — hoping ending); sizes timing (additives flowing — breaks numbering (evolutions ordering — surprises declining (timing proving — flagging ending).

**What problem it solves** — the always trio: *"always version" preaching* (majors churning — meaning diluting (dogma owning — judgment missing (preaching charging — clarity declining); *costs hiding* (breaks silencing — sunsets surprising (prices unowned — coordination failing (hiding billing — honesty declining); *timings ignoring* ("later" promising — removals drifting (deferral hoping — cruft accumulating (ignoring charging — decisiveness missing). Honest answers converting preaching to scoping (breaks numbering — additives flowing (sunsets announcing — surprises declining); interviewers hiring scopers, not preachers (scoping proving → hirable; preaching → passed).

**Modern guidance** — answer shape per trade-off question (bill → scope → announce):

```typescript
// GOOD: "How evolve without breaking?" — billed, scoped, announced (answer shape).
// Bill: versions numbering (breaking bumping — additive flowing — surprises declining).
// Scope: changes reviewing (diffs gating — breaks dating — merges blocking).
// Announce: sunsets declaring (ends stating — clients migrating — traffic draining).
// Number breaks; gate diffs — honesty stated, not hoped.)
```

```typescript
// BAD: trade-offs preaching — always versioning, costs hiding (real dogmatic shape).
// "Version everything." (majors churning — meaning diluting — judgment missing).
// "Breaking is fine." (clients crashing — coordination failing — honesty declining).
// Bill versions; scope changes; announce sunsets.)
```

**Common confusion** — *"honesty means no opinion (neutrality performing)."* Honesty pricing options (breaks numbering — sunsets announcing (contexts weighing — judgment owning (pricing funding — dogma refusing); opinions deciding bets (defaults stating — reversals naming (conviction serving — waffling declining (deciding proving — performing declining). "No opinion" describing abdication (judgment missing — hiring passing); honesty describing pricing (breaks billing — sunsets announcing). Price options (breaks numbering — contexts weighing); state bets (defaults stating — reversals naming).

**Performance note** — honesty economics: pricing costing one version (breaks numbering — sunsets announcing (surprises declining — trust earning); preached equivalents costing clarity (majors churning — meaning diluting (judgment missing — hiring passing). Price cheaply (versions — sunsets); preach never (dogma — clarity).

**Mentor note** — drill "bill every break" (juniors pricing one version per change design honestly-scoped responses on first hearing; always-answers interrogated ("which break?" — honesty demanding per claim). Bill one option once (breaks numbering — sunsets announcing tangible (preaching ending — honesty proving permanently). Number breaking; flow additive — honesty discipline in three habits, reviewed per mock.

## 3. Safety live under pressure (errors, envelopes, leaks — ownership stated, not hoped)

**Definition** — safety answers: errors typing, envelopes unifying, leaks declining — ownership stated (failures owning — shapes asserting (clients guiding — surprises declining (owning proving — prose declining); not hoped (runs asserting — greps confirming (evidence funding — wishing ending (stating serving — hoping declining).

**What problem it solves** — the hopeful trio: *errors proseing* (bodies apologizing — machines guessing (parsers bloating — consistency failing (proseing billing — typing declining); *statuses lying* (200 answering — errors hiding (success parsing — failures missing (lying charging — contracts breaking); *leaks traveling* (stacks serializing — secrets broadcasting (internals exposing — trust eroding (traveling billing — safety declining). Owned answers converting hoping to typing (codes classifying — statuses guiding (leaks declining — breaches preventing); interviewers hiring owners, not hopers (typing proving → hirable; hoping → passed).

**Modern guidance** — answer shape per safety question (type → mean → decline):

```typescript
// GOOD: "How do errors work?" — typed, meant, declined (answer shape).
// Type: codes classifying (failures typing — remedies stating — reqIds tracing).
// Mean: statuses guiding (2xx succeeding — 4xx fixing — 5xx owning).
// Decline: leaks refusing (stacks logging — details genericizing — secrets keeping).
// Classify failures; guide clients — ownership stated, not hoped.)
```

```typescript
// BAD: safety hoping — errors proseing, statuses lying (real hopeful shape).
// "We return 200 with error field." (success parsing — failures missing — contracts breaking).
// "Stack traces help debugging." (internals exposing — attackers reading — trust eroding).
// Type codes; mean statuses; decline leaks.)
```

**Common confusion** — *"safety answers test paranoia (fear performing)."* Paranoia fearing everything (threats imagining — ships halting (fearing serving — value missing (performing charging — building declining); safety owning errors (codes typing — leaks declining (clients guiding — breaches preventing (owning funding — hoping declining). "Paranoia" describing fear (threats imagining — ships halting); safety describing ownership (failures owning — shapes asserting). Own failures (codes typing — leaks declining); fear never (threats imagining — ships halting).

**Performance note** — safety economics: owning costing envelopes (codes typing — remedies stating (reqIds tracing — guesses ending); hoped equivalents costing breaches (internals exposing — attackers reading (trust eroding — incidents scheduling). Own cheaply (envelopes — codes); hope never (prose — leaks).

**Mentor note** — drill "type, mean, decline" (juniors answering one safety question per shape design ownership-stated responses on first hearing; 200-error answers interrogated ("which status?" — owning demanding per failure). Shape one answer once (codes typing — statuses guiding tangible (proseing ending — owning proving permanently). State codes; refuse leaks — safety discipline in three habits, reviewed per mock.
