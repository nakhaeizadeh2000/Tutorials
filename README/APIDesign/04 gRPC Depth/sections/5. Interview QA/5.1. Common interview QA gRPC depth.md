## 1. Contracts live under pressure (protos, shapes, versions — diagnosed with fixes, priced)

**Definition** — contract answers: protos defining, shapes choosing, versions numbering — under pressure (diagnosed with fixes — causes naming (understanding proving — reciting declining); priced with trade-offs — evolution funding (judgment owning — dogma refusing (pricing earning — honesty proving).

**What problem it solves** — the reciting trio: *protos listing* ("IDL contracts" naming — services missing (vocabulary showing — ownership absenting (reciting funding — designing declining); *shapes gesturing* ("four kinds" claiming — needs unmatching (words owning — fit missing (gesturing proving — choosing declining); *versions handwaving* ("compatible" asserting — numbers reusing (labels owning — collisions hiding (handwaving charging — reserving declining). Diagnosed answers converting reciting to stating (causes naming — fixes stating (services proving — numbers retiring); interviewers hiring staters, not listers (diagnosing proving → hirable; reciting → passed).

**Modern guidance** — answer shape per contract question (diagnose → fix → price):

```typescript

// Diagnose: JSON-by-convention (shapes hoping — numbers missing — clients discovering).
// Fix: protos defining (services stating — messages typing — fields numbering).

// State services; number fields — pressure stated, not hoped.)
```

```typescript
// BAD: contracts reciting — vocabulary stating, services missing (real weak shape).
// "Protobuf is efficient." (needs missing — costs hiding — designing declining).
// "Streams are cool." (flows unfitting — states owning — choosing declining).
// Diagnose causes; state fixes; price evolution.)
```

**Common confusion** — *"contract answers need binary benchmarks (numbers impressing)."* Benchmarks timing payloads (bytes measuring — frames counting (speeds proving — fits missing (timing serving — matching declining (benchmarking funding — choosing declining); answers proving contracts (causes naming — fixes stating (costs pricing — trade-offs owning (proving funding — reciting declining). "Benchmarks" describing speed (bytes timing — frames counting); answers describing ownership (services stating — numbers retiring). **Performance note** — answer economics: diagnosing costing one cause per question (understanding proving — reciting declining (hirable funding — chanting ending); recited equivalents costing offers (words owning — services missing (designing declining — hiring passing). Diagnose cheaply (causes — fixes); recite never (vocabulary — passes).

**Mentor note** — drill "diagnose, fix, price" (juniors answering one contract question per shape design hirable responses on first hearing; vocabulary-only answers interrogated ("which proto?" — diagnosing demanding per answer). Shape one answer once (causes naming — fixes stating tangible (reciting ending — designing proving permanently).
