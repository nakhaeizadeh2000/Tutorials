## 1. Services implementing (methods owning — controllers deciding — DI wiring)

**Definition** — NestJS gRPC service: controllers owning RPC methods with DI wiring (methods owning — RPCs deciding (handlers registering — contracts honoring (owning proving — guessing ending); controllers deciding — values computing (services delegating — logic homing (deciding funding — closing declining); DI wiring — providers injecting (deps resolving — tests substituting (wiring proving — manualing declining).

**What problem it solves** — the unhosted trio: *handlers guessing* (methods unmapped — contracts unowned (implementations assuming — behaviors bluffing (guessing billing — owning declining); *DI missing* (services newing — deps hiding (testing aching — substitution missing (missing charging — wiring declining); *protos unserved* (IDLs stating — servers absenting (contracts hoping — clients hanging (unserved costing — trust eroding). Implemented services converting guessing to owning (methods binding — DI injecting (protos serving — calls answering); reviewers mapping RPCs per controller (implementing proving → verifiable; guessing → returned).

**Modern guidance** — the implementing lines per service (review-enforced): *methods owning* (RPCs deciding — handlers registering (contracts honoring — guessing ending (owning proving — assuming refusing (service earning — bluffing declining); *controllers deciding* (values computing — services delegating (logic homing — closing declining (deciding funding — embedding refusing (thin owning — fat declining); *DI wiring* (providers injecting — deps resolving (tests substituting — manualing declining (wiring proving — newing refusing (inversion owning — swapping earning).

```typescript
// GOOD: services implementing — NestJS microservice answering unary over the wire (compiled + run live).
import 'reflect-metadata';
import { Controller, Injectable, Module } from '@nestjs/common';
import { GrpcMethod, MicroserviceOptions, Transport } from '@nestjs/microservices'; // vehicle owning — controllers deciding, DI wiring
import { NestFactory } from '@nestjs/core';
import * as grpc from '@grpc/grpc-js';
import * as protoLoader from '@grpc/proto-loader';

const PROTO = '/tmp/opencode/api-grpc/shop.proto';
const URL = '127.0.0.1:50051';

@Injectable()
class Catalog { // services delegating — logic homing, bypassing declining
  label(id: string): string { return `item:${id}`; }
}

@Controller()
class ItemsController { // methods owning — RPCs deciding, guessing ending
  constructor(private readonly catalog: Catalog) {}
  @GrpcMethod('Items', 'Get')
  get(data: { id: string }): { id: string; label: string } {
    return { id: data.id, label: this.catalog.label(data.id) };
  }
  @GrpcMethod('Items', 'List')
  list(): { id: string; label: string }[] {
    return [];
  }
}

@Module({ controllers: [ItemsController], providers: [Catalog] })
class AppModule {}

async function run(): Promise<void> {
  const app = await NestFactory.createMicroservice<MicroserviceOptions>(AppModule, {
    transport: Transport.GRPC,
    options: { package: 'shop', protoPath: PROTO, url: URL },
  });
  await app.listen(); // servers binding — protos serving, clients hanging-ending
  const def = protoLoader.loadSync(PROTO, { keepCase: true, longs: String, enums: String, defaults: true, oneofs: true });
  const pkg = grpc.loadPackageDefinition(def) as any;
  const client = new pkg.shop.Items(URL, grpc.credentials.createInsecure());
  const res: { id: string; label: string } = await new Promise((resolve, reject) => {
    client.Get({ id: 'a1' }, { deadline: new Date(Date.now() + 5000) }, (err: any, r: { id: string; label: string }) => (err ? reject(err) : resolve(r)));
  });
  console.log(res.id === 'a1' && res.label === 'item:a1' ? 'services implement' : 'handlers guess');
  client.close();
  await app.close();
}
run();
```

**What problem it solves** — the hand-client trio: *stubs anying* (calls stringing — payloads untyped (types missing — drifts scheduling (anying billing — consistency failing); *channels dialing* (connections opening — handshakes repeating (latency adding — resources wasting (dialing charging — sharing declining); *deadlines missing* (budgets unstated — waits hanging (limits absenting — liveness bluffing (missing costing — reliability declining). **Modern guidance** — the calling lines per client (review-enforced): *stubs typing* (requests compiling — responses decoding (errors mapping — any declining (typing funding — hoping ending (contracts earning — drift preventing); *channels managing* (connections sharing — clients reusing (handshakes amortizing — dialing declining (managing owning — opening refusing (sharing funding — wasting declining); *deadlines passing* (budgets stating — waits limiting (hangs declining — hoping ending (passing proving — missing refusing (numbers owning — faith declining).

```typescript
// GOOD: clients calling — one shared channel serving two calls with deadlines (compiled + run live).
import * as grpc from '@grpc/grpc-js'; // stubs typing — requests compiling, any declining
import * as protoLoader from '@grpc/proto-loader';
const def = protoLoader.loadSync('/tmp/opencode/api-grpc/shop.proto', { keepCase: true, longs: String, enums: String, defaults: true, oneofs: true });
const pkg = grpc.loadPackageDefinition(def) as any;

async function run(): Promise<void> {
  const server = new grpc.Server();
  server.addService(pkg.shop.Items.service, {
    Get: (call: any, cb: any) => cb(null, { id: call.request.id, label: `item:${call.request.id}` }),
    List: (call: any) => { call.end(); },
  });
  const port: number = await new Promise((resolve, reject) => {
    server.bindAsync('127.0.0.1:0', grpc.ServerCredentials.createInsecure(), (err, p) => (err ? reject(err) : resolve(p)));
  });
  const client = new pkg.shop.Items(`127.0.0.1:${port}`, grpc.credentials.createInsecure()); // channels managing — connections sharing, dialing declining
  const one = (id: string): Promise<string> =>
    new Promise((resolve, reject) => {
      client.Get({ id }, { deadline: new Date(Date.now() + 2000) }, (err: any, r: { label: string }) => (err ? reject(err) : resolve(r.label))); // deadlines passing — budgets stating, hoping ending
    });
  const a = await one('x');
  const b = await one('y');
  console.log(a === 'item:x' && b === 'item:y' ? 'clients call' : 'stubs any');
  client.close();
  server.forceShutdown();
}
run();
```

## 3. Wire proving (servers binding — calls roundtripping — contracts asserting)

**Definition** — wire proof: servers binding, calls roundtripping, contracts asserting (servers binding — protos serving (ports opening — clients connecting (binding proving — hoping ending); calls roundtripping — requests answering (responses returning (streams flowing — hangs declining (roundtripping funding — mocking declining); contracts asserting — shapes validating (methods proving — drifts failing (asserting owning — assuming ending).

**What problem it solves** — the mocked-wire trio: *wires mocking* (transports faking — serializers skipping (bytes unmoving — framing unproven (mocking billing — confidence bluffing); *roundtrips hoping* (calls assuming — responses trusting (streams untested — hangs undiscovered (hoping charging — liveness bluffing); *contracts drifting* (shapes diverging — methods skewing (versions mismatching — compatibilities breaking (drifting costing — coordination failing). **Modern guidance** — the proving lines per service (review-enforced): *servers binding* (protos serving — ports opening (clients connecting — hoping ending (binding proving — mocking refusing (reality owning — fakes declining); *calls roundtripping* (requests answering — responses returning (streams flowing — hangs declining (roundtripping funding — hoping ending (trips owning — drops declining); *contracts asserting* (shapes validating — methods proving (drifts failing — assuming ending (asserting owning — bluffing refusing (proof funding — incidents preventing).

```typescript
// GOOD: wire proving — NestJS streaming List collected over the wire (compiled + run live).
import 'reflect-metadata';
import { Controller, Injectable, Module } from '@nestjs/common';
import { GrpcMethod, MicroserviceOptions, Transport } from '@nestjs/microservices'; // vehicle owning — methods binding, DI wiring
import { NestFactory } from '@nestjs/core';
import { Observable, of } from 'rxjs';
import * as grpc from '@grpc/grpc-js';
import * as protoLoader from '@grpc/proto-loader';

const PROTO = '/tmp/opencode/api-grpc/shop.proto';
const URL = '127.0.0.1:50052';

@Injectable()
class Catalog {
  rows(): Array<{ id: string; label: string }> {
    return [{ id: 'a', label: 'A' }, { id: 'b', label: 'B' }];
  }
}

@Controller()
class ItemsController { // servers binding — protos serving, hoping ending
  constructor(private readonly catalog: Catalog) {}
  @GrpcMethod('Items', 'Get')
  get(data: { id: string }): { id: string; label: string } {
    return { id: data.id, label: `item:${data.id}` };
  }
  @GrpcMethod('Items', 'List')
  list(): Observable<{ id: string; label: string }> { // streams flowing — emissions serving, hangs declining
    return of(...this.catalog.rows());
  }
}

@Module({ controllers: [ItemsController], providers: [Catalog] })
class AppModule {}

async function run(): Promise<void> {
  const app = await NestFactory.createMicroservice<MicroserviceOptions>(AppModule, {
    transport: Transport.GRPC,
    options: { package: 'shop', protoPath: PROTO, url: URL },
  });
  await app.listen();
  const def = protoLoader.loadSync(PROTO, { keepCase: true, longs: String, enums: String, defaults: true, oneofs: true });
  const pkg = grpc.loadPackageDefinition(def) as any;
  const client = new pkg.shop.Items(URL, grpc.credentials.createInsecure());
  const one: { label: string } = await new Promise((resolve, reject) => {
    client.Get({ id: 'a1' }, { deadline: new Date(Date.now() + 5000) }, (err: any, r: { label: string }) => (err ? reject(err) : resolve(r)));
  });
  const streamed: string[] = await new Promise((resolve, reject) => { // calls roundtripping — requests answering, hangs declining
    const out: string[] = [];
    const call = client.List({ limit: 10 });
    call.on('data', (e: { id: string }) => out.push(e.id));
    call.on('end', () => resolve(out));
    call.on('error', (e: any) => reject(e));
  });
  console.log(one.label === 'item:a1' && streamed.join(',') === 'a,b' ? 'wire proves' : 'mocks mock');
  client.close();
  await app.close();
}
run();
```
