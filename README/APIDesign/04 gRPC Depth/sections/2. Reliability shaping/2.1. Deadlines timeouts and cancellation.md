# 2.1. Deadlines timeouts and cancellation

## 1. Deadlines bounding (budgets stating — chains propagating — waits limiting)

**Definition** — call deadlines: absolute time budgets stated per call and propagated downstream (budgets stating — times bounding (waits limiting — hangs declining (stating proving — hoping ending); chains propagating — budgets inheriting (hops subtracting — contexts carrying (propagating funding — resetting declining); waits limiting — hangs capping (resources freeing — cascades preventing (limiting owning — lingering declining).

**What problem it solves** — the unbounded trio: *waits hanging* (calls lingering — threads holding (resources pinning — cascades scheduling (hanging billing — budgets missing); *chains resetting* (hops rebudgeting — parents ignoring (timeouts compounding — latencies multiplying (resetting charging — propagating declining); *budgets unstating* (deadlines missing — gives-up hoping (limits absenting — liveness bluffing (unstating costing — reliability declining). Bounded deadlines converting hanging to stating (budgets bounding — chains inheriting (waits capping — hangs declining); reviewers seeing deadlines per RPC (bounding proving → verifiable; hanging → returned).

**Modern guidance** — the bounding lines per call (review-enforced): *budgets stating* (times bounding — waits limiting (hangs declining — hoping ending (stating proving — missing refusing (numbers owning — faith declining); *chains propagating* (budgets inheriting — hops subtracting (contexts carrying — resetting declining (propagating funding — rebudgeting refusing (inheritance owning — compounding declining); *waits limiting* (hangs capping — resources freeing (cascades preventing — lingering declining (limiting owning — hanging refusing (caps funding — holds declining).

```typescript
// GOOD: deadlines bounding — server observing propagated remaining budget (compiled + run live).
import * as grpc from '@grpc/grpc-js'; // engine owning — bounding funding, mechanics borrowing
import * as protoLoader from '@grpc/proto-loader';
const def = protoLoader.loadSync('/tmp/opencode/api-grpc/shapes.proto', { keepCase: true, longs: String, enums: String, defaults: true, oneofs: true });
const pkg = grpc.loadPackageDefinition(def) as any;

async function run(): Promise<void> {
  const server = new grpc.Server();
  let seenMs = -1;
  server.addService(pkg.shapes.Pipe.service, {
    Once: (call: any, cb: any) => {
      const deadline = call.getDeadline(); // chains propagating — budgets inheriting, resetting declining
      const at = deadline instanceof Date ? deadline.getTime() : deadline; // grpc-js serving numbers — Dates declining, assumes refusing
      seenMs = typeof at === 'number' ? at - Date.now() : -1;
      cb(null, { ok: true });
    },
    Watch: (call: any) => { call.end(); },
    Collect: (call: any, cb: any) => { call.on('data', () => undefined); call.on('end', () => cb(null, { n: 0 })); },
    Chat: (call: any) => { call.on('data', () => undefined); call.on('end', () => call.end()); },
  });
  const port: number = await new Promise((resolve, reject) => {
    server.bindAsync('127.0.0.1:0', grpc.ServerCredentials.createInsecure(), (err, p) => (err ? reject(err) : resolve(p)));
  });
  const client = new pkg.shapes.Pipe(`127.0.0.1:${port}`, grpc.credentials.createInsecure());
  await new Promise<void>((resolve, reject) => {
    client.Once({ id: 'j1' }, { deadline: new Date(Date.now() + 5000) }, (err: any) => (err ? reject(err) : resolve())); // budgets stating — times bounding, hoping ending
  });
  console.log(seenMs > 0 && seenMs <= 5000 ? 'deadlines bound' : 'waits hang');
  client.close();
  server.forceShutdown();
}
run();
```

**Common confusion** — *"deadlines equal timeouts (terms equating)."* Deadlines bounding absolutes (times stating — chains inheriting (waits capping — hangs declining (bounding proving — resetting declining); timeouts firing durations (gives-up owning — resources freeing (failures mapping — hangs ending (firing funding — lingering declining). "Equaling" describing confusion (terms merging — behaviors blurring); deadlines describing budgets (times bounding — chains propagating). State deadlines (times bounding — chains inheriting); fire timeouts (durations owning — resources freeing).

**Performance note** — bounding economics: stating costing options (times bounding — chains inheriting (hangs declining — cascades preventing); hung equivalents costing holds (calls lingering — threads pinning (resources wasting — cascades scheduling). State cheaply (deadlines — options); hang never (waits — holds).

**Mentor note** — teach "deadline per call, propagated per hop" (juniors bounding one budget per RPC design hang-proof chains on first hearing; deadline-less calls interrogated ("which budget?" — bounding demanding per call). Bound one wait once (times stating — chains propagating tangible (hanging ending — bounding proving permanently). State times; inherit downstream — bounding discipline in three habits, reviewed per RPC.

## 2. Timeouts firing (clients giving-up — servers observing — resources freeing)

**Definition** — timeout firing: clients abandoning at budgets, servers observing, resources freeing (clients giving-up — waits ending (hangs declining — holds releasing (firing proving — lingering ending); servers observing — deadlines reading (cancels noticing — work abandoning (observing funding — zombie declining); resources freeing — threads releasing (pools returning — capacity restoring (freeing owning — leaking declining).

**What problem it solves** — the infinite trio: *hangs lingering* (calls pending — threads holding (resources pinning — capacity draining (lingering billing — budgets missing); *failures unmapping* (timeouts erroring-generically — callers guessing (kinds blurring — retries misjudging (unmapping charging — handling declining); *resources leaking* (abandoned working — threads orphaning (pools shrinking — capacity fading (leaking costing — throughput dying). Fired timeouts converting lingering to giving-up (clients abandoning — servers noticing (resources releasing — hangs ending); reviewers mapping timeout codes per call (firing proving → verifiable; lingering → returned).

**Modern guidance** — the firing lines per call (review-enforced): *clients giving-up* (waits ending — hangs declining (holds releasing — lingering ending (firing proving — pending refusing (abandonment owning — stuck declining); *servers observing* (deadlines reading — cancels noticing (work abandoning — zombie declining (observing funding — blindness ending (watchfulness owning — orphan declining); *resources freeing* (threads releasing — pools returning (capacity restoring — leaking declining (freeing owning — holding refusing (restoration funding — drain declining).

```typescript
// GOOD: timeouts firing — slow calls mapping DEADLINE_EXCEEDED, fast paths serving (compiled + run live).
import * as grpc from '@grpc/grpc-js'; // engine owning — firing funding, mechanics borrowing
import * as protoLoader from '@grpc/proto-loader';
const def = protoLoader.loadSync('/tmp/opencode/api-grpc/shapes.proto', { keepCase: true, longs: String, enums: String, defaults: true, oneofs: true });
const pkg = grpc.loadPackageDefinition(def) as any;

async function run(): Promise<void> {
  const server = new grpc.Server();
  server.addService(pkg.shapes.Pipe.service, {
    Once: (_call: any, cb: any) => { setTimeout(() => cb(null, { ok: true }), 300); }, // servers observing — deadlines reading, zombie declining
    Watch: (call: any) => { call.end(); },
    Collect: (call: any, cb: any) => { call.on('data', () => undefined); call.on('end', () => cb(null, { n: 0 })); },
    Chat: (call: any) => { call.on('data', () => undefined); call.on('end', () => call.end()); },
  });
  const port: number = await new Promise((resolve, reject) => {
    server.bindAsync('127.0.0.1:0', grpc.ServerCredentials.createInsecure(), (err, p) => (err ? reject(err) : resolve(p)));
  });
  const client = new pkg.shapes.Pipe(`127.0.0.1:${port}`, grpc.credentials.createInsecure());
  const slow: number = await new Promise((resolve) => {
    client.Once({ id: 'j1' }, { deadline: new Date(Date.now() + 50) }, (err: any) => resolve(err === null || err === undefined ? -1 : err.code)); // clients giving-up — waits ending, lingering ending
  });
  const fast: boolean = await new Promise((resolve) => {
    client.Once({ id: 'j1' }, { deadline: new Date(Date.now() + 2000) }, (err: any, r: { ok: boolean }) => resolve((err === null || err === undefined) && r.ok));
  });
  console.log(slow === grpc.status.DEADLINE_EXCEEDED && fast ? 'timeouts fire' : 'hangs linger');
  client.close();
  server.forceShutdown();
}
run();
```

**Common confusion** — *"timeouts fix slowness (budgets curing)."* Timeouts bounding harm (waits ending — resources freeing (hangs declining — cascades preventing (bounding proving — curing declining); slowness needing causes (queries optimizing — capacities funding (waits shortening — users trusting (needing serving — masking declining). "Fixing" describing cure (slowness ending — causes addressing); timeouts describing bounds (waits capping — resources freeing). Bound harm (waits ending — resources freeing); fix causes (queries optimizing — capacities funding).

**Performance note** — firing economics: giving-up costing deadlines (waits ending — resources freeing (hangs declining — cascades preventing); lingered equivalents costing holds (calls pending — threads holding (capacity draining — throughput dying). Fire cheaply (timeouts — options); linger never (hangs — holds).

**Mentor note** — teach "timeout with mapped code per call" (juniors firing one budget per RPC design linger-proof clients on first hearing; unmapped timeouts interrogated ("which code?" — firing demanding per call). Fire one wait once (clients giving-up — servers observing tangible (lingering ending — firing proving permanently). Abandon waits; free resources — firing discipline in three habits, reviewed per call.

## 3. Cancellations honoring (peers signaling — work abandoning — leaks declining)

**Definition** — cancellation honor: abandoned work stopping on peer signals (peers signaling — clients canceling (servers noticing — contexts ending (signaling proving — completing declining); work abandoning — loops exiting (timers clearing — writes rolling-back (abandoning funding — zombie declining); leaks declining — loops ending (handles closing — memory freeing (declining proving — orphaning ending).

**What problem it solves** — the zombie trio: *cancels ignoring* (peers abandoning — servers continuing (work wasting — results discarding (ignoring billing — signaling declining); *loops running* (timers ticking — writes committing (abandoned working — sides effecting (running charging — stopping declining); *handles leaking* (streams opening — closes missing (resources pinning — memory growing (leaking costing — throughput dying). Honored cancels converting ignoring to abandoning (peers signaling — work stopping (leaks declining — zombies ending); reviewers watching cancel flags per stream (honoring proving → verifiable; ignoring → returned).

**Modern guidance** — the honoring lines per stream (review-enforced): *peers signaling* (clients canceling — servers noticing (contexts ending — completing declining (signaling proving — ignoring refusing (communication owning — silence declining); *work abandoning* (loops exiting — timers clearing (writes rolling-back — zombie declining (abandoning funding — continuing refusing (stops owning — waste ending); *leaks declining* (goroutines ending — handles closing (memory freeing — orphaning declining (declining proving — pinning refusing (cleanup funding — growth declining).

```typescript
// GOOD: cancellations honoring — client abandoning, server observing, work stopping (compiled + run live).
import * as grpc from '@grpc/grpc-js'; // engine owning — honoring funding, mechanics borrowing
import * as protoLoader from '@grpc/proto-loader';
const def = protoLoader.loadSync('/tmp/opencode/api-grpc/shapes.proto', { keepCase: true, longs: String, enums: String, defaults: true, oneofs: true });
const pkg = grpc.loadPackageDefinition(def) as any;

async function run(): Promise<void> {
  const server = new grpc.Server();
  let observed = false;
  server.addService(pkg.shapes.Pipe.service, {
    Once: (_call: any, cb: any) => cb(null, { ok: true }),
    Watch: (call: any) => { // servers observing — deadlines reading, zombie declining
      let seq = 0;
      const timer = setInterval(() => {
        if (call.cancelled) { // peers signaling — clients canceling, completing declining
          observed = true;
          clearInterval(timer);
          return;
        }
        seq += 1;
        call.write({ seq });
      }, 10);
    },
    Collect: (call: any, cb: any) => { call.on('data', () => undefined); call.on('end', () => cb(null, { n: 0 })); },
    Chat: (call: any) => { call.on('data', () => undefined); call.on('end', () => call.end()); },
  });
  const port: number = await new Promise((resolve, reject) => {
    server.bindAsync('127.0.0.1:0', grpc.ServerCredentials.createInsecure(), (err, p) => (err ? reject(err) : resolve(p)));
  });
  const client = new pkg.shapes.Pipe(`127.0.0.1:${port}`, grpc.credentials.createInsecure());
  let got = 0;
  await new Promise<void>((resolve) => {
    const call = client.Watch({ topic: 't' });
    call.on('data', () => {
      got += 1;
      if (got === 1) call.cancel(); // work abandoning — loops exiting, zombie declining
    });
    call.on('error', () => resolve());
    setTimeout(() => resolve(), 2000); // leaks declining — handles closing, orphaning ending
  });
  await new Promise((r) => setTimeout(r, 100));
  console.log(got >= 1 && observed ? 'cancels honor' : 'zombies work');
  client.close();
  server.forceShutdown();
}
run();
```


**Common confusion** — *"cancellation is best-effort (signals hoping)."* Best-effort attempting stops (tries owning — guarantees missing (hoping funding — certainty declining (attempting proving — ensuring declining); honoring observing flags (peers signaling — work abandoning (loops exiting — timers clearing (honoring proving — ignoring declining). "Best-effort" describing hope (guarantees missing — certainty declining); honoring describing observation (flags watching — work stopping). Watch flags (peers signaling — loops exiting); hope never (guarantees missing — certainty declining).

**Performance note** — honoring economics: abandoning costing checks (flags watching — loops exiting (waste ending — zombies declining); ignored equivalents costing zombies (peers abandoning — servers continuing (work wasting — resources pinning). Abandon cheaply (checks — flags); ignore never (cancels — loops).

**Mentor note** — teach "check cancelled per loop" (juniors honoring one flag per stream design zombie-proof servers on first hearing; unchecked loops interrogated ("cancel observed?" — honoring demanding per stream). Honor one signal once (peers signaling — work abandoning tangible (ignoring ending — honoring proving permanently). Signal peers; stop work — honoring discipline in three habits, reviewed per stream.
