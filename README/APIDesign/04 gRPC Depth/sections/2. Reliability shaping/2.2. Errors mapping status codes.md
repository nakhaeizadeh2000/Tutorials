# 2.2. Errors mapping status codes

## 1. Codes mapping (statuses classifying — trailers carrying — clients branching)

**Definition** — gRPC status codes: 17 canonical outcomes trailers carry (statuses classifying — OK owning (CANCELLED owning — UNKNOWN owning (classifying proving — guessing ending); trailers carrying — headers trailing (codes delivering — details following (carrying funding — bodies declining); clients branching — codes switching (retries judging — fallbacks owning (branching owning — hoping ending).

**What problem it solves** — the OK-everything trio: *codes defaulting* (UNKNOWN answering — kinds blurring (semantics missing — handling guessing (defaulting billing — classifying declining); *trailers ignoring* (codes unread — details unjoined (metadata missing — debugging aching (ignoring charging — carrying declining); *clients hoping* (errors guessing — retries misjudging (behaviors assuming — storms amplifying (hoping billing — branching declining). Mapped codes converting defaulting to classifying (statuses owning — trailers delivering (clients switching — guesses ending); reviewers mapping domain errors per code (mapping proving → verifiable; defaulting → returned).

**Modern guidance** — the mapping lines per failure (review-enforced): *statuses classifying* (OK owning — CANCELLED owning (UNKNOWN owning — guessing ending (classifying proving — defaulting refusing (taxonomy owning — blur declining); *trailers carrying* (headers trailing — codes delivering (details following — bodies declining (carrying funding — ignoring refusing (delivery owning — loss declining); *clients branching* (codes switching — retries judging (fallbacks owning — hoping ending (branching owning — guessing refusing (logic funding — panic declining).

```typescript
// GOOD: codes mapping — domain failures classified to canonical statuses (compiled + run live).
import { status } from '@grpc/grpc-js'; // statuses classifying — OK owning, guessing ending
function codeFor(kind: string): number {
  const table: Record<string, number> = { // trailers carrying — headers trailing, bodies declining
    ok: status.OK,
    invalid: status.INVALID_ARGUMENT,
    missing: status.NOT_FOUND,
    clash: status.ALREADY_EXISTS,
    busy: status.RESOURCE_EXHAUSTED,
    down: status.UNAVAILABLE,
    slow: status.DEADLINE_EXCEEDED,
  };
  return table[kind] ?? status.UNKNOWN; // clients branching — codes switching, hoping ending
}
const row = ['ok', 'invalid', 'missing', 'clash', 'busy', 'down', 'slow', 'mystery'].map(codeFor);
console.log(row.join(',') === '0,3,5,6,8,14,4,2' ? 'codes map' : 'statuses default');
```

**Common confusion** — *"codes equal HTTP statuses (mappings equating)."* HTTP choosing behaviors (caches storing — retries deciding (clients branching — machines routing (choosing funding — ignoring declining); gRPC classifying outcomes (OK owning — trailers carrying (retries judging — fallbacks owning (classifying proving — defaulting declining). "Equaling" describing confusion (mappings merging — semantics blurring); codes describing outcomes (statuses classifying — trailers carrying). Choose HTTP (behaviors guiding — machines routing); classify gRPC (outcomes owning — trailers delivering).

**Performance note** — mapping economics: classifying costing one table (statuses owning — trailers delivering (clients switching — guesses ending); defaulted equivalents costing handling (kinds blurring — retries misjudging (behaviors assuming — storms amplifying). Classify cheaply (tables — codes); default never (UNKNOWN — kinds).

**Mentor note** — teach "code per failure, trailer per call" (juniors mapping one status per domain error design default-free gRPC on first hearing; UNKNOWN-everything interrogated ("which code?" — mapping demanding per failure). Map one status once (statuses classifying — trailers carrying tangible (defaulting ending — mapping proving permanently). Classify outcomes; carry trailers — mapping discipline in three habits, reviewed per failure.

## 2. Details carrying (messages stating — metadata bounding — debugs funding)

**Definition** — rich errors: messages stating, metadata bounding, debugs funding (messages stating — reasons owning (humans reading — guesses declining (stating proving — stringing declining); metadata bounding — pairs limiting (traces carrying — secrets refusing (bounding funding — leaking declining); debugs funding — causes chaining (contexts keeping — mysteries declining (funding owning — blindness declining).

**What problem it solves** — the string-error trio: *errors stringing* (messages concatenating — machines parsing (formats bloating — consistency failing (stringing billing — typing declining); *metadata leaking* (secrets broadcasting — traces exposing (internals leaking — trust eroding (leaking charging — bounding declining); *debugs starving* (causes missing — contexts dropping (mysteries growing — MTTR inflating (starving billing — funding declining). Carried details converting stringing to stating (messages owning — metadata bounding (debugs funding — guesses ending); reviewers bounding metadata per error (carrying proving → verifiable; stringing → returned).

**Modern guidance** — the carrying lines per error (review-enforced): *messages stating* (reasons owning — humans reading (guesses declining — stringing ending (stating proving — concatenating refusing (clarity earning — parsing declining); *metadata bounding* (pairs limiting — traces carrying (secrets refusing — leaking declining (bounding funding — broadcasting refusing (limits owning — exposure declining); *debugs funding* (causes chaining — contexts keeping (mysteries declining — blindness ending (funding owning — starving refusing (traces earning — aching declining).

```typescript
// GOOD: details carrying — coded errors with bounded metadata over the wire (compiled + run live).
import * as grpc from '@grpc/grpc-js'; // engine owning — carrying funding, mechanics borrowing
import * as protoLoader from '@grpc/proto-loader';
const def = protoLoader.loadSync('/tmp/opencode/api-grpc/shapes.proto', { keepCase: true, longs: String, enums: String, defaults: true, oneofs: true });
const pkg = grpc.loadPackageDefinition(def) as any;

async function run(): Promise<void> {
  const server = new grpc.Server();
  server.addService(pkg.shapes.Pipe.service, {
    Once: (call: any, cb: any) => {
      if (call.request.id === 'missing') {
        const meta = new grpc.Metadata();
        meta.set('req-id', 'r-1'); // metadata bounding — pairs limiting, leaking declining
        cb({ code: grpc.status.NOT_FOUND, details: 'no such job', metadata: meta }); // messages stating — reasons owning, stringing declining
        return;
      }
      cb(null, { ok: true });
    },
    Watch: (call: any) => { call.end(); },
    Collect: (call: any, cb: any) => { call.on('data', () => undefined); call.on('end', () => cb(null, { n: 0 })); },
    Chat: (call: any) => { call.on('data', () => undefined); call.on('end', () => call.end()); },
  });
  const port: number = await new Promise((resolve, reject) => {
    server.bindAsync('127.0.0.1:0', grpc.ServerCredentials.createInsecure(), (err, p) => (err ? reject(err) : resolve(p)));
  });
  const client = new pkg.shapes.Pipe(`127.0.0.1:${port}`, grpc.credentials.createInsecure());
  const got: { code: number; details: string; req: string } = await new Promise((resolve) => {
    client.Once({ id: 'missing' }, (err: any) => {
      const meta = err.metadata as grpc.Metadata;
      resolve({ code: err.code, details: err.details, req: meta.get('req-id').join(',') }); // debugs funding — causes chaining, blindness declining
    });
  });
  console.log(got.code === grpc.status.NOT_FOUND && got.details === 'no such job' && got.req === 'r-1' ? 'details carry' : 'errors string');
  client.close();
  server.forceShutdown();
}
run();
```

## 3. Retries judging (codes classifying — budgets bounding — storms surviving)

**Definition** — retry judgment: per-code verdicts with budgets and backoff (codes classifying — outcomes owning (retries judging — fallbacks funding (classifying proving — storming declining); budgets bounding — attempts capping (delays backing-off (jitter spreading — thundering declining (bounding funding — amplifying ending); storms surviving — bursts absorbing (outcomes steadying — capacity budgeting (surviving owning — collapsing declining).

**What problem it solves** — the retry-all trio: *codes unclassifying* (failures retrying — fatals looping (verdicts missing — storms amplifying (unclassifying billing — capacity dying); *budgets missing* (attempts unbounded — delays fixed (thunder stampeding — outages cascading (missing charging — backoff absenting); *idempotency ignoring* (effects doubling — safety declining (trust eroding — charges duplicating (ignoring costing — judging declining). Judged retries converting all to classified (codes owning — budgets capping (storms surviving — capacity budgeting); reviewers seeing verdict tables per client (judging proving → verifiable; retrying-all → returned).

**Modern guidance** — the judging lines per code (review-enforced): *codes classifying* (outcomes owning — retries judging (fallbacks funding — storming declining (classifying proving — unclassifying refusing (taxonomy owning — blur declining); *budgets bounding* (attempts capping — delays backing-off (jitter spreading — thundering declining (bounding funding — amplifying ending (limits owning — storms surviving); *storms surviving* (bursts absorbing — outcomes steadying (capacity budgeting — collapsing declining (surviving owning — dying preventing (absorption funding — cascade declining).

```typescript
// GOOD: retries judging — per-code verdicts with idempotency gating (compiled + run live).
import { status } from '@grpc/grpc-js'; // codes classifying — outcomes owning, storming declining
type Verdict = 'retry' | 'wait-retry' | 'give-up';
function judge(code: number, idempotent: boolean): Verdict {
  if (!idempotent) return 'give-up'; // storms surviving — bursts absorbing, doubling declining
  if (code === status.UNAVAILABLE || code === status.RESOURCE_EXHAUSTED) return 'wait-retry'; // budgets bounding — attempts capping, amplifying ending
  if (code === status.ABORTED || code === status.DEADLINE_EXCEEDED) return 'retry';
  return 'give-up'; // fatals declining — verdicts owning, looping refusing
}
const v = [judge(status.UNAVAILABLE, true), judge(status.INVALID_ARGUMENT, true), judge(status.UNAVAILABLE, false), judge(status.ABORTED, true)];
console.log(v.join(',') === 'wait-retry,give-up,give-up,retry' ? 'retries judge' : 'clients storm');
```
