**Modern guidance** — the batching lines per loader (review-enforced): *loads grouping* (keys collecting — ticks batching (waits sharing — scattering declining (grouping proving — tripping refusing (batches owning — singles declining); *rounds collapsing* (N trips folding — queries counting-once (latencies dividing — multiplying ending (collapsing funding — adding refusing (folds earning — sums declining); *queries counting-once* (stores hitting singly — meters asserting — hope declining (counting owning — bluffing refusing (proof funding — incidents preventing).
