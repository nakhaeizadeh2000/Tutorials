# 1.1. Resources naming nouns verbs mapping

## 1. Nouns resourcing (collections naming — members addressing — verbs declining)

**Definition** — resource nouns: plural collections addressed with member ids, verbs never in paths (collections naming — sets owning (items listing — members containing (naming proving — verbing declining); members addressing — ids locating (paths nesting-once — parents scoping (addressing funding — guessing declining); verbs declining — actions refusing (paths nouning — methods owning (declining proving — tunneling ending).

**What problem it solves** — the verb-URL trio: *actions tunneling* (paths verbing — methods flattening (RPC hiding — semantics losing (tunneling billing — caching breaking); *plurals mixing* (item/items varying — clients branching (shapes differing — contracts blurring (mixing charging — consistency failing); *nests deepening* (paths descending — parents chaining (depths growing — usability dying (deepening billing — addresses rotting). Noun resources converting tunneling to naming (collections owning — members locating (verbs refusing — methods owning); reviewers linting paths per resource (resourcing proving → verifiable; tunneling → returned).

**Modern guidance** — the resourcing lines per resource (review-enforced): *collections naming* (sets owning — items listing (members containing — verbing declining (naming proving — action refusing (plurals owning — singulars declining); *members addressing* (ids locating — paths nesting-once (parents scoping — guessing declining (addressing funding — deepening refusing (locators owning — chains bounding); *verbs declining* (actions refusing — paths nouning (methods owning — tunneling ending (declining proving — RPC hiding-ending (nouns ruling — verbs serving).

```typescript
// GOOD: nouns resourcing — path lint catching verbs, singulars, and deep nests (compiled + run live).
function lintPath(path: string): string[] { // collections naming — sets owning, verbing declining
  const issues: string[] = [];
  const segs = path.split('/').filter((s) => s.length > 0 && !s.startsWith('v'));
  const verbs = ['get', 'create', 'delete', 'update', 'fetch', 'do'];
  for (const s of segs) {
    const tokens = s.replace(/([a-z])([A-Z])/g, '$1 $2').toLowerCase().split(/[\s_-]+/); // camel splitting — getOrders yielding get, documents staying whole
    if (tokens.some((t) => verbs.includes(t))) issues.push(`verb:${s}`); // verbs declining — actions refusing, tunneling ending
  }
  if (segs.length > 4) issues.push('deep-nest'); // members addressing — paths nesting-once, guessing declining
  return issues;
}
const good = lintPath('/v1/orders/i1');
const bad = lintPath('/v1/getOrders/doRefund');
console.log(good.length === 0 && bad.join(',') === 'verb:getOrders,verb:doRefund' ? 'nouns resource' : 'verbs tunnel');
```

```typescript
// BAD: actions tunneling — paths verbing, nests deepening (real RPC shape).
// POST /v1/getOrders/doRefundNow // verbs tunneling — methods flattening, caching breaking.
// GET /v1/a/b/c/d/e // depths growing — usability dying, addresses rotting.
// } // Resource nouns: collections naming, members addressing, verbs declining.)
```

**Common confusion** — *"nouns mean no actions ever (resources absoluting)."* Nouns naming things (collections owning — members locating (resources serving — verbs declining (naming proving — tunneling ending); actions modeling jobs (async owning — statuses polling (processes serving — completion funding (modeling earning — tunneling declining). "Never" describing absolutism (actions refusing — processes missing (absoluting charging — reality declining); nouns describing addressing (things naming — members locating). Name things (collections owning — members locating); model jobs (processes serving — statuses polling).

**Performance note** — resourcing economics: naming costing plural discipline (sets owning — members locating (caching funding — guessing declining); tunneled equivalents costing cacheability (methods flattening — semantics losing (caching breaking — intermediaries blinding). Name cheaply (nouns — plurals); tunnel never (verbs — paths).

**Mentor note** — teach "nouns in paths, verbs in methods" (juniors nouning one resource per path design tunnel-free APIs on first hearing; verbed paths interrogated ("which noun?" — resourcing demanding per route). Resource one noun once (collections naming — members addressing tangible (tunneling ending — resourcing proving permanently). Name collections; address members — resourcing discipline in three habits, reviewed per route.

## 2. Verbs mapping (GET reading — POST creating — PUT replacing)

**Definition** — verb mapping: HTTP methods owning fixed semantics (GET reading — queries answering (safe owning — cacheable proving (reading funding — writing declining); POST creating — subordinates adding (unsafe owning — non-idempotent proving (creating serving — replacing declining); PUT replacing — wholes overwriting (idempotent owning — retries trusting (replacing funding — patching declining).

| Method | Safe | Idempotent | Owns |
|---|---|---|---|
| GET, HEAD, OPTIONS | yes | yes | reads, cacheable |
| PUT, DELETE | no | yes | replace, remove (retryable) |
| POST, PATCH | no | no | create, partial update (guarded) |

**What problem it solves** — the method-misuse trio: *POST everythinging* (creates reading — deletes hiding (semantics flattening — caches breaking (everythinging billing — safety declining); *GET bodying* (queries hiding — caches varying (bodies smuggling — intermediaries blinding (bodying charging — visibility declining); *PUT patching* (replaces merging — retries risking (semantics confusing — guarantees blurring (patching billing — idempotency hoping). Mapped verbs converting misusing to owning (methods fixing — semantics holding (safety proving — caches funding); reviewers checking method tables per route (mapping proving → verifiable; misusing → returned).

**Modern guidance** — the mapping lines per route (review-enforced): *GET reading* (queries answering — safe owning (cacheable proving — writing declining (reading funding — bodying refusing (safety owning — visibility earning); *POST creating* (subordinates adding — unsafe owning (non-idempotent proving — creating serving (guarding requiring — retrying judging); *PUT replacing* (wholes overwriting — idempotent owning (retries trusting — patching declining (replacing funding — merging refusing (wholes demanding — partials declining).

```typescript
// GOOD: verbs mapping — method semantics asserting safety and idempotency (compiled + run live).
interface Verb { // GET reading — queries answering, writing declining
  safe: boolean;
  idempotent: boolean;
}
const matrix: Record<string, Verb> = { // methods fixing — semantics holding, safety proving
  GET: { safe: true, idempotent: true },
  PUT: { safe: false, idempotent: true },
  DELETE: { safe: false, idempotent: true },
  POST: { safe: false, idempotent: false },
  PATCH: { safe: false, idempotent: false },
};
function retryable(method: string): boolean { // PUT replacing — wholes overwriting, retries trusting
  return matrix[method]?.idempotent === true;
}
function cacheable(method: string): boolean {
  return matrix[method]?.safe === true;
}
console.log(retryable('PUT') && !retryable('POST') && cacheable('GET') && !cacheable('DELETE') ? 'verbs map' : 'methods misuse');
```

```typescript
// BAD: verbs misusing — POST everythinging, GET bodying (real misuse shape).
// POST /v1/items/search { ... } // creates reading — semantics flattening, caches breaking.
// GET /v1/items { body: {...} } // bodies smuggling — intermediaries blinding, visibility declining.
// } // Map verbs: GET reading, POST creating, PUT replacing.)
```

**Common confusion** — *"PUT must update fully or nothing (wholes absoluting)."* PUT replacing representations (wholes overwriting — idempotent owning (retries trusting — merging refusing (replacing proving — patching declining); absolutism refusing partials (bodies rejecting — clients resending (bandwidth taxing — practicality declining (absoluting charging — usability failing). "Must" describing absolutism (partials refusing — practicality declining); PUT describing replacement (wholes overwriting — idempotency owning). Replace wholes (representations overwriting — retries trusting); patch partials (deltas merging — idempotency declining).

**Performance note** — mapping economics: fixing costing one table (methods owning — semantics holding (caches funding — retries trusting); misused equivalents costing cacheability (semantics flattening — intermediaries blinding (safety declining — visibility losing). Fix cheaply (tables — verbs); misuse never (methods — semantics).

**Mentor note** — teach "method chooses guarantees" (juniors mapping one verb per route design guarantee-owned APIs on first hearing; POST-everything interrogated ("safe? idempotent?" — mapping demanding per route). Map one verb once (semantics holding — guarantees owning tangible (misusing ending — mapping proving permanently). Read safely; replace idempotently — mapping discipline in three habits, reviewed per route.

## 3. Actions declining (RPC tunneling — verbs abusing — nouns keeping)

**Definition** — action decline: non-CRUD operations modeled as resources or jobs, never path verbs (RPC tunneling — actions hiding (methods flattening — semantics losing (tunneling billing — caching breaking); verbs abusing — paths verbing (nouns abandoning — methods flattening (abusing charging — resourcing declining); nouns keeping — things naming (collections owning — members locating (keeping proving — tunneling refusing).

**What problem it solves** — the action trio: *verbs tunneling* (doX posting — actions hiding (semantics losing — caches breaking (tunneling billing — resourcing declining); *jobs missing* (async needing — statuses unowned (processes hoping — polling guessing (missing charging — completion bluffing); *nouns abandoning* (things unnamed — resources missing (addressing failing — modeling declining (abandoning billing — tunneling inviting). Declined actions converting tunneling to modeling (verbs refusing — jobs owning (nouns keeping — semantics holding); reviewers modeling operations per action (declining proving → verifiable; tunneling → returned).

**Modern guidance** — the declining lines per action (review-enforced): *RPC tunneling declining* (actions refusing — paths nouning (methods owning — semantics holding (declining proving — hiding refusing (nouns ruling — verbs serving); *verbs abusing declining* (paths verbing-refusing — nouns abandoning-refusing (resourcing owning — tunneling ending (declining funding — abusing ending (discipline owning — sloppiness declining); *nouns keeping* (things naming — collections owning (members locating — tunneling refusing (keeping proving — abandoning declining (modeling earning — hiding ending).

```typescript
// GOOD: actions declining — RPC paths rewritten to resources and jobs (compiled + run live).
function toResource(rpc: string): string { // nouns keeping — things naming, tunneling refusing
  const table: Record<string, string> = {
    '/v1/refundOrder': 'POST /v1/refunds',
    '/v1/getOrderStatus': 'GET /v1/orders/{id}',
    '/v1/cancelAll': 'POST /v1/cancellation-jobs',
  };
  return table[rpc] ?? rpc; // verbs abusing declining — paths nouning, methods owning
}
const a = toResource('/v1/refundOrder');
const b = toResource('/v1/getOrderStatus');
const kept = toResource('/v1/orders');
console.log(a === 'POST /v1/refunds' && b === 'GET /v1/orders/{id}' && kept === '/v1/orders' ? 'actions decline' : 'RPC tunnels');
```

```typescript
// BAD: actions tunneling — doX posting, jobs missing (real tunnel shape).
// POST /v1/doRefundNow { ... } // actions hiding — semantics losing, caches breaking.
// // Async with no status (processes hoping — polling guessing). Model resources; own jobs; keep nouns.)
```

**Common confusion** — *"jobs overcomplicate actions (processes bureaucratizing)."* Jobs owning async (statuses polling — completions funding (processes serving — hope ending (owning proving — tunneling declining); bureaucracy padding ceremony (forms multiplying — value missing (swaps unnamed — comprehension taxing (padding charging — judgment absenting). "Bureaucracy" describing ceremony (value missing — comprehension taxing); jobs describing processes (statuses owning — completions funding). Own jobs (processes serving — statuses polling); pad never (forms multiplying — value missing).

**Performance note** — declining economics: modeling costing resources (nouns keeping — semantics holding (caches funding — tunneling declining); tunneled equivalents costing semantics (actions hiding — methods flattening (caching breaking — intermediaries blinding). Model cheaply (resources — nouns); tunnel never (verbs — paths).

**Mentor note** — teach "verb in path? model it" (juniors declining one RPC per resource design tunnel-free APIs on first hearing; doX routes interrogated ("which resource?" — declining demanding per verb). Decline one action once (verbs refusing — nouns keeping tangible (tunneling ending — modeling proving permanently). Refuse verbs; keep nouns — declining discipline in three habits, reviewed per route.
