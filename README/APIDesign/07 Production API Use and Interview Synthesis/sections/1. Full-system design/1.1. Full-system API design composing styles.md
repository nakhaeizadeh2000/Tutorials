# 1.1. Full-system API design composing styles

## 1. Journeys composing (styles cohosting — entries unifying — clients flowing)

**Definition** — journey composition: client tasks completed across cohosted styles behind unified entries (styles cohosting — REST answering (graphs resolving — contracts streaming (cohosting proving — siloing declining); entries unifying — gateways fronting (BFFs shaping — versions scoping (unifying funding — scattering declining); clients flowing — journeys completing (hops minimizing — experiences funding (flowing owning — bouncing ending).

**What problem it solves** — the style-silo trio: *journeys fragmenting* (tasks spanning — endpoints multiplying (hops adding — clients bouncing (fragmenting billing — composing declining); *entries scattering* (gateways spawning — ownership blurring (routes duplicating — maintenance doubling (scattering charging — unifying declining); *clients bouncing* (teams owning-separately — contracts forking (consistency failing — latencies growing (bouncing billing — flowing declining). Composed journeys converting fragmentation to flowing (styles cohosting — entries unifying (hops minimizing — tasks completing); reviewers tracing journeys per client task (composing proving → verifiable; fragmenting → returned).

**Modern guidance** — the composing lines per journey (review-enforced): *styles cohosting* ([05/3.1](<../../../05 Choosing and Unifying Styles/sections/3. Unifying vehicle/3.1. NestJS unifying slice gateway plus styles.md>) — REST answering (graphs resolving — contracts streaming (cohosting proving — siloing refusing (sharing owning — forking declining); *entries unifying* ([05/2.2](<../../../05 Choosing and Unifying Styles/sections/2. Unifying patterns/2.2. Gateways unifying routing auth limits.md>) — gateways fronting (BFFs shaping — versions scoping (unifying funding — scattering refusing (fronting earning — multiplying declining); *clients flowing* (journeys completing — hops minimizing (experiences funding — bouncing ending (flowing owning — fragmenting refusing (completion funding — task proving).

```typescript
// GOOD: journeys composing — client tasks traced across cohosted styles (compiled + run live).
interface Leg { // styles cohosting — REST answering, siloing declining
  task: string;
  style: string;
  entry: string;
}
function fragmented(journey: Leg[]): string[] {
  const gaps: string[] = []; // entries unifying — gateways fronting, scattering declining
  for (const l of journey) {
    if (l.entry.length === 0 || l.style.length === 0) gaps.push(l.task);
  }
  return gaps; // clients flowing — journeys completing, bouncing ending
}
const checkout: Leg[] = [
  { task: 'browse', style: 'REST', entry: '/v1/items' },
  { task: 'recommend', style: 'GraphQL', entry: '/v1/graph' },
  { task: 'pay', style: 'gRPC', entry: 'billing.Charge' },
];
const broken: Leg[] = [{ task: 'browse', style: '', entry: '/v1/items' }];
console.log(fragmented(checkout).length === 0 && fragmented(broken).join() === 'browse' ? 'journeys compose' : 'tasks fragment');
```

**Performance note** — composing economics: cohosting costing contracts (styles sharing — entries unifying (journeys completing — tasks flowing); fragmented equivalents costing hops (endpoints multiplying — latencies growing (bouncing — experiences degrading). // GOOD: contracts unifying — shared shapes with scoped versions (compiled + run live).
interface Shared { // shapes sharing — DTOs reusing, duplicating declining
  id: string;
  version: string;
}
function forked(shapes: Shared[]): string[] {
  const seen = new Map<string, string>(); // versions scoping — releases numbering, mixing declining
  const dups: string[] = [];
  for (const s of shapes) {
    const prior = seen.get(s.id);
    if (prior !== undefined && prior !== s.version) dups.push(s.id);
    seen.set(s.id, s.version);
  }
  return dups; // drift declining — skews surfacing, discovering ending
}
const clean: Shared[] = [
  { id: 'Item', version: 'v1' },
  { id: 'Order', version: 'v1' },
];
const split: Shared[] = [
  { id: 'Item', version: 'v1' },
  { id: 'Item', version: 'v2-untracked' },
];
console.log(forked(clean).length === 0 && forked(split).join() === 'Item' ? 'contracts unify' : 'shapes fork');
```

// // REST Item + GraphQL ItemType + proto Item (models forking — drifts scheduling).
// // Versions unnumbered (clients breaking — surprises scheduling). Share DTOs; scope versions; surface drift.)
```

Share cheaply (DTOs — versions); fork never (shapes — teams).

interface Entry { // guards enforcing — tokens checking, hoping declining
  route: string;
  guarded: boolean;
  capped: boolean;
  documented: boolean;
}
function naked(entries: Entry[]): string[] {
  const gaps: string[] = []; // limits bounding — budgets stating, crushing declining

    if (!e.guarded || !e.capped || !e.documented) gaps.push(e.route);
