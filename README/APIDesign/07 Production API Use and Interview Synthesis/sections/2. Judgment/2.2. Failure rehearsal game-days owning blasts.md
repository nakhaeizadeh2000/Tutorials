# 2.2. Failure rehearsal game-days owning blasts

## 1. Faults scripting (failures scheduling — surprises declining — drills owning)

**Definition** — scripted faults: scheduled failure scenarios with owned drills (failures scheduling — scenarios scripting (faults injecting — surprises declining (scheduling proving — debuting declining); surprises declining — unknowns converting (behaviors asserting — assumptions checking (declining owning — paging ending); drills owning — teams rehearsing (procedures proving — confidence earning (owning funding — improvising declining).

**What problem it solves** — the debut-in-production trio: *faults unscheduling* (failures debuting-live (scenarios unscripted — surprises ruling (unscheduling billing — recklessness proving); *surprises ruling* (behaviors unasserted — assumptions unchecked (unknowns paging — incidents discovering (ruling charging — calibration missing); *drills unowning* (teams improvising — procedures missing (recoveries fumbling — outages extending (unowning costing — readiness theatering). Scripted faults converting debuting to scheduling (scenarios scripting — unknowns asserting (teams rehearsing — surprises declining); reviewers finding fault scripts per dependency (scripting proving → verifiable; debuting → returned).

**Modern guidance** — the scripting lines per dependency (review-enforced): *failures scheduling* (scenarios scripting — faults injecting (surprises declining — debuting refusing (scheduling proving — live-testing declining (scripts owning — recklessness ending); *surprises declining* (unknowns converting — behaviors asserting (assumptions checking — paging ending (declining owning — ruling refusing (assertions funding — calibration earning); *drills owning* (teams rehearsing — procedures proving (confidence earning — improvising refusing (ownership funding — theater declining).

```typescript
// GOOD: faults scripting — scheduled scenarios with owned drills (compiled + run live).
interface Fault { // failures scheduling — scenarios scripting, debuting declining
  dependency: string;
  fault: string;
  drilledDaysAgo: number;
}
function unscripted(faults: Fault[], maxStale: number): string[] {
  const gaps: string[] = []; // surprises declining — unknowns converting, paging declining
  for (const f of faults) {
    if (f.fault.length === 0 || f.drilledDaysAgo > maxStale) gaps.push(f.dependency);
  }
  return gaps; // drills owning — teams rehearsing, improvising declining
}
const drilled: Fault[] = [
  { dependency: 'auth', fault: 'keys-revoked', drilledDaysAgo: 20 },
  { dependency: 'billing', fault: 'grpc-deadline', drilledDaysAgo: 40 },
];
const stale: Fault[] = [{ dependency: 'auth', fault: 'keys-revoked', drilledDaysAgo: 200 }];
console.log(unscripted(drilled, 90).length === 0 && unscripted(stale, 90).join() === 'auth' ? 'faults script' : 'failures debut');
```

**Common confusion** — *"game-days risk production (drills breaking)."* Drills breaking unscoped systems (blasts unbounding — damage unlimited (rehearsals debuting — recklessness proving (breaking charging — maturity missing); game-days bounding blasts (scopes graduating — traffic sharing (damage limiting — confidence earning (bounding funding — debuting refusing). "Risking" describing unscoped chaos (blasts unbounding — damage unlimited); drills describing graduated radii (scopes proving — production bounding). Script faults (scenarios scheduling — surprises declining); bound blasts (scopes graduating — damage limiting).

**Performance note** — scripting economics: scheduling costing scenarios (faults scripting — unknowns asserting (teams rehearsing — surprises declining); debuting equivalents costing user-impacting incidents (damage unlimited — recklessness ruling (trust eroding — pages multiplying). Script cheaply (faults — dependencies); debut never (failures — production).

**Mentor note** — teach "script the failure before it scripts you" (juniors scheduling one fault per dependency design debut-proof operations on first hearing; unscripted dependencies interrogated ("fails how?" — scripting demanding per dependency). Script one fault once (scenarios scheduling — unknowns asserting tangible (debuting ending — scripting proving permanently). ## 2. Blasts bounding (scopes graduating — traffic sharing — damage limiting)

**Definition** — bounded blasts: graduated drill scopes with shared traffic and limited damage (scopes graduating — radii expanding (staging proving — production bounding (graduating proving — debuting declining); traffic sharing — canaries splitting (percentages ramping — cohorts comparing (sharing funding — flooding declining); damage limiting — ceilings capping (kill-switches arming — rollbacks readying (limiting owning — avalanching ending).

**What problem it solves** — the all-or-nothing trio: *scopes ungraduating* (radii unowned — staging skipping (production debuting — damage unlimited (ungraduating billing — discipline missing); *traffic unflooding* (releases flipping — cohorts missing (comparisons absenting — regressions hiding (unflooding charging — evidence failing); *damage unlimiting* (ceilings missing — kill-switches absenting (cascades avalanching — recovery unbounded (unlimiting costing — safety bluffing). Bounded blasts converting debuting to graduating (radii expanding — traffic splitting (ceilings capping — damage containing); reviewers finding radii per drill (bounding proving → verifiable; all-or-nothing → returned).

**Modern guidance** — the bounding lines per drill (review-enforced): *scopes graduating* (radii expanding — staging proving (production bounding — debuting refusing (graduating proving — skipping declining (radii earning — maturity demonstrating); *traffic sharing* (canaries splitting — percentages ramping (cohorts comparing — flooding refusing (sharing funding — flipping declining (splits owning — evidence earning); *damage limiting* (ceilings capping — kill-switches arming (rollbacks readying — avalanching refusing (limiting owning — missing declining (ceilings funding — recovery bounding).

```typescript
// GOOD: blasts bounding — graduated scopes with shared traffic (compiled + run live).
interface Drill { // scopes graduating — radii expanding, debuting declining
  name: string;
  radius: number;
  canary: number;
  killSwitch: boolean;
}
function unbound(drills: Drill[], maxRadius: number): string[] {
  const gaps: string[] = []; // traffic sharing — canaries splitting, flooding declining
  for (const d of drills) {
    if (d.radius > maxRadius || d.canary <= 0 || !d.killSwitch) gaps.push(d.name);
  }
  return gaps; // damage limiting — ceilings capping, avalanching declining
}
const bounded: Drill[] = [{ name: 'auth-revoke', radius: 2, canary: 5, killSwitch: true }];

console.log(unbound(bounded, 3).length === 0 && unbound(wild, 3).join() === 'auth-revoke' ? 'blasts bound' : 'releases flip');
```

## 3. Recoveries proving (rollbacks readying — MTTR stating — trust earning)

**Definition** — proved recovery: ready rollbacks with stated MTTR earning trust (rollbacks readying — reversals rehearsing (flags arming — restores timing (readying proving — stranding declining); MTTR stating — minutes quoting (targets bounding — trends shrinking (stating funding — unknowning declining); trust earning — users believing (incidents shrinking — confidence compounding (earning owning — bluffing declining).

**What problem it solves** — the unrecoverable trio: *rollbacks unreadied* (reversals unrehearsed — flags unarmed (restores fumbling — outages extending (unreadied billing — shipping hoping); *MTTR unstating* (minutes unquoting — targets unbounding (recoveries unmeasured — improvements unowned (unstating charging — calibration missing); *trust unerning* (incidents repeating — confidence eroding (users leaving — reputation burning (unerning costing — reliability bluffing). **Modern guidance** — the proving lines per incident class (review-enforced): *rollbacks readying* (reversals rehearsing — flags arming (restores timing — stranding refusing (readying proving — fumbling declining (rehearsals earning — outages shrinking); *MTTR stating* (minutes quoting — targets bounding (trends shrinking — unknowning refusing (stating funding — unmeasured declining (quotes owning — calibration earning); *trust earning* (users believing — incidents shrinking (confidence compounding — bluffing refusing (earning owning — repeating declining (belief funding — reputation keeping).

```typescript
// GOOD: recoveries proving — rehearsed rollbacks with stated MTTR (compiled + run live).
interface Recovery { // rollbacks readying — reversals rehearsing, stranding declining
  incident: string;
  rollbackMins: number;
  targetMins: number;
}
function unready(recs: Recovery[]): string[] {
  const gaps: string[] = []; // MTTR stating — minutes quoting, unknowning declining
  for (const r of recs) {
    if (!(r.rollbackMins > 0) || r.rollbackMins > r.targetMins) gaps.push(r.incident);
  }
  return gaps; // trust earning — users believing, bluffing declining
}
const ready: Recovery[] = [
  { incident: 'bad-deploy', rollbackMins: 8, targetMins: 15 },
  { incident: 'key-leak', rollbackMins: 20, targetMins: 30 },
];
const fumbling: Recovery[] = [{ incident: 'bad-deploy', rollbackMins: 90, targetMins: 15 }];
console.log(unready(ready).length === 0 && unready(fumbling).join() === 'bad-deploy' ? 'recoveries prove' : 'outages strand');
```
