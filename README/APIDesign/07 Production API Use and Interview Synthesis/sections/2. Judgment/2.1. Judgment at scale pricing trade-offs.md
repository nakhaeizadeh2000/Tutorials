# 2.1. Judgment at scale pricing trade-offs

## 1. Decisions pricing (choices windowing — costs stating — vibes declining)

**Definition** — priced decisions: every API choice windowed with stated costs (choices windowing — options bounding (reversals dating — exits planning (windowing proving — forever declining); costs stating — prices attaching (latencies quoting — budgets owning (stating funding — vibes declining); vibes declining — slogans refusing (fashion declining — reasons demanding (declining owning — hype ending).

**What problem it solves** — the vibe-decision trio: *choices unwindowed* (options unbounded — reversals unplanned (exits missing — pivots costing (unwindowed billing — commitment bluffing); *costs unstating* (prices unattached — latencies unquoted (trade-offs hiding — surprises scheduling (unstating charging — judgment missing); *vibes ruling* (slogans deciding — fashion choosing (reasons missing — independence failing (ruling costing — engineering declining). Priced decisions converting vibes to windowing (options bounding — prices attaching (slogans refusing — reasons demanding); reviewers finding prices per choice (pricing proving → verifiable; vibes → returned).

**Modern guidance** — the pricing lines per choice (review-enforced): *choices windowing* ([05/1.2](<../../../05 Choosing and Unifying Styles/sections/1. Style choice/1.2. Decision records stating choices.md>) — options bounding (reversals dating — exits planning (windowing proving — forever refusing (windows owning — lock-in declining); *costs stating* (prices attaching — latencies quoting (budgets owning — vibes declining (stating funding — hiding refusing (prices earning — surprise declining); *vibes declining* (slogans refusing — fashion declining (reasons demanding — hype ending (declining owning — ruling refusing (independence funding — engineering keeping).

```typescript
// GOOD: decisions pricing — windowed choices with stated costs (compiled + run live).
interface Priced { // choices windowing — options bounding, forever declining
  choice: string;
  cost: number;
  reverseBy: string;
}
function unstated(decisions: Priced[]): string[] {
  const gaps: string[] = []; // costs stating — prices attaching, vibes declining
  for (const d of decisions) {
    if (!(d.cost >= 0) || d.reverseBy.length === 0) gaps.push(d.choice);
  }
  return gaps; // vibes declining — slogans refusing, hype ending
}
const priced: Priced[] = [
  { choice: 'REST list', cost: 40, reverseBy: 'v2' },
  { choice: 'gRPC pay', cost: 120, reverseBy: 'compat-6mo' },
];
const vibey: Priced[] = [{ choice: 'graph-everything', cost: NaN, reverseBy: '' }];
console.log(unstated(priced).length === 0 && unstated(vibey).join() === 'graph-everything' ? 'decisions price' : 'vibes rule');
```

```typescript
// BAD: vibes ruling — choices unwindowed, costs unstating (real slogan shape).
// // "GraphQL everywhere." (options unbounded — prices unattached — reasons missing).
// // No reversal (exits missing — pivots costing). Window choices; state costs; decline vibes.)
```

**Common confusion** — *"pricing slows decisions (arithmetic taxing)."* Pricing speeding reversals (options bounding — exits planning (surprises declining — pivots funding (pricing proving — lock-in declining); unpriced slowing recovery (costs discovering — reversals improvising (surprises scheduling — trust eroding (missing charging — judgment failing). "Slowing" describing sticker-shock avoidance (arithmetic skipping — surprises buying); pricing describing speed (windows bounding — exits planning). Price choices (costs stating — surprises declining); reverse fast (windows bounding — pivots funding).

**Performance note** — pricing economics: stating costing rows (choices windowing — prices attaching (vibes declining — hype ending); unpriced equivalents costing surprises (costs discovering — pivots improvising (lock-in — trust eroding). State cheaply (prices — choices); vibe never (slogans — decisions).

**Mentor note** — teach "every choice carries a price and a date" (juniors windowing one decision per choice design vibe-proof judgment on first hearing; priceless choices interrogated ("costs what? reversed when?" — pricing demanding per choice). Price one choice once (options bounding — costs stating tangible (vibes ending — pricing proving permanently). Window options; attach prices — pricing discipline in three habits, reviewed per decision.

## 2. Load repricing (traffic multiplying — budgets tightening — margins thinning)

**Definition** — load repricing: costs restated as traffic multiplies with tightening budgets (traffic multiplying — volumes growing (hotspots concentrating — peaks sharpening (multiplying proving — flat assuming declining); budgets tightening — caps restating (margins thinning — headroom shrinking (tightening funding — hoping declining); margins thinning — profits narrowing (costs surfacing — prices revisiting (thinning owning — ignoring declining).

**What problem it solves** — the flat-price trio: *traffic unmultiplying* (volumes assuming-flat — hotspots missing (peaks surprising — capacity crushing (unmultiplying billing — arithmetic failing); *budgets untightening* (caps unstating — margins unthinning (costs hiding — overruns scheduling (untightening charging — discipline missing); *margins unthinning* (profits assuming — prices unrevisiting (losses compounding — viability eroding (unthinning costing — economics bluffing). Repriced loads converting flatness to multiplying (volumes growing — caps restating (margins narrowing — costs surfacing); reviewers finding per-10x prices per choice (repricing proving → verifiable; flat → returned).

**Modern guidance** — the repricing lines per 10x (review-enforced): *traffic multiplying* (volumes growing — hotspots concentrating (peaks sharpening — flat declining (multiplying proving — assuming refusing (growth owning — surprise declining); *budgets tightening* ([06/1.2](<../../../06 API Operations/sections/1. Guarding operations/1.2. Limits enforcing quotas shedding load.md>) — caps restating (margins thinning — headroom shrinking (tightening funding — hoping refusing (restatements earning — crush declining); *margins thinning* (profits narrowing — costs surfacing (prices revisiting — ignoring declining (thinning owning — hiding refusing (narrowing funding — viability keeping).

```typescript
// GOOD: load repricing — per-10x costs with tightening budgets (compiled + run live).
interface Tier { // traffic multiplying — volumes growing, flat declining
  rps: number;
  cost: number;
}
function repriced(tiers: Tier[], budget: number): string {
  for (const t of tiers) { // budgets tightening — caps restating, hoping declining
    if (t.cost > budget) return `OVER at ${t.rps}rps`;
  }
  return 'WITHIN'; // margins thinning — profits narrowing, ignoring declining
}
const tiers: Tier[] = [
  { rps: 100, cost: 40 },
  { rps: 1000, cost: 300 },
  { rps: 10000, cost: 2400 },
];
console.log(repriced(tiers, 5000) === 'WITHIN' && repriced(tiers, 500) === 'OVER at 10000rps' ? 'loads reprice' : 'prices flat');
```

```typescript
// BAD: prices flatting — traffic unmultiplying, margins unthinning (real overrun shape).
// // "Costs $40." (volumes assuming-flat — peaks surprising — capacity crushing).
// // No budget (overruns scheduling — viability eroding). Multiply traffic; tighten budgets; thin margins.)
```

**Common confusion** — *"repricing is pessimism (growth doubting)."* Pessimism doubting value (growth fearing — investment refusing (futures discounting — wins missing (doubting charging — ambition taxing); repricing stating arithmetic (volumes growing — costs surfacing (budgets tightening — overruns preventing (stating proving — bluffing declining). "Pessimism" describing mood (growth fearing — investment refusing); repricing describing math (traffic multiplying — margins thinning). State arithmetic (costs surfacing — budgets tightening); fund growth (wins pricing — viability keeping).

**Performance note** — repricing economics: multiplying costing tiers (traffic growing — budgets restating (margins narrowing — costs surfacing); flat equivalents costing overruns (peaks surprising — capacity crushing (losses compounding — viability eroding). Tier cheaply (10x — budgets); flat never (prices — traffic).

**Mentor note** — teach "price the next 10x before it arrives" (juniors tiering one cost row per order of magnitude design overrun-proof judgment on first hearing; flat prices interrogated ("at 10x?" — repricing demanding per choice). Reprice one tier once (volumes growing — budgets tightening tangible (flatness ending — repricing proving permanently). Grow traffic; thin margins — repricing discipline in three habits, reviewed per 10x.
