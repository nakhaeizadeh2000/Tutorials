# 2.2. Contracts testing pacts catching breaks

## 1. Pacts pinning (consumers declaring — providers proving — drift declining)

**Definition** — consumer pacts: callers declaring expected shapes with providers proving them per build (consumers declaring — expectations filing (fields naming — samples attaching (declaring proving — assuming ending); providers proving — responses matching (suites replaying — failures paging (proving funding — drifting declining); drift declining — skews surfacing (versions aligning — trust compounding (declining owning — discovering ending).

**What problem it solves** — the handshake-hope trio: *consumers undeclaring* (expectations unfiling — shapes assuming (providers guessing — drift hiding (undeclaring billing — integration hoping); *providers unproving* (responses unmatching — suites unreplaying (breaks shipping — callers paging (unproving charging — confidence bluffing); *drift undiscovering* (skews accumulating — versions misaligning (failures productioning — debugging archaeologizing (undiscovering costing — trust eroding). Pinned pacts converting hoping to declaring (expectations filing — responses matching (skews surfacing — breaks paging); reviewers finding pacts per consumer (pinning proving → verifiable; handshaking → returned).

**Modern guidance** — the pinning lines per consumer (review-enforced): *consumers declaring* (expectations filing — fields naming (samples attaching — assuming ending (declaring proving — guessing refusing (filings owning — drift surfacing); *providers proving* (responses matching — suites replaying (failures paging — drifting declining (proving funding — shipping refusing (proofs earning — confidence compounding); *drift declining* (skews surfacing — versions aligning (trust compounding — discovering ending (declining owning — hiding refusing (surfacing funding — archaeology declining).

```typescript
// GOOD: pacts pinning — consumer expectations proved per provider build (compiled + run live).
interface Shape { // consumers declaring — expectations filing, assuming ending
  [field: string]: string;
}
function honours(response: Shape, need: Shape): string[] {
  const gaps: string[] = []; // providers proving — responses matching, drifting declining
  for (const k of Object.keys(need)) {
    if (response[k] !== need[k]) gaps.push(k);
  }
  return gaps; // drift declining — skews surfacing, discovering ending
}
const need: Shape = { id: 'string', total: 'number' };
const good: Shape = { id: 'string', total: 'number', note: 'string' };
const skew: Shape = { id: 'string', total: 'string' };
console.log(honours(good, need).length === 0 && honours(skew, need).join() === 'total' ? 'pacts pin' : 'handshakes hope');
```

```typescript
// BAD: handshake hope — consumers undeclaring, providers unproving (real drift shape).
// await fetch('/v1/items'); // expectations unfiling — shapes assuming, drift hiding.
// // Provider renames total (breaks shipping — callers paging). File pacts; prove per build; surface skews.)
```

**Common confusion** — *"pacts double testing (suites duplicating)."* Pacts sharing assertions (expectations filing once — providers replaying (integration confirming — drift detecting (sharing proving — value doubling); duplication copying suites (tests cloning — value halving (maintenance doubling — drift scheduling (copying charging — trust eroding). "Doubling" describing copies (tests cloning — value halving); pacts describing sharing (filing once — replaying everywhere). File once (expectations declaring — drift surfacing); prove everywhere (providers matching — confidence compounding).

**Performance note** — pinning economics: filing costing expectations (consumers declaring — providers proving (skews surfacing — breaks paging); hoped equivalents costing production drift (breaks shipping — callers paging (debugging archaeologizing — trust eroding). File cheaply (pacts — consumers); hope never (handshakes — drift).

**Mentor note** — teach "every consumer files its shape" (juniors filing one pact per consumer design drift-proof integration on first hearing; pact-less consumers interrogated ("expects what?" — pinning demanding per consumer). Pin one pact once (expectations filing — responses matching tangible (hoping ending — pinning proving permanently). Declare shapes; prove per build — pinning discipline in three habits, reviewed per consumer.

## 2. Breaks catching (schemas diffing — gates blocking — incidents declining)

**Definition** — breaking-change gates: schema diffs blocking incompatible releases (schemas diffing — fields comparing (required watching — types checking (diffing proving — silently declining); gates blocking — builds failing (merges stopping — deploys refusing (blocking funding — shipping declining); incidents declining — production sparing (pages preventing — trust keeping (declining owning — firefighting ending).

**What problem it solves** — the green-but-broken trio: *schemas undiffing* (fields uncomparing — removals hiding (incompatibilities shipping — callers breaking (undiffing billing — evolution hoping); *gates unblocking* (builds passing — merges flowing (breaks deploying — incidents paging (unblocking charging — safety theatering); *production firefighting* (failures discovering — rollbacks racing (goodwill burning — velocity dying (firefighting costing — prevention missing). Diffed gates converting shipping to blocking (fields comparing — builds failing (production sparing — pages preventing); reviewers finding diff verdicts per release (catching proving → verifiable; green-but-broken → returned).

**Modern guidance** — the catching lines per release (review-enforced): *schemas diffing* (fields comparing — required watching (types checking — silently declining (diffing proving — hiding refusing (comparisons owning — discovery ending); *gates blocking* (builds failing — merges stopping (deploys refusing — shipping declining (blocking funding — theater refusing (failures earning — safety proving); *incidents declining* (production sparing — pages preventing (trust keeping — firefighting ending (declining owning — racing refusing (prevention funding — goodwill keeping).

```typescript
// GOOD: breaks catching — schema diffs gating releases (compiled + run live).
interface Field { // schemas diffing — fields comparing, silently declining
  name: string;
  required: boolean;
}
function breaking(prev: Field[], next: Field[]): string[] {
  const names = next.map((f) => f.name); // gates blocking — builds failing, shipping declining
  return prev.filter((f) => f.required && !names.includes(f.name)).map((f) => f.name); // incidents declining — production sparing, firefighting ending
}
const v1: Field[] = [
  { name: 'id', required: true },
  { name: 'total', required: true },
];
const v2: Field[] = [
  { name: 'id', required: true },
  { name: 'note', required: false },
];
const v3: Field[] = [{ name: 'id', required: true }];
console.log(breaking(v1, v2).join() === 'total' && breaking(v1, v3).join() === 'total' && breaking(v1, v1).length === 0 ? 'breaks catch' : 'releases blind');
```

```typescript
// BAD: green-but-broken — schemas undiffing, gates unblocking (real fire shape).
// // All unit tests pass (builds passing — merges flowing — breaks deploying).
// // total removed (callers breaking — incidents paging). Diff schemas; gate releases; spare production.)
```

**Common confusion** — *"gates slow releases (blocking taxing)."* Gates pricing safety (fields comparing — builds failing (production sparing — trust keeping (pricing proving — firefighting declining); ungated slowing recovery (failures discovering — rollbacks racing (goodwill burning — velocity dying (missing charging — prevention failing). "Slowing" describing incident recovery (discovering — racing); gates describing speed (blocking early — shipping confidently). Gate releases (diffs comparing — production sparing); ship faster (confidence compounding — velocity funding).

**Performance note** — catching economics: diffing costing comparisons (fields comparing — builds failing (production sparing — pages preventing); ungated equivalents costing incidents (breaks deploying — failures discovering (rollbacks racing — goodwill burning). Compare cheaply (schemas — releases); firefight never (production — pages).

**Mentor note** — teach "diff the schema before the deploy" (juniors comparing one schema pair per release design break-proof evolution on first hearing; undiffed releases interrogated ("removed what?" — catching demanding per release). Diff one schema once (fields comparing — builds failing tangible (shipping-ending — catching proving permanently). Watch requireds; gate merges — catching discipline in three habits, reviewed per release.

## 3. Evolutions proving (additions passing — removals flagging — trust earning)

**Definition** — additive evolution: compatible additions passing freely with flagged removals (additions passing — optionals extending (clients ignoring (compatibilities proving — adoption funding); removals flagging — breakers dating (sunsets announcing (migrations pathing (flagging owning — ambushing declining); trust earning — consumers upgrading (fear declining (confidence compounding (earning funding — pinning ending).

**What problem it solves** — the frozen-schema trio: *additions fearing* (optionals blocking — extensions queuing (evolution stalling — value waiting (fearing billing — compatibility doubting); *removals unflagging* (breakers hiding — sunsets missing (clients ambushing — trust burning (unflagging charging — forewarning failing); *upgrades fearing* (consumers pinning — versions freezing (security lagging — features missing (fearing costing — evolution stalling). Proved evolutions converting freezing to passing (optionals extending — breakers dating (consumers upgrading — fear declining); reviewers finding additive proofs per change (proving revealing → verifiable; frozen → returned).

**Modern guidance** — the proving lines per change (review-enforced): *additions passing* (optionals extending — clients ignoring (compatibilities proving — adoption funding (passing owning — fearing refusing (extensions earning — value flowing); *removals flagging* (breakers dating — sunsets announcing (migrations pathing — ambushing declining (flagging owning — hiding refusing (dates funding — goodwill keeping); *trust earning* (consumers upgrading — fear declining (confidence compounding — pinning ending (earning funding — freezing refusing (upgrades flowing — evolution funding).

```typescript
// GOOD: evolutions proving — additive gates with flagged removals (compiled + run live).
interface Change { // additions passing — optionals extending, fearing declining
  kind: string;
  optional: boolean;
  announced: boolean;
}
function verdict(changes: Change[]): string {
  for (const c of changes) { // removals flagging — breakers dating, ambushing declining
    if (c.kind === 'remove' && !c.announced) return 'BLOCKED';
    if (c.kind === 'change' && !c.optional && !c.announced) return 'BLOCKED';
  }
  return 'PASS'; // trust earning — consumers upgrading, pinning ending
}
const additive: Change[] = [{ kind: 'add', optional: true, announced: false }];
const silent: Change[] = [{ kind: 'remove', optional: false, announced: false }];
const dated: Change[] = [{ kind: 'remove', optional: false, announced: true }];
console.log(verdict(additive) === 'PASS' && verdict(silent) === 'BLOCKED' && verdict(dated) === 'PASS' ? 'evolutions prove' : 'schemas freeze');
```

```typescript
// BAD: frozen schemas — additions fearing, upgrades fearing (real stall shape).
// // Never change anything (extensions queuing — evolution stalling — value waiting).
// // Or break silently (clients ambushing — trust burning). Pass additives; flag removals; earn upgrades.)
```

**Common confusion** — *"additive always means safe (extensions harmless)."* Additive defaulting safely (optionals extending — old clients ignoring (compatibilities holding — adoption flowing (defaulting serving — fearing curing); semantics shifting sneakily (meanings changing — validations tightening (old passing — new failing (shifting charging — safety bluffing). "Always" describing shape (fields adding — payloads growing); safety describing semantics (meanings holding — validations loosening). Extend shapes (additives passing — clients ignoring); preserve semantics (meanings holding — safety proving).

**Performance note** — proving economics: passing costing verdicts (changes judging — removals flagging (consumers upgrading — fear declining); frozen equivalents costing stalls (extensions queuing — evolution stalling (value waiting — features missing). Judge cheaply (verdicts — changes); freeze never (schemas — value).

**Mentor note** — teach "add freely, remove loudly" (juniors passing one additive per change and dating one removal per sunset design stall-proof evolution on first hearing; silent removals interrogated ("announced where?" — proving demanding per removal). Prove one change once (additives passing — removals flagging tangible (freezing ending — proving earning permanently). Extend optionals; date sunsets — proving discipline in three habits, reviewed per change.
