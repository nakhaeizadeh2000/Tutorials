# 2.1. Docs publishing OpenAPI guiding clients

## 1. Specs publishing (contracts declaring — examples showing — guesses declining)

**Definition** — published specs: machine-readable contracts with worked examples per operation (contracts declaring — paths tabling (operations naming — schemas binding (declaring proving — hoping ending); examples showing — requests sampling (responses illustrating — errors demonstrating (showing funding — guessing declining); guesses declining — clients coding (SDKs generating — mocks serving (declining owning — archaeology ending).

**What problem it solves** — the tribal-API trio: *contracts undeclaring* (shapes living in handlers — clients reading code (specs missing — integration guessing (undeclaring billing — archaeology requiring); *examples unshowing* (fields undocumented — formats unstating (callers trial-erroring — support answering (unshowing charging — onboarding slowing); *SDKs ungenerating* (clients hand-writing — drift entering (versions skewing — breaks surprising (ungenerating costing — consistency hoping). Published specs converting archaeology to declaring (contracts tabling — examples sampling (SDKs generating — guesses ending); reviewers finding examples per operation (publishing proving → verifiable; tribal → returned).

**Modern guidance** — the publishing lines per operation (review-enforced): *contracts declaring* (paths tabling — operations naming (schemas binding — hoping ending (declaring proving — code-reading refusing (tables owning — archaeology declining); *examples showing* (requests sampling — responses illustrating (errors demonstrating — guessing declining (showing funding — trial-error refusing (samples earning — onboarding funding); *guesses declining* (clients coding — SDKs generating (mocks serving — archaeology ending (declining owning — hoping refusing (generation funding — drift declining).

```typescript
// GOOD: specs publishing — declared operations with worked examples (compiled + run live).
interface Operation { // contracts declaring — paths tabling, hoping ending
  path: string;
  method: string;
  example: string;
}
function missing(ops: Operation[]): string[] {
  const gaps: string[] = []; // examples showing — requests sampling, guessing declining
  for (const o of ops) {
    if (o.path.length === 0 || o.method.length === 0 || o.example.length === 0) gaps.push(`${o.method} ${o.path}`);
  }
  return gaps; // guesses declining — clients coding, archaeology ending
}
const ops: Operation[] = [
  { path: '/v1/items', method: 'GET', example: '{"items":[]}' },
  { path: '/v1/items', method: 'POST', example: '{"id":"i1"}' },
];
const thin: Operation[] = [{ path: '/v1/items', method: 'GET', example: '' }];
console.log(missing(ops).length === 0 && missing(thin).join() === 'GET /v1/items' ? 'specs publish' : 'apis tribal');
```

```typescript
// BAD: tribal APIs — contracts undeclaring, examples unshowing (real archaeology shape).
// // Read the handler (shapes living in code — clients guessing — integration hoping).
// // No examples (trial-erroring — support answering). Declare contracts; show examples; generate SDKs.)
```

**Common confusion** — *"docs rot anyway (specs decaying — writing wasting)."* Rotting documenting manually (specs hand-writing — code drifting (copies aging — contradictions officiating (rotting charging — trust eroding); publishing generating from truth (specs deriving — tests pinning (examples executing — drift detecting (generating funding — rot declining). "Rotting" describing copies (hand-writing — code drifting); specs describing generation (deriving — pinning). Generate from truth (specs deriving — drift detecting); never hand-copy (copies aging — trust eroding).

**Performance note** — publishing economics: declaring costing examples (operations sampling — SDKs generating (guesses ending — onboarding funding); tribal equivalents costing archaeology (code reading — trial-erroring (support answering — onboarding slowing). Sample cheaply (examples — operations); tribalize never (handlers — guesses).

**Mentor note** — teach "no operation without an example" (juniors sampling one example per operation design guess-proof APIs on first hearing; example-less operations interrogated ("called how?" — publishing demanding per operation). Publish one spec once (contracts tabling — examples sampling tangible (archaeology ending — publishing proving permanently). Declare paths; show examples — publishing discipline in three habits, reviewed per operation.

## 2. Changes announcing (versions diffing — migrations guiding — surprises declining)

**Definition** — announced evolution: diffed versions with guided migrations per change (versions diffing — operations comparing (additions listing — removals flagging (diffing proving — silently declining); migrations guiding — upgraders pathing (steps ordering — codemods offering (guiding funding — stranding declining); surprises declining — clients forewarning (sunsets dating — breaks justifying (declining owning — paging ending).

**What problem it solves** — the silent-break trio: *versions undiffing* (changes unlisting — removals hiding (clients discovering — production paging (undiffing billing — evolution hoping); *migrations unguilding* (upgraders stranding — steps missing (clients rewriting — trust eroding (unguilding charging — adoption stalling); *sunsets unsurprising* (deprecations unannouncing — breaks ambushing (integrators firefighting — goodwill burning (unsurprising costing — forewarning missing). Announced changes converting ambushing to diffing (versions comparing — migrations pathing (sunsets dating — surprises ending); reviewers finding changelogs per release (announcing proving → verifiable; silent → returned).

**Modern guidance** — the announcing lines per release (review-enforced): *versions diffing* (operations comparing — additions listing (removals flagging — silently declining (diffing proving — hiding refusing (diffs owning — discovery ending); *migrations guiding* (upgraders pathing — steps ordering (codemods offering — stranding declining (guiding funding — rewriting refusing (paths earning — adoption funding); *surprises declining* (clients forewarning — sunsets dating (breaks justifying — paging ending (declining owning — ambushing refusing (forewarning funding — goodwill keeping).

```typescript
// GOOD: changes announcing — version diffs with guided migrations (compiled + run live).
interface Release { // versions diffing — operations comparing, silently declining
  version: string;
  endpoints: string[];
  migrate: string;
}
function removed(prev: Release, next: Release): string[] {
  return prev.endpoints.filter((e) => !next.endpoints.includes(e)); // migrations guiding — upgraders pathing, stranding declining
}
const v1: Release = { version: 'v1', endpoints: ['GET /a', 'GET /b'], migrate: 'b moves to /c' };
const v2: Release = { version: 'v2', endpoints: ['GET /a', 'GET /c'], migrate: 'b moves to /c' };
const gone = removed(v1, v2);
console.log(gone.join() === 'GET /b' && v2.migrate.length > 0 ? 'changes announce' : 'breaks ambush');
```

```typescript
// BAD: silent breaks — versions undiffing, sunsets unsurprising (real ambush shape).
// // Removed /b (changes unlisting — clients discovering — production paging).
// // No migration (upgraders stranding — trust eroding). Diff versions; guide migrations; date sunsets.)
```

**Common confusion** — *"changelogs slow shipping (announcing taxing)."* Changelogs pricing trust (versions diffing — migrations guiding (surprises declining — goodwill keeping (pricing proving — ambushing declining); silent breaking slowing adoption (clients firefighting — integrators pinning (upgrades fearing — velocity dying (missing charging — trust eroding). "Slowing" describing ambush recovery (firefighting — pinning); announcing describing speed (paths guiding — surprises ending). Announce changes (diffs comparing — goodwill keeping); ship faster (trust compounding — adoption funding).

**Performance note** — announcing economics: diffing costing comparisons (versions comparing — migrations pathing (surprises ending — goodwill keeping); silent equivalents costing pages (clients discovering — production paging (firefighting — trust eroding). Diff cheaply (releases — endpoints); ambush never (removals — clients).

**Mentor note** — teach "every removal ships with a path" (juniors pairing one migration per removal design ambush-proof evolution on first hearing; pathless removals interrogated ("migrate how?" — announcing demanding per removal). Announce one release once (versions diffing — migrations guiding tangible (silence ending — announcing proving permanently). Diff versions; date sunsets — announcing discipline in three habits, reviewed per release.

## 3. Clients guiding (remedies quoting — runbooks linking — tickets declining)

**Definition** — guided failures: every error quoting remedies with linked runbooks (remedies quoting — codes mapping (actions stating — retries judging (quoting proving — guessing declining); runbooks linking — operations pathing (incidents routing — humans unblocking (linking funding — ticket-queuing declining); tickets declining — repeats self-serving (first teaching — rest following (declining owning — supporting ending).

**What problem it solves** — the dead-end-error trio: *remedies unquoting* (codes bareing — actions missing (callers guessing — support bridging (unquoting billing — self-service failing); *runbooks unlinking* (operations hiding — incidents wandering (responders asking — resolution waiting (unlinking charging — wandering scheduling); *repeats ticketing* (failures recurring — humans bridging (load scaling — novelty starving (ticketing costing — service draining). Quoted remedies converting guessing to guiding (codes mapping — runbooks linking (repeats self-serving — support shrinking); reviewers finding remedies per error (guiding proving → verifiable; dead-end → returned).

**Modern guidance** — the guiding lines per error (review-enforced): *remedies quoting* (codes mapping — actions stating (retries judging — guessing declining (quoting proving — bare refusing (maps owning — self-service funding); *runbooks linking* (operations pathing — incidents routing (humans unblocking — ticket-queuing declining (linking funding — wandering refusing (paths earning — resolution funding); *tickets declining* (repeats self-serving — first teaching (rest following — supporting ending (declining owning — bridging refusing (teaching funding — load bounding).

```typescript
// GOOD: clients guiding — remedy tables with linked runbooks (compiled + run live).
interface Remedy { // remedies quoting — codes mapping, guessing declining
  code: string;
  retry: boolean;
  action: string;
  runbook: string;
}
function remedyFor(table: Remedy[], code: string): string {
  const hit = table.filter((r) => r.code === code)[0]; // runbooks linking — operations pathing, wandering declining
  if (hit === undefined) return 'unknown: read the spec';
  return `${hit.action} :: ${hit.runbook} :: retry=${hit.retry ? 'yes' : 'no'}`; // tickets declining — repeats self-serving, bridging declining
}
const table: Remedy[] = [
  { code: 'RATE_LIMITED', retry: true, action: 'wait Retry-After then retry with jitter', runbook: '/runbooks/limits' },
  { code: 'AUTH_EXPIRED', retry: false, action: 'refresh the token then replay once', runbook: '/runbooks/auth' },
];
console.log(remedyFor(table, 'RATE_LIMITED') === 'wait Retry-After then retry with jitter :: /runbooks/limits :: retry=yes' && remedyFor(table, 'NOPE') === 'unknown: read the spec' ? 'clients guide' : 'errors dead-end');
```

```typescript
// BAD: dead-end errors — remedies unquoting, runbooks unlinking (real guess shape).
// throw new Error('Internal error'); // codes bareing — actions missing, callers guessing.
// // No runbook (responders asking — resolution waiting). Quote remedies; link runbooks; shrink tickets.)
```

**Common confusion** — *"verbose errors leak internals (remedies exposing)."* Verbose leaking stacks (traces printing — paths revealing (attackers arming — breaches inviting (leaking charging — exposure widening); remedies stating actions (codes mapping — runbooks linking (clients guiding — tickets declining (stating serving — guessing curing). "Verbose" describing traces (stacks printing — paths revealing); guiding describing remedies (actions stating — paths linking). Quote actions (remedies mapping — clients guiding); never print stacks (traces hiding — exposure declining).

**Performance note** — guiding economics: quoting costing tables (codes mapping — runbooks linking (repeats self-serving — support shrinking); dead-end equivalents costing tickets (callers guessing — humans bridging (load scaling — novelty starving). Table cheaply (remedies — errors); dead-end never (codes — callers).

**Mentor note** — teach "every error teaches its fix" (juniors quoting one remedy per error design ticket-proof APIs on first hearing; remedy-less errors interrogated ("then what?" — guiding demanding per code). Guide one error once (codes mapping — runbooks linking tangible (guessing ending — guiding proving permanently). Map codes; link runbooks — guiding discipline in three habits, reviewed per error.
