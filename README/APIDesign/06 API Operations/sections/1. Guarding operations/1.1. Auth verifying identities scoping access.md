## 1. Identities verifying (tokens validating — lifetimes bounding — forgeries declining)

**Definition** — operation auth: every request proving identity with lifetime-bounded tokens (tokens validating — signatures checking (issuers trusting — expiries enforcing (validating proving — hoping ending); lifetimes bounding — access expiring fast (refresh rotating — windows pricing (bounding funding — replay declining (exposure owning — eternity refusing); forgeries declining — fakes refusing (claims proving — clocks trusting (declining owning — breaches preventing).

**What problem it solves** — the forever-token trio: *tokens unvalidating* (signatures hoping — issuers trusting blindly (forgeries arriving — breaches scheduling (unvalidating charging — safety declining); *lifetimes unbounding* (access lasting months — leaks persisting (refresh missing — revocation hoping (unbounding billing — exposure compounding); *clocks ignoring* (expiries skipping — skew unhandling (replays arriving — windows leaking (ignoring costing — forgery inviting). Bounded identities converting hoping to verifying (tokens checking — lifetimes capping (forgeries refusing — breaches declining); reviewers finding max-age per token kind (verifying proving → verifiable; forever → returned).

**Modern guidance** — the verifying lines per API (review-enforced): *tokens validating* (signatures checking — issuers trusting (expiries enforcing — hoping ending (validating proving — forging declining (checks owning — breaches preventing); *lifetimes bounding* (access expiring fast — refresh rotating (windows pricing — replay declining (bounding funding — eternity refusing (exposure owning — persistence declining); *forgeries declining* (fakes refusing — claims proving (clocks trusting — breaches preventing (declining owning — hoping ending (safety funding — incidents declining).

```typescript
// GOOD: identities verifying — lifetime-bounded tokens with issuer checks (compiled + run live).
interface Identity { // tokens validating — signatures checking, hoping ending
  sub: string;
  scopes: string[];
  exp: number;
  iat: number;
}
function verifyIdentity(raw: string, now: number, maxAge: number): Identity | undefined {
  const parts = raw.split('|'); // issuers trusting — expiries enforcing, forgeries declining
  const sub = parts[0] ?? '';
  const scopes = parts[1] ?? '';
  const exp = Number(parts[2]);
  const iat = Number(parts[3]);
  if (sub.length === 0 || scopes.length === 0) return undefined;
  if (!(exp > now)) return undefined; // lifetimes bounding — access expiring fast, replay declining
  if (exp - iat > maxAge) return undefined;
  return { sub, scopes: scopes.split(','), exp, iat };
}
const fresh = verifyIdentity('ada|items:read|2000|1000', 1500, 3600);
const stale = verifyIdentity('ada|items:read|1200|1000', 1500, 3600);
const roomy = verifyIdentity('ada|items:read|9999|1000', 1500, 3600);
console.log(fresh !== undefined && stale === undefined && roomy === undefined ? 'identities verify' : 'tokens forge');
```

```typescript
// GOOD: access scoping — route scope maps with least-privilege audits (compiled + run live).
interface RoutePolicy { // routes declaring — handlers stating needs, hoping ending
  route: string;
  need: string[];
}
function uncovered(routes: RoutePolicy[], granted: string[]): string[] {
  const out: string[] = []; // scopes inventorying — grants listing, sprawling declining
  for (const r of routes) {
    for (const s of r.need) {
      if (!granted.includes(s) && !out.includes(r.route)) out.push(r.route);
    }
  }
  return out; // leaks declining — over-grants refusing, breaches preventing
}

  { route: 'GET /items', need: ['items:read'] },
  { route: 'POST /items', need: ['items:write'] },

const full = uncovered(policies, ['items:read', 'items:write']);
const thin = uncovered(policies, ['items:read']);
console.log(full.length === 0 && thin.join() === 'POST /items' ? 'access scopes' : 'routes leak');
```

**What problem it solves** — the eternal-key trio: *keys unversioned* (secrets singularing — generations missing (rotation breaking (versions absenting — overlap impossibleing (unversioned billing — outages scheduling); *revocations unpropagating* (withdrawals localing — caches trusting (compromises persisting — attackers lingering (unpropagating charging — breaches extending); *breaches unbounding* (leaks lasting — windows missing (damage spreading — trust eroding (unbounding costing — containment hoping). **Modern guidance** — the rotating lines per key (review-enforced): *keys versioning* (kids tagging — generations numbering (overlap windowing — breaking declining (versioning proving — singular refusing (numbers owning — outages declining); *revocations propagating* (compromises withdrawing — lists publishing (caches expiring — trusting ending (propagating funding — lingering refusing (withdrawals owning — persistence declining); *breaches bounding* (leaks windowing — exposure capping (damage containing — persisting declining (bounding owning — spreading refusing (windows earning — safety funding).

```typescript
// GOOD: secrets rotating — versioned keys with overlap windows (compiled + run live).
interface KeyRing { // keys versioning — kids tagging, ambiguity declining
  current: number;
  prev: number;
  prevUntil: number;
}
function keyFor(ring: KeyRing, now: number): number {
  return now <= ring.prevUntil ? ring.prev : ring.current; // overlap windowing — breaking declining, outages refusing
}
function signToken(ring: KeyRing, now: number, msg: string): string {
  return `${keyFor(ring, now)}:${msg}`;
}
function acceptToken(ring: KeyRing, token: string, now: number): boolean {
  const sep = token.indexOf(':'); // revocations propagating — lists publishing, trusting ending
  if (sep < 0) return false;
  const k = token.slice(0, sep);
  const msg = token.slice(sep + 1);
  if (msg.length === 0) return false;
  const okKeys = now <= ring.prevUntil ? [String(ring.prev), String(ring.current)] : [String(ring.current)];
  return okKeys.includes(k); // breaches bounding — leaks windowing, persisting declining
}
const ring: KeyRing = { current: 7, prev: 5, prevUntil: 2000 };
const early = signToken(ring, 1500, 'hi');
const late = signToken(ring, 2500, 'hi');
console.log(acceptToken(ring, early, 1500) && acceptToken(ring, late, 2500) && !acceptToken(ring, '9:hi', 2500) ? 'secrets rotate' : 'keys stall');
```
