# 1.2. Limits enforcing quotas shedding load

## 1. Quotas enforcing (budgets owning — tenants isolating — floods declining)

**Definition** — per-tenant quotas: explicit call budgets per key with isolated accounting (budgets owning — caps stating (windows bounding — usage counting (owning proving — hoping ending); tenants isolating — keys partitioning (neighbors protecting — hogs containing (isolating funding — starving declining); floods declining — surges refusing (abuse pricing — capacity defending (declining owning — crushing ending).

**What problem it solves** — the shared-bucket trio: *budgets unowning* (caps unstating — usage uncounting (limits hoping — floods arriving (unowning billing — policy declining); *tenants unisolating* (keys sharing — hogs consuming (neighbors starving — fairness missing (unisolating charging — commons collapsing); *floods unpricing* (abuse freeriding — capacity crushing (legit queuing — service falling (unpricing costing — availability dying). Owned quotas converting sharing to isolating (budgets stating — tenants partitioning (floods pricing — service sustaining); reviewers finding caps per tenant (enforcing proving → verifiable; sharing → returned).

**Modern guidance** — the enforcing lines per tenant (review-enforced): *budgets owning* (caps stating — windows bounding (usage counting — hoping ending (owning proving — flooding refusing (caps earning — strain declining); *tenants isolating* (keys partitioning — neighbors protecting (hogs containing — starving declining (isolating funding — sharing refusing (partitions owning — fairness serving); *floods declining* (surges refusing — abuse pricing (capacity defending — crushing ending (declining owning — freeriding refusing (pricing funding — availability defending).

```typescript
// GOOD: quotas enforcing — per-tenant budgets with isolation (compiled + run live).
class QuotaLedger { // budgets owning — caps stating, hoping ending
  private used = new Map<string, number>();
  constructor(private readonly perTenant: number) {}
  spend(tenant: string, n = 1): boolean {
    const cur = this.used.get(tenant) ?? 0; // tenants isolating — keys partitioning, starving declining
    if (cur + n > this.perTenant) return false;
    this.used.set(tenant, cur + n);
    return true; // floods declining — surges refusing, crushing ending
  }
}
const ledger = new QuotaLedger(2);
const t1a = ledger.spend('ada');
const t1b = ledger.spend('ada');
const t1c = ledger.spend('ada');
const t2a = ledger.spend('grace');
console.log(t1a && t1b && !t1c && t2a ? 'quotas enforce' : 'buckets share');
```

**Common confusion** — *"quotas punish growth (caps blocking)."* Quotas pricing abuse (budgets stating — hogs containing (neighbors protecting — service sustaining (pricing proving — collapsing declining); unquotaed collapsing everyone (floods arriving — capacity crushing (legit starving — availability dying (missing charging — fairness failing). "Punishing" describing unexamined caps (growth throttling — value blocking); quotas describing isolation (tenants partitioning — neighbors protecting). Budget tenants (caps stating — fairness serving); refuse floods (surges declining — availability defending).

**Performance note** — enforcing economics: owning costing counters (caps stating — usage counting (hogs containing — fairness serving); shared equivalents costing collapse (floods arriving — capacity crushing (legit starving — trust eroding). Count cheaply (counters — tenants); share never (buckets — hogs).

**Mentor note** — teach "every tenant carries a budget" (juniors owning one cap per key design hog-proof APIs on first hearing; global-only limits interrogated ("which tenant?" — enforcing demanding per key). Budget one tenant once (caps stating — isolation partitioning tangible (sharing ending — enforcing proving permanently). State caps; partition keys — enforcing discipline in three habits, reviewed per tenant.

## 2. Bursts absorbing (headers signaling — retries informing — stampedes declining)

**Definition** — burst discipline: absorbing spikes with signaled headers and informed retries (headers signaling — limits advertising (remaining stating — resets dating (signaling proving — guessing declining); retries informing — backoffs suggesting (waits quoting — jitter randomizing (informing funding — thundering declining); stampedes declining — herds dispersing (spikes queuing — cascades preventing (declining owning — collapsing ending).

**What problem it solves** — the silent-429 trio: *headers unsignaling* (limits hiding — remaining unstating (clients blindfolding — retries guessing (unsignaling billing — contracts failing); *retries uninforming* (waits unquoting — backoffs missing (clients hammering — herds stampeding (uninforming charging — pressure compounding); *bursts undispersing* (spikes rejecting — stampedes cascading (outages deepening — trust eroding (undispersing costing — absorbing declining). Signaled bursts converting blindness to absorbing (limits advertising — waits quoting (herds dispersing — pressure easing); reviewers finding limit headers per response (absorbing proving → verifiable; silent → returned).

**Modern guidance** — the absorbing lines per response (review-enforced): *headers signaling* (limits advertising — remaining stating (resets dating — guessing declining (signaling proving — hiding refusing (headers owning — blindness ending); *retries informing* (backoffs suggesting — waits quoting (jitter randomizing — thundering declining (informing funding — hammering refusing (guidance owning — stampedes dispersing); *stampedes declining* (herds dispersing — spikes queuing (cascades preventing — collapsing ending (declining owning — compounding refusing (dispersion earning — pressure easing).

```typescript
// GOOD: bursts absorbing — signaled headers with informed retries (compiled + run live).
interface Verdict { // headers signaling — limits advertising, guessing declining
  ok: boolean;
  remaining: number;
  retryAfter: number;
}
function judge(used: number, cap: number, resetIn: number): Verdict {
  if (used < cap) return { ok: true, remaining: cap - used - 1, retryAfter: 0 }; // retries informing — waits quoting, hammering refusing
  return { ok: false, remaining: 0, retryAfter: resetIn }; // stampedes declining — herds dispersing, collapsing ending
}
const a = judge(3, 5, 30);
const b = judge(5, 5, 30);
const c = judge(9, 5, 30);
console.log(a.ok && a.remaining === 1 && !b.ok && b.retryAfter === 30 && !c.ok ? 'bursts absorb' : 'clients hammer');
```

## 3. Overload shedding (sheds prioritizing — degradations declaring — collapses declining)

**Definition** — graceful shedding: under overload dropping low-priority work first with declared degradations (sheds prioritizing — ranks ordering (critical serving — bulk deferring (prioritizing proving — random declining); degradations declaring — modes announcing (features trimming — clients adapting (declaring funding — surprising declining); collapses declining — cores protecting (cascades preventing — recovery bounding (declining owning — avalanching ending).

**What problem it solves** — the egalitarian-collapse trio: *sheds unprioritizing* (drops randoming — critical falling (ranks missing — value destroying (unprioritizing billing — importance ignoring); *degradations undeclaring* (modes hiding — features failing silently (clients confusing — retries amplifying (undeclaring charging — adaptation missing); *cores unprotecting* (sheds absenting — queues growing (latencies spiking — cascades avalanching (unprotecting costing — recovery unbounded). Prioritized sheds converting avalanching to degrading (ranks ordering — modes announcing (cores protecting — recovery bounding); reviewers finding shed order per service (shedding proving → verifiable; random → returned).

**Modern guidance** — the shedding lines per service (review-enforced): *sheds prioritizing* (ranks ordering — critical serving (bulk deferring — random declining (prioritizing proving — importance honoring (ranks owning — value defending); *degradations declaring* (modes announcing — features trimming (clients adapting — surprising declining (declaring funding — hiding refusing (modes owning — confusion ending); *collapses declining* (cores protecting — cascades preventing (recovery bounding — avalanching ending (declining owning — unbounded refusing (protection earning — trust keeping).

```typescript
// GOOD: overload shedding — priority-ordered sheds with declared modes (compiled + run live).
interface Job { // sheds prioritizing — ranks ordering, random declining
  id: string;
  prio: number;
}
function shed(queue: Job[], cap: number): { serve: string[]; drop: string[] } {
  const ranked = [...queue].sort((a, b) => b.prio - a.prio); // degradations declaring — modes announcing, surprising declining
  return {
    serve: ranked.slice(0, cap).map((j) => j.id),
    drop: ranked.slice(cap).map((j) => j.id), // collapses declining — cores protecting, avalanching ending
  };
}
const out = shed(
  [
    { id: 'bulk-export', prio: 1 },
    { id: 'checkout', prio: 9 },
    { id: 'health', prio: 10 },
  ],
  2,
);
console.log(out.serve.join() === 'health,checkout' && out.drop.join() === 'bulk-export' ? 'sheds prioritize' : 'drops randomize');
```
