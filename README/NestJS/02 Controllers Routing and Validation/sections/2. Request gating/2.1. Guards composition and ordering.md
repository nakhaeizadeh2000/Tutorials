## 1. Guards gate execution (contexts checking — roles deciding — denials throwing)

**What problem it solves** — the ungated trio: *auth scattering* (checks duplicating — handlers guarding (logic repeating — policies drifting (ownership missing — audits failing (security hoping — breaches inviting); *contexts blinding* (middleware guessing — handlers unknowing (targets missing — precision dying (decisions hoping — overgranting scheduling (blindness owning — incidents inviting); *denials varying* (rejections mixing — codes scattering (clients guessing — handling aching (uniformity failing — trust eroding (closure missing — discipline absenting). **Modern guidance** — the gate lines per route (review-enforced): *contexts checking* (requests inspecting — handlers knowing (execution owning — targeting proving (precision owning — bluntness declining (security serving — trust earning (checking owning — guessing declining); *roles deciding* (headers reading — memberships proving (access granting — strangers refusing (authorization owning — breaches declining (policy serving — audits easing (deciding owning — hoping declining); *denials throwing* (exceptions raising — statuses mapping (403 stating — clients handling (uniformity owning — guessing ending (closure serving — consistency holding (throwing owning — varying declining).

```typescript
// GOOD: guards gating — contexts checking, roles deciding, denials throwing (compiled + run live).
import 'reflect-metadata';
import { CanActivate, Controller, ExecutionContext, ForbiddenException, Get, Injectable, Module } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { FastifyAdapter } from '@nestjs/platform-fastify';

@Injectable()
class RolesGuard implements CanActivate {
  canActivate(ctx: ExecutionContext): boolean {
    const req = ctx.switchToHttp().getRequest() as any; // contexts checking — requests inspecting, handlers knowing
    if (req.headers['x-role'] === 'admin') return true; // roles deciding — memberships proving, access granting
    throw new ForbiddenException('admin only'); // denials throwing — statuses mapping, clients handling
  }
}

@Controller('admin')
class AdminController {
  @Get()
  panel(): object {
    return { panel: true };
  }
}

@Module({ controllers: [AdminController], providers: [RolesGuard] })
class AppModule {}

async function run(): Promise<void> {
  const app = await NestFactory.create(AppModule, new FastifyAdapter());
  app.useGlobalGuards(app.get(RolesGuard));
  await app.init();
  const http = app.getHttpAdapter().getInstance() as any;
  const ok = await http.inject({ method: 'GET', url: '/admin', headers: { 'x-role': 'admin' } });
  const no = await http.inject({ method: 'GET', url: '/admin' });
  console.log(ok.json().panel === true && no.statusCode === 403 ? 'gate holds' : 'guard broken');
  await app.close();
}
run();
```

// BAD: auth scattering — checks duplicating, contexts blinding, denials varying (real if-admin-in-handler shape).
// Per-handler header checks with bespoke 401/403/500 mixes (auth scattering — policies drifting — audits failing).
// Middleware guessing targets without ExecutionContext (contexts blinding — overgranting scheduling). Gate guards; throw denials; unify codes.)
```

**Common confusion** — *"guards are middleware (stages duplicating)."* Guards gating execution (contexts checking — handlers knowing (precision owning — targeting proving (authorization serving — breaches declining); middleware edging requests (functions running — next calling (edges owning — logging serving (context lacking — targeting missing (boundaries serving — cross-cutting owning); conflating costing misplacement (auth middlewareing — precision dying). "Middleware" describing edges (requests entering — responses exiting); guards describing gates (execution allowing — denials throwing). Edge middleware (logging serving — boundaries owning); gate guards (auth owning — execution knowing).

**Performance note** — gate economics: checking costing context reads (requests inspecting — handlers knowing (precision owning — trust earning); scattering costing branches (checks duplicating — policies drifting). Check cheaply (guards — contexts); gate always (routes — execution).

**Mentor note** — teach "guard the route, never the handler body" (juniors gating per route design protected execution on first hearing; inline role checks interrogated ("which guard?" — gating demanding per route). Gate one route once (contexts checking — denials throwing tangible (scattering ending — protecting holding permanently). // GOOD: composition ordering — global widening, controller narrowing, handler overriding (compiled + run live).
import 'reflect-metadata';
import { CanActivate, Controller, ExecutionContext, Get, Injectable, Module, UseGuards } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { FastifyAdapter } from '@nestjs/platform-fastify';

@Injectable()
class OpenGuard implements CanActivate {
  canActivate(_ctx: ExecutionContext): boolean {
    return true;
  }
}

@Injectable()
class ClosedGuard implements CanActivate {
  canActivate(_ctx: ExecutionContext): boolean {
    return false;
  }
}

@Controller('mixed')
@UseGuards(OpenGuard) // controller narrowing — subtree gating, ownership stating
class MixedController {
  @Get('open')
  open(): object {
    return { open: true };
  }
  @Get('shut')
  @UseGuards(ClosedGuard) // handler overriding — endpoints specializing, intent stating
  shut(): object {
    return { shut: true };
  }
}

@Module({ controllers: [MixedController], providers: [OpenGuard, ClosedGuard] })
class AppModule {}

async function run(): Promise<void> {
  const app = await NestFactory.create(AppModule, new FastifyAdapter());
  await app.init();
  const http = app.getHttpAdapter().getInstance() as any;
  const a = await http.inject({ method: 'GET', url: '/mixed/open' });
  const b = await http.inject({ method: 'GET', url: '/mixed/shut' });
  console.log(a.statusCode === 200 && b.statusCode === 403 ? 'composition holds' : 'composition broken');
  await app.close();
}
run();
```

"Replacing" describing swaps (layers dropping — gaps opening); NestJS describing composition (guards adding — denials compounding). Layer deliberately (coverage owning — gaps closing); never assume swaps (thinning declining — exposure ending).

**Performance note** — composition economics: layering costing guard runs (coverage deepening — precision rising (protection compounding — trust earning); gaping costing breaches (exposure inviting — incidents scheduling). Layer cheaply (guards — routes); compose always (layers — coverage).

**Mentor note** — teach "widen, narrow, override — in that direction" (juniors composing per layer design gapless coverage on first hearing; remembered-routes-only guarding interrogated ("global default?" — widening demanding per app). Compose one app once (global widening — handler overriding tangible (gaping ending — coverage holding permanently).
