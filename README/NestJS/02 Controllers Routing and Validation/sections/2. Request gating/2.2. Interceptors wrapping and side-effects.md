# 2.2. Interceptors wrapping and side-effects

## 1. Interceptors wrap calls (before entering — after mapping — errors replacing)

**Definition** — `NestInterceptor.intercept(ctx, next)`: RxJS operators around `next.handle()` — before entering, after mapping, errors replacing (before entering (requests observing — contexts reading (setup owning — downstream preparing (wrapping serving — handlers uncluttering (entry owning — clutter declining); after mapping (responses transforming — shapes standardizing (outputs owning — clients serving (uniformity proving — drift ending (mapping serving — consistency holding); errors replacing (failures catching — shapes mapping (throws translating — statuses choosing (closure owning — leaks declining (robustness serving — trust earning). Interceptors wrapping (before entering — after mapping (errors replacing — calls enclosing).

**What problem it solves** — the unwrapped trio: *handlers cluttering* (timing embedding — logging scattering (side-effects mixing — decisions blurring (concerns crossing — testing aching (wrapping missing — clarity eroding (focus hoping — discipline absenting); *responses drifting* (shapes varying — envelopes mixing (mapping hoping — clients branching (uniformity failing — trust eroding (standardizing missing — contracts breaking); *errors escaping* (throws leaking — shapes varying (replacing missing — clients guessing (closure failing — robustness hoping (mapping absenting — mastery doubting). Wrapping interceptors converting cluttering to entering (before observing — after mapping (errors replacing — handlers focusing); reviewers checking interceptor layers, not handler clutter (wrapping proving → verifiable; cluttering → returned).

**Modern guidance** — the wrap lines per app (review-enforced): *before entering* (requests observing — contexts reading (setup owning — downstream preparing (wrapping serving — handlers uncluttering (entry owning — clutter declining (observing owning — ignoring declining); *after mapping* (responses transforming — shapes standardizing (outputs owning — clients serving (uniformity proving — drift ending (mapping serving — consistency holding (transforming owning — drifting declining); *errors replacing* (failures catching — shapes mapping (throws translating — statuses choosing (closure owning — leaks declining (robustness serving — trust earning (replacing owning — escaping declining).

```typescript
// GOOD: interceptors wrapping — before entering, after mapping, errors replacing (compiled + run live).
import 'reflect-metadata';
import { CallHandler, Controller, ExecutionContext, Get, Injectable, Module, NestInterceptor, UseInterceptors } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { FastifyAdapter } from '@nestjs/platform-fastify';
import { Observable, tap } from 'rxjs';

@Injectable()
class TimingInterceptor implements NestInterceptor {
  intercept(_ctx: ExecutionContext, next: CallHandler): Observable<unknown> {
    const started = Date.now(); // before entering — requests observing, downstream preparing
    return next.handle().pipe(
      tap(() => {
        (globalThis as any).__took = Date.now() - started; // after mapping — responses transforming, outputs owning
      }),
    );
  }
}

@Controller('timed')
@UseInterceptors(TimingInterceptor)
class TimedController {
  @Get()
  ok(): object {
    return { ok: true };
  }
}

@Module({ controllers: [TimedController], providers: [TimingInterceptor] })
class AppModule {}

async function run(): Promise<void> {
  const app = await NestFactory.create(AppModule, new FastifyAdapter());
  await app.init();
  const http = app.getHttpAdapter().getInstance() as any;
  const r = await http.inject({ method: 'GET', url: '/timed' });
  console.log(r.json().ok === true && typeof (globalThis as any).__took === 'number' ? 'wrap holds' : 'intercept broken');
  await app.close();
}
run();
```

```typescript
// BAD: handlers cluttering — timing embedding, responses drifting, errors escaping (real fat-handler shape).
// Date.now + console.log + try/catch inside every handler (handlers cluttering — concerns crossing — testing aching).
// Per-handler response reshaping drifting apart (responses drifting — clients branching). Wrap interceptors; map centrally; replace errors.)
```

**Common confusion** — *"interceptors are middleware (wraps duplicating)."* Interceptors wrapping execution (before entering — after mapping (responses transforming — errors replacing (calls enclosing — handlers uncluttering (RxJS owning — results knowing (context enriching — mapping serving); middleware edging requests (functions running — next calling (edges owning — logging serving (results unknowing — mapping missing (boundaries serving — cross-cutting owning); conflating costing misplaced mapping (middleware transforming — results missing). "Middleware" describing edges (requests entering — responses exiting); interceptors describing wraps (calls enclosing — results mapping). Edge middleware (requests owning — boundaries serving); wrap interceptors (execution owning — results mapping).

**Performance note** — wrap economics: enclosing costing operator chains (before observing — after mapping (handlers focusing — clarity earning); cluttering costing duplication (timing embedding — logging scattering). Wrap cheaply (interceptors — operators); enclose always (calls — layers).

**Mentor note** — teach "wrap once, handle clean" (juniors wrapping per concern design uncluttered handlers on first hearing; handler-embedded timing interrogated ("which interceptor?" — wrapping demanding per concern). Wrap one concern once (before entering — after mapping tangible (clutter ending — focus holding permanently). Enter before; map after — wrap discipline in three habits, reviewed per concern.

## 2. Side-effects stay outside handlers (logging serving — caching returning — timing measuring)

**Definition** — handler-external side-effects: logging serving observability, caching returning repeats, timing measuring latency — all outside deciding logic (logging serving (requests recording — outcomes tracing (debugging funding — audits serving (visibility owning — blindness ending (operations proving — incidents easing); caching returning (repeats serving — computes skipping (latency cutting — loads declining (economy owning — waste ending (performance serving — scale funding); timing measuring (durations capturing — slowness naming (budgets proving — regressions catching (evidence owning — guessing ending (accountability serving — velocity sustaining). Side-effects externalizing (logging serving — caching returning (timing measuring — handlers deciding).

**What problem it solves** — the in-handler trio: *logging tangling* (prints embedding — formats varying (handlers branching — logic blurring (visibility hoping — consistency failing (tangling owning — audits aching (serving missing — blindness scheduling); *caching duplicating* (memo embedding — keys drifting (handlers guarding — freshness hoping (duplication scheduling — staleness inviting (returning hoping — economy missing (sharing absenting — waste compounding); *timing guessing* (durations assuming — slowness surprising (measuring missing — budgets hoping (evidence absenting — regressions hiding (accountability failing — velocity doubting). **Modern guidance** — the external lines per concern (review-enforced): *logging serving* (requests recording — outcomes tracing (debugging funding — audits serving (visibility owning — blindness ending (operations proving — incidents easing (serving owning — tangling declining); *caching returning* (repeats serving — computes skipping (latency cutting — loads declining (economy owning — waste ending (performance serving — scale funding (returning owning — duplicating declining); *timing measuring* (durations capturing — slowness naming (budgets proving — regressions catching (evidence owning — guessing ending (accountability serving — velocity sustaining (measuring owning — guessing declining).

```typescript
// GOOD: side-effects externalizing — logging serving, caching returning, timing measuring (compiled + run live).
import 'reflect-metadata';
import { CallHandler, Controller, ExecutionContext, Get, Injectable, Module, NestInterceptor, UseInterceptors } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { FastifyAdapter } from '@nestjs/platform-fastify';
import { Observable, of, tap } from 'rxjs';

let calls = 0;
@Injectable()
class CacheInterceptor implements NestInterceptor {
  private hit: unknown = undefined;
  intercept(_ctx: ExecutionContext, next: CallHandler): Observable<unknown> {
    if (this.hit !== undefined) return of(this.hit); // caching returning — repeats serving, computes skipping
    return next.handle().pipe(tap((v) => { this.hit = v; }));
  }
}

@Controller('cached')
@UseInterceptors(CacheInterceptor)
class CachedController {
  @Get()
  expensive(): object {
    calls += 1;
    return { n: calls }; // handlers deciding — logic owning, side-effects absenting
  }
}

@Module({ controllers: [CachedController], providers: [CacheInterceptor] })
class AppModule {}

async function run(): Promise<void> {
  const app = await NestFactory.create(AppModule, new FastifyAdapter());
  await app.init();
  const http = app.getHttpAdapter().getInstance() as any;
  const a = await http.inject({ method: 'GET', url: '/cached' });
  const b = await http.inject({ method: 'GET', url: '/cached' });
  console.log(a.json().n === 1 && b.json().n === 1 && calls === 1 ? 'cache holds' : 'cache broken');
  await app.close();
}
run();
```

```typescript
// In-handler memo objects with drifting keys per endpoint (caching duplicating — staleness inviting).
// console.time scattered with no aggregation (timing guessing — regressions hiding). Externalize interceptors; share caches; measure centrally.)
```

"Services" describing decisions (computes owning — freshness governing); interceptors describing responses (repeats serving — handlers deciding). Cache responses in interceptors (economy owning — latency cutting); memoize decisions in services (judgment owning — correctness holding).

**Performance note** — external economics: returning costing stored values (repeats serving — computes skipping (latency cutting — loads declining); duplicating costing recomputes (memo embedding — freshness hoping). Return cheaply (caches — repeats); externalize always (side-effects — interceptors).

**Mentor note** — teach "handlers decide, interceptors serve" (juniors externalizing per concern design testable handlers on first hearing; in-handler caching interrogated ("which interceptor?" — externalizing demanding per side-effect). Externalize one concern once (caching returning — handlers deciding tangible (tangling ending — deciding holding permanently). Serve outside; decide inside — external discipline in three habits, reviewed per handler.

```typescript
// GOOD: composition nesting — global widening, local narrowing, order stating (compiled + run live).
import 'reflect-metadata';
import { CallHandler, Controller, ExecutionContext, Get, HttpException, Injectable, Module, NestInterceptor, UseInterceptors } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { FastifyAdapter } from '@nestjs/platform-fastify';
import { Observable, catchError, throwError } from 'rxjs';

@Injectable()
class ReplaceInterceptor implements NestInterceptor {
  intercept(_ctx: ExecutionContext, next: CallHandler): Observable<unknown> {
    return next.handle().pipe(
      catchError(() => throwError(() => new HttpException({ error: 'downstream' }, 503))), // errors replacing — failures catching, shapes mapping
    );
  }
}

@Controller('fragile')
@UseInterceptors(ReplaceInterceptor) // local narrowing — subtree shaping, ownership stating
class FragileController {
  @Get()
  boom(): object {
    throw new Error('raw failure');
  }
}

@Module({ controllers: [FragileController], providers: [ReplaceInterceptor] })
class AppModule {}

async function run(): Promise<void> {
  const app = await NestFactory.create(AppModule, new FastifyAdapter());
  await app.init();
  const http = app.getHttpAdapter().getInstance() as any;
  const r = await http.inject({ method: 'GET', url: '/fragile' });
  console.log(r.statusCode === 503 && r.json().error === 'downstream' ? 'replace holds' : 'replace broken: ' + r.statusCode);
  await app.close();
}
run();
```
