# NestJS track (recommended order, October 2026 era)

Enterprise Node framework on TypeScript — NestJS from foundations to production: controllers, providers, modules, request lifecycle, data access, testing, and operations — from zero to hero and beyond (junior to mentor depth). Runs on the **Fastify adapter by default** throughout this track (same Fastify engine as the [Fastify track](<../Fastify/README.md>) — schema validation, hooks, and inject testing carry over; the Express adapter is never taught here). Decorator *mechanics* live in the [TypeScript track](<../TypeScript/README.md>) (TS 14); minimal-framework *contrast* lives in the [Express track](<../Express/README.md>). This track assumes working TypeScript + HTTP basics and teaches *NestJS*: what each layer owns, costs, and deserves. Version-sensitive claims are labeled (as of October 2026: NestJS 12.x stable, verified 12.1.2; TypeScript 5.9; Fastify 5.x under the adapter, verified 5.12.5).
