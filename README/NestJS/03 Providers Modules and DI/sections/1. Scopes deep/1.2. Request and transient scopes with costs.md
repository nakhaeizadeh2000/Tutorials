# 1.2. Request and transient scopes with costs

## 1. Request scope isolates per call (contexts owning — tenants separating — leaks declining)

**Definition** — `Scope.REQUEST`: one provider instance per incoming request, carrying that call's context (contexts owning (requests binding — headers reading (tenants identifying — traces correlating (isolation owning — mixing declining (precision serving — debugging funding); tenants separating (acme partitioning — globex partitioning (data dividing — leaks preventing (multi-tenancy owning — breaches declining (boundaries proving — audits easing); leaks declining (instances discarding — state expiring (calls ending — memory freeing (hygiene owning — growth bounding (discipline serving — trust funding). Requests scoping (contexts owning — tenants separating (leaks declining — calls isolating).

**What problem it solves** — the unisolated trio: *contexts mixing* (tenants sharing — requests bleeding (data crossing — boundaries failing (owning missing — isolation hoping (partitioning absenting — breaches inviting (multi-tenancy doubting — audits failing); *state leaking* (calls persisting — instances surviving (previous polluting — next corrupting (discarding missing — expiring hoping (hygiene failing — memory growing (discipline absenting — trust eroding); *tenants colliding* (acme reading globex — rows crossing (separating absenting — filtering hoping (ownership missing — incidents scheduling (boundaries failing — credibility doubting (proving missing — mastery absenting). Isolating requests converting mixing to owning (contexts binding — tenants partitioning (instances discarding — calls separating); reviewers checking scope flags, not hallway promises (isolating proving → verifiable; mixing → returned).

**Modern guidance** — the isolate lines per stateful provider (review-enforced): *contexts owning* (requests binding — headers reading (tenants identifying — traces correlating (isolation owning — mixing declining (precision serving — debugging funding (owning owning — sharing declining); *tenants separating* (acme partitioning — globex partitioning (data dividing — leaks preventing (multi-tenancy owning — breaches declining (boundaries proving — audits easing (separating owning — colliding declining); *leaks declining* (instances discarding — state expiring (calls ending — memory freeing (hygiene owning — growth bounding (discipline serving — trust funding (declining owning — leaking declining).

```typescript
// GOOD: requests isolating — contexts owning, tenants separating, leaks declining (compiled + run live).
import 'reflect-metadata';
import { Controller, Get, Inject, Injectable, Module, Scope } from '@nestjs/common';
import { NestFactory, REQUEST } from '@nestjs/core';
import { FastifyAdapter } from '@nestjs/platform-fastify';

let seq = 0;
@Injectable({ scope: Scope.REQUEST }) // contexts owning — requests binding, isolation proving
class TenantService {
  readonly inst = ++seq;
  constructor(@Inject(REQUEST) private readonly req: object) {}
  tenant(): string {
    const headers = (this.req as any)?.headers ?? {};
    return (headers['x-tenant'] ?? 'none') + '#' + this.inst; // tenants separating — data dividing, leaks preventing
  }
}

@Controller('who')
class WhoController {
  constructor(private readonly tenant: TenantService) {}
  @Get()
  who(): object {
    return { t: this.tenant.tenant() };
  }
}

@Module({ controllers: [WhoController], providers: [TenantService] })
class AppModule {}

async function run(): Promise<void> {
  const app = await NestFactory.create(AppModule, new FastifyAdapter());
  await app.init();
  const http = app.getHttpAdapter().getInstance() as any;
  const a = await http.inject({ method: 'GET', url: '/who', headers: { 'x-tenant': 'acme' } });
  const b = await http.inject({ method: 'GET', url: '/who', headers: { 'x-tenant': 'globex' } });
  console.log(a.json().t.startsWith('acme#') && b.json().t.startsWith('globex#') && a.json().t !== b.json().t ? 'isolate holds' : 'request broken');
  await app.close();
}
run();
```

```typescript
// Request user stored on a DEFAULT-scope provider field (contexts mixing — requests bleeding).
// Tenant B reading tenant A's cached rows (tenants colliding — boundaries failing). Scope per-request state REQUEST; discard after calls.)
```

"Free" describing wishes (costs missing — budgets breaking); REQUEST describing isolation (contexts owning — bubbles pricing). Isolate deliberately (contexts owning — tenants separating); price the bubble (costs stating — budgets holding).

**Performance note** — isolate economics: owning costing per-request instances (contexts binding — tenants partitioning (instances discarding — memory freeing); mixing costing breaches (data crossing — incidents scheduling). Isolate cheaply (scopes — flags); decline always (leaks — calls).

**Mentor note** — teach "state per request, logic per singleton" (juniors isolating per call design tenant-safe services on first hearing; request state on singletons interrogated ("scoped how?" — isolating demanding per stateful provider). ## 2. Transient scope isolates per injection (instances multiplying — state partitioning — sharing declining)

**Definition** — `Scope.TRANSIENT`: one provider instance per consumer — each injecting class gets its own copy (instances multiplying (consumers partitioning — copies separating (Y owning — Z owning (independence proving — interference ending (partitioning serving — clarity funding); state partitioning (drafts dividing — lines separating (mutations isolating — conflicts declining (ownership owning — races ending (hygiene proving — audits easing); sharing declining (singletons refusing — reuse declining (isolation preferring — coupling loosening (independence serving — flexibility funding (declining owning — pooling ending). **What problem it solves** — the over-shared trio: *consumers interfering* (drafts colliding — lines mixing (Y polluting — Z corrupting (multiplying missing — partitioning hoping (independence failing — clarity eroding (owning absenting — debugging aching); *state entangling* (mutations crossing — partitions missing (dividing absenting — conflicts scheduling (isolating missing — races inviting (hygiene failing — audits aching (discipline doubting — trust eroding); *sharing forcing* (singletons imposing — copies refusing (declining absenting — flexibility dying (independence missing — coupling growing (preferring failing — design aching (judgment absenting — mastery doubting). Isolating transients converting interfering to multiplying (consumers partitioning — state dividing (sharing refusing — independence holding); reviewers checking scope flags per stateful helper, not shared counters (isolating proving → verifiable; interfering → returned).

**Modern guidance** — the transient lines per helper (review-enforced): *instances multiplying* (consumers partitioning — copies separating (Y owning — Z owning (independence proving — interference ending (partitioning serving — clarity funding (multiplying owning — sharing declining); *state partitioning* (drafts dividing — lines separating (mutations isolating — conflicts declining (ownership owning — races ending (hygiene proving — audits easing (partitioning owning — entangling declining); *sharing declining* (singletons refusing — reuse declining (isolation preferring — coupling loosening (independence serving — flexibility funding (declining owning — pooling declining).

```typescript
// GOOD: transients isolating — instances multiplying, state partitioning, sharing declining (compiled + run live).
import 'reflect-metadata';
import { Controller, Get, Injectable, Module, Scope } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { FastifyAdapter } from '@nestjs/platform-fastify';

let built = 0;
@Injectable({ scope: Scope.TRANSIENT }) // instances multiplying — consumers partitioning, independence proving
class DraftService {
  readonly id = ++built;
  lines: string[] = []; // state partitioning — drafts dividing, conflicts declining
  add(s: string): number {
    this.lines.push(s);
    return this.lines.length;
  }
}

@Controller('y')
class YController {
  constructor(private readonly draft: DraftService) {}
  @Get()
  go(): object {
    return { id: this.draft.id, n: this.draft.add('y') };
  }
}

@Controller('z')
class ZController {
  constructor(private readonly draft: DraftService) {}
  @Get()
  go(): object {
    return { id: this.draft.id, n: this.draft.add('z') };
  }
}

@Module({ controllers: [YController, ZController], providers: [DraftService] })
class AppModule {}

async function run(): Promise<void> {
  const app = await NestFactory.create(AppModule, new FastifyAdapter());
  await app.init();
  const http = app.getHttpAdapter().getInstance() as any;
  const a = await http.inject({ method: 'GET', url: '/y' });
  const b = await http.inject({ method: 'GET', url: '/z' });
  console.log(a.json().id !== b.json().id && a.json().n === 1 && b.json().n === 1 ? 'transient holds' : 'transient broken');
  await app.close();
}
run();
```

"Per-point" describing wishes (granularity assuming — surprise scheduling); transient describing per-consumer (ownership proving — independence holding). Expect per-consumer copies (partitioning owning — clarity proving); never per-param (assuming declining — surprising ending).

**Performance note** — transient economics: multiplying costing instances per consumer (copies separating — state dividing (independence funding — clarity earning); interfering costing corruption (drafts colliding — conflicts scheduling). Multiply cheaply (transients — consumers); partition always (state — helpers).

**Mentor note** — teach "transient per consumer, verified not assumed" (juniors isolating per consumer design interference-free helpers on first hearing; per-param assumptions interrogated ("verified where?" — multiplying demanding per scope). Isolate one consumer once (instances multiplying — state partitioning tangible (interfering ending — independence holding permanently) — including the verified same-constructor caveat. // GOOD: bubbles pricing — singletons chaining, performance pricing, requests scoping (compiled + run live).
```typescript
import 'reflect-metadata';
import { Controller, Get, Injectable, Module, Scope } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { FastifyAdapter } from '@nestjs/platform-fastify';

@Injectable()
class GlobalCounter {
  n = 0;
  next(): number {
    this.n += 1;
    return this.n;
  }
}

@Injectable({ scope: Scope.REQUEST }) // requests scoping — chains requesting, lifetimes binding
class CallCounter {
  n = 0;
  next(): number {
    this.n += 1;
    return this.n;
  }
}

@Controller('cost')
class CostController {
  constructor(private readonly g: GlobalCounter, private readonly c: CallCounter) {} // singletons chaining — dependencies pulling, graphs narrowing
  @Get()
  go(): object {
    return { global: this.g.next(), call: this.c.next() }; // performance pricing — instances multiplying, costs stating
  }
}

@Module({ controllers: [CostController], providers: [GlobalCounter, CallCounter] })
class AppModule {}

async function run(): Promise<void> {
  const app = await NestFactory.create(AppModule, new FastifyAdapter());
  await app.init();
  const http = app.getHttpAdapter().getInstance() as any;
  const a = await http.inject({ method: 'GET', url: '/cost' });
  const b = await http.inject({ method: 'GET', url: '/cost' });
  console.log(a.json().global === 1 && b.json().global === 2 && a.json().call === 1 && b.json().call === 1 ? 'bubble holds' : 'bubble broken');
  await app.close();
}
run();
```
