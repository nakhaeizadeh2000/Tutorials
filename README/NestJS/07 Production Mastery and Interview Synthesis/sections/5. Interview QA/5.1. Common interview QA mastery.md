**What problem it solves** — the partial trio: *layers sampling* (controllers reciting — data unmentioned (composing absenting — wholes fragmenting (translating failing — deciding missing (flowing lacking — persisting missing (entry doubting — trust eroding (owning absenting — mastery missing); *delivery omitting* (gates unmentioned — probes undescribed (composing failing — wholes thinning (blocking absenting — answering missing (landing lacking — sealing missing (protecting failing — outages inviting (declining absenting — safety doubting); *pressure freezing* (whites blanking — questions stalling (composing missing — panic owning (holding failing — narratives dying (designing absenting — offers losing (narrating lacking — confidence failing). Designing systems converting sampling to composing (routes translating — data flowing (delivery gating — wholes holding); interviewers hearing vertical slices with prices, not layer names (composing proving → hirable; sampling → passed) — drawing on [§1.1](<../../sections/1. Full-system design/1.1. Full-system NestJS design.md>) and [§1.2](<../../sections/1. Full-system design/1.2. Full-system delivery design.md>).

**Modern guidance** — the answer lines per design (stated, not hoped): *routes composing* (translating naming — bounding describing (entry proving — trust earning (clarity owning — velocity funding); *data composing* (flowing stating — pairing describing (integrity proving — confidence earning (durability owning — trust holding); *delivery composing* (gating naming — answering describing (protecting proving — outages declining (safety owning — velocity keeping).

```typescript

// "Controllers translate with bound DTOs, services own queries with scoped transactions, delivery gates merges and deploys — sell/count round-trip proven live" (composing owning — evidence showing).
// "Contracts bound horizontally with enveloped errors, evidence dated per gate — wholes judged, never sampled" (earning owning — holding proving). References 1.1 + 1.2 numbers.)
```

**Common confusion** — *"system design is diagramming (boxes drawing)."* Design composing decisions (routes translating — data flowing (delivery gating — wholes holding (judgment owning — pressure surviving (wisdom serving — offers earning); diagramming drawing boxes (shapes arranging — arrows connecting (aesthetics owning — decisions missing (prettiness serving — rigor failing (drawing owning — proving absenting); conflating costing pretty ignorance (drawing admiring — composing missing). **Performance note** — design-answer economics: composing costing vertical stories (routes proving — data flowing (delivery gating — evidence showing (rigor owning — guessing ending); sampling costing offers (layers naming — wholes missing). Compose cheaply (stories — slices); hold always (wholes — systems).

**Mentor note** — teach "slice vertically, price horizontally" (juniors composing per system design hirable depth on first hearing; layer-name recitation interrogated ("flows how? priced where?" — composing demanding per answer). Compose one system once (routes composing — delivery composing tangible (sampling ending — holding staying permanently). Compose layers; bound contracts — design-answer discipline in three habits, rehearsed per question.
