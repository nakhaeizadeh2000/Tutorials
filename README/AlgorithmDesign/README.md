# Algorithm Design track (recommended order, September 2026 era)

Thinking in algorithms and choosing the best one — complexity analysis, sorting and searching, structural techniques, graphs, dynamic programming, and interview-grade problem solving (junior to mentor depth). Language mechanics live in the [JavaScript track](<../JavaScript/README.md>); this track teaches *how to think and measure*, and links out instead of re-teaching the language. Deliberately placed after the Git track so learners version-control their practice from day one.
