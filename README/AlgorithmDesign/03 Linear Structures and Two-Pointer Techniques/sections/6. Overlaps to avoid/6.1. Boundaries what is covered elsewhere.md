### 4) **Common confusion**

- "Linear techniques are where advanced algorithms live" — linear patterns are *foundational*; the advanced mechanics distribute across structures (04), graphs (05), and paradigms (06). This domain is the workhorse stable, not the whole ranch.
- "Boundaries leaves are filler" — they are the DRY contract made visible: each states what its domain deliberately does *not* teach so the repo can teach it once.

### 5) **Performance note**

No runtime cost to boundaries — the performance is editorial: one-line links instead of copied sections keep every leaf short, searchable, and single-sourced. When [Domain 04](<../../../04 Hashing Trees and Heaps/README.md>) changes hash guidance, one domain updates instead of seven.
