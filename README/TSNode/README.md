# TS-Node track (recommended order, September 2026 era)

The TypeScript execution layer for Node.js — how `.ts` files actually run on Node, from ts-node's load-time hooks to native type stripping — from zero to hero and beyond (junior to mentor depth). The pipeline survey lives in the [TypeScript track](<../TypeScript/README.md>); the Node runtime lives in the [Node.js track](<../NodeJS/README.md>). This track assumes both foundations and teaches the *operation*: installing, configuring, running, debugging, and shipping TypeScript on Node. Runtime-sensitive claims are labeled (as of September 2026: Node.js 24 is Active LTS, 22 Maintenance LTS, 26 Current; TypeScript 5.9 stable).
