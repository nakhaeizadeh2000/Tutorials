## 2. Latency differs from slowness (event-loop stalls vs slow commands — blocking vs executing, diagnosed separately, fixed differently)

## 3. Diagnose with data, fix the command (O(N) culprits replacing — SCAN paging, Lua bounding, never hoping)

**Definition** — the remediation contract: data naming culprits, commands changing (KEYS replacing with SCAN (O(N) paging — loops unblocking (traversal spreading — latency composing (diagnostics surviving — service serving); HGETALL bounding with HSCAN (hashes paging — fields streaming (payloads sizing — transfers capping (big hashes taming — loops freeing); Lua bounding (scripts timing — execution limiting (long scripts splitting — event loops freeing (monopolies ending — latency composing). **What problem it solves** — the unremediated trio: *KEYS in production* (full scans freezing (event loops held — clients hanging (diagnostics DoSsing — service sacrificing (availability attacking — housekeeping killing); *HGETALL unbounded* (megabyte hashes fetching (payloads ballooning — transfers choking (loops blocking — latency spiking (big fetching — service stalling); *Lua monopolizing* (scripts running long (event loops held — commands queuing (latency cliffing — monopolies official (execution unbounded — kill-switches missing). Fixed commands converting freezes to flows (SCAN paging — HSCAN streaming — Lua bounding (loops freeing — service serving); reviewers banning O(N)-unbounded, not O(N) (paging allowed — freezing returned).

**Modern guidance** — the remediation lines per culprit (review-enforced): *KEYS banning* (SCAN paging instead (cursors iterating — loops freeing (traversal spreading — service serving (diagnostics surviving — availability preserving); *HGETALL capping* (HSCAN streaming (payloads sizing — transfers capping (hashes paging — loops freeing (big taming — service flowing); *Lua bounding* (scripts splitting (execution limiting — loops freeing (monopolies ending — latency composing (timeouts configuring — kill-switches owning); *data driving* (SLOWLOG naming — culprits listing (evidence driving — fixes placing (remedies landing — incidents ending).
