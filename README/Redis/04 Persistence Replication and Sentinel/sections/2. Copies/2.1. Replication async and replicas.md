## 2. Resyncs reattach cheaply (partial PSYNC2 — brief disconnects replaying backlog, full syncs rare)

## 3. Reads scale, writes don't (replicas serving reads — write throughput single-primary, topology honest)

**Definition** — the scaling contract: replicas multiplying read capacity (READONLY members serving (stale-tolerable queries offloading — primaries unburdened (throughput multiplying — scaling linear-ish (replicas numbered — capacity planned); writes single-primary (mutations routing to master (replicas read-only (write throughput unscaled — primaries bounding (topology honest — sharding (Domain 05) scaling writes, never replicas); staleness priced per read (tolerable → replicas (sessions/profiles/caches — lag invisible); critical → primary (money/inventory — freshness required (routing explicit — staleness never hoped).

**What problem it solves** — the scale-mismatch trio: *writes fanning to replicas* (mutations misrouted (READONLY rejecting (errors serving — topology misunderstood (writes unscaled — attempts failing (scaling hoped); *critical reads stale* (money reading replicas (lag serving (staleness biting — freshness hoped (routing unexamined — tolerance missing); *primaries overloaded* (all reads primary-bound (replicas idling (capacity wasted — scaling unbought (offloading unconsidered — primaries bounding unnecessarily). Honest topology converting mismatch to routing (reads splitting (tolerance deciding — replicas serving; writes centralizing (primaries owning — throughput bounded); reviewers checking routes, not instances (routing stated → verifiable; unexamined → returned).

**Modern guidance** — the routing lines per workload (review-enforced): *tolerable → replicas* (staleness invisible (sessions/profiles/caches — lag priced (freshness unneeded — offloading structural); *critical → primary* (freshness required (money/inventory — recency guaranteed (routing explicit — staleness never risked); *writes → primary always* (mutations centralizing (replicas READONLY — attempts failing loudly (topology honest — scaling via Domain 05 (forward — unbuilt), never replica wishes); *lag budgets stated* (tolerance documented per read class (routers enforcing — mismatches returned (contracts structural).
