# 1.2. Full-system messaging design

## 1. Vehicles match loss tolerance (lists/streams/pubsub placed — contracts stated, never hoped)

**Definition** — the messaging whole: vehicles placed per signal across the system ([Domain 03 §1.2](<../../../03 Streams Queues and PubSub/sections/1. Streams/1.2. Vehicles matching (tolerance deciding — contracts stating — hope absenting (placements judging — recitations declining).

**What problem it solves** — the monovehicle trio: *one vehicle everywhere* (streams for heartbeats (ceremony pricing — value absenting (complexity taxing — ephemera slowing); lists for money (crashes losing — redrives manualing (losses discovering — durability hoping); pubsub for orders (offline missing — gaps reconciling (contracts unread — loss designing surprising). Matched vehicles converting monovehicles to fit (tolerance placing — contracts stating — hope absenting); reviewers checking vehicles per signal, not architectures (fit judging → verifiable; defaulted → returned).

**Modern guidance** — the vehicle lines per signal (review-enforced — composition, never repetition): *ephemeral → lists/pubsub* (loss tolerating — recomputation cheaping (freshness replacing — redelivery pointlessing (at-most-once expliciting — simplicity winning); *money → streams + groups* (loss bankrupting — history requiring (at-least-once expliciting — PEL tracking (redelivery managing — duplicates absorbing); *presence → pubsub* (connected receiving — offline missing (ephemerality expliciting — gaps expecting (replays never requesting — contracts honesting); *tolerance documenting* (contracts stating per signal — reviewers verifying fit (mismatches returning — messaging judging).

// Thumbnails → lists (re-driveable cheaply — at-most-once explicit — simplicity winning, ceremony declining)
// Orders → streams + groups + ACKs (history requiring — at-least-once explicit — durability pricing, losses impossible)
// Live ticks → pubsub (misses superseding — recovery naturing — ephemerality explicit, redelivery pointless)
// BAD: monovehicles — one everywhere, tolerance unexamined, contracts absent (real failure shapes).

// Lists for payments (crashes losing — durability hoping — losses discovering (money vanishing — recovery manualing).

**Common confusion** — *"one messaging primitive simplifies (uniformity reducing complexity)."* Uniformity misfitting (ephemera ceremoning — money risking (tolerance ignoring — contracts absenting (fit hoping — incidents teaching); fit simplifying operations (vehicles behaving — contracts holding (surprises declining — incidents preventing (clarity compounding — cognition easing); contracts unifying interfaces (semantics stating — tolerance documenting (clarity preserving — reviewers reading (vehicles varying — understanding holding). Vary vehicles (tolerance fitting — contracts stating); unify contracts (semantics stating — clarity preserving).

**Performance note** — vehicle economics: lists costing O(1) zero-ceremony (simplicity freeing — durability absenting); streams costing PEL + ACK + dedupe (durability pricing — losses impossibleing); pubsub costing O(receivers) transient (idle freeing — history absenting); monovehicles costing ceremony-without-value or losses-without-visibility (prices unbounded — incidents discovering). **Mentor note** — teach "loss tolerable?" per signal (juniors answering with vehicles design messaging fit on first hearing; unanswerable signals interrogated ("missed costs what?" — tolerance demanding per signal). Sort one workload once (ephemeral/money/presence placing — fit tangible (judgment visible — tolerance priced, never hoped). Match tolerance; state contracts — vehicle judgment in two habits, reviewed per signal.

## 2. Consumers survive crashes (groups tracking — idempotency absorbing, fencing ordering)

**Definition** — the survival whole: consumers outliving crashes across the pipeline ([Domain 03 §2.1](<../../../03 Streams Queues and PubSub/sections/2. Reliable consumption/2.1. **Modern guidance** — the survival lines per pipeline (review-enforced — composition, never repetition): *groups tracking* (XREADGROUP dividing — PEL recording (in-flight visibling — crashes surfacing (losses impossibleing — stalls claiming (work reassigning — liveness preserving); *handlers absorbing* (NX guarding — duplicates skipping (effects oncing — correctness holding (absorption structuraling — applied-twice impossibleing); *writers fencing* (tokens monotonicing — stale rejecting (ordering enforcing — zombies defanging (locks declining — coordination cheaping); *survival testing* (crash drilling — PEL redelivering (guards absorbing — fences rejecting (continuity proving — hope ending).

**Common confusion** — *"survival equals redundancy (more consumers surviving)."* Redundancy multiplying members (throughput dividing — parallelism scaling (capacity adding — crashes outlasting numerically (bodies counting — correctness unaddressing); survival guaranteeing continuity (PEL tracking — absorption holding (ordering enforcing — work continuing (mechanisms composing — crashes surviving structurally (correctness addressing — losses impossibleing); members without mechanisms multiplying fragility (duplicates doubling — zombies writing (redundancy harming — numbers hurting (bodies crashing — correctness breaking). **Mentor note** — teach "track, absorb, fence — every pipeline" (juniors composing per pipeline design surviving consumers on first hearing; throughput-only interrogated ("crash then?" — survival demanding per pipeline). ## 3. Broadcasts split deliberately (ephemeral vs durable — audiences choosing, never defaulting)

**What problem it solves** — the undivided-broadcast trio: *pubsub for catch-up* (late joining empty — history absenting (onboarding failing — replays impossibleing (audiences unserving — gaps permanenting (durability missing — ephemerality misplacing); *streams for ticks* (frames persisting — retention trimming endlessly (ceremony pricing — value absenting (pointlessness structuring — history burdening); *audiences unasked* (needs assuming — vehicles defaulting (tolerance unexamining — contracts absenting (fit hoping — incidents teaching). **Modern guidance** — the split lines per broadcast (review-enforced — composition, never repetition): *live ticking* (pubsub serving — connected receiving (ephemerality expliciting — gaps expecting (replays never requesting — recovery naturing (freshness replacing — redelivery pointlessing); *catch-up recording* (streams persisting — history replaying (durability composing — onboarding freeing (replays owning — audiences serving (late joining — gaps closing); *hybrids composing* (audiences splitting — needs distinguishing (vehicles pairing — boundaries cleaning (composition deliberate — duality designing (defaults declining — tolerance pricing); *audiences asking* (needs matching — vehicles choosing (contracts stating — fit judging (defaults interrogating — tolerance demanding).
