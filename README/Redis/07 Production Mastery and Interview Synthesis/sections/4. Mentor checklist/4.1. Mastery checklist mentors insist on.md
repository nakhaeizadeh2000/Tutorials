## 1. Every domain answers three questions (what/why/cost — judgments complete, never partial)

**Definition** — the completeness line on every domain: what + why + cost answered (what instructing ([Domain 01](<../../../01 Redis Foundations and Mental Model/README.md>) — structures naming (shapes describing — vocabulary owning (definitions grounding — usage enabling); why justifying (patterns/reasons composing ([Domain 02](<../../../02 Caching Patterns at Scale/README.md>)/[Domain 03](<../../../03 Streams Queues and PubSub/README.md>) — contracts stating (freshness pricing — tolerance deciding (decisions trading — coupling costing); cost pricing ([Domain 04](<../../../04 Persistence Replication and Sentinel/README.md>)/[Domain 05](<../../../05 Cluster and Partitioning/README.md>)/[Domain 06](<../../../06 Production Redis Operations/sections/1. Observe/1.1. Observability with INFO and metrics.md>) — windows numbering (losses bounding — throughput spending (honesty earning — safety costing). Three answering (judgments completing — partials declining (mastery proving — wisdom demonstrating).

**What problem it solves** — the partial-judgment trio: *what-only knowing* (commands listing — mechanics reciting (usage describing — reasons missing (decisions unjustifying — trade-offs hiding (knowledge shallow — judgment absenting); *why-only arguing* (reasons debating — costs ignoring (prices missing — budgets blowing (decisions floating — numbers absenting (rigor lacking — evidence missinging); *cost-only optimizing* (numbers cutting — value missing (worth ignoring — purposes forgetting (efficiency worshipping — effectiveness abandoning (savings counting — outcomes losing). Complete judgments converting partials to mastery (what grounding — why justifying — cost pricing); reviewers checking triples, not singles (judgments completing → verifiable; partial → returned).

**Modern guidance** — the triple lines per domain (review-enforced — capstone, never repetition): *what instructing* (structures naming — shapes describing (vocabulary owning — definitions grounding (usage enabling — foundations laying); *why justifying* (contracts stating — freshness pricing (decisions trading — coupling costing (reasons owning — trade-offs exposing); *cost pricing* (windows numbering — throughput spending (honesty earning — safety costing (budgets owning — numbers ruling); *triples checking* (reviews traversing ([3.1](<../../sections/3. Mentor capstone/3.1. Staff-level Redis review.md>) — layers stacking (judgment compounding — wisdom transferring (mastery demonstrating — partials declining).

```text
# GOOD: judgments completing — what grounding, why justifying, cost pricing (capstone, linked).
# Caching: structures serving (what) + aside staleness ≤TTL (why: freshness pricing) + misses priced (cost)
# Streams: groups tracking (what) + at-least-once honesty (why) + PEL RAM + dedupe lookups (cost)
# Cluster: slots splitting (what) + writes scaling (why) + moves trickling (cost) — triples completing, partials declining
```

```text

# Commands reciting sans reasons (decisions unjustifying — trade-offs hiding — knowledge shallowing (judgment absenting).

"Replacing" describing theater (boxes ticking — understanding missing); checklists describing scaffolds (thinking structuring — novices deciding). Scaffold thinking (checklists structuring — quality stabilizing); model traversal (mentors narrating — wisdom transferring).

**Performance note** — triple economics: whats costing definitions (structures naming — vocabulary owning (foundations laying — usage enabling); whys costing reasons (contracts stating — trade-offs exposing (decisions trading — rigor demonstrating); costs costing numbers (windows numbering — budgets owning (honesty earning — safety costing); partial equivalents costing shallow/ungrounded/wasteful judgment (knowledge shallowing — budgets blowing — outcomes losing). **Mentor note** — teach "what, why, cost — every domain, every review" (juniors tripling per domain design complete judgment on first practicing; single-answers interrogated ("other two?" — triples demanding per domain). ## 2. Every link resolves somewhere real (composition navigating — knowledge graphed, never stranded)

**Definition** — the integrity line on the whole track: every relative link resolving (94/94 D05, 101/101 D04, 108/108 D03, 85/85 D02-pattern echoes — sweeps verifying (script checking — unquote handling (spaces surviving — integrity proving); forwards landing (textual maturing — links arriving (boundaries living — maintenance owning (staleness declining — freshness keeping); graphs navigating (domains chaining — knowledge composing (readers traveling — understanding layering (immersion preserving — completeness composing). **Modern guidance** — the integrity lines per unit (review-enforced — hardest discipline in the track): *links resolving* (targets existing — references living (readers traveling — understanding layering (navigation working — trust earning (integrity proving — stranding absenting); *forwards landing* (textual maturing — links arriving (boundaries living — maintenance owning (handoffs completing — contracts honoring (ownership transferring — arrivals welcoming); *sweeps scripting* (checkers running — counts reporting (broken fixing — integrity proving (verification automating — trust earning (habit compounding — misses ending); *normalizing pre-committing* (regex anchoring — classes collapsing (remediation preventing — discipline institutionalizing (S2 lesson compounding — habit proving).
