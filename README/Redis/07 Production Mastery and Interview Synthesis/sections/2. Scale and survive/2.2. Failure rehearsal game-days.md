# 2.2. Failure rehearsal game-days

## 1. Scenarios script the scary (kill -9, failover, split-brain — failures scheduled, never surprising)

**Definition** — game-day scenarios: scripted failure rehearsals ([Domain 04 §3.1](<../../../04 Persistence Replication and Sentinel/sections/3. Crash truth/3.1. Crash semantics and durability windows.md>) mechanics + [Domain 06 §3.1](<../../../06 Production Redis Operations/sections/3. Runbooks/3.1. Scenarios scripting (failures scheduling — surprises declining (practice owning — incidents rehearsing).

**What problem it solves** — the unscripted-failure trio: *failures surprising* (incidents teaching — recovery improvising (steps inventing — quality varying (practice absenting — panic directing (procedures missing — drills nevering); *mechanics untested* (drills theorizing — kill -9 assuming (losses unmeasuring — totals unverifying (honesty claiming — evidence absenting (calibration unproving — confidence hoping); *procedures unpracticed* (runbooks shelving — steps reading never performing (owners naming never acting (rehearsals skipping — readiness feigning (paper proving — reality failing). Scripted scenarios converting surprise to rehearsal (failures scheduling — mechanics testing — procedures practicing); reviewers checking scenario calendars, not confidence (rehearsals scripting → verifiable; brave-hoping → returned).

**Modern guidance** — the scenario lines per quarter (review-enforced — program, never repeated mechanics): *kill -9 scripting* (ungraceful dying — buffers unflushing (windows testing — losses measuring (staging firsting — production graduating (practice scaling — confidence earning); *failover scripting* (promotions timing — redirects verifying (automation proving — elections realing (evidence freshing — succession completing); *split scripting* (partitions isolating — quorum gating (minorities forbidding — decisions backing (safety structuring — coherence holding); *scenarios versioning* (scripts owning — teams performing (knowledge persisting — improvisation declining (practice compounding — readiness growing).

```bash
# GOOD: scary scripting — kill scripting, failover scripting, split scripting (program, linked).
# Q-game-day: kill -9 primary staging → measure loss vs windows (mechanics testing — totals verifying, honesty earning)
# Q-game-day: partition primary from replicas → quorum gating observed (minorities forbidding — decisions backing)
# Q-game-day: failover drill timed → succession completing (automation proving — evidence freshing, confidence earning)
```

```bash
# BAD: failures surprising — scenarios unscripting, mechanics untesting, procedures unpracticing (real failure shapes).
# Incidents teaching first (recovery improvising — steps inventing — quality varying (practice absenting — panic directing).
# Drills theorizing (losses unmeasuring — totals unverifying — honesty claiming (evidence absenting — calibration unproving).
# Runbooks shelving (rehearsals skipping — readiness feigning — paper proving (reality failing). Script; test; practice.)
```

**Common confusion** — *"game-days are chaos engineering (randomness testing)."* Chaos randomizing (failures injecting blindly — hypotheses missing (learning hoping — surprises compounding (experiments gambling — knowledge scattering); game-days scripting (scenarios planning — mechanics testing (hypotheses stating — learning directing (experiments designing — knowledge compounding); maturity graduating (staging proving — production planning (blast radii bounding — rollbacks readying (discipline scaling — risk managing). "Chaos" describing randomness (injections blinding — hypotheses missing); game-days describing rehearsals (scenarios scripting — learning directing). Script scenarios (hypotheses stating — learning directing); graduate maturity (staging proving — production planning).

**Performance note** — scenario economics: scripting costing planning hours (failures scheduling — surprises declining (practice owning — incidents rehearsing); staging costing environment time (mechanics testing — totals verifying (honesty earning — confidence building); graduating costing risk management (blast radii bounding — rollbacks readying (discipline scaling — maturity growing); surprising equivalents costing outages teaching (recovery improvising — panic directing). Script cheaply (hours — surprises declining); graduate deliberately (risk managing — maturity growing).

**Mentor note** — teach "schedule the scary before it schedules you" (juniors scripting per quarter design rehearsed readiness on first hearing; brave-hoping interrogated ("rehearsed when?" — scenarios demanding per quarter). Run one game-day once (kill -9 staging measuring — losses verifying (rehearsal tangible — readiness proven, never hoped). Script scenarios; version scripts — scenario discipline in two habits, reviewed per quarter.

## 2. Cadence compounds confidence (quarterly rehearsals — evidence freshening, drills evolving)

**Definition** — rehearsal cadence: recurring drills compounding readiness (quarterly scheduling — evidence freshening (procedures proving — confidence earning (demonstrations recurring — honesty continuing (systems evolving — proof refreshing); drills evolving (scenarios hardening — findings fixing (gaps closing — systems improving (reviews acting — evidence compounding (practice deepening — readiness growing); calendars owning (dates scheduling — owners naming (accountability assigning — rehearsals happening (aspirations executing — intentions realizing). **What problem it solves** — the one-off-drill trio: *drills dating* (rehearsals aging — systems evolving (procedures expiring — evidence perishing (confidence decaying — demonstrations lapsing (honesty historying — proof failing); *findings shelving* (gaps discovering — fixes postponing (reviews noting — actions missing (drills performing — improvements skipping (practice wasting — readiness stalling); *calendars wishing* (rehearsals aspiring — dates unscheduling (owners unnaming — accountability diffusing (intentions floating — executions missing (aspirations hoping — reality skipping). **Modern guidance** — the cadence lines per organization (review-enforced): *quarterlies scheduling* (rehearsals recurring — evidence freshening (procedures proving — confidence earning (demonstrations continuing — honesty renewing (systems evolving — proof refreshing); *findings closing* (gaps fixing — systems hardening (reviews acting — evidence compounding (practice deepening — readiness growing (drills evolving — scenarios hardening); *owners calendaring* (dates scheduling — accountability assigning (rehearsals happening — aspirations executing (intentions realizing — executions owning (ownership explicit — action guaranteeing); *maturity tracking* (quarters comparing — readiness trending (confidence graphing — drills grading (evolution visualizing — readiness proving).

**Common confusion** — *"cadence equals bureaucracy (meetings multiplying)."* Bureaucracy performing process (ceremonies observing — outcomes missing (rehearsals staging — findings shelving (practice wasting — readiness stalling (process theatering — value absenting); cadence compounding evidence (drills executing — findings closing (systems hardening — readiness growing (outcomes improving — value proving (practice deepening — confidence earning); calendars executing accountability (dates scheduling — owners naming (rehearsals happening — aspirations realizing (intentions executing — executions owning). "Bureaucracy" describing theater (process observing — outcomes missing); cadence describing compounding (evidence freshening — findings closing). **Performance note** — cadence economics: quarterlies costing staging hours (evidence freshening — procedures proving (confidence earning — demonstrations recurring); findings costing fix effort (systems hardening — reviews acting (evidence compounding — practice deepening); calendars costing scheduling (accountability assigning — rehearsals happening (aspirations executing — executions owning); dating equivalents costing decayed confidence (systems evolving — proof failing). **Mentor note** — teach "drills expire like milk, not wine" (juniors scheduling per quarter design fresh evidence on first hearing; story-drills interrogated ("dated when?" — recurrence demanding per drill). ## 3. Blast radii graduate (staging first, production planned — maturity growing, never assuming)

**Definition** — blast-radius graduation: rehearsal scope expanding with maturity (staging firsting (practice safing — procedures owning (confidence earning — graduation earning (evidence building — readiness proving); production planning (blast bounding — rollbacks readying (impact containing — stakeholders informing (risk managing — maturity demonstrating (discipline scaling — confidence spending); maturity growing (quarters compounding — scopes expanding (evidence accumulating — readiness proving (graduation earning — assumption ending). **What problem it solves** — the ungraduated trio: *production-first drilling* (blast unbounding — customers impacting (rollbacks missing — stakeholders surprising (risk unmanaged — maturity assumed (discipline skipping — confidence spending unearned); *staging-only forever* (scopes capping — production differing (realism missing — confidence capping (graduation fearing — maturity stalling (practice sandboxing — readiness theoreticaling); *radii unowned* (scopes unbounding — impacts uncontaining (blast spreading — stakeholders blindsiding (risk hoping — maturity performing (discipline theatering — confidence feigning).
