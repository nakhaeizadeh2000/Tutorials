# Redis track (recommended order, September 2026 era)

Caching & data structures for huge apps — Redis from foundations to production: structures, expiry, caching patterns, streams, persistence, clustering, and operations — from zero to hero and beyond (junior to mentor depth). Relational *modeling* lives in the [Database Design track](<../DatabaseDesign/README.md>); data-access *layers* live in the [ORM track](<../ORM/README.md>); raw driver mechanics live in Databases 04. This track assumes working data structures and teaches *Redis*: what each structure owns, costs, and deserves. Version-sensitive claims are labeled (as of September 2026: Redis 8.0.2 stable; node-redis 6.3.0; ioredis 6.0.0).
