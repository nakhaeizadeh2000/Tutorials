## 7.1. Boundaries — what is covered elsewhere

### 1) **JavaScript runtime mechanics** (closure, hoisting, `this` binding, `arguments`) — [JavaScript 02 Functions](<../../../../JavaScript/05 Functions Deep Dive/README.md>)

This domain owns the *static* callable-type model — call signatures, params, overloads, `this: T`, variance, predicates. Runtime `this` binding rules, closure capture, hoisting, and `arguments` object live in [JavaScript 02 Functions](<../../../../JavaScript/05 Functions Deep Dive/README.md>) — link there for execution semantics; here for type contracts.

```typescript
// type-level (this domain) — call signature and explicit this
type Handler = (this: { id: string }, x: number) => string;
// runtime (JS domain) — how this is bound at call site
function handler(this: { id: string }, x: number): string { return this.id + String(x); }
handler.call({ id: "u1" }, 42); // runtime binding per JS rules
```

### 2) **Classes and `this` in OO** (constructors, private fields, method decorators) — [06 Classes and Object-Oriented Types](<../06 Classes and Object-Oriented Types/README.md>) (textual forward)
