## 1.3. History and 5.6 Era (what is stable now)

### 1) **Version** (5.6 as of Aug 2026)

**Definition** — As of August 2026 the stable line is TypeScript **5.6** (released July 2024, patch 5.6.3 current). The track labels itself "5.6 era" per `PROMPT.md:15` — meaning every claim is checked against 5.6 Handbook + release notes, with version-specific callouts where behavior changed.

Timeline (condensed):

- 2012 TS 0.8 open-sourced (Microsoft). 2014 TS 1.0, 2016 TS 2.0 (`strictNullChecks`), 2018 TS 3.0 (`unknown`, `in` narrowing), 2020 TS 4.0 (variadic tuples), 2022 TS 4.7 (`in`/`out` variance), 4.9 (`satisfies`), 2023 TS 5.0 (decorators stage-3, `const` type params), 5.2 (`using`), 2024 TS 5.5 (inferred type predicates), **5.6** — Iterator helpers typing (`--lib esnext`), stricter `--noUncheckedIndexedAccess` interactions, optimized `tsc --build` incremental.

### 2) **Comparison** (roadmap.sh vs Handbook)

Two legitimate roadmaps, different purposes:

| Source | What it optimizes | Strength | Weakness |
|--------|-------------------|----------|----------|
| **TypeScript Handbook** (typescriptlang.org) | Correctness & completeness | Authoritative on every type feature, with version notes | Linear reference — weak on "what to learn when" |
| **roadmap.sh TypeScript** | Learning order & production stack | Visual progression fundamentals → config → tooling → migration | Opinionated ordering; occasionally lags handbook on newest flags |

**How this track reconciles them:** curriculum follows Handbook's progression (types → functions → classes → advanced → modules → config) but uses roadmap.sh for *boundaries* (e.g., roadmap places ESLint/Biome/type-testing under Tooling — this track mirrors that as domain `09`, not inside `08` build). Where they conflict, Handbook wins on semantics; roadmap wins on sequencing.

**Research notes**: verified against TS 5.6 release notes (iterator helpers, `noUncheckedIndexedAccess` docs), Handbook "Conditional Types" and "Module Resolution" pages, and `typescript@5.6.3` lib definitions for `Iterator` helpers.

### Mentor note

Version-label every blog post and slide. Students waste weeks debugging "why doesn't `using` compile?" — answer is always `target`/`lib`. Teach them to read `tsc --version` + `lib` + `target` as a triple.

### Common confusion

- "Latest TS = latest JS" — no. TS `target` controls emitted JS; TS version controls checking. You can run TS 5.6 emitting ES2017.
- "roadmap.sh covers everything" — roadmap is *sequence*, handbook is *truth*; check both.
