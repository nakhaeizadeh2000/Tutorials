## 7.1. Boundaries — What Is Covered Elsewhere

### 1) **Definition** (where this domain stops)

**Definition** — This domain (Fundamentals, Mental Model, Toolchain) owns erasure, structural typing concept, and toolchain orientation. It **stops** before detailed types, modules, and config/build — those live in siblings.

- **Owns:** what TS is, why types matter, history 5.6 era, structural vs nominal, erasure, `tsc` vs `tsx` vs `ts-node` choice.
- **Does not re-teach:** primitives/literals, unions/intersections, objects/interfaces, functions/overloads, classes/generics, advanced types, modules/declarations, `tsconfig`, lint/type-tests, migration/runtime.

### 2) **Comparison** (sibling domains)

- Primitives, literals, `as const`, unions/intersections, narrowing → [02 Primitive Literal and Union Types](<../../../02%20Primitive%20Literal%20and%20Union%20Types/README.md>) — `02/1`, `02/2`, `02/3`.
- Objects, `object` vs `Object` vs `{}`, `interface` vs `type`, excess freshness → [03 Objects Interfaces and Type Aliases](<../../../03%20Objects%20Interfaces%20and%20Type%20Aliases/README.md>).
