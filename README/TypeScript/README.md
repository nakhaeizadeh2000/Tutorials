# TypeScript track (recommended order, TypeScript 5.9 era)

Typed JavaScript — the type system, tooling, and production patterns built on top of JavaScript — from zero to hero and beyond (junior to mentor depth). Plain JavaScript mechanics live in the [JavaScript track](<../JavaScript/README.md>); this track assumes that foundation and adds static types. Runtime claims labeled (as of September 2026: TypeScript 5.9 stable, 6.0 beta; Node.js 24 Active LTS, 22 Maintenance LTS).
