# TypeScript track

Typed JavaScript — the type system, tooling, and production patterns built on top of JavaScript — from zero to hero and beyond (junior to mentor depth). Plain JavaScript mechanics live in the [JavaScript track](<../JavaScript/README.md>); this track assumes that foundation and adds static types. The verified compiler baseline is TypeScript 7.0.2 (2026-10-12), following the [stable 7.0 release](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/). Individual examples declare their tested runtime/compiler versions; older release examples remain identified where relevant. Returning readers can start with the [7.0 configuration migration](<25 Update TypeScript 7.0/sections/1. Configuration Migration/1.1. Configuration defaults and removed options.md>). New learners can use the [current learning route](<25 Update TypeScript 7.0/sections/6. Overlaps and Update Route/6.1. Overlaps and the current learning route.md>) at the appropriate prerequisites. All six 7.0 update lessons are published. The approved full-track review and repairs were completed on 2026-10-18; see the [verified outcomes and complete lesson inventory](<DOCUMENTATION_REVIEW_2026-10-18_32.md>).
