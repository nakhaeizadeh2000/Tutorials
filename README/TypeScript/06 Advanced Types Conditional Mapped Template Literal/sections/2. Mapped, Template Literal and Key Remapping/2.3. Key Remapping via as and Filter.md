## 2.3. Key Remapping via as and Filter

### 1) **Definition** (as never)

**Definition** — `as` in a mapped type remaps the output key: `{ [K in keyof T as NewKey]: ... }`. Mapping to `never` *filters* that property out.

```typescript
type User = { id: string; name: string; age: number; password: string };

// remap keys via template + intrinsic
type Getters = { [K in keyof User as `get${Capitalize<string & K>}`]: () => User[K] };
// { getId: ()=>string; getName ... }

// filter via never
type OmitPassword = { [K in keyof User as K extends "password" ? never : K]: User[K] };
// { id: string; name: string; age: number }
type _Omit = Omit<User, "password">; // same — built-in uses as never

// change shape while filtering
type PublicUser = { [K in keyof User as K extends `password` ? never : K]: User[K] };
let pub: PublicUser = { id: "1", name: "Ava", age: 30 }; // password excluded
```

### 2) **Example** (Omit by pattern)

```typescript
// omit private-like keys (_ prefix) by pattern
type StripPrivate<T> = { [K in keyof T as K extends `_${string}` ? never : K]: T[K] };
type WithPrivate = { name: string; _secret: string; age: number };
type Clean = StripPrivate<WithPrivate>; // { name: string; age: number }

// prefix filter
type ExtractByPrefix<T, Prefix extends string> = { [K in keyof T as K extends `${Prefix}${string}` ? K : never]: T[K] };
type Pref = ExtractByPrefix<{ getName: () => void; getAge: () => number; name: string }, "get">; // { getName, getAge }

// remap to kebab
type Kebab<S extends string> = S extends `${infer Head}${infer Tail}` ? Head extends Uncapitalize<Head> ? `${Head}${Kebab<Tail>}` : `-${Lowercase<Head>}${Kebab<Tail>}` : S; // sketch recursive

// built-in key remapping utils all use as
// PickByValue<T, V> = { [K in keyof T as T[K] extends V ? K : never]: T[K] }
type PickByValue<T, V> = { [K in keyof T as T[K] extends V ? K : never]: T[K] };
type StringsOnly = PickByValue<User, string>; // { id, name, password } (string members)
```

### 3) **Expert** (as filter)

**Expert tips:**

- Filtering with `never` removes key from output type entirely (not optional `never`).
- Combine `as` with conditional + `infer` for data-driven remapping (e.g., strip `Api` suffix).
- Use `Exclude`/`Extract` on keys vs remapping — `as` remaps per property, `Exclude` filters key unions.

```typescript
// conditional filter + transformation
type ToOptional<T, K extends keyof T> = { [P in keyof T as P extends K ? P : never]?: T[P] } & { [P in keyof T as P extends K ? never : P]: T[P] };
// or built-in Partial/Pick combo

// discriminate helper
type NonNullKeys<T> = { [K in keyof T as T[K] extends null ? never : K]: T[K] };

// as never vs optional never
type FilterNever = { [K in "a"|"b" as K extends "a" ? never : K]: number }; // { b: number } — a gone, not { a?: never }

// performance: remapping over huge keyof (e.g., lib.dom keys) can be expensive — keep helper generic shallow
```

### Mentor note

Show the `never` filter trick as "mapped type + conditional = pick." Once students see `K extends "password" ? never : K` they stop manually writing `Omit` loops.

### Common confusion

- "`as` changes runtime key" — no, erased. It's type-level rename only.

### Performance note

Excessive key-remapping with recursive template distributes over large unions — keep recursion bounded; `tsc` flag `noErrorTruncation` hides blow-ups, watch build time.
