## 2.2. Template Literal Types and Intrinsic

### 1) **Definition** (`on${Cap}`)

**Definition** — Template literal types combine string literals at type level: `` `on${Capitalize<string>}` `` produces `"onFoo"` for any `"foo"`. Combined with mapped `as`, they generate API surfaces from a base union.

```typescript
type EventName = "click" | "scroll" | "mousemove";
type OnKey = `on${Capitalize<EventName>}`; // "onClick" | "onScroll" | "onMousemove"

type Props = { [K in EventName as OnKey]: () => void };
// { onClick: () => void; onScroll: ...; onMousemove: ... }

// general helper
type Prefixed<K extends string, P extends string> = `${P}${K}`;
type X = Prefixed<"name" | "age", "get">; // "getname" | "getage" — use Capitalize to fix casing

type WithPrefix = `get${Capitalize<"name" | "age">}`; // "getName" | "getAge"
```

Intrinsic string manipulators (built-in, evaluated by checker):

- `Uppercase<S>`, `Lowercase<S>`, `Capitalize<S>`, `Uncapitalize<S>`.

### 2) **Example** (event names)

```typescript
// event map from literal union
type Events = "user:created" | "user:deleted";
type HandlerName = `handle${Capitalize<Events extends `${infer Before}:${infer After}` ? `${Capitalize<Before>}${Capitalize<After>}` : never>}`;
// but simpler practical:
type HandlerMap<T extends string> = { [K in T as `on${Capitalize<K>}`]: (payload: unknown) => void };
type AppEvents = HandlerMap<"create" | "delete">; // { onCreate, onDelete }

// discriminated helper for CSS-like
type Size = "sm" | "md" | "lg";
type Color = "red" | "blue";
type ClassName = `${Size}-${Color}`; // "sm-red" | "sm-blue" | ...
let cls: ClassName = "md-red"; // ok

// infer helper inside template (pattern parse — ties to 1.2)
type ExtractRouteParam<S> = S extends `${string}:${infer Param}/${infer Rest}` ? Param | ExtractRouteParam<Rest> : S extends `${string}:${infer Param}` ? Param : never;
type P = ExtractRouteParam<"/user/:id/post/:postId">; // "id" | "postId"

// with intrinsic
type Header = `X-${Uppercase<string>}`;
let h: Header = "X-REQUEST-ID"; // ok (Uppercase check is permissive — any uppercase string)
```
