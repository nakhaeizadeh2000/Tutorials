## 3.1. Utility Types (Partial, Required, Pick, Omit, etc.)

### 1) **Catalog** (built-ins)

Complete catalog (all zero-emit, from `lib.es5.d.ts` + newer libs):

| Utility | Purpose | Implementation sketch |
|---------|---------|------------------------|
| `Partial<T>` | all props optional | `{ [K in keyof T]?: T[K] }` |
| `Required<T>` | all required | `{ [K in keyof T]-?: T[K] }` |
| `Readonly<T>` | all readonly | `{ readonly [K in keyof T]: T[K] }` |
| `Pick<T, K>` | subset | `{ [K in K]: T[K] }` |
| `Omit<T, K>` | exclude keys | `Pick<T, Exclude<keyof T, K>>` (uses `as never`) |
| `Exclude<T, U>` | filter union | `T extends U ? never : T` (distributive) |
| `Extract<T, U>` | keep union | `T extends U ? T : never` |
| `NonNullable<T>` | strip `null\|undefined` | `T extends null \| undefined ? never : T` |
| `ReturnType<T>` | fn return | `T extends (...args: unknown[])=>infer R ? R : never` |
| `Parameters<T>` | fn params | `T extends (...args:infer P)=>unknown ? P : never` |
| `InstanceType<T>` | `new` instance | `T extends new (...args: unknown[])=>infer I ? I : never` |
| `Awaited<T>` | unwraps `Promise` recursively | `T extends Promise<infer U> ? Awaited<U> : T` |
| `Record<K,V>` | dict | `{ [K in K]: V }` |

```typescript
type User = { id: string; name: string; age: number; email: string; };
type Patch = Partial<User>;
type JustName = Pick<User, "name" | "email">;
type WithoutAge = Omit<User, "age">;
type Strings = Extract<"a" | 1 | "b", string>; // "a"|"b"
type NoNull = NonNullable<string | null | undefined>; // string
declare function fetchUser(id: string): Promise<User>;
type Fetched = Awaited<ReturnType<typeof fetchUser>>; // User
type FetchParams = Parameters<typeof fetchUser>; // [id: string]
```

### 2) **Example** (Pick vs Extract)

Confusion pair:

```typescript
type A = "a" | "b" | 1 | 2;
type Keys = { a: string; b: number; c: boolean };
type K = keyof Keys; // "a"|"b"|"c"

// Pick works on object keys — picks properties from object type
type Picked = Pick<Keys, "a" | "b">; // { a: string; b: number }
// Pick<union, never> misuse: Pick doesn't operate on unions directly

// Extract / Exclude work on unions — filters members
type Extracted = Extract<A, string>; // "a"|"b"
type Excluded = Exclude<A, number>;  // "a"|"b"

// common pattern: Awaited + ReturnType chain
async function load(): Promise<{ id: string }> { return { id: "1" }; }
type Loaded = Awaited<ReturnType<typeof load>>; // { id: string }
type LoadedArray = Awaited<ReturnType<typeof load>[]>; // careful — ReturnType of array? Use Elem helper (1.2)
```

### 3) **Bad** (re-implementing badly)

```typescript
// bad: hand-rolled Omit that forgets homomorphic preservation
type BadOmit<T, K> = { [P in keyof T]: T[P] } & { K: never }; // nonsense

// bad: duplicating Pick manually — drifts
type Manual = { name: string; email: string }; // instead of Pick<User, "name"|"email">

// bad: using any for "strip undefined"
type BadNonNull<T> = T extends any ? T : never; // any leaks — use NonNullable
// good: library types
type Clean = NonNullable<string | null>; // string

// bad: Awaited misuse without recursive
type ShallowAwaited<T> = T extends Promise<infer U> ? U : T;
type S1 = ShallowAwaited<Promise<Promise<string>>>; // Promise<string> — not fully unwrapped, use built-in Awaited
type Good = Awaited<Promise<Promise<string>>>; // string
```

### Mentor note

Ban hand-rolled `MyOmit` when built-in `Omit` suffices — review checklist: "did you duplicate a lib utility?" Exception only for performance-tuned deep utility that changes semantics.

### Common confusion

- "`Pick` vs `Extract`" — `Pick` picks *props* from object; `Extract` keeps *members* from union.
- "`Omit` with string literal doesn't error if key missing" — `Omit<T, K>` with `K` not in `keyof T` silently does nothing (since `Exclude` yields `never` on missing).

### Performance note

Deeply nested utility chains (`Partial<Pick<Omit<...>>>`) cost checker time. Keep depth <4 or cache intermediate via `type Mid = Omit<User, "age">`.
