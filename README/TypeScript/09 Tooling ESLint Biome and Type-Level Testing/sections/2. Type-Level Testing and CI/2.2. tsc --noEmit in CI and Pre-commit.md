## 2.2. tsc --noEmit in CI and Pre-commit

### 1) **Pipeline** (typecheck)

**Definition** — `tsc --noEmit` typechecks without emitting — the source of truth for types. Run it in CI (and optionally pre-commit watch). `tsc --build` variant honors project references incremental cache.

```
CI:  biome check → tsc --noEmit → eslint (typed) → vitest → build
 ^-- fast fail    ^-- type gate    ^-- promise gate   ^-- runtime
```

```yaml
# .github/workflows/ci.yml
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - run: npm ci
      - run: npm run lint        # biome check
      - run: npm run typecheck   # tsc --noEmit (or --build)
      - run: npm run test -- --run
      - run: npm run build       # tsc --build or vite build (emit)
```

```jsonc
// package.json
{
  "scripts": {
    "typecheck": "tsc --noEmit",
    "typecheck:watch": "tsc --noEmit --watch",
    "lint": "biome check ./src",
    "lint:typed": "eslint --max-warnings=0 ./src"
  }
}
```

### 2) **Example** (husky)

```bash
# .husky/pre-commit (lint-staged)
#!/usr/bin/env sh
. "$(dirname -- "$0")/_/husky.sh"
npx lint-staged

# lint-staged.config.js
export default {
  "*.ts": ["biome check --write --staged", "eslint --max-warnings=0 --fix --staged"],
  "*.ts": ["tsc --noEmit --pretty --incremental false"] // optional — heavy, many teams skip pre-commit typecheck and rely on CI
}
```

```typescript
// typecheck-only guard file (src/_typecheck.ts) — optional aggregate
import { expectTypeOf } from "expect-type";
import type { User } from "./models.js";
expectTypeOf<User>().toHaveProperty("id");
// tsc --noEmit will fail this file if User shape breaks — catches without runtime
```

### 3) **Mistake** (skip typecheck)

**Bad — skipping typecheck in CI:**

```typescript
// bad ci: only build, never tsc --noEmit alone
// "build": "vite build" — vite uses esbuild (transpile only), so type errors slip to deploy
// vite build succeeded but tsc error: Property 'email' missing — bug shipped

// bad: pre-commit heavy tsc --noEmit blocks commits 10s each — devs bypass --no-verify
// fix: run tsc --noEmit in CI required (blocking), pre-commit only lint + quick check if references incremental

// bad: caching missing — tsc runs cold each CI
// fix: cache .tsbuildinfo + node_modules
// actions/cache: key: ${{ hashFiles('**/tsconfig.json', '**/pnpm-lock.yaml') }} + tsbuildinfo
```

Quality gate: make `typecheck` a required check (branch protection) so merge blocked on type error.

### Mentor note

Show CI config as docs: "our type gate is `tsc --noEmit` — it never emits, only checks." Onboard: `npm run typecheck` local before push.

### Common confusion

- "`tsc --build` already checks, why also `--noEmit`?" — `--build` checks via references; solo `--noEmit` is fine for single-project. Use one consistently.

### Performance note

`tsc --build` incremental + caching `.tsbuildinfo` per package cuts CI typecheck 2–5× vs `tsc --noEmit` cold on large monorepo.
