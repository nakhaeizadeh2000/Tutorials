### 4) **Strictness as validation practice** (exhaustiveness, assertions, boundary validation — using strictness) — [15 Strictness, Errors and Validation](<../15 Strictness Errors and Validation/README.md>) (textual forward)

**Definition** — *using* strictness (exhaustive switches, assertion functions, schema validation at boundaries, error-as-value patterns) lives in domain 15 — this domain *configures* the strictness being used (`strict` family on, precision flags tuned). Configuration enables; practice applies — 13 without 15 is potential (flags on, nothing proven); 15 without 13 is exhortation (practices preached, nothing enforced).

**What problem it solves / history** — strict flags without validation practice produce narrow types nobody consumes (exhaustive switches unsunk, `unknown` un-narrowed, boundaries unvalidated — precision configured but unapplied). Validation practice without flags produces discipline without teeth (assertions written where convenient, skipped where tedious). The pair composes: flags enforce the vocabulary, practice speaks it — full sentences only together.

**Modern guidance** — as of TypeScript 5.9 era, configure here (flags on, triaged, gated) then practice in 15 (sinks, guards, schemas at every boundary) — configuration first (tools ready), practice second (tools used). Until 15 lands: narrow with 07's guards, sink with 07's `never`, validate unknown with 03's top type — the practice preview, fully usable.

**Runnable example** — configuration enabling practice (multi-file sets):

```typescript
// file: strict204.ts

// file: app204.ts
import type { Sig204 } from "./strict204.js";

    case "a": return 1;
    case "b": return 2;
    default: return assertNever(s); // sink (practice using configuration: strict makes the sink bite)
  }
}
console.log(act("a")); // 1 — flags (13) enabling sinks (15-preview): configuration + practice composed
// bad — flags on, switches unsunk (precision configured, coverage unproven — half the contract honored)
// fix — 15's practices on 13's configuration (both halves; either alone is potential-or-exhortation)
```
