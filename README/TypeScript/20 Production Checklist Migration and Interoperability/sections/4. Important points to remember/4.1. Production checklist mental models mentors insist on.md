## 4.1. Production checklist — mental models mentors insist on

### 1) **Gate everything releasable** (statics surfaces packaging baselines, none advisory)

**Definition** — the first check: five blocking gates at every release cut (1.1 — `noEmit`, typecheck, unit, `attw`/`publint` on tarballs, baseline diffs); plus flag audits (1.2 — strict/trio/pairing signed, overrides expiring); plus parity (1.2 part 3 — dev/CI/prod configs identical). Advisory on none (pressure proceduralized — break-glass + postmortem the only exception path).

**What problem it solves / history** — advisory-gate incidents (5.1 incident 1 — attw warned, release proceeded, `any` everywhere): blocking gates converting warnings into procedure (red blocking publish — pressure withstood structurally, not heroically).

**Modern guidance** — as of TypeScript 5.9 era (Aug 2026: TS 5.9 stable, 6.0 beta; Node 24 Active LTS), branch-protect all five (required checks — release branches); paste gate logs in release PRs (evidence — 16/2.3 mentor note restated at release scale); break-glass documented (override roles + mandatory postmortems — exceptions proceduralized, never casual).

**Runnable example** — gated releases (good vs bad, `tsc --strict`):

```typescript
// good — release contract pinned across gates (statics + behavior + baselines — all blocking)
export {}; // module marker (consistent module scope across fences)
type Equal<X, Y> = (<T>() => T extends X ? 1 : 2) extends (<T>() => T extends Y ? 1 : 2) ? true : false;
declare function assertType<T extends true>(): void;
export function releaseCut(): string { return "cut"; } // release API (contract pinned — gates blocking at the cut)
assertType<Equal<ReturnType<typeof releaseCut>, string>>(); // gate 1 (statics — shapes proven)
console.log(releaseCut()); // cut — gate 3 (behavior — values proven beside shapes)
// bad — advisory gates at release ("ship now, verify later" — drift bundled, incidents hotfixed per 5.1)
// fix — five blocking gates (red blocking — pressure proceduralized, exceptions break-glass-only)
```

**Common confusion** — "gates delay hotfixes" — gates *pace* hotfixes (minutes at authoring — bundled regressions costing days; 1.1's pressure argument restated). "small releases exempt" — small releases drifting identically (gates proportional — five checks running regardless of diff size).

**Performance note** — parallel gates ≈ slowest (seconds-to-minutes — incident-class prevention at release scale, cheapest insurance).

**Mentor note** — "all five green?" (release-review opener — advisory answers rejected like missing tests).

**Cross-links** — release gates → [1.1. Pre-release gates](<../1. Production Checklist/1.1. Pre-release type gates all green.md>); exemption counts → [1.2. Config audits](<../1. Production Checklist/1.2. Strictness and configuration audits.md>).

### 2) **Migrate in files and flags, never in flag-days** (incremental playbooks, velocity with safety)

**Definition** — the second check: JS→TS per file (2.1 loops — rename-tighten-test-merge, backlog ratcheting); versions triaged per minor (2.2 — branch builds, dual pipelines, ecosystem gating); strictness per wave (2.3 — nullability→any→variance, class baselines, paced rollout). Flag-days never (big-bangs stalling — 5.1 incident 2's epitaph).

**What problem it solves / history** — migration stalls (flag-day freezes abandoned mid-flight — quarters vaporized, zero files shipped): incremental playbooks compounding velocity (files/waves/minors merging daily — momentum with safety, always).

**Modern guidance** — loops per file (2.1 — independence total); triage per minor (2.2 — breaking lists short); waves per flag (2.3 — value-ordered); baselines throughout (ratchets shrinking — progress dashboarded per 17/3.3).

**Runnable example** — incremental momentum (good vs bad, `tsc --strict`):

```typescript
// good — looped file conversion (one file green — momentum compounding, velocity with safety)
export {}; // module marker (consistent module scope across fences)
export function converted(name: string): string {
  return `hi:${name}`; // tightened (annotations real — 2.1 loop shape: rename, tighten, test, merge)
}
console.log(converted("ada")); // hi:ada — file loops (independence total — 200 files as 200 merges, never one stall)
// bad — flag-day migrations (freezes announced — stalls abandoned mid-flight per 5.1, quarters vaporized)
// fix — playbooks (files + flags + versions — increments merging daily, momentum compounding)
```

**Common confusion** — "increments prolong" — increments *complete* (big-bangs stalling at month three — duration to done favoring loops decisively). "playbooks bureaucratic" — playbooks *pace* (loops/waves/triage — velocity with safety as procedure, not paperwork).

**Performance note** — loops minutes-to-hours each (steady throughput — big-bang quarters with zero shipped the comparison baseline).

**Mentor note** — migration metric: files/waves/minors merged (velocity dashboarded — stalls visible as flat lines, addressed early).

**Cross-links** — file loops → [2.1. JS to TS](<../2. Migration Playbooks/2.1. JavaScript to TypeScript file by file.md>); strict waves → [2.3. Loose to strict](<../2. Migration Playbooks/2.3. Loose to strict sequencing.md>).

### 3) **Interop honest, never hopeful** (shims minimal, trust versioned, precision progressive)

**Definition** — the third check: ambient shims minimal + tracker-linked (3.3 part 1 — honesty over completeness, deletion scheduled); trust laddered (3.3 part 2 — shim→parse→precise, versions evidencing); exits planned (3.3 part 3 — fork-PR-replace, sunsets dated). Hopeful `any` unrepresentable (lies bounded, precision progressing quarterly).

**What problem it solves / history** — hopeful interop (any-shimmed SDKs widening silently — 5.1 incident 3's analytics class): honest interop bounding lies (used surfaces typed — upgrades breaking loudly at shims, precision deepening per rung).

**Modern guidance** — shim minimally (used names — tracker links); parse at boundaries (unknown in, proven out — 15/3.3 discipline); climb quarterly (precision deepening — trust transferring with evidence).

**Runnable example** — honest interop (good vs bad, `tsc --strict`):

```typescript
// good — laddered trust (shim → parse → proven — honesty progressing quarterly)
export {}; // module marker (consistent module scope across fences)
declare function legacyId(raw: string): unknown; // rung-1 (unknown-honest — ignorance stated, not hoped)
export function useId(raw: string): string {
  const v: unknown = legacyId(raw); // boundary (validation next — assumption never)
  if (typeof v !== "string") throw new Error("id-shaped"); // rung-2 (parsed — proven, not cast)
  return v;
}
console.log(useId("x")); // x — honest interop (lies bounded — precision progressing per rung)
// bad — hopeful any shims (any-forever — payloads widening silently, incidents finance-discovered per 5.1)
// fix — ladders (rungs scheduled — trust earned, exits planned, sunsets dated)
```

**Common confusion** — "shims are debt" — *unplanned* shims are debt (planned shims with trackers/exits are transitions — residence justifying like `any`). "ladders over-process" — ladders *schedule* trust (permanence requiring justification — progression default, residence exceptional).

**Performance note** — validation microseconds per boundary (parse discipline — hopeful-any costing finance-discovered incidents, asymmetry decisive).

**Mentor note** — dependency review: "which rung, exit when?" (rungs stated, sunsets dated — interop honest by procedure).

**Cross-links** — trust ladders → [3.3. Declaration-first](<../3. Interop and Portable Code/3.3. Declaration-first consumption of untyped JavaScript.md>); parse discipline → [3.3. Parse boundaries](<../../../15 Strictness Errors and Validation/sections/3. Schema Validation in Practice/3.3. Parse do not validate at boundaries.md>).

### 4) **Observe what you ship** (errors taxed, health modeled, shutdowns phased)

**Definition** — the fourth check: typed error reporting with sampling (1.3 part 1 — taxonomies flowing, volume budgeted); union-modeled health (1.3 part 2 — degraded driving automation); phased shutdown (1.3 part 3 — stop→drain→exit, SIGTERM tested). Production as proof (observability evidencing — shipped working, not shipped hoping).

**What problem it solves / history** — unobserved shipping (string dumps, boolean health, SIGTERM ignorance — 5.1 incident 4's severed checkouts): observability proving (errors taxed by class, health modeled by shape, shutdowns phased by procedure — production evidenced).

**Modern guidance** — report classes + causes (payload contracts — 1.3 part 1); model health unions (automation routing — 1.3 part 2); phase shutdowns (tested drains — 1.3 part 3, 17/2.3 doubles).

**Runnable example** — proof over hope (good vs bad, `tsc --strict`):

```typescript
// good — observed shipping (errors taxed, health modeled, shutdowns phased — production evidenced)
export {}; // module marker (consistent module scope across fences)
export type ShipHealth = { ok: true } | { ok: false; why: string }; // modeled (union — automation routing per 1.3 part 2)
export async function shipCheck(): Promise<ShipHealth> { return { ok: true }; } // probed (health exercised — evidence, not hope)
console.log((await shipCheck()).ok); // true — observed production (proof over hope — shipped working, evidenced continuously)
// bad — unobserved shipping (dumps, booleans, ignorance — incidents user-reported, causes unlogged, shutdowns severing)
// fix — observability triple (report + model + phase — production as proof, continuously)
```

**Common confusion** — "observability post-release" — observability *pre*-release (hooks in the checklist — 1.3 gates at the cut, not after incidents). "sampling loses signal" — sampling *budgets* signal (fatals always — transients fractionally; undifferentiated volume drowning signal per 1.3 part 1).

**Performance note** — hooks microseconds-to-milliseconds (rare paths + bounded probes — production evidence cheapest insurance).

**Mentor note** — "prove it ships working" (errors/health/shutdown evidenced — hope rejected as release strategy).
