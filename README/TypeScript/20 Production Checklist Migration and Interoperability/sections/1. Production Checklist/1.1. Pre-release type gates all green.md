## 1.1. Pre-release type gates all green

### 1) **Three-gate composition at release** (noEmit plus typecheck plus unit, none advisory)

**Definition** — the release-cut gate set (17/3.3 composed at release): (1) `tsc --noEmit` whole-program (inline pins, directives, matrices — contracts); (2) `tsd`/`vitest --typecheck` surface (declarations — packaging inputs); (3) unit runners (behavior — values). At release: all three *blocking* (advisory gates skipped under pressure — pressure exactly when gates matter most).

**What problem it solves / history** — release-pressure gate-skipping ("statics advisory for this hotfix" — drift shipping with the fix, hotfix + regression bundled): blocking gates converting pressure into procedure (red blocking merge — hotfixes waiting like features, regressions never bundled).

**Modern guidance** — as of TypeScript 5.9 era (Aug 2026: TS 5.9 stable, 6.0 beta; Node 24 Active LTS), branch-protect all three gates on release branches (required status checks — no override roles except documented break-glass with postmortem); run the identical `npm run check` locally and in CI (17/5.1 part 4 parity — laptop green meaning CI green).

**Runnable example** — gates blocking (good vs bad, `tsc --strict`):

```typescript
// good — release-cut contract pinned (three gates evaluating — none advisory at the cut)
export {}; // module marker (consistent module scope across fences)
type Equal<X, Y> = (<T>() => T extends X ? 1 : 2) extends (<T>() => T extends Y ? 1 : 2) ? true : false;
declare function assertType<T extends true>(): void;
export function shipTotal(items: number[]): number { return items.reduce((a, b) => a + b, 0); } // release API (contract pinned below — gates blocking at the cut)
assertType<Equal<ReturnType<typeof shipTotal>, number>>(); // gate 1 (noEmit — statics blocking)
console.log(shipTotal([2, 3])); // 5 — gate 3 (behavior — values proven beside shapes)
// bad — advisory statics at release ("skip typecheck, ship the hotfix" — drift bundled with fixes, regressions hotfixed later)
// fix — blocking gates (red blocking merge — pressure proceduralized, never excepted without break-glass + postmortem)
```

```jsonc
// good — release pipeline shape (three jobs + packaging + baselines, all required)
// release.yml (labeled config doc — jobs): { "typecheck": "tsc --noEmit", "typetest": "tsd",
//   "unit": "vitest run", "pack": "attw --pack && publint", "baselines": "diff api-report.md" }
// required: [all five] (branch protection — release cut green on every gate, advisory on none)
```

**Common confusion** — "hotfixes exempt" — hotfixes need gates *most* (pressure correlating with mistakes — exemptions bundling regressions with fixes; break-glass + postmortem the only exception path). "gates slow releases" — gates *pace* releases (red caught in minutes at authoring — post-release incidents costing days; net velocity positive by the second incident prevented).

**Performance note** — parallel gates wall-time ≈ slowest (II 17/3.3 composition — total ≈ max, not sum; release cuts paying seconds-to-minutes for incident-class prevention).

**Mentor note** — release-review opener: "all five green?" (gates enumerated — advisory answers rejected like missing tests).

### 2) **Packaging gates on the tarball** (attw plus publint pre-publish, consumer proof)

**Definition** — *tarball gates* (16/2.3 operated, required here): `attw --pack` (consumer-equivalent resolution per importer — types resolving for every exports condition) + `publint` (packaging coherence — files/conditions/shapes) run against the *packed tarball* (not the working tree — the artifact consumers install). Pre-publish = pre-push-to-registry (gates inside the release job, failures blocking publish, not warning after).

**What problem it solves / history** — warned-but-shipped packaging bugs (5.1 incident 1: attw *warned*, release *proceeded* — `any` to every consumer, patch + apology): warnings promoted to blockers (packaging red = publish blocked — the incident's one-line policy fix generalized to every release).

**Modern guidance** — pack-then-gate in the release job (`npm pack` → `attw --pack tarball.tgz` → `publint` — artifact tested, not tree); block on red (publish steps conditional on gates — pipeline YAML enforcing, not humans remembering); paste gate logs in release PRs (evidence per 16/2.3 mentor note — claims never substituting).

**Runnable example** — tarball proof (good vs bad, `tsc --strict`):

```text
// good — pack-gate-publish sequence (artifact proven — consumers resolving before registry sees it)
// release job (labeled CLI doc — ordered steps):
// $ npm pack --pack-destination ./pkg (artifact built — the shippable, not the tree)
// $ npx attw --pack ./pkg/*.tgz (consumer-equivalent resolution — every condition resolving declarations)
// $ npx publint ./pkg/*.tgz (coherence — files/conditions/shapes linted)
// $ npm publish ./pkg/*.tgz (publish conditional — gates green, and only then)
```

```typescript
// good — dual-shape coherence pre-verified (the invariant gates prove — both shapes serving types)
export {}; // module marker (consistent module scope across fences)
export interface Shippable { id: string } // surface (both conditions serving — attw verifying per importer kind)
export function makeShippable(id: string): Shippable { return { id }; } // dual-shape safe (import + require resolving — proven on tarball, not hoped from tree)
console.log(makeShippable("s1").id); // s1 — coherence proven (gates on artifact — consumer outcomes verified pre-publish)
// bad — tree-tested packaging (tsc green on sources — packed layout broken, consumers resolving any)
// fix — tarball gates (artifacts proven — trees never shipping directly)
```

**Common confusion** — "CI tsc covers packaging" — `tsc` checks *sources* (no exports map involved — 17/3.2's gap restated at release; tarball gates checking *packed resolution*). "warnings suffice for packaging" — warnings ship (incident 1 evidencing — humans overriding under pressure; blockers holding under pressure).

**Performance note** — pack + gates seconds (tarball I/O + resolution matrix — release-job scale; warnings-to-blockers zero-cost policy change, incident-class prevention free).

**Mentor note** — release policy one-liner: "packaging warnings are blockers" (incident 1's epitaph — policy generalized, never re-debated).

### 3) **Baseline diffs reviewed** (type perf API baselines, deliberate moves only)

**Definition** — *release baselines*: checked-in snapshots of consumer-visible contracts (API reports per 17/3.2 part 3, perf budgets per 19/1.2 part 3, error-count ratchets per 17/3.3 part 3) diffed at the release cut (moves listed with names — deliberate + versioned, or accidental + reverted; silent moves unshippable).

**What problem it solves / history** — silent contract moves in "patch" releases (renamed options, widened returns — consumers breaking at `npm update`, see 17/3.2 break-detection): baseline diffs enumerating moves (reviewers deciding major-vs-revert with evidence — semver as procedure, not memory).

**Modern guidance** — baseline files in-repo (api-report + perf-budget + error-counts — three diffs at the cut); moves reviewed per name (each moved/removed/widened contract a changelog entry or a revert); automation diffing (CI posting baseline diffs on release PRs — evidence attached, not hunted).

**Runnable example** — moves deliberate (good vs bad, `tsc --strict`):

```typescript
// good — baseline-pinned release contract (moves listed — deliberate or reverted, never silent)
export {}; // module marker (consistent module scope across fences)
type Equal<X, Y> = (<T>() => T extends X ? 1 : 2) extends (<T>() => T extends Y ? 1 : 2) ? true : false;
declare function assertType<T extends true>(): void;
export function connect(host: string, port?: number): string { return `${host}:${port ?? 80}`; } // released contract (baseline pinned below — moves listed at the cut)
assertType<Equal<Parameters<typeof connect>, [host: string, port?: number]>>(); // baseline (new required param breaking HERE — major-or-revert, never silent)
console.log(connect("h")); // h:80 — deliberate moves (evidence attached — semver as procedure)
// bad — unbaselined releases ("patch" renaming options — consumers breaking at update, discovered downstream)
// fix — baseline diffs (moves enumerated — deliberate + versioned, or reverted on sight)
```

**Common confusion** — "baselines freeze releases" — baselines freeze *silent* moves (deliberate moves updating baselines in the same PR — evolution with evidence per 17/3.2). "small packages exempt" — small packages breaking consumers identically (moves move regardless of size — baselines proportional, never exempt). "diffs replace review" — diffs *focus* review (moves listed — humans judging intent, automation enumerating).

**Performance note** — baseline diffs seconds (text compares — cheapest gate; silent-move incidents quarters — ratio astronomical).

**Mentor note** — release checklist line: "baselines diffed, moves deliberate" (semver evidenced — procedure over memory, every cut).
