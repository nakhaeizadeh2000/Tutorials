## 7.1. Boundaries — What Is Covered Elsewhere

### 1) **Definition** (where this domain stops)

**Definition** — This domain owns primitives, literals, unions/intersections, narrowing, enums vs unions, tuples. It stops before objects/interfaces, functions, and advanced utilities.

### 2) **Comparison** (sibling domains)

**Where to find it instead:**

- Objects, `interface` vs `type`, optional/readonly, excess checks, `Pick`/`Record` intro → [03 Objects Interfaces and Type Aliases](<../../../03%20Objects%20Interfaces%20and%20Type%20Aliases/README.md>).
- Advanced utilities, conditional `extends`, `infer`, mapped/template, branding → [06 Advanced Types Conditional Mapped Template Literal](<../../../06%20Advanced%20Types%20Conditional%20Mapped%20Template%20Literal/README.md>).
- Runtime validation (`Zod`) for `unknown` boundaries → [10 Migration Interop](<../../../10%20Migration%20Interop%20and%20Runtime%20Gaps/README.md>).

### 3) **Link** (how to use)

**Guidance** — Use this domain for per-value fundamentals; for object composition see `03`, for type-level programming see `06`.
