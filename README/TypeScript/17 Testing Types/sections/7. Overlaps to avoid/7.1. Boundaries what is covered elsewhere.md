**Definition** — runner operation (vitest/jest configuration, coverage thresholds, watch modes, e2e with Playwright per track mission), suite organization at scale, and behavior-assertion ergonomics live in the future Testing track — this domain proves *statics* (contracts, rejections, surfaces, gates); runners prove *behavior* (values, flows, pixels).
