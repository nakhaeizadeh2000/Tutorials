## 1. Every wait bounding (timeouts stating — tiers timing — fallbacks pairing)

**Definition** — the wait line on every dependency: timeouts proving (budgets stating — tails trimming (hangs refusing — unbounded declining (proving owning — hoping declining); tiers proving (lanes separating — ratios pricing (slows isolating — mixing declining (proving funding — blocking declining); fallbacks proving (defaults stating — degrades declaring (callers continuing — crashing declining (proving earning — total declining).

**What problem it solves** — the unbounded trio: *timeouts unstating* (budgets undeclared — tails unfattened (hangs scheduling — threads leaking (unstating billing — discipline missing); *tiers untiming* (lanes unseparated — ratios unpriced (slows unisolated — urgents starving (untiming charging — priority failing); *fallbacks unpairing* (defaults unstated — degrades undeclared (callers crashing — users losing (unpairing costing — grace missing). Bounded waits converting unboundedness to proving (budgets stating — lanes separating (defaults stating — hangs ending); reviewers finding timeouts per dependency (bounding proving → verifiable; unbounded → returned).

**Modern guidance** — the bounding lines per dependency (review-enforced): *timeouts proving* ([1.1](<../../sections/1. Fault thinking/1.1. Timeouts bounding waits.md>) — budgets stating (tails trimming — hangs refusing (proving owning — hoping refusing); *tiers proving* ([1.1](<../../sections/1. Fault thinking/1.1. Timeouts bounding waits.md>) — lanes separating (ratios pricing — slows isolating (proving funding — mixing refusing); *fallbacks proving* ([1.1](<../../sections/1. Fault thinking/1.1. Timeouts bounding waits.md>) — defaults stating (degrades declaring — callers continuing (proving earning — crashing refusing).

**Common confusion** — *"bounding slows journeys (budgets throttling)."* Throttling capping throughput (rates limiting — flows shaping (waits bounding — floods declining (throttling serving — budgets differing); bounding ending hangs (budgets stating — tiers timing (fallbacks pairing — leaks ending (bounding proving — unbounded declining). "Slowing" describing fear (budgets avoiding — decisions ducking); bounding describing liveness (timeouts stating — threads freeing). State budgets (waits capping — hangs refusing); time lanes (ratios pricing — slows isolating).

**Performance note** — bounding-check economics: stating costing declarations (budgets declaring — tiers timing (fallbacks pairing — hangs ending); unbounded equivalents costing leaks (tails fattening — urgents starving (users losing — trust eroding). State cheaply (waits — dependencies); hang never (threads — journeys).

**Mentor note** — teach "timeout, tier, fallback — every dependency" (juniors bounding per dependency design leak-proof waits on first hearing; unbound waits interrogated ("timeout? lane? degrade?" — bounding demanding per dependency). Bound one wait once (budgets stating — tiers timing tangible (unbounded ending — bounding proving permanently).
