Judged retryables converting everything to classifying (kinds typing — keys carrying (callers declining — storms ending); reviewers finding retry tables per call (judging proving → verifiable; everything → returned).

**Modern guidance** — the judging lines per call (review-enforced): *errors classifying* (kinds typing — retryables listing (faults refusing — blinding declining (classifying proving — everything refusing (kinds earning — storms preventing); *idempotents repeating* ([CA 02/2.2](<../../../../CleanArchitecture/02 Use Cases and Application Services/sections/2. // GOOD: retryables judging — classified errors with repeated idempotents (compiled + run live).
```typescript
function retryable(kind: string, keyed: boolean): boolean {
  if (kind === 'CALLER-FAULT') return false; // errors classifying — kinds typing, blinding declining

```

## 2. Backoffs spacing (waits growing — jitter dispersing — herds declining)

**Definition** — spaced backoffs: growing waits dispersing jitter declining herds (waits growing — delays exponentiating (caps bounding — patience pricing (growing proving — hammering declining); jitter dispersing — fleet desynchronizing (pulses smoothing — recoveries breathing (dispersing funding — stampeding declining); herds declining — thunder diffusing (servers reviving — outages ending (declining owning — amplifying declining).

**What problem it solves** — the instant-retry trio: *waits ungrowing* (delays unexponentiated — caps unbounded (impatience billing — hammering inviting (ungrowing charging — politeness failing); *jitters undispersing* (fleets synchronized — pulses aligning (recoveries choking — servers drowning (undispersing billing — thunder scheduling); *herds undeclining* (thunder undiffused — servers unrevived (outages extending — trust eroding (undeclining costing — amplification ruling). Spaced backoffs converting hammering to growing (delays exponentiating — fleets desynchronizing (thunder diffusing — servers reviving); reviewers finding backoff curves per caller (spacing proving → verifiable; hammering → returned).

**Modern guidance** — the spacing lines per caller (review-enforced): *waits growing* (delays exponentiating — caps bounding (patience pricing — hammering declining (growing proving — instant refusing (growths earning — politeness keeping); *jitter dispersing* ([ITVocabulary 04/2.2](<../../../../ITVocabulary/04 Networks Web and Internet Vocabulary/sections/2. Latency vs bandwidth and timeouts.md>) — fleets desynchronizing (pulses smoothing — recoveries breathing (dispersing funding — stampeding refusing (dispersions owning — thunder ending); *herds declining* (thunder diffusing — servers reviving (outages ending — amplifying declining (declining owning — pulsing refusing (diffusions funding — revival earning).

```typescript
// GOOD: backoffs spacing — grown waits dispersing jitter (compiled + run live).
function backoffMs(attempt: number, baseMs: number, capMs: number): number {
  const grown = baseMs * 2 ** attempt; // waits growing — delays exponentiating, hammering declining
  return Math.min(grown, capMs); // herds declining — thunder diffusing, amplifying declining
}
function spread(waitMs: number, jitterMs: number): number {
  return waitMs + jitterMs; // jitter dispersing — fleets desynchronizing, stampeding declining
}
console.log(backoffMs(0, 100, 2000) === 100 && backoffMs(3, 100, 2000) === 800 && backoffMs(9, 100, 2000) === 2000 && spread(800, 37) === 837 ? 'backoffs space' : 'retries hammer');
```

Exponentiate delays (growths earning — politeness keeping); cap totals (caps bounding — patience pricing).

**Performance note** — spacing economics: growing costing waits (delays exponentiating — fleets desynchronizing (thunder diffusing — servers reviving); hammering equivalents costing thunder (servers drowning — outages extending (trust eroding — pages multiplying). Grow cheaply (backoffs — attempts); hammer never (retries — fleets).

## 3. Budgets enforcing (attempts counting — deadlines capping — storms declining)

**Definition** — enforced retry budgets: counted attempts capping deadlines declining storms (attempts counting — tries numbering (loops bounding — infinities refusing (counting proving — forever declining); deadlines capping — totals bounding (clocks stopping — waits ending (capping owning — drifting declining); storms declining — amplifiers muting (neighbors serving — outages ending (declining owning — thundering declining).

**What problem it solves** — the infinite-retry trio: *attempts uncounting* (tries unnumbered — loops unbounded (infinities looping — resources burning (uncounting billing — discipline missing); *deadlines uncapping* (totals unbounded — clocks unstopped (waits drifting — hangs scheduling (uncapping charging — timeliness failing); *storms undeclining* (amplifiers unmuted — neighbors unserved (outages extending — trust eroding (undeclining costing — survival bluffing). **Modern guidance** — the enforcing lines per retrier (review-enforced): *attempts counting* (tries numbering — loops bounding (infinities refusing — forever declining (counting proving — looping refusing (numbers owning — burn ending); *deadlines capping* (totals bounding — clocks stopping (waits ending — drifting declining (capping owning — unbounded refusing (caps funding — timeliness keeping); *storms declining* (amplifiers muting — neighbors serving (outages ending — thundering declining (declining owning — blowing refusing (mutes earning — survival keeping).

```typescript
// GOOD: budgets enforcing — counted attempts capping deadlines (compiled + run live).
interface RetryBudget { // attempts counting — tries numbering, forever declining
  maxAttempts: number;
  deadlineMs: number;
}
function over(b: RetryBudget, attempts: number, elapsedMs: number): boolean {
  if (attempts >= b.maxAttempts) return true; // deadlines capping — totals bounding, drifting declining
  return elapsedMs >= b.deadlineMs; // storms declining — amplifiers muting, thundering declining
}

console.log(!over(budget, 1, 500) && over(budget, 3, 500) && over(budget, 1, 2500) ? 'budgets enforce' : 'retries infinite');
```
