# 1.1. Timeouts bounding waits

## 1. Waits capping (budgets stating — tails trimming — hangs refusing)

**Definition** — capped waits: stated budgets trimming tails refusing hangs (budgets stating — timeouts declaring (waits bounding — overruns refusing (stating proving — hoping declining); tails trimming — p99 capping (outliers shedding — latencies bounding (trimming funding — fattening declining); hangs refusing — stalls abandoning (threads freeing — callers unblocking (refusing owning — leaking declining).

**What problem it solves** — the unbounded-wait trio: *budgets unstating* (timeouts undeclared — waits unbounded (tails fattening — hangs scheduling (unstating billing — discipline missing); *tails untrimming* (p99 uncapping — outliers untrimmed (latencies growing — callers suffering (untrimming charging — liveness failing); *hangs unrefusing* (stalls unabandoned — threads unfreed (callers blocked — pools exhausting (unrefusing costing — survival bluffing). Capped waits converting unboundedness to stating (budgets declaring — p99 capping (stalls abandoning — hangs ending); reviewers finding timeouts per dependency (capping proving → verifiable; unbounded → returned).

**Modern guidance** — the capping lines per dependency (review-enforced): *budgets stating* ([01/3.1](<../../../01 Microservices Foundations and Mental Model/sections/3. First safety/3.1. Contracts between services.md>) — timeouts declaring (waits bounding — overruns refusing (stating proving — hoping refusing (declarations owning — hangs ending); *tails trimming* (p99 capping — outliers shedding (latencies bounding — fattening declining (trimming funding — growing refusing (caps earning — suffering ending); *hangs refusing* (stalls abandoning — threads freeing (callers unblocking — leaking declining (refusing owning — exhausting declining (abandons funding — liveness earning).

```typescript
// GOOD: waits capping — stated budgets trimming tails (compiled + run live).
interface Wait { // budgets stating — timeouts declaring, hoping declining
  dep: string;
  timeoutMs: number;
  p99Ms: number;
}
function uncapped(waits: Wait[]): string[] {
  const gaps: string[] = []; // tails trimming — p99 capping, fattening declining
  for (const w of waits) {
    if (!(w.timeoutMs > 0) || w.p99Ms > w.timeoutMs) gaps.push(w.dep);
  }
  return gaps; // hangs refusing — stalls abandoning, leaking declining
}
const capped: Wait[] = [
  { dep: 'billing', timeoutMs: 500, p99Ms: 320 },
  { dep: 'notify', timeoutMs: 200, p99Ms: 90 },
];
const loose: Wait[] = [{ dep: 'billing', timeoutMs: 0, p99Ms: 9000 }];
console.log(uncapped(capped).length === 0 && uncapped(loose).join() === 'billing' ? 'waits cap' : 'calls hang');
```

```typescript
// BAD: calls hanging — budgets unstating, tails untrimming (real leak shape).
// await client.send(cmd, data).toPromise(); // waits unbounded — tails fattening, hangs scheduling.
// // No timeout (threads unfreed — pools exhausting). State budgets; trim tails; refuse hangs.)
```

**Common confusion** — *"timeouts slow systems (clocks throttling)."* Throttling capping throughput (rates limiting — flows shaping (waits bounding — floods declining (throttling serving — budgets differing); capping bounding lateness (budgets stating — tails trimming (hangs refusing — threads freeing (capping proving — unbounded declining). "Slowing" describing fear (clocks avoiding — decisions ducking); timeouts describing liveness (waits bounding — threads freeing). State budgets (timeouts declaring — overruns refusing); trim tails (p99 capping — suffering ending).

**Performance note** — capping economics: stating costing declarations (budgets declaring — p99 capping (stalls abandoning — hangs ending); unbounded equivalents costing leaks (tails fattening — threads leaking (pools exhausting — liveness dying). State cheaply (timeouts — dependencies); hang never (waits — threads).

**Mentor note** — teach "every dependency states its timeout" (juniors capping one budget per dependency design leak-proof waits on first hearing; timeoutless calls interrogated ("waits how long?" — capping demanding per dependency). Cap one wait once (budgets stating — tails trimming tangible (unbounded ending — capping proving permanently). Declare timeouts; abandon stalls — capping discipline in three habits, reviewed per dependency.

## 2. Tiers timing (lanes separating — ratios pricing — slow isolating)

**Definition** — tiered timings: separated lanes with priced ratios isolating slowness (lanes separating — fasts fast-tracking (slows queueing-apart (deploys decoupling — head-blocking declining (separating proving — mixing declining); ratios pricing — budgets proportioning (timeouts scaling (slows costing (pricing funding — flat declining); slow isolating — laggards quarantining (neighbors serving — cores protecting (isolating owning — dragging declining).

**What problem it solves** — the single-timeout trio: *lanes unseparating* (fasts unfast-tracked — slows unqueued-apart (head-blocking arriving — urgents starving (unseparating billing — priority missing); *ratios unpricing* (budgets unproportioned — timeouts unscaled (slows uncosted — overruns scheduling (unpricing charging — arithmetic failing); *slows unisolating* (laggards unquarantined — neighbors undragged (cores shared-dying — availability coupling (unisolating costing — containment failing). Tiered timings converting mixing to separating (fasts fast-tracking — budgets proportioning (laggards quarantining — urgents flowing); reviewers finding lanes per latency class (timing proving → verifiable; mixing → returned).

**Modern guidance** — the timing lines per lane (review-enforced): *lanes separating* (fasts fast-tracking — slows queueing-apart (head-blocking declining — starving ending (separating proving — mixing refusing (lanes earning — priority keeping); *ratios pricing* (budgets proportioning — timeouts scaling (slows costing — flat declining (pricing funding — unscaled refusing (proportions owning — arithmetic keeping); *slow isolating* (laggards quarantining — neighbors serving (cores protecting — dragging declining (isolating owning — sharing refusing (quarantines funding — availability keeping).

```typescript
// GOOD: tiers timing — separated lanes with priced ratios (compiled + run live).
interface Lane { // lanes separating — fasts fast-tracking, mixing declining
  name: string;
  timeoutMs: number;
  share: number;
}
function tiered(lanes: Lane[], totalMs: number): boolean {
  let sum = 0; // ratios pricing — budgets proportioning, flat declining
  for (const l of lanes) sum += l.timeoutMs * l.share;
  return sum <= totalMs; // slow isolating — laggards quarantining, dragging declining
}
const lanes: Lane[] = [
  { name: 'fast', timeoutMs: 200, share: 0.9 },
  { name: 'slow', timeoutMs: 2000, share: 0.1 },
];
console.log(tiered(lanes, 500) && !tiered(lanes, 300) ? 'tiers time' : 'lanes mix');
```

```typescript
// BAD: lanes mixing — fasts unfast-tracked, slows unisolating (real block shape).
// // One 5s timeout everywhere (head-blocking arriving — urgents starving — priority missing).
// // Slow dep blocks all (neighbors dragged — cores shared-dying). Separate lanes; price ratios; isolate slow.)
```

**Common confusion** — *"tiers complicate timeouts (lanes multiplying)."* Multiplying confusing callers (configs sprawling — docs thickening (onboards slowing — mistakes scheduling (multiplying charging — simplicity failing); tiering isolating slowness (fasts fast-tracking — slows quarantining (urgents flowing — cores protecting (tiering proving — mixing declining). "Complicating" describing sprawl (configs multiplying — mistakes scheduling); tiers describing priority (lanes separating — ratios pricing). Separate two lanes (fast tracking — slow apart); price shares (budgets proportioning — arithmetic keeping).

**Performance note** — timing economics: separating costing lanes (fasts tracking — budgets proportioning (laggards quarantining — urgents flowing); mixed equivalents costing head-blocking (urgents starving — neighbors dragged (availability coupling — priority missing). Separate cheaply (lanes — classes); mix never (timeouts — dependencies).

**Mentor note** — teach "fast and slow never share a lane" (juniors separating one lane per latency class design block-proof timings on first hearing; single-timeout fleets interrogated ("slow lane?" — timing demanding per class). Time one tier once (lanes separating — ratios pricing tangible (mixing ending — timing proving permanently). Fast-track urgents; quarantine laggards — timing discipline in three habits, reviewed per lane.

## 3. Fallbacks pairing (defaults stating — degrades declaring — callers continuing)

**Definition** — paired fallbacks: stated defaults declaring degrades continuing callers (defaults stating — values caching (stales tolerating — empties declining (stating proving — crashing declining); degrades declaring — modes announcing (features trimming — clients adapting (declaring funding — surprising declining); callers continuing — journeys completing (users serving — trust keeping (continuing owning — abandoning declining).

**What problem it solves** — the all-or-nothing trio: *defaults unstating* (values uncaching — stales untolerated (empties erroring — users losing (unstating billing — grace missing); *degrades undeclaring* (modes unannounced — features untrimmed (clients confusing — retries amplifying (undeclaring charging — adaptation missing); *callers uncontinuing* (journeys undropping — users unserved (trust eroding — abandonment scheduling (uncontinuing costing — resilience bluffing). Paired fallbacks converting crashing to stating (values caching — modes announcing (journeys completing — grace earning); reviewers finding fallbacks per dependency (pairing proving → verifiable; crashing → returned).

**Modern guidance** — the pairing lines per dependency (review-enforced): *defaults stating* (values caching — stales tolerating (empties declining — crashing declining (stating proving — missing refusing (caches owning — grace earning); *degrades declaring* (modes announcing — features trimming (clients adapting — surprising declining (declaring funding — hiding refusing (modes earning — confusion ending); *callers continuing* (journeys completing — users serving (trust keeping — abandoning declining (continuing owning — dropping refusing (completions funding — resilience keeping).

```typescript
// GOOD: fallbacks pairing — stated defaults with declared degrades (compiled + run live).
function withFallback(primary: () => string, fallback: string): string {
  try {
    const res = primary(); // defaults stating — values caching, crashing declining
    if (res.length === 0) return fallback;
    return res;
  } catch {
    return fallback; // degrades declaring — modes announcing, surprising declining
  }
  // callers continuing — journeys completing, abandoning declining (structured below)
}
const ok = withFallback(() => 'live-price', 'cached-price');
const down = withFallback(() => { throw new Error('boom'); }, 'cached-price');
const empty = withFallback(() => '', 'cached-price');
console.log(ok === 'live-price' && down === 'cached-price' && empty === 'cached-price' ? 'fallbacks pair' : 'calls crash');
```

```typescript
// // No fallback (journeys dropping — abandonment scheduling). State defaults; declare degrades; continue callers.)
```

**Common confusion** — *"fallbacks hide failures (degradation masking)."* Masking silencing evidence (failures unlogging — alerts unsounding (blindness ruling — tuning hoping (masking charging — honesty failing); pairing serving loudly (defaults stating — modes announcing (callers continuing — evidence recording (pairing proving — crashing declining). "Hiding" describing silence (failures unlogging — evidence missing); fallbacks describing grace (values caching — journeys completing). Serve degraded (users keeping — trust holding); log loudly (failures recording — alerts firing).

**Performance note** — pairing economics: stating costing defaults (values caching — modes announcing (journeys completing — grace earning); crashing equivalents costing outages (empties erroring — users losing (abandonment scheduling — trust eroding). State cheaply (fallbacks — dependencies); crash never (calls — users).

**Mentor note** — teach "every dependency states its degrade" (juniors pairing one fallback per dependency design crash-proof calls on first hearing; fallback-less calls interrogated ("down then?" — pairing demanding per dependency). Pair one fallback once (defaults stating — modes announcing tangible (crashing ending — pairing proving permanently). Cache values; announce modes — pairing discipline in three habits, reviewed per dependency.
