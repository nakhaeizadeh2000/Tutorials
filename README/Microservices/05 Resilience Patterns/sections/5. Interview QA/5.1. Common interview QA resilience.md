Pressured faults converting reciting to diagnosing (budgets stating — curves spacing (attempts capping — answers holding); interviewers hearing timeouts with budgets, not pattern names (diagnosing proving → hirable; reciting → passed) — drawing on [1.1](<../../sections/1. Fault thinking/1.1. Timeouts bounding waits.md>) and [1.2](<../../sections/1. Fault thinking/1.2. Retries budgeting attempts.md>).

**Modern guidance** — the faults lines (interview-enforced): *timeouts stating* (budgets declaring — tails trimming (hangs refusing — unbounded declining (stating proving — hoping refusing); *retries spacing* (errors classifying — backoffs growing (budgets enforcing — hammering declining (spacing funding — instant refusing); *budgets capping* (attempts counting — deadlines bounding (fallbacks serving — burning declining (capping owning — infinite refusing). Every claim carrying timeout + curve + budget (judgment demonstrable — pressure survivable).
