# 2.1. Circuit breaking cascades

## 1. Failures counting (faults tallying — thresholds tripping — opens refusing)

**Definition** — counted failures: tallied faults tripping thresholds refusing opens (faults tallying — errors counting (rates windowing — streaks tracking (tallying proving — ignoring declining); thresholds tripping — limits breaching (circuits opening — calls refusing (tripping funding — tolerating declining); opens refusing — fasts failing (waits skipping — threads freeing (refusing owning — queueing declining).

**What problem it solves** — the blind-caller trio: *faults untallying* (errors uncounting — rates unwindowed (failures invisible — tripping unjudged (untallying billing — visibility failing); *thresholds untripping* (limits unbreached — circuits unopened (calls flowing-into-fire (overloads feeding — outages deepening (untripping charging — protection failing); *opens unrefusing* (fasts unfailing — waits unskipped (threads held — pools exhausting (unrefusing costing — survival bluffing). Counted failures converting blindness to tallying (errors counting — limits breaching (fasts failing — threads freeing); reviewers finding counters per dependency (counting proving → verifiable; blindness → returned).

**Modern guidance** — the counting lines per dependency (review-enforced): *faults tallying* (errors counting — rates windowing (streaks tracking — ignoring declining (tallying proving — blind refusing (counts earning — visibility keeping); *thresholds tripping* (limits breaching — circuits opening (calls refusing — tolerating declining (tripping funding — flowing refusing (breaches owning — overloads ending); *opens refusing* (fasts failing — waits skipping (threads freeing — queueing declining (refusing owning — holding declining (fails funding — survival earning).

```typescript
// GOOD: failures counting — tallied faults tripping thresholds (compiled + run live).
class FaultTally { // faults tallying — errors counting, ignoring declining
  private streak = 0;
  constructor(private readonly threshold: number) {}
  record(ok: boolean): string {
    this.streak = ok ? 0 : this.streak + 1; // thresholds tripping — limits breaching, tolerating declining
    return this.streak >= this.threshold ? 'OPEN' : 'CLOSED'; // opens refusing — fasts failing, queueing declining
  }
}
const tally = new FaultTally(3);
const s1 = tally.record(false);
const s2 = tally.record(false);
const s3 = tally.record(false);
const s4 = tally.record(true);
console.log(s1 === 'CLOSED' && s2 === 'CLOSED' && s3 === 'OPEN' && s4 === 'CLOSED' ? 'failures count' : 'callers blind');
```

```typescript
// BAD: callers blinding — faults untallying, opens unrefusing (real feed-fire shape).
// await call(); await call(); await call(); // errors uncounting — overloads feeding, outages deepening.
// // No threshold (calls flowing-into-fire — threads held). Tally faults; trip thresholds; refuse opens.)
```

**Common confusion** — *"counting adds overhead (tallies taxing)."* Taxing slowing calls (counters incrementing — windows sliding (checks branching — nanoseconds spending (taxing charging — speed missing); counting freeing threads (faults tallying — opens refusing (waits skipping — pools surviving (counting proving — blindness declining). "Overhead" describing nanoseconds (counters incrementing — speed missing); failures describing survival (threads freeing — overloads ending). Tally faults (errors counting — visibility keeping); refuse opens (fasts failing — survival earning).

**Performance note** — counting economics: tallying costing counters (errors counting — limits breaching (fasts failing — threads freeing); blind equivalents costing feeds (overloads feeding — threads held (pools exhausting — outages deepening). Count cheaply (tallies — dependencies); blind never (callers — faults).

**Mentor note** — teach "every dependency counts its faults" (juniors tallying one streak per dependency design blind-proof callers on first hearing; uncounted callers interrogated ("streak what?" — counting demanding per dependency). Count one fault once (errors tallying — thresholds tripping tangible (blindness ending — counting proving permanently). Window rates; breach limits — counting discipline in three habits, reviewed per dependency.

## 2. Probes half-opening (trials admitting — recoveries testing — closes earning)

**Definition** — half-open probes: admitted trials testing recoveries earning closes (trials admitting — singles passing (lanes narrowing — loads sampling (admitting proving — flooding declining); recoveries testing — health checking (latencies measuring — errors watching (testing funding — assuming declining); closes earning — successes counting (confidence rebuilding — circuits closing (earning owning — flapping declining).

**What problem it solves** — the stuck-open trio: *trials unadmitting* (singles unpassing — lanes unnarowed (recoveries untested — opens permanenting (unadmitting billing — healing missing); *recoveries untesting* (health unchecked — latencies unmeasured (flaps undetected — closes prematureing (untesting charging — confidence bluffing); *closes unearned* (successes uncounted — confidence unrebuilt (circuits flapping — neighbors whiplashing (unearned costing — stability failing). Half-open probes converting permanence to admitting (singles passing — health checking (successes counting — closes earning); reviewers finding probe policies per breaker (probing proving → verifiable; permanence → returned).

**Modern guidance** — the probing lines per breaker (review-enforced): *trials admitting* (singles passing — lanes narrowing (loads sampling — flooding declining (admitting proving — blocking refusing (singles earning — healing testing); *recoveries testing* (health checking — latencies measuring (errors watching — assuming declining (testing funding — flapping refusing (checks owning — confidence earning); *closes earning* (successes counting — confidence rebuilding (circuits closing — flapping declining (earning owning — premature refusing (counts funding — stability keeping).

```typescript
// GOOD: probes half-opening — admitted trials testing recoveries (compiled + run live).
type Breaker = 'CLOSED' | 'OPEN' | 'HALF';
function probe(state: Breaker, trialOk: boolean, need: number, have: number): Breaker {
  if (state === 'OPEN') return 'HALF'; // trials admitting — singles passing, flooding declining
  if (state === 'HALF') return trialOk && have + 1 >= need ? 'CLOSED' : 'OPEN'; // recoveries testing — health checking, assuming declining
  return state; // closes earning — successes counting, flapping declining
}
console.log(probe('OPEN', true, 2, 0) === 'HALF' && probe('HALF', true, 2, 1) === 'CLOSED' && probe('HALF', false, 2, 1) === 'OPEN' && probe('CLOSED', true, 2, 9) === 'CLOSED' ? 'probes half-open' : 'breakers stick');
```

```typescript
// BAD: breakers sticking — trials unadmitting, closes unearned (real permanent shape).
// // Open forever (recoveries untested — opens permanenting — healing missing).
// // Manual reset (confidence bluffing — neighbors whiplashing). Admit trials; test recoveries; earn closes.)
```

**Common confusion** — *"half-open risks thunder (trials flooding)."* Flooding admitting crowds (lanes widening — loads surging (recoveries drowning — servers relapsing (flooding charging — healing failing); probing admitting singles (trials passing-one (loads sampling — recoveries testing (admitting proving — flooding declining). "Risks" describing crowds (lanes widening — loads surging); half-open describing samples (singles passing — health checking). Admit one (singles passing — loads sampling); earn close (successes counting — flapping declining).

**Performance note** — probing economics: admitting costing singles (trials passing — health checking (successes counting — closes earning); stuck equivalents costing permanence (recoveries untested — opens permanenting (healing missing — neighbors waiting). Admit cheaply (trials — breakers); stick never (opens — recoveries).

**Mentor note** — teach "open recovers through one trial at a time" (juniors admitting one probe per breaker design stick-proof circuits on first hearing; trialless breakers interrogated ("recovers how?" — probing demanding per breaker). Probe one trial once (singles passing — health checking tangible (permanence ending — probing proving permanently). Narrow lanes; count successes — probing discipline in three habits, reviewed per breaker.

## 3. Cascades containing (neighbors shielding — fallbacks serving — availability keeping)

**Definition** — contained cascades: shielded neighbors serving fallbacks keeping availability (neighbors shielding — faults isolating (blasts bounding — callers decoupling (shielding proving — propagating declining); fallbacks serving — defaults stating (degrades declaring (users keeping — trust holding (serving owning — crashing declining); availability keeping — SLOs holding (downtimes bounding — contracts honoring (keeping owning — breaching declining).

**What problem it solves** — the domino trio: *neighbors unshielding* (faults unisolating — blasts unbounding (callers coupling — failures hopping (unshielding billing — containment failing); *fallbacks unserving* (defaults unstating — degrades undeclared (users losing — trust eroding (unserving charging — grace missing); *availability unkeeping* (SLOs unheld — downtimes unbounded (contracts breaching — pages multiplying (unkeeping costing — promises bluffing). Contained cascades converting hopping to shielding (faults isolating — defaults stating (SLOs holding — availability keeping); reviewers finding bulkheads per neighbor (containing proving → verifiable; hopping → returned).

**Modern guidance** — the containing lines per neighbor (review-enforced): *neighbors shielding* (faults isolating — blasts bounding (callers decoupling — propagating declining (shielding proving — hopping refusing (shields earning — dominoes ending); *fallbacks serving* ([1.1](<../../sections/1. Fault thinking/1.1. Timeouts bounding waits.md>) — defaults stating (degrades declaring — users keeping (serving owning — crashing refusing (states funding — grace earning); *availability keeping* (SLOs holding — downtimes bounding (contracts honoring — breaching declining (keeping owning — hoping refusing (holds earning — trust keeping).

```typescript
// GOOD: cascades containing — shielded neighbors serving fallbacks (compiled + run live).
function contained(neighbors: number, shielded: number, fallbackOk: boolean): string {
  if (shielded < neighbors) return 'EXPOSED'; // neighbors shielding — faults isolating, propagating declining
  return fallbackOk ? 'DEGRADED' : 'DOWN'; // fallbacks serving — defaults stating, crashing declining
  // availability keeping — SLOs holding, breaching declining (asserted below)
}
console.log(contained(3, 3, true) === 'DEGRADED' && contained(3, 2, true) === 'EXPOSED' && contained(3, 3, false) === 'DOWN' ? 'cascades contain' : 'dominoes fall');
```

```typescript
// BAD: dominoes falling — neighbors unshielding, fallbacks unserving (real cascade shape).
// // One failure, three outages (faults hopping — blasts widening — callers coupling).
// // No fallback (users losing — trust eroding). Shield neighbors; serve fallbacks; hold SLOs.)
```

**Common confusion** — *"containing accepts failure (shields surrendering)."* Surrendering tolerating outages (faults winning — users losing (downtimes extending — trust eroding (surrendering charging — resilience failing); containing bounding blast (faults isolating — fallbacks serving (SLOs holding — availability keeping (containing proving — hopping declining). "Accepting" describing defeat (outages tolerating — users losing); containing describing bulkheads (neighbors shielding — dominoes ending). Isolate faults (blasts bounding — callers decoupling); keep availability (SLOs holding — contracts honoring).

**Performance note** — containing economics: shielding costing bulkheads (faults isolating — defaults stating (SLOs holding — availability keeping); domino equivalents costing wholes (blasts widening — users losing (contracts breaching — trust eroding). Shield cheaply (neighbors — faults); domino never (cascades — systems).

**Mentor note** — teach "every neighbor stands behind glass" (juniors shielding one neighbor per dependency design domino-proof topologies on first hearing; unshielded neighbors interrogated ("blast radius?" — containing demanding per neighbor). Contain one cascade once (faults isolating — fallbacks serving tangible (hopping ending — containing proving permanently). Bound blasts; state defaults — containing discipline in three habits, reviewed per neighbor.
