# 2.2. Sagas compensating stepwise

## 1. Steps journaling (forwards staging — progress persisting — restarts resuming)

**Definition** — journaled steps: staged forwards with persisted progress resuming restarts (forwards staging — intents ordering (work chunking — locks declining (staging proving — lumping declining); progress persisting — journals appending (states checkpointing — positions remembering (persisting funding — amnesia declining); restarts resuming — crashes recovering (positions rereading — work continuing (resuming owning — rerunning declining).

**What problem it solves** — the amnesiac-flow trio: *forwards unstaging* (intents unlumping — work unchunking (locks requiring — parties blocking (unstaging billing — flow missing); *progress unpersisting* (journals unappended — states uncheckpointed (restarts rerunning — steps duplicating (unpersisting charging — recovery guessing); *restarts unresuming* (crashes unrecovered — positions unread (work restarting — effects doubling (unresuming costing — convergence failing). Journaled steps converting amnesia to staging (intents ordering — journals appending (crashes recovering — restarts continuing); reviewers finding step journals per saga (journaling proving → verifiable; amnesia → returned).

**Modern guidance** — the journaling lines per saga (review-enforced): *forwards staging* ([CA 02/2.1](<../../../../CleanArchitecture/02 Use Cases and Application Services/sections/2. Long flows/2.1. Sagas sequencing without distributed lockstep.md>) — intents ordering (work chunking — locks declining (staging proving — lumping refusing (orders earning — blockage ending); *progress persisting* (journals appending — states checkpointing (positions remembering — amnesia declining (persisting funding — guessing refusing (appends keeping — recovery owning); *restarts resuming* (crashes recovering — positions rereading (work continuing — rerunning declining (resuming owning — doubling refusing (recoveries funding — convergence earning).

```typescript
// GOOD: steps journaling — staged forwards with persisted progress (compiled + run live).
interface StepLog { // forwards staging — intents ordering, lumping declining
  step: string;
  done: boolean;
}
function resume(log: StepLog[]): string {
  for (const s of log) { // progress persisting — journals appending, amnesia declining
    if (!s.done) return s.step;
  }
  return 'COMPLETE'; // restarts resuming — crashes recovering, rerunning declining
}
const crashed: StepLog[] = [
  { step: 'reserve', done: true },
  { step: 'charge', done: false },
  { step: 'ship', done: false },
];
const finished: StepLog[] = [
  { step: 'reserve', done: true },
  { step: 'charge', done: true },
];
console.log(resume(crashed) === 'charge' && resume(finished) === 'COMPLETE' ? 'steps journal' : 'flows forget');
```

```typescript
// BAD: flows forgetting — forwards unstaging, progress unpersisting (real amnesia shape).
// // Chain calls (intents unlumping — locks requiring — parties blocking).
// // Crash reruns all (steps duplicating — effects doubling). Stage forwards; persist progress; resume restarts.)
```

**Common confusion** — *"journals slow sagas (writes taxing)."* Taxing adding latency (appends costing — checkpoints pausing (throughput dipping — speed missing (taxing charging — speed failing); journaling enabling recovery (progress persisting — restarts resuming (duplicates preventing — convergence earning (enabling proving — amnesia declining). "Slowing" describing microseconds (appends costing — throughput dipping); journals describing survival (positions remembering — work continuing). Append journals (states checkpointing — recovery owning); resume crashes (positions rereading — doubling preventing).

**Performance note** — journaling economics: staging costing appends (intents ordering — journals appending (crashes recovering — restarts continuing); amnesiac equivalents costing doubles (steps duplicating — effects doubling (recovery guessing — trust eroding). Append cheaply (journals — steps); forget never (flows — crashes).

**Mentor note** — teach "every step journals before acting" (juniors appending one journal per step design amnesia-proof sagas on first hearing; unjournaled steps interrogated ("resume from where?" — journaling demanding per step). Journal one step once (intents ordering — progress persisting tangible (amnesia ending — journaling proving permanently). Order intents; remember positions — journaling discipline in three habits, reviewed per saga.

## 2. Inverses unwinding (compensators naming — order reversing — converges earning)

**Definition** — unwound inverses: named compensators reversing order earning convergence (compensators naming — undos owning (steps pairing — failures planning (naming proving — stranding declining); order reversing — unwinds sequencing-backward (dependencies respecting — states restoring (reversing funding — corrupting declining); converges earning — ends enumerating (audits passing — customers informing (earning owning — diverging declining).

**What problem it solves** — the uncompensated trio: *compensators unnamed* (undos unowned — steps unpaired (failures stranding — halves persisting (unnamed billing — consistency breaking); *orders unreversing* (unwinds sequencing-forward (dependencies violating — states corrupting (unreversing charging — retreat failing); *converges unearned* (ends unenumerated — audits unpassing (customers uninformed — trust eroding (unearned costing — divergence ruling). Unwound inverses converting stranding to naming (undos owning — unwinds reversing (ends enumerating — convergence earning); reviewers reading inverses per step (unwinding proving → verifiable; stranding → returned).

**Modern guidance** — the unwinding lines per step (review-enforced): *compensators naming* (undos owning — steps pairing (failures planning — stranding declining (naming proving — missing refusing (names earning — halves ending); *order reversing* (unwinds sequencing-backward — dependencies respecting (states restoring — corrupting declining (reversing funding — forwarding refusing (reversals keeping — retreat succeeding); *converges earning* (ends enumerating — audits passing (customers informing — diverging declining (earning owning — hoping refusing (enumerations funding — trust keeping).

```typescript
// GOOD: inverses unwinding — named compensators reversing order (compiled + run live).
interface Compensated { // compensators naming — undos owning, stranding declining
  step: string;
  undo: string;
}
function unwind(done: string[], plan: Compensated[]): string[] {
  const undos: string[] = []; // order reversing — unwinds sequencing-backward, corrupting declining
  for (let i = done.length - 1; i >= 0; i--) {
    const found = plan.filter((p) => p.step === done[i])[0];
    undos.push(found === undefined ? `missing-undo:${done[i]}` : found.undo);
  }
  return undos; // converges earning — ends enumerating, diverging declining
}
const plan: Compensated[] = [
  { step: 'reserve', undo: 'release' },
  { step: 'charge', undo: 'refund' },
];
console.log(unwind(['reserve', 'charge'], plan).join() === 'refund,release' ? 'inverses unwind' : 'steps strand');
```

```typescript
// BAD: steps stranding — compensators unnamed, orders unreversing (real half-shape).
// // charge, ship (undos unowned — failures stranding — halves persisting).
// // Undo forward (dependencies violating — states corrupting). Name compensators; reverse order; earn convergence.)
```

**Common confusion** — *"compensations are rollbacks (undos reverting)."* Reverting rewinding storage (transactions unwinding — partials vanishing (atomicity restoring — invisibility returning (reverting serving — simplicity funding); inverses compensating business (undos owning — orders reversing (ends enumerating — convergence earning (compensating proving — stranding declining). "Rollbacks" describing storage (partials vanishing — atomicity restoring); inverses describing business (refunds issuing — releases freeing). Name undos (compensators owning — failures planning); reverse carefully (dependencies respecting — states restoring).

**Performance note** — unwinding economics: naming costing inverses (undos owning — orders reversing (ends enumerating — convergence earning); stranded equivalents costing halves (failures stranding — states corrupting (customers uninformed — trust eroding). Name cheaply (undos — steps); strand never (flows — halves).

**Mentor note** — teach "every forward ships its backward" (juniors naming one inverse per step design strand-proof sagas on first hearing; inverseless steps interrogated ("undo how?" — unwinding demanding per step). Unwind one saga once (undos owning — orders reversing tangible (stranding ending — unwinding proving permanently). Pair steps; reverse order — unwinding discipline in three habits, reviewed per saga.

## 3. Drivers placing (flows orchestrating — reactions choreographing — sizes weighing)

**Definition** — placed saga drivers: orchestrated flows with choreographed reactions weighed by size (flows orchestrating — drivers deciding (steps commanding — visibility earning (orchestrating proving — scattering declining); reactions choreographing — parties emitting (listeners reacting — couples loosening (choreographing funding — centralizing declining); sizes weighing — steps counting (owners scattering — drivers assigning (weighing proving — defaulting declining).

**What problem it solves** — the undriven-saga trio: *flows unorchestrating* (drivers undeciding — steps uncommanded (visibility missing — debugs fumbling (unorchestrating billing — ownership failing); *reactions unchoreographing* (parties unemitting — listeners unreacting (couples tightening — bottlenecks forming (unchoreographing charging — decoupling failing); *sizes unweighing* (steps uncounting — owners unscattering (drivers defaulting — sprawls scheduling (unweighing costing — judgment missing). Placed drivers converting drifting to deciding (drivers commanding — parties emitting (steps counting — sizes judging); reviewers finding driver choices per saga (placing proving → verifiable; drifting → returned).

**Modern guidance** — the placing lines per saga (review-enforced): *flows orchestrating* ([CA 02/2.1](<../../../../CleanArchitecture/02 Use Cases and Application Services/sections/2. Long flows/2.1. Sagas sequencing without distributed lockstep.md>) — drivers deciding (steps commanding — visibility earning (orchestrating proving — scattering refusing (decisions owning — fumbling ending); *reactions choreographing* ([1.2](<../../sections/1. Event thinking/1.2.
```typescript
// GOOD: drivers placing — orchestrated flows with weighed sizes (compiled + run live).
function driverFor(steps: number, owners: number): string {
  if (steps <= 3 && owners <= 1) return 'choreography'; // reactions choreographing — parties emitting, centralizing declining
  return 'orchestrator'; // flows orchestrating — drivers deciding, scattering declining
}
function sized(drivers: string[]): boolean {
  return drivers.every((d) => d === 'choreography' || d === 'orchestrator'); // sizes weighing — steps counting, defaulting declining
}
console.log(driverFor(2, 1) === 'choreography' && driverFor(9, 4) === 'orchestrator' && sized(['choreography', 'orchestrator']) ? 'drivers place' : 'sagas drift');
```
