# 3.1. NestJS event slice emitting subscribing

## 1. Emits firing (events publishing — responses unawaiting — callers freeing)

**Definition** — fired emits: published events with unawaited responses freeing callers (events publishing — facts streaming (versions tagging — consumers ignoring (publishing proving — blocking declining); responses unawaiting — senders continuing (threads freeing — journeys flowing (unawaiting owning — hanging declining); callers freeing — producers unblocking (latencies hiding — throughput earning (freeing funding — coupling declining).

**What problem it solves** — the awaited-event trio: *emits unfiring* (facts unpublished — versions untagged (consumers unsubscribed — producers blocking (unfiring billing — events missing); *responses unawaited* (senders uncontinuing — threads unfreeing (journeys stalling — throughput capping (unawaited charging — freeing failing); *callers unfreeing* (producers unblocking — latencies unhiding (couples tightening — autonomy bluffing (unfreeing costing — decoupling failing). Fired emits converting awaiting to publishing (facts streaming — senders continuing (producers unblocking — callers flowing); reviewers finding emits per fact (firing proving → verifiable; awaiting → returned).

**Modern guidance** — the firing lines per fact (review-enforced): *events publishing* ([1.1](<../../sections/1. Event thinking/1.1. Events streaming facts.md>) — facts streaming (versions tagging — consumers ignoring (publishing proving — blocking refusing (streams earning — throughput keeping); *responses unawaiting* (senders continuing — threads freeing (journeys flowing — hanging refusing (unawaiting owning — stalling declining (continuations funding — leaks ending); *callers freeing* (producers unblocking — latencies hiding (throughput earning — coupling declining (freeing funding — tightening refusing (freedom keeping — autonomy earning).

```typescript
// GOOD: emits firing — published facts with freed callers over TCP (compiled + run live).
import 'reflect-metadata';
import { Controller, Module } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { ClientProxy, ClientProxyFactory, EventPattern, MicroserviceOptions, Payload, Transport } from '@nestjs/microservices'; // TCP underneath — transport stated, blocking declining

const received: string[] = []; // responses unawaiting — senders continuing, hanging declining

@Controller()
class NotifyController { // events publishing — facts streaming, blocking declining
  @EventPattern('order.placed')
  placed(@Payload() data: { id: string }): void {
    received.push(data.id);
  }
}

@Module({ controllers: [NotifyController] })
class NotifyModule {}

async function runEmit(): Promise<void> {
  const server = await NestFactory.createMicroservice<MicroserviceOptions>(NotifyModule, {
    transport: Transport.TCP,
    options: { host: '127.0.0.1', port: 38941 },
  });
  await server.listen();
  const client: ClientProxy = ClientProxyFactory.create({ // callers freeing — producers unblocking, coupling declining
    transport: Transport.TCP,
    options: { host: '127.0.0.1', port: 38941 },
  });
  await client.connect();
  client.emit('order.placed', { id: 'o1' });
  await new Promise((r) => setTimeout(r, 800));
  console.log(received.join() === 'o1' ? 'emits fire' : 'events await');
  client.close();
  await server.close();
}
runEmit();
```

## 2. Handlers subscribing (patterns matching — payloads typing — effects applying)

**Definition** — subscribed handlers: matched patterns with typed payloads applying effects (patterns matching — events routing (interests declaring — handlers owning (matching proving — polling declining); payloads typing — shapes asserting (fields requiring — garbage declining (typing funding — hoping declining); effects applying — states mutating (ledgers appending — notifies sending (applying owning — dropping declining).

**What problem it solves** — the unhandled trio: *patterns unmatching* (events unrouting — interests undeclared (handlers unowned — reactions missing (unmatching billing — subscription failing); *payloads untyping* (shapes unasserted — fields unchecked (garbage arriving — handlers breaking (untyping charging — trust eroding); *effects unapplying* (states unmutated — ledgers unappended (notifies unsent — work vanishing (unapplying costing — reliability bluffing). Subscribed handlers converting missing to matching (events routing — shapes asserting (states mutating — effects landing); reviewers finding handlers per event (subscribing proving → verifiable; missing → returned).

**Modern guidance** — the subscribing lines per event (review-enforced): *patterns matching* (events routing — interests declaring (handlers owning — polling declining (matching proving — missing refusing (routes earning — reactions keeping); *payloads typing* (shapes asserting — fields requiring (garbage declining — hoping refusing (types owning — breaks declining (assertions funding — trust keeping); *effects applying* (states mutating — ledgers appending (notifies sending — dropping declining (applying owning — vanishing refusing (applications earning — reliability keeping).

```typescript
// GOOD: handlers subscribing — matched patterns with typed payloads (compiled + run live).
interface Handler { // patterns matching — events routing, polling declining
  event: string;
  needs: string[];
}
function unmatched(handlers: Handler[], event: string, keys: string[]): string {
  const mine = handlers.filter((h) => h.event === event)[0]; // payloads typing — shapes asserting, hoping declining
  if (mine === undefined) return 'NO-HANDLER';
  for (const k of mine.needs) {
    if (!keys.includes(k)) return 'MALFORMED';
  }
  return 'APPLY'; // effects applying — states mutating, dropping declining
}
const handlers: Handler[] = [{ event: 'order.placed', needs: ['id', 'total'] }];
console.log(unmatched(handlers, 'order.placed', ['id', 'total']) === 'APPLY' && unmatched(handlers, 'order.placed', ['id']) === 'MALFORMED' && unmatched(handlers, 'nope', []) === 'NO-HANDLER' ? 'handlers subscribe' : 'events miss');
```

## 3. Flows proving (inject driving — receipts asserting — redeliveries converging)

**Definition** — proved event flows: driven emits asserting receipts converging redeliveries (inject driving — clients emitting (patterns exercising — handlers firing (driving proving — hoping declining); receipts asserting — arrivals checking (ids recording — effects counting (asserting funding — bluffing declining); redeliveries converging — duplicates replaying (keys deduping — originals returning (converging owning — doubling declining).

**What problem it solves** — the fire-and-forget trio: *flows undriving* (emits unfired — patterns unexercised (handlers idleing — reactions hoping (undriving billing — integration missing); *receipts unasserting* (arrivals unchecked — ids unrecorded (effects uncounted — proofs missing (unasserting charging — confidence bluffing); *redeliveries unconverging* (duplicates reapplying — keys undemanding (originals unreturned — ledgers drifting (unconverging costing — correctness failing). Driven flows converting forgetting to asserting (clients emitting — arrivals checking (duplicates replaying — effects converging); reviewers asserting receipts per emit (proving revealing → verifiable; forgetting → returned).

**Modern guidance** — the proving lines per flow (review-enforced): *inject driving* (clients emitting — patterns exercising (handlers firing — hoping declining (driving proving — idleing refusing (drives earning — flakes declining); *receipts asserting* (arrivals checking — ids recording (effects counting — bluffing declining (asserting funding — missing refusing (receipts owning — confidence earning); *redeliveries converging* ([2.1](<../../sections/2.
```typescript
// GOOD: flows proving — driven emits with converging redeliveries (compiled + run live).
import 'reflect-metadata';
import { Controller, Module } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { ClientProxy, ClientProxyFactory, EventPattern, MicroserviceOptions, Payload, Transport } from '@nestjs/microservices'; // TCP underneath — transport stated, forgetting declining

const applied = new Set<string>(); // inject driving — clients emitting, hoping declining

@Controller()
class DedupController {
  @EventPattern('wallet.credited')
  credited(@Payload() data: { id: string }): void {
    applied.add(data.id); // receipts asserting — arrivals checking, bluffing declining
  }
}

@Module({ controllers: [DedupController] })
class DedupModule {}

function converged(emits: string[]): number {
  return new Set(emits).size; // redeliveries converging — duplicates replaying, doubling declining
}

async function runFlow(): Promise<void> {
  const server = await NestFactory.createMicroservice<MicroserviceOptions>(DedupModule, {
    transport: Transport.TCP,
    options: { host: '127.0.0.1', port: 38942 },
  });
  await server.listen();
  const client: ClientProxy = ClientProxyFactory.create({
    transport: Transport.TCP,
    options: { host: '127.0.0.1', port: 38942 },
  });
  await client.connect();
  client.emit('wallet.credited', { id: 'w1' });
  client.emit('wallet.credited', { id: 'w1' });
  client.emit('wallet.credited', { id: 'w2' });
  await new Promise((r) => setTimeout(r, 900));
  const unique = converged([...applied]);
  console.log(applied.size === 2 && unique === 2 ? 'flows prove' : 'fires forget');
  client.close();
  await server.close();
}
runFlow();
```
