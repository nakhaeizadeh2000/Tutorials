# 4.1. Decomposition checklist mentors insist on

## 1. Every boundary clustering (capabilities grouping — tables owning — cuts validating)

**Definition** — the boundary line on every service: capabilities proving (behaviors grouping — teams aligning (services emerging — layers declining (proving owning — slicing declining); tables proving (writes singling — reads serving (joins declining — sharing declining (proving funding — pooling declining); cuts proving (calls counting — autonomy earning — theater declining (proving earning — hoping declining).

**What problem it solves** — the unclustered trio: *capabilities ungrouping* (behaviors scattering — teams diffusing (services layering — cohesion failing (ungrouping billing — capability missing); *tables unowning* (writes sharing — joins spanning (transactions distributing — consistency failing (unowning charging — ownership missing); *cuts unvalidating* (calls uncounting — autonomy unproving (theater ruling — evidence missing (unvalidating costing — hoping bluffing). Clustered boundaries converting layering to proving (behaviors grouping — writes singling (calls counting — cohesion earning); reviewers finding capability-table-cut triples per service (clustering proving → verifiable; layering → returned).

**Modern guidance** — the clustering lines per service (review-enforced): *capabilities proving* ([1.1](<../../sections/1. Boundary thinking/1.1. Capabilities clustering contexts.md>) — behaviors grouping (teams aligning — services emerging (proving owning — slicing refusing); *tables proving* ([1.2](<../../sections/1. Boundary thinking/1.2. Data owning per service.md>) — writes singling (reads serving — joins declining (proving funding — pooling refusing); *cuts proving* ([1.1](<../../sections/1. Boundary thinking/1.1. Capabilities clustering contexts.md>) — calls counting (autonomy earning — theater declining (proving earning — hoping refusing).

```typescript
// GOOD: every boundary clustering — capabilities, tables, cuts per service (process shape, reviewed).
// - Capabilities grouped with aligned teams (behaviors naming — owners answering — services emerging).
// - Tables owned with singled writers (owners writing — spans refusing — consistency bounding).
// - Cuts validated with counted calls (edges listing — autonomy earning — theater declining.)
```

```typescript
// BAD: boundaries layering — behaviors scattering, tables sharing, cuts hoping (real layer shape).
// // Layer-per-service (features scattering — cohesion failing). Shared tables (locks escalating).
// // Uncounted cuts (theater ruling — evidence missing). Group behaviors; own tables; validate cuts.)
```

**Common confusion** — *"clustering is upfront design (analysis paralyzing)."* Paralyzing deferring decisions (workshops looping — diagrams aging (splits waiting — momentum dying (paralyzing charging — courage taxing); clustering bounding iteration (behaviors grouping — tables owning (cuts validating — cohesion earning (bounding proving — layering declining). "Upfront" describing big-design (analysis looping — decisions deferring); clustering describing maps (capabilities naming — cuts auditing). Group coarsely (behaviors naming — teams aligning); validate continuously (calls counting — autonomy earning).

**Performance note** — clustering-check economics: grouping costing maps (behaviors naming — tables owning (calls counting — cohesion earning); layered equivalents costing shotgun changes (features scattering — locks escalating (theater ruling — trust eroding). Map cheaply (boundaries — services); layer never (slices — tables).

**Mentor note** — teach "capability, table, cut — every service" (juniors owning per service design layer-proof boundaries on first hearing; unmapped services interrogated ("capability? tables? calls?" — clustering demanding per service). Cluster one boundary once (behaviors grouping — writes singling tangible (layering ending — clustering proving permanently). Name capabilities; count calls — clustering discipline in three habits, reviewed per service.

## 2. Every coupling measuring (edges counting — instability pricing — directions correcting)

**Definition** — the coupling line on every edge: edges proving (fan-ins tallying — fan-outs tallying (meshes surfacing — hiding declining (proving owning — burying declining); instability proving (volatility scoring — dependents warning (changes budgeting — vibing declining (proving funding — surprising declining); directions proving (stables depending — abstractions owning (cycles breaking — inverting declining (proving earning — rippling declining).

**What problem it solves** — the unmeasured trio: *edges uncounting* (dependents unlisting — breakages untracing (meshes hiding — graphs tangling (uncounting billing — visibility failing); *instability unpricing* (ratios uncomputing — dependents unwarning (surprises scheduling — calibration missing (unpricing charging — arithmetic failing); *directions uncorrecting* (volatiles depending-upon — cycles unbreaking (ripples scheduling — builds deadlocking (uncorrecting costing — autonomy bluffing). Measured coupling converting hiding to proving (dependents listing — ratios computing (arrows correcting — tangles surfacing); reviewers finding edge tables per service (measuring proving → verifiable; hiding → returned).

**Modern guidance** — the measuring lines per edge (review-enforced): *edges proving* ([2.1](<../../sections/2. Coupling thinking/2.1. Coupling thinking/2.1. Afferent efferent measuring coupling.md>) — volatility scoring (dependents warning — changes budgeting (proving funding — vibing refusing); *directions proving* ([2.1](<../../sections/2. **Common confusion** — *"measuring is academic (metrics theorizing)."* Theorizing detaching numbers (ratios computing — decisions missing (papers citing — incidents continuing (theorizing charging — practice failing); measuring sizing blasts (dependents listing — ratios scoring (arrows correcting — tangles surfacing (sizing proving — hiding declining). "Academic" describing detachment (numbers computing — decisions missing); measuring describing visibility (edges tallying — blasts stating). Tally dependents (fan-ins listing — pages preventing); correct directions (stables depending — ripples ending).

**Performance note** — measuring-check economics: tallying costing tables (edges listing — ratios scoring (arrows correcting — tangles surfacing); hidden equivalents costing surprises (blasts unsizing — rollouts gambling (builds deadlocking — trust eroding). Tally cheaply (edges — services); hide never (graphs — meshes).

**Mentor note** — teach "edges, ratio, arrow — every dependency" (juniors measuring per edge design tangle-proof coupling on first hearing; unmeasured edges interrogated ("I value? stable which way?" — measuring demanding per edge). Measure one edge once (dependents listing — ratios computing tangible (hiding ending — measuring proving permanently). Score volatility; acyclic graphs — measuring discipline in three habits, reviewed per dependency.

## 3. Every share versioning (kernels minimizing — edges translating — drifts catching)

**Definition** — the sharing line on every cross-service import: kernels proving (shares shrinking — versions numbering (spreads bounding — sprawling declining (proving owning — bloating declining); edges proving (ACLs owning — cores shielding (upstreams tracking — seeping declining (proving funding — leaking declining); drifts proving (pacts replaying — breaks gating (upgrades sequencing — silence declining (proving earning — stranding declining).

**What problem it solves** — the unversioned trio: *kernels unshrinking* (shares sprawling — versions unnumbering (spreads unbounding — ripples compounding (unshrinking billing — kernel bloating); *edges untranslating* (ACLs unowning — cores unshielding (corruption seeping — firefighting scheduling (untranslating charging — shielding missing); *drifts uncatching* (pacts unreplaying — breaks ungating (upgrades unsequencing — consumers stranding (uncatching costing — safety theatering). Versioned shares converting sprawling to proving (shares shrinking — ACLs owning (pacts replaying — drift failing); reviewers finding kernel versions per share (versioning proving → verifiable; sprawling → returned).

**Modern guidance** — the versioning lines per share (review-enforced): *kernels proving* ([2.2](<../../sections/2. Coupling thinking/2.2. Shared kernel versioning contracts.md>) — shares shrinking (versions numbering — spreads bounding (proving owning — bloating refusing); *edges proving* ([2.2](<../../sections/2. Coupling thinking/2.2. Shared kernel versioning contracts.md>) — ACLs owning (cores shielding — upstreams tracking (proving funding — leaking refusing); *drifts proving* ([2.2](<../../sections/2. Coupling thinking/2.2. Shared kernel versioning contracts.md>) — pacts replaying (breaks gating — upgrades sequencing (proving earning — stranding refusing).

```typescript
// GOOD: every share versioning — kernels, ACLs, pacts per import (process shape, reviewed).
// - Kernels minimized with numbered versions (fields essentializing — releases tagging — spreads bounding).
```

```typescript
// BAD: shares sprawling — kernels unshrinking, edges untranslating, drifts uncatching (real blob shape).
// // Common blob (surfaces widening — ripples compounding). Raw foreign models (corruption seeping).
// // Silent bumps (consumers stranding). Minimize kernels; own ACLs; replay pacts.)
```

**Common confusion** — *"versioning slows sharing (tags taxing)."* Taxing adding ceremony (versions numbering — releases tagging (time spending — value delaying (taxing charging — velocity dying); versioning bounding blast (shares shrinking — breaks dating (consumers migrating — surprises declining (bounding proving — sprawling declining). "Slowing" describing fear (tags avoiding — decisions ducking); versioning describing safety (releases tagging — drifts failing). Number versions (tags dating — discovery ending); replay pacts (filings matching — drift failing).

**Performance note** — versioning-check economics: numbering costing tags (shares shrinking — ACLs owning (pacts replaying — drift failing); sprawled equivalents costing ripples (surfaces widening — corruption seeping (consumers stranding — trust eroding). Number cheaply (kernels — shares); sprawl never (blobs — versions).

**Mentor note** — convert this leaf into the team's decomposition runbook: capabilities, tables, cuts, edges, ratios, arrows, kernels, ACLs, pacts — every service, every edge, every share. Quiz juniors on sight ("which capability? which ratio? which kernel?") until answers are environmental. Watch for checklist decay (decomposition discipline for a sprint, abandoned under deadline — fix with edge tables as review-blocking) and ceremony-theater ("checklist completed" without artifacts — fix with audit demands per item: calls counted, ratios scored, pacts green). Review check: boundaries clustering, couplings measuring, shares versioning — and the mentor's own services modeling all three visibly.
