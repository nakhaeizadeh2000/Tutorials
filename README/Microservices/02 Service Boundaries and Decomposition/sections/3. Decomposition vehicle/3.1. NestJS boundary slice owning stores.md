## 1. Stores owning (tables partitioning — writes singling — reads serving)

**Definition** — owned service stores: partitioned tables with singled writes serving reads (tables partitioning — stores separating (orders owning-orders (invoices owning-billing (partitioning proving — pooling declining); writes singling — owners writing (contenders queueing — conflicts serializing (singling funding — sharing declining); reads serving — patterns answering (queries returning — callers coding (serving owning — starving declining).

**What problem it solves** — the shared-store trio: *tables unpartitioning* (stores pooling — services co-writing (locks escalating — blasts widening (unpartitioning billing — isolation failing); *writes unsharing* (owners unlisted — contenders colliding (conflicts compounding — deadlocks scheduling (unsharing charging — ownership missing); *reads unstarving* (patterns unanswering — queries hanging (callers waiting — neighbors degrading (unstarving costing — serving failing). Owned stores converting pooling to partitioning (stores separating — owners writing (patterns answering — consistency bounding); reviewers finding owner stores per service (owning proving → verifiable; pooling → returned).

**Modern guidance** — the owning lines per service (review-enforced): *tables partitioning* ([1.2](<../../sections/1. Boundary thinking/1.2. Data owning per service.md>) — stores separating (orders owning-orders (invoices owning-billing (partitioning proving — pooling refusing (separations earning — blasts bounding); *writes singling* (owners writing — contenders queueing (conflicts serializing — sharing refusing (singling funding — colliding declining (owners keeping — deadlock ending); *reads serving* (patterns answering — queries returning (callers coding — starving refusing (serving owning — hanging declining (answers funding — degradation ending).

```typescript
// GOOD: stores owning — partitioned orders store serving reads over TCP (compiled + run live).
import 'reflect-metadata';
import { Controller, Module } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { ClientProxy, ClientProxyFactory, MessagePattern, MicroserviceOptions, Payload, Transport } from '@nestjs/microservices'; // TCP underneath — transport stated, pooling declining

@Controller()
class OrdersController { // tables partitioning — stores separating, pooling declining
  private readonly orders = new Map<string, string>();
  @MessagePattern({ cmd: 'place' })
  place(@Payload() data: { id: string }): object {
    this.orders.set(data.id, 'placed'); // writes singling — owners writing, sharing declining
    return { id: data.id, state: 'placed' };
  }
  @MessagePattern({ cmd: 'fetch' })
  fetch(@Payload() data: { id: string }): object {
    return { id: data.id, state: this.orders.get(data.id) ?? 'missing' }; // reads serving — patterns answering, starving declining
  }
}

@Module({ controllers: [OrdersController] })
class OrdersModule {}

async function runOrders(): Promise<void> {
  const server = await NestFactory.createMicroservice<MicroserviceOptions>(OrdersModule, {
    transport: Transport.TCP,
    options: { host: '127.0.0.1', port: 38921 },
  });
  await server.listen();
  const client: ClientProxy = ClientProxyFactory.create({
    transport: Transport.TCP,
    options: { host: '127.0.0.1', port: 38921 },
  });
  await client.connect();
  const placed = await client.send<object, { id: string }>({ cmd: 'place' }, { id: 'o1' }).toPromise();
  const got = await client.send<object, { id: string }>({ cmd: 'fetch' }, { id: 'o1' }).toPromise();
  const missed = await client.send<object, { id: string }>({ cmd: 'fetch' }, { id: 'o9' }).toPromise();
  console.log(
    JSON.stringify(placed) === '{"id":"o1","state":"placed"}' &&
      JSON.stringify(got) === '{"id":"o1","state":"placed"}' &&
      JSON.stringify(missed) === '{"id":"o9","state":"missing"}'
      ? 'stores own'
      : 'tables pool',
  );
  client.close();
  await server.close();
}
runOrders();
```

**Common confusion** — *"separate stores mean separate servers (hosts multiplying)."* Hosts multiplying hardware (servers provisioning — failures bounding (bills growing — capacity splitting (multiplying proving — sharing declining); stores scoping writes (owners writing — tables partitioning (conflicts serializing — joins declining (owning funding — pooling declining). "Servers" describing infrastructure (hosts provisioning — bills growing); stores describing ownership (writers singling — spans refusing). Partition logically (owners writing — blasts bounding); share hosts pragmatically (servers provisioning — bills bounding).

**Performance note** — owning economics: partitioning costing stores (tables separating — owners writing (patterns answering — consistency bounding); pooled equivalents costing contention (locks escalating — blasts widening (deadlocks scheduling — trust eroding). Partition cheaply (stores — services); pool never (tables — blasts).

**Mentor note** — teach "one store, one writer, on the wire" (juniors partitioning one table per service design pool-proof stores on first hearing; shared stores interrogated ("writer who?" — owning demanding per table). Own one store once (tables partitioning — writes singling tangible (pooling ending — owning proving permanently). Separate stores; single writes — owning discipline in three habits, reviewed per service.

```typescript
// GOOD: kernels sharing — versioned money contract coded by callers (compiled + run live).
interface MoneyKernel { // contracts versioning — releases tagging, ambushing declining
  version: string;
  amount: number;
  ccy: string;
}
function priced(m: MoneyKernel, wantVersion: string): string {
  if (m.version !== wantVersion) return 'STALE-KERNEL'; // callers coding — shapes trusting, assuming declining
  if (!(m.amount >= 0) || m.ccy.length !== 3) return 'MALFORMED';
  return `${m.amount}${m.ccy}`; // drifts failing — skews surfacing, shipping declining
}
const v3: MoneyKernel = { version: 'kernel-v3', amount: 42, ccy: 'USD' };
const stale: MoneyKernel = { version: 'kernel-v1', amount: 42, ccy: 'USD' };
console.log(priced(v3, 'kernel-v3') === '42USD' && priced(stale, 'kernel-v3') === 'STALE-KERNEL' ? 'kernels share' : 'shares ambush');
```

```typescript
@Module({ controllers: [BillingController] })
```
