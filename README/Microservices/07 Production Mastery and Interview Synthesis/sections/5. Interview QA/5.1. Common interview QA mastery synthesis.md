# 5.1. Common interview QA mastery synthesis

## 1. Systems live under pressure (services, contracts, evidence — designed with gates, priced)

**Definition** — the systems answer interviewers grade: given a product surface, design it end-to-end with gates ([1.1](<../../sections/1. Full-system design/1.1. Full-system service design composing domains.md>)/[1.2](<../../sections/1. Full-system design/1.2. Full-system delivery evidence proving journeys.md>)) — services proving (boundaries clustering — comms choosing (resilience embedding — slicing declining (proving owning — fragmenting declining); contracts proving (shapes versioning — events evolving (drifts failing — sprawling declining (proving funding — duplicating declining); evidence proving (gates greening — journeys driving (readiness dating — hoping declining (proving earning — assuming declining). "Live" means fifteen minutes max (clarify, compose, gate, price, rehearse — prioritized, not completed).

**What problem it solves** — the reciting trio: *services undescribing* (systems unlisting — boundaries unowning (designs narrating-patterns — journeys missing (undescribing serving — hiring failing (stories owning — systems doubting); *contracts unproving* (shapes unsharing — versions unscoped (depth reciting — integration hoping (unproving owning — mastery missing (claims serving — evidence failing); *evidence unpricing* (gates ungating — journeys undriven (judgment vibing — launches hoping (unpricing charging — ownership absenting (hope serving — calibration failing). Pressured systems converting reciting to composing (services clustering — contracts unifying (gates greening — answers holding); interviewers hearing systems with gates, not pattern names (composing proving → hirable; reciting → passed) — drawing on [1.1](<../../sections/1. Full-system design/1.1. Full-system service design composing domains.md>) and [1.2](<../../sections/1. Full-system design/1.2. Full-system delivery evidence proving journeys.md>).

**Modern guidance** — the systems lines (interview-enforced): *services composing* (boundaries clustering — comms choosing (resilience embedding — slicing declining (composing proving — fragmenting refusing); *contracts unifying* (shapes versioning — events evolving (pacts replaying — drifts failing (unifying funding — sprawling refusing); *evidence gating* (gates greening — journeys driving (readiness dating — hoping declining (gating owning — assuming refusing). Every design carrying service + contract + gate (judgment demonstrable — pressure survivable).

```typescript
// GOOD: systems answers — services, contracts, gates with traced proof (answer shape, hiring-grade).
// "Checkout clusters billing with owned tables (services composing — cuts validating).
//  Item v3 with green pacts (contracts unifying — drifts failing).
//  Merges gate on spec-pact-diff, journeys driven (evidence gating — hopes ending).
//  Priced per 10x with shed order bulk-first (judgment pricing — surprises declining).")
```

```typescript
// BAD: systems recitals — pattern names without services, claims without gates (real fail shape).
// // "Microservices with Kafka." (systems unlisting — boundaries unowning — stories owning).
// // "Tested." (gates ungating — evidence missing). Compose services; unify contracts; gate evidence.)
```

**Common confusion** — *"breadth answers systems (services listing)."* Listing reciting topologies (names enumerating — trade-offs missing (journeys untracing — gates unpricing (listing serving — designing failing); systems composing wholes (services clustering — contracts unifying (evidence gating — hopes ending (composing proving — reciting declining). "Breadth" describing vocabulary (services spelling — meaning missing); systems describing synthesis (domains composing — journeys completing). Cluster services (boundaries grouping — comms choosing); gate evidence (specs fetching — diffs passing).

**Performance note** — systems-answer economics: composing costing journeys (services clustering — contracts unifying (gates greening — answers holding); reciting equivalents costing doubt (names listing — evidence missing (depth doubting — hiring failing). Compose cheaply (systems — journeys); recite never (patterns — names).

**Mentor note** — drill "service, contract, gate" (candidates designing per surface with clustered services, unified contracts, and green gates defend systems on first hearing; pattern-list answers interrogated ("which service? which gate?" — systems demanding per design). Rehearse one checkout trace once (cluster-unify-gate tangible (reciting ending — composing proving permanently). Compose domains; price gates — systems answers in three artifacts, reviewed per interview.

## 2. Failures live under pressure (faults, blasts, recoveries — honesty stated, not hoped)

**Definition** — the failures answer interviewers grade: given an outage, narrate the rehearsal with MTTR ([2.2](<../../sections/2. Judgment/2.2. Failure rehearsal game-days owning blasts.md>)) — faults proving (scenarios scripting — surprises declining (drills owning — debuting declining (proving owning — improvising declining); blasts proving (scopes graduating — traffic sharing (damage limiting — debuting declining (proving funding — avalanching declining); recoveries proving (rollbacks readying — MTTR stating (trust earning — stranding declining (proving earning — fumbling declining). "Live" means honesty first (scripts stating — radii owning — MTTR quoting (truth proving — heroics declining).

**What problem it solves** — the heroics trio: *faults unscripting* (scenarios unlisting — surprises ruling (unknowns paging — incidents discovering (unscripting serving — hiring failing (stories owning — readiness doubting); *blasts unbounding* (radii unowning — damage unlimited (releases flipping — cascades avalanching (unbounding owning — discipline missing (theater serving — safety failing); *recoveries unquoting* (MTTR unknowing — reversals unfumbling (outages extending — trust eroding (unquoting charging — calibration missing (hope serving — honesty failing). Pressured failures converting heroics to scripting (scenarios scheduling — radii graduating (minutes quoting — answers holding); interviewers hearing scripts with MTTR, not war stories (scripting proving → hirable; heroics → passed) — drawing on [2.2](<../../sections/2. Judgment/2.2. Failure rehearsal game-days owning blasts.md>).

**Modern guidance** — the failures lines (interview-enforced): *faults narrating* (scenarios listing — unknowns asserting (rehearsals owning — surprises declining (narrating proving — debuting refusing); *blasts owning* (radii stating — traffic splitting (damage containing — avalanches preventing (owning funding — flipping refusing); *recoveries quoting* (MTTR stating — reversals rehearsing (trust earning — outages shrinking (quoting owning — fumbling refusing). Every story carrying script + radius + MTTR (judgment demonstrable — pressure survivable).

```typescript
// GOOD: failures answers — scripts, radii, MTTR with owned lessons (answer shape, hiring-grade).
// "Billing-down drilled quarterly at radius 2 with kill-switch (faults scripting — blasts bounding).
//  Last drill MTTR 8 minutes against a 15 target (recoveries quoting — trends shrinking).
//  Lesson: stale-pass window halved, pact added (learning owning — repeats preventing).")
```

```typescript
// BAD: failures heroics — war stories without scripts, uptime without MTTR (real fail shape).
// // "We stayed up all night." (scenarios unlisting — MTTR unknowing — heroics performing).
// // No lesson (repeats scheduling — trust eroding). Script faults; bound radii; quote MTTR.)
```

**Common confusion** — *"clean records answer failures (incidents denying)."* Denying hiding growth (outages unmentioning — lessons unlearning (luck masquerading — calibration missing (denying charging — honesty failing); failures narrating rehearsal (faults scripting — blasts bounding (recoveries quoting — trust earning (narrating proving — heroics declining). "Clean" describing luck (incidents hiding — lessons missing); failures describing readiness (scripts owning — MTTR quoting). Own outages (scripts listing — lessons owning); quote recoveries (MTTR stating — trust earning).

**Performance note** — failures-answer economics: scripting costing scenarios (faults narrating — radii stating (MTTR quoting — answers holding); heroics equivalents costing doubt (stories floating — numbers missing (calibration doubting — hiring failing). Script cheaply (faults — drills); heroicize never (nights — stories).

**Mentor note** — drill "script, radius, MTTR" (candidates answering per outage with scheduled faults, graduated blasts, and quoted recoveries defend failures on first hearing; heroics interrogated ("drilled when? MTTR what?" — failures demanding per story). Rehearse one outage narrative once (script-radius-MTTR tangible (heroics ending — scripting proving permanently). Schedule faults; own lessons — failures answers in three receipts, reviewed per interview.

## 3. Judgment live under pressure (prices, fashion, offers — ownership stated, not hoped)

**Definition** — the judgment answer interviewers grade: given a contested choice, defend it with prices ([2.1](<../../sections/2. Judgment/2.1. Judgment at scale pricing trade-offs.md>)) — prices proving (choices windowing — costs stating (surprises declining — trust earning (proving owning — vibing declining); fashion proving (recitation refusing — reasons demanding (independence keeping — hype ending (proving earning — mimicking declining); offers proving (judgment demonstrating — value proving (hiring earning — bluffing declining (earning owning — claiming declining). "Live" means defended trade-offs (options bounding — reversals dating — dissent welcoming (proof stating — dogma declining).

**What problem it solves** — the recitation trio: *prices unstating* (costs hiding — windows missing (choices vibing — surprises scheduling (unstating serving — hiring failing (claims owning — arithmetic doubting); *fashion undeclining* (slogans deciding — herds following (reasons missing — migrations costing (undeclining owning — independence failing (hype serving — engineering declining); *offers unearning* (judgment claiming — value asserting (proofs missing — pressure folding (unearning charging — hiring failing (bluff serving — calibration missing). Pressured judgment converting reciting to pricing (choices windowing — slogans interrogating (offers demonstrating — answers holding); interviewers hearing prices with reversals, not best practices (pricing proving → hirable; reciting → passed) — drawing on [2.1](<../../sections/2. Judgment/2.1. Judgment at scale pricing trade-offs.md>).

**Modern guidance** — the judgment lines (interview-enforced): *prices defending* (choices windowing — costs attaching (reversals dating — surprises declining (defending proving — vibing refusing); *fashion interrogating* (slogans questioning — reasons demanding (contexts fitting — herds declining (interrogating funding — mimicking refusing); *offers demonstrating* (judgment showing — value proving (pressure surviving — bluffing declining (demonstrating earning — claiming refusing). Every defense carrying price + reversal + dissent (judgment demonstrable — pressure survivable).

```typescript
// GOOD: judgment answers — prices, reversals, dissent with owned calls (answer shape, hiring-grade).
// "TCP sync at $30/100rps reversing to broker later (prices stating — windows bounding).
//  Declined mesh-everything: no priced reason fit our calls (fashion interrogating — teams choosing).
//  Would revisit past 10k rps with repriced tiers (dissent welcoming — judgment demonstrating).")
```

```typescript
// BAD: judgment recitals — best practices without prices, confidence without reversals (real fail shape).
// // "Industry standard." (slogans deciding — costs hiding — reasons missing).
// // No reversal (exits missing — pivots costing). State prices; date reversals; welcome dissent.)
```

**Common confusion** — *"confidence answers judgment (certainty performing)."* Performing pretending infallibility (doubts hiding — reversals missing (pressure bluffing — calibration failing (performing charging — trust risking); judgment owning uncertainty (prices stating — reversals dating (dissent welcoming — surprises declining (owning proving — dogma declining). "Confidence" describing delivery (certainty performing — doubts hiding); judgment describing ownership (prices defending — reversals planning). State prices (costs attaching — surprises declining); date reversals (windows bounding — pivots funding).

**Performance note** — judgment-answer economics: defending costing prices (choices windowing — slogans interrogating (offers demonstrating — answers holding); reciting equivalents costing doubt (slogans floating — prices missing (calibration doubting — hiring failing). Defend cheaply (prices — choices); recite never (practices — judgment).

**Mentor note** — drill "price, reversal, dissent" (candidates defending per choice with stated costs, dated exits, and welcomed counterarguments demonstrate judgment on first hearing; "best practice" interrogated ("priced how? reversed when?" — judgment demanding per claim). Rehearse one contested call once (price-reversal-dissent tangible (reciting ending — defending proving permanently). Attach prices; plan exits — judgment answers in three ownerships, reviewed per interview.
