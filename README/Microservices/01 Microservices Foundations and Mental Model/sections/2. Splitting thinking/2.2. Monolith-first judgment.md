# 2.2. Monolith-first judgment

## 1. Monoliths serving first (deploys singling — debugs simplifying — velocity funding)

**Definition** — monolith-first: one deployable serving until splits earn themselves (deploys singling — releases atomicking (versions locking-in-step (singling proving — matrix declining); debugs simplifying — stacks tracing (logs grepapping (states inspecting (simplifying funding — archaeology declining); velocity funding — ships accelerating (refactors fearlessing (onboards quickening (funding owning — toil declining).

**What problem it solves** — the premature-distribution trio: *deploys multiplying-early* (pipelines duplicating — matrices versioning (toil compounding — ships slowing (multiplying billing — autonomy bluffing); *debugs distributing* (traces spanning — logs scattering (states hiding — incidents archaeologizing (distributing charging — simplicity failing); *velocity taxing* (refactors fearing — onboards drowning (contracts negotiating — courage draining (taxing costing — shipping declining). First monoliths converting distribution to singling (releases atomicking — stacks tracing (ships accelerating — toil declining); reviewers finding split triggers before service diagrams (serving proving → verifiable; premature → returned).

**Modern guidance** — the serving lines per system (review-enforced): *deploys singling* (releases atomicking — versions locking-in-step (matrices declining — toil refusing (singling proving — multiplying declining (atoms owning — pipelines singling); *debugs simplifying* (stacks tracing — logs grepapping (states inspecting — archaeology declining (simplifying funding — spanning refusing (traces earning — incidents quickening); *velocity funding* (ships accelerating — refactors fearlessing (onboards quickening — toil declining (funding owning — taxing refusing (speed compounding — courage keeping).

```typescript
// GOOD: monoliths serving first — single deploys with simple debugs (compiled + run live).
interface System { // deploys singling — releases atomicking, matrix declining
  deployables: number;
  team: number;
  rps: number;
}
function splitNow(s: System): string {
  if (s.deployables > 1) return 'already-split'; // debugs simplifying — stacks tracing, archaeology declining
  if (s.team >= 8 || s.rps >= 5000) return 'earn-split';
  return 'monolith-first'; // velocity funding — ships accelerating, toil declining
}
const small: System = { deployables: 1, team: 3, rps: 200 };
const straining: System = { deployables: 1, team: 12, rps: 9000 };
console.log(splitNow(small) === 'monolith-first' && splitNow(straining) === 'earn-split' ? 'monoliths serve' : 'splits premature');
```

```typescript
// BAD: splits prematuring — deploys multiplying-early, velocity taxing (real regret shape).
// // Three engineers, nine services (pipelines duplicating — toil compounding — ships slowing).
// // Debugging across wires (traces spanning — incidents archaeologizing). Single deploys; simplify debugs; fund velocity.)
```

**Common confusion** — *"monolith means legacy (singles aging)."* Aging accruing debt (code fossilizing — deploys fearing (changes dreading — velocity dying (aging charging — health failing); first serving pragmatism (releases atomicking — debugs simplifying (ships accelerating — splits earning (serving proving — fashion declining). "Legacy" describing neglect (debt accruing — fear growing); monolith-first describing sequence (singles serving — splits earning). Serve monoliths (deploys singling — velocity funding); earn splits (triggers meeting — evidence stating).

**Performance note** — serving-first economics: singling costing nothing (releases atomic — debugs simple (ships fast — toil minimal); premature equivalents costing toil (pipelines duplicating — traces spanning (ships slowing — courage draining). Single cheaply (deploys — systems); premature never (splits — teams).

**Mentor note** — teach "monolith until the triggers fire" (juniors serving one deployable per system design regret-proof starts on first hearing; day-one distributions interrogated ("trigger which?" — serving demanding per service). Serve one monolith once (releases atomicking — debugs simplifying tangible (premature ending — serving proving permanently). Single releases; trace stacks — serving discipline in three habits, reviewed per system.

## 2. Extractions earning (teams growing — contexts straining — scales demanding)

**Definition** — earned extractions: splits triggered by teams, contexts, and scale (teams growing — coordination exceeding (ownership splitting — communication saturating (growing proving — coziness declining); contexts straining — meanings colliding (changes conflicting — releases coupling (straining funding — scoping declining); scales demanding — hotspots isolating (resources sizing — bottlenecks freeing (demanding owning — sharing declining).

**What problem it solves** — the uneared-extraction trio: *teams unexceeding* (coordination fitting — ownership clear (splits unneeded — communication flowing (unexceeding proving — extraction bluffing); *contexts unstraining* (meanings scoping — changes routing (releases decoupling — models holding (unstraining funding — splitting declining); *scales undemanding* (hotspots absenting — resources fitting (bottlenecks missing — scale coupling (undemanding owning — distribution bluffing). Earned extractions converting fashion to triggering (coordination exceeding — meanings colliding (hotspots isolating — splits proving); reviewers finding triggers per extraction (earning proving → verifiable; fashion → returned).

**Modern guidance** — the earning lines per extraction (review-enforced): *teams growing* (coordination exceeding — ownership splitting (communication saturating — coziness declining (growing proving — fitting refusing (growth owning — splits earning); *contexts straining* ([2.1](<./2.1. Seams before services.md>) — meanings colliding (changes conflicting — releases coupling (straining funding — holding refusing (strains surfacing — scopes demanding); *scales demanding* (hotspots isolating — resources sizing (bottlenecks freeing — sharing refusing (demanding owning — fitting declining (isolation funding — distribution earning).

```typescript
// GOOD: extractions earning — team, context, scale triggers per split (compiled + run live).
interface Triggers { // teams growing — coordination exceeding, coziness declining
  team: number;
  contexts: number;
  hotRps: number;
}
function earned(t: Triggers): string[] {
  const hits: string[] = []; // contexts straining — meanings colliding, holding declining
  if (t.team >= 8) hits.push('team');
  if (t.contexts >= 3) hits.push('context');
  if (t.hotRps >= 5000) hits.push('scale'); // scales demanding — hotspots isolating, fitting declining
  return hits;
}
const cozy: Triggers = { team: 3, contexts: 1, hotRps: 200 };
const ripe: Triggers = { team: 10, contexts: 4, hotRps: 9000 };
console.log(earned(cozy).length === 0 && earned(ripe).join() === 'team,context,scale' ? 'extractions earn' : 'fashion splits');
```

```typescript
// BAD: fashions splitting — triggers unfiring, extractions uneared (real covering shape).
// // "Scale demands it." at 200 rps (triggers unfiring — evidence missing — fashion deciding).
// // Three contexts, one team (coordination fitting — splits unneeded). Fire triggers; earn extractions; decline fashion.)
```

**Common confusion** — *"triggers delay inevitability (splits postponing)."* Postponing deferring value (extracts waiting — autonomy delaying (wins missing — momentum dying (postponing charging — courage taxing); triggering timing splits (teams exceeding — contexts colliding (scales demanding — evidence stating (triggering proving — fashion declining). "Delaying" describing fear (splits avoiding — decisions ducking); earning describing timing (triggers firing — evidence stating). Time splits (triggers firing — evidence stating); never fashion-split (hype deciding — regret scheduling).

**Performance note** — earning economics: triggering costing counts (teams counting — contexts scoping (scales measuring — splits proving); fashioned equivalents costing regret (evidence missing — toil compounding (surprises scheduling — trust eroding). Count cheaply (triggers — teams); fashion never (splits — hype).

**Mentor note** — teach "three triggers or it stays" (juniors firing team-context-scale per split design fashion-proof extractions on first hearing; triggerless splits interrogated ("which trigger?" — earning demanding per extraction). Earn one split once (teams growing — contexts straining tangible (fashion ending — earning proving permanently). Count teams; measure hots — earning discipline in three habits, reviewed per extraction.

## 3. Distributions declining (networks refusing — fashions declining — evidence demanding)

**Definition** — declined distributions: networks refused without evidence with fashions declined (networks refusing — calls unpaying (latencies unadding (deployments unsplitting — toil uncompounding (refusing proving — freeriding declining); fashions declining — hype discounting (recitations refusing — reasons demanding (declining funding — mimicking declining); evidence demanding — numbers justifying (triggers firing — splits earning (demanding owning — vibing declining).

**What problem it solves** — the default-distributed trio: *networks unrefusing* (calls unbilling — latencies unadding (chats chattering — tails growing (unrefusing billing — physics declining); *fashions undeclining* (hype deciding — recitations ruling (reasons missing — independence failing (undeclining charging — engineering declining); *evidence undemanding* (numbers unjustifying — triggers unfiring (splits vibing — regret scheduling (undemanding costing — judgment missing). Declined distributions converting defaulting to demanding (calls billing — hype discounting (numbers justifying — splits earning); reviewers finding refusals per default (declining proving → verifiable; defaulting → returned).

**Modern guidance** — the declining lines per default (review-enforced): *networks refusing* ([1.1](<../../sections/1. First thinking/1.1. What microservices are and are not.md>) — calls billing (latencies adding — deployments unsplitting (refusing proving — freeriding declining (refusals earning — tails bounding); *fashions declining* (hype discounting — recitations refusing (reasons demanding — mimicking declining (declining funding — ruling refusing (discounts owning — independence keeping); *evidence demanding* (numbers justifying — triggers firing (splits earning — vibing declining (demanding owning — hoping refusing (justifications funding — regret declining).

```typescript
// GOOD: distributions declining — refused networks with demanded evidence (compiled + run live).
interface Default { // networks refusing — calls billing, freeriding declining
  split: string;
  bill: number;
  trigger: string;
}
function accepted(defaults: Default[], budget: number): string[] {
  const pass: string[] = []; // fashions declining — hype discounting, mimicking declining
  for (const d of defaults) {
    if (d.bill <= budget && d.trigger.length > 0) pass.push(d.split);
  }
  return pass; // evidence demanding — numbers justifying, vibing declining
}
const judged: Default[] = [
  { split: 'billing-out', bill: 160, trigger: 'team-10' },
  { split: 'notify-out', bill: 9000, trigger: '' },
];
console.log(accepted(judged, 500).join() === 'billing-out' ? 'distributions decline' : 'defaults distribute');
```

```typescript
// BAD: defaults distributing — networks unrefusing, evidence undemanding (real default shape).
// // "Services by default." (calls unbilling — hype deciding — numbers unjustifying).
// // No triggers (splits vibing — regret scheduling). Refuse networks; decline fashions; demand evidence.)
```

**Common confusion** — *"declining means never (judgment freezing)."* Freezing fearing splits (distributions blocking — value waiting (evolution stalling — wins missing (freezing charging — courage taxing); declining demanding evidence (networks billing — reasons demanding (triggers firing — splits earning (demanding proving — defaulting declining). "Never" describing dogma (splits blocking — evolution stalling); declining describing defaults (networks refusing — evidence demanding). Refuse defaults (calls billing — hype discounting); earn splits (triggers firing — evidence stating).

**Performance note** — declining economics: refusing costing bills (networks billing — fashions declining (evidence demanding — splits earning); defaulted equivalents costing regret (tails growing — toil compounding (surprises scheduling — trust eroding). Refuse cheaply (defaults — bills); default never (distributions — evidence).

**Mentor note** — teach "distribute by exception, monolith by default" (juniors refusing one default per split design default-proof systems on first hearing; default distributions interrogated ("bill? trigger?" — declining demanding per split). Decline one default once (networks refusing — evidence demanding tangible (defaulting ending — declining proving permanently). Bill networks; fire triggers — declining discipline in three habits, reviewed per default.
