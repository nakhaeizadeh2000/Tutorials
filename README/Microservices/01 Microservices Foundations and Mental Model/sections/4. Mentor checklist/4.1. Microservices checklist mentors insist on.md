# 4.1. Microservices checklist mentors insist on

## 1. Every service owning (processes scaling — failures isolating — contracts stating)

**Definition** — the service line on every deployable: processes proving (instances multiplying — loads splitting (bottlenecks isolating — sharing declining (proving owning — coupling declining); failures proving (blasts bounding — crashes containing (neighbors serving — cascading declining (proving funding — propagating refusing); contracts proving (shapes sharing — versions scoping (callers coding — drifts declining (proving earning — duplicating refusing).

**What problem it solves** — the unowned trio: *processes unscaling* (instances sharing — loads contending (bottlenecks spreading — scale coupling (unscaling billing — independence missing); *failures uncascading* (crashes propagating — neighbors falling (blasts widening — availability dying (uncascading charging — isolation missing); *contracts unstating* (shapes duplicating — versions unscoped (callers assuming — breaks shipping (unstating costing — trust eroding). Owned services converting coupling to proving (instances multiplying — blasts bounding (shapes sharing — drifts failing); reviewers checking scales, blasts, and shapes per service (owning proving → verifiable; hoping → returned).

**Modern guidance** — the owning lines per service (review-enforced): *processes proving* ([1.1](<../../sections/1. First thinking/1.1. What microservices are and are not.md>) — instances multiplying (loads splitting — bottlenecks isolating (proving owning — sharing refusing); *failures proving* ([1.1](<../../sections/1. First thinking/1.1. What microservices are and are not.md>) — blasts bounding (crashes containing — neighbors serving (proving funding — cascading refusing); *contracts proving* ([3.1](<../../sections/3. First safety/3.1. Contracts between services.md>) — shapes sharing (versions scoping — callers coding (proving earning — duplicating refusing).

```typescript
// GOOD: every service owning — scales, blasts, shapes per deployable (process shape, reviewed).
// - Deploys alone with versions (instances multiplying — releases independing — teams shipping).
// - Blasts bounded with neighbors serving (crashes containing — cascades declining — availability keeping).
// - Shapes shared versioned (contracts owning — callers coding — drifts failing.)
```

```typescript
// BAD: services hoping — scales coupling, blasts widening, shapes duplicating (real ball shape).
// // Lockstep release (teams waiting — ships queuing). Shared crash (neighbors falling).
// // Copied DTOs (consumers breaking). Scale instances; bound blasts; share shapes.)
```

**Common confusion** — *"checklists cover code, not services (owning untestable)."* Owning testing deterministically (deploys asserting — blasts bounding (shapes matching — drifts failing (testing proving — confidence earning); hoping untestable (scales assuming — contracts wishing (evidence missing — trust bluffing (hoping charging — incidents scheduling). "Untestable" describing vibes (owning hoping — evidence missing); services describing artifacts (deploys releasing — shapes matching). Assert deploys (instances multiplying — teams shipping); match shapes (contracts owning — drifts failing).

**Performance note** — owning-check economics: proving costing checks (scales checking — blasts bounding (shapes matching — drifts failing); hoped equivalents costing coupling (loads contending — crashes propagating (breaks shipping — trust eroding). Check cheaply (services — deployables); hope never (runtimes — shapes).

**Mentor note** — teach "scale, blast, shape — every service" (juniors owning per deployable design coupling-proof services on first hearing; unowned services interrogated ("deploys alone?" — owning demanding per service). Own one service once (instances multiplying — blasts bounding tangible (hoping ending — owning proving permanently). Multiply instances; share shapes — owning discipline in three habits, reviewed per service.

## 2. Every split earning (seams proving — teams growing — networks pricing)

**Definition** — the split line on every extraction: seams proving (modules scoping — contexts mapping (deploys following — premature declining (proving owning — tearing declining); teams proving (coordination exceeding — ownership splitting (communication saturating — coziness declining (proving funding — fitting refusing); networks proving (calls billing — operations charging (evidence buying — fashion declining (proving earning — freeness refusing).

**What problem it solves** — the unearned trio: *seams unproving* (modules untangling — contexts unmapping (extracts tearing — confidence bluffing (unproving billing — splitting hoping); *teams unfiring* (coordination fitting — splits unneeded (fashion deciding — toil compounding (unfiring charging — evidence missing); *networks unbilling* (calls assuming-free — operations uncharging (regret scheduling — viability eroding (unbilling costing — honesty failing). Earned splits converting fashion to proving (modules scoping — coordination exceeding (calls billing — regret declining); reviewers finding seams, triggers, and bills per split (earning proving → verifiable; fashion → returned).

Monolith-first judgment.md>) — coordination exceeding (ownership splitting — communication saturating (proving funding — fitting refusing); *networks proving* ([1.1](<../../sections/1. First thinking/1.1. What microservices are and are not.md>) — calls billing (operations charging — evidence buying (proving earning — freeness refusing).

**Common confusion** — *"earning slows decomposition (triggers delaying)."* Delaying postponing value (extracts waiting — autonomy delaying (wins missing — momentum dying (delaying charging — courage taxing); earning timing splits (seams proving — triggers firing (bills pricing — regret declining (timing proving — fashion declining). **Performance note** — earning-check economics: proving costing maps (seams scoping — triggers firing (bills pricing — regret declining); fashioned equivalents costing tears (extracts bleeding — toil compounding (surprises scheduling — trust eroding). **Mentor note** — teach "seam, trigger, bill — every split" (juniors earning per extraction design fashion-proof decomposition on first hearing; triggerless splits interrogated ("seam? trigger? bill?" — earning demanding per split). ## 3. Every call bounding (timeouts stating — shapes asserting — failures surfacing)

**Definition** — the call line on every service hop: timeouts proving (waits capping — tails bounding (hangs refusing — hoping declining (proving owning — hanging declining); shapes proving (bodies checking — contracts owning (garbage declining — hoping declining (proving funding — assuming declining); failures proving (statuses mapping — callers handling (swallows refusing — silence declining (proving earning — hiding declining).

**What problem it solves** — the unbounded trio: *timeouts unstating* (waits uncapping — tails growing (callers hanging — threads starving (unstating billing — latency hoping); *shapes unasserting* (bodies unchecked — garbage arriving (clients breaking — trust eroding (unasserting costing — safety bluffing); *failures unsurfaced* (statuses unmapping — callers unhandling (swallows spreading — archaeology requiring (unsurfacing charging — observability failing). Bounded calls converting hanging to proving (waits capping — bodies checking (statuses mapping — silence ending); reviewers finding budgets per hop (bounding proving → verifiable; unbounded → returned).

**Modern guidance** — the bounding lines per hop (review-enforced): *timeouts proving* ([3.1](<../../sections/3. First safety/3.1. Contracts between services.md>) — bodies checking (contracts owning — garbage declining (proving funding — assuming refusing); *failures proving* ([3.1](<../../sections/3. First safety/3.1. Contracts between services.md>) — statuses mapping (callers handling — swallows refusing (proving earning — hiding refusing).

**Common confusion** — *"bounding pessimizes happy paths (caps slowing)."* Slowing adding overhead (waits checking — budgets enforcing (handles branching — nanoseconds spending (slowing charging — speed missing); bounding containing failures (timeouts capping — shapes asserting (statuses mapping — cascades declining (containing proving — hanging declining). "Slowing" describing nanoseconds (caps checking — speed missing); bounding describing survival (failures containing — cascades declining). State budgets (timeouts capping — storms declining); map handlers (statuses typing — silence declining).

**Performance note** — bounding-check economics: proving costing caps (timeouts stating — shapes asserting (failures mapping — silence ending); unbounded equivalents costing hangs (threads starving — garbage arriving (archaeology requiring — trust eroding). Cap cheaply (calls — hops); hang never (waits — threads).

**Mentor note** — convert this leaf into the team's foundations runbook: scales, blasts, shapes, seams, triggers, bills, timeouts, handlers — every service, every split, every call. Quiz juniors on sight ("which deployable? which trigger? which timeout?") until answers are environmental. Watch for checklist decay (foundations discipline for a sprint, abandoned under deadline — fix with gates as review-blocking) and ceremony-theater ("checklist completed" without artifacts — fix with proof demands per item: deploys releasing, triggers firing, budgets capping). Review check: services owning, splits earning, calls bounding — and the mentor's own services modeling all three visibly.
