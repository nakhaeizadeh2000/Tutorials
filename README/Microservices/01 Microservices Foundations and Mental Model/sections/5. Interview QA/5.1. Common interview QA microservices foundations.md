# 5.1. Common interview QA microservices foundations

## 1. Foundations live under pressure (services, seams, splits — diagnosed with fixes, priced)

**Definition** — the foundations answer interviewers grade: given a system, name the service shape with seams ([1.1](<../../sections/1. First thinking/1.1. What microservices are and are not.md>)/[2.1](<../../sections/2. Splitting thinking/2.1. Seams before services.md>)) — services proving (processes scaling — failures isolating (deploys decoupling — autonomy earning (proving owning — coupling declining); seams proving (modules scoping — contexts mapping (deploys following — premature declining (proving funding — tearing declining); splits pricing (networks billing — operations charging (evidence buying — fashion declining (pricing earning — freeness declining). "Live" means diagnosed fixes (gaps naming — remedies stating — prices attaching (proof stating — bluffing declining).

**What problem it solves** — the reciting trio: *services reciting* (deployables naming — runtimes unmentioned (scales undescribed — blasts unjudged (reciting serving — hiring failing (knowledge hoping — depth doubting); *seams confusing* (modules equating — contexts unplaced (splits unassigned — extracts cluttering (conflating owning — clarity missing (confusion serving — confidence failing (placing hoping — precision doubting); *splits hoping* (triggers unregistered — bills untrailed (guessing owning — regret scheduling (stating missing — discipline absenting (hoping serving — incidents inviting (judgment failing — experience doubting). Pressured foundations converting reciting to diagnosing (processes scaling — seams scoping (splits pricing — answers holding); interviewers hearing deploys with seams, not names (diagnosing proving → hirable; reciting → passed) — drawing on [1.1](<../../sections/1. First thinking/1.1. What microservices are and are not.md>) and [2.1](<../../sections/2. Splitting thinking/2.1. Seams before services.md>).

**Modern guidance** — the foundations lines (interview-enforced): *services deciding* (processes scaling — failures isolating (deploys decoupling — autonomy earning (deciding proving — coupling refusing); *seams scoping* (modules bounding — contexts mapping (extracts easing — tears declining (scoping funding — meshing refusing); *splits pricing* (networks billing — operations charging (evidence buying — fashion declining (pricing earning — freeness refusing). Every claim carrying deployable + seam + bill (judgment demonstrable — pressure survivable).

```typescript
// GOOD: foundations answers — deployables, seams, bills with diagnosed fixes (answer shape, hiring-grade).
// "Two deployables releasing alone (processes scaling — failures isolating — teams shipping).
//  Seams scoped on tables with one cross-call budgeted (modules owning — chatter capping — autonomy earning).
//  Split billed 160 network-plus-ops with team-10 trigger (pricing proving — fashion declining).")
```

```typescript
// BAD: foundations recitals — names without deployables, hopes without seams (real fail shape).
// // "We do microservices." (deployables unmentioned — scales undescribed — knowledge hoping).
// // "Loose coupling." (seams confusing — splits hoping). Name deployables; scope seams; price splits.)
```

**Common confusion** — *"naming patterns answers foundations (services stating)."* Naming stating topologies (letters reciting — mechanics listing (shapes naming — seams missing (stating serving — owning failing); answering proving runtime (processes scaling — seams scoping (splits pricing — autonomy earning (proving funding — reciting declining). "Answering" describing judgments (deploys stating — seams bounding); naming describing vocabulary (services spelling — meaning missing). Decide runtimes (processes scaling — deploys decoupling); scope seams (modules bounding — extracts easing).

**Performance note** — foundations-answer economics: diagnosing costing triples (deployables stating — seams scoping (splits pricing — answers holding); reciting equivalents costing doubt (names listing — judgments missing (depth doubting — hiring failing). State cheaply (triples — services); recite never (names — hopes).

**Mentor note** — drill "deployable, seam, bill" (candidates answering per system with releases, boundaries, and prices defend foundations on first hearing; microservices-only answers interrogated ("deploys alone? seam what? billed where?" — foundations demanding per claim). Rehearse one split story once (deploy-seam-bill tangible (reciting ending — diagnosing proving permanently). Name deployables; price bills — foundations answers in three artifacts, reviewed per interview.

"Live" means honesty first (prices stating — triggers firing — monoliths defending (truth proving — hype declining).

Pressured trade-offs converting waving to stating (bills pricing — triggers firing (monoliths defending — answers holding); interviewers hearing prices with triggers, not adjectives (stating proving → hirable; waving → passed) — drawing on [1.1](<../../sections/1. First thinking/1.1. What microservices are and are not.md>) and [2.2](<../../sections/2. Splitting thinking/2.2. Monolith-first judgment.md>).

**Modern guidance** — the trade-off lines (interview-enforced): *costs pricing* (networks billing — operations charging (evidence buying — freeness declining (pricing proving — hiding refusing); *teams firing* (coordination exceeding — contexts colliding (scales demanding — splits earning (firing funding — fitting refusing); *timings defending* (monoliths serving — extractions sequencing (rewrites declining — gambles ending (defending owning — rushing refusing). ## 3. Safety live under pressure (contracts, bounds, failures — ownership stated, not hoped)

**Definition** — the safety answer interviewers grade: given a service call, name the contract with bounds ([3.1](<../../sections/3. First safety/3.1. Contracts between services.md>)/[1.2](<../../sections/1. First thinking/1.2. First NestJS services slice.md>)) — contracts owning (shapes sharing — versions scoping (drifts declining — breaks paging (owning proving — duplicating declining); bounds stating (timeouts capping — retries budgeting (cascades containing — storms declining (stating funding — hanging declining); failures owning (statuses mapping — callers handling (swallows refusing — silence declining (owning earning — hiding declining). "Live" means ownership stated (shapes versioning — budgets capping — handlers covering (proof stating — silence declining).

**What problem it solves** — the claiming trio: *contracts claiming* (shapes unsharing — versions unscoped (callers assuming — breaks shipping (claiming serving — hiring failing (artifacts missing — proof doubting); *bounds missing* (timeouts unstating — retries unbudgeting (callers hanging — storms amplifying (missing owning — discipline failing (silence serving — pressure compounding); *failures hoping* (statuses unmapping — callers unhandling (swallows spreading — archaeology requiring (hoping serving — honesty failing). Pressured safety converting claiming to owning (shapes sharing — timeouts capping (statuses mapping — answers holding); interviewers hearing contracts with budgets, not assurances (owning proving → hirable; claiming → passed) — drawing on [3.1](<../../sections/3. First safety/3.1. Contracts between services.md>) and [1.2](<../../sections/1. First thinking/1.2. First NestJS services slice.md>).

**Modern guidance** — the safety lines (interview-enforced): *contracts versioning* (shapes sharing — versions scoping (pacts replaying — drifts failing (versioning proving — duplicating refusing); *bounds capping* (timeouts stating — retries budgeting (cascades containing — storms declining (capping funding — hanging refusing); *failures handling* (statuses mapping — callers covering (fallbacks planning — silence declining (handling owning — hoping refusing). Every claim carrying shape + budget + handler (judgment demonstrable — pressure survivable).

```typescript
// GOOD: safety answers — shapes, budgets, handlers with owned failures (answer shape, hiring-grade).
// "Item v1 shared with pact replay (shapes sharing — versions scoping — drifts failing).
//  500ms timeout with 3 attempts (bounds capping — storms declining — cascades containing).

```

```typescript
// BAD: safety claiming — assurances without shapes, retries without budgets (real fail shape).
// // "Reliable calls." (shapes unsharing — versions unscoped — artifacts missing).
// // "We retry." (budgets uncounting — storms amplifying). Version shapes; cap attempts; map failures.)
```

**Common confusion** — *"confidence answers safety (certainty performing)."* Certainty performing infallibility (doubts hiding — bounds missing (pressure bluffing — calibration failing (performing charging — trust risking); safety owning failures (shapes sharing — bounds capping (handlers covering — silence declining (owning proving — claiming declining). "Confidence" describing delivery (certainty performing — doubts hiding); safety describing ownership (contracts versioning — failures handling). Share shapes (contracts owning — drifts failing); map handlers (statuses typing — silence declining).

**Performance note** — safety-answer economics: owning costing artifacts (shapes sharing — bounds capping (handlers covering — answers holding); claiming equivalents costing doubt (assurances floating — artifacts missing (proof doubting — hiring failing). Own cheaply (artifacts — calls); claim never (assurances — safety).

**Mentor note** — drill "shape, budget, handler" (candidates answering per call with versioned DTOs, timeout budgets, and mapped failures defend safety on first hearing; "reliable" interrogated ("version? timeout? fallback?" — safety demanding per call). Rehearse one bounded call once (shape-budget-handler tangible (claiming ending — owning proving permanently). Version contracts; budget attempts — safety answers in three ownerships, reviewed per interview.
