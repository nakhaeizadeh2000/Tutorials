## 1. Values layering (bases defaulting — envs overriding — secrets mounting)

Layered values converting baking to defaulting (defaults shipping — deployments differing (vaults injecting — rebuilds ending); reviewers finding layer tables per service (layering proving → verifiable; baking → returned).

**Modern guidance** — the layering lines per service (review-enforced): *bases defaulting* (defaults shipping — safeties bounding (surprises limiting — hardcoding declining (defaulting proving — missing refusing (defaults earning — sanity keeping); *envs overriding* (deployments differing — regions varying (tenants scoping — rebuilding declining (overriding funding — cutting refusing (overrides owning — portability earning); *secrets mounting* (vaults injecting — files avoiding (histories excluding — leaking declining (mounting owning — committing refusing (mounts funding — breaches preventing).

```typescript
// GOOD: values layering — defaulted bases overridden per environment (compiled + run live).
interface Layered { // bases defaulting — defaults shipping, hardcoding declining
  base: Record<string, string>;
  env: Record<string, string>;
  secret: string[];
}
function merged(l: Layered): Record<string, string> {
  const out: Record<string, string> = { ...l.base }; // envs overriding — deployments differing, rebuilding declining
  for (const k of Object.keys(l.env)) out[k] = l.env[k] ?? '';
  for (const s of l.secret) delete out[s]; // secrets mounting — vaults injecting, committing declining
  return out;
}
const cfg: Layered = { base: { port: '3000', key: 'SECRET' }, env: { port: '8080' }, secret: ['key'] };
const out = merged(cfg);
console.log(out['port'] === '8080' && !('key' in out) ? 'values layer' : 'configs bake');
```

// GOOD: boots gating — validated schemas crashing early (compiled + run live).
function gate(env: Record<string, string>, need: string[]): string {
  for (const k of need) { // schemas validating — shapes requiring, hoping declining
    if ((env[k] ?? '').length === 0) return `BLOCK:${k}`;

**What problem it solves** — the silent-drift trio: *audits undiffing* (currents uncompared — baselines unversioned (deviations hiding — rot accumulating (undiffing billing — visibility failing); *changes unannouncing* (diffs unpublished — owners unnotified (migrations scrambling — firefighting scheduling (unannouncing charging — coordination failing); *surprises undeclining* (clients unforewarned — expects unaligned (pages scheduling — trust eroding (undeclining costing — honesty failing). **Modern guidance** — the detecting lines per release (review-enforced): *audits diffing* (currents comparing — baselines versioning (deviations flagging — rotting declining (diffing proving — hiding refusing (comparisons owning — rot surfacing); *changes announcing* (diffs publishing — owners notifying (migrations planning — ambushing declining (announcing funding — scrambling refusing (publications earning — coordination keeping); *surprises declining* (clients forewarning — expects aligning (pages preventing — discovering ending (declining owning — ambushing refusing (forewarnings funding — trust keeping).

```typescript
// GOOD: drifts detecting — diffed audits announcing changes (compiled + run live).
function drifted(current: Record<string, string>, baseline: Record<string, string>): string[] {
  const gaps: string[] = []; // audits diffing — currents comparing, rotting declining
  for (const k of Object.keys(current)) {
    if (baseline[k] !== current[k]) gaps.push(k);
  }
  return gaps; // changes announcing — diffs publishing, ambushing declining
  // surprises declining — clients forewarning, discovering ending (asserted below)
}
const base: Record<string, string> = { port: '3000', log: 'info' };
const now: Record<string, string> = { port: '3000', log: 'debug' };
console.log(drifted(now, base).join() === 'log' && drifted(base, base).length === 0 ? 'drifts detect' : 'changes silent');
```
