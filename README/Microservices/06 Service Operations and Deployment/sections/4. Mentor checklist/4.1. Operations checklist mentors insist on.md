# 4.1. Operations checklist mentors insist on

## 1. Every release sequencing (rollouts staging — canaries proving — rollbacks readying)

**Definition** — the release line on every deploy: rollouts proving (batches sizing — health gating (traffic shifting — flipping declining (proving owning — flagging declining); canaries proving (percentages ramping — metrics comparing (blasts bounding — blindness declining (proving funding — dumping declining); rollbacks proving (reverts rehearsing — outs preserving (recoveries timing — stranding declining (proving earning — trapping declining).

**What problem it solves** — the unsequenced trio: *rollouts unstaging* (batches unsizing — health ungating (traffic unshifting — blasts unlimited (unstaging billing — discipline missing); *canaries unproving* (percentages unramping — metrics uncomparing (blasts unbounding — regressions hiding (unproving charging — evidence failing); *rollbacks unreadying* (reverts unrehearsing — outs unpreserved (recoveries untimed — outages extending (unreadying costing — safety theatering). Sequenced releases converting flipping to proving (batches sizing — percentages ramping (reverts rehearsing — blasts bounding); reviewers finding batch plans per release (sequencing proving → verifiable; flipping → returned).

**Modern guidance** — the sequencing lines per release (review-enforced): *rollouts proving* ([1.1](<../../sections/1. Deploy thinking/1.1. Releases sequencing safely.md>) — batches sizing (health gating — traffic shifting (proving owning — flipping refusing); *canaries proving* ([1.1](<../../sections/1. Deploy thinking/1.1. Releases sequencing safely.md>) — percentages ramping (metrics comparing — blasts bounding (proving funding — blindness refusing); *rollbacks proving* ([1.1](<../../sections/1. Deploy thinking/1.1. Releases sequencing safely.md>) — reverts rehearsing (outs preserving — recoveries timing (proving earning — trapping refusing).

```typescript
// GOOD: every release sequencing — batches, canaries, rollbacks per deploy (process shape, reviewed).
// - Rollouts staged with health gates (fleets fractioning — probes passing — loads migrating).
// - Canaries proved with compared metrics (traffic splitting — errors contrasting — scopes limiting).
// - Rollbacks readied with preserved outs (reversals practicing — escapes maintaining — MTTR quoting.)
```

```typescript
// BAD: releases flipping — rollouts unstaging, canaries unproving, rollbacks unreadying (real flag-day shape).
// // 100% deploy (blasts unlimited — drops scheduling). No canary (regressions hiding).
// // No rollback (outages extending). Stage batches; prove canaries; ready rollbacks.)
```

**Common confusion** — *"sequencing slows shipping (waves delaying)."* Delaying postponing value (batches waiting — waves lingering (ships slowing — momentum dying (delaying charging — courage taxing); sequencing bounding blast (fleets fractioning — percentages ramping (reverts rehearsing — damage limiting (sequencing proving — flipping declining). "Slowing" describing fear (releases avoiding — decisions ducking); sequencing describing safety (batches sizing — health gating). Size fleets (fractions owning — damage limiting); rehearse reversals (flags arming — outages shrinking).

**Performance note** — sequencing-check economics: sizing costing waves (batches sizing — percentages ramping (reverts rehearsing — blasts bounding); flipped equivalents costing flag-days (blasts unlimited — regressions hiding (outages extending — trust eroding). Stage cheaply (batches — releases); flip never (fleets — traffic).

**Mentor note** — teach "batch, canary, rollback — every release" (juniors sequencing per release design flag-day-proof deploys on first hearing; unsequenced releases interrogated ("batches? canary? back?" — sequencing demanding per release). Sequence one release once (fleets fractioning — percentages ramping tangible (flipping ending — sequencing proving permanently). Gate health; compare metrics — sequencing discipline in three habits, reviewed per release.

## 2. Every service gating (probes splitting — drains landing — verdicts acting)

**Definition** — the gating line on every service: probes proving (live cheaping — ready deeping (traffic gating — merging declining (proving owning — lying declining); drains proving (accepts stopping — inflight completing (exits timing — severing declining (proving funding — cutting declining); verdicts proving (unready shedding — unlively restarting (orchestrators deciding — ignoring declining (proving earning — theater declining).

**What problem it solves** — the ungated trio: *probes unsplitting* (checks shallowing — dependencies unchecked (traffic misrouted — truth hidden (unsplitting billing — verdicts lying); *drains unlanding* (accepts unsevered — inflight undropped (data lost — clients hanging (unlanding charging — grace failing); *verdicts unacting* (unready unserved — unlively unrestored (automation absent — toil ruling (unacting costing — observability theatering). Gated services converting merging to proving (live cheaping — accepts stopping (unready shedding — verdicts working); reviewers finding probe splits per service (gating proving → verifiable; merging → returned).

**Modern guidance** — the gating lines per service (review-enforced): *probes proving* ([1.2](<../../sections/1. Deploy thinking/1.2. Health gating traffic.md>) — live cheaping (ready deeping — traffic gating (proving owning — lying refusing); *drains proving* ([1.2](<../../sections/1. Deploy thinking/1.2. Health gating traffic.md>) — accepts stopping (inflight completing — exits timing (proving funding — severing refusing); *verdicts proving* ([1.2](<../../sections/1. Deploy thinking/1.2. Health gating traffic.md>) — unready shedding (unlively restarting — orchestrators deciding (proving earning — theater refusing).

```typescript
// GOOD: every service gating — probes, drains, verdicts per service (process shape, reviewed).
// - Probes split live-cheap ready-deep (processes answering — dependencies checking — traffic gating).
// - Drains landed with timed exits (sockets closing — requests finishing — graces capping).
// - Verdicts acted with shed-restart (routes updating — corpses replacing — platforms polling.)
```

```typescript
// BAD: services merging — probes unsplitting, drains unlanding, verdicts unacting (real lie shape).
// // Single /health ok (truth hiding — traffic misrouted). SIGTERM exit(0) (data lost).
// // Unpolled verdicts (toil ruling). Split probes; land drains; act verdicts.)
```

**Common confusion** — *"gating complicates services (probes burdening)."* Burdening scattering policy (checks multiplying — branches tangling (graphs knotting — simplicity failing (burdening charging — owning missing); gating driving platforms (live cheaping — drains landing (verdicts acting — misroutes ending (gating proving — merging declining). "Complicating" describing meshes (policies scattering — graphs tangling); gating describing verdicts (probes splitting — drains timing). Cheapen live (processes answering — restarts gating); time exits (graces capping — deadlocks ending).

**Performance note** — gating-check economics: splitting costing endpoints (live cheaping — drains landing (verdicts acting — misroutes ending); merged equivalents costing lies (truth hiding — data lost (toil ruling — trust eroding). Split cheaply (probes — services); merge never (health — verdicts).

**Mentor note** — teach "split, land, act — every service" (juniors gating per service design lie-proof health on first hearing; ungated services interrogated ("live? ready? drain?" — gating demanding per service). Gate one service once (live cheaping — drains landing tangible (merging ending — gating proving permanently). Ping deeply; close bounded — gating discipline in three habits, reviewed per service.

## 3. Every environment externalizing (values layering — boots gating — journeys observing)

**What problem it solves** — the unbaked trio: *values unlayering* (bases undefaulted — envs unoverridden (secrets committed — rebuilds required (unlayering billing — portability failing); *boots ungating* (schemas unvalidated — crashes unearly (deploys unblocked — breakages shipped (ungating charging — quality theatering); *journeys unobserving* (logs unstructuring — traces uncorrelated (metrics unalarmed — blindness ruling (unobserving costing — forensics failing). Externalized environments converting baking to proving (bases defaulting — schemas validating (logs structuring — rebuilds ending); reviewers finding layers per environment (externalizing proving → verifiable; baking → returned).

**Modern guidance** — the externalizing lines per environment (review-enforced): *values proving* ([2.1](<../../sections/2. Operate thinking/2.1. **Common confusion** — *"externalizing slows promotions (layers taxing)."* Taxing adding lookups (values resolving — secrets fetching (overrides merging — starts pausing (taxing charging — speed missing); externalizing freeing promotions (defaults shipping — envs overriding (rebuilds ending — velocity funding (externalizing proving — baking declining). "Slowing" describing milliseconds (lookups resolving — speed missing); layers describing portability (same image — every environment). Ship defaults (safeties bounding — surprises limiting); mount secrets (vaults injecting — histories excluding).

**Performance note** — externalizing-check economics: layering costing lookups (bases defaulting — schemas validating (logs structuring — rebuilds ending); baked equivalents costing rebuilds (promotions re-cutting — breakages shipped (blindness ruling — trust eroding). Layer cheaply (values — environments); bake never (configs — images).

**Mentor note** — convert this leaf into the team's operations runbook: batches, canaries, rollbacks, probes, drains, verdicts, layers, gates, journeys — every release, every service, every environment. Quiz juniors on sight ("which batch? which probe? which layer?") until answers are environmental.
