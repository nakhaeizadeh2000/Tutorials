# 5.1. Common interview QA service operations

## 1. Deploys live under pressure (rollouts, canaries, rollbacks — diagnosed with fixes, priced)

**Definition** — the deploys answer interviewers grade: given a release, name the sequence with gates ([1.1](<../../sections/1. Deploy thinking/1.1. Releases sequencing safely.md>)) — rollouts proving (batches sizing — health gating (traffic shifting — flipping declining (proving owning — flagging declining); canaries proving (percentages ramping — metrics comparing (blasts bounding — blindness declining (proving funding — dumping declining); rollbacks proving (reverts rehearsing — outs preserving (recoveries timing — stranding declining (proving earning — trapping declining). "Live" means diagnosed fixes (batches naming — metrics stating — outs preserving (proof stating — bluffing declining).

**What problem it solves** — the reciting trio: *rollouts reciting* (deploys naming — batches unmentioned (gates undescribed — traffic unshifted (reciting serving — hiring failing (knowledge hoping — depth doubting); *canaries confusing* (percentages equating — metrics unplaced (blasts unjudged — regressions hiding (conflating owning — clarity missing (confusion serving — confidence failing (placing hoping — precision doubting); *rollbacks hoping* (reverts unrehearsed — outs unpreserved (recoveries untimed — outages extending (hoping serving — incidents inviting (judgment failing — experience doubting). Pressured deploys converting reciting to diagnosing (batches sizing — metrics comparing (outs preserving — answers holding); interviewers hearing batches with rollbacks, not tool names (diagnosing proving → hirable; reciting → passed) — drawing on [1.1](<../../sections/1. Deploy thinking/1.1. Releases sequencing safely.md>).

**Modern guidance** — the deploys lines (interview-enforced): *rollouts staging* (batches sizing — health gating (traffic shifting — flipping declining (staging proving — wholes refusing); *canaries gating* (percentages ramping — metrics comparing (blasts bounding — blindness declining (gating funding — dumping refusing); *rollbacks readying* (reverts rehearsing — outs preserving (recoveries timing — stranding declining (readying owning — trapping refusing). Every claim carrying batch + metric + out (judgment demonstrable — pressure survivable).

```typescript
// GOOD: deploys answers — batches, metrics, outs with diagnosed fixes (answer shape, hiring-grade).
// "10-50-100 waves gated on health (rollouts staging — traffic shifting — blasts bounding).
//  Canary promotes on error delta under 2% (percentages ramping — metrics comparing).
//  Previous pinned with 8-minute rollback drilled (outs preserving — recoveries timing).")
```

```typescript
// BAD: deploys recitals — names without batches, hopes without outs (real fail shape).
// // "Kubernetes rolling updates." (batches unmentioned — gates undescribed — knowledge hoping).
// // "We can roll back." (reverts unrehearsed — outs unpreserved). Size batches; compare metrics; preserve outs.)
```

**Common confusion** — *"naming platforms answers deploys (tools stating)."* Stating listing platforms (letters reciting — tools naming (shapes describing — batches missing (stating serving — owning failing); answering proving sequences (batches sizing — metrics comparing (outs preserving — blasts bounding (proving funding — reciting declining). "Answering" describing judgments (batches naming — rollbacks readying); naming describing vocabulary (platforms spelling — meaning missing). Stage batches (fleets fractioning — damage limiting); ready outs (escapes maintaining — outages shrinking).

**Performance note** — deploys-answer economics: diagnosing costing triples (batches stating — metrics comparing (outs preserving — answers holding); reciting equivalents costing doubt (names listing — judgments missing (depth doubting — hiring failing). State cheaply (triples — releases); recite never (names — hopes).

**Mentor note** — drill "batch, metric, out" (candidates answering per release with wave plans, canary deltas, and preserved outs defend deploys on first hearing; platform-only answers interrogated ("batches? metrics? back?" — deploys demanding per claim). Rehearse one sequenced release once (batch-metric-out tangible (reciting ending — diagnosing proving permanently). Gate health; time recoveries — deploys answers in three artifacts, reviewed per interview.

## 2. Health live under pressure (probes, drains, verdicts — honesty stated, not hoped)

**Definition** — the health answer interviewers grade: given a service, name the probes with drains ([1.2](<../../sections/1. Deploy thinking/1.2. Health gating traffic.md>)) — probes proving (live cheaping — ready deeping (traffic gating — merging declining (proving owning — lying declining); drains proving (accepts stopping — inflight completing (exits timing — severing declining (proving funding — cutting declining); verdicts proving (unready shedding — unlively restarting (orchestrators deciding — ignoring declining (proving earning — theater declining). "Live" means honesty first (splits stating — drains landing (verdicts acting — truth proving — hoping declining).

**What problem it solves** — the hand-waving trio: *probes waving* (splits unstating — checks unmerged (dependencies unchecked — truth hidden (waving serving — hiring failing (numbers missing — judgment doubting); *drains forgetting* (accepts unsevered — inflight unfinished (data lost — clients hanging (forgetting owning — grace failing (silence serving — preservation missing); *verdicts missing* (actions untaken — platforms unpolled (automation absent — toil ruling (missing charging — observability theatering (hope serving — calibration failing). Pressured health converting waving to stating (splits declaring — drains landing (verdicts acting — answers holding); interviewers hearing splits with drains, not adjectives (stating proving → hirable; waving → passed) — drawing on [1.2](<../../sections/1. Deploy thinking/1.2. Health gating traffic.md>).

**Modern guidance** — the health lines (interview-enforced): *probes splitting* (live cheaping — ready deeping (traffic gating — merging declining (splitting proving — lying refusing); *drains landing* (accepts stopping — inflight completing (exits timing — severing declining (landing funding — cutting refusing); *verdicts acting* (unready shedding — unlively restarting (orchestrators deciding — ignoring declining (acting owning — theater refusing). Every claim carrying split + drain + verdict (judgment demonstrable — pressure survivable).

```typescript
// GOOD: health answers — splits, drains, verdicts with honest gates (answer shape, hiring-grade).
// "Live cheap, ready pings stores (probes splitting — traffic gating — truth telling).
//  SIGTERM drains 5s bounded (accepts stopping — inflight completing — data preserving).
//  Unready sheds, dead restarts (verdicts acting — automation working).")
```

```typescript
// BAD: health waves — adjectives without splits, comfort without drains (real fail shape).
// // "Health checks." (splits unstating — checks unmerged — numbers missing).
// // "Graceful." (drains unlanded — verdicts unactioned). Split probes; land drains; act verdicts.)
```

**Common confusion** — *"uptime answers health (percentages stating)."* Stating quoting nines (numbers floating — splits missing (drains absenting — verdicts unactioned (stating serving — gating failing); health proving verdicts (live cheaping — drains landing (verdicts acting — misroutes ending (proving funding — waving declining). "Uptime" describing history (nines quoting — splits missing); health describing control (probes splitting — platforms polling). Split verdicts (live cheaping — ready deeping); land shutdowns (accepts stopping — exits timing).

**Performance note** — health-answer economics: stating costing splits (probes declaring — drains landing (verdicts acting — answers holding); waving equivalents costing doubt (adjectives floating — numbers missing (judgment doubting — hiring failing). State cheaply (splits — drains); wave never (adjectives — verdicts).

**Mentor note** — drill "split, drain, verdict" (candidates answering per service with probe pairs, bounded drains, and acted verdicts defend health on first hearing; "health checks" interrogated ("split? drain? action?" — health demanding per claim). Rehearse one gated service once (split-drain-verdict tangible (waving ending — stating proving permanently). Cheapen live; bound grace — health answers in three honesty, reviewed per interview.

## 3. Ops live under pressure (config, traces, proof — ownership stated, not hoped)

**What problem it solves** — the claiming trio: *config claiming* (layers unnamed — envs unoverridden (secrets committed — rebuilds required (claiming serving — hiring failing (names missing — proof doubting); *traces missing* (logs unstructuring — ids unpropagated (thresholds unpaged — blindness ruling (missing owning — forensics failing (silence serving — observability bluffing); *proofs hoping* (patterns undriven — receipts unasserted (faults unsurfaced — silence spreading (hoping serving — evidence failing). Pressured ops converting claiming to layering (bases defaulting — logs structuring (patterns driving — answers holding); interviewers hearing layers with proof, not assurances (layering proving → hirable; claiming → passed) — drawing on [2.1](<../../sections/2. Operate thinking/2.1. Config externalizing per environment.md>) and [2.2](<../../sections/2. Operate thinking/2.2. Observability tracing journeys.md>).

**Modern guidance** — the ops lines (interview-enforced): *config layering* (bases defaulting — envs overriding (secrets mounting — baking declining (layering proving — leaking refusing); *traces bounding* (logs structuring — ids propagating (thresholds paging — blinding declining (bounding owning — wallpapering refusing); *proof exercising* (patterns driving — receipts asserting (faults surfacing — silence declining (exercising owning — hoping refusing). Every claim carrying layer + trace + drive (judgment demonstrable — pressure survivable).

// GOOD: ops answers — layers, traces, drives with owned environments (answer shape, hiring-grade).
