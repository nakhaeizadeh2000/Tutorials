# 1.1. Releases sequencing safely

## 1. Rollouts staging (batches sizing — health gating — traffic shifting)

**Definition** — staged rollouts: sized batches gating health shifting traffic (batches sizing — fleets fractioning (waves sequencing — blasts bounding (sizing proving — flipping declining); health gating — probes passing (verdicts acting — routes updating (gating funding — blind shifting declining); traffic shifting — loads migrating (old draining — new warming (shifting owning — dropping declining).

**What problem it solves** — the flag-day trio: *batches unsizing* (fleets unattended — waves unsequenced (releases flipping — blasts unlimited (unsizing billing — discipline missing); *health ungating* (probes unpassing — verdicts unacted (routes unupdated — traffic misdirected (ungating charging — automation failing); *traffic unshifting* (loads unmigrated — old undrained (drops scheduling — users impacting (unshifting costing — safety bluffing). Staged rollouts converting flipping to sizing (fleets fractioning — probes passing (loads migrating — blasts bounding); reviewers finding batch plans per release (staging proving → verifiable; flipping → returned).

**Modern guidance** — the staging lines per release (review-enforced): *batches sizing* (fleets fractioning — waves sequencing (blasts bounding — flipping declining (sizing proving — wholes refusing (fractions earning — damage limiting); *health gating* (probes passing — verdicts acting (routes updating — blind declining (gating funding — shifting refusing (gates owning — misdirection ending); *traffic shifting* (loads migrating — old draining (new warming — dropping declining (shifting owning — cutting refusing (migrations funding — impact bounding).

```typescript
// GOOD: rollouts staging — sized batches gating health (compiled + run live).
interface Wave { // batches sizing — fleets fractioning, flipping declining
  pct: number;
  healthy: boolean;
}
function advance(waves: Wave[], idx: number): string {
  const wave = waves[idx]; // health gating — probes passing, blind declining
  if (wave === undefined) return 'DONE';
  if (!wave.healthy) return 'HOLD';
  return `ROLL-${wave.pct}`; // traffic shifting — loads migrating, dropping declining
}
const waves: Wave[] = [
  { pct: 10, healthy: true },
  { pct: 50, healthy: true },
  { pct: 100, healthy: false },
];
console.log(advance(waves, 0) === 'ROLL-10' && advance(waves, 1) === 'ROLL-50' && advance(waves, 2) === 'HOLD' && advance(waves, 9) === 'DONE' ? 'rollouts stage' : 'releases flip');
```

// // 100% at once (drops scheduling — users impacting). Size batches; gate health; shift traffic.)

**Common confusion** — *"staging slows releases (waves delaying)."* Delaying postponing value (batches waiting — waves lingering (ships slowing — momentum dying (delaying charging — courage taxing); staging bounding blast (fleets fractioning — probes passing (loads migrating — damage limiting (staging proving — flipping declining). "Slowing" describing fear (releases avoiding — decisions ducking); staging describing safety (batches sizing — health gating). Size fleets (fractions owning — damage limiting); shift gradually (loads migrating — impact bounding).

**Performance note** — staging economics: sizing costing waves (fleets fractioning — probes passing (loads migrating — blasts bounding); flipped equivalents costing flag-days (blasts unlimited — drops scheduling (users impacting — trust eroding). Stage cheaply (batches — releases); flip never (fleets — traffic).

**Mentor note** — teach "no fleet moves all at once" (juniors staging one batch plan per release design flag-day-proof deploys on first hearing; whole-fleet releases interrogated ("batch plan?" — staging demanding per release). Stage one rollout once (fleets fractioning — probes passing tangible (flipping ending — staging proving permanently). Fraction fleets; pass gates — staging discipline in three habits, reviewed per release.

```typescript
// GOOD: canaries proving — ramped percentages comparing metrics (compiled + run live).
interface Canary { // percentages ramping — traffic splitting, flipping declining
  pct: number;
  errRate: number;
  baselineErr: number;
}
function promote(c: Canary, tolerance: number): string {
  if (c.errRate - c.baselineErr > tolerance) return 'ROLLBACK'; // metrics comparing — errors contrasting, hoping declining
  if (c.pct >= 100) return 'COMPLETE';
  return 'RAMP'; // blasts bounding — scopes limiting, widening declining
}
const good: Canary = { pct: 10, errRate: 0.011, baselineErr: 0.01 };
const bad: Canary = { pct: 10, errRate: 0.09, baselineErr: 0.01 };
const done: Canary = { pct: 100, errRate: 0.01, baselineErr: 0.01 };
console.log(promote(good, 0.02) === 'RAMP' && promote(bad, 0.02) === 'ROLLBACK' && promote(done, 0.02) === 'COMPLETE' ? 'canaries prove' : 'releases blind');
```

## 3. Rollbacks readying (reverts rehearsing — outs preserving — recoveries timing)

**Definition** — readied rollbacks: rehearsed reverts preserving outs timing recoveries (reverts rehearsing — reversals practicing (flags arming — restores timing (rehearsing proving — stranding declining); outs preserving — escapes maintaining (downgrades readying (versions pinning — rollforwards declining (preserving owning — trapping declining); recoveries timing — MTTR quoting (targets bounding — trends shrinking (timing funding — hoping declining).

**What problem it solves** — the forward-only trio: *reverts unrehearsing* (reversals unpracticed — flags unarmed (restores fumbling — outages extending (unrehearsing billing — safety theatering); *outs unpreserving* (escapes unmaintained — downgrades unreadied (versions unpinned — rollforwards forcing (unpreserving charging — options missing); *recoveries untiming* (MTTR unquoting — targets unbounding (improvements unowned — calibration missing (untiming costing — readiness bluffing). **Modern guidance** — the readying lines per release (review-enforced): *reverts rehearsing* (reversals practicing — flags arming (restores timing — stranding declining (rehearsing proving — fumbling refusing (rehearsals earning — outages shrinking); *outs preserving* (escapes maintaining — downgrades readying (versions pinning — rollforwards declining (preserving owning — trapping refusing (escapes keeping — options owning); *recoveries timing* (MTTR quoting — targets bounding (trends shrinking — hoping declining (timing funding — bluffing refusing (quotes owning — calibration earning).

```typescript
// GOOD: rollbacks readying — rehearsed reverts preserving outs (compiled + run live).
interface Release { // reverts rehearsing — reversals practicing, stranding declining
  version: string;
  rollbackMins: number;
  pinnedPrev: boolean;
}
function shippable(r: Release, mttrCap: number): string {
  if (!r.pinnedPrev) return 'NO-OUT'; // outs preserving — escapes maintaining, trapping declining
  if (!(r.rollbackMins > 0) || r.rollbackMins > mttrCap) return 'UNREADY';
  return 'SHIP'; // recoveries timing — MTTR quoting, hoping declining
}
const ready: Release = { version: '2.4.0', rollbackMins: 8, pinnedPrev: true };
const trapped: Release = { version: '2.4.0', rollbackMins: 8, pinnedPrev: false };
console.log(shippable(ready, 15) === 'SHIP' && shippable(trapped, 15) === 'NO-OUT' ? 'rollbacks ready' : 'releases trap');
```
