## 1. Every call choosing (sync fitting — coupling timing — async deferring)

**Definition** — the choice line on every service call: sync proving (answers gating — waits bounding (journeys completing — events deferring (proving owning — always declining); coupling proving (clocks aligning — nines compounding (SLOs tightening — surprises declining (proving funding — freeness declining); async proving (patience allowing — events streaming (independence earning — defaulting declining (proving earning — syncing declining).

**What problem it solves** — the unchosen trio: *sync unfitting* (answers ungating — waits unbounding (journeys dropping — events missing (unfitting billing — always ruling); *coupling untiming* (clocks unaligning — nines uncompounding (downtimes surprising — contracts breaching (untiming charging — math missing); *async undeferring* (patience unallowing — events unstreaming (independence unearned — threads wasted (undeferring costing — defaulting ruling). Chosen calls converting always to proving (answers gating — clocks aligning (patience allowing — coupling earning); reviewers finding gates per call (choosing proving → verifiable; always → returned).

Request reply choosing sync.md>) — answers gating (waits bounding — journeys completing (proving owning — always refusing); *coupling proving* ([1.1](<../../sections/1. Call thinking/1.1. Request reply choosing sync.md>) — clocks aligning (nines compounding — SLOs tightening (proving funding — freeness refusing); *async proving* ([1.1](<../../sections/1. Call thinking/1.1. Request reply choosing sync.md>) — patience allowing (events streaming — independence earning (proving earning — defaulting refusing).

```typescript
// GOOD: every call choosing — gates, math, patience per call (process shape, reviewed).
// - Sync gated on answers (responses needing — waits bounding — journeys completing).
// - Coupling timed with products (clocks aligning — nines compounding — SLOs tightening).
```

```typescript

// // Everything sync (answers ungating — coupling hiding — threads wasting).
// // No math (downtimes surprising — contracts breaching). Gate answers; time coupling; defer patience.)
```

**Common confusion** — *"choosing is analysis-paralysis (decisions delaying)."* Delaying postponing calls (choices waiting — journeys stalling (value missing — momentum dying (delaying charging — courage taxing); choosing pricing coupling (answers gating — clocks aligning (patience allowing — always declining (choosing proving — defaulting declining). "Paralysis" describing fear (decisions ducking — calls drifting); choosing describing gates (responses needing — budgets bounding). Gate sync (answers needing — waits bounding); defer patience (events streaming — clocks freeing).

**Performance note** — choosing-check economics: gating costing decisions (answers needing — clocks aligning (patience allowing — coupling earning); always equivalents costing threads (waits unbounded — downtimes surprising (availability dying — autonomy bluffing). Gate cheaply (calls — answers); always never (sync — journeys).

**Mentor note** — teach "gate, time, defer — every call" (juniors choosing per call design always-proof sync on first hearing; unchosen calls interrogated ("gates what?" — choosing demanding per call). Choose one call once (answers gating — clocks aligning tangible (always ending — choosing proving permanently). Need answers; multiply nines — choosing discipline in three habits, reviewed per call.
