## 1. Proxies reusing (connections pooling — channels sharing — handshakes amortizing)

**Definition** — reused proxies: pooled connections with shared channels amortizing handshakes (connections pooling — clients caching (sockets reusing — dials saving (pooling proving — dialing declining); channels sharing — transports multiplexing (streams interleaving — headroom preserving (sharing funding — opening declining); handshakes amortizing — setups dividing (costs spreading — calls cheapening (amortizing owning — repeating declining).

**What problem it solves** — the dial-per-call trio: *connections unpooling* (clients rebuilding — sockets redialing (handshakes repeating — latencies adding (unpooling billing — reuse missing); *channels unsharing* (transports unmultiplexing — streams serializing (headroom wasting — throughput capping (unsharing charging — sharing failing); *handshakes unamortizing* (setups repeating — costs reccurring (calls pricing-high — budgets bleeding (unamortizing costing — economy missing). Reused proxies converting dialing to pooling (clients caching — transports multiplexing (setups dividing — calls cheapening); reviewers finding proxy registries per address (reusing proving → verifiable; dialing → returned).

**Modern guidance** — the reusing lines per address (review-enforced): *connections pooling* (clients caching — sockets reusing (dials saving — dialing declining (pooling proving — rebuilding refusing (caches owning — latencies bounding); *channels sharing* (transports multiplexing — streams interleaving (headroom preserving — opening declining (sharing funding — serializing refusing (multiplexes earning — throughput keeping); *handshakes amortizing* (setups dividing — costs spreading (calls cheapening — repeating declining (amortizing owning — recurring refusing (divisions funding — budgets keeping).

```typescript
// GOOD: proxies reusing — pooled clients keyed by address (compiled + run live).
class ProxyPool { // connections pooling — clients caching, dialing declining
  private readonly pool = new Map<string, object>();
  dials = 0;
  forAddress(addr: string): object {
    const hit = this.pool.get(addr); // channels sharing — transports multiplexing, opening declining
    if (hit !== undefined) return hit;
    this.dials += 1;
    const fresh: object = { addr }; // handshakes amortizing — setups dividing, repeating declining
    this.pool.set(addr, fresh);
    return fresh;
  }
}
const pool = new ProxyPool();
const a = pool.forAddress('127.0.0.1:38921');
const b = pool.forAddress('127.0.0.1:38921');
const c = pool.forAddress('127.0.0.1:38922');
console.log(a === b && a !== c && pool.dials === 2 ? 'proxies reuse' : 'calls redial');
```

```typescript
// GOOD: calls timing — racing timeouts with mapped fallbacks on RxJS (compiled + run live).
import { lastValueFrom, of } from 'rxjs'; // timeouts racing — clocks competing, waiting declining
import { catchError, delay, timeout } from 'rxjs/operators';
async function timed(workMs: number, budgetMs: number): Promise<string> {
  return lastValueFrom(
    of('served').pipe(
      delay(workMs),
      timeout(budgetMs), // fallbacks mapping — defaults stating, crashing declining
      catchError(() => of('fallback')),
    ),
  ); // hangs refusing — stalls abandoning, leaking declining
}
async function runTimed(): Promise<void> {
  const fast = await timed(10, 500);
  const slow = await timed(500, 20);
  console.log(fast === 'served' && slow === 'fallback' ? 'calls time' : 'awaits forever');
}
runTimed();
```
