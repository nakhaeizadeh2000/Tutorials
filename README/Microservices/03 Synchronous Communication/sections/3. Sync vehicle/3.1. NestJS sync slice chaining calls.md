# 3.1. NestJS sync slice chaining calls

## 1. Chains composing (gateway calling — services answering — journeys completing)

**Definition** — composed sync chains: gateway calls answered by services completing journeys (gateway calling — entries fronting (requests routing — backends invoking (calling proving — scattering declining); services answering — patterns binding (payloads typing — responses matching (answering funding — hoping declining); journeys completing — tasks finishing (quotes totaling — confirms recording (completing owning — dropping declining).

**What problem it solves** — the unchained trio: *gateways uncalling* (entries unfronting — requests unrouting (backends uninvoked — journeys unstarted (uncalling billing — composition missing); *services unanswering* (patterns unbound — payloads untyped (responses unmatching — callers discovering (unanswering charging — contracts hoping); *journeys undropping* (tasks unfinishing — quotes untotaling (clients hanging — trust eroding (undropping costing — completion missing). Composed chains converting scattering to calling (entries fronting — patterns binding (tasks finishing — journeys flowing); reviewers driving chains per journey (composing proving → verifiable; scattering → returned).

**Modern guidance** — the composing lines per chain (review-enforced): *gateway calling* ([APIDesign 05/2.2](<../../../../APIDesign/05 Choosing and Unifying Styles/sections/2. Unifying patterns/2.2. Gateways unifying routing auth limits.md>) — entries fronting (requests routing — backends invoking (calling proving — scattering refusing (fronts earning — multiplies declining); *services answering* ([01/1.2](<../../../01 Microservices Foundations and Mental Model/sections/1. First thinking/1.2. First NestJS services slice.md>) — patterns binding (payloads typing — responses matching (answering funding — hoping refusing (bindings owning — discovery ending); *journeys completing* (tasks finishing — quotes totaling (confirms recording — dropping declining (completing owning — pausing refusing (finishes funding — trust earning).

```typescript
// GOOD: chains composing — gateway-routed quote journey over TCP (compiled + run live).
import 'reflect-metadata';
import { Controller, Module } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { ClientProxy, ClientProxyFactory, MessagePattern, MicroserviceOptions, Payload, Transport } from '@nestjs/microservices'; // TCP underneath — transport stated, scattering declining

@Controller()
class QuoteController { // services answering — patterns binding, hoping declining
  @MessagePattern({ cmd: 'quote' })
  quote(@Payload() data: { qty: number }): object {
    return { total: data.qty * 21 }; // journeys completing — tasks finishing, dropping declining
  }
  @MessagePattern({ cmd: 'confirm' })
  confirm(@Payload() data: { id: string }): object {
    return { id: data.id, state: 'confirmed' };
  }
}

@Module({ controllers: [QuoteController] })
class QuoteModule {}

async function runChain(): Promise<void> {
  const server = await NestFactory.createMicroservice<MicroserviceOptions>(QuoteModule, {
    transport: Transport.TCP,
    options: { host: '127.0.0.1', port: 38931 },
  });
  await server.listen();
  const client: ClientProxy = ClientProxyFactory.create({ // gateway calling — entries fronting, scattering declining
    transport: Transport.TCP,
    options: { host: '127.0.0.1', port: 38931 },
  });
  await client.connect();
  const quoted = await client.send<object, { qty: number }>({ cmd: 'quote' }, { qty: 2 }).toPromise();
  const done = await client.send<object, { id: string }>({ cmd: 'confirm' }, { id: 'o1' }).toPromise();
  console.log(JSON.stringify(quoted) === '{"total":42}' && JSON.stringify(done) === '{"id":"o1","state":"confirmed"}' ? 'chains compose' : 'calls scatter');
  client.close();
  await server.close();
}
runChain();
```

**Common confusion** — *"chaining means orchestration (controllers commanding)."* Commanding centralizing logic (workflows owning — services commanding (steps sequencing — sagas managing (commanding serving — choreography declining); chaining composing calls (gateway fronting — services answering (journeys completing — tasks flowing (composing proving — scattering declining). "Orchestration" describing control (workflows owning — steps sequencing); chaining describing journeys (calls composing — tasks finishing). Compose chains (gateway calling — journeys completing); orchestrate deliberately (workflows owning — sagas managing).

**Performance note** — composing economics: calling costing hops (gateway fronting — services answering (journeys completing — tasks flowing); scattered equivalents costing dials (entries unfronting — backends uninvoked (trust eroding — journeys dropping). Chain cheaply (calls — journeys); scatter never (gateways — tasks).

**Mentor note** — teach "one chain per journey, driven on the wire" (juniors composing one gateway-led chain per journey design scatter-proof sync on first hearing; unchained callers interrogated ("journey which?" — composing demanding per chain). Compose one chain once (gateway calling — services answering tangible (scattering ending — composing proving permanently). Front entries; finish tasks — composing discipline in three habits, reviewed per journey.

## 2. Budgets enforcing (deadlines forwarding — overruns refusing — tails bounding)

**Definition** — enforced chain budgets: forwarded deadlines with refused overruns bounding tails (deadlines forwarding — remaining stating (hops deducting — spends accounting (forwarding proving — refreshing declining); overruns refusing — expired rejecting (work shedding — cascades declining (refusing funding — zombie declining); tails bounding — p99 capping (outliers trimming — waits limiting (bounding owning — growing declining).

**What problem it solves** — the budget-blind trio: *deadlines unforwarding* (remaining unstating — hops refreshing (spends unaccounted — tails compounding (unforwarding billing — propagation missing); *overruns unrefusing* (expired unrejecting — zombies working (resources burning — cascades scheduling (unrefusing charging — discipline missing); *tails unbounding* (p99 uncapping — outliers untrimmed (waits growing — callers hanging (unbounding costing — latency bluffing). Enforced budgets converting blindness to forwarding (remaining stating — expired rejecting (p99 capping — tails ending); reviewers finding budgets per chain (enforcing proving → verifiable; blind → returned).

**Modern guidance** — the enforcing lines per chain (review-enforced): *deadlines forwarding* ([1.2](<../../sections/1. Call thinking/1.2.
```typescript
// GOOD: budgets enforcing — forwarded deadlines with refused overruns (compiled + run live).
function chainLeft(budgetMs: number, spendsMs: number[]): number {
  let left = budgetMs; // deadlines forwarding — remaining stating, refreshing declining
  for (const s of spendsMs) left -= s;
  return left;
}
function gate(leftMs: number): string {
  if (!(leftMs > 0)) return 'REJECT'; // overruns refusing — expired rejecting, zombie declining
  return 'SERVE'; // tails bounding — p99 capping, growing declining
}
const left = chainLeft(500, [40, 120]);
console.log(left === 340 && gate(left) === 'SERVE' && gate(-60) === 'REJECT' ? 'budgets enforce' : 'chains blind');
```

## 3. Calls proving (inject driving — responses matching — faults surfacing)

**Definition** — proved sync calls: driven patterns with matched responses surfacing faults (inject driving — clients sending (patterns exercising — responses awaiting (driving proving — hoping declining); responses matching — payloads comparing (shapes asserting — mismatches failing (matching proving — assuming declining); faults surfacing — errors propagating (callers handling — silence declining (surfacing owning — hanging ending).

**What problem it solves** — the unproved-chain trio: *calls undriving* (patterns unexercised — responses unawaited (journeys hoping — clients discovering (undriving billing — integration missing); *responses unmatching* (payloads uncomparing — shapes unasserted (mismatches shipping — callers breaking (unmatching charging — contracts hoping); *faults unsurfaced* (errors unpropagating — callers unhandling (silence spreading — debugging archaeologizing (unsurfacing costing — observability failing). Driven calls converting hoping to matching (clients sending — payloads comparing (errors propagating — silence ending); reviewers exercising patterns per chain (proving revealing → verifiable; hoping → returned).

**Modern guidance** — the proving lines per chain (review-enforced): *inject driving* ([2.1](<../../sections/2. Client thinking/2.1. Client proxies owning calls.md>) — clients sending (patterns exercising — responses awaiting (driving proving — hoping refusing (drives earning — flakes declining); *responses matching* (payloads comparing — shapes asserting (mismatches failing — assuming declining (matching proving — shipping refusing (comparisons owning — breakage ending); *faults surfacing* (errors propagating — callers handling (silence declining — hanging ending (surfacing owning — swallowing refusing (propagation funding — archaeology declining).

```typescript
// GOOD: calls proving — driven ledger with matched balances and surfaced faults (compiled + run live).
import 'reflect-metadata';
import { Controller, Module } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { ClientProxy, ClientProxyFactory, MessagePattern, MicroserviceOptions, Payload, Transport } from '@nestjs/microservices'; // TCP underneath — transport stated, hoping declining

@Controller()
class LedgerController { // inject driving — clients sending, hoping declining
  private balance = 0;
  @MessagePattern({ cmd: 'credit' })
  credit(@Payload() data: { amount: number }): object {
    this.balance += data.amount; // responses matching — payloads comparing, assuming declining
    return { balance: this.balance };
  }
  @MessagePattern({ cmd: 'read' })
  read(): object {
    return { balance: this.balance };
  }
}

@Module({ controllers: [LedgerController] })
class LedgerModule {}

async function runLedger(): Promise<void> {
  const server = await NestFactory.createMicroservice<MicroserviceOptions>(LedgerModule, {
    transport: Transport.TCP,
    options: { host: '127.0.0.1', port: 38932 },
  });
  await server.listen();
  const client: ClientProxy = ClientProxyFactory.create({
    transport: Transport.TCP,
    options: { host: '127.0.0.1', port: 38932 },
  });
  await client.connect();
  await client.send<object, { amount: number }>({ cmd: 'credit' }, { amount: 40 }).toPromise();
  await client.send<object, { amount: number }>({ cmd: 'credit' }, { amount: 2 }).toPromise();
  const read = await client.send<object, object>({ cmd: 'read' }, {}).toPromise();
  let fault = 'silent'; // faults surfacing — errors propagating, hanging ending
  try {
    await client.send<object, object>({ cmd: 'missing' }, {}).toPromise();
  } catch {
    fault = 'surfaced';
  }
  console.log(JSON.stringify(read) === '{"balance":42}' && fault === 'surfaced' ? 'calls prove' : 'chains hope');
  client.close();
  await server.close();
}
runLedger();
```
