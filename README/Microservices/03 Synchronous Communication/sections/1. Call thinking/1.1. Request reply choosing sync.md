# 1.1. Request reply choosing sync

## 1. Sync fitting (answers needing — callers waiting — journeys completing)

**Definition** — fitting sync: request-reply where answers gate the journey (answers needing — responses gating (callers blocking — tasks pausing (needing proving — firing declining); callers waiting — threads holding (timeouts bounding — budgets pricing (waiting funding — hanging declining); journeys completing — tasks finishing (clients flowing — experiences funding (completing owning — dropping declining).

**What problem it solves** — the always-sync trio: *answers unneeding* (responses ungating — callers unblocking (events sufficing — patience allowing (unneeding billing — sync hoping); *callers unwaiting* (threads unholding — budgets unpricing (waits unbounded — hangs scheduling (unwaiting charging — discipline missing); *journeys undropping* (tasks unfinishing — clients hanging (experiences breaking — trust eroding (undropping costing — completion missing). Fitting sync converting always to needing (responses gating — threads holding (tasks finishing — events deferring); reviewers finding answer-gates per call (fitting proving → verifiable; always → returned).

**Modern guidance** — the fitting lines per call (review-enforced): *answers needing* (responses gating — callers blocking (tasks pausing — firing declining (needing proving — hoping refusing (gates owning — events deferring); *callers waiting* ([01/3.1](<../../../01 Microservices Foundations and Mental Model/sections/3. First safety/3.1. Contracts between services.md>) — threads holding (timeouts bounding — budgets pricing (waiting funding — hanging refusing (holds earning — storms declining); *journeys completing* (tasks finishing — clients flowing (experiences funding — dropping declining (completing owning — pausing refusing (finishes funding — trust earning).

```typescript
// GOOD: sync fitting — answer-gated calls with bounded waits (compiled + run live).
interface Call { // answers needing — responses gating, firing declining
  name: string;
  gatesAnswer: boolean;
  timeoutMs: number;
}
function misfit(calls: Call[], timeoutCap: number): string[] {
  const gaps: string[] = []; // callers waiting — threads holding, hanging declining
  for (const c of calls) {
    if (!c.gatesAnswer || !(c.timeoutMs > 0) || c.timeoutMs > timeoutCap) gaps.push(c.name);
  }
  return gaps; // journeys completing — tasks finishing, dropping declining
}
const fit: Call[] = [
  { name: 'price-quote', gatesAnswer: true, timeoutMs: 300 },
  { name: 'auth-check', gatesAnswer: true, timeoutMs: 200 },
];
const loose: Call[] = [{ name: 'notify', gatesAnswer: false, timeoutMs: 0 }];
console.log(misfit(fit, 1000).length === 0 && misfit(loose, 1000).join() === 'notify' ? 'sync fits' : 'calls always');
```

```typescript
// BAD: calls alwaysing — answers unneeding, callers unwaiting (real sync-everywhere shape).
// // Notify over request-reply (responses ungating — patience allowing — events sufficing).
// // No timeout (waits unbounded — hangs scheduling). Gate answers; bound waits; complete journeys.)
```

**Common confusion** — *"sync is simpler (calls awaiting)."* Awaiting simplifying code (responses returning — flows reading (logics lineating — debugs easing (awaiting serving — coupling missing); sync timing coupling (callers blocking — failures sharing (availability multiplying — independence declining (timing charging — simplicity bluffing). "Simpler" describing syntax (calls awaiting — flows reading); fitting describing coupling (answers gating — budgets bounding). Await where gated (responses needing — journeys completing); defer where patient (events streaming — independence earning).

**Performance note** — fitting economics: gating costing decisions (answers needing — waits bounding (journeys completing — events deferring); always equivalents costing coupling (threads holding — failures sharing (hangs scheduling — availability dying). Gate cheaply (answers — calls); always never (sync — journeys).

**Mentor note** — teach "sync only where the answer gates" (juniors gating one answer per sync call design always-proof communication on first hearing; gateless sync interrogated ("waits for what?" — fitting demanding per call). Fit one call once (responses gating — waits bounding tangible (always ending — fitting proving permanently). Need answers; bound callers — fitting discipline in three habits, reviewed per call.

## 2. Coupling timing (temporal binding — failures sharing — availability multiplying)

**Definition** — timed coupling: sync binding availability across services (temporal binding — clocks aligning (uptimes conjoining — deploys coinciding (binding proving — freeing declining); failures sharing — faults propagating (neighbors falling — blasts widening (sharing funding — isolating declining); availability multiplying — nines compounding (downtimes unioning — SLOs tightening (multiplying owning — assuming declining).

**What problem it solves** — the free-sync trio: *temporal unbinding* (clocks unaligning — uptimes unconjoining (availability assuming — math missing (unbinding billing — coupling hiding); *failures unsharing* (faults unpropagating — neighbors unfalling (blasts unmeasured — pages surprising (unsharing charging — isolation bluffing); *availability unmultiplying* (nines uncompounding — SLOs uncomputed (downtimes surprising — contracts breaching (unmultiplying costing — arithmetic failing). Timed coupling converting freeness to multiplying (clocks aligning — faults propagating (nines compounding — SLOs tightening); reviewers finding availability math per chain (timing proving → verifiable; free → returned).

**Modern guidance** — the timing lines per chain (review-enforced): *temporal binding* (clocks aligning — uptimes conjoining (deploys coinciding — freeing declining (binding proving — assuming refusing (alignments earning — math keeping); *failures sharing* (faults propagating — neighbors falling (blasts widening — isolating declining (sharing funding — containing refusing (propagations owning — pages predicting); *availability multiplying* (nines compounding — downtimes unioning (SLOs tightening — assuming declining (multiplying owning — hoping refusing (products funding — contracts keeping).

```typescript
// GOOD: coupling timing — compounded availability with shared failures (compiled + run live).
interface Link { // temporal binding — clocks aligning, freeing declining
  name: string;
  uptime: number;
}
function chainUptime(links: Link[]): number {
  let acc = 1; // availability multiplying — nines compounding, assuming declining
  for (const l of links) acc *= l.uptime;
  return Math.round(acc * 10000) / 10000; // failures sharing — faults propagating, isolating declining
}
const chain: Link[] = [
  { name: 'gateway', uptime: 0.999 },
  { name: 'orders', uptime: 0.999 },
  { name: 'billing', uptime: 0.99 },
];
console.log(chainUptime(chain) === 0.988 ? 'coupling times' : 'sync frees');
```

```typescript
// BAD: sync freeing — temporal unbinding, availability unmultiplying (real math-missing shape).

```

**Common confusion** — *"nines add (availabilities summing)."* Summing miscomputing unions (nines adding — downtimes understating (SLOs loosening — breaches scheduling (summing charging — arithmetic failing); multiplying compounding chains (uptimes conjoining — downtimes unioning (contracts tightening — surprises declining (multiplying proving — hoping declining). "Adding" describing wishes (nines summing — math missing); timing describing products (clocks aligning — uptimes multiplying). Multiply uptimes (chains compounding — SLOs tightening); share failure math (faults propagating — pages predicting).

**Performance note** — timing economics: multiplying costing arithmetic (clocks aligning — nines compounding (SLOs tightening — surprises declining); free equivalents costing breaches (downtimes surprising — contracts breaching (pages multiplying — trust eroding). Multiply cheaply (uptimes — chains); free never (sync — availability).

**Mentor note** — teach "multiply the nines before chaining" (juniors compounding one product per chain design math-proof coupling on first hearing; uncomputed chains interrogated ("nines product?" — timing demanding per chain). ## 3. Async deferring (patience allowing — events streaming — independence earning)

**Definition** — deferred async: patient work streaming events earning independence (patience allowing — answers unneeded (callers unblocking — tasks continuing (allowing proving — gating declining); events streaming — facts publishing (consumers subscribing — backlogs absorbing (streaming funding — coupling declining); independence earning — deploys decoupling (failures isolating — clocks freeing (earning owning — binding declining).

**What problem it solves** — the sync-default trio: *patience unallowing* (answers unneeded-yet-awaited (callers blocking-needlessly — threads wasting (unallowing billing — events missing); *events unstreaming* (facts unpublished — consumers unsubscribed (backlogs absenting — coupling persisting (unstreaming charging — independence failing); *independence unearned* (deploys coinciding — failures sharing (clocks aligning — autonomy bluffing (unearned costing — async theatering). Deferred async converting defaulting to allowing (answers unblocking — facts publishing (deploys decoupling — independence earning); reviewers finding patience per call (deferring proving → verifiable; defaulting → returned).

**Modern guidance** — the deferring lines per call (review-enforced): *patience allowing* (answers unneeded — callers unblocking (tasks continuing — gating declining (allowing proving — awaiting refusing (patience earning — threads freeing); *events streaming* (facts publishing — consumers subscribing (backlogs absorbing — coupling declining (streaming funding — blocking refusing (streams owning — independence funding); *independence earning* (deploys decoupling — failures isolating (clocks freeing — binding declining (earning owning — coinciding refusing (freedom funding — autonomy keeping). Async lands in Domain 04 (events owning — patience serving); this leaf defers without preteaching (no dead links either way).

```typescript
// GOOD: async deferring — patient calls routed to events (compiled + run live).
interface Work { // patience allowing — answers unneeded, gating declining
  name: string;
  needsAnswer: boolean;
}
function route(work: Work[]): { sync: string[]; async: string[] } {
  const sync: string[] = [];
  const async: string[] = []; // events streaming — facts publishing, coupling declining
  for (const w of work) {
    (w.needsAnswer ? sync : async).push(w.name);
  }
  return { sync, async }; // independence earning — deploys decoupling, binding declining
}
const jobs: Work[] = [
  { name: 'quote', needsAnswer: true },
  { name: 'receipt', needsAnswer: false },
  { name: 'audit', needsAnswer: false },
];
const routed = route(jobs);
console.log(routed.sync.join() === 'quote' && routed.async.join() === 'receipt,audit' ? 'async defers' : 'sync defaults');
```

```typescript
// BAD: sync defaulting — patience unallowing, independence unearned (real default shape).
// // Everything request-reply (callers blocking-needlessly — threads wasting — coupling persisting).
// // Receipts awaited (answers unneeded-yet-awaited). Allow patience; stream events; earn independence.)
```

"Better" describing fashion (events curing — judgment missing); choosing describing gates (answers gating — patience allowing). Gate sync (responses needing — waits bounding); stream patience (facts publishing — clocks freeing).

**Performance note** — deferring economics: allowing costing judgment (patience judging — events streaming (independence earning — coupling declining); defaulted equivalents costing threads (callers blocking-needlessly — clocks aligning (availability dying — autonomy bluffing). Judge cheaply (patience — calls); default never (sync — work).

**Mentor note** — teach "needs-answer decides the transport" (juniors routing one call per patience design default-proof communication on first hearing; unrouted calls interrogated ("answer gates?" — deferring demanding per call).
