# 1.2. Deadlines propagating budgets downstream

## 1. Budgets forwarding (remaining stating — hops deducting — tails bounding)

**Definition** — forwarded budgets: remaining milliseconds stated per hop with deducted spends (remaining stating — deadlines carrying (budgets declaring — hops reading (stating proving — assuming declining); hops deducting — spends subtracting (latencies accounting — ledgers balancing (deducting funding — overspending declining); tails bounding — p99 capping (outliers trimming — waits limiting (bounding owning — growing declining).

**What problem it solves** — the fresh-budget trio: *budgets unforwarding* (deadlines uncarrying — hops rereading-full (spends unaccounted — tails compounding (unforwarding billing — propagation missing); *hops undeducting* (latencies unsubtracting — ledgers unbalancing (overspends hiding — overruns scheduling (undeducting charging — arithmetic failing); *tails unbounding* (p99 uncapping — outliers untrimmed (waits growing — callers hanging (unbounding costing — latency bluffing). Forwarded budgets converting freshness to stating (deadlines carrying — spends subtracting (p99 capping — tails ending); reviewers finding remaining-ms per hop (forwarding proving → verifiable; fresh → returned).

**Modern guidance** — the forwarding lines per hop (review-enforced): *remaining stating* (deadlines carrying — budgets declaring (hops reading — assuming declining (stating proving — hiding refusing (declarations owning — freshness ending); *hops deducting* (spends subtracting — latencies accounting (ledgers balancing — overspending declining (deducting funding — hiding refusing (subtractions earning — overruns preventing); *tails bounding* (p99 capping — outliers trimming (waits limiting — growing declining (bounding owning — compounding refusing (caps funding — hangs ending).

```typescript
// GOOD: budgets forwarding — remaining milliseconds deducted per hop (compiled + run live).
interface Hop { // remaining stating — deadlines carrying, assuming declining
  name: string;
  spentMs: number;
}
function remaining(budgetMs: number, hops: Hop[]): number {
  let left = budgetMs; // hops deducting — spends subtracting, overspending declining
  for (const h of hops) left -= h.spentMs;
  return left; // tails bounding — p99 capping, growing declining
}
const hops: Hop[] = [
  { name: 'gateway', spentMs: 40 },
  { name: 'orders', spentMs: 120 },
];
const left = remaining(500, hops);
console.log(left === 340 && remaining(100, hops) === -60 ? 'budgets forward' : 'hops refresh');
```

```typescript
// BAD: hops refreshing — budgets unforwarding, tails unbounding (real compound shape).
// // Each hop waits full 500ms (deadlines uncarrying — spends unaccounted — tails compounding).
// // p99 explodes (outliers untrimmed — callers hanging). State remaining; deduct spends; bound tails.)
```

**Common confusion** — *"timeouts per hop suffice (budgets localing)."* Localing capping hops (waits bounding — tails trimming (overruns declining — hangs ending (localing serving — propagation missing); forwarding deducting chains (deadlines carrying — spends subtracting (ledgers balancing — overruns preventing (forwarding proving — freshness declining). "Sufficing" describing singles (hops capping — chains hoping); budgets describing journeys (remaining stating — spends deducting). Cap hops (timeouts stating — tails bounding); forward remaining (deadlines carrying — ledgers balancing).

**Performance note** — forwarding economics: stating costing headers (deadlines carrying — spends subtracting (p99 capping — tails ending); fresh equivalents costing compounds (spends unaccounted — tails compounding (waits growing — callers hanging). State cheaply (headers — hops); refresh never (budgets — chains).

**Mentor note** — teach "every hop spends from one budget" (juniors forwarding one remaining-ms per hop design compound-proof deadlines on first hearing; fresh-budget hops interrogated ("remaining what?" — forwarding demanding per hop). Forward one budget once (deadlines carrying — spends subtracting tangible (freshness ending — forwarding proving permanently). Carry deadlines; balance ledgers — forwarding discipline in three habits, reviewed per hop.

## 2. Overruns refusing (expired rejecting — work shedding — cascades declining)

**Definition** — refused overruns: expired budgets rejected with shed work declining cascades (expired rejecting — deadlines checking (lateness refusing — wasted declining (rejecting proving — working declining); work shedding — queues dropping (loads lightening — cores protecting (shedding funding — drowning declining); cascades declining — failures containing (neighbors serving — avalanches preventing (declining owning — amplifying ending).

**What problem it solves** — the zombie-work trio: *expired unrejecting* (deadlines unchecked — lateness working (results discarded — resources burning (unrejecting billing — discipline missing); *work unshedding* (queues undropping — loads undiminishing (cores drowning — neighbors starving (unshedding charging — protection failing); *cascades undeclining* (failures uncontaining — neighbors unserving (avalanches scheduling — availability dying (undeclining costing — containment missing). **Modern guidance** — the refusing lines per hop (review-enforced): *expired rejecting* (deadlines checking — lateness refusing (wasted declining — working refusing (rejecting proving — checking declining (checks owning — burn ending); *work shedding* (queues dropping — loads lightening (cores protecting — drowning declining (shedding funding — keeping refusing (drops earning — starvation ending); *cascades declining* (failures containing — neighbors serving (avalanches preventing — amplifying declining (declining owning — propagating refusing (containment funding — availability keeping).

```typescript
// GOOD: overruns refusing — expired budgets rejected with shed work (compiled + run live).
function admit(remainingMs: number): string {
  if (!(remainingMs > 0)) return 'REJECT-EXPIRED'; // expired rejecting — deadlines checking, working declining
  if (remainingMs < 50) return 'SHED-LOAD'; // work shedding — queues dropping, drowning declining
  return 'SERVE'; // cascades declining — failures containing, amplifying declining
}
console.log(admit(340) === 'SERVE' && admit(20) === 'SHED-LOAD' && admit(-60) === 'REJECT-EXPIRED' ? 'overruns refuse' : 'zombies work');
```

## 3. Clocks trusting (skews bounding — timeouts aligning — hangs ending)

**Definition** — trusted clocks: bounded skews with aligned timeouts ending hangs (skews bounding — drifts capping (offsets measuring — disagreements limiting (bounding proving — assuming declining); timeouts aligning — waits agreeing (hops harmonizing — tails converging (aligning funding — diverging declining); hangs ending — stalls surfacing (watchdogs firing — recoveries starting (ending owning — lingering declining).

**What problem it solves** — the clock-hope trio: *skews unbounding* (drifts uncapping — offsets unmeasuring (nodes disagreeing — deadlines misreading (unbounding billing — time assuming); *timeouts unaligning* (waits disagreeing — hops diverging (tails spreading — budgets fragmenting (unaligning charging — harmony failing); *hangs unending* (stalls unsurfaced — watchdogs unfiring (recoveries unstarted — threads leaking (unending costing — liveness bluffing). Trusted clocks converting hoping to bounding (drifts capping — waits agreeing (stalls surfacing — hangs ending); reviewers finding skew bounds per fleet (trusting proving → verifiable; hoping → returned).

**Modern guidance** — the trusting lines per fleet (review-enforced): *skews bounding* (drifts capping — offsets measuring (disagreements limiting — assuming declining (bounding proving — hoping refusing (caps owning — misreads ending); *timeouts aligning* (waits agreeing — hops harmonizing (tails converging — diverging declining (aligning funding — fragmenting refusing (agreements earning — spreads narrowing); *hangs ending* (stalls surfacing — watchdogs firing (recoveries starting — lingering declining (ending owning — leaking refusing (surfacing funding — liveness earning).

```typescript
// GOOD: clocks trusting — bounded skews with aligned timeouts (compiled + run live).
function skewed(offsetMs: number, skewCapMs: number): boolean {
  return Math.abs(offsetMs) > skewCapMs; // skews bounding — drifts capping, assuming declining
}
function aligned(timeouts: number[], toleranceMs: number): boolean {
  const spread = Math.max(...timeouts) - Math.min(...timeouts); // timeouts aligning — waits agreeing, diverging declining
  return spread <= toleranceMs; // hangs ending — stalls surfacing, lingering declining
}
console.log(!skewed(30, 100) && skewed(250, 100) && aligned([450, 500, 550], 150) && !aligned([100, 900], 150) ? 'clocks trust' : 'time hopes');
```

```typescript
// BAD: time hoping — skews unbounding, hangs unending (real stall shape).
// // Assume synced clocks (drifts uncapping — deadlines misreading — time assuming).
// // No watchdog (stalls unsurfaced — threads leaking). Bound skews; align timeouts; end hangs.)
```

**Common confusion** — *"NTP means synced (daemons guaranteeing)."* Guaranteeing promising precision (daemons running — offsets shrinking (discipline owning — perfection missing (promising charging — assuming failing); bounding pricing disagreement (drifts capping — spreads measuring (deadlines discounting — misreads declining (bounding proving — hoping declining). "Synced" describing aspirations (daemons running — perfection missing); trusting describing bounds (skews capping — spreads measuring). Cap skews (drifts bounding — misreads ending); discount readings (offsets measuring — assumptions pricing).

**Performance note** — trusting economics: bounding costing measurements (skews capping — waits agreeing (stalls surfacing — hangs ending); hoped equivalents costing misreads (deadlines misreading — threads leaking (recoveries unstarted — liveness bluffing).
