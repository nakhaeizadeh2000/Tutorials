# 3.1. Contract tests pinning ports

## 1. Suites pinning (contracts asserting — adapters proving — drift detecting)

**Definition** — contract suite: shared assertions per port that every adapter runs (contracts asserting — behaviors stating (implementations proving — doubles honoring (pinning funding — drifting declining); adapters proving — vendors passing (doubles sliding — details serving (proving owning — hoping ending); drift detecting — breakages surfacing (suites failing — changes flagging (detecting funding — silence ending).

**What problem it solves** — the bespoke-test trio: *suites duplicating* (per-adapter copies — assertions drifting (copies multiplying — maintenance doubling (duplicating billing — consistency failing); *adapters unproven* (vendors shipping — contracts hoping (implementations assuming — behaviors bluffing (unproven charging — swaps fearing); *drift hiding* (changes landing — suites greening (breakages masking — confidence lying (hiding costing — incidents scheduling). Pinned suites converting bespoke to shared (one suite owning — every adapter passing (contracts asserting — drift detecting); reviewers running one suite per port (pinning proving → verifiable; bespoke → returned).

**Modern guidance** — the pinning lines per port (review-enforced): *contracts asserting* (behaviors stating — implementations proving (doubles honoring — drifts detecting (asserting funding — hoping ending (pinning owning — bespoke declining); *adapters proving* (vendors passing — doubles sliding (details serving — cores ignoring (proving owning — assuming declining (passing earning — fearing ending); *drift detecting* (breakages surfacing — changes flagging (suites failing — silence ending (detecting funding — masking preventing (vigilance owning — incidents declining). Technique first shown for fakes in [02/2.2](<../../../02 Use Cases and Application Services/sections/2. Long flows/2.2. Idempotency guarding retries.md>) — applied here to driven vendors, never re-taught.

```typescript
// GOOD: suites pinning — happy-path plus error parity across vendors, broken caught (compiled + run live).
interface Vault { // driven door — app needing, details serving
  keep(secret: string): void;
  count(): number;
}
function vaultSuite(make: () => Vault): boolean { // suite pinning — contracts asserting, drift detecting
  const v = make();
  v.keep('a');
  v.keep('b');
  let threw = false;
  try { v.keep(''); } catch { threw = true; } // error parity — breakages surfacing, masking preventing
  return v.count() === 2 && threw;
}
class MemoryVault implements Vault { // vendor one — details serving, owning declining
  private n = 0;
  keep(secret: string): void {
    if (secret.length === 0) throw new Error('secret required');
    this.n += 1;
  }
  count(): number { return this.n; }
}
class CappedVault implements Vault { // vendor two — swapping earning, lock-in declining
  private items: string[] = [];
  keep(secret: string): void {
    if (secret.length === 0) throw new Error('secret required');
    if (this.items.length >= 1000) throw new Error('vault full');
    this.items.push(secret);
  }
  count(): number { return this.items.length; }
}
class BrokenVault implements Vault { // drift proving — suites failing, silence ending
  keep(_s: string): void { /* swallows — breakages masking, confidence lying */ }
  count(): number { return 0; }
}
console.log(vaultSuite(() => new MemoryVault()) && vaultSuite(() => new CappedVault()) && !vaultSuite(() => new BrokenVault()) ? 'suites pin' : 'adapters drift');
```

"Duplicating" describing overlap (assertions repeating — value questioning); contracts describing portability (swaps trusting — drifts detecting). **Performance note** — pinning economics: asserting costing one suite (contracts stating — adapters proving (drift detecting — incidents declining); bespoke equivalents costing maintenance (copies multiplying — assertions drifting (consistency failing — trust eroding). ## 2. Every adapter passing (implementations honoring — behaviors matching — swaps trusting)

**Definition** — adapter gate: production admission requiring suite passage (implementations honoring — contracts proving (vendors passing — doubles sliding (honoring funding — assuming declining); behaviors matching — outcomes identical (replays returning — errors paritying (matching proving — drifting declining); swaps trusting — replacements earning (vendors trading — confidence funding (trusting owning — fearing ending).

**What problem it solves** — the unproven-admission trio: *vendors shipping* (implementations assuming — contracts hoping (behaviors bluffing — suites missing (shipping billing — swaps fearing); *behaviors mismatching* (outcomes differing — errors diverging (replays breaking — callers branching (mismatching charging — callers coupling); *trust hoping* (migrations praying — rollbacks planning (confidence absenting — dread funding (hoping costing — options dying). Passing gates converting shipping to honoring (suites asserting — adapters proving (behaviors matching — swaps trusting); reviewers blocking unproven adapters per merge (passing proving → verifiable; shipping → returned).

**Modern guidance** — the passing lines per adapter (review-enforced): *implementations honoring* (contracts proving — vendors passing (doubles sliding — details serving (honoring funding — assuming declining (passing earning — fearing ending (admission owning — bluffing refusing); *behaviors matching* (outcomes identical — errors paritying (replays returning — callers simplifying (matching proving — drifting declining (parity owning — branching ending); *swaps trusting* (replacements earning — vendors trading (confidence funding — hoping ending (trusting owning — dreading declining (trading earning — locking declining).

## 3. Harness reusing (suites sharing — Nest injecting — mechanics borrowing)

**What problem it solves** — the rebuilt-harness trio: *suites hand-rolling* (modules manualing — graphs hoping (construction scattering — substitution missing (hand-rolling billing — wiring doubting); *wiring unproven* (adapters unwired — tokens unmapped (graphs untested — boot hoping (unproven charging — runtime breaking); *mechanics reteaching* (Test reexplaining — inject rederiving (pages duplicating NestJS — maintenance doubling (reteaching scheduling — drift arriving).
```typescript
// GOOD: harness reusing — two wired apps proving one contract through HTTP (compiled + run live).
import 'reflect-metadata';
import { Controller, Get, Inject, Injectable, Module } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { FastifyAdapter } from '@nestjs/platform-fastify'; // Fastify underneath — adapter stated, Express declining

interface Counter { // driven door — app needing, details serving
  add(n: number): void;
  total(): number;
}

@Injectable()
class MemoryCounter implements Counter { // vendor one — details serving, owning declining
  private sum = 0;
  add(n: number): void { this.sum += n; }
  total(): number { return this.sum; }
}

@Injectable()
class EntryCounter implements Counter { // vendor two — swapping earning, lock-in declining
  private entries: number[] = [];
  add(n: number): void { this.entries.push(n); }
  total(): number { return this.entries.reduce((a, b) => a + b, 0); }
}

@Injectable()
class Adder { // core deciding — ports importing, vendors unknown
  constructor(@Inject('COUNTER') private readonly counter: Counter) {}
  run(): number {
    this.counter.add(3);
    this.counter.add(4);
    return this.counter.total();
  }
}

@Controller('run')
class RunController { // driving adapter — inward translating, decisions declining
  constructor(private readonly adder: Adder) {}
  @Get()
  go(): object { return { total: this.adder.run() }; }
}

@Module({ controllers: [RunController], providers: [Adder, MemoryCounter, { provide: 'COUNTER', useClass: MemoryCounter }] })
class MemoryApp {}

@Module({ controllers: [RunController], providers: [Adder, EntryCounter, { provide: 'COUNTER', useClass: EntryCounter }] })
class EntryApp {}

async function prove(mod: new () => unknown): Promise<string> {
  const app = await NestFactory.create(mod, new FastifyAdapter());
  await app.init();
  const http = app.getHttpAdapter().getInstance() as any; // inject proving — instance driving, ports skipping
  const res = await http.inject({ method: 'GET', url: '/run' });
  await app.close();
  return res.body;
}

async function run(): Promise<void> {
  const a = await prove(MemoryApp);
  const b = await prove(EntryApp);
  console.log(a === '{"total":7}' && b === '{"total":7}' ? 'harness reuses' : 'wiring differs');
}
run();
```
