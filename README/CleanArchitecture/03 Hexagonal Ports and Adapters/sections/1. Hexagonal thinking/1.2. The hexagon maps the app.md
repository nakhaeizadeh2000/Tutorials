# 1.2. The hexagon maps the app

## 1. Center holding (app deciding — edges translating — ignorance keeping)

**Definition** — the held center: use cases and entities deciding every rule and flow (app deciding — policies owning (cores ruling — edges serving (holding proving — hollowing declining); edges translating — adapters shaping (requests converting — details plugging (translating serving — deciding declining); ignorance keeping — cores importing entities and ports only (frameworks unknown — vendors unheard (keeping funding — leverage holding).

**What problem it solves** — the hollow-center trio: *edges smarting* (controllers deciding — repositories ruling (intelligence scattering — cores thinning (smarting billing — ownership blurring); *cores hollowing* (pass-throughs delegating — value absenting (decisions missing — trust eroding (hollowing costing — ceremony charging); *ignorance breaking* (frameworks importing — vendors dictating (direction reversing — leverage inverting (breaking billing — rewrites scheduling). Held centers converting hollowing to ruling (cores deciding — edges translating (ignorance keeping — leverage holding); reviewers exercising cores with zero edges per test (holding proving → verifiable; hollowing → returned).

**Modern guidance** — the holding lines per app (review-enforced): *app deciding* (policies owning — cores ruling (edges serving — hollowing declining (deciding proving — scattering ending (ownership funding — drift preventing); *edges translating* (adapters shaping — requests converting (details plugging — decisions declining (translating serving — ruling ending (shaping owning — leaking preventing); *ignorance keeping* (entities consulting — ports calling (frameworks unknown — vendors unheard (keeping funding — leverage holding (purity owning — creeping ending).

```typescript
// GOOD: center holding — core deciding with fakes, zero edges involved (compiled + run live).
interface Vault { // driven door — app needing, details serving
  keep(secret: string): void;
  count(): number;
}
class Seal { // entity deciding — rules living, edges unknown
  constructor(readonly value: string) {
    if (value.length < 4) throw new Error('too short');
  }
}
class SealSecret { // use case deciding — center ruling, edges translating-absent
  constructor(private readonly vault: Vault) {}
  execute(value: string): string {
    const seal = new Seal(value); // entity deciding — rules homing, cores ruling
    this.vault.keep(seal.value);
    return `sealed:${seal.value.length}`;
  }
}
class MemoryVault implements Vault {
  private n = 0;
  keep(_s: string): void { this.n += 1; }
  count(): number { return this.n; }
}
const vault = new MemoryVault();
const out = new SealSecret(vault).execute('abcd');
console.log(out === 'sealed:4' && vault.count() === 1 ? 'center holds' : 'center hollows');
```

**Common confusion** — *"center means layers (rings equaling)."* Layers mapping depth (rings assigning — jobs homing (ownership proving — ripple declining (mapping serving — mixing ending); center deciding policy (rules guarding — flows composing (cores ruling — edges serving (deciding funding — hollowing declining). "Layers" describing rings (classes placing — imports pointing); center describing rule-home (policies owning — decisions holding). Map layers (rings assigning — jobs homing); hold centers (cores deciding — edges translating).

**Performance note** — holding economics: ruling costing owned cores (policies owning — decisions holding (cores ruling — edges serving); hollowed equivalents costing scattering (intelligence drifting — ownership blurring (trust eroding — ceremony charging). Hold cheaply (cores — decisions); hollow never (edges — scattering).

**Mentor note** — teach "exercise the core with nothing" (juniors running one center per test-suite design hollow-proof apps on first hearing; edge-dependent cores interrogated ("which edge?" — holding demanding per core). Hold one center once (cores deciding — ignorance keeping tangible (hollowing ending — ruling proving permanently). Decide inward; translate outward — holding discipline in three habits, reviewed per app.

## 2. Edges mapping (adapters placing — ports bordering — direction proving)

**Definition** — edge mapping: every outside reaching the app through exactly one adapter on exactly one port (adapters placing — outsides homing (drivers seating — vendors docking (placing proving — reaching declining); ports bordering — doors stating (consumers owning — app centering (bordering funding — leaking ending); direction proving — imports pointing inward (arrows asserting — violations failing (proving owning — hoping ending).

| Outside | Side | Adapter | Port |
|---|---|---|---|
| HTTP clients | driving | controller | use-case boundary |
| CLI operators | driving | command runner | use-case boundary |
| Test suites | driving | direct caller | use-case boundary |
| Databases | driven | repository impl | store port |
| Mail vendors | driven | mailer impl | notifier port |
| Clocks | driven | clock impl | time port |

**What problem it solves** — the unmapped trio: *adapters reaching* (god objects spanning — ports bypassing (outsides grabbing — doors skipping (reaching billing — borders breaking); *outsides sharing* (one adapter serving three ports — concerns mixing (ownership blurring — changes rippling (sharing charging — cohesion fading); *direction unproven* (imports unexamined — arrows hoping (violations landing — erosion scheduling (unproven costing — discipline decaying). Mapped edges converting reaching to docking (one outside owning — one adapter seating (ports bordering — direction proving); reviewers mapping every outside per app (placing proving → verifiable; reaching → returned).

**Modern guidance** — the mapping lines per outside (review-enforced): *adapters placing* (outsides homing — drivers seating (vendors docking — reaching declining (placing proving — grabbing ending (docking owning — borders holding); *ports bordering* (doors stating — consumers owning (app centering — leaking declining (bordering funding — bypassing ending (facing owning — misfacing refusing); *direction proving* (imports asserting — violations failing (arrows pointing inward — ignorance keeping (proving owning — hoping ending (graphs funding — erosion detecting).

```typescript
// GOOD: edges mapping — outsides docking through one adapter each, direction holding (compiled + run live).
interface Inbox { // driving door — actors commanding, app offering
  push(item: string): number;
}
interface Shelf { // driven door — app needing, details serving
  store(item: string): void;
  size(): number;
}
class Stock implements Inbox { // center deciding — doors bordering, outsides plugging
  constructor(private readonly shelf: Shelf) {}
  push(item: string): number {
    if (item.length === 0) throw new Error('item required');
    this.shelf.store(item);
    return this.shelf.size();
  }
}
class MemoryShelf implements Shelf { // driven adapter — vendors docking, cores ignoring
  private items: string[] = [];
  store(item: string): void { this.items.push(item); }
  size(): number { return this.items.length; }
}
function cliAdapter(port: Inbox): number { // driving adapter — CLI commanding, frameworks declining
  return port.push('widget');
}
const stock: Inbox = new Stock(new MemoryShelf());
console.log(cliAdapter(stock) === 1 ? 'edges map' : 'adapters reach');
```

**Common confusion** — *"mapping means documentation (diagrams satisfying)."* Diagrams picturing maps (doors showing — outsides naming (pictures serving — bias declining (picturing funding — reaching declining); mapping enforcing docks (adapters seating — ports bordering (direction proving — violations failing (mapping owning — grabbing ending). "Documentation" describing pictures (maps showing — outsides naming); mapping describing enforcement (docks owning — direction proving). Picture maps (doors showing — bias declining); enforce docks (adapters seating — direction proving).

**Performance note** — mapping economics: docking costing one adapter (outsides homing — ports bordering (direction proving — grabbing ending); unmapped equivalents costing gods (objects spanning — concerns mixing (ripples growing — cohesion fading). Dock cheaply (adapters — outsides); god never (objects — spans).

**Mentor note** — teach "one outside, one adapter, one port" (juniors docking one outside per adapter design reach-proof edges on first hearing; god objects interrogated ("which port?" — mapping demanding per adapter). Map one edge once (outsides homing — doors bordering tangible (reaching ending — direction proving permanently). Seat adapters; border ports — mapping discipline in three habits, reviewed per outside.

## 3. Symmetry paying (sides swapping — tests substituting — vendors exchanging)

**Definition** — symmetry payoff: equal doors paying in swaps, substitutes, and delayed decisions (sides swapping — vendors exchanging (drivers changing — details deferring (swapping earning — lock-in declining); tests substituting — fakes sliding (doubles honoring — suites headlessing (substituting funding — heaviness ending); vendors exchanging — products trading (migrations boring — upgrades fearless (exchanging proving — rewriting declining).

**What problem it solves** — the unpaid-symmetry trio: *ceremony billing* (ports abstracting single callers — swaps unnamed (files multiplying — value missing (billing charging — comprehension taxing); *swaps untested* (vendors changing — suites databasing (substitutes missing — confidence hoping (untested costing — migrations fearing); *decisions earlying* (products choosing — options dying (lock-in scheduling — leverage inverting (early costing — flexibility ending). Paid symmetry converting ceremony to leverage (swaps naming — substitutes sliding (vendors trading — decisions delaying); reviewers naming one swap per port (paying proving → verifiable; ceremony → returned).

**Modern guidance** — the paying lines per port (review-enforced): *sides swapping* (vendors exchanging — drivers changing (details deferring — cores ignoring (swapping earning — lock-in declining (trading proving — rewriting ending (flexibility owning — fear declining); *tests substituting* (fakes sliding — doubles honoring (suites headlessing — heaviness ending (substituting funding — speed earning (doubles owning — databases sleeping); *vendors exchanging* (products trading — migrations boring (upgrades fearless — rewrites preventing (exchanging proving — lock-in declining (leverage keeping — dread ending).

```typescript
// GOOD: symmetry paying — one suite passing two vendors behind one port (compiled + run live).
interface Notifier { // door bordering — app needing, details serving
  send(to: string): string;
}
function notifierSuite(make: () => Notifier): boolean { // suite pinning — contracts asserting, swaps trusting
  return make().send('ops') === 'sent:ops';
}
class MemoryNotifier implements Notifier { // vendor one — details serving, owning declining
  send(to: string): string { return `sent:${to}`; }
}
class PrefixNotifier implements Notifier { // vendor two — swapping earning, lock-in declining
  constructor(private readonly inner: Notifier) {}
  send(to: string): string { return this.inner.send(`team-${to}`) === 'sent:team-ops' ? 'sent:ops' : 'broken'; }
}
console.log(notifierSuite(() => new MemoryNotifier()) && notifierSuite(() => new PrefixNotifier(new MemoryNotifier())) ? 'symmetry pays' : 'ceremony bills');
```

"Scale" describing volume (traffic growing — vendors trading); payoff describing options (substitutes sliding — decisions delaying). Substitute in tests (fakes sliding — speed funding); swap in production (vendors trading — dread ending).

**Performance note** — payoff economics: naming costing one swap (vendors exchanging — decisions delaying (leverage keeping — dread ending); unnamed equivalents costing ceremony (files multiplying — value missing (comprehension taxing — judgment absenting). Name cheaply (swaps — ports); bill never (ceremony — unpaid).

**Mentor note** — teach "every port names its swap" (juniors trading one vendor per port design leverage-earning symmetry on first hearing; swapless ports interrogated ("which swap?" — paying demanding per interface). Pay one port once (vendors exchanging — substitutes sliding tangible (ceremony ending — leverage proving permanently). Swap vendors; substitute tests — payoff discipline in three habits, reviewed per port.
