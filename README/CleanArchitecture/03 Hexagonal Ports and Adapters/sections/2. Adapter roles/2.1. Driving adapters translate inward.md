# 2.1. Driving adapters translate inward

## 1. Inward translating (requests shaping — use cases calling — frameworks declining)

**Definition** — driving adapter: outside protocol converted into driving-port calls (requests shaping — protocols converting (edges translating — cores shielding (translating proving — leaking declining); use cases calling — intents invoking (flows starting — rules homing (calling funding — deciding declining); frameworks declining — adapters owning protocol (NestJS serving — cores ignoring (declining proving — dictating ending).

**What problem it solves** — the leaking-protocol trio: *protocols drilling* (HTTP types invading — request objects branching (transports owning — tests heavying (drilling billing — portability dying); *cores frameworking* (decorators colonizing — imports creeping (vendors owning — policy obeying (frameworking charging — ignorance breaking); *translations skipping* (raw passing — shapes assuming (garbage entering — corruption arriving (skipping costing — trust eroding). Inward translation converting drilling to shaping (protocols converting — ports calling (cores shielding — leaks declining); reviewers finding protocol types only in adapters per flow (translating proving → verifiable; drilling → returned).

**Modern guidance** — the translating lines per driving adapter (review-enforced): *requests shaping* (protocols converting — edges translating (cores shielding — leaks declining (shaping proving — drilling ending (translation owning — exposure declining); *use cases calling* (intents invoking — flows starting (rules homing — decisions declining (calling funding — skipping ending (delegation owning — duplication declining); *frameworks declining* (adapters owning — cores ignoring (vendors serving — policy deciding (declining proving — dictating ending (deferral funding — leverage keeping). Interface-token wiring (custom providers) lives in the NestJS DI domain — class-typed injection suffices here because direction holds.

```typescript
// GOOD: inward translating — controller shaping HTTP into port calls, core protocol-free (compiled + run live).
import 'reflect-metadata';
import { Controller, Get, Injectable, Module } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { FastifyAdapter } from '@nestjs/platform-fastify'; // Fastify underneath — adapter stated, Express declining

interface GreetPort { // DRIVING port — app offering, actors commanding
  hello(name: string): string;
}

@Injectable()
class GreetUseCase implements GreetPort { // core deciding — rules homing, protocols absenting
  hello(name: string): string {
    if (name.length === 0) throw new Error('name required');
    return `hi:${name}`;
  }
}

@Controller('greet')
class GreetController { // DRIVING adapter — inward translating, decisions declining
  constructor(private readonly use: GreetUseCase) {}
  @Get()
  go(): object { return { msg: this.use.hello('ada') }; } // use cases calling — intents invoking, frameworks declining
}

@Module({ controllers: [GreetController], providers: [GreetUseCase] })
class AppModule {}

async function run(): Promise<void> {
  const app = await NestFactory.create(AppModule, new FastifyAdapter());
  await app.init();
  const http = app.getHttpAdapter().getInstance() as any; // inject proving — instance driving, ports skipping
  const res = await http.inject({ method: 'GET', url: '/greet' });
  console.log(res.statusCode === 200 && res.body === '{"msg":"hi:ada"}' ? 'inward translates' : 'protocol drills');
  await app.close();
}
run();
```

"Wrappers" describing pass-through (calls forwarding — value missing); adapters describing translation (protocols converting — ports calling). Shape requests (protocols converting — cores shielding); call ports (intents invoking — flows starting).

**Performance note** — translating economics: shaping costing one adapter (protocols converting — cores shielding (leaks declining — trust earning); drilled equivalents costing portability (transports owning — tests heavying (protocol binding — reuse dying). Shape cheaply (adapters — edges); drill never (protocols — cores).

## 2. Controllers thinning (HTTP parsing — DTOs validating — decisions absenting)

**Definition** — thin controller: HTTP parsed, DTOs validated, use case called, response shaped — no branches deciding (HTTP parsing — requests shaping (transports serving — handlers assuming (parsing funding — drilling declining); DTOs validating — shapes proving (garbage declining — cores shielding (validating owning — corruption preventing); decisions absenting — branches declining (rules homing — tests easing (absenting proving — fattening ending).

**What problem it solves** — the fat-controller trio: *handlers branching* (ifs deciding — totals computing (logic scattering — reuse absenting (branching billing — ownership blurring); *DTOs skipping* (any accepting — unknowns smuggling (shapes unproven — corruption arriving (skipping costing — trust eroding); *responses shaping logic* (statuses deciding — envelopes branching (presentation ruling — domain obeying (shaping charging — layering breaking). Thin controllers converting fattening to shaping (parsing owning — calling delegating (decisions declining — rules homing); reviewers reading handlers in seconds per endpoint (thinning proving → verifiable; branching → returned).

**Modern guidance** — the thinning lines per endpoint (review-enforced): *HTTP parsing* (requests shaping — transports serving (handlers assuming — drilling declining (parsing funding — invading ending (shaping owning — leaking preventing); *DTOs validating* (shapes proving — garbage declining (cores shielding — corruption preventing (validating owning — skipping refusing (contracts bounding — trust earning); *decisions absenting* (branches declining — rules homing (tests easing — fattening ending (absenting proving — scattering declining (thin owning — reuse funding).

```typescript
// GOOD: controllers thinning — parse, validate, call, shape; branches absent (compiled + run live).
interface PagePort { // driving door — app offering, actors commanding
  list(page: number): string;
}
class Lister implements PagePort { // core deciding — rules homing, branches owning-here
  list(page: number): string {
    if (page < 1) throw new Error('page >= 1 required');
    return `page:${page}`;
  }
}
function listEndpoint(port: PagePort, raw: unknown): { status: number; body: string } { // controller-shape thinning — translating, never deciding
  if (typeof raw !== 'object' || raw === null) return { status: 400, body: '{"error":"shape invalid"}' }; // HTTP parsing — requests shaping, drilling declining
  const page = (raw as { page: unknown }).page;
  if (!Number.isInteger(page)) return { status: 400, body: '{"error":"page integer required"}' }; // DTOs validating — shapes proving, cores shielding
  try {
    return { status: 200, body: JSON.stringify({ data: port.list(page as number) }) }; // use cases calling — decisions absenting, rules homing
  } catch {
    return { status: 422, body: '{"error":"page >= 1 required"}' };
  }
}
const port: PagePort = new Lister();
const okRes = listEndpoint(port, { page: 3 });
const badRes = listEndpoint(port, { page: 'three' });
console.log(okRes.status === 200 && okRes.body === '{"data":"page:3"}' && badRes.status === 400 ? 'thin serves' : 'controllers fatten');
```

## 3. Many driving (CLI commanding — tests invoking — events triggering)

**Definition** — many drivers: one driving port commanded by several actors (CLI commanding — operators invoking (scripts serving — humans driving (commanding funding — HTTP-only ending); tests invoking — suites calling (doubles sliding — feedback speeding (invoking proving — heaviness declining); events triggering — schedulers firing (timers owning — flows starting (triggering serving — polling declining).

**What problem it solves** — the HTTP-only trio: *ports single-actoring* (controllers owning — CLIs duplicating (logic forking — drift growing (single charging — reuse declining); *tests httping* (suites booting — servers listening (feedback dying — flakes growing (httping costing — confidence eroding); *triggers polling* (loops checking — schedules missing (polling billing — timeliness declining (checking charging — events absenting). Many drivers converting single to several (ports sharing — actors multiplying (reuse funding — drift ending); reviewers listing actors per port (many proving → verifiable; single → returned).

**Modern guidance** — the many lines per driving port (review-enforced): *CLI commanding* (operators invoking — scripts serving (humans driving — HTTP-only ending (commanding funding — forking declining (scripts owning — duplication ending); *tests invoking* (suites calling — doubles sliding (feedback speeding — heaviness declining (invoking proving — httping ending (tests owning — servers sleeping); *events triggering* (schedulers firing — timers owning (flows starting — polling declining (triggering serving — checking ending (events funding — timeliness earning).

```typescript
// GOOD: many driving — CLI, tests, and scheduler commanding one port (compiled + run live).
interface Counter { // driving door — app offering, actors commanding
  bump(): number;
}
class Hits implements Counter { // center deciding — actors multiplying, logic single
  private n = 0;
  bump(): number { this.n += 1; return this.n; }
}
function cliDriver(port: Counter, argv: string[]): number { // actor one — CLI commanding, core ignoring
  return argv.includes('--bump') ? port.bump() : port.bump();
}
function testDriver(port: Counter): number { // actor two — tests invoking, servers sleeping
  return port.bump();
}
function scheduleDriver(port: Counter, ticks: number): number { // actor three — events triggering, polling declining
  let last = 0;
  for (let i = 0; i < ticks; i += 1) last = port.bump();
  return last;
}
const port: Counter = new Hits();
const a = cliDriver(port, ['--bump']);
const b = testDriver(port);
const c = scheduleDriver(port, 2);
console.log(a === 1 && b === 2 && c === 4 ? 'many drive' : 'http only');
```
