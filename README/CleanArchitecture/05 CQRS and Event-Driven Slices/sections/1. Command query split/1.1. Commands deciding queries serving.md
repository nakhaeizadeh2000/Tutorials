# 1.1. Commands deciding queries serving

## 1. Commands deciding (intents owning — writes guarding — reads declining)

**Definition** — command: intent to change, validated and guarded, answering acknowledgment — never data (intents owning — flows stating (changes requesting — reads refusing (owning proving — querying declining); writes guarding — rules enforcing (invariants checking — corruption refusing (guarding funding — hoping ending); reads declining — queries absenting (projections unneeded — shapes unreturned (declining proving — mixing ending).

**What problem it solves** — the querying-command trio: *commands returning* (lists answering — shapes shaping (reads serving — writes confusing (returning billing — splitting breaking); *reads guarding* (queries validating — writes missing (concerns mixing — models compromising (guarding charging — serving declining); *intents blurring* (verbs muddying — effects surprising (ownership missing — audits guessing (blurring costing — trust eroding). Deciding commands converting querying to owning (intents stating — writes guarding (reads declining — acks answering); reviewers finding void-or-ack returns per command (deciding proving → verifiable; returning → passed).

**Modern guidance** — the deciding lines per command (review-enforced): *intents owning* (flows stating — changes requesting (reads refusing — mixing declining (owning proving — querying ending (commands ruling — queries serving); *writes guarding* (rules enforcing — invariants checking (corruption refusing — hoping ending (guarding funding — assuming declining (checks owning — breaks declining); *reads declining* (queries absenting — projections unneeded (shapes unreturned — mixing ending (declining proving — serving refusing (acks answering — data withholding).

```typescript
// GOOD: commands deciding — split controllers, writes guarding, reads declining (compiled + run live).
import 'reflect-metadata';
import { Body, Controller, Get, Injectable, Module, Post } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { FastifyAdapter } from '@nestjs/platform-fastify'; // Fastify underneath — adapter stated, Express declining

@Injectable()
class OrdersWrite { // command deciding — intents owning, writes guarding
  private ids = 0;
  private readonly placed: string[] = [];
  place(item: string): string {
    if (item.length === 0) throw new Error('item required'); // writes guarding — rules enforcing, corruption refusing
    this.ids += 1;
    const id = `o${this.ids}`;
    this.placed.push(id);
    return id; // reads declining — acks answering, data withholding
  }
}

@Injectable()
class OrdersRead { // query serving — reads shaping, writes absenting
  list(): string[] { return ['o1']; }
}

@Controller('orders')
class WriteController { // write edge — commands owning, reads declining
  constructor(private readonly write: OrdersWrite) {}
  @Post()
  place(@Body() body: { item: string }): object { return { id: this.write.place(body.item) }; }
}

@Controller('orders-view')
class ReadController { // read edge — queries serving, writes absenting
  constructor(private readonly read: OrdersRead) {}
  @Get()
  all(): object { return { orders: this.read.list() }; }
}

@Module({ controllers: [WriteController, ReadController], providers: [OrdersWrite, OrdersRead] })
class AppModule {}

async function run(): Promise<void> {
  const app = await NestFactory.create(AppModule, new FastifyAdapter());
  await app.init();
  const http = app.getHttpAdapter().getInstance() as any; // inject proving — instance driving, ports skipping
  const placed = await http.inject({ method: 'POST', url: '/orders', payload: { item: 'book' } });
  const listed = await http.inject({ method: 'GET', url: '/orders-view' });
  console.log(placed.statusCode === 201 && JSON.parse(placed.body).id === 'o1' && listed.body === '{"orders":["o1"]}' ? 'commands decide' : 'models mix');
  await app.close();
}
run();
```

## 2. Queries serving (reads shaping — projections answering — writes absenting)

**Definition** — query: shaped read answered by projections without side effects (reads shaping — questions answering (views serving — mutations refusing (shaping proving — changing declining); projections answering — folds serving (events deriving — joins precomputing (answering funding — loading declining); writes absenting — commands declining (mutations refusing — stores unchanging (absenting proving — mixing ending).

**What problem it solves** — the mutating-query trio: *queries writing* (reads incrementing — views logging (sides effecting — audits confusing (writing billing — purity dying (mutating charging — trust eroding); *domains loading* (aggregates fetching — graphs traversing (reads joining — contention growing (loading billing — display overpaying (serving charging — scaling declining); *shapes computing* (joins runtimeing — sorts repeating (queries slowing — caches missing (computing costing — users waiting (repeating charging — latency growing). Serving queries converting mutating to shaping (reads answering — projections serving (writes absenting — sides pure); reviewers proving query purity per read (serving proving → verifiable; mutating → returned).

**Modern guidance** — the serving lines per query (review-enforced): *reads shaping* (questions answering — views serving (mutations refusing — changing declining (shaping proving — writing ending (queries owning — commands declining); *projections answering* (folds serving — events deriving (joins precomputing — loading declining (answering funding — runtime ending (views earning — latency sparing); *writes absenting* (commands declining — mutations refusing (stores unchanging — mixing ending (absenting proving — effecting declining (pure owning — auditing easing).

```typescript
// GOOD: queries serving — shaped reads over precomputed views, inputs frozen (compiled + run live).
interface OrderView { // projection serving — folds answering, joins precomputed
  id: string;
  total: number;
}
function topOrders(views: readonly OrderView[], limit: number): string[] { // reads shaping — questions answering, mutations refusing
  return [...views].sort((a, b) => b.total - a.total).slice(0, limit).map((v) => v.id);
}
const views: OrderView[] = [
  { id: 'o1', total: 44 },
  { id: 'o2', total: 120 },
  { id: 'o3', total: 9 },
];
const before = JSON.stringify(views);
const leaders = topOrders(views, 2);
console.log(leaders.join(',') === 'o2,o1' && JSON.stringify(views) === before ? 'queries serve' : 'reads mutate');
```

## 3. Models splitting (write owning — read serving — scaling funding)

**Definition** — model split: write and read models diverging when pressures differ (write owning — aggregates guarding (commands funneling — contention sparing (owning proving — compromising declining); read serving — projections answering (queries shaping — latency bounding (serving funding — joining declining); scaling funding — pressures paying (reads multiplying — writes contending (funding proving — ceremony declining).

**What problem it solves** — the one-model trio: *models compromising* (writes guarding — reads joining (concerns mixing — pressures conflicting (compromising billing — neither serving (mixing charging — scaling blocking); *splits defaulting* (ceremony billing — pressure unmeasured (files multiplying — value missing (defaulting charging — judgment missing); *stores splitting early* (databases dividing — sync worrying (ceremony doubling — consistency debating (early costing — pressure absenting). Split models converting compromising to funding (write owning — read serving (pressures paying — ceremony billing-only-when-measured); reviewers demanding pressure numbers per split (splitting proving → verifiable; defaulting → returned).

**Modern guidance** — the splitting lines per pressure (review-enforced): *write owning* (aggregates guarding — commands funneling (contention sparing — compromising declining (owning proving — mixing ending (guards earning — splits funding); *read serving* (projections answering — queries shaping (latency bounding — joining declining (serving funding — compromising ending (views earning — waits declining); *scaling funding* (pressures paying — reads multiplying (writes contending (funding proving — ceremony declining (numbers owning — defaults refusing).

```typescript
// GOOD: models splitting — asymmetry scoring routing unified versus split (compiled + run live).
function split(readsPerSec: number, writesPerSec: number): string { // pressures paying — numbers owning, defaults refusing
  const asymmetry = readsPerSec / Math.max(writesPerSec, 1); // reads multiplying — writes contending, funding proving
  if (asymmetry >= 50) return 'split'; // read serving — projections answering, latency bounding
  return 'unified'; // write owning — ceremony declining, simplicity funding
}
const hot = split(5000, 20);
const even = split(40, 30);
console.log(hot === 'split' && even === 'unified' ? 'pressure splits' : 'defaults rule');
```
