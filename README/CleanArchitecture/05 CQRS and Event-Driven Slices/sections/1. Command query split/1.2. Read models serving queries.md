# 1.2. Read models serving queries

## 1. Reads shaping (queries answering — projections serving — joins precomputing)

**Definition** — read model: query-shaped view precomputed for one question (queries answering — screens serving (views owning — mutations refusing (shaping proving — joining declining); projections serving — folds answering (events deriving — builds funding (serving owning — runtime declining); joins precomputing — relations flattening (reads speeding — contention sparing (precomputing funding — runtime ending).

**What problem it solves** — the display-domain trio: *aggregates displaying* (graphs fetching — traversals joining (reads loading — contention growing (displaying billing — scaling declining (overpaying charging — latency growing); *joins runtimeing* (relations resolving — sorts repeating (queries slowing — caches missing (runtimeing costing — users waiting (repeating charging — budgets blowing); *views missing* (screens assembling — clients joining (shaping absenting — payloads bloating (missing billing — trust eroding). Shaped reads converting loading to serving (views owning — joins precomputing (queries answering — mutations refusing); reviewers finding one view per screen per query (shaping proving → verifiable; loading → returned).

**Modern guidance** — the shaping lines per query (review-enforced): *queries answering* (screens serving — views owning (mutations refusing — changing declining (answering proving — loading ending (reads earning — waits declining); *projections serving* (folds answering — events deriving (builds funding — runtime declining (serving owning — computing ending (views funding — latency sparing); *joins precomputing* (relations flattening — reads speeding (contention sparing — runtime ending (precomputing funding — repeating declining (flats owning — graphs refusing).

```typescript
// GOOD: reads shaping — two views answering two questions from one log (compiled + run live).
interface Placed { kind: 'placed'; id: string; total: number; }
interface Shipped { kind: 'shipped'; id: string; }
type Fact = Placed | Shipped;
const log: Fact[] = [ // facts owning — histories keeping, queries answering-absent
  { kind: 'placed', id: 'o1', total: 44 },
  { kind: 'placed', id: 'o2', total: 120 },
  { kind: 'shipped', id: 'o1' },
];
function revenue(facts: Fact[]): number { // view one — questions answering, joins precomputed
  return facts.reduce((a, f) => (f.kind === 'placed' ? a + f.total : a), 0);
}
function pending(facts: Fact[]): string[] { // view two — screens serving, mutations refusing
  const shipped = new Set(facts.filter((f) => f.kind === 'shipped').map((f) => f.id));
  return facts.filter((f) => f.kind === 'placed' && !shipped.has(f.id)).map((f) => f.id);
}
console.log(revenue(log) === 164 && pending(log).join(',') === 'o2' ? 'reads shape' : 'domains load');
```

**Common confusion** — *"read models duplicate domain logic (rules copying)."* Duplicating copying rules (guards forking — drift growing (validity splitting — consistency failing (duplicating charging — value missing); shaping answering questions (views serving — joins precomputing (reads owning — mutations refusing (shaping funding — ruling declining). "Duplicating" describing rules (guards forking — drift growing); reads describing service (questions answering — mutations refusing). Guard in domains (rules owning — validity holding); shape in reads (questions answering — joins precomputing).

**Performance note** — shaping economics: precomputing costing builds (joins flattening — latency sparing (views earning — runtime ending); loaded equivalents costing contention (graphs traversing — reads joining (scaling declining — users waiting). Precompute cheaply (views — builds); load never (domains — display).

**Mentor note** — teach "one view per question" (juniors shaping one projection per query design load-proof reads on first hearing; aggregate-displaying queries interrogated ("which view?" — shaping demanding per screen). Shape one read once (questions answering — joins precomputing tangible (loading ending — serving proving fast permanently). Answer questions; refuse mutations — shaping discipline in three habits, reviewed per query.

```typescript
// GOOD: denormalizing deliberately — priced copies with staleness windows, events syncing (compiled + run live).
interface Copy { // duplication pricing — copies counting, queries speeding
  total: number;
  atVersion: number;
  maxLag: number; // freshness budgeting — windows bounding, hoping ending
}
function synced(copy: Copy, sourceVersion: number): boolean {
  return sourceVersion - copy.atVersion <= copy.maxLag; // staleness stating — consumers tolerating, surprises declining
}
const priced: Copy = { total: 164, atVersion: 9, maxLag: 2 }; // copies counting — storage billing, fear declining
const fresh = synced(priced, 10);
const stale = synced(priced, 12);
console.log(fresh && !stale ? 'copies price' : 'freshness hopes');
```

## 3. Writes absenting (commands declining — mutations refusing — caches serving)

**Definition** — read-side purity: views frozen, mutators absent, derivation copying (commands declining — writes refusing (stores unchanging — mixing ending (declining proving — effecting ending); mutations refusing — inputs freezing (changes copying — originals keeping (refusing funding — corruption declining); caches serving — snapshots answering (reads speeding — computes skipping (serving earning — repeating declining).

**What problem it solves** — the writable-read trio: *reads mutating* (views editing — caches poisoning (sides effecting — trust eroding (mutating billing — purity dying); *commands duplicating* (writes forking — paths doubling (ownership blurring — audits confusing (duplicating charging — consistency failing); *caches hand-rolling* (snapshots expiring — keys colliding (invalidation hoping — staleness surprising (hand-rolling billing — discipline missing). Absent writes converting mutating to serving (inputs freezing — changes copying (caches answering — sides pure); reviewers finding zero mutators per read (absenting proving → verifiable; mutating → returned).

**Modern guidance** — the absenting lines per read (review-enforced): *commands declining* (writes refusing — stores unchanging (mixing ending — effecting declining (declining proving — forking refusing (reads owning — writes routing); *mutations refusing* (inputs freezing — changes copying (originals keeping — corruption declining (refusing funding — poisoning ending (frost proving — drift preventing); *caches serving* (snapshots answering — reads speeding (computes skipping — repeating declining (serving earning — expiring disciplined (hits owning — misses measuring).

```typescript
// GOOD: writes absenting — frozen views, copy-on-derive, originals intact (compiled + run live).
interface Board { // view freezing — inputs frozen, mutations refusing
  readonly title: string;
  readonly count: number;
}
function counted(board: Board): Board { // changes copying — originals keeping, corruption declining
  return { title: board.title, count: board.count + 1 };
}
const frozen: Board = Object.freeze({ title: 'sales', count: 7 }); // stores unchanging — mixing ending, effecting declining
const derived = counted(frozen);
console.log(Object.isFrozen(frozen) && frozen.count === 7 && derived.count === 8 ? 'writes absent' : 'reads mutate');
```
