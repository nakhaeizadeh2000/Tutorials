# 2.2. Idempotency guarding retries

## 1. Retries guarding (keys carrying — replays detecting — effects-once holding)

**Definition** — retry guarding: every retryable intent carrying a key that replays detect (keys carrying — intents identifying (callers generating — stores remembering (carrying proving — doubling declining); replays detecting — seen keys short-circuiting (effects skipping — responses returning (detecting funding — reprocessing ending); effects-once holding — side effects applying exactly once per key (atomic check-acting — storms surviving (holding proving — doubling preventing).

**What problem it solves** — the naked-retry trio: *timeouts doubling* (clients retrying — servers re-executing (charges doubling — emails duplicating (doubling billing — trust eroding); *effects multiplying* (handlers rerunning — stores appending (side effects compounding — ledgers drifting (multiplying charging — consistency breaking); *at-least-once denying* (delivery assuming-once — networks redelivering (assumptions hoping — reality retrying (denying costing — duplicates arriving). Guarded retries converting doubling to once (keys identifying — replays short-circuiting (effects holding — storms surviving); reviewers finding a key per retryable intent (guarding proving → verifiable; naked → returned).

**Modern guidance** — the guarding lines per retryable intent (review-enforced): *keys carrying* (intents identifying — callers generating (stores remembering — windows bounding (carrying proving — doubling declining (identifying funding — anonymity ending); *replays detecting* (seen short-circuiting — effects skipping (responses returning — reprocessing ending (detecting funding — multiplying preventing (dedupe owning — storms surviving); *effects-once holding* (atomic check-acting — storms surviving (once proving — doubling preventing (holding owning — trust earning).

```typescript
// GOOD: retries guarding — keyed executor applying effects once per key (compiled + run live).
class KeyedExecutor { // guard owning — keys carrying, replays detecting
  private readonly seen = new Set<string>(); // stores remembering — effects-once holding, doubling declining
  private effects = 0;
  run(key: string, effect: () => void): string {
    if (this.seen.has(key)) return 'replay'; // replays detecting — seen short-circuiting, reprocessing ending
    this.seen.add(key);
    effect();
    this.effects += 1;
    return 'applied';
  }
  count(): number { return this.effects; }
}
const ex = new KeyedExecutor();
const first = ex.run('order-7', () => undefined);
const replay = ex.run('order-7', () => undefined); // timed-out client retrying — effect skipping, response returning
const other = ex.run('order-8', () => undefined);
console.log(first === 'applied' && replay === 'replay' && other === 'applied' && ex.count() === 2 ? 'retries guard' : 'effects double');
```

```typescript
// GOOD: receivers idempotenting — dedupe store absorbing replays, outcomes identical (compiled + run live).
class Receiver { // handler reentering — messages deduping, storms surviving
  private readonly outcomes = new Map<string, string>(); // processed remembering — replays returning, doubling declining
  private charges = 0;
  receive(id: string, amount: number): string {
    const known = this.outcomes.get(id);
    if (known !== undefined) return known; // replays returning — effects skipping, responses identical
    if (amount <= 0) throw new Error('amount must be positive');
    this.charges += amount;
    const outcome = `charged:${amount}`;
    this.outcomes.set(id, outcome);
    return outcome;
  }
  total(): number { return this.charges; }
}
const rx = new Receiver();
const a = rx.receive('msg-1', 50);
const replay = rx.receive('msg-1', 50); // broker redelivering — dedupe absorbing, effect skipping
console.log(a === 'charged:50' && replay === 'charged:50' && rx.total() === 50 ? 'receivers hold' : 'replays double');
```

// GOOD: keys owned — deterministic derivation matching intents, differing otherwise (compiled + run live).
function keyFor(intent: string, fields: Array<[string, string]>): string { // callers generating — intents deriving, anonymity ending
  const sorted = [...fields].sort(([a], [b]) => (a < b ? -1 : 1));
  return `${intent}:${sorted.map(([k, v]) => `${k}=${v}`).join('&')}`;
}
const retryA = keyFor('charge', [['card', '4242'], ['amount', '50']]);
