## 1. Boundary matching (transaction scoping — use case owning — partials declining)

Matched boundaries converting scattering to atomicity (one execution owning — one transaction scoping (partials declining — work atomizing); reviewers checking transaction edges per use case (matching proving → verifiable; scattering → returned).

**Modern guidance** — the matching lines per use case (review-enforced): *transaction scoping* (work atomizing — units bounding (partials declining — corruption ending (scoping proving — hoping ending (atomicity owning — fragments declining); *use case owning* (intent defining — flows proving (boundaries stating — edges translating (owning funding — spanning declining (app service opening — use case running); *partials declining* (all committing — none lingering (wholeness owning — breakage declining (declining proving — stranding preventing (discipline owning — reliability earning). ```typescript
// GOOD: boundaries matching — staged writes committing whole, failing steps rolling back (compiled + run live).
class StagedStore { // fake runner — staging owning, cores ignorant
  committed: number[] = [];
  private staged: number[] = [];
  private open = false;
  begin(): void { this.open = true; this.staged = []; }
  stage(n: number): void {
    if (!this.open) throw new Error('no transaction');
    if (n <= 0) throw new Error('invalid entry'); // failing step — partials declining, corruption ending
    this.staged.push(n);
  }
  commit(): void { this.committed.push(...this.staged); this.open = false; }
  rollback(): void { this.staged = []; this.open = false; }
}
function execute(staged: number[], store: StagedStore): string { // use-case boundary — one execution, one transaction
  store.begin();
  try {
    for (const n of staged) store.stage(n);
    store.commit();
    return 'committed';
  } catch {
    store.rollback();
    return 'rolled-back';
  }
}
const okStore = new StagedStore();
const ok = execute([10, 20], okStore);
const badStore = new StagedStore();
const bad = execute([10, -5], badStore); // failing step — halves refusing, stranding preventing
console.log(ok === 'committed' && okStore.committed.join(',') === '10,20' && bad === 'rolled-back' && badStore.committed.length === 0 ? 'boundaries match' : 'partials strand');
```

## 2. Unit-of-work porting (needs declaring — runners implementing — cores ignorant)

**Definition** — unit-of-work port: transactional needs declared as a consumer-owned interface (needs declaring — begin stating (commits promising — rollbacks requiring (declaring funding — dictating ending); runners implementing — real drivers plugging behind (details serving — cores ignoring (implementing proving — owning declining); cores ignorant — use cases importing the port, never the driver (direction holding — leverage keeping (ignorance proving — heaviness declining).

**What problem it solves** — the concrete-runner trio: *drivers importing* (DataSource drilling — managers threading (vendors owning — policy obeying (importing billing — leverage inverting); *tests databasing* (suites booting — runners opening (feedback dying — flakes growing (heavying costing — confidence eroding); *isolation unproven* (halves untested — rollbacks unasserted (behavior hoping — atomicity bluffing (unproven charging — corruption scheduling). Ported units converting concrete to needs (begin stating — commits promising (consumers owning — drivers obeying); reviewers injecting fake runners per test (porting proving → verifiable; importing → returned).

**Modern guidance** — the porting lines per unit of work (review-enforced): *needs declaring* (begin stating — commits promising (rollbacks requiring — consumers owning (declaring funding — dictating ending (shapes bounding — details deferring); *runners implementing* (drivers plugging — details serving (cores ignoring — suites substituting (implementing proving — owning declining (plugging funding — swapping earning); *cores ignorant* (ports importing — drivers unheard (direction holding — leverage keeping (ignorance proving — heaviness declining (purity owning — creeping ending). Scale discipline (pools sizing — isolation choosing) is owned in [ORM 06/1.2](<../../../../ORM/06 Production ORM Use/sections/1. Connections and transactions/1.2. // GOOD: needs ported — fake runner proving commit and rollback, core ignorant (compiled + run live).
interface UnitOfWork { // port owned inward — transactional needs declaring, drivers obeying
  begin(): void;
  commit(): void;
  rollback(): void;
  readonly log: string[];
}
class FakeWork implements UnitOfWork { // fake sliding — runners faking, suites headlessing
  readonly log: string[] = [];
  begin(): void { this.log.push('begin'); }
  commit(): void { this.log.push('commit'); }
  rollback(): void { this.log.push('rollback'); }
}
function transfer(uow: UnitOfWork, fail: boolean): string { // core ignorant — port importing, drivers unheard
  uow.begin();
  if (fail) { uow.rollback(); return 'rolled-back'; }
  uow.commit();
  return 'committed';
}
const a = new FakeWork();
const b = new FakeWork();
const ra = transfer(a, false);
const rb = transfer(b, true);
console.log(ra === 'committed' && a.log.join(',') === 'begin,commit' && rb === 'rolled-back' && b.log.join(',') === 'begin,rollback' ? 'ports carry work' : 'core imports drivers');
```

## 3. Rollback judging (failures atomicing — compensations sequencing — contexts deciding)

**Definition** — rollback judgment: choosing atomic rollback versus compensating saga per flow context (failures atomicing — single-writer unwinding (units scoping — partials declining (atomic proving — stranding ending); compensations sequencing — multi-party inverses staging (flows unwinding — consistency earning (sequencing funding — lockstep declining); contexts deciding — writer-count judging (one owning rollback — many owning saga (judging proving — defaulting declining).

**What problem it solves** — the one-mechanism trio: *rollback stretching* (distributed hoping — parties unbinding (atomicity bluffing — consistency breaking (stretching billing — stranding scheduling); *2PC defaulting* (lockstep coordinating — availability taxing (participants blocking — latency multiplying (defaulting charging — judgment missing); *compensation missing* (failures stranding — inverses unnamed (unwinding absenting — consistency hoping (missing costing — trust eroding). Judged failures converting defaulting to context (single atomicing — many compensating (writers counting — mechanisms matching); reviewers naming the writer count per flow (judging proving → verifiable; defaulting → returned).

**Modern guidance** — the judging lines per flow (review-enforced): *failures atomicing* (single-writer unwinding — units scoping (partials declining — corruption ending (atomic proving — stranding ending (rollback owning — simplicity funding); *compensations sequencing* (multi-party inverses staging — flows unwinding (consistency earning — lockstep declining (sequencing funding — availability keeping); *contexts deciding* (writer-count judging — mechanisms matching (judging proving — defaulting declining (context owning — dogma refusing). ```typescript
// GOOD: failures judged — writer-count routing rollback versus compensation (compiled + run live).
type Strategy = 'rollback' | 'compensate';
function judge(writers: number): Strategy { // context deciding — writer-count judging, defaulting declining
  if (writers <= 1) return 'rollback'; // failures atomicing — single-writer unwinding, simplicity funding
  return 'compensate'; // compensations sequencing — multi-party inverses staging, availability keeping
}
const single = judge(1);
const multi = judge(3);
