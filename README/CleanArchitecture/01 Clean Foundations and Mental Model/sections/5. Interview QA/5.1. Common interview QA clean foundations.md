# 5.1. Common interview QA clean foundations

## 1. Foundations live under pressure (layers, rule, slices — diagnosed with fixes, priced)

**Definition** — foundation answers: layers placed, rule stated, slices cut — under pressure (diagnosed with fixes — causes naming (understanding proving — reciting declining); priced with trade-offs — costs itemizing (judgment owning — dogma refusing (pricing funding — honesty earning).

**What problem it solves** — the reciting trio: *layers listing* (names stating — jobs missing (vocabulary showing — ownership absenting (reciting funding — designing declining); *rules quoting* ("dependencies point inward" chanting — violations unrecognized (words owning — arrows missing (quoting proving — enforcing declining); *slices handwaving* ("vertical" claiming — folders kinded (labels stating — structures contradicting (handwaving charging — evidence absenting). Diagnosed answers converting reciting to designing (causes naming — fixes stating (understanding proving — chanting declining); interviewers hiring designers, not chanters (diagnosing proving → hirable; reciting → passed).

**Modern guidance** — answer shape per foundation question (diagnose → fix → price):

```typescript
// GOOD: "Where does business logic live?" — diagnosed with fixes, priced (answer shape).
// Diagnose: logic scattering (controllers deciding — SQL computing — frontend discounting (ownership missing — changes rippling).
// Fix: entities deciding (invariants guarding — transitions checking); use cases orchestrating (ports calling — flows composing).
// Price: one class per intent (ownership proving — hunts ending); ports billing interfaces (direction holding — swaps earning).
// Own policy; defer details — direction stated, not hoped.)
```

```typescript
// BAD: foundations reciting — names stating, jobs missing (real weak shape).
// "Entities, use cases, controllers, frameworks." (jobs missing — ownership absenting — designing declining).
// "Dependencies point inward." (violations unrecognized — arrows missing — enforcing declining).
// Diagnose causes; state fixes; price honestly.)
```

**Common confusion** — *"interview answers need jargon (vocabulary impressing)."* Jargon labeling concepts (names stating — structures contradicting (labeling serving — understanding absenting (impressing hoping — hiring declining); answers proving judgment (causes naming — fixes stating (costs pricing — trade-offs owning (proving funding — reciting declining). "Jargon" describing vocabulary (words owning — arrows missing); answers describing design (ownership stating — prices itemizing). Diagnose causes (understanding proving — chanting declining); price fixes (judgment owning — dogma refusing).

**Performance note** — answer economics: diagnosing costing one cause per question (understanding proving — reciting declining (hirable funding — chanting ending); recited equivalents costing offers (words owning — arrows missing (designing declining — hiring passing). Diagnose cheaply (causes — fixes); recite never (jargon — passes).

**Mentor note** — drill "diagnose, fix, price" (juniors answering one question per shape design hirable responses on first hearing; jargon-only answers interrogated ("which cause?" — diagnosing demanding per answer). Shape one answer once (causes naming — fixes stating tangible (reciting ending — designing proving permanently). Diagnose causes; price fixes — answering discipline in three habits, reviewed per mock.

## 2. Trade-offs live under pressure (costs, sizes, timings — honesty stated, not hoped)

**Definition** — trade-off answers: costs billed, sizes weighed, timings named — honestly (honesty stating — context weighing (judgment owning — dogma refusing (stating funding — hoping ending); sizes timing (CRUD declining — growth affording (context deciding — ceremony billing (weighing proving — preaching declining).

**What problem it solves** — the always-trio: *"always layer" preaching* (sizes dismissing — ceremony billing (dogma owning — honesty absenting (preaching charging — judgment missing); *costs hiding* (files uncounted — comprehension untaxed (bills hiding — value unproven (hiding billing — ceremony growing); *timings ignoring* ("later" promising — erosion scheduling (deferral hoping — big-balling arriving (ignoring charging — rewrites looming). Honest answers converting preaching to pricing (bills itemizing — swaps naming (context deciding — dogma refusing); interviewers hiring judgers, not preachers (pricing proving → hirable; preaching → passed).

**Modern guidance** — answer shape per trade-off question (bill → weigh → time):

```typescript
// GOOD: "When is clean architecture overkill?" — billed, weighed, timed (answer shape).
// Bill: 5 files per intent (entity + port + use case + adapter + controller — indirection honest).
// Weigh: solo CRUD declining (simplicity funding — velocity keeping); second swap affording (tests demanding — direction paying).
// Time: seams at growth (features multiplying — swaps arriving); gates from day one (graphs asserting — erosion detecting).
// Price honestly; layer conditionally — judgment stated, not hoped.)
```

```typescript
// BAD: trade-offs preaching — always layering, costs hiding (real dogmatic shape).
// "Always use clean architecture." (sizes dismissing — ceremony billing — judgment missing).
// "Ports for everything." (files uncounted — comprehension untaxed — value unproven).
// Bill honestly; weigh context; time seams.)
```

**Common confusion** — *"honesty means no opinion (neutrality performing)."* Honesty pricing options (bills itemizing — swaps naming (context weighing — judgment owning (pricing funding — dogma refusing); opinions deciding bets (defaults stating — reversals naming (conviction serving — waffling declining (deciding proving — performing declining). "No opinion" describing abdication (judgment missing — hiring passing); honesty describing priced conviction (options billing — bets stating). Price options (bills itemizing — context weighing); state bets (defaults stating — reversals naming).

**Performance note** — honesty economics: pricing costing one bill per option (judgment owning — dogma refusing (hirable funding — preaching ending); preached equivalents costing credibility (sizes dismissing — ceremony billing (judgment missing — hiring passing). Price cheaply (bills — swaps); preach never (dogma — passes).

**Mentor note** — drill "bill every abstraction" (juniors pricing one port per answer design honestly-judged responses on first hearing; always-answers interrogated ("for which size?" — weighing demanding per claim). Bill one option once (indirection honest — swaps naming tangible (preaching ending — judgment proving permanently). Itemize bills; name swaps — pricing discipline in three habits, reviewed per mock.

## 3. Modeling live under pressure (entities, DTOs, use cases — ownership stated, not hoped)

**Definition** — modeling answers: entities guarding, DTOs carrying, use cases orchestrating — ownership stated (jobs homing — axes separating (ownership proving — mixing declining); not hoped (tests asserting — throws proving (evidence funding — wishing ending (stating serving — hoping declining).

**What problem it solves** — the merging trio: *models merging* ("same shape" claiming — purposes differing (jobs blurring — layers leaking (merging charging — ownership missing); *anemia defending* ("services decide" insisting — objects declining (scripting billing — envy growing (defending costing — cohesion fading); *ports handwaving* ("abstractions" gesturing — consumers unnamed (needs unstated — sizes unbounded (handwaving charging — evidence absenting). Owned answers converting merging to homing (rules living — shapes carrying (flows orchestrating (ownership proving — blurring declining); interviewers hiring owners, not mergers (homing proving → hirable; merging → passed).

**Modern guidance** — answer shape per modeling question (own → prove → bound):

```typescript
// GOOD: "Anemic model or rich entity?" — owned, proven, bounded (answer shape).
// Own: rules living with data (transitions checking — guards throwing — validity holding).
// Prove: invalid unbuildable (construction throwing — tests asserting throws — corruption unborn).
// Bound: services arranging flows (intents orchestrating — ports calling — entities deciding).
// Home behavior; arrange flows — ownership stated, not hoped.)
```

```typescript
// BAD: modeling merging — same-shaping, services-deciding (real muddled shape).
// "DTOs and entities are the same." (purposes differing — layers leaking — ownership missing).
// "Services hold the logic." (objects declining — envy growing — cohesion fading).
// Own jobs; prove guards; bound flows.)
```

**Common confusion** — *"modeling questions test memory (definitions recalling)."* Memory stating vocabulary (names reciting — jobs missing (reciting funding — designing declining (memory serving — hiring passing); modeling proving ownership (jobs homing — guards throwing (flows orchestrating — evidence showing (proving funding — merging declining). "Memory" describing recall (words owning — arrows missing); modeling describing placement (rules homing — validity holding). Place jobs (ownership proving — blurring declining); recall never (jargon — passes).

**Performance note** — modeling economics: owning costing one home per rule (validity holding — cohesion funding (ownership proving — blurring declining); merged equivalents costing drift (callers rechecking — guards reimplementing (ownership missing — consistency failing). Home cheaply (models — rules); merge never (shapes — drift).

**Mentor note** — drill "whose job?" (juniors homing one rule per answer design ownership-stated responses on first hearing; merged models interrogated ("which job?" — homing demanding per object). Home one rule once (guards throwing — flows orchestrating tangible (merging ending — ownership proving permanently). State owners; show guards — modeling discipline in three habits, reviewed per mock.
