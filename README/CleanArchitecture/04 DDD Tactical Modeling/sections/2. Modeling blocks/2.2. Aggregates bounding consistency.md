**Modern guidance** — the guarding lines per aggregate (review-enforced): *invariants owning* (rules spanning — spans guarding (breaches refusing — bypassing declining (owning proving — scattering ending (roots ruling — homelessness ending); *entries funneling* (changes passing — children hiding (callers routing — grabbing ending (funneling funding — reaching declining (doors owning — windows closing); *writes atomizing* (units committing — halves refusing (corruption ending — stranding declining (atomizing owning — splitting refusing (wholes proving — parts declining).

```typescript
    return this.lines.reduce((a, l) => a + l.qty * l.price, 0);

}

order.addLine('book-b', 1, 5);
const peeked = order.linesCopy();
```

## 3. Repositories serving (aggregates persisting — roots loading — rules keeping)

**Definition** — aggregate repository: collection-like persistence per root, wholes loading and saving (aggregates persisting — units storing (roots owning — parts declining (persisting funding — splitting ending); roots loading — wholes fetching (children joining — graphs assembling (loading proving — reaching declining); rules keeping — invariants surviving (round-trips guarding — corruption refusing (keeping owning — breaking declining).

**Modern guidance** — the serving lines per aggregate (review-enforced): *aggregates persisting* (units storing — roots owning (parts declining — splitting ending (persisting funding — scattering declining (wholes proving — halves refusing); *roots loading* (wholes fetching — children joining (graphs assembling — reaching declining (loading proving — lazing ending (eager owning — N+1 refusing); *rules keeping* (invariants surviving — round-trips guarding (corruption refusing — breaking declining (keeping funding — hoping ending (guards owning — trust earning).
```typescript
// GOOD: repositories serving — wholes saving and loading, invariants surviving (compiled + run live).
class Order { // root owning — invariants spanning, entries funneling
  private lines: Array<{ sku: string; qty: number }> = [];
  constructor(readonly id: string) {}
  addLine(sku: string, qty: number): void {
    if (qty <= 0) throw new Error('qty positive required');
    this.lines.push({ sku, qty });
  }
  count(): number { return this.lines.reduce((a, l) => a + l.qty, 0); }
  snapshot(): { id: string; lines: Array<{ sku: string; qty: number }> } {
    return { id: this.id, lines: this.lines.map((l) => ({ ...l })) };
  }
  static restore(s: { id: string; lines: Array<{ sku: string; qty: number }> }): Order {
    const o = new Order(s.id);
    for (const l of s.lines) o.addLine(l.sku, l.qty); // round-trips guarding — corruption refusing, rules keeping
    return o;
  }
}
class OrderRepo { // repository serving — wholes storing, roots owning
  private readonly rows = new Map<string, { id: string; lines: Array<{ sku: string; qty: number }> }>();
  save(order: Order): void { this.rows.set(order.id, order.snapshot()); }
  load(id: string): Order {
    const s = this.rows.get(id);
    if (s === undefined) throw new Error('order missing');
    return Order.restore(s); // roots loading — wholes fetching, reaching declining
  }
}
const repo = new OrderRepo();
const order = new Order('o7');
order.addLine('book-a', 2);
repo.save(order);
const reloaded = repo.load('o7');
reloaded.addLine('book-b', 1);
console.log(reloaded.count() === 3 ? 'repositories serve' : 'repos multiply');
```
