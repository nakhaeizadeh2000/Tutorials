# 4.1. Modeling checklist mentors insist on

## 1. Every term ubiquitousing (language sharing — contexts bounding — maps drawing)

**Definition** — the language gate: each domain term shared with experts, bounded per context, mapped per relation (language sharing — experts naming (code echoing — models speaking (sharing proving — jargoning declining); contexts bounding — meanings scoping (terms translating — conflicts declining (bounding owning — merging breaking); maps drawing — relations naming (owners assigning — sameness declining (drawing funding — assuming ending).

**What problem it solves** — the unshared trio: *terms jargoning* (tech colonizing — experts translating (understanding declining — decisions wobbling (jargoning billing — rigor missing); *meanings merging* (terms colliding — models compromising (precision dying — conflicts hiding (merging charging — clarity declining); *relations assuming* (sameness hoping — translations unowned (corruption arriving — cascades scheduling (assuming costing — autonomy dying). The gate converting jargon to sharing (experts naming — contexts bounding (maps drawing — models speaking); mentors asking one question per term ("what does the expert call it?" — sharing demanding per class).

**Modern guidance** — the gate commands (run per term, enforced in review):

```typescript
// GOOD: language gated — terms sharing, contexts bounding, maps drawing (checklist shape).
// 1. Term proof (experts naming — code echoing):
//    every domain class named from expert vocabulary — tech synonyms rejected, renames welcomed.
// 2. Context proof (meanings scoping — conflicts declining):
//    every term owning one meaning per bounded context — collisions split, translations explicit.
// 3. Relation proof (pairs naming — owners assigning):
//    every context pair naming its relation — ACLs at edges, sameness never assumed.
// Share terms; bound contexts; draw maps.)
```

```typescript
// BAD: terms unshared — jargon colonizing, meanings merging (real unshared shape).
// class DataManager { /* ... */ } // tech owning — experts translating, understanding declining.
// // One global Account (rules conflicting — precision dying). Share language; bound meanings; map relations.)
```

**Common confusion** — *"gates police vocabulary (language policing)."* Gates evidencing rigor (experts naming — code echoing (proof reusing — judgment focusing (evidencing funding — slowing declining); policing punishing words (style enforcing — meaning ignoring (punishing serving — value missing (policing charging — morale declining). "Policing" describing punishment (words enforcing — meaning ignoring); gates describing evidence (rigor proving — models speaking). Evidence rigor (terms sharing — models speaking); punish never (style enforcing — morale declining).

**Performance note** — language economics: gating costing seconds per term (experts naming — code echoing (meetings aligning — translating declining); unshared equivalents costing misalignment (experts translating — developers guessing (understanding declining — decisions wobbling). Gate cheaply (seconds — terms); jargon never (tech — translation).

**Mentor note** — demand "expert word in the name" (juniors echoing one term per model design rigor-carrying reviews on first hearing; tech-named models interrogated ("expert word?" — sharing demanding per class). Share one term once (experts naming — models speaking tangible (jargoning ending — rigor proving permanently). Name from experts; bound per context — language discipline in three habits, reviewed per term.

## 2. Every aggregate rooting (invariants owning — entries funneling — writes atomizing)

**Definition** — the rooting gate: each consistency span owned by one root, entries funneled, writes atomic (invariants owning — spans guarding (breaches refusing — bypassing declining (owning proving — scattering ending); entries funneling — changes passing (children hiding — callers routing (funneling funding — grabbing ending); writes atomizing — units committing (halves refusing — corruption ending (atomizing owning — splitting refusing).

**What problem it solves** — the unrooted trio: *invariants homeless* (rules scattering — spans unowned (ownership missing — drift growing (homeless charging — consistency failing); *children grabbing* (callers reaching — guards bypassing (invariants breaking — trust eroding (grabbing billing — funneling missing); *aggregates bloating* (graphs loading — locks contending (throughput dying — scaling failing (bloating charging — thought missing). The gate converting homeless to owned (roots ruling — entries funneling (writes atomizing — breaches refusing); mentors asking one question per cluster ("which root, which span?" — rooting demanding per aggregate).

**Modern guidance** — the gate commands (run per aggregate, enforced in review):

```typescript
// GOOD: rooting gated — invariants owning, entries funneling, writes atomizing (checklist shape).
// 1. Span proof (rules spanning — breaches refusing):
//    every invariant owned inside exactly one aggregate — cross-span rules routed to sagas, never widened.
// 2. Entry proof (changes passing — children hiding):
//    all mutations behind root methods — child-reaching code returned, copies shared for reads.
// 3. Size proof (spans bounding — references keying):
//    aggregates small by span — cross-aggregate links by id, object graphs pruned, contention measured.
// Own spans; funnel entries; atomize writes.)
```

```typescript
// BAD: aggregates unrooted — invariants homeless, children grabbing (real unrooted shape).
// order.lines.push({...}); // callers reaching — guards bypassing, invariants breaking.
// class Order { customer: Customer; /* ... */ } // objects linking — contention growing, scaling failing.
// } // Gate rooting: spans owning, entries funneling, writes atomizing.)
```

**Common confusion** — *"gates slow modeling (process dragging)."* Gates preventing corruption (spans owning — breaches refusing (incidents declining — trust earning (preventing funding — dragging declining); missing gates slowing recovery (invariants breaking — cleanups paging (incidents multiplying — velocity dying (missing charging — modeling declining). "Slowing" describing ceremony (meetings multiplying — value missing); gates describing leverage (proof reusing — corruption preventing). Gate spans (invariants owning — trust earning); model faster (incidents declining — velocity funding).

**Performance note** — rooting economics: gating costing one span decision (rules spanning — breaches refusing (trust earning — incidents declining); unrooted equivalents costing corruption (callers reaching — guards bypassing (invariants breaking — trust eroding). Gate cheaply (spans — roots); grab never (children — reaches).

**Mentor note** — demand "span and root stated" (juniors owning one span per root design corruption-proof reviews on first hearing; rootless clusters interrogated ("which invariant?" — rooting demanding per cluster). Own one span once (rules spanning — entries funneling tangible (homeless ending — rooting proving permanently). Span invariants; funnel mutations — rooting discipline in three habits, reviewed per aggregate.

## 3. Every change eventing (facts naming — roots emitting — versions evolving)

**Definition** — the eventing gate: each state change named as a past-tense fact, emitted by roots, evolved additively (facts naming — verbs passing (histories keeping — commanding declining (naming proving — ordering refusing); roots emitting — changes announcing (commits dispatching — brokers edging (emitting owning — importing declining); versions evolving — fields adding (consumers tolerating — contracts keeping (evolving funding — breaking declining).

**What problem it solves** — the unevented trio: *changes silenting* (moves vanishing — audits guessing (histories missing — disputes losing (silenting billing — truth declining); *brokers entitying* (SDKs arriving — vendors owning (ignorance breaking — heaviness billing (entitying charging — policy obeying); *facts breaking* (fields renaming — consumers crashing (replays failing — history breaking (breaking charging — auditing declining). The gate converting silence to facts (changes naming — roots emitting (versions evolving — histories keeping); mentors asking one question per change ("which event?" — eventing demanding per mutation).

**Modern guidance** — the gate commands (run per change, enforced in review):

```typescript
// GOOD: eventing gated — facts naming, roots emitting, versions evolving (checklist shape).
// 1. Naming proof (verbs passing — histories keeping):
//    every state change publishing a past-tense business fact — timestamped, immutable, expert-worded.
// 2. Emission proof (changes announcing — commits dispatching):
//    roots collecting, infrastructure dispatching at commit — zero broker imports in aggregates, ever.
// 3. Evolution proof (fields adding — consumers tolerating):
//    events additive with upcasters — renames versioned, old shapes readable, consumers N/N-1.
// Name facts; emit from roots; evolve additive.)
```

```typescript
// BAD: changes unevented — silence keeping, brokers entitying (real unevented shape).
// // State mutating with no event (moves vanishing — audits guessing — disputes losing).
// import { broker } from '../infra/bus'; // inside the entity — vendors owning, ignorance breaking.
// } // Gate eventing: facts naming, roots emitting, versions evolving.)
```

**Common confusion** — *"gates replace domain thinking (checks substituting)."* Gates evidencing discipline (facts naming — roots emitting (proof reusing — judgment focusing (evidencing funding — slowing declining); thinking owning models (spans bounding — invariants guarding (understanding proving — designing funding (thinking serving — checking declining). "Replacing" describing substitution (models skipping — understanding missing); gates describing evidence (discipline proving — trust earning). Think in models (spans owning — invariants guarding); evidence with gates (facts naming — runs asserting).

**Performance note** — eventing economics: gating costing one fact (verbs passing — histories keeping (audits owning — disputes winning); unevented equivalents costing disputes (moves vanishing — audits guessing (truth declining — trust eroding). Gate cheaply (facts — events); silence never (changes — disputes).

**Mentor note** — demand "event per change" (juniors naming one fact per mutation design audit-proof reviews on first hearing; silent mutations interrogated ("which fact?" — eventing demanding per change). Name one change once (verbs passing — roots emitting tangible (silence ending — auditing proving permanently). State facts; evolve additive — eventing discipline in three habits, reviewed per change.
