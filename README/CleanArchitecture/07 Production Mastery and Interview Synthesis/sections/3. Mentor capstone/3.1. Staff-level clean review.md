# 3.1. Staff-level clean review

## 1. Reviews traversing (layers walking — wholes judging — samples refusing)

**Definition** — traversal review: staff walking every layer, edge, and evidence before judging (layers walking — rings visiting (policy reading — vendors checking (walking proving — sampling declining); wholes judging — features owning (systems deciding — parts refusing (judging funding — skimming ending); samples refusing — spot-checks declining (coverage demanding — gaps flagging (refusing owning — hoping ending).

**What problem it solves** — the sampled trio: *reviews sampling* (files skimming — layers skipping (coverage hoping — gaps hiding (sampling billing — judgment bluffing); *edges unvisited* (vendors unchecked — boundaries unproven (risks missing — leaks landing (unvisited charging — trust eroding); *wholes unjudged* (parts approving — systems assuming (integration hoping — failures surfacing (unjudged costing — confidence bluffing). Traversing reviews converting sampling to walking (layers visiting — wholes owning (samples refusing — gaps flagging); mentees watching full traversals per review (traversing proving → verifiable; sampling → returned).

**Modern guidance** — the traversing lines per review (review-enforced): *layers walking* (rings visiting — policy reading (vendors checking — sampling declining (walking proving — skimming ending (traversal owning — faith refusing); *wholes judging* (features owning — systems deciding (parts refusing — skimming ending (judging funding — sampling declining (ownership earning — hope ending); *samples refusing* (spot-checks declining — coverage demanding (gaps flagging — hoping ending (refusing owning — bluffing declining (rigor funding — laziness ending).

```typescript
// GOOD: reviews traversing — layer coverage proving wholes, gaps flagged (compiled + run live).
type Ring = 'entities' | 'usecases' | 'ports' | 'adapters' | 'edges' | 'evidence';
function traversed(visited: Ring[]): boolean {
  const all: Ring[] = ['entities', 'usecases', 'ports', 'adapters', 'edges', 'evidence']; // layers walking — rings visiting, sampling declining
  return all.every((r) => visited.includes(r)); // wholes judging — features owning, skimming ending
}
const full: Ring[] = ['entities', 'usecases', 'ports', 'adapters', 'edges', 'evidence'];
const gapped: Ring[] = ['entities', 'usecases', 'edges'];
console.log(traversed(full) && !traversed(gapped) ? 'reviews traverse' : 'samples judge');
```

```typescript
// BAD: reviews sampling — files skimming, edges unvisited (real sample shape).
// // LGTM after reading the controller (layers skipping — coverage hoping — gaps hiding).
// // Vendors unchecked (risks missing — leaks landing). Walk layers; judge wholes; refuse samples.)
```

**Common confusion** — *"traversal means line-by-line (reads exhausting)."* Traversal visiting layers (rings checking — edges proving (wholes owning — gaps flagging (visiting funding — sampling declining); line-reading exhausting attention (files drowning — judgment tiring (focus scattering — value missing (exhausting charging — thoroughness bluffing). "Line-by-line" describing exhaustion (attention drowning — value missing); traversal describing coverage (layers visiting — wholes judging). Visit layers (rings checking — gaps flagging); sample never (spot-checks declining — hope ending).

**Performance note** — traversing economics: walking costing one traversal (rings visiting — wholes owning (gaps flagging — hope ending); sampled equivalents costing gaps (layers skipping — coverage hoping (risks missing — trust eroding). Walk cheaply (layers — traversals); sample never (spots — gaps).

**Mentor note** — teach "walk before you judge" (juniors traversing one full stack per review design sample-proof judgment on first hearing; LGTM-without-traversal interrogated ("which layers?" — traversing demanding per approval). Walk one system once (layers visiting — wholes judging tangible (sampling ending — rigor proving permanently). Visit rings; flag gaps — traversing discipline in three habits, reviewed per approval.

## 2. Ledgers pricing (choices windowing — debts totaling — paydowns sequencing)

**Definition** — ledger pricing: reviews totaling decision prices plus debt exposure with paydown plans (choices windowing — options stating (reversals naming — vibes declining (windowing proving — feeling refusing); debts totaling — costs summing (owners naming — balances stating (totaling funding — hiding ending); paydowns sequencing — dates committing (sprints allocating — balances shrinking (sequencing owning — forever declining).

**What problem it solves** — the unpriced trio: *approvals unpricing* (merges landing — costs unstated (prices missing — reversals unowned (unpricing billing — judgment bluffing); *debts blinding* (ledgers absenting — exposures unknown (balances hiding — surprises scheduling (blinding charging — accountability declining); *paydowns missing* (dates uncommitted — sprints unallocated (balances growing — bankruptcies arriving (missing costing — velocity dying). Priced ledgers converting unpricing to totaling (choices stating — debts summing (paydowns committing — surprises declining); reviewers approving with numbers per merge (pricing proving → verifiable; unpricing → returned).

**Modern guidance** — the ledgering lines per review (review-enforced): *choices windowing* (options stating — reversals naming (vibes declining — feeling refusing (windowing proving — bluffing declining (options owning — impulses declining); *debts totaling* (costs summing — owners naming (balances stating — hiding ending (totaling funding — blinding refusing (numbers owning — dread ending); *paydowns sequencing* (dates committing — sprints allocating (balances shrinking — forever declining (sequencing owning — postponing refusing (calendars funding — bankruptcy declining).

```typescript
// GOOD: ledgers pricing — review verdicts computed from priced choices and debt (compiled + run live).
interface Priced { // choices windowing — options stating, vibes declining
  choice: string;
  cost: number;
}
function verdict(prices: Priced[], debtDays: number, ownerNamed: boolean): string {
  const total = prices.reduce((a, p) => a + p.cost, 0) + debtDays; // debts totaling — costs summing, hiding ending
  if (!ownerNamed) return 'hold';
  if (total <= 8) return 'approve';
  return 'approve-with-paydown'; // paydowns sequencing — dates committing, forever declining
}
const v1 = verdict([{ choice: 'cache', cost: 2 }], 3, true);
const v2 = verdict([{ choice: 'rewrite', cost: 9 }], 6, true);
const v3 = verdict([{ choice: 'cache', cost: 2 }], 3, false);
console.log(v1 === 'approve' && v2 === 'approve-with-paydown' && v3 === 'hold' ? 'ledgers price' : 'approvals blind');
```

```typescript
// BAD: approvals unpricing — merges landing, debts blinding (real unpriced shape).
// // LGTM (costs unstated — reversals unowned — judgment bluffing).
// // No debt total (balances hiding — surprises scheduling). Window choices; total debts; sequence paydowns.)
```

**Common confusion** — *"pricing blocks pragmatism (numbers obstructing)."* Pricing informing trade-offs (options stating — debts summing (judgment funding — surprises declining (informing proving — bluffing declining); obstructing vetoing value (numbers weaponizing — ships blocking (process taxing — momentum dying (obstructing charging — pragmatism declining). "Blocking" describing veto (ships blocking — value missing); pricing describing information (choices stating — debts totaling). Inform trade-offs (options stating — debts summing); veto rarely (evidence demanding — ships funding).

**Performance note** — ledger economics: totaling costing sums (choices stating — debts summing (surprises declining — hiding ending); unpriced equivalents costing surprises (costs unstated — balances hiding (judgment bluffing — trust eroding). Total cheaply (sums — ledgers); blind never (approvals — prices).

**Mentor note** — demand "priced approval" (juniors totaling one ledger per review design blind-proof merges on first hearing; unpriced LGTMs interrogated ("total cost?" — pricing demanding per approval). Price one review once (choices stating — debts summing tangible (unpricing ending — pricing proving permanently). Window choices; total debts — pricing discipline in three habits, reviewed per merge.

## 3. Mentors multiplying (checklists teaching — drills coaching — mastery compounding)

**Definition** — mentor multiplication: reviews teaching through checklists and drills, compounding team mastery (checklists teaching — items explaining (juniors growing — knowledge spreading (teaching proving — hoarding declining); drills coaching — scenarios running (recoveries timing — confidence building (coaching funding — telling declining); mastery compounding — lessons accumulating (grades passing — radii growing (compounding owning — stagnating declining).

**What problem it solves** — the gatekeeping trio: *reviews gatekeeping* (approvals wielding — knowledge hoarding (power owning — growth blocking (gatekeeping billing — mastery declining); *comments nitpicking* (styles policing — meanings ignoring (trivia owning — value missing (nitpicking charging — morale declining); *lessons evaporating* (insights unrecorded — drills unassigned (wisdom vanishing — repeats scheduling (evaporating costing — compounding declining). Multiplying mentors converting gatekeeping to teaching (checklists explaining — drills coaching (mastery compounding — hoarding declining); mentees growing per review (multiplying proving → verifiable; gatekeeping → returned).

**Modern guidance** — the multiplying lines per review (review-enforced): *checklists teaching* (items explaining — juniors growing (knowledge spreading — hoarding declining (teaching proving — wielding refusing (lessons owning — power declining); *drills coaching* (scenarios running — recoveries timing (confidence building — telling declining (coaching funding — lecturing ending (practice owning — theory declining); *mastery compounding* (lessons accumulating — grades passing (radii growing — stagnating declining (compounding owning — evaporating refusing (growth funding — plateau declining).

```typescript
// GOOD: mentors multiplying — review comments mapped to teaching artifacts (compiled + run live).
interface Note { // checklists teaching — items explaining, hoarding declining
  comment: string;
  teaches: boolean;
  drill: boolean;
}
function growth(notes: Note[]): number {
  const taught = notes.filter((n) => n.teaches).length;
  const drilled = notes.filter((n) => n.drill).length; // drills coaching — scenarios running, telling declining
  return taught * 2 + drilled * 3; // mastery compounding — lessons accumulating, stagnating declining
}
const review: Note[] = [
  { comment: 'arrow outward', teaches: true, drill: false },
  { comment: 'add contract suite', teaches: true, drill: true },
  { comment: 'nit: spacing', teaches: false, drill: false },
];
console.log(growth(review) === 7 ? 'mentors multiply' : 'reviews gatekeep');
```

```typescript
// BAD: reviews gatekeeping — approvals wielding, comments nitpicking (real gate shape).
// // "Fix spacing." x12, no teaching (trivia owning — value missing — morale declining).
// // Knowledge hoarding (power owning — growth blocking). Teach checklists; coach drills; compound mastery.)
```

**Common confusion** — *"teaching slows reviews (mentoring taxing)."* Teaching compounding mastery (lessons accumulating — juniors growing (knowledge spreading — hoarding declining (teaching funding — gatekeeping declining); taxing slowing ships (meetings owning — value missing (process charging — momentum dying (taxing serving — agility declining). "Taxing" describing process (meetings owning — value missing); teaching describing leverage (checklists explaining — mastery compounding). Teach in reviews (items explaining — juniors growing); tax never (meetings owning — value missing).

**Performance note** — multiplying economics: teaching costing explanations (items explaining — juniors growing (knowledge spreading — hoarding declining); gatekept equivalents costing growth (power owning — mastery declining (wisdom hoarding — repeats scheduling). Teach cheaply (checklists — comments); gatekeep never (approvals — power).

**Mentor note** — teach "every review grows someone" (seniors mapping one comment per checklist item design growth-owned reviews on first hearing; teachless approvals interrogated ("who grew?" — multiplying demanding per review). Multiply one mentee once (checklists teaching — drills coaching tangible (gatekeeping ending — mastery proving compounded permanently). Explain items; assign drills — multiplying discipline in three habits, reviewed per review.
