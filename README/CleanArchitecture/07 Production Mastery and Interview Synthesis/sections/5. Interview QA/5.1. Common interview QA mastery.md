# 5.1. Common interview QA mastery

## 1. Systems designing live (layers composing — failures gracing — judgment pricing)

**Definition** — system-design answers: layers composing, failures gracing, judgment pricing — live (composing proving — siloing declining (wholes owning — parts refusing (proving funding — sketching declining); gracing owning — fallbacks serving (degradation designing — outages surviving (gracing earning — crashing declining); pricing funding — choices windowing (trade-offs stating — vibes declining (pricing owning — hoping ending).

**What problem it solves** — the whiteboard trio: *boxes drawing* (rectangles naming — arrows hoping (pictures serving — boundaries unproven (drawing billing — designing declining); *failures ignoring* (happy-pathing — outages unmentioned (resilience assuming — incidents discovering (ignoring charging — robustness bluffing); *judgment missing* (options unstated — prices unowned (choices hoping — trade-offs hiding (missing costing — offers declining). Live-designed systems converting drawing to composing (layers walking — failures gracing (judgment pricing — hope ending); interviewers hiring composers, not drawers (composing proving → hirable; drawing → passed).

**Modern guidance** — answer shape per system question (compose → grace → price):

```typescript
// GOOD: "Design order placement." — composed, graced, priced (answer shape).
// Compose: policy deciding (entities guarding — use cases composing); edges translating (adapters shaping — vendors serving).
// Grace: failures scripting (fallbacks serving — rollbacks readying — MTTR stating).
// Price: choices windowing (options stating — reversals naming — vibes declining).
// Walk layers; script faults; price choices — mastery stated, not hoped.)
```

```typescript
// BAD: systems sketching — boxes drawing, failures ignoring (real whiteboard shape).
// // [ app ] → [ db ] (arrows hoping — boundaries unproven — designing declining).
// // No failures, no prices (resilience assuming — judgment missing). Compose layers; grace failures; price judgment.)
```

**Common confusion** — *"system answers need scale numbers (throughput impressing)."* Numbers grounding capacity (volumes stating — cliffs naming (budgets bounding — surprises declining (grounding funding — bluffing declining); answers proving architecture (layers composing — failures gracing (judgment pricing — hope ending (proving serving — drawing declining). "Numbers" describing capacity (volumes stating — cliffs naming); answers describing design (wholes owning — trade-offs stating). Ground capacity (numbers stating — cliffs naming); prove architecture (layers composing — judgment pricing).

**Performance note** — design economics: composing costing traversals (layers walking — wholes owning (gaps flagging — hope ending); drawn equivalents costing gaps (arrows hoping — boundaries unproven (failures surfacing — trust eroding). Compose cheaply (walks — layers); draw never (boxes — hope).

**Mentor note** — drill "compose, grace, price" (juniors answering one system question per shape design hirable responses on first hearing; box-only answers interrogated ("which failure?" — composing demanding per diagram). Shape one answer once (layers composing — failures gracing tangible (drawing ending — designing proving permanently). Walk wholes; state prices — system discipline in three habits, reviewed per mock.

## 2. Failures handling live (faults scripting — rollbacks readying — MTTR stating)

**Definition** — failure answers: faults scripting, rollbacks readying, MTTR stating — live (scripting proving — surprises declining (drills owning — hoping ending); readying owning — outs preserving (panics declining — stranding ending (readying funding — bluffing declining); stating funding — means timing (trends proving — progress showing (stating owning — guessing declining).

**What problem it solves** — the brave trio: *failures handwaving* ("resilient" claiming — faults unscripted (resilience assuming — paths untested (handwaving billing — robustness bluffing); *rollbacks hoping* (outs unready — reverts unrehearsed (recoveries praying — downtimes arriving (hoping charging — safety declining); *MTTR guessing* (means unmeasured — trends unknown (progress bluffing — improvement hoping (guessing costing — maturity declining). **Modern guidance** — answer shape per failure question (script → ready → state):

// Script: faults injecting (dependency killing — fallback asserting — recovery timing).
// Ready: rollbacks preserving (outs rehearsing — traffic bleeding — panics declining).

// BAD: failures braving — resilience claiming, rollbacks hoping (real brave shape).

**Common confusion** — *"failure answers test pessimism (gloom performing)."* Pessimism predicting doom (outages forecasting — ships halting (gloom serving — value missing (predicting charging — building declining); answers proving rehearsal (faults scripting — rollbacks readying (MTTR stating — surprises declining (proving funding — handwaving declining). **Performance note** — handling economics: scripting costing drills (faults injecting — rollbacks readying (MTTR stating — surprises declining); braved equivalents costing outages (failures arriving — paths untested (behaviors unknown — trust eroding). Script cheaply (drills — faults); brave never (claims — outages).

**Mentor note** — drill "script, ready, state" (juniors answering one failure question per shape design hirable responses on first hearing; resilient-claiming answers interrogated ("last drill?" — handling demanding per claim). Shape one answer once (faults scripting — rollbacks readying tangible (handwaving ending — handling proving permanently). **Definition** — judgment answers: prices stating, fashion declining, offers earning — live (stating proving — hiding declining (trade-offs owning — surprises declining (proving funding — bluffing declining); declining owning — slogans refusing (reasons demanding — herds resisting (declining earning — following ending); earning funding — offers arriving (hires funding — careers compounding (earning proving — passing declining).
