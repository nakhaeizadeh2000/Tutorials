# 1.1. Full-system clean design

## 1. Layers composing vertically (policy deciding — edges translating — details serving)

**Definition** — full-system composition: one feature owning every ring from entity to edge (policy deciding — rules guarding (flows composing — cores ruling (deciding proving — scattering ending); edges translating — adapters shaping (protocols converting — details plugging (translating serving — drilling declining); details serving — vendors obeying (products plugging — cores ignoring (serving funding — dictating ending).

**What problem it solves** — the siloed-design trio: *layers designing separately* (teams owning rings — features splitting (handoffs queuing — integration hoping (designing billing — ownership blurring); *integration lasting* (wires meeting at boot — failures surfacing late (causes hiding — confidence hoping (lasting charging — debugging guessing); *rings skipping* (shortcuts jumping — boundaries breaking (convenience charging — rewrites scheduling (skipping billing — discipline decaying). Composed layers converting silos to features (policy deciding — edges translating (details serving — integration earning-early); reviewers walking one feature top to bottom per design (composing proving → verifiable; siloing → returned).

**Modern guidance** — the composing lines per feature (review-enforced): *policy deciding* (rules guarding — flows composing (cores ruling — edges serving (deciding proving — scattering ending (ownership funding — drift preventing); *edges translating* (adapters shaping — protocols converting (details plugging — drilling declining (translating serving — ruling ending (shaping owning — leaking preventing); *details serving* (vendors obeying — products plugging (cores ignoring — dictating declining (serving funding — earlying ending (plugging earning — lock-in declining).

```typescript
// GOOD: layers composing — entity to edge in one Nest slice, inject proving (compiled + run live).
import 'reflect-metadata';
import { Controller, Get, Inject, Injectable, Module } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { FastifyAdapter } from '@nestjs/platform-fastify'; // Fastify underneath — adapter stated, Express declining

class Seat { // LAYER 1 entities — rules living, edges unknown
  constructor(readonly id: string, readonly held: boolean) {}
}

interface SeatStore { // LAYER 2 port — needs declaring, drivers obeying
  save(seat: Seat): void;
  count(): number;
}

@Injectable()
class HoldSeat { // LAYER 2 use cases — flows composing, cores ruling
  constructor(@Inject('SEAT_STORE') private readonly store: SeatStore) {} // token wiring — interfaces needing runtime names, direction holding
  execute(id: string): number {
    const seat = new Seat(id, true);
    this.store.save(seat);
    return this.store.count();
  }
}

@Injectable()
class MemorySeats implements SeatStore { // LAYER 3 adapters — details serving, cores ignoring
  private n = 0;
  save(_seat: Seat): void { this.n += 1; }
  count(): number { return this.n; }
}

@Controller('seats')
class SeatsController { // LAYER 3 edge — translating owning, deciding declining
  constructor(private readonly hold: HoldSeat) {}
  @Get('hold')
  go(): object { return { held: this.hold.execute('a1') }; }
}

@Module({ controllers: [SeatsController], providers: [HoldSeat, MemorySeats, { provide: 'SEAT_STORE', useClass: MemorySeats }] })
class AppModule {} // LAYER 4 wiring — composing, never deciding

async function run(): Promise<void> {
  const app = await NestFactory.create(AppModule, new FastifyAdapter());
  await app.init();
  const http = app.getHttpAdapter().getInstance() as any; // inject proving — instance driving, ports skipping
  const res = await http.inject({ method: 'GET', url: '/seats/hold' });
  console.log(res.statusCode === 200 && res.body === '{"held":1}' ? 'layers compose' : 'silos design');
  await app.close();
}
run();
```

```typescript
// // Entity team, service team, controller team (handoffs queuing — ownership blurring — integration hoping).
// // Wires meeting at boot (failures surfacing late — causes hiding). Compose features; earn integration early.)
```

**Common confusion** — *"full-system means big design up front (documents preceding)."* Upfront documenting guesses (diagrams aging — code diverging (assumptions funding — waste scheduling (documenting charging — agility declining); composing walking slices (features owning — rings proving (integration earning — confidence funding (composing serving — siloing declining). "Upfront" describing guesses (documents aging — code diverging); full-system describing traversal (layers walking — wholes judging). Walk slices (features owning — integration earning); document lightly (decisions recording — guesses expiring).

**Performance note** — composing economics: walking costing one traversal (features owning — integration earning (confidence funding — siloing declining); siloed equivalents costing integration (wires meeting late — failures surfacing (causes hiding — debugging guessing). Walk cheaply (slices — traversals); silo never (layers — handoffs).

**Mentor note** — teach "walk the whole slice" (juniors traversing one feature per design review architecturally-complete judgment on first hearing; ring-sampled reviews interrogated ("and the edges?" — composing demanding per feature). Walk one slice once (policy deciding — details serving tangible (siloing ending — composing proving permanently). Decide policy; serve details — composing discipline in three habits, reviewed per feature.

## 2. Boundaries evidencing (arrows proving — gates passing — imports asserting)

**Definition** — boundary evidence: every claimed boundary backed by checkable proof (arrows proving — imports asserting (graphs owning — hope declining (proving funding — claiming ending); gates passing — lint blocking (suites greening — merges proving (passing owning — decay preventing); imports asserting — greps confirming (leaks absenting — ignorance proving (asserting serving — trusting declining).

**What problem it solves** — the trust-me trio: *boundaries claiming* (diagrams asserting — code contradicting (pictures serving — arrows reversing (claiming billing — enforcement absenting); *gates missing* (CI hoping — merges unexamined (violations landing — erosion compounding (missing charging — discipline decaying); *arrows drifting* (imports creeping — directions reversing (shortcuts accumulating — big-balling arriving (drifting billing — rewrites looming). Evidenced boundaries converting claiming to proving (arrows asserting — gates passing (imports confirming — hope ending); reviewers attaching gate output per boundary (evidencing proving → verifiable; claiming → returned).

**Modern guidance** — the evidencing lines per boundary (review-enforced): *arrows proving* (imports asserting — graphs owning (hope declining — drift detecting (proving funding — claiming ending (evidence owning — erosion detecting); *gates passing* (lint blocking — suites greening (merges proving — decay preventing (passing owning — missing refusing (automation funding — fatigue declining); *imports asserting* (greps confirming — leaks absenting (ignorance proving — trusting declining (asserting serving — hoping ending (checks owning — faith declining).

```typescript
// GOOD: boundaries evidencing — claims checked against sources, gaps reported (compiled + run live).
interface Claim { // arrows proving — imports asserting, hope declining
  boundary: string;
  proof: string;
}
function audit(claims: Claim[]): string[] { // gates passing — lint blocking, decay preventing

}
const claims: Claim[] = [ // imports asserting — greps confirming, trusting declining
  { boundary: 'core→ports', proof: 'grep-clean' },
  { boundary: 'edges→DTOs', proof: '' },
  { boundary: 'vendors→adapters', proof: 'lint-green' },

const gaps = audit(claims);
console.log(gaps.join(',') === 'edges→DTOs' ? 'boundaries evidence' : 'trust-me claims');
```

## 3. Debts ledgering (shortcuts pricing — owners naming — paydowns scheduling)

**Definition** — debt ledger: recorded shortcuts with prices, owners, and paydown dates (shortcuts pricing — costs stating (interest estimating — surprises declining (pricing proving — hiding ending); owners naming — humans answering (accountability owning — diffusion declining (naming funding — blaming ending); paydowns scheduling — dates committing (sprints allocating — balances shrinking (scheduling owning — forever declining).

**What problem it solves** — the hidden-debt trio: *shortcuts hiding* (TODOs scattering — hacks unowned (costs invisible — interest compounding (hiding billing — surprises scheduling); *owners missing* (debts orphaning — paydowns hoping (accountability absenting — diffusion owning (missing charging — balances growing); *paydowns postponing* (sprints skipping — balances compounding (forever scheduling — bankruptcies arriving (postponing costing — velocity dying). Ledgered debts converting hiding to pricing (shortcuts stating — owners answering (paydowns committing — surprises declining); reviewers reading ledger exposure per quarter (ledgering proving → verifiable; hiding → returned).

**Modern guidance** — the ledgering lines per shortcut (review-enforced): *shortcuts pricing* (costs stating — interest estimating (surprises declining — hiding ending (pricing proving — invisibility refusing (numbers owning — dread ending); *owners naming* (humans answering — accountability owning (diffusion declining — blaming ending (naming funding — orphaning refusing (people owning — debts answering); *paydowns scheduling* (dates committing — sprints allocating (balances shrinking — forever declining (scheduling owning — postponing refusing (calendars funding — bankruptcy declining).

```typescript
// GOOD: debts ledgering — exposure totaled, overdue flagged, owners named (compiled + run live).
interface Debt { // shortcuts pricing — costs stating, surprises declining
  item: string;
  costDays: number;
  owner: string;
  dueQ: string;
}
function exposure(debts: Debt[]): number {
  return debts.reduce((a, d) => a + d.costDays, 0);
}
function overdue(debts: Debt[], nowQ: string): string[] {
  return debts.filter((d) => d.dueQ < nowQ).map((d) => d.item); // paydowns scheduling — dates committing, forever declining
}
const ledger: Debt[] = [ // owners naming — humans answering, diffusion declining
  { item: 'god-mapper', costDays: 3, owner: 'team-a', dueQ: 'Q4' },
  { item: 'shared-tx', costDays: 5, owner: 'team-b', dueQ: 'Q3' },
];
console.log(exposure(ledger) === 8 && overdue(ledger, 'Q4').join(',') === 'shared-tx' ? 'debts ledger' : 'todos hide');
```
