# 4.1. Mastery checklist mentors insist on

## 1. Every layer answering (decisions owning — costs stating — evidence dating)

**Definition** — the layer gate: each ring owning decisions, stating costs, dating evidence (decisions owning — policies deciding (rules guarding — flows composing (owning proving — scattering ending); costs stating — prices attaching (trade-offs admitting — surprises declining (stating funding — hiding ending); evidence dating — gates checking (drills timing — owners naming (dating proving — bluffing ending).

**What problem it solves** — the unowned-layer trio: *decisions drifting* (policies unowned — rules homeless (ownership missing — drift growing (drifting billing — scattering ending-absent); *costs hiding* (prices unstated — trade-offs unowned (surprises scheduling — judgment bluffing (hiding charging — honesty declining); *evidence bluffing* (gates unrun — drills undated (freshness hoping — trust assuming (bluffing costing — incidents scheduling). The gate converting drifting to owning (decisions stating — costs attaching (evidence dating — hope ending); mentors asking one question per layer ("who decides, what costs, what proves?" — answering demanding per ring).

**Modern guidance** — the gate commands (run per layer, enforced in review):

```typescript
// GOOD: layers gated — decisions owning, costs stating, evidence dating (checklist shape).
// 1. Decision proof (policies deciding — rules guarding):
//    every ring owning its decisions — entities guarding, use cases composing, edges translating.
// 2. Cost proof (prices attaching — trade-offs admitting):
//    every decision windowed with cost and reversal — vibes declining, judgment funding.
// 3. Evidence proof (gates checking — drills timing):
//    every boundary backed by gate output — arrows asserting, suites greening, owners naming.
// Own decisions; state costs; date evidence.)
```

```typescript
// BAD: layers unowning — decisions drifting, costs hiding (real unowned shape).
// // "The service handles it." (policies unowned — rules homeless — drift growing).
// // No prices, no gates (surprises scheduling — trust assuming). Own rings; state prices; date proof.)
```

**Common confusion** — *"gates formalize reviews (process stiffening)."* Gates evidencing ownership (decisions owning — costs stating (proof reusing — judgment focusing (evidencing funding — slowing declining); formalizing freezing judgment (rules rigidifying — contexts ignoring (stiffening serving — agility declining (freezing charging — wisdom missing). "Formalizing" describing rigidity (rules freezing — contexts ignoring); gates describing evidence (ownership proving — trust earning). Evidence ownership (decisions owning — costs stating); freeze never (rules rigidifying — contexts ignoring).

**Performance note** — layer economics: owning costing answers (decisions stating — costs attaching (evidence dating — hope ending); unowned equivalents costing drift (policies unowned — rules homeless (ownership missing — surprises scheduling). Own cheaply (answers — layers); drift never (policies — homelessness).

**Mentor note** — demand "decision, cost, proof per layer" (juniors owning one ring per answer design drift-proof reviews on first hearing; answerless layers interrogated ("who decides here?" — answering demanding per ring). Own one layer once (decisions owning — costs stating tangible (drifting ending — owning proving permanently). State costs; date proof — layer discipline in three habits, reviewed per ring.

## 2. Every boundary proving (arrows asserting — gates passing — imports checking)

**Definition** — the boundary gate: each crossing asserting arrows, passing gates, checking imports (arrows asserting — graphs owning (hope declining — drift detecting (asserting funding — claiming ending); gates passing — lint blocking (suites greening — merges proving (passing owning — missing refusing (automation funding — fatigue declining); imports checking — greps confirming (leaks absenting — ignorance proving (checking serving — trusting declining).

**What problem it solves** — the unproven trio: *arrows hoping* (imports unexamined — directions reversing (shortcuts accumulating — big-balling arriving (hoping billing — enforcement absenting); *gates missing* (CI unexamined — violations landing (erosion compounding — discipline decaying (missing charging — proof absenting); *imports creeping* (frameworks arriving — vendors dictating (direction reversing — leverage inverting (creeping billing — quarantine breaking). The gate converting hoping to asserting (arrows owning — gates blocking (imports confirming — hope ending); mentors asking one question per crossing ("show me the gate" — proving demanding per edge).

**Modern guidance** — the gate commands (run per boundary, enforced in review):

```typescript
// GOOD: boundaries gated — arrows asserting, gates passing, imports checking (checklist shape).
// 1. Arrow proof (graphs owning — hope declining):
//    dependency directions asserted per feature — outward edges absenting, violations failing.
// 2. Gate proof (lint blocking — suites greening):
//    import rules and contract suites green — merges proving, decay preventing, confidence earning.
// 3. Import proof (greps confirming — leaks absenting):
//    core imports audited per file — frameworks unknown, vendors unheard, ignorance keeping.
// Assert arrows; pass gates; check imports.)
```

```typescript
// BAD: boundaries hoping — arrows unexamined, gates missing (real hope shape).
// // "Arrows point inward (probably)." (shortcuts accumulating — big-balling arriving — enforcement absenting).
// // No lint, no audit (violations landing — erosion compounding). Assert directions; block merges; grep cores.)
```

**Common confusion** — *"gates replace architecture reviews (automation substituting)."* Gates evidencing direction (arrows asserting — suites greening (proof reusing — judgment focusing (evidencing funding — slowing declining); reviews judging trade-offs (wholes owning — prices stating (context weighing — hope ending (judging serving — automating declining). "Replacing" describing substitution (humans skipping — context ignoring); gates describing evidence (direction proving — trust earning). Evidence direction (arrows asserting — gates passing); judge wholes (trade-offs stating — contexts weighing).

**Performance note** — boundary economics: asserting costing gate output (arrows owning — suites greening (hope ending — erosion detecting); hoped equivalents costing erosion (shortcuts accumulating — violations landing (discipline decaying — rewrites looming). Assert cheaply (gates — outputs); hope never (arrows — drift).

**Mentor note** — demand "gate green per boundary" (juniors asserting one direction per crossing design hope-proof architectures on first hearing; gateless boundaries interrogated ("which check?" — proving demanding per edge). Assert one crossing once (arrows owning — gates passing tangible (hoping ending — proving permanently). Own arrows; pass gates — boundary discipline in three habits, reviewed per crossing.

## 3. Every debt ledgering (shortcuts pricing — owners naming — paydowns scheduling)

**Definition** — the ledger gate: each shortcut priced, owned, and scheduled for paydown (shortcuts pricing — costs stating (interest estimating — surprises declining (pricing proving — hiding ending); owners naming — humans answering (accountability owning — diffusion declining (naming funding — orphaning ending); paydowns scheduling — dates committing (sprints allocating — balances shrinking (scheduling owning — forever declining).

**What problem it solves** — the unledgered trio: *shortcuts hiding* (TODOs scattering — hacks unowned (costs invisible — interest compounding (hiding billing — surprises scheduling); *owners missing* (debts orphaning — paydowns hoping (accountability absenting — diffusion owning (missing charging — balances growing); *paydowns postponing* (sprints skipping — balances compounding (forever scheduling — bankruptcies arriving (postponing costing — velocity dying). The gate converting hiding to pricing (shortcuts stating — owners answering (paydowns committing — surprises declining); mentors asking one question per hack ("price, owner, quarter?" — ledgering demanding per shortcut).

**Modern guidance** — the gate commands (run per shortcut, enforced in review):

```typescript
// GOOD: ledger gated — shortcuts pricing, owners naming, paydowns scheduling (checklist shape).
// 1. Price proof (costs stating — interest estimating):
//    every shortcut carrying day-costs plus accruing interest — exposure totaling, surprises declining.
// 2. Owner proof (humans answering — accountability owning):
//    every debt naming its payer — diffusion declining, orphaning refusing, pride funding.
// 3. Schedule proof (dates committing — sprints allocating):
//    every debt quartered for paydown — balances shrinking, forever declining, bankruptcy preventing.
// Price shortcuts; name owners; schedule paydowns.)
```

```typescript
// BAD: debts unledgering — shortcuts hiding, owners missing (real unledgered shape).
// // TODO: clean up (costs invisible — interest compounding — surprises scheduling).
// // No owner, no quarter (accountability absenting — balances growing). Price hacks; name payers; date quarters.)
```

**Common confusion** — *"ledgers shame authors (records blaming)."* Ledgers owning work (shortcuts pricing — owners naming (accountability funding — surprises declining (owning proving — hiding ending); shaming attacking people (authors blaming — morale taxing (value missing — safety declining (attacking charging — learning stopping). "Shaming" describing attack (people blaming — morale taxing); ledgers describing ownership (work pricing — paydowns committing). Own work (shortcuts pricing — paydowns committing); blame never (authors attacking — safety declining).

**Performance note** — ledger economics: pricing costing entries (costs stating — owners naming (surprises declining — hiding ending); hidden equivalents costing surprises (TODOs scattering — interest compounding (balances growing — velocity dying). Ledger cheaply (entries — quarters); hide never (TODOs — surprises).

**Mentor note** — demand "price, owner, quarter per hack" (juniors ledgering one debt per shortcut design surprise-free codebases on first hearing; unledgered hacks interrogated ("who pays, when?" — ledgering demanding per TODO). Ledger one debt once (shortcuts pricing — paydowns committing tangible (hiding ending — accountability proving permanently). State prices; commit dates — ledgering discipline in three habits, reviewed per shortcut.
