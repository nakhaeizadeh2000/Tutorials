# 2.1. Judgment at scale

## 1. Decisions pricing (choices windowing — trade-offs stating — vibes declining)

**Definition** — priced decisions: every architectural choice windowed with cost and reversal (choices windowing — options stating (prices attaching — reversals naming (windowing proving — vibing declining); trade-offs stating — gains pricing (losses admitting — contexts weighing (stating funding — hiding declining); vibes declining — feelings refusing (evidence demanding — reasons owning (declining proving — hoping ending).

**What problem it solves** — the unpriced trio: *choices vibing* (decisions feeling — options unstated (reasons missing — reversals unowned (vibing billing — judgment bluffing); *trade-offs hiding* (gains touting — losses omitting (contexts ignoring — surprises scheduling (hiding charging — honesty declining); *reversals missing* (decisions fossilizing — mistakes compounding (outs absenting — pivots dreading (missing costing — agility dying). Priced decisions converting vibing to windowing (options stating — trade-offs admitting (reversals naming — feelings refusing); reviewers seeing prices per decision (pricing proving → verifiable; vibing → returned).

**Modern guidance** — the pricing lines per decision (review-enforced): *choices windowing* (options stating — prices attaching (reversals naming — vibing declining (windowing proving — feeling refusing (options owning — impulses declining); *trade-offs stating* (gains pricing — losses admitting (contexts weighing — hiding declining (stating funding — touting ending (honesty owning — surprise declining); *vibes declining* (feelings refusing — evidence demanding (reasons owning — hoping ending (declining proving — bluffing refusing (rigor funding — mood declining).

```typescript
// GOOD: decisions pricing — options windowed with cost and reversal, minimum chosen (compiled + run live).
interface Option { // choices windowing — options stating, vibing declining
  plan: string;
  cost: number;
  reversal: number;
}
function choose(options: Option[]): string {
  let best = options[0];
  for (const o of options.slice(1)) {
    if (o.cost + o.reversal < best.cost + best.reversal) best = o; // trade-offs stating — gains pricing, losses admitting
  }
  return best.plan;
}
const pick = choose([
  { plan: 'monolith', cost: 3, reversal: 8 },
  { plan: 'modular', cost: 5, reversal: 2 }, // reversals naming — outs owning, pivots funding
  { plan: 'micro', cost: 9, reversal: 6 },
]);
console.log(pick === 'modular' ? 'decisions price' : 'vibes decide');
```

```typescript
// BAD: decisions vibing — feelings deciding, reversals missing (real vibe shape).
// // "Microservices feel right." (options unstated — reasons missing — judgment bluffing).
// // No reversal named (decisions fossilizing — pivots dreading). Window choices; state trade-offs; name reversals.)
```

**Common confusion** — *"pricing needs exact numbers (precision demanding)."* Pricing windowing ranges (options stating — costs estimating (orders owning — decisions funding (windowing proving — precision declining); exactness demanding audits (numbers certifying — decimals defending (precision serving — judgment delaying (demanding charging — shipping declining). "Exact" describing audits (numbers certifying — decisions delaying); pricing describing windows (options stating — reversals naming). Window options (costs estimating — reversals naming); audit rarely (numbers certifying — decisions delaying).

**Performance note** — pricing economics: windowing costing one table (options stating — reversals naming (feelings refusing — judgment funding); vibed equivalents costing fossils (decisions fossilizing — mistakes compounding (outs absenting — agility dying). Window cheaply (options — tables); vibe never (feelings — fossils).

**Mentor note** — teach "price, then pick" (juniors windowing one option set per decision design vibe-free judgment on first hearing; unpriced decisions interrogated ("what does it cost to reverse?" — pricing demanding per choice). Price one decision once (options stating — reversals naming tangible (vibing ending — judgment proving permanently). State trade-offs; name reversals — pricing discipline in three habits, reviewed per decision.

## 2. Load repricing (traffic multiplying — budgets tightening — margins thinning)

**Definition** — load repricing: every choice repriced at 10x and 100x load (traffic multiplying — volumes growing (assumptions breaking — cliffs approaching (multiplying proving — steady declining); budgets tightening — latencies bounding (costs capping — margins thinning (tightening funding — slack declining); margins thinning — headrooms shrinking (buffers consuming — failures nearing (thinning warning — comfort declining).

**What problem it solves** — the current-load trio: *designs steadying* (loads assuming — traffic hoping (growth ignoring — cliffs missing (steadying billing — surprises scheduling); *cliffs surprising* (latencies exploding — queues overflowing (breakpoints unowned — incidents arriving (surprising charging — capacity bluffing); *margins assuming* (headrooms hoping — buffers unmeasured (slack assuming — failures nearing (assuming costing — safety bluffing). Repriced loads converting steadying to multiplying (volumes growing — budgets tightening (margins thinning — cliffs naming); reviewers seeing 10x prices per choice (repricing proving → verifiable; steadying → returned).

**Modern guidance** — the repricing lines per choice (review-enforced): *traffic multiplying* (volumes growing — assumptions breaking (cliffs approaching — steady declining (multiplying proving — hoping ending (growth owning — stagnation refusing); *budgets tightening* (latencies bounding — costs capping (margins thinning — slack declining (tightening funding — assuming ending (bounds owning — blowouts declining); *margins thinning* (headrooms shrinking — buffers consuming (failures nearing — comfort declining (thinning warning — complacency ending (gauges owning — blindness declining).

```typescript
// GOOD: load repricing — latency model naming the cliff where budgets break (compiled + run live).
function latencyMs(rps: number): number { // traffic multiplying — volumes growing, assumptions breaking
  return 20 + rps * rps * 0.002; // budgets tightening — latencies bounding, slack declining
}
function cliff(budgetMs: number): number {
  let rps = 0;
  while (latencyMs(rps) <= budgetMs) rps += 10; // margins thinning — headrooms shrinking, comfort declining
  return rps;
}
const at = cliff(100);
console.log(latencyMs(at - 10) <= 100 && latencyMs(at) > 100 ? `cliff at ${at}rps` : 'cliffs surprise');
```

```typescript
// BAD: loads steadying — traffic hoping, cliffs missing (real steady shape).
// // "Handles our traffic." (growth ignoring — cliffs missing — surprises scheduling).
// // No 10x price (assumptions breaking-unexamined — breakpoints unowned). Multiply traffic; tighten budgets; name cliffs.)
```

**Common confusion** — *"repricing is premature optimization (scaling pre-building)."* Optimizing building early (capacity provisioning — complexity funding (scaling serving — simplicity declining (optimizing charging — restraint declining); repricing naming cliffs (volumes growing — budgets tightening (margins thinning — surprises declining (naming funding — hoping ending). "Premature" describing building (capacity provisioning — restraint declining); repricing describing knowing (cliffs naming — budgets bounding). Name cliffs (volumes growing — margins thinning); build conditionally (evidence demanding — restraint keeping).

**Performance note** — repricing economics: naming costing one model (volumes growing — budgets tightening (surprises declining — incidents preventing); steadied equivalents costing cliffs (latencies exploding — queues overflowing (incidents arriving — trust eroding). Name cheaply (models — cliffs); steady never (loads — surprises).

**Mentor note** — teach "price at 1x, 10x, 100x" (juniors multiplying one load per choice design cliff-aware judgment on first hearing; single-load designs interrogated ("price at 10x?" — repricing demanding per choice). Reprice one choice once (traffic multiplying — margins thinning tangible (steadying ending — cliffs proving named permanently). Multiply volumes; bound latencies — repricing discipline in three habits, reviewed per choice.

## 3. Fashion declining (recitation refusing — reasons demanding — independence keeping)

**Definition** — fashion decline: recited stacks refused without measured reasons (recitation refusing — slogans declining (hype resisting — evidence demanding (refusing proving — following ending); reasons demanding — pilots measuring (adoptions justifying — sunsets stating (demanding funding — vibing declining); independence keeping — teams deciding (contexts weighing — options owning (keeping proving — herding declining).

**What problem it solves** — the hype trio: *stacks reciting* ("everyone uses X" stating — reasons missing (slogans owning — judgment absenting (reciting billing — independence dying); *adoptions resuming* (pilots skipping — evidence bluffing (resumes padding — production risking (resuming charging — prudence declining); *sunsets missing* (bets fossilizing — exits unplanned (lock-in hardening — pivots dreading (missing costing — agility dying). Declined fashion converting reciting to reasoning (slogans declining — pilots measuring (sunsets stating — herds thinning); reviewers demanding reasons per adoption (declining proving → verifiable; reciting → passed).

**Modern guidance** — the declining lines per adoption (review-enforced): *recitation refusing* (slogans declining — hype resisting (evidence demanding — following ending (refusing proving — herding declining (spines owning — crowds declining); *reasons demanding* (pilots measuring — adoptions justifying (sunsets stating — vibing declining (demanding funding — resuming ending (proof owning — padding declining); *independence keeping* (teams deciding — contexts weighing (options owning — herding declining (keeping proving — stampeding refusing (autonomy earning — groupthink declining).

```typescript
// GOOD: fashion declining — adoptions gated on measured pilots with sunsets (compiled + run live).
interface Bid { // reasons demanding — pilots measuring, vibing declining
  tool: string;
  measuredGainPct: number;
  sunsetQ: string;
}
function adopt(bids: Bid[], barPct: number): string[] {
  return bids.filter((b) => b.measuredGainPct >= barPct && b.sunsetQ.length > 0).map((b) => b.tool); // recitation refusing — slogans declining, evidence demanding
}
const chosen = adopt(
  [
    { tool: 'hype-db', measuredGainPct: 2, sunsetQ: '' },
    { tool: 'boring-q', measuredGainPct: 35, sunsetQ: 'Q2' },
  ],
  10,
);
console.log(chosen.join(',') === 'boring-q' ? 'fashion declines' : 'hype adopts');
```

```typescript
// BAD: fashion following — slogans reciting, pilots skipping (real hype shape).
// // "Everyone uses hype-db." (reasons missing — judgment absenting — independence dying).
// // No sunset (bets fossilizing — pivots dreading). Refuse recitation; demand reasons; keep independence.)
```

**Common confusion** — *"declining is luddism (progress refusing)."* Luddism refusing tools (progress declining — value missing (refusing serving — stagnation funding (luddism charging — learning declining); declining demanding reasons (pilots measuring — sunsets stating (evidence funding — vibing declining (demanding proving — herding ending). "Luddism" describing refusal (tools declining — learning stopping); declining describing independence (reasons demanding — herds resisting). Demand reasons (pilots measuring — sunsets stating); adopt proven (gains pricing — exits planning).

**Performance note** — declining economics: demanding costing one pilot (reasons stating — evidence funding (vibing declining — herding ending); followed equivalents costing lock-in (bets fossilizing — pivots dreading (judgment absenting — agility dying). Demand cheaply (pilots — reasons); follow never (slogans — herds).

**Mentor note** — teach "reasons, then tools" (juniors demanding one measured reason per adoption design hype-proof judgment on first hearing; slogan adoptions interrogated ("measured where?" — declining demanding per tool). Decline one hype once (recitation refusing — reasons demanding tangible (following ending — independence proving permanently). Measure pilots; state sunsets — declining discipline in three habits, reviewed per adoption.
