# 2.2. Failure rehearsal game-days

## 1. Faults scripting (failures scheduling — surprises declining — drills owning)

**Definition** — fault scripting: scheduled dependency failures with asserted degraded behavior (failures scheduling — stores dying (upstreams slowing — nodes killing (scheduling proving — surprising declining); surprises declining — outages rehearsing (paths proving — panics preventing (declining funding — hoping ending); drills owning — teams running (scenarios scripting — recoveries timing (owning proving — skipping declining).

**What problem it solves** — the unrehearsed trio: *outages surprising* (failures arriving — paths untested (behaviors unknown — panics scheduling (surprising billing — resilience bluffing); *fallbacks hoping* (degrades assuming — code unexercised (safety bluffing — incidents discovering (hoping charging — trust eroding); *drills skipping* (quarters passing — scenarios unrun (confidence assuming — staleness hiding (skipping costing — maturity bluffing). Scripted faults converting surprising to scheduling (failures injecting — behaviors asserting (recoveries timing — panics declining); reviewers seeing fault scripts per dependency (scripting proving → verifiable; surprising → returned).

**Modern guidance** — the scripting lines per dependency (review-enforced): *failures scheduling* (stores dying — upstreams slowing (nodes killing — surprising declining (scheduling proving — hoping ending (scenarios owning — chaos declining); *surprises declining* (outages rehearsing — paths proving (panics preventing — hoping ending (declining funding — bluffing refusing (rehearsals owning — incidents preparing); *drills owning* (teams running — scenarios scripting (recoveries timing — skipping declining (owning proving — assuming refusing (practice funding — maturity earning).

```typescript
// GOOD: faults scripting — injected store death driving asserted fallback and recovery (compiled + run live).
class Primary { // dependency owning — stores serving, failures scheduling-absent
  constructor(private dead: boolean) {}
  fetch(): string {
    if (this.dead) throw new Error('store down'); // failures scheduling — stores dying, surprises declining
    return 'live-data';
  }
}
function readWithFallback(primary: Primary): string { // drills owning — teams running, recoveries timing
  try {
    return primary.fetch();
  } catch {
    return 'cached-data'; // surprises declining — outages rehearsing, panics preventing
  }
}
const alive = readWithFallback(new Primary(false));
const dead = readWithFallback(new Primary(true));
const recovered = readWithFallback(new Primary(false));
console.log(alive === 'live-data' && dead === 'cached-data' && recovered === 'live-data' ? 'faults script' : 'outages surprise');
```

```typescript
// BAD: outages surprising — failures arriving, fallbacks hoping (real unrehearsed shape).
// const data = await store.fetch(); // paths untested — behaviors unknown, panics scheduling.
// // No fallback (safety bluffing — incidents discovering). Script faults; assert fallbacks; time recoveries.)
```

**Common confusion** — *"game-days need production (stakes requiring)."* Production bounding blasts (traffic sharing — rollbacks readying (maturity earning — downtimes declining (bounding proving — recklessness declining); staging proving responses (failures scheduling — behaviors asserting (recoveries timing — surprises declining (proving funding — hoping ending). "Production" describing radii (blasts bounding — maturity earning); game-days describing rehearsal (faults scripting — recoveries timing). Prove in staging (failures scheduling — behaviors asserting); bound in production (blasts bounding — maturity earning).

**Performance note** — scripting economics: scheduling costing drill hours (faults injecting — behaviors asserting (panics declining — maturity earning); surprised equivalents costing outages (failures arriving — paths untested (behaviors unknown — trust eroding). Script cheaply (hours — drills); surprise never (outages — panics).

**Mentor note** — teach "script one fault per dependency" (juniors injecting one failure per store design surprise-proof services on first hearing; unscripted dependencies interrogated ("what if it dies?" — scripting demanding per dependency). Script one fault once (failures scheduling — fallbacks asserting tangible (surprising ending — resilience proving permanently). Schedule failures; assert fallbacks — scripting discipline in three habits, reviewed per dependency.

## 2. Coverage compounding (quarters sequencing — MTTR shrinking — confidence earning)

**Definition** — coverage compounding: quarterly-sequenced failure classes with shrinking MTTR (quarters sequencing — classes expanding (scenarios growing — gaps closing (sequencing proving — stalling declining); MTTR shrinking — recoveries timing (means declining — trends proving (shrinking funding — stagnating ending); confidence earning — programs maturing (grades passing — radii graduating (earning proving — bluffing declining).

**What problem it solves** — the one-off trio: *drills one-offing* (scenarios running-once — classes freezing (coverage stalling — gaps persisting (one-offing billing — compounding declining); *MTTR unmeasuring* (recoveries untimed — trends unknown (means missing — progress bluffing (unmeasuring charging — improvement hoping); *classes freezing* (failures repeating — novelties absenting (scenarios staling — surprises returning (freezing costing — maturity bluffing). Compounded coverage converting one-off to sequencing (quarters ordering — classes expanding (MTTR timing — confidence earning); reviewers seeing growing matrices per quarter (compounding proving → verifiable; one-offing → returned).

**Modern guidance** — the compounding lines per program (review-enforced): *quarters sequencing* (classes expanding — scenarios growing (gaps closing — stalling declining (sequencing proving — freezing refusing (cadence owning — drift preventing); *MTTR shrinking* (recoveries timing — means declining (trends proving — stagnating ending (shrinking funding — hoping ending (speed owning — slowness declining); *confidence earning* (programs maturing — grades passing (radii graduating — bluffing declining (earning proving — assuming refusing (maturity funding — incidents preparing).

```typescript
// GOOD: coverage compounding — quarterly matrix growing, MTTR trend shrinking (compiled + run live).
interface Quarter { // quarters sequencing — classes expanding, gaps closing
  q: string;
  classes: number;
  mttrMin: number;
}
function coverage(rows: Quarter[], totalClasses: number): number {
  const done = new Set<string>();
  for (const r of rows) for (let i = 0; i < r.classes; i += 1) done.add(`${r.q}#${i}`);
  return done.size / totalClasses;
}
function improving(rows: Quarter[]): boolean { // MTTR shrinking — recoveries timing, trends proving
  return rows.every((r, i) => i === 0 || r.mttrMin <= rows[i - 1].mttrMin);
}
const program: Quarter[] = [ // confidence earning — programs maturing, bluffing declining
  { q: 'Q1', classes: 2, mttrMin: 45 },
  { q: 'Q2', classes: 3, mttrMin: 30 },
];
console.log(coverage(program, 5) === 1 && improving(program) ? 'coverage compounds' : 'drills stall');
```

```typescript
// BAD: drills one-offing — scenarios running-once, MTTR unmeasuring (real one-off shape).
// // Annual chaos day (classes freezing — gaps persisting — compounding declining).
// // No MTTR trend (recoveries untimed — progress bluffing). Sequence quarters; time recoveries; grow classes.)
```

**Common confusion** — *"compounding needs dedicated teams (staffing gating)."* Staffing funding programs (teams owning — drills running (cadence keeping — maturity earning (funding serving — compounding declining); compounding sequencing quarters (classes expanding — MTTR timing (confidence earning — bluffing declining (sequencing proving — stalling declining). "Dedicated" describing staffing (teams owning — drills running); compounding describing cadence (quarters sequencing — classes growing). Fund cadence (quarters owning — classes expanding); staff pragmatically (teams owning — drills running).

**Performance note** — compounding economics: sequencing costing quarterly hours (classes expanding — MTTR timing (confidence earning — bluffing declining); one-off equivalents costing staleness (scenarios freezing — gaps persisting (surprises returning — maturity bluffing). Sequence cheaply (quarters — classes); stall never (one-offs — gaps).

**Mentor note** — teach "grow the matrix quarterly" (juniors sequencing one class-set per quarter design stall-proof programs on first hearing; static matrices interrogated ("new classes?" — compounding demanding per quarter). Compound one quarter once (classes expanding — MTTR timing tangible (one-offing ending — confidence proving earned permanently). Sequence quarters; shrink MTTR — compounding discipline in three habits, reviewed per quarter.

## 3. Radii graduating (staging proving — production bounding — maturity earning)

**Definition** — radius graduation: blast radius growing with passing grades (staging proving — behaviors asserting (recoveries timing — surprises declining (proving funding — hoping ending); production bounding — traffic sharing (rollbacks readying — downtimes declining (bounding owning — recklessness declining); maturity earning — grades passing (radii growing — confidence compounding (earning proving — bluffing declining).

**What problem it solves** — the prod-first trio: *blasts unbounding* (failures flooding — customers catching (scopes missing — downtimes arriving (unbounding billing — recklessness owning); *grades skipping* (staging bypassing — behaviors unproven (confidence assuming — surprises scheduling (skipping charging — maturity bluffing); *maturity bluffing* (programs claiming — drills missing (grades absenting — incidents discovering (bluffing costing — trust eroding). Graduated radii converting prod-first to staging-first (behaviors asserting — traffic sharing (grades passing — blasts bounding); reviewers gating radii per grade (graduating proving → verifiable; bluffing → returned).

**Modern guidance** — the graduating lines per program (review-enforced): *staging proving* (behaviors asserting — recoveries timing (surprises declining — hoping ending (proving funding — skipping refusing (staging owning — confidence earning); *production bounding* (traffic sharing — rollbacks readying (downtimes declining — recklessness declining (bounding owning — flooding refusing (limits funding — blasts containing); *maturity earning* (grades passing — radii growing (confidence compounding — bluffing declining (earning proving — claiming refusing (maturity funding — incidents preparing).

```typescript
// GOOD: radii graduating — grades gating blast growth, failures holding (compiled + run live).
type Radius = 'staging' | 'canary' | 'prod-bounded';
function next(grade: string): Radius | 'hold' { // staging proving — behaviors asserting, hoping ending
  if (grade === 'green-staging') return 'canary';
  if (grade === 'green-canary') return 'prod-bounded'; // production bounding — traffic sharing, recklessness declining
  return 'hold'; // maturity earning — grades passing, bluffing declining
}
const a = next('green-staging');
const b = next('green-canary');
const held = next('red-staging');
console.log(a === 'canary' && b === 'prod-bounded' && held === 'hold' ? 'radii graduate' : 'blasts flood');
```

```typescript
// BAD: blasts flooding — prod-first drilling, grades skipping (real flood shape).
// // Game-day in production, first drill (customers catching — downtimes arriving — recklessness owning).
// // No grades (confidence assuming — surprises scheduling). Prove staging; bound production; earn maturity.)
```

**Common confusion** — *"graduation slows programs (grades throttling)."* Graduation gating blasts (behaviors asserting — traffic sharing (downtimes declining — recklessness ending (gating funding — flooding declining); throttling slowing value (approvals queuing — ships waiting (process taxing — momentum dying (throttling charging — agility declining). "Throttling" describing process (approvals queuing — value missing); graduation describing safety (grades passing — blasts bounding). Gate radii (grades passing — downtimes declining); ship steadily (cadence keeping — momentum funding).

**Performance note** — graduating economics: gating costing grades (behaviors asserting — traffic sharing (downtimes declining — recklessness ending); flooded equivalents costing customers (failures flooding — downtimes arriving (trust eroding — incidents scheduling). Gate cheaply (grades — radii); flood never (blasts — customers).

**Mentor note** — teach "earn the next radius" (juniors graduating one blast level per grade design flood-proof programs on first hearing; ungraded blasts interrogated ("which grade?" — graduating demanding per radius). Prove staging; bound production — graduating discipline in three habits, reviewed per program.
