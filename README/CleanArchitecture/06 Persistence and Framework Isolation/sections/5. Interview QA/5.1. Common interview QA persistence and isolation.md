# 5.1. Common interview QA persistence and isolation

## 1. Mappers live under pressure (directions, vendors, leaks — diagnosed with fixes, priced)

**Definition** — mapper answers: directions separating, vendors hiding, leaks declining — under pressure (diagnosed with fixes — causes naming (understanding proving — reciting declining); priced with trade-offs — crossings billing (judgment owning — dogma refusing (pricing funding — honesty earning).

**What problem it solves** — the reciting trio: *mappers gesturing* ("translation layer" stating — directions missing (vocabulary showing — ownership absenting (reciting funding — designing declining); *vendors assuming* ("we use X" stating — ports absenting (products naming — doors missing (assuming billing — symmetry breaking); *leaks handwaving* ("ORM handles it" claiming — shapes traveling (hope funding — exposure scheduling (handwaving charging — shielding declining). Diagnosed answers converting gesturing to separating (causes naming — fixes stating (directions owning — leaks preventing); interviewers hiring separators, not gesturers (diagnosing proving → hirable; reciting → passed).

**Modern guidance** — answer shape per mapper question (diagnose → fix → price):

```typescript
// GOOD: "Where does mapping live?" — diagnosed with fixes, priced (answer shape).
// Diagnose: god mappers (directions sharing — logic branching — layers leaking).
// Fix: directions separating (inbound building — outbound shaping — logic declining).
// Price: one function per direction (layers holding — drift ending); vendors hiding (ports declaring — swaps earning).
// Separate directions; hide vendors — ownership stated, not hoped.)
```

```typescript
// BAD: mappers reciting — layers gesturing, vendors assuming (real weak shape).
// "Mappers convert objects." (directions missing — logic unowned — designing declining).
// "Repositories abstract the DB." (drivers unhidden — ports unnamed — symmetry breaking).
// Diagnose causes; state fixes; price honestly.)
```

**Common confusion** — *"mapper answers need tool names (products impressing)."* Tools naming products (vendors stating — versions pinning (naming serving — bias owning (impressing hoping — hiring declining); answers proving discipline (causes naming — fixes stating (costs pricing — trade-offs owning (proving funding — reciting declining). "Tools" describing vendors (products naming — versions pinning); answers describing ownership (directions separating — vendors hiding). Diagnose causes (understanding proving — chanting declining); price fixes (judgment owning — dogma refusing).

**Performance note** — answer economics: diagnosing costing one cause per question (understanding proving — reciting declining (hirable funding — chanting ending); recited equivalents costing offers (words owning — directions missing (designing declining — hiring passing). Diagnose cheaply (causes — fixes); recite never (tools — passes).

**Mentor note** — drill "diagnose, fix, price" (juniors answering one mapper question per shape design hirable responses on first hearing; tool-only answers interrogated ("which direction?" — diagnosing demanding per answer). Shape one answer once (causes naming — fixes stating tangible (reciting ending — designing proving permanently). Diagnose causes; price fixes — answering discipline in three habits, reviewed per mock.

## 3. Changes live under pressure (models, transitions, downtime — ownership stated, not hoped)

**Definition** — change answers: models evolving, transitions bridging, downtime declining — ownership stated (shapes growing — phases sequencing (deploys overlapping — cuts avoiding (owning proving — windowing declining); not hoped (runs asserting — rollbacks keeping (evidence funding — wishing ending (stating serving — hoping declining).

**What problem it solves** — the flag-day trio: *models renaming* (fields rebranding — readers crashing (contracts breaking — deploys coordinating (renaming billing — flag-days scheduling); *migrations banging* (tables locking — writes blocking (downtimes scheduling — users waiting (banging charging — availability declining); *downtimes windowing* (maintenance announcing — trust taxing (scheduling billing — availability declining (windowing charging — overlapping refusing). Owned answers converting renaming to evolving (shapes growing — transitions bridging (downtime declining — cuts avoiding); interviewers hiring owners, not flaggers (evolving proving → hirable; renaming → passed).

**Modern guidance** — answer shape per change question (grow → bridge → overlap):

```typescript
// GOOD: "How migrate without downtime?" — grown, bridged, overlapped (answer shape).
// Grow: shapes evolving (fields adding — versions numbering — breaks declining).
// Bridge: transitions phasing (expands contracting — duals mapping — rollbacks keeping).
// Overlap: deploys coexisting (readers tolerating — writers sequencing — cuts avoiding).
// Evolve additive; bridge phases — ownership stated, not hoped.)
```

```typescript
// BAD: changes hoping — models renaming, migrations banging (real flag shape).
// "ALTER TABLE on deploy." (readers crashing — downtimes scheduling — evolving absenting).
// "Sunday maintenance window." (trust taxing — availability declining — overlapping refusing).
// Grow shapes; bridge transitions; overlap deploys.)
```

**Common confusion** — *"change answers test operations (deploys recalling)."* Operations executing mechanics (phases scripting — windows planning (executing serving — stopping declining (operations funding — banging ending); changes owning evolution (shapes growing — transitions bridging (downtime declining — cuts avoiding (owning proving — renaming declining). "Operations" describing execution (phases scripting — windows planning); changes describing ownership (models evolving — downtime declining). **Mentor note** — drill "grow, bridge, overlap" (juniors answering one change question per shape design ownership-stated responses on first hearing; alter-table answers interrogated ("which phase?" — owning demanding per change). Shape one answer once (shapes growing — transitions bridging tangible (renaming ending — owning proving permanently). State evolution; show overlap — change discipline in three habits, reviewed per mock.
