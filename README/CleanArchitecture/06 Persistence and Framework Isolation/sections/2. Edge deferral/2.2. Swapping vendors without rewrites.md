# 2.2. Swapping vendors without rewrites

## 1. Swaps rehearsing (doubles proving — suites pinning — confidence earning)

**Definition** — swap rehearsal: new vendors proven by doubles and suites before cutover (doubles proving — fakes honoring (contracts asserting — behaviors matching (proving funding — hoping ending); suites pinning — adapters passing (drifts detecting — breaks surfacing (pinning owning — assuming declining); confidence earning — replacements trusting (vendors trading — dread declining (earning proving — fearing ending).

**What problem it solves** — the hope-cutover trio: *swaps untested* (vendors shipping — contracts hoping (behaviors bluffing — suites missing (untested billing — incidents scheduling); *doubles missing* (fakes absenting — substitutes unproven (confidence hoping — migrations fearing (missing charging — lock-in hardening); *cutovers flipping* (flags toggling — rollbacks absenting (traffic switching — failures stranding (flipping billing — recovery missing). Rehearsed swaps converting hoping to proving (doubles honoring — suites passing (confidence earning — cutovers boring); reviewers seeing suite runs per vendor per merge (rehearsing proving → verifiable; hoping → returned).

**Modern guidance** — the rehearsing lines per vendor (review-enforced): *doubles proving* (fakes honoring — contracts asserting (behaviors matching — drifts detecting (proving funding — hoping ending (doubles owning — bluffing refusing); *suites pinning* (adapters passing — breaks surfacing (changes flagging — assuming declining (pinning owning — bespoke refusing (suites earning — fear declining); *confidence earning* (replacements trusting — vendors trading (dread declining — hoping ending (earning proving — praying declining (trust funding — incidents preventing).

```typescript
// GOOD: swaps rehearsing — suite gating cutover, both vendors proving readiness (compiled + run live).
interface Store { // contract holding — suites asserting, behaviors matching
  put(k: string, v: number): void;
  fetch(k: string): number | undefined;
}
function storeSuite(make: () => Store): boolean {
  const s = make();
  s.put('a', 1);
  return s.fetch('a') === 1 && s.fetch('missing') === undefined;
}
class OldStore implements Store {
  private readonly m = new Map<string, number>();
  put(k: string, v: number): void { this.m.set(k, v); }
  fetch(k: string): number | undefined { return this.m.get(k); }
}
class NewStore implements Store {
  private keys: string[] = [];
  private vals: number[] = [];
  put(k: string, v: number): void { this.keys.push(k); this.vals.push(v); }
  fetch(k: string): number | undefined {
    const i = this.keys.lastIndexOf(k);
    return i < 0 ? undefined : this.vals[i];
  }
}
const oldReady = storeSuite(() => new OldStore());
const newReady = storeSuite(() => new NewStore()); // doubles proving — fakes honoring, confidence earning
const cutover = oldReady && newReady ? 'new' : 'old'; // suites pinning — adapters passing, hoping ending
console.log(cutover === 'new' ? 'swaps rehearse' : 'cutovers hope');
```

```typescript
// // Flag flipped Friday (traffic switching — failures stranding). Rehearse doubles; pin suites; earn confidence.)
```

**Common confusion** — *"rehearsals double testing cost (suites duplicating)."* Duplicating copying assertions (per-vendor bespoke — drifts hiding (maintenance doubling — consistency failing (duplicating charging — value missing); rehearsing sharing suites (contracts asserting — adapters proving (doubles honoring — confidence earning (rehearsing funding — hoping ending). "Doubling" describing copies (assertions bespoke — drifts hiding); rehearsals describing sharing (suites pinning — vendors proving). Share suites (contracts asserting — adapters proving); bespoke never (copies duplicating — drifts hiding).

**Performance note** — rehearsing economics: proving costing one suite (contracts asserting — adapters passing (confidence earning — incidents declining); hoped equivalents costing incidents (vendors shipping — behaviors bluffing (failures stranding — recovery missing). Prove cheaply (suites — doubles); hope never (cutovers — flags).

**Mentor note** — teach "suite before switch" (juniors proving one vendor per suite design hope-free cutovers on first hearing; suiteless swaps interrogated ("which run?" — rehearsing demanding per vendor). Rehearse one swap once (doubles proving — suites pinning tangible (hoping ending — confidence proving earned permanently). Prove doubles; pin suites — rehearsing discipline in three habits, reviewed per vendor.

## 2. Stranglers growing (routes shifting — traffic bleeding — rollbacks readying)

**Definition** — strangler growth: new vendors alongside old, traffic bled incrementally, rollback ready (routes shifting — percentages owning (traffic bleeding — risk bounding (shifting proving — flipping declining); traffic bleeding — loads transferring (old serving — new proving (bleeding funding — big-bang declining); rollbacks readying — flags reverting (outs restoring — panics declining (readying owning — stranding ending).

**What problem it solves** — the big-bang trio: *cutovers flipping* (traffic switching — failures stranding (recoveries missing — downtimes arriving (flipping billing — rehearsals absenting); *rollbacks missing* (outs absenting — reverts hoping (strands stranding — panics scheduling (missing charging — safety declining); *traffic uncompared* (outputs differing — behaviors drifting (mismatches hiding — confidence bluffing (uncompared billing — trust eroding). **Modern guidance** — the growing lines per migration (review-enforced): *routes shifting* (percentages owning — traffic bleeding (risk bounding — flipping declining (shifting proving — banging ending (routes earning — cliffs declining); *traffic bleeding* (loads transferring — old serving (new proving — big-bang declining (bleeding funding — stranding ending (transfers owning — shocks declining); *rollbacks readying* (flags reverting — outs restoring (panics declining — stranding ending (readying owning — hoping ending (safety funding — dread declining).

```typescript
// GOOD: stranglers growing — percentage routing with instant rollback (compiled + run live).
function route(key: string, percentNew: number): string { // routes shifting — percentages owning, flipping declining
  let h = 0;
  for (let i = 0; i < key.length; i += 1) h = (h * 31 + key.charCodeAt(i)) >>> 0;
  return h % 100 < percentNew ? 'new' : 'old';
}
function served(keys: string[], percentNew: number, rolledBack: boolean): string[] {
  if (rolledBack) return keys.map(() => 'old'); // rollbacks readying — flags reverting, panics declining
  return keys.map((k) => route(k, percentNew)); // traffic bleeding — loads transferring, shocks declining
}
const keys = ['a', 'b', 'c', 'd', 'e', 'f', 'g', 'h'];
const half = served(keys, 50, false);
const back = served(keys, 50, true);
const mixed = half.includes('new') && half.includes('old');
console.log(mixed && back.every((s) => s === 'old') ? 'stranglers grow' : 'bangs flip');
```

```typescript
function path(unknowns: number, spans: number): string { // risks bounding — scopes limiting, bets declining
```
