# 2.1. Frameworks deferred to edges

## 1. Details deferring (frameworks edging — vendors plugging — cores ruling)

**Definition** — framework deferral: delivery and storage frameworks living at edges, cores ruling policy (frameworks edging — adapters owning (protocols serving — cores ignoring (edging proving — centering declining); vendors plugging — details serving (products obeying — cores deciding (plugging funding — dictating ending); cores ruling — policies owning (decisions holding — leverage keeping (ruling proving — obeying declining).

**What problem it solves** — the framework-first trio: *structures vendor-branding* (folders naming products — diagrams centering boxes (bias owning — policy whispering (branding billing — direction breaking); *cores importing* (frameworks drilling — SDKs arriving (vendors owning — policy obeying (importing billing — leverage inverting); *choices earlying* (products selecting — options dying (lock-in scheduling — migrations fearing (early costing — flexibility ending). Deferred details converting vendor-first to policy-first (frameworks edging — vendors plugging (cores ruling — choices delaying); reviewers finding framework names only at edges per app (deferring proving → verifiable; branding → returned).

**Modern guidance** — the deferring lines per framework (review-enforced): *frameworks edging* (adapters owning — protocols serving (cores ignoring — centering declining (edging proving — branding ending (edges owning — cores ruling); *vendors plugging* (details serving — products obeying (cores deciding — dictating ending (plugging funding — earlying declining (options keeping — dread ending); *cores ruling* (policies owning — decisions holding (leverage keeping — obeying declining (ruling proving — importing refusing (centrality owning — inversion declining).

```typescript
// GOOD: details deferring — one core commanded by CLI-shape and HTTP-shape identically (compiled + run live).
class Double { // core ruling — policies owning, frameworks unknown
  run(n: number): number {
    if (n < 0) throw new Error('n >= 0 required');
    return n * 2;
  }
}
function cliEdge(core: Double, argv: string[]): number { // edge one — CLI translating, core ignoring
  return core.run(Number(argv[0]));
}
function httpEdge(core: Double, body: { n: number }): { doubled: number } { // edge two — HTTP translating, core ignoring
  return { doubled: core.run(body.n) };
}
const core = new Double();
console.log(cliEdge(core, ['21']) === 42 && httpEdge(core, { n: 21 }).doubled === 42 ? 'details defer' : 'frameworks center');
```

**Common confusion** — *"deferral means no frameworks (purity absoluting)."* Deferral placing frameworks (edges owning — adapters serving (cores ignoring — policy deciding (placing funding — centering declining); purity banning tools (libraries refusing — work rebuilding (absoluting serving — value missing (banning charging — pragmatism declining). "No frameworks" describing refusal (tools banning — work rebuilding); deferral describing placement (edges owning — cores ruling). Place frameworks (edges owning — adapters serving); rule cores (policies owning — leverage keeping).

**Performance note** — deferring economics: edging costing adapters (protocols serving — cores ignoring (choices delaying — options keeping); centered equivalents costing lock-in (migrations fearing — upgrades dictating (choices earlying — flexibility ending). Edge cheaply (adapters — frameworks); center never (vendors — policy).

**Mentor note** — teach "frameworks at edges, policy at center" (juniors edging one framework per adapter design vendor-deferred apps on first hearing; framework-centered cores interrogated ("which edge?" — deferring demanding per import). Defer one framework once (edges owning — cores ruling tangible (branding ending — choices proving delayed permanently). Edge details; rule cores — deferring discipline in three habits, reviewed per framework.

## 2. Plugins swapping (adapters exchanging — contracts holding — options keeping)

**Definition** — plugin swapping: vendors exchanged behind stable contracts via registration (adapters exchanging — products trading (details deferring — cores ignoring (exchanging proving — hardwiring declining); contracts holding — suites asserting (behaviors matching — drifts detecting (holding funding — breaking declining); options keeping — choices delaying (migrations boring — upgrades fearless (keeping proving — locking declining).

**What problem it solves** — the hardwired trio: *vendors importing* (products concreting — cores editing (migrations fearing — upgrades pinning (importing billing — flexibility dying); *contracts unheld* (behaviors assuming — swaps hoping (suites missing — confidence absenting (unheld charging — lock-in hardening); *options expiring* (choices earlying — decisions fossilizing (alternatives dying — leverage inverting (expiring costing — dread funding). Swappable plugins converting hardwiring to registration (adapters exchanging — contracts holding (options keeping — rewrites declining); reviewers swapping vendors per config per suite (swapping proving → verifiable; hardwiring → returned).

**Modern guidance** — the swapping lines per vendor (review-enforced): *adapters exchanging* (products trading — details deferring (cores ignoring — hardwiring declining (exchanging proving — importing refusing (trading earning — locking declining); *contracts holding* (suites asserting — behaviors matching (drifts detecting — breaking declining (holding funding — hoping ending (suites owning — fear declining); *options keeping* (choices delaying — migrations boring (upgrades fearless — locking declining (keeping proving — expiring refusing (flexibility owning — dread ending).

```typescript
// GOOD: plugins swapping — Nest registering vendors behind one token, both serving (compiled + run live).
import 'reflect-metadata';
import { Controller, Get, Inject, Injectable, Module } from '@nestjs/common';
import { NestFactory } from '@nestjs/core';
import { FastifyAdapter } from '@nestjs/platform-fastify'; // Fastify underneath — adapter stated, Express declining

interface Counter { // contract holding — suites asserting, behaviors matching
  add(n: number): void;
  total(): number;
}

@Injectable()
class MemoryCounter implements Counter { // plugin one — adapters exchanging, cores ignoring
  private sum = 0;
  add(n: number): void { this.sum += n; }
  total(): number { return this.sum; }
}

@Injectable()
class FlooredCounter implements Counter { // plugin two — products trading, hardwiring declining
  private sum = 0;
  add(n: number): void { this.sum += Math.max(n, 0); }
  total(): number { return this.sum; }
}

@Injectable()
class Tally { // core deciding — ports importing, vendors unknown
  constructor(@Inject('COUNTER') private readonly counter: Counter) {}
  run(): number {
    this.counter.add(5);
    return this.counter.total();
  }
}

@Controller('tally')
class TallyController {
  constructor(private readonly tally: Tally) {}
  @Get()
  go(): object { return { total: this.tally.run() }; }
}

@Module({ controllers: [TallyController], providers: [Tally, MemoryCounter, { provide: 'COUNTER', useClass: MemoryCounter }] })
class MemoryApp {} // registration owning — adapters exchanging, options keeping

@Module({ controllers: [TallyController], providers: [Tally, FlooredCounter, { provide: 'COUNTER', useClass: FlooredCounter }] })
class FloorApp {}

async function prove(mod: new () => unknown): Promise<string> {
  const app = await NestFactory.create(mod, new FastifyAdapter());
  await app.init();
  const http = app.getHttpAdapter().getInstance() as any; // inject proving — instance driving, ports skipping
  const res = await http.inject({ method: 'GET', url: '/tally' });
  await app.close();
  return res.body;
}

async function run(): Promise<void> {
  const a = await prove(MemoryApp);
  const b = await prove(FloorApp);
  console.log(a === '{"total":5}' && b === '{"total":5}' ? 'plugins swap' : 'vendors hardwire');
}
run();
```

## 3. Cores ruling (policies deciding — ignorance keeping — leverage holding)

**Definition** — ruling cores: policy independence surviving framework upgrades (policies deciding — rules owning (flows composing — vendors ignoring (deciding proving — obeying declining); ignorance keeping — frameworks unknown (vendors unheard — details deferred (keeping funding — heaviness declining); leverage holding — upgrades edging (changes localizing — rewrites declining (holding proving — inverting ending).

**What problem it solves** — the upgrade-dictated trio: *upgrades rewriting* (versions bumping — cores editing (migrations fearing — features pausing (rewriting billing — leverage inverting); *leverage inverting* (vendors deciding — policy obeying (tails wagging — dogs following (inverting charging — centrality declining); *independence unproven* (cores untested-alone — frameworks required (policy hoping — ignorance bluffing (unproven costing — ruling declining). Ruling cores converting dictating to edging (policies deciding — ignorance keeping (upgrades localizing — rewrites declining); reviewers upgrading frameworks without touching cores per release (ruling proving → verifiable; rewriting → returned).

**Modern guidance** — the ruling lines per core (review-enforced): *policies deciding* (rules owning — flows composing (vendors ignoring — obeying declining (deciding proving — dictating refusing (centrality owning — inversion declining); *ignorance keeping* (frameworks unknown — vendors unheard (details deferred — heaviness declining (keeping funding — creeping ending (purity owning — polling declining); *leverage holding* (upgrades edging — changes localizing (rewrites declining — inverting ending (holding proving — dictating declining (options keeping — dread ending).

// GOOD: cores ruling — framework upgrade swapping adapters, core untouched and identical (compiled + run live).
class Total { // core ruling — policies deciding, ignorance keeping
  sum(lines: number[]): number {
    return lines.reduce((a, b) => a + b, 0);
  }
}
function adapterV1(core: Total, raw: string): number { // edge one — frameworks edging, upgrades localizing
  return core.sum(raw.split(',').map(Number));
}
function adapterV2(core: Total, parsed: { lines: number[] }): number { // edge two — changes localizing, rewrites declining
  return core.sum(parsed.lines);
}
const core = new Total();
const a = adapterV1(core, '10,20,30');
const b = adapterV2(core, { lines: [10, 20, 30] });
console.log(a === 60 && b === 60 ? 'cores rule' : 'upgrades rewrite');
