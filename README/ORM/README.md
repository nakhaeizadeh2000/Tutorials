# ORM track (recommended order, September 2026 era)

Data access for huge apps — Prisma, TypeORM, and Drizzle from foundations to production: patterns, migrations, relations, performance, and choosing wisely — from zero to hero and beyond (junior to mentor depth). Hands-on Postgres & Mongo *usage* lives in the [Databases track](<../Databases/README.md>); schema *design* lives in the [Database Design track](<../DatabaseDesign/README.md>); raw driver mechanics live in Databases 04. This track assumes working SQL and teaches *data-access layers*: what each tool owns, costs, and deserves. Version-sensitive claims are labeled (as of September 2026: Prisma 7.10.0 stable with v8.0.0-rc.19 prerelease tagged `latest`; TypeORM 1.1.1 stable; Drizzle 0.45.3 stable with 1.0.0-rc in prerelease).
