# 4.1. Mentor checklist for the whole track

## 1. Teaching order is the track order (foundations before tools, tools before operating)

**Definition** — the pedagogical contract: teach domains in track order (01 foundations → 02–04 tools → 05 selection → 06 operations → 07 synthesis) because each layer assumes the last (tool mechanics assume layer judgment (strategies/patterns/ledgers — unplaced tools operated blindly); selection assumes tool mechanics (positions mapped per lived behavior — unoperated tools compared theoretically); operations assume selections (pools/gauges/upgrades per chosen tool — verdicts unexamined (misconfigured operations). Reordering breaks prerequisites silently (tools before foundations — magic without jurisdictions (convenience without economics — surprises scheduled); selection before mechanics — verdicts without evidence (fashion compared — misfits scheduled); operations before selection — gauges without verdicts (monitoring unowned tools — orphaned metrics).

**What problem it solves** — the two sequencing failures: *tools-first* (Prisma on day one — generated clients operated without layer judgment (flat workloads under ceremony (jurisdiction unexamined); N+1 unstrategized (detectors unknown — linearities scheduled); magic uninventoried (defaults flipping silently — surprises paging); and *selection-first* (comparison tables before mechanics (positions memorized — jurisdictions unmapped (workloads unexamined — fashion compared, not fitness); ledgers unpriced (costs unknown — bills arriving quarterly). Tools-first produces fluent fragility (syntax without judgment — incidents scheduled per unexamined layer); selection-first produces confident misfits (verdicts without mechanics — mismatches scheduled per unoperated tool). Sequence builds judgment before fluency, fluency before verdicts, verdicts before operations — competence compounding per layer, never skipping.

**Modern guidance** — the teaching calendar (per learner or cohort, paced by mastery not weeks): **01** until layers/patterns/ledgers fluent (layer placed per feature + N+1 counted + seam honored — graduation test below); **02–04** until one tool operated deeply each (Prisma includes stated + TypeORM relations batched + Drizzle composition safe — mechanics lived, magic inventoried per tool); **05** until verdicts priced (positions mapped per workload — triggers dated — revisits calendared); **06** until operations owned (pools sized, transactions bounded, gauges dashboarded, upgrades rehearsed); **07** capstone + interviews (method performed whole — graduation). Gate advancement per domain (tests next promise — demonstrable, never self-assessed); revisit earlier layers when later layers wobble (unstrategized queries → re-drill 01 detector — foundations, not remediation-shame).

```typescript
// GOOD: the ordered curriculum — prerequisites chained, gates enforced (excerpt).
// Week 1-2: 01 (layers/patterns/ledgers — graduate: place tool per feature + count N+1 + honor seam).
// Week 3-5: 02–04 (one tool deeply each — graduate: includes stated + relations batched + composition safe).
// Week 6: 05 (selection — graduate: positions mapped + ledgers priced + triggers dated).
// Week 7-8: 06 (operations — graduate: pools sized + transactions bounded + gauges owned + upgrades rehearsed).
// Week 9: 07 (capstone + interviews — graduate: traveling answer + incident parables).
// Gates enforced (demonstrable per domain); wobbles recurse (later confusion → earlier drill).
```

```typescript
// BAD: the shuffled curriculum — prerequisites assumed, foundations missing (real shapes).
// Week 1: Prisma (generated clients operated without layer judgment (flat workloads under ceremony —
// jurisdiction unexamined; N+1 unstrategized (detectors unknown — linearities scheduled).
// Week 2: selection (verdicts without mechanics (positions memorized — tools unoperated (magic
// uninventoried — surprises paging). Week 3: interviews (traveling answers without lenses visited —
// vocabulary parade). Operations/volume/evolution: skipped ("advanced" — deferred forever — pools
// defaulted, upgrades unrehearsed, gauges absent). Order shuffled; prerequisites voided;
// competence fragmented. Fast calendar, hollow graduates.)
```

**Common confusion** — *"experienced engineers can start anywhere (skip 01–02)."* Experience self-assessed misleads (seniors "knowing ORMs" who can't state loading strategies (fluency without judgment — magic unexamined); placement by demonstration (graduation tests per domain — test out by performing, never by asserting seniority — staff engineers whiteboarding layer placement gladly, juniors attempting fearlessly). Test-out honors experience (fast passage for fluent performers — no condescension, pure demonstration); self-placement honors confidence (uncorrelated with competence — Dunning-Kruger scheduled as curriculum without gates). Demonstrate, don't assert — placement by performance, all levels, no exceptions.

**Performance note** — ordered-teaching economics: prerequisites chained (each layer practiced on previous outputs — learning efficiency maximized — handoffs learned as method); gates enforced (demonstrable advancement — no hollow graduates consuming senior review cycles re-teaching foundations); wobbles recursed (later confusion → earlier drill — targeted remediation, not course repetition — coaching precise, time bounded). Shuffled teaching costs re-teaching (foundations retaught per advanced confusion — mentor-hours burning); gated ordering costs tests (minutes per gate — cheapest assessment available). Order once; gate always; recurse precisely.

**Mentor note** — protect sequence against impatience (learners rushing to tools/interviews ("boring basics" — skipping to fun parts); managers compressing calendars ("two-week ORM course" — seven domains in ten days — fragments guaranteed). Impatience accommodated via test-outs (fluent performers advance fast — demonstrated, never asserted — speed earned, not granted); impatience indulged via skipping produces hollow graduates (fast calendar, failing interviews, incidents scheduled). Pace by mastery (gates enforced), accelerate by demonstration (test-outs honored), never by assertion (confidence uncalibrated). Sequence protected; mastery gated; graduates genuine.

## 2. Drills per domain, capstones across (timed narrations + integrated exercises)

**Definition** — the two drill tempos (mirroring review cadence from [1.2](<../1. Track synthesis/1.2. Review as a practice across tools.md>)): **per-domain drills** (timed narrations — jurisdictions/prices/triggers performed live per domain §5.1 — minutes each, weekly during that domain — fluency built); **cross-domain capstones** (integrated exercises — one feature through all lenses — quarterly or per-milestone — composition built). Drills train moves (derivation reflexes — layer placed, strategy stated, verdict priced — automatic under time pressure); capstones train performance (whole method under observation — layers sequenced, transitions narrated, handoffs honored). Moves without performance fragment (brilliant drills, uncomposed features); performance without moves collapses (capstones attempted without drill fluency — slow, silent, ungraded).

**What problem it solves** — the two training failures: *drill-only fluency* (timed placements perfected — capstone never attempted — moves uncomposed (features decided single-layered despite drill mastery — transfer absent — practice-theoretic, production-fragmented)); and *capstone-only ambition* (integrated exercises assigned without drill foundations — slow silent struggles (no jurisdictions to place, no prices to compute — capstones attempted vocabulary-first, failing comprehensively, discouraging deeply). Drills-then-capstones sequences both (moves automatic before performance demanded — fluency preceding composition, confidence built on competence). Training like athletics (drills daily, games weekly — moves before matches, always); unlike academia (lectures then finals — knowledge tested unperformed — the failure mode this track exists to prevent).

**Modern guidance** — the drill calendar (per domain during its weeks, capstones at milestones): *drills* (each domain §5.1's timed narrations — 90-second verdicts, 5-minute whiteboards, 3-minute estimations — rehearsed weekly — times recorded (fluency measurable — rehearsal times dropping = readiness rising)); *capstones* (one feature, six lenses — [1.1](<../1. Track synthesis/1.1. The data-access method end to end.md>)'s procedure — quarterly per team, monthly per learner in intensive programs — reviewed layer-by-layer (gaps located precisely — targeted drill follow-ups prescribed)); *progression* (drill times gate capstone readiness (fluent moves → attempt performance); capstone gaps gate drill focus (wobbled layer → drill that domain — targeted, never generic "study more")). Fluency measured (times), composition witnessed (reviews), gaps prescribed (drills) — training engineered, not hoped.

```typescript
// GOOD: training engineered — drills timed, capstones witnessed, gaps prescribed (excerpt).
// Drills (weekly per domain): placements 90s (01), verdicts 90s rapid-fire (05), estimations 3min live (05),
// claim-writing 90s (Drizzle/claim analogues — timed per tool domain 02–04).
// Capstones (quarterly): order-API feature, six lenses, reviewed layer-by-layer —
// gaps located ("tools solid, gauges unowned" → prescribed (drill 06/5.1 × 3 rounds).
// Progression: drill fluency → capstone attempt → gap prescription → drill focus → re-attempt.
```

```typescript
// BAD: training hoped — lectures attended, finals feared, transfer absent (real shapes).
// Lectures (seven domains presented — attendance recorded, comprehension unmeasured).
// Finals (capstone assigned cold — no drill foundations — slow silent struggles graded
// harshly — discouragement, not diagnosis). Gaps undescribed ("study data access more" —
// generic, unactionable — learners re-reading randomly, improving accidentally).
// Drills absent (moves unpracticed — jurisdictions unplaced under pressure); capstones rare
// (composition unattempted — fragments uncomposed). Attended thoroughly; learned thinly.
```

**Common confusion** — *"drills are interview prep, not engineering training."* Drills train derivation reflexes (placements/prices/triggers under time pressure — the same reflexes production incidents demand (outage diagnosis timed, migration decisions pressured, launch reviews hurried — speed with method, always). Interview performance is a *side effect* of operational reflexes (candidates performing method briskly under interview pressure perform it identically under incident pressure — interviewers selecting for production traits via timed exercises, correctly). Train reflexes for production (incidents, launches, reviews — timed realities); collect interviews as bonus (same reflexes, friendlier stakes). Drills serve on-call first, hiring second — both well.

**Performance note** — training economics: drills cost minutes weekly (timed narrations — cheapest fluency available — rehearsal times as readiness metrics, free); capstones cost hours quarterly (integrated exercises — diagnosis complete — gaps located precisely, coaching targeted); unpracticed incidents cost quarters (derivation under pressure without reflexes — slow, silent, wrong — production grading the untrained). Drill minutes prevent incident quarters — the steepest training ROI in engineering (minutes-to-quarters ratio exceeding 1000× on first prevented repeat — stated finally, track nearly complete).

**Mentor note** — run drills visibly (mentors performing timed narrations first — authority demonstrating fluency, not just demanding it — "watch me place tools in 90 seconds" teaches more than "practice placements"). Time learners kindly (records, not rankings — fluency personal, improving — never leaderboards (competition poisons practice — anxiety replacing fluency — drill culture dies with first ranking). Witness capstones thoroughly (layer-by-layer reviews — gaps prescribed precisely — coaching targeted, morale preserved (gaps normal, prescription clear, progress visible). Demonstrate, time kindly, witness thoroughly, prescribe precisely — mentorship in four verbs, track nearly complete.

## 3. Graduation tests gate advancement (demonstrable, never self-assessed)

**Definition** — the gates: per-domain graduation demonstrations (01: place tool per feature + count N+1 + honor seam; 02: schema + relations + strategies stated; 03: entities + flavors + migrations witnessed; 04: tables + composition + relations triple-complete; 05: positions mapped + ledgers priced + triggers dated; 06: pools sized + transactions bounded + gauges owned + upgrades rehearsed; 07: traveling answer + incident parables) — performed live before a mentor (or recorded for review — async acceptable, unwitnessed unacceptable), judged pass/retry (retry with prescribed drills — never fail-and-abandon — gaps coachable, always). Self-assessment ("I know Drizzle") gates nothing (confidence uncalibrated — Dunning-Kruger scheduled as curriculum without gates); demonstration gates everything (performed method — witnessed, judged, recorded).

**What problem it solves** — the two advancement failures: *time-served advancement* (weeks completed → next domain unlocked — attendance mistaken for competence — hollow graduates accumulating (fragments per domain, composition never — advancing calendar, stagnant capability)); and *confidence-based advancement* ("I got it" → skip drills → next domain — self-assessment uncalibrated (overconfident advancing hollow; underconfident stalling despite fluency — both miscalibrated, both ungated). Gates convert advancement to evidence (demonstrated method per domain — witnessed fluency, recorded progression); retry converts failure to prescription (gaps located → drills assigned → re-attempt scheduled — failure as diagnosis, never verdict). Advancement earned visibly; retry coached precisely; competence compounded genuinely.

**Modern guidance** — the gate contract per domain (demonstration + judge + retry): *demonstrate* (domain's graduation test performed live — timed per §5.1 prescriptions — transitions narrated, prices computed, artifacts shown — complete performance, not fragments); *judge* (mentor passes or prescribes (pass: advance; retry: gap located + drills assigned + re-attempt dated — binary with prescription, never vague "needs work")); *record* (pass logged with date + evidence link (recording/transcript — institutional memory of competence — staffing decisions informed (who's fluent where — project assignment by demonstrated capability, not claimed)); *retry kindly* (gaps normal — prescription clear — re-attempt scheduled within two weeks — momentum preserved, shame absent — retry culture (failing forward visibly) beats pass culture (advancing hollowly)). Gates enforced (unskippable — even staff engineers demonstrate (gladly — fluency performs fast)); retries bounded (three attempts → coaching conversation (method mismatch? motivation? — humane inquiry, never bureaucratic loop)).

```typescript
// GOOD: gates evidenced — demonstrations witnessed, retries prescribed, competence recorded.
// 01 gate: place tool + count N+1 + honor seam (passed 2026-10-14 — recording linked).
// 04 gate: tables + composition + triple-complete relations (retry 1: registration missed → drill 04/1.2 ×3 →
// retry 2 passed — gap closed measurably). 06 gate: pools sized + gauges owned (passed).
// Staffing: project X needs Drizzle fluency → assignees 04-passed (capability-matched).
// Retries: kind, bounded, prescriptive (failure as diagnosis — culture learning, never shaming).
```

```typescript
// BAD: advancement assumed — attendance logged, competence hoped (real shapes).
// Week 4 complete → 05 unlocked (03 graduation: unattempted — flavors unplaced, strategies unstated —
// advancing hollow). "I know joins" → 04 skipped (composition untested — dynamics concatenated in
// production). Senior joins → placed advanced (asserted fluency — untested — mentoring juniors in
// fragments while missing relations personally). Retries: none (failure unacknowledged — gaps invisible —
// hollow compounding). Attendance itemized; competence absent; advancement automatic. Graduates certified;
// capabilities fictional.
```

**Common confusion** — *"gates slow down fast learners."* Gates *accelerate* fluent performers (demonstration takes minutes for the fluent — test-outs honored immediately — speed earned visibly) while *protecting* teams from hollow advancement (ungated confidence advancing gaps that consume senior review cycles re-teaching foundations — quarters of drag per hollow graduate). Fast learners love gates (showcase fluency, advance rapidly — recognition); hollow advancers fear them (exposure — correctly, kindly, with prescription). Gate speed correlates with fluency (fast passes for the fluent — the system rewarding competence with velocity). Slow down the hollow; speed up the fluent — gates do both simultaneously, automatically.

**Performance note** — gate economics close the track's training argument finally: gates cost minutes per demonstration (mentor time — the scarcest teaching resource, spent precisely on witnessed performance); ungated advancement costs quarters (hollow graduates consuming reviews, scheduling incidents, requiring remediation — expensive, diffuse, unbounded). Retry prescriptions cost drill rounds (targeted, bounded — gaps closing measurably); unprescribed failure costs abandonment (learners stalling silently — talent lost, morale damaged). Minutes of witnessing prevent quarters of hollowness — assessment ROI exceeding all other teaching investments (witnessed competence compounds; assumed competence decays). Gate always; retry kindly; record permanently.

**Mentor note** — celebrate passes publicly (graduation acknowledged — team visibility for demonstrated fluency — recognition motivating more than mandates ever could); normalize retries privately-kindly (retry framed as prescription ("relations triple needs drills — three rounds, re-attempt Friday" — diagnosis + plan + date — failure without shame, progress without doubt). Never weaponize gates (advancement withheld punitively — gates as control — culture poisoned instantly, permanently); always wield educationally (gates as diagnosis — competence mapped, coaching targeted — culture learning, durably). Celebrate passes; normalize retries; wield educationally — mentorship's closing verbs, track nearly complete.
