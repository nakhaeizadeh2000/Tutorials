**Definition** — the exercise: *"connections refused under load — diagnose live"* (the operations filter). **What problem it solves** — pool questions filter for operations maturity (most candidates answer configurationally ("increase max" — multiplication unexamined (limits exceeded further — refused connections multiplying (more clients hammering saturated database — contention worsening); waits unasked (infinite hangs persisting — gateway timeouts continuing); statements unexamined (runaways holding — starvation persisting). ## 2. N+1 in production (triage shape — counts, strategies, prevention — the three-beat answer)

Count-fix-prevent with *staging-vs-production framing* (scale explaining the discrepancy — fixtures vs data — measurement closing the gap permanently).

**What problem it solves** — production-N+1 questions filter for scale thinking (most candidates answer configurationally ("add caching" — bandaging uncounted N+1 (stale data serving linear queries faster — wrongness accelerating, not fixed); "add indexes" — tuning uncounted N+1 (lookups optimized individually — N+1 intact (50k statements, each fast — slowness structural (counts unexamined — tuning what should be batched). Scale-named, batch-fixed, immunity-designed.

## 3. Upgrade a major safely (rehearse, canary, roll back — operations answers, not version notes)

**Definition** — the closer: *"Prisma 8 goes stable — how do we upgrade?"* (the operations filter). The graded answer rehearses-then-canaries-then-rolls-back (inventory breaking changes (defaults/idioms/APIs — changelog read fully — surprises listed); rehearse on staging (gauges compared pre/post — N+1 counts, slow rates, error budgets — deltas investigated); canary service-by-service (blast radius bounded — gauges compared per wave — promotion gated on evidence); roll back rehearsed (downgrade proven — reversibility demonstrated, never hoped); ledgers re-priced (generation/strategies/magic costs presently priced — stale prices retired). Rehearse/canary/rollback/re-price — operations maturity in four verbs, performed under questioning.

**What problem it solves** — upgrade questions filter for change judgment (most candidates answer configurationally ("bump the version, run tests" — green tests asserting old behaviors (new defaults unexamined — strategies un re-audited (N+1 appearing post-upgrade — magic uninventoried (gauges dead — v7 lesson unapplied (surprises repeating per major — history unlearned); canary absent (flag-day upgrades — blast total (failures fleet-wide — rollback unknown (downgrade untested — stranded versions (forward-fix under fire). Rehearsed/canaried/rollback-proven/re-priced upgrades convert surprises to findings (staging surfacing breakage calmly — gauges verified continuously — ledgers current presently — rollbacks proven preemptively).

**Modern guidance** — the two-minute shape: (1) *inventory* (30s — breaking changes listed (defaults/idioms/APIs — N+1 posture? gauge idioms? magic defaults? — impact priced per change); (2) *rehearse* (30s — staging upgraded (production-shaped data/load — gauges compared (deltas investigated — regressions fixed pre-production); (3) *canary* (30s — service-by-service (blast bounded — gauges compared per wave — promotion gated on evidence (green canaries — schedule serving safety); (4) *roll back + re-price* (30s — downgrade rehearsed (reversibility proven — failed upgrades reverting cleanly); ledgers re-priced (costs current — stale prices retired). Inventory → rehearse → canary → rollback/re-price (operations maturity, performed under questioning — drama declined structurally).

**Common confusion** — *"green tests mean safe upgrades (CI passing suffices)."* Tests assert *old* behaviors (written against previous defaults — passing irrelevantly post-change (strategies unexamined (new defaults untested — coverage green on stale assumptions); gauges unwired to new idioms (counters testing removed APIs (passing vacuously — observability dead silently); flags unexamined (new behaviors untested (default paths uncovered — surprises scheduled). "Green" describes old-behavior conformance (regression absent for tested paths); safety requires new-behavior examination (defaults re-listed, gauges re-verified, flags reviewed — audit beyond green). Green necessary (regressions caught); insufficient alone (novelties unexamined). Green + audit; never green-alone (restated from 06/2.1 — permanent value).

**Performance note** — close with upgrade economics ("rehearsal hours prevent incident quarters (staging surfacing breakage calmly — findings cheap, drama declined); canary days bound blast radius (bounded waves — failures contained); rollback rehearsals prevent stranded versions (reversibility proven — forward-fix-under-fire declined); ledger re-pricing prevents stale decisions (costs current — mismatches preempted).
