## 2. Changing tools

### [2.1. Migrating between tools](<./sections/2. Changing tools/2.1. Migrating between tools.md>)

1. **Triggers fire first** (misfit measured — ceremony/toil/coupling billed quarterly — migrate on evidence)
2. **Strangler pattern applies** (new features on new tool, old paths migrated per touch — both live, contracts stable)
3. **Schemas migrate once** (single DDL history continuous — tools project it differently, never fork it)

---

### [2.2. Polyglot persistence honestly](<./sections/2. Changing tools/2.2. Polyglot persistence honestly.md>)

1. **Two tools maximum per service** (cognitive budget bounded — third tool justified like architecture)
2. **Boundaries documented per tool** (which tables/queries each owns — overlap forbidden structurally)
3. **Shared types cross boundaries** (domain types owned once — mappers translating to them, never defining)

## 3. Measurement honesty

### [3.1. Benchmarks that inform (and deceive)](<./sections/3. Measurement honesty/3.1. Benchmarks that inform (and deceive).md>)

1. **Measure your workload** (your queries, your data, your concurrency — vendor benchmarks inform never)
2. **Count statements first** (N+1 dominates all micro-differences — batching decided before benchmarking)
3. **Micro-benchmarks deceive systematically** (hello-world ORM shootouts — unrepresentative by construction)
