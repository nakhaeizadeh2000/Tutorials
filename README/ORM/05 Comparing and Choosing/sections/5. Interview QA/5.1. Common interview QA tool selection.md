# 5.1. Common interview QA tool selection

## 1. Place three tools live (positions, matches, triggers — ninety seconds, fashion absent)

**Definition** — the exercise: *"Prisma, TypeORM, or Drizzle for our API?"* (the fashion trap, interviewed). The graded performance is positions-matches-triggers in ninety seconds (positions stated (Prisma graphs+greenfield+types; TypeORM classes/legacy/both-flavors; Drizzle SQL-control+dynamics+thin — positions from [Domain 01 §2.1](<../../01 Data Access Foundations and Mental Model/sections/2. Mapping patterns/2.1. ActiveRecord versus DataMapper.md>), performed from memory); matches argued (workload examined live — graphs/dynamics/flatness classified on the spot — tool per center, never per fashion); triggers dated (graphs past 2 relations → re-evaluate; majors → ledger re-price; yearly revisits calendared — verdicts temporary, correct for current context).

**What problem it solves** — the podium answer (one winner, all workloads — fashion stated ("Prisma is modern" — context unexamined — mismatches scheduled (flat admin tools under ceremony; dynamic reports under graph mappers; legacy classes unmigrated); triggers absent (verdicts permanent — misfits compounding silently). Positioned answers signal senior judgment (tools serving workloads — triggers dating verdicts); podium answers signal tribalism (tools serving fashion — verdicts tattooed). Match per feature, default per team, revisit yearly — complete selection judgment in ninety seconds.

**Modern guidance** — the ninety-second shape: (1) positions stated (30s — three tools, one line each (graphs/classes/dynamics — jurisdictions mapped — fashion absent); (2) workload matched (30s — graphs + greenfield + typed API → Prisma (graphs earn mappers); admin dynamics → Drizzle (dynamics earn builders); legacy classes → TypeORM (idioms honored); flat remainder → typed raw (ceremony declined); (3) triggers dated (30s — graphs past 2 relations re-evaluate Prisma anywhere; Prisma 8 RC watch → yearly ledger re-price; team default Drizzle (exceptions filed with reasons). Positions, matches, triggers — ninety seconds, fashion absent, judgment present.

```typescript
// GOOD (spoken, 90 seconds — positions, matches, triggers):
// "Positions: Prisma graphs+greenfield+types; TypeORM classes/legacy/both-flavors; Drizzle
// SQL-control+dynamics+thin. This API (order graph, 12 relations, greenfield): Prisma
// (graphs earn mappers — explicit includes, migration tooling, end-to-end types). Admin lists
// alongside: Drizzle (dynamics earn builders — flat shapes decline mappers). Triggers: graphs
// past 2 relations re-evaluate Prisma anywhere; Prisma 8 RC watch → yearly ledger re-price;
// team default Drizzle (exceptions filed with reasons). Matched per feature, defaulted per team,
// revisited yearly. Fashion absent; judgment present."
```

```typescript
// BAD (spoken): the podium answer — one winner, all workloads, fashion stated.
// "Prisma — it's the modern standard, best DX." (Graphs? Unasked (flat admin tools under
// ceremony — build seconds per trivial change). Dynamics? Unasked (hand-tunable reports under
// graph mappers — control surrendered). Legacy/classes? Unasked (idioms ignored). Triggers?
// Absent (verdicts permanent — misfits compounding silently). Podium stated; workloads unexamined;
// mismatches scheduled. Winners hire nowhere senior — matches hire everywhere. Positions, not podiums.)
```

**Common confusion** — *"knowing all three tools is expected (depth everywhere)."* Foundations expected (patterns in Domain 01 — tool-agnostic, learned once); one tool deeply (daily driver — complete fluency — hired competence); others positionally (placed accurately — jurisdictions + triggers — selection judgment). "All three deeply" is staff scope (leads choosing stacks — breadth earned over years); "one deeply + positions" is senior scope (the interview's actual bar — depth demonstrated, breadth mapped). Depth + positions hire seniors; foundations + one depth hire mids. Calibrate scope honestly; place accurately always.

**Performance note** — volunteer placement economics ("matched tools perform natively (strategies fitting workloads — N+1 preventable, SQL tunable, ceremony justified); mismatched tools bill quarterly (ceremony without graphs, toil without control — misfit taxes recurring)"). Economics with triggers (revisit dates — versions moving, workloads shifting — placements living documents, never tattoos). Unvolunteered economics invites "at scale?" probing (reactive answers scoring lower). Volunteer economics; preempt probing.

**Mentor note** — teach positions, not preferences (juniors placing tools per workload shape (graphs/flat/dynamics — with reasons stated) decide reviewably; juniors preferring tools per vibes decide tribally (fashion defended passionately, workloads unexamined). Preference interrogated ("why Prisma here?" — flat workload answer exposing fashion instantly); positions drilled (rapid-fire placements — tool + reason + trigger — fashion failing visibly under time pressure). Positions drilled; preferences interrogated; fashion retired. Place deliberately; prefer never.

## 2. Defend a migration (evidence, strangler plan, rollback — judgment performing under questioning)

**Definition** — the follow-up: *"we're on X, should we move to Y?"* (the migration filter). The graded answer leads with evidence (measured misfit — ceremony/toil/coupling quantified with sources (build logs, incident counts, suite timings — numbers, not adjectives); proposes strangler execution (new-on-target, touch-migrated, seams stable, deadline dated — [2.1](<../2. Changing tools/2.1. Migrating between tools.md>) performed); names rollback per path (revert touched feature, not whole system — reversibility designed, never hoped); preserves schema continuity (single DDL history, baselined honestly — tools projecting, never forking). Evidence + strangler + rollback + continuity — judgment performing under questioning, all four evidenced.

**What problem it solves** — migration questions filter for change judgment (most candidates answer tribally ("migrate — new tools better" — fashion forward, evidence absent; or "never migrate — stability" — comfort backward, misfits unexamined). Interviewers listen for triggers (misfit measured — numbers cited — evidence over hype/comfort); execution shape (strangler vs big-bang — reversibility designed — risk managed); history honesty (schemas baselined — continuity preserved — truth singular). Tribal answers signal fashion/comfort (unmeasured, unscheduled); evidenced answers signal senior judgment (measured misfits, strangler plans, rollback paths, continuous histories).

**Modern guidance** — the two-minute shape: (1) *evidence* (30s — misfit measured (ceremony/toil/coupling quantified with sources — numbers cited (build-minutes, incident counts — evidence, never vibes); (2) *strangler* (45s — new-on-target (greenfield correct from birth); touch-migrated (boy-scout layers — migration amortized); seams stable (contracts unchanged — policy green throughout); deadline dated (dual-run bounded — fossilization declined); (3) *rollback* (15s — revert touched path (reversible per feature — big-bang rejected (all-or-nothing cutover — failure catastrophic); (4) *continuity* (30s — single DDL history (baselined honestly — tools projecting, never forking — reproducibility intact). Evidence, strangler, rollback, continuity — migration complete, judgment performed.

```typescript
// GOOD (spoken, 2 min — evidence, strangler, rollback, continuity):
// "Evidence: generation 12 build-min/day on flat shapes (measured CI logs — ceremony quantified);
// toil unmeasured? No — hand-mapping graphs would cost more (staying correct here — evidence cuts
// against migration (stasis justified — triggers monitored, dormant). Hypothetically firing:
// strangler (new-on-target, touch-migrated, seams stable, deadline Q3); rollback per path
// (revert touched feature — big-bang rejected); continuity (single DDL history, baselined).
// Evidenced (numbers cited); executable (strangler planned); reversible (rollback designed)."
// (Note honesty: evidence may argue stasis — triggered migration, never fashionable migration.)
```

```typescript
// BAD (spoken): the fashionable migration — evidence absent, execution big-bang, history forked.
// "Move everything to X (modern, fast)." (Evidence? Absent (misfit unmeasured — working tools
// replaced — quarters billed, benefits zero). Execution? Big-bang (flag-day tool switch — branches
// diverging for months; rollback impossible (all-or-nothing — failure catastrophic). History?
// Forked (fresh migrations from empty — reproducibility void — truth plural). Fashion forward;
// evidence absent; reversibility none; continuity broken. Migrate never on these terms.)
```

**Common confusion** — *"defending stasis looks unambitious (migrate to impress)."* Stasis on evidence impresses (triggers monitored, dormant — misfit absent — migration correctly declined — judgment performing (restraint priced identically to action); migration on fashion exposes (evidence absent — quarters billed for novelty — ambition theatrical, not engineering). "Ambitious" describes impact (misfits fixed where measured — genuine improvements shipped); fashion describes motion (tools changed — velocity theatrical). Impress with evidence (measured stasis defended brilliantly outscores fashionable migration); never with motion (motion without misfit is toil wearing ambition).

**Performance note** — volunteer migration economics ("strangler amortizes (migration per touched path — business unblocked — velocity sustained); big-bang concentrates (velocity zeroed for months + all-or-nothing failure); evidence bounds cost (measured misfit vs rewrite quarters — payback computed (break-even horizon — horizons under a year migrating). Economics with reversibility (rollback per path — risk bounded — big-bang rejected explicitly). Unvolunteered economics invites "at what cost?" probing (reactive answers scoring lower). Volunteer economics; preempt probing.

**Mentor note** — drill migration defenses (ten scenarios, ninety seconds each — measured misfit vs fashion proposal vs comfort stagnation — verdicts timed, evidence cited, execution shaped). Speed forces internalization (triggers reflex, strangler shape, rollback paths — fashion failing visibly under time pressure). Tribal answers die in drills (evidence demanded — numbers cited — fashion indefensible at speed); judgment performs (measured, strangler-planned, rollback-designed — hired). Drill defenses; demand evidence; shape stranglers.

## 3. Dissect a benchmark (methodology audited — workload match judged, micro-numbers dismissed)

**Definition** — the closer: *"X benchmarks 3× faster than Y — thoughts?"* (the methodology filter). The graded performance audits axes (workload match? (hello-world vs production lists/graphs — mismatch disqualifying); N+1 counted? (single-row numbers — linearities silent — uncounted benchmarks inapplicable to list-heavy production); concurrency modeled? (idle vs loaded — contention absent — pool/lock/replica realities untested); transfer measured? (SELECT-* unexamined — bytes absent where latencies live); statistics rigorous? (warmups/intervals/runs — single-shot noise presented as signal). Axes checked, applicability judged, own-workload measurement commissioned — dissection complete, worship declined, cynicism corrected (dismissal paired with alternative — critique constructive).

**What problem it solves** — benchmark questions filter for critical judgment (most candidates worship ("3× faster — adopting" — methodology unexamined (workload mismatched — N+1 uncounted — concurrency idle — transfer unmeasured — statistics absent — numbers inapplicable, decisions misled); or dismiss nihilistically ("all benchmarks useless" — measurement abandoned (own-workload numbers uncommissioned — cynicism replacing methodology — decisions unmade (vibes filling evidence gaps). Dissection distinguishes (axes checked — applicable rare (adopted cautiously); inapplicable common (dismissed with commissioned alternative — own-workload measurement). Worship fails (misled); nihilism fails (undecided); dissection passes (methodological — applicable adopted, inapplicable dismissed, alternatives commissioned).

**Modern guidance** — the ninety-second shape: (1) workload ("queries matching our hot paths? (lists/graphs/dynamics — hello-world disqualifying — mismatch dismissive)"); (2) N+1 ("list shapes benched? (statement counts published? — single-row numbers silent on linearities — uncounted inapplicable)"); (3) concurrency ("load modeled? (connections/workers/peaks — idle numbers predicting loaded behavior never)"); (4) transfer ("bytes measured? (SELECT-* examined — transfer dominating real latencies — unbenched numbers blind)"); (5) statistics ("warmups/intervals/runs? (single-shot noise — confidence absent — error bars missing)"); close commissioned ("inapplicable here — own-workload measurement: hot paths listed, production seeded, concurrency simulated — numbers applicable in weeks, decisions evidence-backed"). Five axes, one close — dissected, dismissed-or-adopted, alternative commissioned.

```typescript
// GOOD (spoken, 90 seconds — axes checked, applicability judged, alternative commissioned):
// "Workload: hello-world single-row CRUD (our lists/graphs absent — mismatch disqualifying).
// N+1: uncounted (single rows only — linearities silent — inapplicable to list-heavy production).
// Concurrency: idle (200-connection reality unmodeled — contention absent). Transfer: unmeasured
// (SELECT-* unexamined — bytes absent where our latencies live). Statistics: single-shot (noise
// presented — confidence absent). Verdict: inapplicable (dismissed politely — own-workload
// measurement commissioned: hot paths, production seed, simulated concurrency — applicable in weeks)."
// Checked, judged, commissioned. Worship declined; nihilism corrected; methodology performed.
```

```typescript
// BAD (spoken): worship or nihilism — methodology unexamined either way (real failure shapes).
// Worship: "3× faster — adopting." (Workload? Unchecked (hello-world vs production lists — mismatch
// unnoticed). N+1? Uncounted (single-row numbers — linearities silent). Concurrency? Idle (loaded
// reality unmodeled). Transfer? Unmeasured (bytes absent). Statistics? Single-shot (noise worshipped).
// Numbers admired; methodology unexamined; production surprised.) Nihilism: "Benchmarks are useless."
// (Own-workload uncommissioned (cynicism replacing methodology — decisions unmade (vibes filling
// evidence gaps). Dismissal without alternative — critique destructive, never constructive.)
```

**Common confusion** — *"dissecting benchmarks looks negative (contrarian)."* Dissection paired with commissioning is constructive (inapplicable dismissed + own-workload measurement proposed — critique with alternative — methodology serving decisions); contrarianism dismisses without alternative (negativity performing intelligence — decisions unmade — vibes filling gaps). "Negative" describes dismissal-only (critique destructive); dissection commissions (alternative proposed — evidence incoming — decisions improving). Pair critique with commission always (dismissed here, measured there — negativity converted to methodology). Constructive dissection hires; contrarian dismissal postures.

**Performance note** — close with dissection economics ("auditing costs minutes (five axes checked — inapplicability determined quickly); commissioning costs hours (listing/seeding/simulating/comparing — evidence-backed decisions aging well); worship costs misselection quarters (wrong-tool incidents — linear latencies, ceremony drag — remediation quarters); nihilism costs vibes-based selection (unmeasured tools — misfits scheduled). Minutes dissecting + hours measuring prevent quarters misselecting — methodology ROI exceeding all other selection investments (evidence over enthusiasm, permanently).

**Mentor note** — teach "dissect, don't dismiss-or-worship" (juniors auditing benchmark methodology design critical judgment on first hearing; worship interrogated ("representative of what?" — applicability demanded per number); cynicism corrected ("commission own-workload instead" — dismissal paired with alternative — critique constructive, never nihilistic). Benchmark literacy as hiring signal (candidates dissecting methodologies outscoring number-reciters — method over metrics, always — same verdict as workload measurement ([3.1](<../3. Measurement honesty/3.1. Benchmarks that inform (and deceive).md>))). Dissect methodically; commission independently; decide evidenced.
