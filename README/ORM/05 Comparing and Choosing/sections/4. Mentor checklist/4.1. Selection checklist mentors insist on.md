# 4.1. Selection checklist mentors insist on

## 1. Decisions recorded with triggers (tool + reasons + revisit date — selection living)

**Definition** — the review's first pass over tool selection: every data-access choice arrives recorded (tool named + workload reasons (positions mapped — [1.1](<../1. Selection by workload/1.1. Workload-matched selection.md>) performed); cost ledger attached ([1.2](<../1. Selection by workload/1.2. Cost ledgers per tool.md>) priced); revisit dated (triggers named — graphs/dynamics/majors (thresholds firing — selection living, never tattooed). Unrecorded selections fail review structurally — "we use X" without reasons/triggers/ledgers is tribalism with tenure (fashion defended passionately, workloads unexamined). Recorded selections age well (triggers firing on schedule — revisions calm, procedural); unrecorded selections fossilize (defaults permanent — misfits compounding silently).

**What problem it solves** — the undocumented default (tools adopted by first-mover (first feature choosing — subsequent features inheriting unexamined (defaults spreading without decisions — codebase standardized accidentally (uniformity without fitness — misfits scheduled per flat/graphic mismatch); triggers absent (graphs/dynamics/majors arriving unplanned — re-evaluation unscheduled (stagnation default — comfort dogma ("always used X" blocking measured migration); ledgers missing (costs unpriced — build/magic/upgrade bills arriving quarterly, unbudgeted). Recorded decisions convert accidental standards to deliberate defaults (reasons stated — exceptions filed (next promise) — triggers dated — revisits calendared (next-next promise). Documentation living (triggers firing — revisions procedural); undocumented defaulting fossilizing (defaults permanent — misfits compounding).

**Modern guidance** — the decision record format (per service, review-enforced): *tool* (named + version pinned (Prisma 7.10.0 / TypeORM 1.1.1 / Drizzle 0.45.3 — era-labeled per track index — versions moving, placements re-derived); *reasons* (workload-matched ([1.1](<../1. Selection by workload/1.1. Workload-matched selection.md>) performed — positions mapped, triggers dated); *ledger* (costs priced ([1.2](<../1. Selection by workload/1.2. Cost ledgers per tool.md>) — generation/strategies/magic/upgrades owned); *triggers* (graphs past 2 relations → re-evaluate; dynamics arriving → builder adoption; majors → ledger re-price (thresholds firing — revisions scheduled); *revisit date* (yearly minimum — majors/versions/workloads re-examined — living selection, never tattoo). Missing line → request changes; "team standard" unstated → record requested (standards documented or drifted — no third option).

```typescript
// GOOD: the decision record — tool, reasons, ledger, triggers, date (excerpt).
// Service: orders (graphs, greenfield, typed API). Tool: Prisma 7.10.0 (positions matched —
// graphs earn mappers ([1.1] performed). Ledger: generation ~4s/build; strategies stated;
// magic inventoried; v8 RC watched (priced — [1.2] attached). Triggers: graphs stable;
// majors yearly re-price. Revisit: 2027-09 (calendared). Exceptions: none (default conforms).
// Verdict: selection living (recorded, priced, triggered, dated).
```

```typescript
// BAD: the undocumented default — tools inherited, reasons absent, triggers missing (real shapes).
// Service: everything ("Prisma everywhere" — first-mover default spreading unexamined (flat admin
// tools under ceremony (build seconds per trivial change); dynamic reports under graph mappers
// (control surrendered); legacy classes unmigrated (idioms skewing). Reasons: unstated ("standard" —
// tradition unstated is drift with seniority). Ledger: missing (costs unpriced — bills arriving
// quarterly). Triggers: absent (graphs/dynamics/majors arriving unplanned — re-evaluation unscheduled).
// Revisit: never (tattooed selection — misfits compounding silently). Undocumented; fossilizing.)
```

**Common confusion** — *"decision records are bureaucracy (just pick tools)."* Records cost paragraphs (tool + reasons + ledger + triggers + date — minutes once, reviewed yearly); undocumented defaults cost misfit quarters (ceremony/toil/coupling billed per quarter indefinitely — unexamined tools billing heedlessly). "Bureaucracy" framing counts record-minutes while ignoring misfit-quarters — full ledger favors records by orders of magnitude, permanently. Records living (triggers firing — revisions procedural); defaults fossilizing (tattoos permanent — misfits compounding). Write paragraphs; schedule revisits; fossilize never.

**Performance note** — decision-record economics: recording costs minutes once (paragraphs per service — reviewed yearly); triggers cost gauges (existing monitoring — thresholds added — firing scheduled); unrecorded defaults cost misfit quarters (ceremony/toil/coupling billed per quarter indefinitely — unexamined tools billing heedlessly). Minutes once + gauges existing prevent quarters recurring — record ROI exceeding all other selection investments (living selections aging well; tattooed defaults decaying silently). Record decisions; date triggers; calendar revisits.

**Mentor note** — teach "record the why" (juniors recording tool+reasons+ledger+triggers+date design deliberate selections on first hearing; unrecorded selections interrogated ("why this tool here?" — reasons demanded per service). Decision records reviewed yearly (triggers firing? workloads shifted? majors moved? — living selections revised procedurally, never sentimentally). Record whys; review yearly; revise triggeredly — selection living in three habits, reviewed per service.

## 2. Exceptions filed explicitly (non-default choices justified — fashion declined structurally)

**Definition** — the review's second pass over non-default tool use: every exception to team defaults arrives filed (exception ADR with workload evidence (measured need, not preference — dynamics unserved by mappers? analytics unmappable? — evidence, not vibes); trigger attached (exception expiring when workload shifts (static-ified reports → secondary removed — exceptions temporary, never fossilizing); boundary documented ([2.2](<../2. Changing tools/2.2. Polyglot persistence honestly.md>) — tables/queries owned per tool — overlap forbidden). Unfiled exceptions fail review structurally (non-default tools without justification — fashion wearing necessity (preference defended passionately, workloads unexamined); comfort wearing pragmatism ("know X better" — familiarity unexamined).

**What problem it solves** — the unjustified exception duo: *fashion exceptions* (tools adopted per hype (conference-driven — workloads unexamined (flat shapes under new mappers — ceremony without graphs); evidence absent (numbers unmeasured — vibes filed); triggers missing (exceptions permanent — fashion fossilized); and *comfort exceptions* (familiar tools retained against defaults (legacy idioms persisting (0.3 customs unmigrated — version-skewed code failing confusingly); team default ignored per author (polyglot per preference — boundaries absent — upgrades touching N idioms). Filed exceptions convert both (workload evidence demanded — fashion declined structurally; comfort interrogated — familiarity unexamined failing review). Exceptions with evidence expire gracefully; without evidence fossilize permanently.

**Modern guidance** — the exception lines per non-default choice (review-enforced): *evidence* (workload measured (dynamics unserved? analytics unmappable? — numbers, not adjectives ("flexible" unmeasured is vibe — "composable filters unserved by finds" measured); *trigger* (exception expiring when workload shifts (static-ified reports → secondary removed — temporary, never fossilizing — expiry dated, review calendared); *boundary* ([2.2](<../2. Changing tools/2.2. Polyglot persistence honestly.md>) performed — tables/queries owned per tool — overlap forbidden (dual access failing review — exception scoped, never sprawling); *review* (exception ADR approved (evidence + trigger + boundary — three lines, complete justification — fashion/comfort declined structurally). Missing line → request changes (unjustified exceptions failing — fashion/comfort unexamined).

```typescript
// GOOD: the exception filed — evidence, trigger, boundary (excerpt).
// Exception ADR-014: Drizzle secondary (dynamics unserved by Prisma finds (measured —
// composable filters per admin reports — evidence filed). Trigger: reports static-ified →
// secondary removed (expiring, dated Q2). Boundary: reports/* tables Drizzle-owned (overlap
// forbidden — linted). Approved (evidence + trigger + boundary — fashion declined structurally).
```

```typescript
// BAD: the unjustified exception — preference filed as necessity (real failure shapes).
// "Using Kysely here (like the API better)." (Evidence? Absent (dynamics served by Drizzle
// secondary already — preference, not need). Trigger? Missing (exception permanent — fashion
// fossilized). Boundary? Unscoped (tables dual-accessed — overlap scheduled). Approved socially
// ("sure, whatever" — review abdicated — exceptions accumulating (collector service scheduled).
// Preference filed; necessity unexamined; fossilization scheduled. File evidence or decline.)
```

**Common confusion** — *"exceptions prove defaults wrong (abandon defaults)."* Exceptions prove defaults *bounded* (defaults serving most workloads — exceptions handling genuine edges (measured dynamics, unmappable analytics — edges real, scoped, expiring); defaults revised when exceptions multiply (three similar exceptions → default re-examined (pattern emerging — default possibly misplaced — evidence accumulated via exceptions, revision scheduled). "Abandon" confuses edge-handling with default-failure (exceptions disproving universality (no default universal — expected) vs defaults failing generally (misfits everywhere — revision warranted). Handle edges (exceptions filed); revise defaults on patterns (three similar → re-examine). Edges excepted; patterns revising.

**Performance note** — exception economics: filed exceptions cost paragraphs (evidence + trigger + boundary — minutes once, reviewed yearly); unjustified exceptions cost collector drag (idioms multiplying — comprehension fragmenting — upgrades multiplying — onboarding multiplying); default revision on patterns costs re-examination (evidence accumulated — revision scheduled — defaults improving). Filed-and-bounded exceptions perform (edges served, defaults intact); unfiled exceptions degrade (fashion fossilizing, comfort stagnating — misfits compounding). File evidence; bound scope; date expiry.

**Mentor note** — teach "evidence for exceptions" (juniors filing workload evidence design bounded exceptions on first hearing; preference-based proposals interrogated ("measured need?" — evidence demanded per exception). Exception patterns watched (three similar → default re-examined — evidence accumulating into revision — defaults living documents, never tattoos). Evidence demanded; patterns watched; defaults revised on evidence — exceptions complete only when justified, bounded, and expiring.

## 3. Revisits calendared yearly (majors re-price ledgers — versions moving, placements re-derived)

**Definition** — the review's closing act over selection currency: yearly revisit (majors released? (Prisma 8 RC → stable watch (breaking changes inventoried pre-adoption — ledger re-priced); TypeORM minors moving (deprecations reviewed — idioms re-verified); Drizzle minors shifting (API deltas checked — relations imports/modes re-confirmed); workloads shifted? (graphs grown? dynamics arrived? flatness persisted? — triggers firing acknowledged (revisions scheduled); defaults fitting? (exceptions patterned? (three similar → default re-examined); collector drift? (tool counts creeping → exceptions filed or tools removed). Calendared (same month yearly — ritual, not intention — owners present, tickets filed); living selections (revised on evidence — yearly cadence minimum, major-driven cadence additionally).

**What problem it solves** — the fossilized selection (tools chosen once, never revisited (majors unexamined (breaking changes arriving as surprises — v7 middleware removal breaking gauges silently (verified live S2 — surprise scheduled by inattention); workloads shifted (graphs grown under flat-chosen tools — ceremony/toil mismatching silently (misfits compounding — triggers firing unacknowledged); defaults decayed (exceptions fossilized (triggers expired unreviewed — temporary made permanent by neglect); versions drifted (minors accumulating unexamined (deprecations surprising — idioms skewing). Yearly revisits convert fossilization to currency (majors inventoried, workloads re-matched, defaults re-examined, versions tracked — selections living, never tattooed).

**Modern guidance** — the revisit lines per service yearly (calendared ritual): *majors* (released majors inventoried (breaking changes listed — ledger deltas priced (adopt/skip/defer decided with numbers — upgrades rehearsed, never hoped); *workloads* (graphs/dynamics/flatness re-matched (triggers firing acknowledged (revisions scheduled — dormant triggers confirmed dormant (still valid — re-affirmed, not assumed); *defaults* (team default re-examined (exceptions patterned? (three similar → revision proposed); collector counts audited (tool creeping → filed or removed); *versions* (minors tracked (deprecation notes reviewed — idioms re-verified (deprecated paths migrated pre-removal — skew preempted). Missing ritual → request process changes (unreviewed selections fossilizing — calendar invites sent during this review — rhythm protected like production uptime, because it protects production value).

```typescript
// GOOD: the revisit ritual — majors, workloads, defaults, versions (excerpt, yearly).
// Majors: Prisma 8 stable? (released → breaking inventoried → ledger re-priced → adopt/defer decided).
// Workloads: graphs grown past triggers? (re-matched — revisions scheduled where firing).
// Defaults: exceptions patterned? (two Drizzle secondaries → default re-examined — evidence reviewed).
// Versions: TypeORM minors (deprecations reviewed — idioms re-verified — skew preempted).
// Verdict: selection current (revised on evidence — living, never tattooed).
```

```typescript
// BAD: the fossilized selection — chosen once, revisited never (real failure shapes).
// 2023: Prisma adopted (reasons: fashion-adjacent ("modern" — prices unexamined).
// 2024: v7 released (middleware removed — gauges dead silently (unreviewed majors surprising).
// 2025: graphs outgrown (flat-chosen tools straining — triggers firing unacknowledged (misfits compounding).
// 2026: minors accumulated (deprecations surprising — idioms skewing (ghosts failing confusingly).
// Revisits: none scheduled (calendar absent — rhythm unprotected — fossilization complete).
// Chosen once; never revisited; billed quarterly (surprises/incidents/misfits/skew compounding).
```

**Common confusion** — *"yearly revisits churn stable stacks (don't fix working tools)."* Revisits *confirm* stability (unchanged verdicts recorded (still fitting — evidence re-affirmed — confidence renewed cheaply); churn only on triggers (firing acknowledged — revisions scheduled deliberately — stability preserved where fitting, changed where misfitting). "Churn" describes untriggered switching (fashion-driven rewrites — correctly declined); revisits *prevent* churn (measured continuity (fitting confirmed — switches declined with evidence) AND stagnation (misfits caught — migrations scheduled deliberately). Confirm stability (cheap); revise on triggers (deliberate); churn never (fashion declined). Revisits preserve working stacks *and* evolve misfitting ones — discernment, not disturbance.

**Performance note** — revisit economics: yearly ritual costs hours per service (majors inventoried, workloads re-matched, defaults re-examined, versions tracked — bounded, calm); fossilized selections cost surprise quarters (major-breakage incidents, misfit drag, skew confusion — unexamined changes billing heedlessly); churned stacks cost rewrite quarters (fashion-driven switches — toil without misfit). Ritual hours prevent surprise quarters and churn quarters alike — discernment cheap, surprises dear, churn dearest. Calendar yearly; confirm stability; revise triggeredly.

**Mentor note** — teach "calendar the revisit" (juniors dating selection reviews design living selections on first hearing; undated selections interrogated ("revisit when?" — rhythm demanded per decision). Rituals protected like uptime (skipped sessions rescheduled within two weeks — leaders attending audits signal priority — audits leaders skip die within two quarters). Calendar yearly; attend faithfully; revise evidenced — selection living in three habits, rhythm protected permanently.
