## 6.1. Boundaries: what is covered elsewhere

This domain teaches *words for the core* — how to learn terms, the computing layers, everyday acronyms and meeting language. It deliberately stops at these borders:

1. **Networks, web, and internet vocabulary** (protocol, DNS, HTTP, latency vs bandwidth, firewall) — [Domain 04 Networks Web and Internet Vocabulary](<../../../LOG.md>) (planned; curriculum recorded in this track's LOG — link to be upgraded to the domain README when it lands).
2. **Data, databases, and AI vocabulary** (schema, query, embedding, token, training vs inference) — Domain 05 (planned, see LOG); storage-unit foundations stay here ([2.2](<../2. Core computing concepts/2.2. Data units bit byte and encoding basics.md>)).
3. **Security, cloud, and DevOps vocabulary** (CVE, IAM, region vs zone, CI/CD, deploy vs release) — Domain 06 (planned, see LOG); the generic "platform" and "shipped" meanings stay here ([2.1](<../2. Core computing concepts/2.1. Hardware software OS and platform.md>), [3.2](<../3. Everyday professional jargon/3.2. Meeting jargon standup sync blockers and shipped.md>)).
4. **Hardware/infrastructure and software-engineering deep vocab** (CPU/RAM/SSD specifics; repo, branch, merge, refactor) — Domains 02 and 03 (planned, see LOG); Git mechanics belong to the Git track, not to any vocabulary leaf.
5. **Language and tooling mechanics** (how JS engines, type systems, or git internals actually work) — the [JavaScript](<../../../JavaScript/README.md>), [TypeScript](<../../../TypeScript/README.md>), and future Git tracks own the technology; this track owns only the words and links out.
6. **Execution internals** (event loop phases, JIT tiers, GC generations) — JavaScript track domains; this domain covers only program/process/thread and compile/interpret/JIT at naming level ([2.3](<../2. Core computing concepts/2.3. Programs processes compile vs interpret.md>)).

If you find yourself explaining how a protocol, engine, or tool *works* inside this domain — stop; define the word in one line, link the neighbor that owns the mechanism, and move on.
