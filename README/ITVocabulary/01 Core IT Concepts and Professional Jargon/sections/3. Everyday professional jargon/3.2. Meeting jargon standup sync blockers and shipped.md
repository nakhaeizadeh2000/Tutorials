## 3.2. Meeting jargon: standup, sync, blockers, and shipped

### 1) **Sync words: standup, sync, retro**

**Definitions** — A *standup* (daily scrum) is a ≤15-minute round where each person states done / doing / blocked. A *sync* is any alignment meeting with no fixed format — the word commits only to "leave with the same picture". A *retro* (retrospective) looks backward at a sprint or incident to extract process fixes, not blame.

- **What problem it solves**: each meeting name is a contract about format and output. Saying "standup" and then opening a design debate breaks the contract and burns five people's mornings; calling something a "sync" when you need a decision guarantees a second meeting.
- **Modern guidance** — match the word to the need: status → standup (or async update, which increasingly replaces it); shared picture → sync with a written agenda; process pain → retro with action items that have owners. And if a recurring sync has no agenda twice in a row, cancel it — that sentence earns senior respect.

```text
# Bad: contract-breaking standup
"Yesterday I... today I... also, let's redesign the auth flow
 [40 minutes of debate with 6 people watching]."

# Good: standup format honored, heavy topic parked
"Yesterday: shipped charge retries. Today: webhook handler.
 Blocked: need payments API quota raised — parking the auth
 redesign for a separate sync, inviting only backend."
```

### 2) **Progress words: blocked, WIP, shipped**

*Blocked* means "I cannot proceed without X from Y" — it is a request for help with an owner, not a status decoration. *WIP* (work in progress) marks unfinished, unreviewable state. *Shipped* means users can touch it — merged is not shipped, deployed is not shipped, *usable by users* is shipped.

- **Why it matters (flow and honesty)**: "blocked" without an owner ("blocked on the API team" — who, exactly?) waits forever; real blocked-items name the person and the need, then escalate after one business day of silence. And teams that call merges "shipped" discover in incidents that the feature flag was never flipped — the word lied, and everyone planned around the lie.
- **Modern guidance** — format blockers as "blocked on [person/team] for [specific thing], needed by [date], asked on [date]". Promote WIP visibility (draft PRs, WIP commits) so help arrives before the deadline. Reserve "shipped" for user-reachable, and say "merged" or "deployed" for the weaker claims.

### 3) **Soft words that harden meaning: ASAP, EOD, ping**

*ASAP* (as soon as possible) expresses urgency without a deadline — which reads as "drop everything" to some and "whenever" to others. *EOD* (end of day) is meaningless across timezones without one attached. *Ping* is a lightweight nudge ("ping me when ready") borrowed from the network utility that checks if a host answers.

- **Why it hurts (conflict and burnout)**: vague urgency is the top generator of pointless friction — the sender meant "today would be nice", the receiver heard "midnight emergency". Every ASAP without context taxes someone's evening or teaches the team to ignore urgency words entirely, which fails when real urgency arrives.
- **Modern guidance** — replace ASAP with a time plus a reason ("by 15:00 CET so the release train includes it"), attach a timezone to every EOD ("EOD Berlin time"), and ping with context ("pinging on the quota request from Tuesday — release blocked until it lands"). Urgency with a reason gets help; urgency without one gets resentment.

### 4) **Common confusion**

- "Sync means decision meeting" — a sync aligns pictures; if you need a decision, say "decision sync" and name the decision up front.
- "Blocked is a passive status" — no: an unowned blocker is a stalled task wearing a costume; every blocker needs an owner and a next nudge date.
- "Shipped = merged to main" — shipped = reachable by users; feature flags, rollouts, and approvals all sit between merge and shipped.

### 5) **Mentor note**

Shadow a junior's first standups and retros and give feedback on words, not just content: did "blocked" name an owner? Did "shipped" mean users? Did the retro produce owned actions or just feelings? Meeting vocabulary is team API design — sloppy words compile into sloppy coordination, and juniors adopt whatever looseness they see tolerated.
