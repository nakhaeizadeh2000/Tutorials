## 6.1. Boundaries: what is covered elsewhere

This domain names teamwork — rhythm, roles, growth, and interviews. It deliberately stops at these borders, which are also the IT Vocabulary track's outer borders — this is the final domain:

1. **Meeting contracts** (standup format, blocked-ownership, shipped meaning, ASAP/EOD discipline) — [Domain 01](<../../../01 Core IT Concepts and Professional Jargon/README.md>) owns the contract angle; this domain owns the process angle ([1.2](<../1. Rhythm words/1.2. Standup retro and demo as process.md>)) — the track's one sanctioned overlap, linked both ways.
2. **Review and release mechanics** (PR craft, pipelines, deploys, incidents, on-call) — [Domain 03](<../../../03 Software Development and Engineering Terms/README.md>) and [Domain 06](<../../../06 Security Cloud and DevOps Vocabulary/README.md>); teamwork words plan and own that work, they don't execute it.
3. **Management practice depth** (running calibrations, designing ladders, hiring loops, compensation) — future Leadership/Management topics; ladders and 1:1s stay here as *words every engineer needs* ([2.2](<../2. People words/2.2. Feedback ladder and one-on-ones.md>)), operating them as a manager lives there.
4. **Technical interview depth** (coding rounds, system design, language trivia) — sibling language/system tracks own the substance; this track's §5 leaves across all domains cover *vocabulary behavior* (precision, triage order, price tags) that carries into every round.
5. **Track boundary**: the IT Vocabulary track teaches *words*, never mechanics — every domain links outward to the track that owns the technology (JavaScript, TypeScript, Git, Databases, Cloud, and futures). If a leaf starts explaining how something *works* instead of what it's *called*, it has left the track — cut it back to one line plus a link.

If you find yourself coaching management technique, running a hiring loop, or teaching interview algorithms inside this domain — stop; name the concept in one line, link the neighbor that owns the practice, and move on.
