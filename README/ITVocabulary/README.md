# IT Vocabulary track

Learn to understand technical documentation, distinguish similar terms, ask useful
questions and explain engineering decisions clearly. The track covers computing,
software, networks, data, security, delivery, professional communication and AI.
You need basic computer skills and simple English; no framework, Linux, database
or Git knowledge is assumed. Small examples introduce their own prerequisites.

The learning path develops Junior → Mid → Senior → Master → Expert → Mentor
outcomes through interpretation, diagnosis, evidence and teaching. Vocabulary
helps you participate in engineering work; practical implementation competence
requires the corresponding subject's deeper study.

Baseline checked **2026-10-18**: terminology has no single runtime version.
Versioned anchors include HTTP semantics RFC 9110, RFC 8174, Semantic Versioning
2.0.0, Scrum Guide 2020, ISTQB CTFL 4.0.1 and OWASP Top 10:2025. Individual lessons
state the sources and versions relevant to their claims. Experimental features,
product-specific usage and team conventions are identified explicitly.
