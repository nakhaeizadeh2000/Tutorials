# IT Vocabulary track (recommended order, August 2026 era)

Keywords, acronyms, and professional jargon — the language developers speak in code reviews, meetings, and interviews — from zero to hero and beyond (junior to mentor depth). Technical depth lives in the sibling tracks (JavaScript, TypeScript, Git, and the rest); this track teaches the *words*, and links out instead of re-teaching the technology. Deliberately placed before the Git track so learners can read docs and follow instructions without tripping over terminology.
