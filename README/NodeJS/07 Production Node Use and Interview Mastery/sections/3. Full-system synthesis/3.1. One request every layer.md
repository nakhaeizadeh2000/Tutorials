## 3.1. One request, every layer

### 1) **Trace cradle to grave**

**Definition** — one request's full journey, each layer named with its owning domain: DNS resolve (lookup — Domain 04/2.2), TCP accept (socket — Domain 04/2.1, Duplex stream — Domain 03), route dispatch (hand match — Domain 04/3.1), body streaming (pipeline + caps — Domain 03/2.1, Domain 04/3.1), compute (loop or worker — Domain 01/3.1, Domain 05/2.1), response serialization (bytes first — Domain 03/3.1), log emission (JSON + reqId — Domain 06/2.2), connection disposition (keep-alive or close — Domain 04/2.2). The trace is the track assembled (seven domains, one exchange — fluency demonstrated by narration).

- **What problem it solves**: layer-blind debugging (slow request blamed on the wrong box — profiler never opened, pool never measured; fix deployed to the innocent layer). Siloed expertise (streams expert lost in DNS — full-system incidents need cradle-to-grave readers). unnarratable systems (working services nobody can whiteboard — bus factor one; unexplainable means unmaintainable). Tracing assembles the engineer (parts known, whole narrated).
- **Modern guidance** — instrument per layer (timestamps at each handoff — DNS done, accepted, routed, bodied, computed, serialized, logged; spans named, not guessed). Read traces layer by layer (slowest span first — optimize the max, never the mean; totals reconciled — parts sum to whole). Practice cold narration (whiteboard without notes — interviewers hire narrators; incidents obey narrators; the skill transfers to every system).

```javascript
// GOOD: instrumented journey, per-layer timings — runs on node v20.20.2 (spans named, total reconciled)
const http = require('node:http'); const dns = require('node:dns').promises;
const server = http.createServer(async (req, res) => { const t = {}; // spans (each handoff timestamped — named, not guessed)
  t.dns = Date.now(); await dns.lookup('localhost'); t.accept = Date.now(); // DNS resolve (Domain 04/2.2 — lookup before connect)
  const chunks = []; for await (const c of req) chunks.push(c); t.body = Date.now(); // body streamed (Domain 03/2.1 — pipelined, capped by policy)
  const n = JSON.parse(Buffer.concat(chunks).toString() || '{"n":0}').n; t.compute = Date.now(); // compute on loop (tiny — workers past 10ms per Domain 05/2.1)
  res.end(JSON.stringify({ double: n * 2 })); t.respond = Date.now(); // bytes first (Domain 03/3.1 — encoding named)
  console.log(`spans ms: dns=${t.accept - t.dns} body=${t.body - t.accept} compute=${t.compute - t.body} respond=${t.respond - t.compute} (slowest span optimized — never the mean)`);
}).listen(0, '127.0.0.1', async () => {
  const port = server.address().port;
  await new Promise((res) => { const r = http.request({ port, host: '127.0.0.1', path: '/', method: 'POST' }, (r2) => { r2.resume().on('end', res); }); r.end('{"n":21}'); });
  server.close(); // journey complete (cradle to grave — seven domains, one exchange)
});
// BAD: "the request goes to the server and back" (narration at one layer — boxes unnamed, budgets absent) —
// unlayered narration debugs nothing; slowness lives in a span, never in "the server"
```

### 2) **Budgets per layer**

**Definition** — the p99 budget decomposed (total latency apportioned — DNS 5 ms, accept queue 10 ms, routing 1 ms, body 20 ms, compute 100 ms, serialize 5 ms, log async 0 ms; numbers per service, measured; slowest span optimized first — Amdahl for requests). Budgets enforced (per-layer timeouts — dependency SLO fractions; leaf 2.2 of Domain 04's discipline, applied per span; over-budget spans alert — attribution automatic). Reconciliation closes the loop (parts sum to whole — unaccounted time investigated, never shrugged).

- **Why it matters (performance)**: mean-optimized tail (average fast, p99 awful — slowest span unexamined; budgets per layer expose tails per span). Unattributed latency (200 ms unaccounted — "network?" shrugged; spans leave nowhere to hide; every millisecond owned). Over-budget silence (dependency creeping slower — no per-span alert; degradation discovered by users; budgets alert before users notice).
- **Modern guidance** — apportion the p99 (spans sum to budget — slowest first; numbers from measurement, not hope). Timeout per span (dependency fractions — cut slow spans; total bounded by construction). Alert per overage (span exceeding budget pages with attribution — the slow box named in the alert). Reconcile always (unaccounted time investigated — instrumentation gaps fixed, never tolerated).

```javascript
// GOOD: budget decomposed and checked — runs on node v20.20.2 (verdicts per span, total reconciled)
const BUDGET = { dns: 5, accept: 10, route: 1, body: 20, compute: 100, serialize: 5 }; // p99 apportionment (measured — per service, per deploy)
const observed = { dns: 1, accept: 2, route: 0, body: 8, compute: 250, serialize: 1 }; // a slow deploy (compute regressed — receipts, not adjectives)
const over = Object.entries(observed).filter(([k, v]) => v > BUDGET[k]).map(([k, v]) => `${k}:${v}ms>${BUDGET[k]}ms`);
const total = Object.values(observed).reduce((a, b) => a + b, 0);
console.log('over budget:', over.length ? over.join(', ') : 'none', '| total:', total, 'ms (slowest span optimized — compute, flame it per Domain 06/1.2)'); // compute:250ms>100ms | 262 (attributed — fix assigned, not guessed)
// BAD: "p99 is 262ms, needs work" (total without spans — optimize what? the mean of everything?) —
// unattributed totals optimize nothing; spans assign; receipts prove
```

### 3) **Narrate it cold**

**Definition** — whiteboard narration without notes (seven boxes drawn — DNS, socket, route, stream, compute, serialize, log; arrows labeled with budgets; failure modes per box recited — what breaks, how it signals, what remedies). Cold narration proves assembly (parts known + whole told — fluency, not familiarity). Interviewers hire narrators (systems questions answered as journeys — evidence of production mileage). Incidents obey narrators (triage follows the boxes — layer order, Domain 06/1.1's discipline, from memory).

- **Why it matters (careers, incidents)**: familiarity without fluency (can follow a trace — cannot lead one; guided tours, not expeditions; seniors lead). Narration-less expertise (knows each part — cannot assemble; debugging stalls at layer boundaries; incidents need cradle-to-grave). Interview opacity (correct fragments, no journey — hiring signal weak; narrated systems signal strong).
- **Modern guidance** — practice weekly (one request type per session — narrated cold; gaps studied, not hidden). Time the narration (five minutes per journey — concise enough for interviews, complete enough for incidents). Recite failure per box (DNS fails → ENOTFOUND, retry policy; socket dies → reset, reconnect; compute slow → flame, offload — remedy per box, unprompted). Teach to retain (narrate to juniors — transfer proves mastery; questions welcomed, gaps celebrated).

### 4) **Common confusion**

- "Tracing needs distributed systems" — tracing needs *spans* (single-process timestamps assemble journeys; distributed tracing extends the habit across services; start local, span everywhere). Local first, distributed next.
- "Budgets constrain velocity" — budgets *direct* velocity (slowest span optimized — effort aimed; unbudgeted tuning wanders; constraints aim, guesses diffuse). Aimed effort ships; wandering tunes.
- "Cold narration is performance" — narration is *proof* (assembly demonstrated — parts + whole; performance optional, fluency mandatory; interviews and incidents both grade it). Prove assembly.
- "One trace covers everything" — traces cover *paths* (happy, slow, failing — three journeys minimum; error paths traced separately — failure spans differ; coverage across conditions). Paths plural.

### 5) **Performance note**

Tracing costs are instrumentation overhead, priced per request: timestamps nanoseconds (Date.now per handoff — invisible; hrtime where precision matters — same order). Span logging sampled in production (1-in-1000 full journeys — representative; errors always full — completeness where it counts). Budget checks arithmetic (comparisons per span — free; alerts on overage — the valuable part). Reconciliation free (sums at analysis — never hot-path). Optimize instrumentation leanness first (timestamps, not objects — hot paths stay hot), sampling second (representative volume — storage bounded), analysis always (slowest-span-first — effort aimed).

### 6) **Mentor note**

Teach the journey as the track's final exam ("narrate any request cold — seven boxes or revise" until assembly flows unprompted). Demo instrumentation live (spans printed per request — slowest highlighted; then budgeted — overages named; evidence assembling). Drill budgets ("p99 300ms — apportion it" per service; slowest optimized; receipts demanded). Watch for the single-box thinker ("the server handles it" — fix with "which span?") and the memorizer (script recited — fix with a variant: "now the failing path"). Review check: boxes drawn, spans timed, budgets apportioned, failures recited, juniors narrate before touching traces.
