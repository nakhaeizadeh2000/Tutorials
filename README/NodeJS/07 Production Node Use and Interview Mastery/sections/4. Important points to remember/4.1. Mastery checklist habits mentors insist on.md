## 4.1. Mastery checklist (habits mentors insist on)

### 1) **Six domains, one engineer**

**Definition** — the fluency inventory: runtime narrated cold (three boxes, phases, lifecycle — Domain 01), packaging gated (manifests, locks, scripts — Domain 02), data pathed (files, streams, bytes — Domain 03), conversations held (events, sockets, HTTP — Domain 04), parallelism routed (processes, workers, cluster — Domain 05), delivery sequenced (observe, configure, ship — Domain 06). Fluent in all (narrate any layer), expert in several (receipts filed), learning always (one gap listed per quarter — mastery as direction, not destination).

- **Why it matters (careers)**: siloed seniors (streams expert lost in DNS — incidents need cradle-to-grave; packaging expert blind to loops — capacity unplanned). T-shaped fluency (broad narration + deep spikes — hireable, promotable, on-callable). Stagnant experts (mastery declared — learning stopped; runtimes evolve yearly; declared mastery expires).
- **Modern guidance** — inventory quarterly (rate 1–5 per domain — gaps listed, weakest studied next; honest scores, no resume inflation). Narrate cold monthly (one request type — seven boxes from memory; fluency exercised like muscle). File receipts per claim (profiles, benchmarks, counts — opinions priced; unmeasured assertions revised). Teach weekly (transfer proves retention — juniors' questions welcomed; explained systems stay explained).

```javascript
// GOOD: fluency inventoried mechanically — runs on node v20.20.2 (7/7 rows, 7/7 dirs — point at any track root)
const fs = require('node:fs');
const track = process.argv[2] ?? '.'; // audit shape, not path (usage: node audit.cjs README/NodeJS)
const rows = fs.readFileSync(`${track}/README.md`, 'utf8').split('\n').filter((l) => /^\| \d+ \|/.test(l)).length; // curriculum rows (promised domains)
const dirs = fs.readdirSync(track).filter((d) => /^\d\d /.test(d)).length; // domain dirs (delivered domains)
console.log(`track coverage: ${dirs}/${rows} domains implemented`, dirs === rows ? '(complete — audit green)' : '(PARTIAL — resume from Next steps)'); // 7/7 (receipt, not opinion)
// BAD: "I know Node" (un inventoried — six domains, unknown gaps; confidence unpriced) —
// fluency inventoried, gaps listed, weakest studied; mastery as direction
```

### 2) **Receipts over opinions**

**Definition** — the evidence habit: measured before claimed (profiles before "slow", benchmarks before "fast", counts before "many" — numbers attached to adjectives); procedures replayable (commands quoted — re-runnable by reviewers; fixtures named — reproducible); verdicts committed (before/after in messages — future debuggers replay). Opinions unpriced are guesses with confidence (velocity without verification — churn billed as progress). Receipts convert debate into arithmetic (numbers compared, not voices).

- **Why it matters (engineering)**: opinion-driven optimization (rewrites without profiles — unmeasured, often pessimizing; "best practice" without context — cargo-culted). Unreplayable fixes ("works now" — procedure unknown; recurrence undebuggable; knowledge evaporated with the author). Confidence without calibration (loudest wins reviews — juniors silenced, evidence ignored; receipts democratize — numbers outrank rank).
- **Modern guidance** — attach numbers to adjectives (every "slow/fast/many" quantified — or reworded; review enforces). Quote procedures (commands + fixtures — replayable; future incidents start from evidence). Commit verdicts (before/after — messages carry receipts; unreceipted claims revised). Calibrate publicly (wrong predictions admitted — estimates vs actuals compared; calibration compounds).

```javascript
// GOOD: opinion priced, verdict committed — runs on node v20.20.2 (measured, replayable, compared)
const t = Date.now(); JSON.stringify({ a: 1, b: [1, 2, 3] }); const micro = Date.now() - t; // measured (not "fast" — 0ms here, quantified)
console.log(`JSON small-object: ${micro}ms (receipt — replay: node -e "same line"; verdict: negligible beside I/O)`);
console.log('opinion: "structured logs are slow" → priced: sub-ms per line → verdict: volume matters, serialization doesn\'t (leaf 2.2 of Domain 06)'); // priced (debate ended arithmetically)
// BAD: "X is slow, use Y" (unmeasured — adjectives without numbers; debates without ends) —
// price it or reword it; receipts or revise
```

### 3) **Teach to retain**

**Definition** — mastery demonstrated by transfer: narrate systems cold (journey told without notes — leaf 3.1; gaps discovered aloud — studied after); review juniors kindly (gates explained, not just enforced — reasons transferred; numbers coached — derivations modeled; failures normalized — blameless, curious); write the missing doc (every answered question documented — team knowledge compounded; docs reviewed like code). Teaching exposes gaps (unexplainable corners studied — retention through transfer). Experts who can't teach haven't finished learning.

- **Why it matters (teams)**: bus-factor-one experts (knowledge unshared — vacations block, departures devastate; transfer distributes). Gate-only reviews (enforced without explained — juniors comply blindly; understanding unbuilt; same defects recur per hire). Undocumented answers (questions answered in chat — evaporated; docs compound — answered once, read forever).
- **Modern guidance** — explain every gate (enforced + why — juniors learn principles, not just rules; curiosity welcomed). Narrate monthly (cold journeys — team watches; questions celebrated; gaps listed publicly). Document answers (chat responses distilled to docs — knowledge compounded; reviewed, versioned, greppable). Mentor deliberately (one mentee per senior — transfer scheduled; mastery measured by mentees' growth).

```javascript
// GOOD: transfer instrumented — runs on node v20.20.2 (questions counted, gaps listed, growth tracked)
// mentorship log shape (one line per session — compounded like code):
const sessions = [{ q: 'why pipeline over pipe?', understood: true }, { q: 'backpressure math?', understood: false }];
const gaps = sessions.filter((s) => !s.understood).map((s) => s.q);
console.log('transferred:', sessions.length - gaps.length, '/', sessions.length, '| gaps to reteach:', gaps.length ? gaps.join('; ') : 'none'); // 1/2 (honest — reteach scheduled, not hidden)
// mastery metric: mentees narrating cold (their journeys, your transfer — growth tracked, not hoped)
// BAD: "they'll pick it up" (transfer unplanned — osmosis as pedagogy; gaps undiscovered; bus factor unchanged) —
// teach deliberately; track honestly; transfer compounds
```

### 4) **Common confusion**

- "Mastery means knowing everything" — mastery means *navigating* everything (fluent narration + known unknowns + receipts habit; encyclopedic recall expires with versions; navigation compounds). Direction, not destination.
- "Checklists are for juniors" — checklists are for *load* (experts skip steps under pressure exactly when steps matter; seniority writes the checklist; everyone runs it — the license-exam model, applied to backends).
- "Teaching slows experts down" — teaching *compounds* experts (gaps discovered, understanding deepened, team unblocked; bus factor distributed; the fastest way to learn is the honest explanation). Transfer accelerates.
- "Receipts slow down shipping" — receipts *accelerate* shipping (unmeasured debates consume quarters; priced verdicts end them; re-litigation prevented by record). Arithmetic ends arguments.

### 5) **Performance note**

Mastery costs are attention + humility, priced per quarter: inventories minutes (ratings honest — gaps listed; cheapest planning there is). Receipts minutes per claim (numbers attached — debates ended; re-litigation prevented). Teaching hours per week (transfer scheduled — team unblocked; bus factor distributed). Narration practice minutes monthly (cold journeys — fluency exercised). Optimize transfer first (team capability — the multiplying asset), receipts second (debate velocity — quarters saved), inventory always (direction maintained — drift prevented).

### 6) **Mentor note**

Teach mastery as direction ("rate yourself 1–5 per domain — defend each number" until inflation *feels* dishonest). Demo the audit (track coverage script above — green observed; gaps listed where red). Drill cold narration (monthly journeys — team watches; questions celebrated). Watch for the declarer ("I know Node" — fix with "narrate a request cold") and the hoarder (knowledge unshared — fix with "who did you teach this week?"). Review check: fluency inventoried, receipts filed, transfer scheduled, juniors narrating — mastery demonstrated by mentees, not claimed by mentors.
