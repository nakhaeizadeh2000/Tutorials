## 5.1. Common interview QA: judgment and synthesis

### 1) **Design a URL shortener, Node edition**

**Definition** — the systems screen: candidates design end to end, narrating each decision with its owning domain. The expected shape: `POST /v1/shorten` (capped body — Domain 04/3.1; validated URL — 400 on malformed), id generation (counter + base62 — external store for multi-worker — Domain 05/3.1 statelessness), storage (managed KV — boring wins — Domain 07/1.1), `GET /:id` (302 redirect — cacheable; unknown id — typed 404 with remedy — Domain 07/2.2), capacity stated (writes/s × bytes — Little's law — Domain 07/1.2), rollout sequenced (ready-first — Domain 06/3.1). Interviewers grade the journey (layers named, numbers attached, failures remedied).

- **What problem it solves**: hand-waving system design (boxes without numbers — capacity unknown; stores unnamed — consistency unconsidered; failures unmentioned — happy-path architectures). The narrated design exposes judgment (boring stores, capped bodies, external sessions — each choice priced). Practice here transfers to every systems question (same layers, same numbers, same remedies — shapes, not scripts).
- **Modern guidance** — start from constraints (traffic, team, SLOs — leaf 1.1; numbers first, boxes second). Name the store boringly (managed KV — operational burden bought away; custom storage never for interviews, rarely for production). Cap and type everything (bodies capped — Domain 04; errors remedied — leaf 2.2). State the rollout (ready-first — Domain 06; migrations expand/contract). Narrate failures per box (store down → stale/errors per policy; worker dies → refork; deploy → drain).

```javascript
// GOOD: the core in thirty lines — runs on node v20.20.2 (round trip exact, collisions absent)
const ALPH = '0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ'; // base62 (compact ids — 7 chars ≈ 3.5T space)
const encode = (n) => n === 0 ? '0' : [...(function* () { while (n > 0) { yield ALPH[n % 62]; n = Math.floor(n / 62); } })()].reverse().join(''); // counter → id (stateless workers share the counter store — Domain 05/3.1)
const store = new Map(); let seq = 1000; // stand-in KV (production: managed store — boring wins)
const shorten = (url) => { if (!/^https?:\/\//.test(url)) throw Object.assign(new Error('malformed URL'), { code: 400 }); const id = encode(seq++); store.set(id, url); return id; }; // validated (400 on malformed — leaf 2.2)
const resolve = (id) => store.get(id) ?? null; // 302 or typed 404 (remedy named — leaf 2.2)
const id = shorten('https://example.com/a'); console.log('round trip:', resolve(id) === 'https://example.com/a' && encode(1000) === id, '| ids unique:', new Set([shorten('https://x/1'), shorten('https://x/2')]).size === 2);
try { shorten('not-a-url'); } catch (e) { console.log('malformed:', e.code === 400 ? 'typed 400 (remedy: send http(s) URL)' : 'UNEXPECTED'); }
// narration: "capped POST → validated → counter-store id → managed KV → 302/404 → ready-first rollout"
// BAD: "id = Math.random(), store in memory, done" (collisions unhandled, state local, rollout unconsidered) —
// demo-shaped answers fail systems interviews; narrate constraints, stores, caps, rollouts
```

### 2) **"Your service falls over at noon" — debug it live**

**Definition** — the incident screen: candidates triage a time-correlated collapse aloud. The expected order: scope (noon correlation — traffic spike? cron? deploy? — metrics first, Domain 06/5.1's triage), separate (lag probe — loop blocked or downstream slow? — Domain 01/3.1's instrument), locate (flame under noon-shaped load — self-time boxes; heap diff if memory climbs — Domain 06/1.2), fix with receipt (shape fix / bound / offload — before/after on replayed load). The interviewer injects twists (CPU flat — look downstream; memory flat — look at descriptors; only Tuesdays — deploy correlation). Order held through twists signals seniority.

- **Why it matters (operations)**: noon collapses recur (traffic-shaped bugs — lunch rush, batch jobs, cron storms; fixed once by triage, forever by capacity — leaf 1.2). Twist-handling separates levels (juniors freeze at surprises — seniors re-route by layer; the ordered walk survives new evidence). Receipts close incidents (fixed with numbers — recurrence detectable; fixed with hope — recurrence scheduled).
- **Modern guidance** — narrate the order first ("scope, separate, locate, receipt" — then execute; order announced, then followed). Instrument live (lag + heap + handles printed — evidence over adjectives; numbers spoken aloud). Take the twists by layer (CPU flat → downstream; memory flat → descriptors/connections; periodic → deploys/crons — each twist a layer question). Commit to a receipt (fix + replayed load + before/after — closed with numbers).

```javascript
// GOOD: triage instruments live — runs on node v20.20.2 (lag clean, heap split, handles counted)
const t = Date.now();
setTimeout(() => { const lag = Date.now() - t - 50; // noon probe (separate: loop or downstream?)
  const mem = process.memoryUsage(); // split (heap vs native — different tools per side)
  console.log('lag ms:', lag, '| heap MB:', (mem.heapUsed / 1048576).toFixed(1), '| rss MB:', (mem.rss / 1048576).toFixed(1), '| ext MB:', (mem.external / 1048576).toFixed(1));
  console.log(lag > 50 ? 'verdict: loop-blocked → flame (Domain 06/1.2)' : 'verdict: loop clean → downstream/descriptors (Domain 04/2.2 timeouts, fds)');
  console.log('narration: "scope noon (deploy? cron? traffic?) → separate (this probe) → locate (flame/diff) → receipt (replay)"');
}, 50);
// twists answered: CPU flat + heap flat + rss climbing → native/handles (buffers, sockets — count fds next)
// BAD: "add more servers" mid-triage (capacity before diagnosis — 2× boxes, same flame, same noon) —
// scale after locating; triage converges, capacity postpones
```

### 3) **Teach the event loop in five minutes**

**Definition** — the mentoring screen: candidates explain the loop to a junior, completely, briefly. The expected shape: three boxes first (V8 runs JS — one thread; libuv loops + pools — timers, I/O, 4 threads; bindings expose OS — Domain 01/1.1), phases second (timers → poll → check — where callbacks wait; `setImmediate` vs `setTimeout(0)` in I/O — Domain 01/3.1), one demo third (ordered output traced aloud — Domain 01/5.1's A–E trace), one rule last ("never block the loop" — chunk, delegate, or worker — the sentence juniors carry). Five minutes, four beats, zero jargon unexplained.

- **Why it matters (careers)**: teaching proves assembly (explainable systems are maintainable by teams — bus factor distributed; inexplicable expertise bottlenecks). Mentoring screens hire multipliers (seniors who raise juniors — team capability compounded; brilliant soloists don't scale). Five-minute constraint forces essence (no rambling — boxes, phases, demo, rule; padding cut by the clock).
- **Modern guidance** — draw before speaking (three boxes — visual anchor; phases as itinerary; juniors point, not just listen). Demo once, live (A–E trace run — order observed; I/O variant — determinism contrasted; two runs, permanent intuition). End with the rule ("never block — chunk/delegate/worker" — one sentence carried out). Invite the gap ("what's fuzzy?" — celebrated, studied next; teaching loops back to learning).

```javascript
// GOOD: the five-minute demo — runs on node v20.20.2 (A–E ordered, narratable cold)
console.log('A: sync (stack drains first — your code, one thread)');
process.nextTick(() => console.log('B: nextTick (between phases — priority, bounded)'));
Promise.resolve().then(() => console.log('C: promise (microtask — after nextTick)'));
setTimeout(() => console.log('D: timer (timers phase — main context first)'), 0);
setImmediate(() => console.log('E: immediate (check phase — main context second; from I/O, first)'));
console.log('narration: "A drains, B jumps phases, C clears microtasks; D vs E in main is weather (either may win — contract nowhere); inside readFile, E beats D deterministically"');
// rule to carry out: "never block the loop — chunk it, delegate it, or worker it (Domain 05/2.1)"
// BAD: reciting phase names without the demo ("timers, pending, poll, check, close" — listed, not shown) —
// lists memorized, intuition absent; demos transfer, recitals evaporate
```

Rapid-fire drills (one sentence each — mechanism named): "Cluster or workers for CPU?" — workers (CPU off-loop; cluster multiplies loops for fan-out). "Phantom dep breaks Friday?" — declare it (borrowed hoist — owned, locked, reviewed). "Uncapped upload?" — 413 + destroy (count during, never buffer-then-judge). "Unguarded emitter?" — crash on routine (error listener at construction — always). "Backpressure ignored?" — OOM by ratio (returns checked or machinery used). "Stale session after refork?" — externalize (workers disposable — state outlives processes). "Deploy drops requests?" — sequence it (close → drain → flush → exit — asserted under load). "Slowest span?" — optimize it (budgets per layer — flame the max, never the mean).

### 4) **Common confusion**

- "Systems answers need scale numbers" — need *reasoning with* numbers (constraints → arithmetic → verdicts; invented traffic fine when labeled estimate; unnumbered boxes fail regardless of scale). Reasoned, not gigantic.
- "Incident answers need war stories" — need *order* (scope → separate → locate → receipt; stories illustrate, order convinces; twists handled by layer, not by anecdote). Ordered, not storied.
- "Teaching answers need completeness" — need *essence* (boxes, phases, demo, rule — five minutes; completeness rambles, essence transfers; depth on questions, not upfront). Essential, not exhaustive.
- "Rapid-fire rewards speed" — rewards *compression* (mechanisms one-lined — derived, not memorized; variants answered, recitals broken). Compressed, not quick.

### 5) **Performance note**

Interview mastery costs are preparation + composure, priced per loop: systems prep (narrated designs — layers, numbers, remedies; practiced aloud, not just read). Incident prep (triage order internalized — scope/separate/locate/receipt; game days lived). Teaching prep (five-minute loop — timed rehearsals; essence distilled). Composure (order under twists — layers answer surprises; breathing beats rushing). Optimize narration first (cold journeys — fluency exercised), numbers second (constraints attached — verdicts priced), composure always (pauses allowed — ordered beats speedy).

### 6) **Mentor note**

Teach interview prep as the track's final assembly ("every leaf maps to a question — walk the track as Q&A" until students route questions to domains unprompted). Drill systems aloud with twists (noon collapse variants — CPU flat, memory flat, Tuesdays only; derivors re-route, reciters freeze). Drill teaching (five-minute loop to a real junior — gaps discovered, essence refined). Watch for the scripter (memorized designs — fix with a twist mid-answer) and the rusher (speed over order — fix with "slow down, name the layer"). Review check: designs narrated, incidents ordered, teaching timed, rapid-fire derived, juniors hired for reasoning, not recital.
