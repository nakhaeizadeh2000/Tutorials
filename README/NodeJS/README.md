# Node.js track (recommended order, September 2026 era)

The Node.js runtime and backend base — how Node executes JavaScript outside the browser, and how to build reliable server-side programs on it — from zero to hero and beyond (junior to mentor depth). Language mechanics live in the [JavaScript track](<../JavaScript/README.md>); this track assumes that foundation and teaches the *runtime*.
