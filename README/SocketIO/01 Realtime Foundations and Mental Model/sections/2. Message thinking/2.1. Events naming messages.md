# 2.1. Events naming messages

## 1. Names registering (events spelling — payloads typing — contracts versioning)

**Definition** — registered names: spelling events typing payloads versioning contracts (events spelling — strings owning (verbs choosing — collisions refusing (spelling proving — mystifying declining); payloads typing — shapes declaring (DTOs validating — unknowns rejecting (typing funding — anying declining); contracts versioning — names numbering (v1 freezing — v2 extending (versioning owning — breaking declining).

**What problem it solves** — the unregistered-name trio: *events unspelling* (strings unowned — verbs unchosen (collisions ruling — handlers guessing (unspelling billing — routing failing); *payloads untyping* (shapes undeclared — DTOs unvalidated (unknowns ruling — crashes dating (untyping charging — correctness failing); *contracts unversioning* (names unnumbered — v1 unfrozen (breaks sneaking — clients stranding (unversioning costing — trust failing). Registered names converting guessing to spelling (strings owning — shapes declaring (names numbering — mysteries ending); reviewers finding name rows per event (registering proving → verifiable; guessing → returned).

**Modern guidance** — the registering lines per event (review-enforced): *events spelling* — strings owning (verbs choosing — collisions refusing (spelling proving — mystifying refusing (spells earning — routes keeping); *payloads typing* — shapes declaring (DTOs validating — unknowns rejecting (typing funding — anying refusing (types keeping — crashes ending); *contracts versioning* ([APIDesign 01/2.2](<../../../../APIDesign/01 API Design Foundations and Mental Model/sections/2. Contract thinking/2.2. Versioning and evolution.md>) — names numbering (v1 freezing — v2 extending (versioning owning — breaking refusing (versions keeping — strands ending).

```typescript
// GOOD: names registering — events spelling, payloads typing (compiled + run live).
import 'reflect-metadata';
import { WebSocketGateway, SubscribeMessage, MessageBody } from '@nestjs/websockets';
interface ChatSend { room: string; text: string }
const CHAT_SEND_V1 = 'chat.send.v1'; // events spelling — strings owning, mystifying declining
function validChat(p: unknown): p is ChatSend {
  const c = p as Partial<ChatSend>;
  return typeof c.room === 'string' && typeof c.text === 'string'; // payloads typing — shapes declaring, anying declining
}
@WebSocketGateway()
class ChatGateway {
  @SubscribeMessage(CHAT_SEND_V1)
  onChat(@MessageBody() payload: unknown): string {
    return validChat(payload) ? `ok:${payload.room}` : 'refused:shape';
  }
}
const chgw = new ChatGateway();
console.log(chgw.onChat({ room: 'lobby', text: 'hi' }) === 'ok:lobby' && chgw.onChat({ room: 7 }) === 'refused:shape' ? 'names register' : 'handlers guess');
```

```typescript
// BAD: names guessing — events unspelling, payloads untyping (real guess shape).
```

**Common confusion** — *"event names are internal details (spelling skipping)."* Skipping naming strings (verbs unchosen — collisions ruling (clients guessing — interop failing (skipping charging — routing failing); spelling owning contracts (strings owning — versions numbering (routes keeping — mysteries ending (spelling earning — skipping declining). "Internal" describing comfort (names hidden — guesses ruling); events describing API (strings owned — clients coded). Own strings (events spelling — routes keeping); number versions (contracts versioning — strands ending).

**Performance note** — registering economics: spelling costing constants (strings owning — shapes declaring (names numbering — mysteries ending); guessed equivalents costing crashes (collisions ruling — unknowns crashing (clients stranding — trust eroding). Register cheaply (names — strings); guess never (events — messages).

**Mentor note** — teach "every event spells its name, types its payload, numbers its version — every handler" (juniors registering one contract per event design guess-proof messaging on first hearing; any-typed handlers interrogated ("shape? version?" — registering demanding per event). Register one event once (events spelling — payloads typing tangible (guessing ending — registering proving permanently). Own verbs; freeze v1 — registering discipline in three habits, reviewed per event.

## 2. Acks pairing (receipts requesting — timeouts bounding — retries deciding)

**Definition** — paired acks: requesting receipts bounding timeouts deciding retries (receipts requesting — callbacks awaiting (deliveries confirming — losses naming (requesting proving — firing declining); timeouts bounding — waits capping (hangs refusing — UX unblocking (bounding funding — freezing declining); retries deciding — failures judging (idempotents resending — storms refusing (deciding owning — spamming declining).

**What problem it solves** — the fire-and-forget trio: *receipts unrequesting* (callbacks unawaited — deliveries unconfirmed (losses unnamed — drops hiding (unrequesting billing — reliability failing); *timeouts unbounding* (waits uncapped — hangs ruling (UX freezing — users leaving (unbounding charging — experience failing); *retries undeciding* (failures unjudged — resends unplanned (storms ruling — duplicates flooding (undeciding costing — correctness failing). Paired acks converting firing to requesting (callbacks awaiting — waits capping (failures judging — drops ending); reviewers finding ack rows per critical emit (pairing proving → verifiable; firing → returned).

**Modern guidance** — the pairing lines per critical emit (review-enforced): *receipts requesting* — callbacks awaiting (deliveries confirming — losses naming (requesting proving — firing refusing (receipts earning — drops ending); *timeouts bounding* ([ITVocabulary 04/2.2](<../../../../ITVocabulary/04 Networks Web and Internet Vocabulary/sections/2. Web talk/2.2. Latency vs bandwidth and timeouts.md>) — waits capping (hangs refusing — UX unblocking (bounding funding — freezing refusing (bounds keeping — users staying); *retries deciding* — failures judging (idempotents resending — storms refusing (deciding owning — spamming refusing (decisions keeping — floods ending).

```typescript
// GOOD: acks pairing — receipts requesting, timeouts bounding (compiled + run live).
import 'reflect-metadata';
import { WebSocketGateway, SubscribeMessage, MessageBody } from '@nestjs/websockets';
function withAck<T>(work: () => T, ms: number): Promise<T> {
  return new Promise((resolve, reject) => {
    const timer = setTimeout(() => reject(new Error('ack-timeout')), ms); // timeouts bounding — waits capping, freezing declining
    try {
      const out = work(); // receipts requesting — callbacks awaiting, firing declining
      clearTimeout(timer);
      resolve(out);
    } catch (e) { clearTimeout(timer); reject(e); }
  });
}
@WebSocketGateway()
class AckGateway {
  @SubscribeMessage('order.place')
  onOrder(@MessageBody() payload: string): string {
    return `placed:${payload}`;
  }
}
const agw = new AckGateway();
void (async () => {
  const ok = await withAck(() => agw.onOrder('x1'), 50);
  let timed = '';
  try { await withAck(() => { throw new Error('down'); }, 50); } catch (e) { timed = (e as Error).message; }
  console.log(ok === 'placed:x1' && timed === 'down' ? 'acks pair' : 'emits fire');
})();
```

```typescript
// BAD: acks firing — receipts unrequesting, retries undeciding (real fire shape).
// // server.emit('order', cart) (callbacks unawaited — losses unnamed — drops hiding).
// // Retry on click (failures unjudged — duplicates flooding). Request receipts; bound waits; decide retries.)
```

**Common confusion** — *"acks make realtime synchronous (pairing blocking)."* Blockingly awaiting receipts (emits stalling — throughput choking (latency spiking — realtime dying (blockingly charging — responsiveness failing); pairing bounding waits (callbacks awaiting — hangs refusing (failures judging — drops ending (pairing earning — blockingly declining). "Sync" describing stalls (emits blocking — throughput choking); acks describing receipts (deliveries confirming — losses naming). Await receipts (receipts requesting — drops ending); cap hangs (timeouts bounding — freezing ending).

**Performance note** — pairing economics: requesting costing callbacks (callbacks awaiting — waits capping (failures judging — drops ending); fired equivalents costing losses (drops hiding — duplicates flooding (trust eroding — revenue risking). Pair cheaply (acks — receipts); fire never (criticals — forgets).

**Mentor note** — teach "every critical emit pairs an ack with a timeout — every flow" (juniors pairing one ack per critical emit design fire-proof reliability on first hearing; timeoutless emits interrogated ("receipt? bound? retry?" — pairing demanding per emit). Pair one emit once (receipts requesting — timeouts bounding tangible (firing ending — pairing proving permanently). Confirm deliveries; judge failures — pairing discipline in three habits, reviewed per emit.

## 3. Broadcasts scoping (self excluding — all including — rooms narrowing)

**Definition** — scoped broadcasts: excluding self including all narrowing rooms (self excluding — senders skipping (echoes declining — loops ending (excluding proving — spamming declining); all including — everyone reaching (announcements serving — presence syncing (including funding — missing declining); rooms narrowing — audiences scoping (members reaching — strangers sparing (narrowing owning — flooding declining).

**What problem it solves** — the unscoped-broadcast trio: *self unexcluding* (senders unskipped — echoes ruling (loops scheduling — clients deduplicating (unexcluding billing — bandwidth failing); *all unincluding* (everyone unreached — announcements unserved (presence unsynced — states diverging (unincluding charging — coherence failing); *rooms unnarrowing* (audiences unscoped — members unreached-strangers-reached (strangers served — floods dating (unnarrowing costing — relevance failing). Scoped broadcasts converting spamming to scoping (senders skipping — everyone reaching (audiences scoping — floods ending); reviewers finding scope rows per broadcast (scoping proving → verifiable; spamming → returned).

**Modern guidance** — the scoping lines per broadcast (review-enforced): *self excluding* — senders skipping (echoes declining — loops ending (excluding proving — spamming refusing (excludes earning — bandwidth keeping); *all including* — everyone reaching (announcements serving — presence syncing (including funding — missing refusing (includes keeping — coherence earning); *rooms narrowing* ([2.2](<./2.2. Rooms scoping audiences.md>) — audiences scoping (members reaching — strangers sparing (narrowing owning — flooding refusing (narrows keeping — relevance earning).

```typescript
// GOOD: broadcasts scoping — self excluding, rooms narrowing (compiled + run live).
import 'reflect-metadata';
import { WebSocketGateway, SubscribeMessage, MessageBody, ConnectedSocket } from '@nestjs/websockets';
import { Socket } from 'socket.io';
@WebSocketGateway()
class CastGateway {
  server!: { to: (room: string) => { emit: (ev: string, data: string) => void } };
  @SubscribeMessage('shout')
  onShout(@MessageBody() payload: string, @ConnectedSocket() client: Socket): string {
    const roomOf = (client.data as { room?: string }).room ?? 'lobby'; // rooms narrowing — audiences scoping, flooding declining
    this.server.to(roomOf).emit('shouted', payload); // self excluding — senders skipping, spamming declining
    return `cast:${roomOf}`;
  }
}
const cgw = new CastGateway();
const seen: string[] = [];
cgw.server = { to: (room: string) => ({ emit: (ev: string, data: string) => { seen.push(`${room}/${ev}=${data}`); } }) };
const fake = { data: { room: 'r2' } } as unknown as Socket;
console.log(cgw.onShout('hi', fake) === 'cast:r2' && seen.join(';') === 'r2/shouted=hi' ? 'broadcasts scope' : 'emits spam');
```

```typescript
// BAD: broadcasts spamming — self unexcluding, rooms unnarrowing (real spam shape).
// // server.emit('update', state) to everyone (senders unskipped — strangers served — floods dating).
// // Echo back to sender (loops scheduling — bandwidth failing). Skip self; include all-when-meant; narrow rooms.)
```

**Common confusion** — *"broadcast is the default emit (scoping skipping)."* Skipping scoping audiences (everyone served — strangers reached (relevance unpriced — floods dating (skipping charging — trust failing); scoping narrowing rooms (members reaching — strangers sparing (echoes declining — relevance earning (scoping earning — skipping declining). "Default" describing comfort (everyone served — floods dating); broadcasts describing scope (self skipped — rooms narrowed). Exclude self (self excluding — loops ending); narrow rooms (rooms narrowing — floods ending).

**Performance note** — scoping economics: excluding costing branches (senders skipping — everyone reaching (audiences scoping — floods ending); spammed equivalents costing floods (echoes looping — strangers served (bandwidth burning — trust eroding). Scope cheaply (broadcasts — rooms); spam never (emits — everyones).

**Mentor note** — teach "self, all, or room stated — every broadcast" (juniors scoping one audience per broadcast design spam-proof messaging on first hearing; scopeless emits interrogated ("to whom? why all?" — scoping demanding per broadcast). Scope one broadcast once (self excluding — rooms narrowing tangible (spamming ending — scoping proving permanently). Skip senders; spare strangers — scoping discipline in three habits, reviewed per broadcast.
