## 1. Every transport upgrading (upgrades negotiating — frames typing — heartbeats proving)

**Definition** — the transport gate: each gateway negotiating upgrades, typing frames, proving heartbeats (upgrades negotiating — methods getting (headers stating — versions choosing (negotiating proving — guessing declining); frames typing — opcodes naming (fragments bounding — giants refusing (typing funding — blobbing declining); heartbeats proving — pings pacing (pongs answering — deads detecting (proving owning — lingering declining).

**What problem it solves** — the ungated-transport trio: *upgrades unnegotiating* (methods ungotten — headers unstated (versions unchosen — handshakes guessing (unnegotiating billing — connection failing); *frames untyping* (opcodes unnamed — fragments unbounded (giants unrefused — peers guessing (untyping charging — interop failing); *heartbeats unproving* (pings unpaced — pongs unanswered (deads undetected — half-opens lingering (unproving costing — liveness failing). Gated transports converting guessing to negotiating (methods getting — opcodes naming (pings pacing — drops ending); reviewers returning gateways missing any row (gating proving → verifiable; guessing → returned).

**Modern guidance** — the gating lines per gateway (review-enforced): *upgrades negotiating* ([1.1](<../1. Transport thinking/1.1. Handshakes upgrading HTTP.md>) — methods getting (headers stating — versions choosing (negotiating proving — guessing refusing (negotiates earning — stalls ending); *frames typing* ([1.2](<../1. Transport thinking/1.2. Frames streaming messages.md>) — opcodes naming (fragments bounding — giants refusing (typing funding — blobbing refusing (types keeping — chokes ending); *heartbeats proving* ([1.2](<../1. Transport thinking/1.2. Frames streaming messages.md>) — pings pacing (pongs answering — deads detecting (proving owning — lingering refusing (proves keeping — leaks ending).

**Common confusion** — *"checklists slow prototyping (gates delaying)."* Delaying gating rows (upgrades negotiating — frames typing (heartbeats proving — drops ending (delaying funding — guessing declining); rushing gating rewrites (handshakes guessing — peers failing (half-opens lingering — prototypes reworked (rushing charging — velocity failing). "Slow" describing rows (headers stated — caps listed); fast describing guesses (defaults hoped — reworks dated). State headers (upgrades negotiating — stalls ending); bound frames (frames typing — chokes ending).

**Performance note** — gating economics: negotiating costing rows (methods getting — opcodes naming (pings pacing — drops ending); guessed equivalents costing reworks (handshakes guessing — peers failing (leaks lingering — trust eroding). Gate cheaply (transports — rows); guess never (gateways — defaults).

**Mentor note** — teach "no transport rows, no gateway review — every connection" (juniors gating one gateway per three proofs design guess-proof transports on first hearing; gateless gateways interrogated ("upgrade? frames? heartbeat?" — gating demanding per gateway). Gate one gateway once (upgrades negotiating — frames typing tangible (guessing ending — gating proving permanently). Demand headers; demand caps — gating discipline in three habits, reviewed per gateway.
