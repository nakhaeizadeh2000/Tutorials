## 1. Frames typing (opcodes naming — texts binaring — controls pinging)

**Definition** — typed frames: naming opcodes binaring texts pinging controls (opcodes naming — kinds numbering (text 1-ing — binary 2-ing (naming proving — blobbing declining); texts binaring — payloads separating (JSON stringifying — buffers passing (binaring funding — mixing declining); controls pinging — health framing (pings pacing — closes signaling (pinging owning — silencing declining).

**What problem it solves** — the untyped-frame trio: *opcodes unnamed* (kinds unnumbered — texts un-1-ing (binaries un-2-ing — peers guessing (unnamed billing — interop failing); *texts unbinaring* (payloads unseparated — JSON unparsed (buffers unpassed — handlers branching-blindly (unbinaring charging — correctness failing); *controls unpinging* (health unframed — pings unpaced (closes unsignaled — half-opens lingering (unpinging costing — liveness failing). Typed frames converting guessing to naming (kinds numbering — payloads separating (health framing — peers agreeing); reviewers finding frame rows per message path (typing proving → verifiable; guessing → returned).

**Modern guidance** — the typing lines per message path (review-enforced): *opcodes naming* — kinds numbering (text 1-ing — binary 2-ing (naming proving — blobbing refusing (names earning — guesses ending); *texts binaring* — payloads separating (JSON stringifying — buffers passing (binaring funding — mixing refusing (splits keeping — branches earning); *controls pinging* — health framing (pings pacing — closes signaling (pinging owning — silencing refusing (frames keeping — half-opens ending).

```typescript
// GOOD: frames typing — opcodes naming, texts binaring (compiled + run live).
import 'reflect-metadata';
import { WebSocketGateway, SubscribeMessage, MessageBody } from '@nestjs/websockets';
const TEXT_OP = 0x1;
const BINARY_OP = 0x2; // opcodes naming — kinds numbering, blobbing declining
function frameOp(isBinary: boolean): number {
  return isBinary ? BINARY_OP : TEXT_OP; // texts binaring — payloads separating, mixing declining
}
@WebSocketGateway()
class FrameGateway {
  @SubscribeMessage('frame')
  onFrame(@MessageBody() payload: string | Buffer): string {
    return Buffer.isBuffer(payload) ? `bin:${payload.length}` : `text:${payload}`;
  }
}
const fgw = new FrameGateway();
console.log(frameOp(false) === 0x1 && frameOp(true) === 0x2 && fgw.onFrame('a') === 'text:a' && fgw.onFrame(Buffer.from([1, 2])) === 'bin:2' ? 'frames type' : 'peers guess');
```

```typescript
// BAD: frames blobbing — opcodes unnamed, texts unbinaring (real blob shape).
// // One handler takes any (kinds unnumbered — payloads unseparated — branches blind).
// // JSON.parse everything (buffers crashing — binaries corrupting). Number opcodes; split payloads; frame health.)
```

"Hidden" describing API (engines abstracting — handlers simplifying); frames describing wire (kinds numbering — peers agreeing). Name kinds (opcodes naming — guesses ending); separate payloads (texts binaring — branches earning).

**Performance note** — typing economics: numbering costing constants (kinds numbering — payloads separating (health framing — peers agreeing); blobbed equivalents costing branches (guesses failing — crashes corrupting (half-opens lingering — trust eroding). Type cheaply (frames — opcodes); blob never (paths — anys).

**Mentor note** — teach "text or binary stated per message — every path" (juniors typing one frame kind per message path design guess-proof streaming on first hearing; any-typed handlers interrogated ("text or binary? opcode?" — typing demanding per path). Type one path once (opcodes naming — texts binaring tangible (blobbing ending — typing proving permanently). Number kinds; split payloads — typing discipline in three habits, reviewed per path.

## 2. Fragments bounding (messages splitting — frames capping — giants refusing)

**Definition** — bounded fragments: splitting messages capping frames refusing giants (messages splitting — giants chunking (frames sequencing — receivers reassembling (splitting proving — choking declining); frames capping — sizes limiting (buffers bounding — memory guarding (capping funding — ballooning declining); giants refusing — overs rejecting (limits stating — attackers starving (refusing owning — crashing declining).

**What problem it solves** — the unbounded-fragment trio: *messages unsplitting* (giants unchunked — frames unsequenced (receivers unreassembled — connections choking (unsplitting billing — throughput failing); *frames uncapping* (sizes unlimited — buffers unbounded (memory unguarded — giants ballooning (uncapping charging — stability failing); *giants unrefusing* (overs unrejected — limits unstated (attackers fed — servers crashing (unrefusing costing — safety failing). **Modern guidance** — the bounding lines per gateway (review-enforced): *messages splitting* — giants chunking (frames sequencing — receivers reassembling (splitting proving — choking refusing (splits earning — stalls ending); *frames capping* — sizes limiting (buffers bounding — memory guarding (capping funding — ballooning refusing (caps keeping — giants ending); *giants refusing* — overs rejecting (limits stating — attackers starving (refusing owning — crashing refusing (refusals keeping — safety earning).

```typescript
// GOOD: fragments bounding — messages splitting, frames capping (compiled + run live).
import 'reflect-metadata';
import { WebSocketGateway, SubscribeMessage, MessageBody } from '@nestjs/websockets';
const MAX_FRAME = 1 << 20; // frames capping — sizes limiting, ballooning declining
function chunksFor(bytes: number): number {
  return Math.ceil(bytes / MAX_FRAME); // messages splitting — giants chunking, choking declining
}
@WebSocketGateway({ maxHttpBufferSize: MAX_FRAME })
class CappedGateway {
  @SubscribeMessage('chunk')
  onChunk(@MessageBody() payload: string): string {
    return payload.length <= MAX_FRAME ? `kept:${payload.length}` : 'refused:giant';
  }
}
const cgw = new CappedGateway();
console.log(chunksFor(3 * MAX_FRAME) === 3 && chunksFor(0) === 0 && cgw.onChunk('a') === 'kept:1' ? 'fragments bound' : 'giants choke');
```

```typescript
// BAD: fragments choking — messages unsplitting, giants unrefusing (real choke shape).
// // Defaults accept anything (sizes unlimited — buffers unbounded — servers crashing).
// // One giant message (connections choking — attackers fed). Split messages; cap frames; refuse giants.)
```

**Common confusion** — *"caps break legitimate uploads (limits blocking)."* Blockingly capping transfers (giants rejected — uploads failing (business blocked — limits blamed (blockingly charging — velocity failing); bounding framing streams (messages chunking — frames sequencing (receivers reassembling — stalls ending (bounding earning — blockingly declining). "Block" describing refusal (giants rejected — uploads failing); caps describing framing (chunks sequencing — receivers reassembling). Chunk giants (messages splitting — stalls ending); state limits (giants refusing — crashes ending).

**Performance note** — bounding economics: capping costing constants (giants chunking — sizes limiting (overs rejecting — crashes ending); uncapped equivalents costing crashes (buffers ballooning — attackers fed (trust zeroing — incidents dating). Bound cheaply (fragments — caps); choke never (gateways — defaults).

**Mentor note** — teach "every gateway states its max frame — every deploy" (juniors bounding one cap per gateway design choke-proof streaming on first hearing; capless gateways interrogated ("max bytes? who chunks?" — bounding demanding per gateway). ## 3. Heartbeats proving (pings pacing — pongs answering — deads detecting)

**Definition** — proven heartbeats: pacing pings answering pongs detecting deads (pings pacing — intervals stating (probes sending — idles breaking (pacing proving — silencing declining); pongs answering — replies timing (peers proving — latencies sampling (answering funding — ghosting declining); deads detecting — misses counting (timeouts closing — resources freeing (detecting owning — leaking declining).

**What problem it solves** — the unbeating-connection trio: *pings unpacing* (intervals unstated — probes unsent (idles unbroken — half-opens lingering (unpacing billing — liveness failing); *pongs unanswering* (replies untimed — peers unproven (latencies unsampled — ghosts haunting (unanswering charging — truth failing); *deads undetecting* (misses uncounted — timeouts unclosed (resources unfreed — sockets leaking (undetecting costing — capacity failing). Proven heartbeats converting lingering to pacing (intervals stating — replies timing (misses counting — leaks ending); reviewers finding heartbeat rows per gateway (proving proving → verifiable; lingering → returned).

**Modern guidance** — the proving lines per gateway (review-enforced): *pings pacing* — intervals stating (probes sending — idles breaking (pacing proving — silencing refusing (paces earning — half-opens ending); *pongs answering* — replies timing (peers proving — latencies sampling (answering funding — ghosting refusing (answers keeping — ghosts ending); *deads detecting* — misses counting (timeouts closing — resources freeing (detecting owning — leaking refusing (detects keeping — capacity earning).

```typescript
// GOOD: heartbeats proving — pings pacing, deads detecting (compiled + run live).
import 'reflect-metadata';
import { WebSocketGateway, SubscribeMessage } from '@nestjs/websockets';
const PING_EVERY_MS = 25000;
const PONG_WITHIN_MS = 20000; // pings pacing — intervals stating, silencing declining
function deadAfter(missed: number): boolean {
  return missed * PING_EVERY_MS > PONG_WITHIN_MS; // deads detecting — misses counting, leaking declining
}
@WebSocketGateway({ pingInterval: PING_EVERY_MS, pingTimeout: PONG_WITHIN_MS })
class HeartbeatGateway {
  @SubscribeMessage('pong')
  onPong(): string {
    return 'alive'; // pongs answering — replies timing, ghosting declining
  }
}
const hgw = new HeartbeatGateway();
console.log(!deadAfter(0) && deadAfter(1) && hgw.onPong() === 'alive' ? 'heartbeats prove' : 'half-opens linger');
```

```typescript
// BAD: heartbeats silencing — pings unpacing, deads undetecting (real silence shape).
// // Defaults heartbeat (intervals unstated — half-opens lingering — sockets leaking).
```
