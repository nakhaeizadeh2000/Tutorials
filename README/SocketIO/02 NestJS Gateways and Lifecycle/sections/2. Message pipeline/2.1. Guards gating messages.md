# 2.1. Guards gating messages

## 1. Sockets switching (hosts adapting — contexts reading — payloads reaching)

**Definition** — switched sockets: adapting hosts reading contexts reaching payloads (hosts adapting — HTTP switching (WsArgumentsHost proving — data exposing (adapting owning — assuming declining); contexts reading — clients extracting (sockets pulling — data reaching (reading funding — blindfolding declining); payloads reaching — messages arriving (handlers receiving — logic deciding (reaching owning — starving declining).

**What problem it solves** — the unswitched-guard trio: *hosts unadapting* (HTTP unswitched — WsArgumentsHost unproven (data unexposed — guards blind (unadapting billing — gating failing); *contexts unread* (clients unextracted — sockets unpulled (data unreached — decisions blindfolded (unread charging — judgment failing); *payloads unreached* (messages unarrived — handlers unreceived (logic undecided — features starved (unreached costing — delivery failing). Switched sockets converting blind to adapting (HTTP switching — clients extracting (messages arriving — gates seeing); reviewers finding switch rows per guard (switching proving → verifiable; blinding → returned).

**Modern guidance** — the switching lines per guard (review-enforced): *hosts adapting* — HTTP switching (WsArgumentsHost proving — data exposing (adapting owning — assuming refusing (adapts earning — blinds ending); *contexts reading* — clients extracting (sockets pulling — data reaching (reading funding — blindfolding refusing (reads keeping — decisions earning); *payloads reaching* — messages arriving (handlers receiving — logic deciding (reaching owning — starving refusing (reaches keeping — features flowing).

```typescript
// GOOD: sockets switching — hosts adapting, contexts reading (compiled + run live).
import 'reflect-metadata';
import { CanActivate, ExecutionContext, Injectable } from '@nestjs/common';
import { Socket } from 'socket.io';
function wsClientOf(ctx: { switchToWs: () => { getClient: () => Socket } }): Socket {
  return ctx.switchToWs().getClient(); // hosts adapting — HTTP switching, assuming declining
}
@Injectable()
class RoomGuard implements CanActivate {
  canActivate(ctx: ExecutionContext): boolean {
    const client = wsClientOf({ switchToWs: () => (ctx as unknown as { switchToWs: () => { getClient: () => Socket } }).switchToWs() });
    return (client.data as { joined?: boolean }).joined === true; // contexts reading — clients extracting, blindfolding declining
  }
}
const guard = new RoomGuard();
const mk = (joined: boolean) => ({ switchToWs: () => ({ getClient: () => ({ data: { joined } }) }) }) as unknown as ExecutionContext;
console.log(guard.canActivate(mk(true)) && !guard.canActivate(mk(false)) ? 'sockets switch' : 'guards blind');
```

```typescript
// BAD: sockets blinding — hosts unadapting, contexts unread (real blind shape).
// // canActivate(ctx) { return true; } (hosts unadapted — contexts unread — gates open).
// // HTTP guards reused untouched (data unexposed — decisions blindfolded). Switch hosts; read clients; reach payloads.)
```

**Common confusion** — *"WS guards equal HTTP guards (switching skipping)."* Skipping adapting contexts (HTTP assuming — sockets unpulled (data unreached — denials misfiring (skipping charging — gating failing); switching reading WS (hosts adapting — clients extracting (payloads reaching — gates seeing (switching earning — skipping declining). "Equal" describing names (CanActivate shared — contexts differing); sockets describing hosts (WsArgumentsHost proving — data exposing). Adapt hosts (hosts adapting — blinds ending); extract clients (contexts reading — decisions earning).

**Performance note** — switching economics: adapting costing switches (HTTP switching — clients extracting (messages arriving — gates seeing); blinded equivalents costing breaches (gates open — denials misfired (trust eroding — incidents dating). Switch cheaply (sockets — hosts); blind never (guards — trues).

**Mentor note** — teach "`switchToWs` first, decide second — every WS guard" (juniors switching one host per guard design blind-proof gating on first hearing; switchless guards interrogated ("WsArgumentsHost? client? data?" — switching demanding per guard). Switch one guard once (hosts adapting — contexts reading tangible (blinding ending — switching proving permanently). Prove hosts; pull clients — switching discipline in three habits, reviewed per guard.

## 2. Memberships proving (rooms checking — roles deciding — strangers refusing)

**Definition** — proven memberships: checking rooms deciding roles refusing strangers (rooms checking — rosters consulting (joins proving — squatters refusing (checking owning — flooding declining); roles deciding — permissions reading (writers admitting — readers fencing (deciding funding — mingling declining); strangers refusing — unknowns denying (sockets dropping — logs stating (refusing owning — trespassing declining).

**What problem it solves** — the unproven-membership trio: *rooms unchecked* (rosters unconsulted — joins unproven (squatters ruling — audiences polluted (unchecked billing — relevance failing); *roles undecided* (permissions unread — writers unadmitted (readers unfenced — concerns mingling (undecided charging — clarity failing); *strangers unrefused* (unknowns undenied — sockets undropped (logs unstated — trespass ruling (unrefused costing — safety failing). **Modern guidance** — the proving lines per guarded event (review-enforced): *rooms checking* ([01/2.2](<../../../01 Realtime Foundations and Mental Model/sections/2. Message thinking/2.2. Rooms scoping audiences.md>) — rosters consulting (joins proving — squatters refusing (checking proving — flooding refusing (checks earning — relevance keeping); *roles deciding* — permissions reading (writers admitting — readers fencing (deciding funding — mingling refusing (decides keeping — clarity earning); *strangers refusing* ([1.1](<../1.
```typescript
// GOOD: memberships proving — rooms checking, roles deciding (compiled + run live).
import 'reflect-metadata';
import { CanActivate, ExecutionContext, Injectable, UseGuards } from '@nestjs/common';
import { WebSocketGateway, SubscribeMessage, MessageBody } from '@nestjs/websockets';
import { Socket } from 'socket.io';
function memberOf(client: Socket, room: string, roster: Map<string, Set<string>>): boolean {
  return roster.get(room)?.has((client.data as { sid?: string }).sid ?? '') ?? false; // rooms checking — rosters consulting, flooding declining
}
@Injectable()
class MemberGuard implements CanActivate {
  constructor(private readonly roster: Map<string, Set<string>>, private readonly room: string) {}
  canActivate(ctx: ExecutionContext): boolean {
    const ws = (ctx as unknown as { switchToWs: () => { getClient: () => Socket } }).switchToWs();
    return memberOf(ws.getClient(), this.room, this.roster); // roles deciding — permissions reading, mingling declining
  }
}
@WebSocketGateway()
class ChatRoomGateway {
  @SubscribeMessage('chat.say')
  @UseGuards()
  onSay(@MessageBody() payload: string): string {
    return `said:${payload}`;
  }
}
const roster = new Map<string, Set<string>>([['r1', new Set(['u1'])]]);
const guard = new MemberGuard(roster, 'r1');
const mk = (sid: string) => ({ switchToWs: () => ({ getClient: () => ({ data: { sid } }) }) }) as unknown as ExecutionContext;
console.log(guard.canActivate(mk('u1')) && !guard.canActivate(mk('u9')) ? 'memberships prove' : 'squatters rule');
```

```typescript
// BAD: memberships squatting — rooms unchecked, strangers unrefused (real squat shape).
// // @SubscribeMessage('admin.nuke') onNuke() (rosters unconsulted — strangers unrefused — trespass ruling).
// // Guard checks login only (rooms unchecked — audiences polluted). Check rooms; decide roles; refuse strangers.)
```

**Common confusion** — *"arrival auth covers messages (memberships inheriting)."* Inheriting trusting connects (handshakes verified — rooms unchecked (squatters ruling — audiences polluted (inheriting charging — gating failing); proving checking rooms (rosters consulting — permissions reading (unknowns denying — pollution ending (proving earning — inheriting declining). "Cover" describing arrivals (connects verified — messages assumed); memberships describing events (rooms checked — strangers denied). Verify arrivals (handshakes verifying — trespass ending); prove per event (rooms checking — squatting ending).

**Performance note** — proving economics: checking costing lookups (rosters consulting — permissions reading (unknowns denying — pollution ending); squatted equivalents costing floods (audiences polluted — trespass dated (trust zeroing — incidents compounding). Prove cheaply (memberships — lookups); squat never (events — inherits).

**Mentor note** — teach "arrival admits the socket, membership admits the message — every event" (juniors proving one membership per guarded event design squat-proof gating on first hearing; connect-only auth interrogated ("room? role?" — proving demanding per event). Prove one event once (rooms checking — roles deciding tangible (squatting ending — proving proving permanently). Consult rosters; deny unknowns — proving discipline in three habits, reviewed per event.

## 3. Denials throwing (exceptions raising — shapes mapping — clients handling)

**Definition** — thrown denials: raising exceptions mapping shapes handling clients (exceptions raising — guards refusing (WsExceptions stating — silence ending (raising proving — opening declining); shapes mapping — errors translating (filters catching — envelopes unifying (mapping funding — leaking declining); clients handling — receivers branching (retries deciding — logins redirecting (handling owning — crashing declining).

**What problem it solves** — the silent-denial trio: *exceptions unraised* (guards unrefusing — denials unspoken (clients hanging — UX freezing (unraised billing — experience failing); *shapes unmapped* (errors untranslated — filters uncaught (stacks leaking — internals exposed (unmapped charging — security failing); *clients unhandled* (receivers unbranched — retries undecided (logins unredirected — apps crashing (unhandled costing — robustness failing). Thrown denials converting hanging to raising (guards refusing — errors translating (receivers branching — crashes ending); reviewers finding denial rows per guard (throwing proving → verifiable; hanging → returned).

**Modern guidance** — the throwing lines per guard (review-enforced): *exceptions raising* — guards refusing (WsExceptions stating — silence ending (raising proving — opening refusing (raises earning — hangs ending); *shapes mapping* ([2.2](<./2.2. Failures answering errors.md>) — errors translating (filters catching — envelopes unifying (mapping funding — leaking refusing (maps keeping — security earning); *clients handling* — receivers branching (retries deciding — logins redirecting (handling owning — crashing refusing (handles keeping — robustness earning).

```typescript
// GOOD: denials throwing — exceptions raising, clients handling (compiled + run live).
import 'reflect-metadata';
import { WsException } from '@nestjs/websockets';
function deny(reason: string): never {
  throw new WsException(reason); // exceptions raising — guards refusing, opening declining
} // shapes mapping — errors translating, leaking declining (filter shapes land in 2.2)
function handled(outcome: string): boolean {
  return outcome === 'ok' || outcome.startsWith('denied'); // clients handling — receivers branching, crashing declining
}
let thrown = '';
try { deny('not-a-member'); } catch (e) { thrown = (e as WsException).message; }
console.log(thrown === 'not-a-member' && handled('ok') && handled('denied:room') && !handled('hang') ? 'denials throw' : 'clients hang');
```

**Performance note** — throwing economics: raising costing exceptions (guards refusing — errors translating (receivers branching — crashes ending); silenced equivalents costing hangs (clients hanging — reasons missing (UX freezing — users leaving). Throw cheaply (denials — reasons); silence never (guards — falses).

**Mentor note** — teach "deny with a WsException, never a bare false — every guard" (juniors throwing one denial per refusal design hang-proof gating on first hearing; boolean denials interrogated ("reason? shape? client branch?" — throwing demanding per denial).
