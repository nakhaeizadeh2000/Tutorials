# System Design track (recommended order, October 2026 era)

Large-scale systems from foundations to production: interview-grade design method, back-of-envelope estimation, bottleneck-first thinking, scaling reads and writes, reliability, data at scale, coordination, delivery, and judgment — from zero to hero and beyond (junior to mentor depth). This track teaches *design under constraints*: clarify scope, estimate load, name the binding constraint, choose per numbers, and prove it. Estimation *meta-skills* live in [Algorithm Design 07](<../AlgorithmDesign/07 Production Problem Solving and Interview Mastery/README.md>) (layers, honesty, probes — linked, never re-taught); capacity *judgment* lives in [Databases 07](<../Databases/07 Production Data Use and Interview Mastery/README.md>) (slots, headroom — linked, never re-taught); failure *prediction* lives in [Database Design 01](<../DatabaseDesign/01 Modeling Foundations and Mental Model/README.md>) (ordered bottlenecks — linked, never re-taught); service *mechanics* live in the [Microservices track](<../Microservices/README.md>) (boundaries, comms, resilience — linked, never re-taught). Examples are runnable arithmetic and design sketches in `typescript` — no framework vehicle: numbers are the runtime here. Version-sensitive claims are labeled (as of October 2026: Dean–Barroso latency numbers era; TypeScript 5.9).
