# 5.1. Common interview QA data systems

## 1. Stores live under pressure (accesses, indexes, splits — diagnosed with fixes, priced)

**Definition** — pressured stores: diagnosed accesses fixing indexes pricing splits (accesses diagnosing — shapes stating (counts quoting — mixes refusing (diagnosing proving — vibing declining); indexes fixing — receipts keeping (plans reading — taxes netting (fixing owning — blessing declining); splits pricing — thresholds judging (syncs costing — sprawls refusing (pricing funding — hoping declining).

**What problem it solves** — the whiteboard-store trio: *accesses undiagnosing* (shapes unstated — counts unquoted (mixes ruling — choices vibed (undiagnosing billing — guessing failing); *indexes unfixing* (receipts unkept — plans unread (taxes unnetted — blessings ruling (unfixing charging — claiming failing); *splits unpricing* (thresholds unjudged — syncs uncosted (sprawls unrefused — stores collected (unpricing costing — toil failing). Pressured stores converting vibed to diagnosing (shapes stating — receipts keeping (thresholds judging — offers earning); interviewers finding numbers per store (pressuring proving → hired; vibing → passed).

**Modern guidance** — the pressured lines per store question (hire-enforced): *accesses diagnosing* ([1.1](<../../sections/1. Store thinking/1.1. Stores choosing per access.md>) — shapes stating (counts quoting — mixes refusing (diagnosing proving — vibing refusing (shapes earning — offers funding); *indexes fixing* ([1.2](<../../sections/1. Store thinking/1.2. Indexes pricing queries.md>) — receipts keeping (plans reading — taxes netting (fixing owning — blessing refusing (fixes funding — latency bounding); *splits pricing* ([1.1](<../../sections/1. Store thinking/1.1. Stores choosing per access.md>) — thresholds judging (syncs costing — sprawls refusing (pricing funding — hoping refusing (prices stating — toil bounding).

```typescript
// GOOD: stores answering — diagnosed accesses fixing indexes (commented answer shape).
// // "Catalog 9k reads, 50 writes, join-heavy — relations; covering index tenant-status-created, receipt 400→12ms, net win 40k vs 100; single store, split at join-pain 70." (shapes stating — receipts keeping — thresholds judging — numbers first, verdict second.)
```

```typescript
// BAD: stores vibing — accesses undiagnosing, splits unpricing (commented weak shape).
// // "Postgres, it's solid." (shapes unstated — receipts unkept — thresholds unjudged).
// // "Add Redis if slow." (taxes unnetted — sprawls unrefused). Diagnose accesses; fix indexes; price splits.)
```

**Common confusion** — *"naming stores answers (choices listing)."* Listing reciting defaults (shapes unstated — receipts unkept (thresholds unjudged — numbers missing (listing charging — hiring failing); diagnosing quoting numbers (accesses diagnosing — indexes fixing (splits pricing — offers earning (diagnosing proving — listing declining). "Naming" describing comfort (stores listing — numbers missing); answers describing arithmetic (counts quoting — taxes netting). State shapes (accesses diagnosing — offers funding); keep receipts (indexes fixing — latency bounding).

**Performance note** — pressured economics: quoting costing numbers (shapes stating — receipts keeping (thresholds judging — offers earning); vibed equivalents costing passes (choices vibed — blessings ruling (sprawls funding — trust eroding). Quote cheaply (stores — numbers); vibe never (names — comforts).

**Mentor note** — teach "numbers first, store second, split gated" (juniors answering one store triple per interview design vibe-proof offers on first hearing; numberless answers interrogated ("reads? receipt? threshold?" — diagnosing demanding per answer). Answer one store once (accesses diagnosing — indexes fixing tangible (vibing ending — diagnosing proving permanently). Count accesses; net taxes — answering discipline in three habits, rehearsed per interview.
