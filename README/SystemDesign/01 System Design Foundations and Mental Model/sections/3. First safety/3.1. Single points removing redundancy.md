# 3.1. Single points removing redundancy

## 1. Points listing (instances counting — zones mapping — blasts sizing)

**Definition** — listed single points: counted instances mapping zones sizing blasts (instances counting — singletons finding (replicas verifying — spares demanding (counting proving — assuming declining); zones mapping — regions plotting (failures bounding — quorums placing (mapping funding — stacking declining); blasts sizing — radii measuring (damages pricing — priorities ordering (sizing owning — hoping declining).

**What problem it solves** — the unlisted-SPOF trio: *instances uncounting* (singletons unfound — replicas unverified (spares undemanded — failures totalizing (uncounting billing — redundancy hoping); *zones unmapping* (regions unplotted — failures unbounded (quorums unplaced — splits braining (unmapping charging — topology failing); *blasts unsizing* (radii unmeasured — damages unpriced (priorities unordered — mitigations misordered (unsizing costing — triage bluffing). Listed points converting hoping to counting (singletons finding — regions plotting (radii measuring — totals preventing); reviewers finding SPOF lists per design (listing proving → verifiable; hoping → returned).

**Modern guidance** — the listing lines per design (review-enforced): *instances counting* (singletons finding — replicas verifying (spares demanding — assuming declining (counting proving — hoping refusing (counts earning — totals preventing); *zones mapping* (regions plotting — failures bounding (quorums placing — stacking declining (mapping funding — piling refusing (maps keeping — splits placing); *blasts sizing* (radii measuring — damages pricing (priorities ordering — hoping declining (sizing owning — guessing refusing (sizes funding — triage earning).

```typescript
// GOOD: points listing — counted instances mapping zones (compiled + run live).
interface Point { // instances counting — singletons finding, assuming declining
  name: string;
  replicas: number;
  zones: number;
}
function single(points: Point[]): string[] {
  const gaps: string[] = []; // zones mapping — regions plotting, stacking declining
  for (const p of points) {
    if (p.replicas < 2 || p.zones < 2) gaps.push(p.name);
  }
  return gaps; // blasts sizing — radii measuring, hoping declining
}
const listed: Point[] = [
  { name: 'api', replicas: 3, zones: 3 },
  { name: 'primary-db', replicas: 1, zones: 1 },
];
console.log(single(listed).join() === 'primary-db' ? 'points list' : 'sps hide');
```

```typescript
// BAD: SPOFs hiding — instances uncounting, zones unmapping (real total shape).
// // Single AZ deploy (replicas unverified — failures totalizing — redundancy hoping).
// // Blast unknown (damages unpriced — mitigations misordered). Count instances; map zones; size blasts.)
```

**Common confusion** — *"redundancy doubles cost (copies billing)."* Billing provisioning spares (replicas numbering — zones spanning (standbys warming — bills growing (billing proving — budget funding); hiding risking totals (singletons failing — blasts unlimited (outages maximizing — trust zeroing (hiding charging — redundancy hoping). "Doubling" describing invoices (spares numbering — bills growing); points describing survival (instances counting — totals preventing). Count singletons (replicas verifying — spares demanding); map regions (zones plotting — splits placing).

**Performance note** — listing economics: counting costing rows (singletons finding — regions plotting (radii measuring — totals preventing); hidden equivalents costing totals (failures totalizing — blasts unlimited (outages maximizing — trust zeroing). Count cheaply (points — designs); hide never (SPOFs — blasts).

**Mentor note** — teach "every singleton names its blast" (juniors listing one SPOF row per design outage-proof audits on first hearing; unlisted singletons interrogated ("replicas? zones?" — listing demanding per design). List one point once (singletons finding — regions plotting tangible (hoping ending — listing proving permanently). Verify replicas; place quorums — listing discipline in three habits, reviewed per design.

**Definition** — added copies: numbered replicas rehearsing failovers splitting brains (replicas numbering — spares provisioning (standbys warming — takeovers readying (numbering proving — singling declining); failovers rehearsing — switches practicing (downtimes measuring — recoveries proving (rehearsing funding — hoping declining); brains splitting — quorums requiring (partitions deciding — halves refusing (splitting owning — merging declining).

```typescript
// GOOD: copies adding — numbered replicas rehearsing failovers (compiled + run live).
function quorum(n: number): number {
  return Math.floor(n / 2) + 1; // replicas numbering — spares provisioning, singling declining
}
function splitBrain(replicas: number, alive: number): string {
  if (alive >= quorum(replicas)) return 'SERVE'; // brains splitting — quorums requiring, merging declining
  return 'REFUSE'; // failovers rehearsing — switches practicing, fumbling declining (caller asserts below)
}
console.log(quorum(3) === 2 && quorum(5) === 3 && splitBrain(3, 2) === 'SERVE' && splitBrain(3, 1) === 'REFUSE' ? 'copies add' : 'singles fail');
```

**Performance note** — adding economics: numbering costing spares (replicas provisioning — switches practicing (quorums requiring — totals preventing); single equivalents costing totals (failures totalizing — cuts fumbling (data diverging — trust zeroing). Number cheaply (copies — points); single never (primaries — blasts).

**Mentor note** — teach "odd replicas, rehearsed failover, quorum writes" (juniors adding one copy-set per point design split-proof redundancy on first hearing; even singletons interrogated ("quorum? rehearsed?" — adding demanding per point). ## 3. Correlations breaking (faults diversifying — deploys staggering — clocks skewing)

**Definition** — broken correlations: diversified faults staggering deploys skewing clocks (faults diversifying — causes varying (suppliers mixing — regions spreading (diversifying proving — coupling declining); deploys staggering — releases phasing (fleets fractioning — blasts bounding (staggering funding — flipping declining); clocks skewing — times offsetting (orderings bounding — simultaneity refusing (skewing owning — assuming declining).

**What problem it solves** — the correlated-failure trio: *faults undiversifying* (causes unvarying — suppliers unsourced (regions unspread — fates coupling (undiversifying billing — independence failing); *deploys unstaggering* (releases unphased — fleets unflipped (blasts unbound — bugs fleet-wideing (unstaggering charging — safety failing); *clocks unskewing* (times unoffset — orderings unbounded (simultaneity assuming — causality breaking (unskewing costing — correctness bluffing). Broken correlations converting coupling to diversifying (causes varying — releases phasing (times offsetting — fates decoupling); reviewers finding diversity axes per design (breaking proving → verifiable; coupling → returned).

**Modern guidance** — the breaking lines per design (review-enforced): *faults diversifying* (causes varying — suppliers mixing (regions spreading — fates decoupling (diversifying proving — coupling refusing (mixes earning — fate ending); *deploys staggering* (releases phasing — fleets fractioning (blasts bounding — flipping declining (staggering funding — fleet-wide refusing (phases keeping — bugs containing); *clocks skewing* (times offsetting — orderings bounding (simultaneity refusing — assuming declining (skewing owning — hoping refusing (offsets measuring — causality keeping).

```typescript
// GOOD: correlations breaking — diversified faults staggering deploys (compiled + run live).
function correlated(shareAZ: boolean, shareDeploy: boolean, shareClock: boolean): boolean {
  return shareAZ || shareDeploy || shareClock; // faults diversifying — causes varying, coupling declining
}
function rolloutOk(staggered: boolean, canaryPct: number): boolean {
  return staggered && canaryPct > 0; // deploys staggering — releases phasing, flipping declining
} // clocks skewing — times offsetting, assuming declining (caller asserts below)
console.log(!correlated(false, false, false) && correlated(true, false, false) && rolloutOk(true, 10) && !rolloutOk(false, 100) ? 'correlations break' : 'fates couple');
```

```typescript
// BAD: fates coupling — faults undiversifying, deploys unstaggering (real common-mode shape).
// // Same AZ, same deploy (causes unvarying — regions unspread — fates coupling).
// // Big-bang release (bugs fleet-wideing — safety failing). Diversify causes; stagger deploys; skew clocks.)
```

**Common confusion** — *"redundancy needs identical copies (sameness cloning)."* Cloning replicating fate (causes shared — deploys synced (bugs fleet-wideing — outages totalizing (cloning charging — diversity failing); breaking diversifying axes (suppliers mixing — releases phasing (times offsetting — fates decoupling (breaking proving — coupling declining). "Identical" describing images (copies cloning — fate sharing); redundancy describing independence (causes varying — blasts bounding). Vary suppliers (regions spreading — fate decoupling); phase rollouts (fleets fractioning — bugs containing).

**Performance note** — breaking economics: diversifying costing axes (causes varying — releases phasing (times offsetting — fates decoupling); coupled equivalents costing common-modes (fates coupling — bugs fleet-wideing (outages totalizing — trust zeroing). Diversify cheaply (axes — designs); couple never (fates — failures).

**Mentor note** — teach "same failure must never take all copies" (juniors breaking one correlation per design outage-proof redundancy on first hearing; correlated copies interrogated ("shared what?" — breaking demanding per copy). Break one correlation once (causes varying — releases phasing tangible (coupling ending — breaking proving permanently). Mix suppliers; offset clocks — breaking discipline in three habits, reviewed per design.
