## 1. Powers rounding (tens working — errors bounding — digits dropping)

**What problem it solves** — the spreadsheet trio: *tens unworking* (orders unrounded — digits uncounted (models unbuilt — decisions stalled (unworking billing — arithmetic failing); *errors unbounding* (factors unstated — precision unclaimed (confidence bluffing — surprises scheduling (unbounding charging — honesty failing); *digits undropping* (decimals undefended — details undelayed (analyses paralyzing — interviews timing-out (undropping costing — judgment missing). **Modern guidance** — the rounding lines per estimate (review-enforced): *tens working* (orders rounding — thousands bunching (millions scaling — counting declining (working proving — modeling refusing (rounds earning — speed keeping); *errors bounding* (factors stating — +/-2x admitting (precision declining — theater refusing (bounds owning — bluffing ending); *digits dropping* (decimals refusing — details deferring (decisions funding — stalling declining (drops keeping — timing-out ending).

```typescript
// GOOD: powers rounding — worked tens bounding errors (compiled + run live).
function round10(n: number): number {
  return 10 ** Math.round(Math.log10(n)); // tens working — orders rounding, counting declining
}
function within2x(est: number, actual: number): boolean {
  return actual / 2 <= est && est <= actual * 2; // errors bounding — factors stating, theater declining
} // digits dropping — decimals refusing, stalling declining (asserted below)
console.log(round10(86400) === 100000 && within2x(100000, 86400) && !within2x(1000, 86400) ? 'powers round' : 'sheets model');
```

// GOOD: quotas deriving — multiplied QPS sizing machines (compiled + run live).
function machines(qps: number, msEach: number, perMachine: number): number {
  const slots = Math.ceil((qps * msEach) / 1000); // QPS multiplying — reads splitting, guessing declining

} // bytes sizing — payloads measuring, hoping declining (caller asserts below)
function storedGB(qps: number, bytesEach: number, days: number): number {
