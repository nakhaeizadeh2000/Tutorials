# 1.2. Replicas scaling reads

## 1. Reads fanning (copies multiplying — loads splitting — primaries unburdening)

**Definition** — fanned-out reads: multiplied copies splitting loads unburdening primaries (copies multiplying — replicas numbering (followers provisioning — lag monitoring (multiplying proving — singling declining); loads splitting — queries routing (shares balancing — hotspots cooling (splitting funding — piling declining); primaries unburdening — writers freeing (locks easing — tails trimming (unburdening owning — choking declining).

**What problem it solves** — the single-reader trio: *copies unmultiplying* (replicas unnumbered — followers unprovisioned (loads unshared — primaries choking (unmultiplying billing — scaling failing); *loads unsplitting* (queries unrouted — shares unbalanced (hotspots burning — neighbors degrading (unsplitting charging — fairness failing); *primaries unburdening* (writers unfreeing — locks uncontended (tails growing — writes stalling (unburdening costing — throughput dying). Fanned reads converting choking to multiplying (replicas numbering — queries routing (writers freeing — loads flowing); reviewers finding replica counts per read path (fanning proving → verifiable; choking → returned).

**Modern guidance** — the fanning lines per read path (review-enforced): *copies multiplying* ([Databases 07/1.1](<../../../../Databases/07 Production Data Use and Interview Mastery/sections/1. Production judgment/1.1. Capacity judgment under constraints.md>) — replicas numbering (followers provisioning — lag monitoring (multiplying proving — singling refusing (numbers earning — choking ending); *loads splitting* (queries routing — shares balancing (hotspots cooling — piling declining (splitting funding — skewing refusing (routes keeping — fairness earning); *primaries unburdening* (writers freeing — locks easing (tails trimming — choking declining (unburdening owning — contending refusing (frees funding — throughput keeping).

```typescript
// GOOD: reads fanning — multiplied copies splitting loads (compiled + run live).
function replicasFor(readQps: number, perReplica: number): number {
  return Math.ceil(readQps / perReplica); // copies multiplying — replicas numbering, singling declining
}
function primaryLeft(totalQps: number, replicaQps: number, replicas: number): number {
  return Math.max(0, totalQps - replicaQps * replicas); // loads splitting — queries routing, piling declining
} // primaries unburdening — writers freeing, choking declining (caller asserts below)
console.log(replicasFor(9000, 3000) === 3 && primaryLeft(10000, 3000, 3) === 1000 ? 'reads fan' : 'primaries choke');
```

```typescript
// BAD: primaries choking — copies unmultiplying, loads unsplitting (real choke shape).
// // All reads on primary (replicas unnumbered — loads unshared — writers stalling).
// // Writes queue (locks contending — tails growing). Number replicas; route queries; free writers.)
```

**Common confusion** — *"replicas double capacity (copies adding)."* Adding multiplying reads (followers provisioning — queries routing (loads splitting — primaries unburdening (adding serving — scaling funding); doubling ignoring writes (writers unshared — lags unmonitored (staleness hiding — consistency bluffing (doubling charging — arithmetic failing). "Doubling" describing wishes (copies adding — capacity hoping); fanning describing math (replicas numbering — loads splitting). Number followers (copies multiplying — choking ending); monitor lag (followers provisioning — staleness bounding).

**Performance note** — fanning economics: multiplying costing replicas (copies numbering — queries routing (writers freeing — loads flowing); choked equivalents costing stalls (loads unshared — locks contending (tails growing — throughput dying). Multiply cheaply (followers — reads); choke never (primaries — queries).

**Mentor note** — teach "reads fan out, writes stay home" (juniors numbering one replica set per read path design choke-proof reads on first hearing; primary-read fleets interrogated ("replicas where?" — fanning demanding per path). Fan one path once (replicas numbering — queries routing tangible (choking ending — fanning proving permanently). Provision followers; split shares — fanning discipline in three habits, reviewed per path.

## 2. Lags tolerating (windows stating — queries routing — staleness bounding)

**Definition** — tolerated replica lag: stated windows routing queries bounding staleness (windows stating — lags quoting (recencies measuring — divergences bounding (stating proving — assuming declining); queries routing — freshness matching (tolerances declaring — criticals pinning (routing funding — misreading declining); staleness bounding — versions tracking (TTL expiring — conflicts resolving (bounding owning — surprising declining).

**What problem it solves** — the lag-blind trio: *windows unstating* (lags unquoted — recencies unmeasured (divergences unbounded — readers staleing (unstating billing — visibility failing); *queries unrouting* (freshness unmatched — tolerances undeclared (criticals unpinned — wrongs serving (unrouting charging — correctness failing); *staleness unbounding* (versions untracked — TTL unexpired (conflicts unhandled — surprises scheduling (unbounding costing — trust eroding). Tolerated lags converting blindness to stating (lags quoting — freshness matching (versions tracking — surprises ending); reviewers finding lag budgets per query (tolerating proving → verifiable; blindness → returned).

**Modern guidance** — the tolerating lines per query (review-enforced): *windows stating* (lags quoting — recencies measuring (divergences bounding — assuming declining (stating proving — hiding refusing (quotes keeping — visibility earning); *queries routing* (freshness matching — tolerances declaring (criticals pinning — misreading declining (routing funding — guessing refusing (routes earning — wrongs preventing); *staleness bounding* (versions tracking — TTL expiring (conflicts resolving — surprising declining (bounding owning — hoping refusing (bounds keeping — correctness earning).

```typescript
// GOOD: lags tolerating — stated windows routing queries (compiled + run live).
function routeRead(lagMs: number, toleranceMs: number): string {
  return lagMs <= toleranceMs ? 'REPLICA' : 'PRIMARY'; // windows stating — lags quoting, assuming declining
} // queries routing — freshness matching, misreading declining (caller asserts below)
function staleReads(total: number, replicaShare: number): number {
  return Math.round(total * replicaShare); // staleness bounding — versions tracking, surprising declining
}
console.log(routeRead(800, 5000) === 'REPLICA' && routeRead(9000, 5000) === 'PRIMARY' && staleReads(10000, 0.9) === 9000 ? 'lags tolerate' : 'reads blind');
```

```typescript
// BAD: reads blinding — windows unstating, queries unrouting (real stale shape).
// // Read-your-write assumed (lags unquoted — recencies unmeasured — readers staleing).
// // Critical reads on lagged replicas (wrongs serving — correctness failing). State windows; match freshness; bound staleness.)
```

**Common confusion** — *"replicas are backups (copies idling)."* Idling awaiting disasters (standbys warming — restores hoping (failovers unrehearsed — cuts fumbling (idling charging — readiness bluffing); tolerating serving reads (lags quoting — queries routing (loads splitting — primaries unburdening (tolerating proving — blindness declining). "Backups" describing insurance (standbys warming — restores hoping); replicas describing capacity (followers provisioning — freshness matching). Quote lags (windows stating — visibility earning); pin criticals (tolerances declaring — wrongs preventing).

**Performance note** — tolerating economics: stating costing windows (lags quoting — freshness matching (versions tracking — surprises ending); blind equivalents costing wrongs (readers staleing — wrongs serving (correctness failing — trust eroding). State cheaply (lags — queries); blind never (reads — replicas).

**Mentor note** — teach "every query states its staleness budget" (juniors quoting one lag window per query design blind-proof reads on first hearing; budgetless reads interrogated ("stale how long?" — tolerating demanding per query). Tolerate one lag once (windows stating — freshness matching tangible (blindness ending — tolerating proving permanently). Measure recency; pin criticals — tolerating discipline in three habits, reviewed per query.

## 3. Failovers reading (promotions rehearsing — traffic shifting — losses bounding)

**Definition** — reading failovers: rehearsed promotions shifting traffic bounding losses (promotions rehearsing — standbys elevating (health confirming — splits braining (rehearsing proving — hoping declining); traffic shifting — loads migrating (primaries demoting — replicas promoting (shifting owning — dropping declining); losses bounding — writes fencing (gaps measuring — recencies proving (bounding funding — diverging declining).

**What problem it solves** — the unrehearsed trio: *promotions unrehearsing* (standbys unelevated — health unconfirmed (brains unsplit — takeovers fumbling (unrehearsing billing — readiness bluffing); *traffic unshifting* (loads unmigrated — primaries undemoted (replicas unpromoted — writes dropping (unshifting charging — continuity failing); *losses unbounding* (writes unfenced — gaps unmeasured (recencies unproved — divergences hiding (unbounding costing — honesty failing). Reading failovers converting hoping to rehearsing (standbys elevating — loads migrating (writes fencing — losses bounding); reviewers finding drill dates per promotion (reading proving → verifiable; hoping → returned).

**Modern guidance** — the reading lines per Promotion (review-enforced): *promotions rehearsing* (standbys elevating — health confirming (splits braining — hoping declining (rehearsing proving — fumbling refusing (practices keeping — takeovers succeeding); *traffic shifting* (loads migrating — primaries demoting (replicas promoting — dropping declining (shifting owning — cutting refusing (migrations funding — continuity keeping); *losses bounding* (writes fencing — gaps measuring (recencies proving — diverging declining (bounding owning — hiding refusing (fences keeping — honesty earning).

```typescript
// GOOD: failovers reading — rehearsed promotions shifting traffic (compiled + run live).
function promote(healthyStandby: boolean, lagMs: number, lagCap: number): string {
  if (!healthyStandby) return 'HOLD'; // promotions rehearsing — standbys elevating, hoping declining
  if (lagMs > lagCap) return 'HOLD';
  return 'PROMOTE'; // traffic shifting — loads migrating, dropping declining
} // losses bounding — writes fencing, diverging declining (caller asserts below)
console.log(promote(true, 200, 5000) === 'PROMOTE' && promote(false, 200, 5000) === 'HOLD' && promote(true, 9000, 5000) === 'HOLD' ? 'failovers read' : 'primaries hope');
```

```typescript
// BAD: primaries hoping — promotions unrehearsing, losses unbounding (real fumble shape).
// // Failover on pager (standbys unelevated — takeovers fumbling — outages extending).
// // Lag unknown (gaps unmeasured — divergences hiding). Rehearse promotions; shift traffic; bound losses.)
```

**Common confusion** — *"failover is automatic (platforms promoting)."* Promoting configuring automation (health checking — standbys elevating (traffic shifting — losses bounding (configuring serving — readiness earning); automatic assuming magic (policies unstated — rehearsals missing (brains unsplit — takeovers fumbling (assuming charging — evidence failing). "Automatic" describing hope (policies unstated — rehearsals missing); reading describing drills (standbys elevating — lags bounding). Elevate standbys (health confirming — takeovers succeeding); fence writes (gaps measuring — honesty earning).

**Performance note** — reading economics: rehearsing costing drills (standbys elevating — traffic shifting (writes fencing — losses bounding); hoped equivalents costing fumbles (takeovers fumbling — gaps unmeasured (outages extending — trust eroding). Rehearse cheaply (promotions — drills); hope never (primaries — failovers).

**Mentor note** — teach "promote only what you rehearse" (juniors rehearsing one promotion per quarter design fumble-proof failovers on first hearing; undrilled promotions interrogated ("last drill?" — reading demanding per promotion). Read one failover once (standbys elevating — traffic shifting tangible (hoping ending — reading proving permanently). Confirm health; measure gaps — reading discipline in three habits, reviewed per quarter.
