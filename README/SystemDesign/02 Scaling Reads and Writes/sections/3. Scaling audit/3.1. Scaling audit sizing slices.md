# 3.1. Scaling audit sizing slices

## 1. Reads auditing (ratios stating — replicas counting — stamps checking)

**Definition** — audited reads: stated ratios counting replicas checking stamps (ratios stating — hits measuring (misses costing — machines saving (stating proving — assuming declining); replicas counting — copies numbering (followers provisioning — lag monitoring (counting funding — choking declining); stamps checking — expiries auditing (jitters verifying — herds dispersing (checking owning — thundering declining).

**What problem it solves** — the unaudited-read trio: *ratios unstating* (hits unmeasuring — misses uncosting (machines unsaved — budgets unkept (unstating billing — arithmetic failing); *replicas uncounting* (copies unnumbered — followers unprovisioned (loads unshared — primaries choking (uncounting charging — scaling failing); *stamps unchecked* (expiries unaudited — jitters unverified (misses synchronized — databases drowning (unchecked costing — thunder scheduling). Audited reads converting assuming to stating (hits measuring — copies numbering (expiries auditing — reloads absorbing); reviewers finding read audits per slice (auditing proving → verifiable; assuming → returned).

**Modern guidance** — the auditing lines per read slice (review-enforced): *ratios stating* ([1.1](<../../sections/1. Read thinking/1.1. Caching sizing hot sets.md>) — hits measuring (misses costing — machines saving (stating proving — hoping refusing (states earning — waste ending); *replicas counting* ([1.2](<../../sections/1. Read thinking/1.2. Replicas scaling reads.md>) — copies numbering (followers provisioning — lag monitoring (counting funding — choking refusing (counts keeping — loads flowing); *stamps checking* (expiries auditing — jitters verifying (herds dispersing — thundering declining (checking owning — synchronized refusing (checks funding — drowning ending).

```typescript
// GOOD: reads auditing — stated ratios counting replicas (compiled + run live).
interface ReadAudit { // ratios stating — hits measuring, assuming declining
  ratio: number;
  replicas: number;
  jittered: boolean;
}
function unaudited(a: ReadAudit): boolean {
  return !(a.ratio > 0) || a.replicas < 1 || !a.jittered; // replicas counting — copies numbering, choking declining
} // stamps checking — expiries auditing, thundering declining (caller asserts below)
const audited: ReadAudit = { ratio: 0.95, replicas: 3, jittered: true };
const thin: ReadAudit = { ratio: 0, replicas: 0, jittered: false };
console.log(!unaudited(audited) && unaudited(thin) ? 'reads audit' : 'caches assume');
```

```typescript
// BAD: caches assuming — ratios unstating, stamps unchecked (real thunder shape).
// // Cache added (hits unmeasuring — machines unsaved — budgets unkept).
// // Uniform TTL (herds undispersed — databases drowning). State ratios; count replicas; check stamps.)
```

**Common confusion** — *"audits slow reads teams (reviews taxing)."* Taxing delaying ships (audits running — rows checking (time spending — velocity dipping (taxing charging — speed missing); auditing pricing machines (ratios stating — replicas counting (stamps checking — waste ending (auditing proving — assuming declining). "Slowing" describing fear (reviews avoiding — decisions ducking); reads describing arithmetic (hits measuring — machines saving). State hits (ratios computing — loads splitting); verify jitter (expiries auditing — herds dispersing).

**Performance note** — auditing economics: stating costing rows (ratios measuring — replicas counting (stamps checking — waste ending); assumed equivalents costing thunder (machines unsaved — primaries choking (databases drowning — trust eroding). State cheaply (audits — reads); assume never (caches — ratios).

**Mentor note** — teach "ratio, replicas, jitter — every read slice" (juniors auditing one triple per read path design assume-proof reads on first hearing; unaudited caches interrogated ("ratio? replicas? stamps?" — auditing demanding per slice). Audit one read once (hits measuring — copies numbering tangible (assuming ending — auditing proving permanently). Compute ratios; spread misses — auditing discipline in three habits, reviewed per slice.

## 3. Growth modeling (10x pricing — cliffs dating — headroom keeping)

**Definition** — modeled growth: priced 10x dating cliffs keeping headroom (10x pricing — tiers costing (volumes multiplying — budgets tightening (pricing proving — flat declining); cliffs dating — ceilings stating (breaks forecasting — migrations scheduling (dating owning — surprising declining); headroom keeping — margins holding (utilizations capping — alarms setting (keeping earning — hoping declining).

**What problem it solves** — the flat-growth trio: *10x unpricing* (tiers uncosted — volumes unmultiplied (budgets untightened — overruns scheduling (unpricing billing — arithmetic failing); *cliffs undating* (ceilings unstated — breaks unforecast (migrations unscheduled — surprises paging (undating charging — planning missing); *headroom unkeeping* (margins unheld — utilizations uncapped (alarms unset — cliffs discovering (unkeeping costing — safety failing). Modeled growth converting flatness to pricing (tiers costing — ceilings stating (margins holding — surprises ending); reviewers finding growth models per slice (modeling proving → verifiable; flatness → returned).

**Modern guidance** — the modeling lines per slice (review-enforced): *10x pricing* (tiers costing — volumes multiplying (budgets tightening — flat declining (pricing proving — hoping refusing (prices keeping — overruns preventing); *cliffs dating* (ceilings stating — breaks forecasting (migrations scheduling — surprising declining (dating owning — hoping refusing (dates funding — planning earning); *headroom keeping* (margins holding — utilizations capping (alarms setting — hoping declining (keeping earning — cliffing refusing (margins earning — safety keeping).

```typescript
// GOOD: growth modeling — priced 10x dating cliffs (compiled + run live).
function growthOk(now: number, cap: number, growthX: number): string {
  const need = now * growthX; // 10x pricing — tiers costing, flat declining
  if (need <= cap * 0.7) return 'HEADROOM';
  if (need <= cap) return 'CLIFF-DATED'; // cliffs dating — ceilings stating, surprising declining
  return 'OVER'; // headroom keeping — margins holding, hoping declining
}
console.log(growthOk(1000, 10000, 10) === 'CLIFF-DATED' && growthOk(100, 10000, 10) === 'HEADROOM' && growthOk(5000, 10000, 10) === 'OVER' ? 'growth models' : 'futures flat');
```

// BAD: futures flatting — 10x unpricing, cliffs undating (real surprise shape).
