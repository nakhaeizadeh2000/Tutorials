# 5.1. Common interview QA scaling

## 1. Reads live under pressure (caches, replicas, stamps — diagnosed with fixes, priced)

**Definition** — the reads answer interviewers grade: given read load, name the cache with replicas ([1.1](<../../sections/1. Read thinking/1.1. Caching sizing hot sets.md>)/[1.2](<../../sections/1. Read thinking/1.2. Replicas scaling reads.md>)) — caches proving (hots sizing — TTLs bounding (stamps preventing — thundering declining (proving owning — everything declining); replicas proving (copies numbering — loads splitting (primaries unburdening — choking declining (proving funding — singling declining); stamps proving (hots splitting — expiries jittering (tails bounding — piling declining (proving earning — burning declining). "Live" means diagnosed fixes (sets sizing — copies numbering (stamps dispersing — proof stating — bluffing declining).

**What problem it solves** — the reciting trio: *caches reciting* (hits naming — sets unmentioned (TTLs undescribed — stamps unjudged (reciting serving — hiring failing (knowledge hoping — depth doubting); *replicas confusing* (copies equating — loads unplaced (lags unassigned — primaries choking (conflating owning — clarity missing (confusion serving — confidence failing (placing hoping — precision doubting); *stamps hoping* (expiries unjittered — misses synchronized (tails unbounded — databases drowning (hoping serving — incidents inviting (judgment failing — experience doubting). Pressured reads converting reciting to diagnosing (hots sizing — copies numbering (stamps dispersing — answers holding); interviewers hearing caches with replicas, not store names (diagnosing proving → hirable; reciting → passed) — drawing on [1.1](<../../sections/1. Read thinking/1.1. Caching sizing hot sets.md>) and [1.2](<../../sections/1. Read thinking/1.2. Replicas scaling reads.md>).

**Modern guidance** — the reads lines (interview-enforced): *caches sizing* (hots measuring — TTLs bounding (stamps preventing — thundering declining (sizing proving — everything refusing); *replicas fanning* (copies numbering — loads splitting (primaries unburdening — choking declining (fanning funding — singling refusing); *stamps dispersing* (hots splitting — expiries jittering (tails bounding — piling declining (dispersing owning — synchronized refusing). Every claim carrying cache + replica + stamp (judgment demonstrable — pressure survivable).

```typescript
// GOOD: reads answers — caches, replicas, stamps with diagnosed fixes (answer shape, hiring-grade).
// "0.95 hit ratio shedding 9.5k of 10k (caches sizing — machines saving).
//  3 followers with 5s lag budgets (replicas fanning — primaries unburdening).
//  Celebrity split with jittered TTLs (stamps dispersing — tails bounding).")
```

```typescript
// BAD: reads recitals — names without caches, hopes without replicas (real fail shape).
// // "Redis cache." (sets unmentioned — TTLs undescribed — knowledge hoping).
// // "Read replicas." (lags unassigned — stamps unjudged). Size hots; fan copies; disperse stamps.)
```

**Common confusion** — *"naming stores answers reads (databases stating)."* Stating listing stores (letters reciting — engines naming (shapes describing — ratios missing (stating serving — owning failing); answering proving scale (hots sizing — copies numbering (stamps dispersing — loads flowing (proving funding — reciting declining). "Answering" describing judgments (caches sizing — replicas fanning); naming describing vocabulary (stores spelling — meaning missing). Measure ratios (hits computing — machines saving); monitor lag (followers provisioning — staleness bounding).

**Performance note** — reads-answer economics: diagnosing costing triples (caches sizing — replicas fanning (stamps dispersing — answers holding); reciting equivalents costing doubt (names listing — judgments missing (depth doubting — hiring failing). State cheaply (triples — reads); recite never (names — hopes).

**Mentor note** — drill "cache, replica, stamp" (candidates answering per read path with hot sets, follower counts, and jitter plans defend reads on first hearing; store-only answers interrogated ("ratio? replicas? stamps?" — reads demanding per claim). Rehearse one scaled read once (cache-replica-stamp tangible (reciting ending — diagnosing proving permanently). Bound TTLs; split celebrities — reads answers in three artifacts, reviewed per interview.

## 2. Writes live under pressure (shards, queues, hots — honesty stated, not hoped)

**Definition** — the writes answer interviewers grade: given write load, name the shard with queues ([2.1](<../../sections/2. Write thinking/2.1. Sharding partitioning writes.md>)/[2.2](<../../sections/2. Write thinking/2.2. Queues absorbing bursts.md>)) — shards proving (keys auditing — hashes distributing (hots isolating — piling declining (proving owning — defaulting declining); queues proving (depths bounding — rates smoothing (backlogs alarming — growing declining (proving funding — flooding declining); hots proving (celebrities splitting — counts precomputing (paths forking — burning declining (proving earning — piling declining). "Live" means honesty first (audits stating — depths capping (splits owning — truth proving — hoping declining).

**What problem it solves** — the hand-waving trio: *shards waving* (keys unaudited — hashes undistributed (hots unisolated — skews hiding (waving serving — hiring failing (numbers missing — judgment doubting); *queues forgetting* (depths uncapped — rates unsmoothed (backlogs unalarmed — neighbors drowning (forgetting owning — discipline missing (silence serving — survival bluffing); *hots missing* (celebrities unsplit — counts unprecomputed (paths unforked — partitions burning (missing charging — scaling failing (hope serving — calibration failing). Pressured writes converting waving to auditing (keys counting — depths capping (celebrities splitting — answers holding); interviewers hearing shards with queues, not adjectives (auditing proving → hirable; waving → passed) — drawing on [2.1](<../../sections/2. Write thinking/2.1. Sharding partitioning writes.md>) and [2.2](<../../sections/2. Write thinking/2.2. Queues absorbing bursts.md>).

**Modern guidance** — the writes lines (interview-enforced): *shards auditing* (keys counting — hashes distributing (hots isolating — piling declining (auditing proving — defaulting refusing); *queues bounding* (depths capping — rates smoothing (backlogs alarming — growing declining (bounding funding — flooding refusing); *hots splitting* (celebrities dividing — counts precomputing (paths forking — burning declining (splitting owning — piling refusing). Every claim carrying shard + queue + hot (judgment demonstrable — pressure survivable).

```typescript
// GOOD: writes answers — shards, queues, hots with honest audits (answer shape, hiring-grade).
// "Shard key audited at 1M distinct, 0.2 hot share (keys auditing — skews spotting).
//  Queue capped 1k with 5s age alarm (depths bounding — stalls surfacing).
//  Celebrity forked with precomputed counts (hots splitting — renders quickening).")
```

```typescript
// BAD: writes waves — adjectives without shards, comfort without queues (real fail shape).
// // "Sharded cluster." (keys unaudited — hashes undistributed — numbers missing).
// // "Async processing." (depths uncapped — backlogs unalarmed). Audit keys; cap depths; split hots.)
```

**Common confusion** — *"more shards answer writes (parts multiplying)."* Multiplying adding nodes (shards numbering — keys hashing (traffic spreading — heat missing (multiplying serving — skew failing); writes auditing heat (keys counting — queues bounding (hots splitting — skews ending (auditing proving — waving declining). "More" describing counts (shards numbering — heat missing); shards describing audits (cardinality counting — celebrities flagging). Audit distincts (buckets balancing — skews spotting); isolate heat (counts precomputing — burns cooling).

**Performance note** — writes-answer economics: auditing costing triples (shards counting — queues bounding (hots splitting — answers holding); waving equivalents costing doubt (adjectives floating — numbers missing (judgment doubting — hiring failing). Audit cheaply (shards — queues); wave never (adjectives — hots).

**Mentor note** — drill "shard, queue, hot" (candidates answering per write path with audited keys, bounded depths, and split celebrities defend writes on first hearing; "sharded" interrogated ("key audit? queue cap? hot plan?" — writes demanding per claim). Rehearse one partitioned write once (shard-queue-hot tangible (waving ending — auditing proving permanently). Steady rings; alarm ages — writes answers in three honesty, reviewed per interview.

## 3. Growth live under pressure (10x, cliffs, audits — ownership stated, not hoped)

**Definition** — the growth answer interviewers grade: given 10x, name the cliff with audits ([3.1](<../../sections/3. Scaling audit/3.1. Scaling audit sizing slices.md>)) — 10x proving (tiers costing — volumes multiplying (budgets tightening — flat declining (proving owning — hoping declining); cliffs proving (ceilings stating — breaks forecasting (migrations scheduling — surprising declining (proving funding — assuming declining); audits proving (reads checking — writes checking (growth rechecking — rotting declining (proving earning — drifting declining). "Live" means ownership stated (tiers pricing — cliffs dating — slices auditing (proof stating — flatness declining).

**What problem it solves** — the claiming trio: *10x claiming* (tiers uncosted — volumes unmultiplied (budgets untightened — overruns scheduling (claiming serving — hiring failing (names missing — proof doubting); *cliffs missing* (ceilings unstated — breaks unforecast (migrations unscheduled — surprises paging (missing owning — planning failing (silence serving — calibration bluffing); *audits hoping* (reads unchecked — writes unverified (growth undrifted — rot accumulating (hoping serving — evidence failing). Pressured growth converting claiming to pricing (tiers costing — ceilings stating (reads checking — answers holding); interviewers hearing tiers with cliffs, not assurances (pricing proving → hirable; claiming → passed) — drawing on [3.1](<../../sections/3. Scaling audit/3.1. Scaling audit sizing slices.md>).

**Modern guidance** — the growth lines (interview-enforced): *10x pricing* (tiers costing — volumes multiplying (budgets tightening — flat declining (pricing proving — hoping refusing); *cliffs dating* (ceilings stating — breaks forecasting (migrations scheduling — surprising declining (dating owning — assuming refusing); *audits repeating* (reads checking — writes checking (growth rechecking — rotting declining (repeating owning — drifting refusing). Every claim carrying tier + cliff + audit (judgment demonstrable — pressure survivable).

```typescript
// GOOD: growth answers — tiers, cliffs, audits with owned futures (answer shape, hiring-grade).
// "10x costs 5 machines at current mix (tiers pricing — budgets tightening).
//  Cliff dated at 8k writes/s with migration queued (ceilings stating — surprises ending).
//  Audits repeat quarterly (reads checking — rot declining).")
```

```typescript
// BAD: growth claiming — assurances without tiers, futures without cliffs (real fail shape).
// // "Designed for scale." (tiers uncosted — volumes unmultiplied — names missing).
// // "We'll handle it." (ceilings unstated — audits unrepeated). Price tiers; date cliffs; repeat audits.)
```

**Common confusion** — *"confidence answers growth (certainty performing)."* Performing pretending headroom (margins claiming — cliffs denying (futures assuming — surprises hiding (performing charging — calibration failing); growth owning arithmetic (tiers pricing — cliffs dating (audits repeating — surprises ending (owning proving — claiming declining). "Confidence" describing delivery (certainty performing — headroom claiming); growth describing budgets (10x costing — margins holding). Cost volumes (tiers multiplying — overruns preventing); hold margins (utilizations capping — safety keeping).

**Performance note** — growth-answer economics: pricing costing artifacts (tiers costing — cliffs dating (audits repeating — answers holding); claiming equivalents costing doubt (assurances floating — artifacts missing (proof doubting — hiring failing). Price cheaply (tiers — growth); claim never (assurances — futures).

**Mentor note** — drill "tier, cliff, audit" (candidates answering per future with priced tiers, dated cliffs, and repeated audits defend growth on first hearing; "designed for scale" interrogated ("10x cost? cliff date? audit cadence?" — growth demanding per claim). Rehearse one modeled future once (tier-cliff-audit tangible (claiming ending — pricing proving permanently). Multiply volumes; schedule migrations — growth answers in three ownerships, reviewed per interview.
