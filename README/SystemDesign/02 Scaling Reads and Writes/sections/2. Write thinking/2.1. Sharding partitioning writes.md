# 2.1. Sharding partitioning writes

## 1. Keys choosing (cardinality auditing — heat measuring — growth modeling)

**Definition** — chosen shard keys: audited cardinality measuring heat modeling growth (cardinality auditing — distincts counting (buckets balancing — skews spotting (auditing proving — hoping declining); heat measuring — writes rating (hotspots ranking — celebrities flagging (measuring funding — averaging declining); growth modeling — volumes forecasting (splits planning — moves budgeting (modeling owning — surprising declining).

**What problem it solves** — the default-key trio: *cardinality unauditing* (distincts uncounted — buckets unbalanced (skews hiding — hotspots scheduling (unauditing billing — arithmetic failing); *heat unmeasuring* (writes unrated — hotspots unranked (celebrities unflagged — partitions burning (unmeasuring charging — visibility failing); *growth unmodeling* (volumes unforecast — splits unplanned (moves unbudgeted — resharding surprising (unmodeling costing — planning failing). Chosen keys converting defaulting to auditing (distincts counting — writes rating (volumes forecasting — skews ending); reviewers finding key audits per dataset (choosing proving → verifiable; defaulting → returned).

**Modern guidance** — the choosing lines per dataset (review-enforced): *cardinality auditing* (distincts counting — buckets balancing (skews spotting — hoping declining (auditing proving — assuming refusing (counts earning — balance keeping); *heat measuring* (writes rating — hotspots ranking (celebrities flagging — averaging declining (measuring funding — hiding refusing (rates keeping — burns surfacing); *growth modeling* ([DatabaseDesign 05/2.1](<../../../../DatabaseDesign/05 Evolution Growth and Partitioning/sections/2. Growth and capacity/2.1. Capacity modeling with measured triggers.md>) — volumes forecasting (splits planning — moves budgeting — surprising declining (modeling owning — hoping refusing (forecasts funding — reshard earning).

```typescript
// GOOD: keys choosing — audited cardinality measuring heat (compiled + run live).
interface KeyAudit { // cardinality auditing — distincts counting, hoping declining
  distinct: number;
  shards: number;
  hotShare: number;
}
function skewed(a: KeyAudit): boolean {
  if (a.distinct < a.shards * 10) return true; // heat measuring — writes rating, averaging declining
  return a.hotShare > 0.5; // growth modeling — volumes forecasting, surprising declining
}
const healthy: KeyAudit = { distinct: 1000000, shards: 8, hotShare: 0.2 };
const celebrity: KeyAudit = { distinct: 1000000, shards: 8, hotShare: 0.8 };
console.log(!skewed(healthy) && skewed(celebrity) ? 'keys choose' : 'ids default');
```

```typescript
// BAD: ids defaulting — cardinality unauditing, heat unmeasuring (real hotspot shape).
// // Shard by id (distincts uncounted — skews hiding — hotspots scheduling).
// // Celebrity burns (partitions burning — visibility failing). Audit cardinality; measure heat; model growth.)
```

**Common confusion** — *"any unique key shards well (uniqueness sufficing)."* Sufficing distributing rows (keys hashing — nodes sharing (traffic spreading — balance hoping (sufficing serving — skew missing); choosing auditing heat (distincts counting — writes rating (celebrities flagging — skews spotting (choosing proving — defaulting declining). "Unique" describing rows (keys hashing — traffic spreading); keys describing heat (writes rating — growth modeling). Count distincts (buckets balancing — skews spotting); rank hotspots (burns surfacing — partitions cooling).

**Performance note** — choosing economics: auditing costing counts (distincts counting — writes rating (volumes forecasting — skews ending); defaulted equivalents costing hotspots (skews hiding — partitions burning (resharding surprising — trust eroding). Audit cheaply (keys — datasets); default never (ids — shards).

**Mentor note** — teach "cardinality, heat, growth — every shard key" (juniors auditing one key triple per dataset design hotspot-proof shards on first hearing; default keys interrogated ("distinct? hot share?" — choosing demanding per key). Choose one key once (distincts counting — heat measuring tangible (defaulting ending — choosing proving permanently). Balance buckets; flag celebrities — choosing discipline in three habits, reviewed per dataset.

## 2. Hashes distributing (rings steadying — nodes adding — moves minimizing)

**Definition** — distributed hashes: steadied rings adding nodes minimizing moves (rings steadying — tokens placing (owners mapping — lookups routing (steadying proving — flapping declining); nodes adding — capacity growing (members joining — shares rebalancing (adding funding — stalling declining); moves minimizing — keys remapping-few (transfers bounding — churn limiting (minimizing owning — reshuffling declining).

**What problem it solves** — the mod-N trio: *rings unsteading* (tokens unplacing — owners unmapped (lookups flooding — nodes flapping (unsteading billing — stability failing); *nodes unadding* (capacity ungrown — members unjoined (shares unbalanced — scaling blocked (unadding charging — elasticity failing); *moves unminimizing* (keys remapped-all (transfers unbounded — churn whipping (unminimizing costing — stability failing). Distributed hashes converting modding to steadying (tokens placing — members joining (keys remapping-few — churn ending); reviewers finding ring maps per cluster (distributing proving → verifiable; modding → returned).

**Modern guidance** — the distributing lines per cluster (review-enforced): *rings steadying* (tokens placing — owners mapping (lookups routing — flapping declining (steadying proving — flooding refusing (placements earning — stability keeping); *nodes adding* (capacity growing — members joining (shares rebalancing — stalling declining (adding funding — blocking refusing (joins keeping — elasticity earning); *moves minimizing* (keys remapping-few — transfers bounding (churn limiting — reshuffling declining (minimizing owning — whipping refusing (minimums funding — stability earning).

```typescript
// GOOD: hashes distributing — steadied rings adding nodes (compiled + run live).
function ownerOf(key: string, nodes: string[]): string {
  let h = 0; // rings steadying — tokens placing, flapping declining
  for (const c of key) h = (h * 31 + c.charCodeAt(0)) % 1000003;
  return nodes[h % nodes.length] ?? 'none'; // nodes adding — capacity growing, stalling declining
} // moves minimizing — keys remapping-few, reshuffling declining (caller asserts below)
const nodes3 = ['a', 'b', 'c'];
const nodes4 = ['a', 'b', 'c', 'd'];
const k = 'user:42';
console.log(ownerOf(k, nodes3) === ownerOf(k, nodes3) && nodes3.includes(ownerOf(k, nodes3)) && nodes4.includes(ownerOf(k, nodes4)) ? 'hashes distribute' : 'mods flap');
```

```typescript
// BAD: mods flapping — rings unsteading, moves unminimizing (real remap shape).
// key.hashCode() % N; // owners unmapped — lookups flooding, stability failing.
// // Node added (keys remapped-all — churn whipping). Place tokens; add members; minimize moves.)
```

**Common confusion** — *"hashing solves skew (parts dividing)."* Dividing spreading keys (hashes distributing — nodes sharing (traffic balancing — uniformity hoping (dividing serving — heat missing); skew surviving hashes (celebrities burning — partitions overloading (hotspots scheduling — uniformity bluffing (surviving charging — arithmetic failing). "Solving" describing distribution (keys spreading — traffic balancing); hashes describing placement (tokens mapping — moves minimizing). Distribute placement (rings steadying — churn ending); isolate celebrities (counts precomputing — burns cooling).

**Performance note** — distributing economics: steadying costing tokens (rings placing — members joining (moves minimizing — churn ending); modded equivalents costing flaps (lookups flooding — keys remapping-all (stability failing — trust eroding). Steady cheaply (rings — tokens); mod never (N — nodes).

**Mentor note** — teach "ring first, modulo never" (juniors placing one token ring per cluster design flap-proof distribution on first hearing; mod-N interrogated ("node added?" — distributing demanding per cluster). Distribute one ring once (tokens placing — members joining tangible (modding ending — distributing proving permanently). Map owners; bound transfers — distributing discipline in three habits, reviewed per cluster.

## 3. Hots isolating (celebrities splitting — counts precomputing — paths forking)

**Definition** — isolated hots: split celebrities precomputing counts forking paths (celebrities splitting — hotspots dividing (traffic shedding — neighbors serving (splitting proving — burning declining); counts precomputing — totals caching (reads serving — writes appending (precomputing funding — scanning declining); paths forking — queries routing (hot serving — cold sharing (forking owning — mixing declining).

**What problem it solves** — the celebrity trio: *celebrities unsplitting* (hotspots undivided — traffic unshed (neighbors dragging — partitions burning (unsplitting billing — scaling failing); *counts unprecomputing* (totals uncaching — reads unscanning (writes blocking — renders crawling (unprecomputing charging — latency failing); *paths unforking* (queries unrouted — hot unserved (cold unshared — mixes tangling (unforking costing — clarity failing). Isolated hots converting burning to splitting (hotspots dividing — totals caching (queries routing — reads flowing); reviewers finding celebrity plans per hotspot (isolating proving → verifiable; burning → returned).

**Modern guidance** — the isolating lines per hotspot (review-enforced): *celebrities splitting* (hotspots dividing — traffic shedding (neighbors serving — burning declining (splitting proving — piling refusing (divisions earning — hotspots cooling); *counts precomputing* (totals caching — reads serving (writes appending — scanning declining (precomputing funding — crawling refusing (caches keeping — renders quickening); *paths forking* (queries routing — hot serving (cold sharing — mixing declining (forking owning — tangling refusing (forks earning — clarity keeping).

```typescript
// GOOD: hots isolating — split celebrities precomputing counts (compiled + run live).
function pathFor(hot: boolean): string {
  return hot ? 'HOT-PATH' : 'COLD-PATH'; // celebrities splitting — hotspots dividing, burning declining
}
function served(total: number, hot: boolean, cached: number): number {
  if (hot) return cached; // counts precomputing — totals caching, scanning declining
  return total; // paths forking — queries routing, mixing declining
}
console.log(pathFor(true) === 'HOT-PATH' && pathFor(false) === 'COLD-PATH' && served(100, true, 99) === 99 && served(100, false, 99) === 100 ? 'hots isolate' : 'celebrities burn');
```

// // Same path for all (hotspots undivided — neighbors dragging — partitions burning).

**Common confusion** — *"isolating is premature (celebs awaiting)."* Awaiting deferring splits (hotspots undivided — traffic unshared (neighbors dragging — partitions burning (awaiting charging — scaling failing); isolating pricing heat (celebrities splitting — counts precomputing (paths forking — reads flowing (isolating proving — burning declining). "Premature" describing fear (splits avoiding — decisions ducking); hots describing arithmetic (heat measuring — burns scheduling). Measure heat (writes rating — hotspots ranking); fork early (paths splitting — renders quickening).

**Performance note** — isolating economics: splitting costing paths (hotspots dividing — totals caching (queries routing — reads flowing); burning equivalents costing partitions (neighbors dragging — renders crawling (latency failing — trust eroding). Split cheaply (hots — paths); burn never (celebrities — traffic).

**Mentor note** — teach "fork the celebrity on day one of heat" (juniors splitting one hot path per hotspot design burn-proof reads on first hearing; un forked hots interrogated ("celebrity path?" — isolating demanding per hotspot). Isolate one hot once (hotspots dividing — totals caching tangible (burning ending — isolating proving permanently). Divide traffic; serve cached — isolating discipline in three habits, reviewed per hotspot.
