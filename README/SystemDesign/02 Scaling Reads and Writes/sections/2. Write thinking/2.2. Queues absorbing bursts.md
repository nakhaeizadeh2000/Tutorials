## 1. Depths bounding (queues capping — waits limiting — overflows shedding)

**Definition** — bounded queue depths: capped queues limiting waits shedding overflows (queues capping — lengths bounding (buffers sizing — memories limiting (capping proving — growing declining); waits limiting — latencies bounding (ages capping — stalls surfacing (limiting funding — lingering declining); overflows shedding — excess dropping (policies stating — neighbors serving (shedding owning — drowning declining).

**What problem it solves** — the unbounded-queue trio: *queues uncapping* (lengths unbounding — buffers unsized (memories growing — OOMs scheduling (uncapping billing — discipline failing); *waits unlimiting* (latencies unbounded — ages uncapped (stalls hiding — callers hanging (unlimiting charging — liveness failing); *overflows unshedding* (excess undropped — policies unstated (neighbors drowning — availability dying (unshedding costing — survival bluffing). Bounded depths converting growing to capping (lengths bounding — latencies capping (excess dropping — overflows ending); reviewers finding depth caps per queue (bounding proving → verifiable; growing → returned).

**Modern guidance** — the bounding lines per queue (review-enforced): *queues capping* (lengths bounding — buffers sizing (memories limiting — growing declining (capping proving — hoping refusing (caps owning — OOMs ending); *waits limiting* (latencies bounding — ages capping (stalls surfacing — lingering declining (limiting funding — hanging refusing (limits keeping — liveness earning); *overflows shedding* (excess dropping — policies stating (neighbors serving — drowning declining (shedding owning — flooding refusing (drops funding — survival keeping).

```typescript
// GOOD: depths bounding — capped queues limiting waits (compiled + run live).
function admit(depth: number, cap: number): string {
  return depth < cap ? 'ENQUEUE' : 'SHED-503'; // queues capping — lengths bounding, growing declining
} // waits limiting — latencies bounding, lingering declining (caller asserts below)
function drainMs(depth: number, ratePerSec: number): number {
  if (ratePerSec <= 0) return Infinity; // overflows shedding — excess dropping, drowning declining
  return Math.ceil((depth / ratePerSec) * 1000);
}
console.log(admit(999, 1000) === 'ENQUEUE' && admit(1000, 1000) === 'SHED-503' && drainMs(2000, 500) === 4000 ? 'depths bound' : 'queues grow');
```

**Common confusion** — *"bigger queues absorb bursts (depths buffering)."* Buffering delaying drops (lengths growing — waits lengthening (latencies hiding — stalls masking (buffering charging — survival theatering); bounding shedding overload (lengths capping — excess dropping (neighbors serving — availability keeping (bounding proving — growing declining). ## 2. Rates smoothing (bursts absorbing — workers pacing — downstream protecting)

**Definition** — smoothed burst rates: absorbed bursts pacing workers protecting downstream (bursts absorbing — spikes queueing (peaks flattening — troughs filling (absorbing proving — hammering declining); workers pacing — consumers throttling (rates limiting — parallelism bounding (pacing funding — stampeding declining); downstream protecting — backends shielding (capacities respecting — overloads declining (protecting owning — drowning declining).

**What problem it solves** — the passthrough trio: *bursts unabsorbing* (spikes unqueued — peaks unflattened (troughs unfilled — downstream hammered (unabsorbing billing — smoothing failing); *workers unpacing* (consumers unthrottled — rates unlimited (parallelism unbounded — stampedes scheduling (unpacing charging — discipline failing); *downstream unprotecting* (backends unshielded — capacities unrespected (overloads arriving — outages scheduling (unprotecting costing — safety failing). **Modern guidance** — the smoothing lines per queue (review-enforced): *bursts absorbing* (spikes queueing — peaks flattening (troughs filling — hammering declining (absorbing proving — passing refusing (absorptions earning — downstream sparing); *workers pacing* (consumers throttling — rates limiting (parallelism bounding — stampeding declining (pacing funding — flooding refusing (paces keeping — thunder ending); *downstream protecting* (backends shielding — capacities respecting (overloads declining — drowning declining (protecting owning — hammering refusing (shields funding — survival keeping).

```typescript
// GOOD: rates smoothing — absorbed bursts pacing workers (compiled + run live).
function workersFor(arrivalPerSec: number, eachMs: number, targetUtil: number): number {
  const need = (arrivalPerSec * eachMs) / 1000 / targetUtil; // bursts absorbing — spikes queueing, hammering declining
  return Math.ceil(need); // workers pacing — consumers throttling, stampeding declining
} // downstream protecting — backends shielding, drowning declining (caller asserts below)

```

"Latency" describing waits (buffers delaying — speed missing); queues describing survival (bursts absorbing — downstream protecting). Absorb peaks (spikes flattening — downstream sparing); pace consumers (rates limiting — thunder ending).

**Performance note** — smoothing economics: absorbing costing queues (spikes queueing — workers pacing (backends shielding — downstream surviving); hammered equivalents costing floods (peaks unflattened — stampedes scheduling (outages arriving — trust eroding).
