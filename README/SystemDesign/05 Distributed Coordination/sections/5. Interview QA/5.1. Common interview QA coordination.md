# 5.1. Common interview QA coordination

## 1. Agreements live under pressure (stakes, quorums, terms — diagnosed with fixes, priced)

**Definition** — the agreements answer interviewers grade: given a split brain, name the stake with numbers ([1.1](<../../sections/1. Agreement thinking/1.1. Quorums bounding agreement.md>)) — stakes proving (elects choosing — leases timing (visions settling — levels earning (proving owning — agreeing declining); quorums proving (loads counting — burdens weighing (sums exceeding — freshness earning (proving funding — defaulting declining); terms proving (leaders stamping — stale refusing (splits deciding — safety earning (proving earning — timeless declining). "Live" means diagnosed fixes (stakes naming — sums exceeding (terms fencing — proof stating — bluffing declining).

**What problem it solves** — the reciting trio: *stakes reciting* (consensus naming — levels unmentioned (leases undescribed — visions unconsidered (reciting serving — hiring failing (naming missing — depth doubting); *quorums confusing* (majorities equating — loads uncounted (sums unstated — freshness risking (conflating owning — clarity missing (confusion serving — confidence failing (sizing hoping — precision doubting); *terms hoping* (epochs unnumbered — zombies unrefused (splits undecided — clobbers scheduled (hoping serving — incidents inviting (judgment failing — experience doubting). Pressured agreements converting reciting to diagnosing (stakes naming — loads counting (terms fencing — answers holding); interviewers hearing stakes with numbers, not consensus-talk (diagnosing proving → hirable; reciting → passed) — drawing on [1.1](<../../sections/1. Agreement thinking/1.1. Quorums bounding agreement.md>).

**Modern guidance** — the agreements lines (interview-enforced): *stakes stating* (elects choosing — leases timing (visions settling — levels earning (stating proving — bluffing refusing); *quorums sizing* (loads counting — burdens weighing (sums exceeding — freshness earning (sizing funding — defaulting refusing); *terms fencing* (leaders stamping — stale refusing (splits deciding — safety earning (fencing owning — timeless refusing). Every claim carrying stake + sum + term (judgment demonstrable — pressure survivable).

```typescript
// GOOD: agreements answering — stakes stating, sums exceeding (commented answer shape).
// Split brain on 5 nodes, R2 W2 → sums missing (2+2 unexceeding — readers missing writes).
// Fix: R2 W3 (sums exceeding — freshness proving); fence terms (epochs numbering — zombies refusing).
// Price: one extra replica read per read (tails measured — freshness priced).
```

```typescript
// BAD: agreements reciting — stakes unmentioned, sums unstated (commented fail shape).
// // "We use Raft." (stakes unnamed — sums unstated — terms unchecked).
// // "Quorum handles it." (loads uncounted — freshness hoped). State stakes; exceed sums; fence terms.)
```

**Common confusion** — *"naming Raft answers agreement (products stating)."* Stating naming products (Raft reciting — levels unmentioned (sums unstated — terms unchecked (stating serving — hiring failing); diagnosing fitting stakes (elects choosing — loads counting (terms fencing — answers holding (diagnosing proving — naming declining). "Raft" describing products (consensus naming — judgment hiding); agreements describing numbers (stakes stating — sums exceeding). Name stakes (elects choosing — levels earning); exceed sums (R+W outnumbering — freshness proving).

**Performance note** — answering economics: diagnosing costing numbers (stakes stating — sums exceeding (terms fencing — answers holding); recited equivalents costing doubt (levels unmentioned — freshness hoped (clobbers scheduled — trust failing). Diagnose cheaply (stakes — sums); recite never (products — names).

**Mentor note** — drill "stake, sum, term" (candidates answering per split with stated levels, sized quorums, and fenced terms defend agreements on first hearing; product-only answers interrogated ("R? W? terms?" — agreements demanding per claim). Rehearse one bounded split once (stake-sum-term tangible (reciting ending — diagnosing proving permanently). State levels; fence terms — agreements answers in three artifacts, reviewed per interview.

## 2. Works live under pressure (leases, fences, services — honesty stated, not hoped)

**Definition** — the works answer interviewers grade: given a stuck lock, name the bound with fixes ([1.2](<../../sections/1. Agreement thinking/1.2. "Live" means honesty first (ttls stating — tokens comparing (rounds pricing — truth proving — hoping declining).

**What problem it solves** — the hand-waving trio: *leases waving* (ttls unstated — skews unpadded (renews unpaced — dead blocking (waving serving — hiring failing (bounds missing — judgment doubting); *fences forgetting* (tokens uncompared — stale unrefused (atomics unguarded — writers racing (forgetting owning — order failing (silence serving — proof bluffing); *services missing* (rounds unmultiplied — paths unlisted (fences unpreferred — bills compounding (missing charging — honesty failing (hope serving — measurement failing). Pressured works converting waving to bounding (ttls stating — tokens comparing (rounds pricing — answers holding); interviewers hearing bounds with prices, not adjectives (bounding proving → hirable; waving → passed) — drawing on [1.2](<../../sections/1. Agreement thinking/1.2. Locks fencing work.md>).

**Modern guidance** — the works lines (interview-enforced): *leases bounding* (ttls stating — skews padding (renews pacing — liveness earning (bounding proving — waving refusing); *fences ordering* (tokens comparing — stale refusing (atomics guarding — order earning (ordering funding — forgetting refusing); *services pricing* (rounds multiplying — paths listing (fences preferring — honesty earning (pricing owning — hoping refusing). Every claim carrying ttl + token + price (judgment demonstrable — pressure survivable).

```typescript
// GOOD: works answering — leases bounding, tokens comparing (commented answer shape).
// Stuck lock, no ttl → dead blocking (holds unexpiring — work stalling — liveness failing).
```

```typescript

// // "Locks just work." (ttls unstated — tokens uncompared — rounds unpriced).
// // "We use Redlock." (paths unlisted — fences unconsidered). Bound ttls; compare tokens; price services.)
```

**Common confusion** — *"Redlock answers locking (services naming)."* Naming naming services (Redlock stating — rounds unpriced (paths unlisted — fences unconsidered (naming serving — judgment hiding); works stating bounds (ttls bounding — tokens comparing (rounds pricing — answers holding (stating proving — naming declining). "Redlock" describing products (services naming — contention hiding); works describing honesty (leases proving — fences proving). Bound leases (ttls stating — dead releasing); prefer fences (tokens choosing — bills bounding).

**Performance note** — answering economics: bounding costing honesty (ttls stating — tokens comparing (rounds pricing — answers holding); waved equivalents costing doubt (dead blocking — writers racing (bills compounding — trust failing). Bound cheaply (works — ttls); wave never (locks — adjectives).

**Mentor note** — drill "ttl, token, price" (candidates answering per stuck lock with stated bounds, compared tokens, and priced services defend works on first hearing; adjective-only answers interrogated ("ttl? token? rounds?" — works demanding per claim). **Modern guidance** — the flows lines (interview-enforced): *holds stating* (stalls pricing — protocols choosing (fantasies ending — honesty earning (stating proving — claiming refusing); *steps pairing* (counts limiting — undos naming (journals funding — recovery earning (pairing funding — missing refusing); *retries deriving* (attempts capping — keys identifying (deliveries choosing — correctness earning (deriving owning — hoping refusing).
