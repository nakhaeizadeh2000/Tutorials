# 1.1. Quorums bounding agreement

## 1. Stakes naming (elections requiring — leases timing — visions converging)

**Definition** — named stakes: requiring elections timing leases converging visions (elections requiring — single deciders choosing (terms fencing — majorities confirming (requiring proving — assuming declining); leases timing — temporary holds granting (ttls bounding — renewals pacing (timing funding — forever declining); visions converging — replicas settling (versions merging — conflicts resolving (converging owning — agreeing declining).

**What problem it solves** — the unstaked-agreement trio: *elections unrequiring* (leaders unchosen — writers multiplying (terms unfenced — brains splitting (unrequiring billing — safety failing); *leases untiming* (holds unbounding — clocks unskewed (renewals unpaced — dead holders blocking (untiming charging — liveness failing); *visions unconverging* (replicas unsettling — versions unmerging (conflicts unresolving — reads disagreeing (unconverging costing — honesty failing). Named stakes converting agreeing to choosing (deciders electing — holds timing (visions settling — levels earning); reviewers finding stake rows per shared state (naming proving → verifiable; agreeing → returned).

**Modern guidance** — the naming lines per shared state (review-enforced): *elections requiring* ([01/3.1](<../../../01 System Design Foundations and Mental Model/sections/3. First safety/3.1. Single points removing redundancy.md>) — single deciders choosing (majorities confirming — terms fencing (requiring proving — splitting refusing (deciders earning — writers singling); *leases timing* — temporary holds granting (ttls bounding — renewals pacing (timing funding — forever refusing (leases keeping — dead releasing); *visions converging* — replicas settling (versions merging — conflicts resolving (converging owning — agreeing refusing (settles keeping — quorums sparing).

```typescript
// GOOD: stakes naming — elections requiring, leases timing (compiled + run live).
type Stake = 'elect' | 'lease' | 'converge';
function stakeFor(singleDecider: boolean, temporary: boolean): Stake {
  if (singleDecider) return 'elect'; // elections requiring — writers singling, splitting declining
  if (temporary) return 'lease'; // leases timing — dead releasing, forever declining
  return 'converge'; // visions converging — quorums sparing, agreeing declining
}
console.log(stakeFor(true, false) === 'elect' && stakeFor(false, true) === 'lease' && stakeFor(false, false) === 'converge' ? 'stakes name' : 'stakes blur');
```

```typescript
// BAD: stakes blurring — elections unrequiring, leases untiming (real blur shape).
// // One lock for everything (quorums pricing — dead blocking — liveness failing).
// // No agreement anywhere (writers multiplying — brains splitting). Name stakes; time leases; converge rest.)
```

**Common confusion** — *"consensus is the default (stakes skipping)."* Skipping agreeing everywhere (deciders unchosen — holds unbounding (visions unconverging — quorums pricing (skipping charging — latency failing); naming fitting levels (elections requiring — leases timing (visions converging — costs matching (naming proving — defaulting declining). "Default" describing comfort (agreeing pricing — dead blocking); stakes describing fit (deciders choosing — holds timing). Elect singly (writers singling — splits deciding); converge rest (settles keeping — quorums sparing).

**Performance note** — naming economics: choosing costing judgments (deciders electing — holds timing (visions settling — levels earning); agreed equivalents costing quorums (majorities waiting — tails growing (dead blocking — trust eroding). Name cheaply (stakes — rows); agree never (consensus — defaults).

**Mentor note** — teach "elect, lease, or converge — every shared state" (juniors naming one stake per shared state design default-proof agreement on first hearing; stakeless agreement interrogated ("elect? lease? converge?" — naming demanding per state). Name one stake once (elections requiring — leases timing tangible (blurring ending — naming proving permanently). Require elections; time leases — naming discipline in three habits, reviewed per state.

## 2. Quorums intersecting (reads sizing — writes sizing — overlaps demanding)

**Definition** — intersecting quorums: sizing reads sizing writes demanding overlaps (reads sizing — loads counting (hot reads lowering — tails sparing (sizing proving — guessing declining); writes sizing — burdens weighing (hot writes lowering — stalls bounding (sizing funding — hoping declining); overlaps demanding — sums exceeding (majorities unneeded — intersections proving (demanding owning — splitting declining).

**What problem it solves** — the non-intersecting trio: *reads unsizing* (loads uncounted — R defaulting (hot paths unlowered — tails growing (unsizing billing — latency failing); *writes unsizing* (burdens unweighed — W defaulting (hot ingests unlowered — stalls hiding (unsizing charging — throughput failing); *overlaps undemanding* (sums unexceeding — majorities assumed (intersections unproven — readers missing writes (undemanding costing — consistency failing). Intersecting quorums converting defaulting to sizing (loads counting — burdens weighing (sums exceeding — freshness proving); reviewers finding R+W sums per workload (intersecting proving → verifiable; defaulting → returned).

**Modern guidance** — the intersecting lines per workload (review-enforced): *reads sizing* ([03/1.2](<../../../03 Reliability and Fault Tolerance/sections/1. Fault thinking/1.2. Redundancy surviving zones.md>) — loads counting (hot reads lowering — tails sparing (sizing proving — defaulting refusing (counts earning — freshness funding); *writes sizing* — burdens weighing (hot writes lowering — stalls bounding (sizing funding — hoping refusing (weights keeping — durability earning); *overlaps demanding* — sums exceeding (R+W outnumbering — readers meeting writers (demanding owning — missing refusing (sums stating — staleness ending).

```typescript
// GOOD: quorums intersecting — reads sizing, writes sizing (compiled + run live).
interface Quorum { // reads sizing — loads counting, defaulting declining
  reads: number;
  writes: number;
  nodes: number;
}
function overlap(q: Quorum): boolean {
  return q.reads + q.writes > q.nodes; // overlaps demanding — sums exceeding, missing declining
} // writes sizing — burdens weighing, hoping declining (caller asserts below)
const crisp: Quorum = { reads: 2, writes: 2, nodes: 3 };
const fog: Quorum = { reads: 1, writes: 1, nodes: 3 };
console.log(overlap(crisp) && !overlap(fog) ? 'quorums overlap' : 'readers miss');
```

```typescript
// BAD: quorums defaulting — reads unsizing, overlaps undemanding (real default shape).
// // Majority for everything (tails growing — stalls hiding — freshness hoping).
// // R1 W1 on 3 nodes (readers missing writes — staleness ruling). Size reads; size writes; demand overlap.)
```

**Common confusion** — *"majority reads and writes is the quorum (sizing skipping)."* Skipping defaulting majorities (loads uncounted — burdens unweighed (sums unstated — tails growing (skipping charging — freshness failing); intersecting sizing per load (reads lowering — writes lowering (sums exceeding — freshness proving (intersecting earning — defaulting declining). "Quorum" describing majorities (sums assuming — tails paying); intersections describing workloads (loads counting — burdens weighing). Count loads (reads sizing — tails sparing); exceed sums (overlaps demanding — staleness ending).

**Performance note** — intersecting economics: sizing costing counts (loads tallying — burdens weighing (sums exceeding — freshness proving); defaulted equivalents costing tails (majorities waiting — stalls hiding (staleness ruling — trust eroding). Size cheaply (quorums — workloads); default never (majorities — comforts).

**Mentor note** — teach "R+W beats N, sized per load" (juniors sizing one read-write pair per workload design default-proof freshness on first hearing; unsized quorums interrogated ("R? W? N?" — intersecting demanding per workload). Size one pair once (reads counting — writes weighing tangible (defaulting ending — intersecting proving permanently). Lower hot paths; exceed totals — intersecting discipline in three habits, reviewed per workload.

## 3. Terms fencing (epochs numbering — zombies defanging — splits deciding)

**Definition** — fencing terms: numbering epochs defanging zombies deciding splits (epochs numbering — leaders stamping (terms monotonicing — recencies proving (numbering owning — timeless declining); zombies defanging — stale leaders refusing (old terms losing — partitions healing (defanging funding — clobbering declining); splits deciding — majorities judging (terms comparing — halves refusing (deciding earning — merging declining).

**What problem it solves** — the termless trio: *epochs unnumbering* (leaders unstamping — terms untracked (recencies unproven — zombies indistinguishable (unnumbering billing — safety failing); *zombies undefanging* (stale leaders writing — old terms winning (fresh state clobbering — partitions healing dangerously (undefanging charging — correctness failing); *splits undeciding* (majorities unjudging — terms uncompared (halves merging — data diverging (undeciding costing — consistency failing). Fencing terms converting timeless to numbering (leaders stamping — stale refusing (majorities judging — splits ending); reviewers finding epoch checks per leadership change (fencing proving → verifiable; timeless → returned).

**Modern guidance** — the fencing lines per leadership (review-enforced): *epochs numbering* — leaders stamping (terms monotonicing — recencies proving (numbering owning — timeless refusing (stamps keeping — zombies naming); *zombies defanging* ([Redis 04/2.2](<../../../../Redis/04 Persistence Replication and Sentinel/sections/2. Copies/2.2. Sentinel failover.md>) — stale leaders refusing (old terms losing — partitions healing (defanging funding — clobbering refusing (fences keeping — freshness earning); *splits deciding* — majorities judging (terms comparing — halves refusing (deciding earning — merging refusing (judgments keeping — divergence ending).

```typescript
// GOOD: terms fencing — epochs numbering, zombies defanging (compiled + run live).
function fenced(incoming: number, seen: number): boolean {
  return incoming > seen; // zombies defanging — old terms losing, clobbering declining
} // epochs numbering — leaders stamping, timeless declining (caller asserts below)
const fresh = fenced(6, 5);
const stale = fenced(3, 5);
console.log(fresh && !stale ? 'terms fence' : 'zombies write');
```

```typescript
// BAD: terms timelessing — epochs unnumbering, zombies undefanging (real timeless shape).
// // Trust the leader (terms untracked — zombies indistinguishable — clobbers scheduled).
// // Fail over blindly (halves merging — data diverging). Number epochs; defang zombies; decide splits.)
```

**Common confusion** — *"fencing needs clocks (epochs timing)."* Timing syncing clocks (skews leaking — bounds drifting (ordering hoping — partitions breaking (timing charging — correctness failing); numbering ordering epochs (leaders stamping — receivers comparing (agreement unneeded — larger winning (numbering proving — clocking declining). "Clocks" describing time (skews leaking — healing breaking); terms describing order (stamps numbering — stale losing). Stamp terms (epochs numbering — recencies proving); refuse stale (old losing — freshness earning).

**Performance note** — fencing economics: numbering costing integers (leaders stamping — stale refusing (splits deciding — safety earning); termless equivalents costing clobbers (fresh state lost — divergences merging (trust zeroing — outages compounding). Number cheaply (terms — epochs); timeless never (leaders — trusts).

**Mentor note** — teach "every leader carries a number, every follower checks it" (juniors fencing one epoch per leadership design zombie-proof promotion on first hearing; numberless leadership interrogated ("epoch? checked where?" — fencing demanding per leader). Fence one term once (epochs numbering — zombies defanging tangible (timeless ending — fencing proving permanently). Stamp leaders; compare terms — fencing discipline in three habits, reviewed per promotion.
