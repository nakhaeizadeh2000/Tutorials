## 1. Agreements auditing (stakes naming — quorums proving — terms checking)

**Definition** — audited agreements: naming stakes proving quorums checking terms (stakes naming — rows stating (elects choosing — leases timing (naming funding — agreeing declining); quorums proving — sums exceeding (R+W outnumbering — defaults refusing (proving owning — missing declining); terms checking — epochs numbering (leaders stamping — zombies refusing (checking earning — timeless declining).

**What problem it solves** — the unaudited-agreement trio: *stakes unnamed* (rows unstated — elects unchosen (leases untimed — agreeing ruling (unnamed billing — comfort failing); *quorums unproven* (sums unexceeded — R+W unstated (defaults ruling — readers missing (unproven charging — freshness failing); *terms unchecked* (epochs unnumbered — leaders unstamped (zombies unrefused — clobbers scheduled (unchecked costing — safety failing). Audited agreements converting ruling to naming (rows stating — sums exceeding (epochs numbering — agreements earning); reviewers finding agreement audits per flow (auditing proving → verifiable; ruling → returned).

**Modern guidance** — the auditing lines per flow (review-enforced): *stakes naming* ([1.1](<../../sections/1. Agreement thinking/1.1. Agreement thinking/1.1. Quorums bounding agreement.md>) — sums exceeding (R+W outnumbering — defaults refusing (proving owning — missing refusing (proofs keeping — freshness earning); *terms checking* ([1.1](<../../sections/1. Agreement thinking/1.1. Quorums bounding agreement.md>) — epochs numbering (leaders stamping — zombies refusing (checking earning — timeless refusing (checks keeping — safety earning).

}

**Performance note** — auditing economics: naming costing rows (stakes stating — sums exceeding (terms numbering — agreements earning); assumed equivalents costing surprises (readers missing — zombies writing (trust eroding — incidents compounding). Audit cheaply (agreements — rows); assume never (stakes — comforts).

**Mentor note** — teach "every flow audits its agreements before shipping" (juniors auditing one agreement triple per flow design assume-proof coordination on first hearing; unaudited flows interrogated ("stakes? quorums? terms?" — auditing demanding per flow).
