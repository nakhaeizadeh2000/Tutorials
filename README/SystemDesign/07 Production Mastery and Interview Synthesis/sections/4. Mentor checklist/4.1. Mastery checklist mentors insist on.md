# 4.1. Mastery checklist mentors insist on

## 1. Every design composing (briefs answering — chains composing — depths embedding)

**Definition** — the design gate: each system answering briefs, composing chains, embedding depths (briefs answering — scopes clarifying (loads estimating — designs reviewing (answering proving — blobbing declining); chains composing — bottlenecks naming (scalings sizing — reliabilities bounding (composing funding — scattering declining); depths embedding — stores choosing (agreements fencing — releases sequencing (embedding owning — defaulting declining).

**What problem it solves** — the ungated-system trio: *briefs unanswering* (scopes unclarified — loads unestimated (designs unreviewed — blobs ruling (unanswering billing — focus failing); *chains uncomposing* (bottlenecks unnamed — scalings unsized (reliabilities unbounded — wholes unheld (uncomposing charging — leverage failing); *depths unembedding* (stores unchosen — agreements unfenced (releases unsequenced — defaults ruling (unembedding costing — data failing). Gated systems converting blobbing to composing (scopes clarifying — bottlenecks naming (stores choosing — gaps closing); reviewers returning systems missing any row (gating proving → verifiable; blobbing → returned).

**Modern guidance** — the gating lines per system (review-enforced): *briefs answering* ([1.1](<../1. Full-system design/1.1. Full-system designs answering briefs.md>) — scopes clarifying (loads estimating — designs reviewing (answering proving — blobbing refusing (answers earning — fog ending); *chains composing* ([1.1](<../1. Full-system design/1.1. Full-system designs answering briefs.md>) — bottlenecks naming (scalings sizing — reliabilities bounding (composing funding — scattering refusing (composes keeping — wholes holding); *depths embedding* ([1.1](<../1. Full-system design/1.1. Full-system designs answering briefs.md>) — stores choosing (agreements fencing — releases sequencing (embedding owning — defaulting refusing (embeds keeping — surprises ending).

```typescript
// GOOD: design gate — briefs answering, chains composing, depths embedding (commented shape).
// // 1. Brief proof (scopes clarifying — loads estimating):
// //    users named with counted loads — box-first designs returned, briefed systems pass.
// // 2. Chain proof (bottlenecks naming — scalings sizing):
// //    binder stated with sized scalings — binderless designs returned.
// // 3. Depth proof (stores choosing — releases sequencing):
// //    deciding layers justified — defaulted layers returned, embedded systems pass.
```

```typescript
// BAD: design hoping — briefs unanswering, depths unembedding (commented anti-shape).
// // Architecture overview (scopes unclarified — chains uncomposed — depths unchecked).
// // Details TBD (defaults ruling — blobs ruling). Gate briefs; gate chains; gate depths.)
```

**Common confusion** — *"checklists gatekeep juniors (gates excluding)."* Excluding demanding rows (briefs answering — chains composing (depths embedding — gaps closing (demanding funding — blobbing declining); gatekeeping hiding bars (scopes unlisted — binders unnamed (reviews unowned — juniors guessing (hiding charging — growth failing). "Gatekeep" describing secrecy (bars hidden — juniors guessing); gates describing clarity (rows listed — gaps closing). List rows (briefs answering — fog ending); close gaps (depths embedding — surprises ending).

**Performance note** — gating economics: answering costing rows (scopes clarifying — bottlenecks naming (stores choosing — gaps closing); hoped equivalents costing blobs (scopes unclarified — chains uncomposed (defaults ruling — trust eroding). Gate cheaply (designs — rows); hope never (systems — overviews).

**Mentor note** — teach "no brief rows, no design review — every system" (juniors gating one system per three proofs design hope-proof mastery on first hearing; gateless systems interrogated ("briefs? chains? depths?" — gating demanding per system). Gate one system once (briefs answering — chains composing tangible (hoping ending — gating proving permanently). Demand scopes; demand binders — gating discipline in three habits, reviewed per system.
