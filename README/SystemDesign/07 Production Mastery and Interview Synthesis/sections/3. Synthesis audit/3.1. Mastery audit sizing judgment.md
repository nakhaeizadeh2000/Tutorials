## 1. Designs auditing (briefs naming — chains proving — depths checking)

**Definition** — audited designs: naming briefs proving chains checking depths (briefs naming — scopes stating (loads estimating — honesty reviewing (naming proving — blobbing declining); chains proving — binders counting (scalings sizing — bounds auditing (proving funding — scattering declining); depths checking — stores verifying (fences verifying — ships verifying (checking owning — defaulting declining).

**What problem it solves** — the unaudited-design trio: *briefs unnaming* (scopes unstated — loads unestimated (honesty unreviewed — blobs ruling (unnaming billing — focus failing); *chains unproving* (binders uncounted — scalings unsized (bounds unaudited — wholes unheld (unproving charging — leverage failing); *depths unchecking* (stores unverified — fences unverified (ships unverified — defaults ruling (unchecking costing — data failing). Audited designs converting blobbing to naming (scopes stating — binders counting (stores verifying — gaps closing); reviewers finding design rows per system (auditing proving → verifiable; blobbing → returned).

**Modern guidance** — the auditing lines per system (review-enforced): *briefs naming* ([1.1](<../1. Full-system design/1.1. Full-system designs answering briefs.md>) — scopes stating (loads estimating — honesty reviewing (naming proving — blobbing refusing (names earning — fog ending); *chains proving* ([1.1](<../1. Full-system design/1.1. Full-system designs answering briefs.md>) — binders counting (scalings sizing — bounds auditing (proving funding — scattering refusing (proofs keeping — wholes holding); *depths checking* — stores verifying (fences verifying — ships verifying (checking owning — defaulting refusing (checks keeping — surprises ending).

```typescript
// GOOD: designs auditing — briefs naming, chains proving (compiled + run live).
interface DesignRow { briefs: number; chains: number; depths: number }
function designGaps(d: DesignRow): number {
  return (3 - Math.min(d.briefs, 3)) + (3 - Math.min(d.chains, 3)) + (3 - Math.min(d.depths, 3)); // briefs naming — scopes stating, blobbing declining
} // chains proving — binders counting, scattering declining (caller asserts below)
const crisp: DesignRow = { briefs: 3, chains: 3, depths: 3 };
const fog: DesignRow = { briefs: 1, chains: 0, depths: 1 };

```

**Common confusion** — *"audits repeat the interview (rows echoing)."* Echoing restating answers (briefs renamed — chains relisted (depths rechecked — time doubling (echoing charging — value failing); auditing sizing judgment (scopes stating — binders counting (stores verifying — gaps closing (auditing earning — echoing declining). "Echo" describing repetition (answers restated — time doubled); audits describing measurement (rows counting — gaps closing). State scopes (briefs naming — fog ending); verify stores (depths checking — surprises ending).

**Performance note** — auditing economics: naming costing rows (scopes stating — binders counting (stores verifying — gaps closing); hoped equivalents costing blobs (scopes unstated — binders uncounted (defaults ruling — trust eroding). Audit cheaply (designs — rows); hope never (systems — solids).

**Mentor note** — teach "every system shows its briefs, chains, and depths — every review" (juniors auditing one system per three rows design hope-proof mastery on first hearing; rowless systems interrogated ("briefs? chains? depths?" — auditing demanding per system). Audit one system once (briefs naming — chains proving tangible (hoping ending — auditing proving permanently). List scopes; count binders — auditing discipline in three habits, reviewed per system.
