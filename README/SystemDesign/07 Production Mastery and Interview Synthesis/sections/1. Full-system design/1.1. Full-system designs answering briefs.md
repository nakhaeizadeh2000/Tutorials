# 1.1. Full-system designs answering briefs

## 1. Briefs answering (scopes clarifying — loads estimating — designs reviewing)

**Definition** — answered briefs: clarifying scopes estimating loads reviewing designs (scopes clarifying — questions asking (users naming — non-goals stating (clarifying proving — blobbing declining); loads estimating — numbers counting (reads tallying — writes weighing (estimating funding — guessing declining); designs reviewing — honesty stating (limits owning — probes planning (reviewing owning — bluffing declining).

**What problem it solves** — the unanswered-brief trio: *scopes unclarifying* (questions unasked — users unnamed (non-goals unstated — blobs ruling (unclarifying billing — focus failing); *loads unestimating* (numbers uncounted — reads uncounted (writes unweighed — boxes drawn (unestimating charging — sizing failing); *designs unreviewing* (honesty unstated — limits unowned (probes unplanned — bluffs ruling (unreviewing costing — trust failing). Answered briefs converting blobbing to clarifying (questions asking — numbers counting (honesty stating — focus earning); reviewers finding brief rows per system (answering proving → verifiable; blobbing → returned).

**Modern guidance** — the answering lines per brief (review-enforced): *scopes clarifying* ([01/1.1](<../../../01 System Design Foundations and Mental Model/sections/1. Design thinking/1.1. Clarify estimate design review.md>) — questions asking (users naming — non-goals stating (clarifying proving — blobbing refusing (scopes earning — fog ending); *loads estimating* ([01/1.2](<../../../01 System Design Foundations and Mental Model/sections/1. Design thinking/1.2. Back-of-envelope arithmetic.md>) — numbers counting (reads tallying — writes weighing (estimating funding — guessing refusing (estimates keeping — boxes earning); *designs reviewing* ([01/1.1](<../../../01 System Design Foundations and Mental Model/sections/1. Design thinking/1.1. Clarify estimate design review.md>) — honesty stating (limits owning — probes planning (reviewing owning — bluffing refusing (reviews keeping — trust earning).

```typescript
// GOOD: briefs answering — scopes clarifying, loads estimating (compiled + run live).
interface Brief { scoped: boolean; estimated: boolean; reviewed: boolean }
function answered(b: Brief): boolean {
  return b.scoped && b.estimated && b.reviewed; // scopes clarifying — questions asking, blobbing declining
} // loads estimating — numbers counting, guessing declining (caller asserts below)
const crisp: Brief = { scoped: true, estimated: true, reviewed: true };
const fog: Brief = { scoped: true, estimated: false, reviewed: true };
console.log(answered(crisp) && !answered(fog) ? 'briefs answer' : 'designs blob');
```

```typescript
// BAD: briefs blobbing — scopes unclarifying, designs unreviewing (real blob shape).
// // Design Twitter (questions unasked — numbers uncounted — boxes drawn).
// // Scale is handled (honesty unstated — bluffs ruling). Clarify scopes; estimate loads; review honestly.)
```

**Common confusion** — *"briefs waste whiteboard time (questions delaying)."* Delaying asking questions (scopes clarifying — loads estimating (designs reviewing — focus earning (delaying funding — blobbing declining); rushing drawing boxes (users unnamed — numbers uncounted (bluffs ruling — rework dating (rushing charging — focus failing). "Slow" describing questions (briefs answering — fog ending); fast describing blobs (boxes drawn — rework scheduled). Ask first (scopes clarifying — fog ending); draw last (designs reviewing — bluffs ending).

**Performance note** — answering economics: clarifying costing minutes (questions asking — numbers counting (honesty stating — focus earning); blobbed equivalents costing reworks (users unnamed — boxes wrong (bluffs ruling — trust eroding). Answer cheaply (briefs — rows); blob never (designs — boxes).

**Mentor note** — teach "scope, estimate, review — every brief" (juniors answering one brief per three rows design blob-proof interviewing on first hearing; box-first designs interrogated ("users? numbers? limits?" — answering demanding per brief). Answer one brief once (scopes clarifying — loads estimating tangible (blobbing ending — answering proving permanently). Name users; count loads — answering discipline in three habits, reviewed per brief.

## 2. Chains composing (bottlenecks naming — scalings sizing — reliabilities bounding)

**Definition** — composed chains: naming bottlenecks sizing scalings bounding reliabilities (bottlenecks naming — binders stating (slowest owning — efforts focusing (naming proving — diffusing declining); scalings sizing — reads caching (writes sharding — bursts queueing (sizing funding — hoping declining); reliabilities bounding — SLOs stating (redundancy numbering — blasts auditing (bounding owning — flooding declining).

**What problem it solves** — the unchained-design trio: *bottlenecks unnamed* (binders unstated — efforts diffusing (optimizers scattering — focus failing (unnamed billing — leverage failing); *scalings unsized* (reads uncaching — writes unsharded (bursts unqueued — cliffs surprising (unsized charging — capacity failing); *reliabilities unbounded* (SLOs unstated — redundancy unnumbered (blasts unaudited — floods dating (unbounded costing — safety failing). Composed chains converting scattering to naming (binders stating — reads caching (SLOs stating — wholes holding); reviewers finding chain rows per design (composing proving → verifiable; scattering → returned).

**Modern guidance** — the composing lines per design (review-enforced): *bottlenecks naming* ([02/2.1](<../../../02 Scaling Reads and Writes/sections/2. Write thinking/2.1. ```typescript
// GOOD: chains composing — bottlenecks naming, scalings sizing (compiled + run live).
interface Chain { binders: number; scalings: number; bounds: number }
function composed(c: Chain): boolean {

```typescript
// BAD: chains scattering — bottlenecks unnamed, reliabilities unbounded (real scatter shape).
// // Cache everything (binders unstated — writes unsharded — SLOs unstated).
// // Reliable by construction (redundancy unnumbered — floods dating). Name binders; size scalings; bound blasts.)
```

**Common confusion** — *"composition means covering everything (chains exhausting)."* Exhausting listing layers (tiers naming — boxes drawing (depth performing — focus diffusing (exhausting charging — leverage failing); composing binding constraints (binders stating — scalings sizing (bounds auditing — wholes holding (composing earning — exhausting declining). "Everything" describing comfort (layers listing — focus diffusing); chains describing leverage (slowest owning — efforts focusing). Bind slowest (bottlenecks naming — focus earning); bound remainder (reliabilities bounding — floods ending).

**Performance note** — composing economics: naming costing rows (binders stating — scalings sizing (bounds auditing — wholes holding); scattered equivalents costing waste (efforts diffusing — cliffs surprising (floods dating — trust eroding). Compose cheaply (chains — binders); scatter never (designs — everythings).

**Mentor note** — teach "binder, scalings, bounds — every design" (juniors composing one chain per three rows design scatter-proof designing on first hearing; binderless designs interrogated ("slowest? cached? bounded?" — composing demanding per design). Compose one chain once (bottlenecks naming — scalings sizing tangible (scattering ending — composing proving permanently). State binders; audit blasts — composing discipline in three habits, reviewed per design.
