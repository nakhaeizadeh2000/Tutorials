# 1.2. Redundancy surviving zones

## 1. Copies numbering (replicas provisioning — zones spreading — quorums requiring)

**Definition** — numbered redundancy: provisioned replicas spreading zones requiring quorums (replicas provisioning — spares numbering (standbys warming — takeovers readying (provisioning proving — singling declining); zones spreading — regions spanning (failures bounding — blasts limiting (spreading funding — stacking declining); quorums requiring — majorities deciding (partitions judging — splits refusing (requiring owning — merging declining).

**What problem it solves** — the single-copy trio: *replicas unprovisioning* (spares unnumbered — standbys unwarming (takeovers unready — failures totalizing (unprovisioning billing — redundancy hoping); *zones unspreading* (regions unspanned — failures unbounded (blasts unlimited — outages maximizing (unspreading charging — topology failing); *quorums unrequiring* (majorities undecided — partitions unjudged (splits merging — data diverging (unrequiring costing — consistency failing). Numbered copies converting singling to provisioning (spares numbering — regions spanning (majorities deciding — totals preventing); reviewers finding replica math per point (numbering proving → verifiable; singling → returned).

**Modern guidance** — the numbering lines per failure point (review-enforced): *replicas provisioning* (spares numbering — standbys warming (takeovers readying — singling declining (provisioning proving — hoping refusing (numbers earning — totals preventing); *zones spreading* (regions spanning — failures bounding (blasts limiting — stacking declining (spreading funding — piling refusing (spans keeping — outages minimizing); *quorums requiring* (majorities deciding — partitions judging (splits refusing — merging declining (requiring owning — diverging refusing (majorities keeping — consistency earning).

```typescript
// GOOD: copies numbering — provisioned replicas spreading zones (compiled + run live).
function quorum(n: number): number {
  return Math.floor(n / 2) + 1; // replicas provisioning — spares numbering, singling declining
}
function zoneSafe(replicas: number, zones: number): boolean {
  return replicas >= 3 && zones >= 3; // zones spreading — regions spanning, stacking declining
} // quorums requiring — majorities deciding, merging declining (caller asserts below)
console.log(quorum(3) === 2 && quorum(5) === 3 && zoneSafe(3, 3) && !zoneSafe(2, 1) ? 'copies number' : 'singles fail');
```

```typescript
// BAD: singles failing — replicas unprovisioning, zones unspreading (real total shape).
// // One instance (spares unnumbered — failures totalizing — redundancy hoping).
// // One zone (blasts unlimited — outages maximizing). Provision spares; span zones; require quorums.)
```

**Common confusion** — *"more replicas mean safer (copies multiplying)."* Multiplying provisioning spares (replicas numbering — standbys warming (takeovers readying — totals preventing (multiplying serving — redundancy funding); safer requiring quorums (partitions judging — splits refusing (data converging — consistency keeping (requiring proving — merging declining). "More" describing counts (spares numbering — bills growing); copies describing majorities (quorums deciding — splits refusing). Number odd (majorities requiring — ties breaking); span regions (zones spanning — blasts limiting).

**Performance note** — numbering economics: provisioning costing spares (replicas numbering — zones spanning (quorums requiring — totals preventing); single equivalents costing totals (failures totalizing — blasts unlimited (outages maximizing — trust zeroing). Number cheaply (copies — points); single never (instances — zones).

**Mentor note** — teach "odd replicas across three zones minimum" (juniors numbering one copy-set per point design single-proof redundancy on first hearing; even singletons interrogated ("quorum? zones?" — numbering demanding per point). Number one copy once (spares provisioning — regions spanning tangible (singling ending — numbering proving permanently). Warm standbys; decide majorities — numbering discipline in three habits, reviewed per point.

## 2. Failovers rehearsing (promotions drilling — traffic shifting — losses bounding)

**Definition** — rehearsed failovers: drilled promotions shifting traffic bounding losses (promotions drilling — standbys elevating (health confirming — splits deciding (drilling proving — hoping declining); traffic shifting — loads migrating (primaries demoting — replicas promoting (shifting owning — dropping declining); losses bounding — writes fencing (gaps measuring — recencies proving (bounding funding — diverging declining).

**What problem it solves** — the pager-failover trio: *promotions undrilling* (standbys unelevated — health unconfirmed (splits undecided — takeovers fumbling (undrilling billing — readiness bluffing); *traffic unshifting* (loads unmigrated — primaries undemoted (replicas unpromoted — writes dropping (unshifting charging — continuity failing); *losses unbounding* (writes unfenced — gaps unmeasured (recencies unproved — divergences hiding (unbounding costing — honesty failing). Rehearsed failovers converting paging to drilling (standbys elevating — loads migrating (writes fencing — losses bounding); reviewers finding drill dates per promotion (rehearsing proving → verifiable; paging → returned).

**Modern guidance** — the rehearsing lines per promotion (review-enforced): *promotions drilling* (standbys elevating — health confirming (splits deciding — hoping declining (drilling proving — paging refusing (drills earning — takeovers succeeding); *traffic shifting* (loads migrating — primaries demoting (replicas promoting — dropping declining (shifting owning — cutting refusing (migrations funding — continuity keeping); *losses bounding* (writes fencing — gaps measuring (recencies proving — diverging declining (bounding owning — hiding refusing (fences keeping — honesty earning).

```typescript
// GOOD: failovers rehearsing — drilled promotions shifting traffic (compiled + run live).
function promote(healthy: boolean, lagMs: number, lagCap: number): string {
  if (!healthy) return 'HOLD'; // promotions drilling — standbys elevating, hoping declining
  if (lagMs > lagCap) return 'HOLD';
  return 'PROMOTE'; // traffic shifting — loads migrating, dropping declining
} // losses bounding — writes fencing, diverging declining (caller asserts below)
console.log(promote(true, 200, 5000) === 'PROMOTE' && promote(false, 200, 5000) === 'HOLD' && promote(true, 9000, 5000) === 'HOLD' ? 'failovers rehearse' : 'pagers hope');
```

```typescript
// BAD: pagers hoping — promotions undrilling, losses unbounding (real fumble shape).
// // Failover on pager (standbys unelevated — takeovers fumbling — outages extending).
// // Lag unknown (gaps unmeasured — divergences hiding). Drill promotions; shift traffic; bound losses.)
```

**Common confusion** — *"failover is automatic (platforms promoting)."* Promoting configuring automation (health checking — standbys elevating (traffic shifting — losses bounding (configuring serving — readiness earning); automatic assuming magic (policies unstated — rehearsals missing (splits undecided — takeovers fumbling (assuming charging — evidence failing). "Automatic" describing hope (policies unstated — rehearsals missing); failovers describing drills (standbys elevating — lags bounding). Elevate standbys (health confirming — takeovers succeeding); fence writes (gaps measuring — honesty earning).

**Performance note** — rehearsing economics: drilling costing exercises (standbys elevating — traffic shifting (writes fencing — losses bounding); hoped equivalents costing fumbles (takeovers fumbling — gaps unmeasured (outages extending — trust eroding). Drill cheaply (promotions — quarters); hope never (pagers — failovers).

**Mentor note** — teach "promote only what you rehearse" (juniors drilling one promotion per quarter design fumble-proof failovers on first hearing; undrilled promotions interrogated ("last drill?" — rehearsing demanding per promotion). Rehearse one failover once (standbys elevating — traffic shifting tangible (hoping ending — rehearsing proving permanently). Confirm health; measure gaps — rehearsing discipline in three habits, reviewed per quarter.

## 3. Fates decoupling (suppliers varying — deploys staggering — clocks skewing)

**Definition** — decoupled deployment fates: varied suppliers staggering deploys skewing clocks (suppliers varying — vendors mixing (regions spreading — dependencies diversifying (varying proving — coupling declining); deploys staggering — releases phasing (fleets fractioning — blasts bounding (staggering funding — flipping declining); clocks skewing — times offsetting (orderings bounding — simultaneity refusing (skewing owning — assuming declining).

**What problem it solves** — the common-mode trio: *suppliers unvarying* (vendors unmixed — regions unspread (dependencies undiversified — fates coupling (unvarying billing — independence failing); *deploys unstaggering* (releases unphased — fleets unflipped (blasts unbound — bugs fleet-wideing (unstaggering charging — safety failing); *clocks unskewing* (times unoffset — orderings unbounded (simultaneity assuming — causality breaking (unskewing costing — correctness bluffing). Decoupled fates converting coupling to varying (vendors mixing — releases phasing (times offsetting — fates separating); reviewers finding diversity axes per design (decoupling proving → verifiable; coupling → returned).

**Modern guidance** — the decoupling lines per design (review-enforced): *suppliers varying* (vendors mixing — regions spreading (dependencies diversifying — coupling declining (varying proving — singling refusing (mixes earning — fate ending); *deploys staggering* (releases phasing — fleets fractioning (blasts bounding — flipping declining (staggering funding — fleet-wide refusing (phases keeping — bugs containing); *clocks skewing* (times offsetting — orderings bounding (simultaneity refusing — assuming declining (skewing owning — hoping refusing (offsets measuring — causality keeping).

```typescript
// GOOD: fates decoupling — varied suppliers staggering deploys (compiled + run live).
function coupled(shareVendor: boolean, shareDeploy: boolean, shareClock: boolean): boolean {
  return shareVendor || shareDeploy || shareClock; // suppliers varying — vendors mixing, coupling declining
}
function rolloutOk(staggered: boolean, canaryPct: number): boolean {
  return staggered && canaryPct > 0; // deploys staggering — releases phasing, flipping declining
} // clocks skewing — times offsetting, assuming declining (caller asserts below)
console.log(!coupled(false, false, false) && coupled(true, false, false) && rolloutOk(true, 10) && !rolloutOk(false, 100) ? 'fates decouple' : 'modes couple');
```

```typescript
// BAD: modes coupling — suppliers unvarying, deploys unstaggering (real common-mode shape).
// // Same vendor, same deploy (dependencies undiversified — fates coupling — independence failing).
// // Synced clocks assumed (simultaneity assuming — causality breaking). Vary suppliers; stagger deploys; skew clocks.)
```

**Common confusion** — *"multi-region doubles cost (zones billing)."* Billing spanning regions (replicas numbering — traffic serving (blasts bounding — outages surviving (billing proving — budget funding); coupling sharing fate (vendors unmixed — deploys synced (bugs fleet-wideing — outages totalizing (coupling charging — independence failing). "Doubling" describing invoices (regions spanning — bills growing); fates describing survival (suppliers varying — blasts bounding). Mix vendors (regions spreading — fate decoupling); phase rollouts (fleets fractioning — bugs containing).

**Performance note** — decoupling economics: varying costing diversity (vendors mixing — releases phasing (times offsetting — fates separating); coupled equivalents costing common-modes (fates coupling — bugs fleet-wideing (outages totalizing — trust zeroing). Vary cheaply (axes — designs); couple never (fates — failures).

**Mentor note** — teach "same failure must never take all copies" (juniors varying one axis per design outage-proof fates on first hearing; single-axis fleets interrogated ("shared what?" — decoupling demanding per copy). Decouple one fate once (vendors mixing — releases phasing tangible (coupling ending — decoupling proving permanently). Spread regions; offset times — decoupling discipline in three habits, reviewed per design.
