## 1. Objectives stating (indicators choosing — targets bounding — windows timing)

**Definition** — stated objectives: chosen indicators bounding targets timing windows (indicators choosing — SLIs naming (goods counting — bads excluding (choosing proving — vibing declining); targets bounding — SLOs stating (nines numbering — errors budgeting (bounding funding — hoping declining); windows timing — periods scoping (burns rating — compliances judging (timing owning — eternaling declining).

**What problem it solves** — the un-SLO trio: *indicators unchoosing* (SLIs unnamed — goods uncounted (bads unexcluded — vanity ruling (unchoosing billing — measurement failing); *targets unbounding* (SLOs unstated — nines unnumbered (errors unbudgeted — vibes ruling (unbounding charging — promises bluffing); *windows untiming* (periods unscoped — burns unrated (compliances unjudged — recencies missing (untiming costing — calibration failing). Stated objectives converting vibes to choosing (SLIs naming — SLOs stating (periods scoping — promises earning); reviewers finding SLI/SLO pairs per journey (stating proving → verifiable; vibing → returned).

**Modern guidance** — the stating lines per journey (review-enforced): *indicators choosing* (SLIs naming — goods counting (bads excluding — vibing declining (choosing proving — vanity refusing (names earning — measurement keeping); *targets bounding* (SLOs stating — nines numbering (errors budgeting — hoping declining (bounding funding — bluffing refusing (bounds owning — promises earning); *windows timing* (periods scoping — burns rating (compliances judging — eternaling declining (timing owning — infinite refusing (scopes keeping — calibration earning).

// GOOD: objectives stating — chosen indicators bounding targets (compiled + run live).
interface Slo { // indicators choosing — SLIs naming, vibing declining
  sli: string;
  target: number;
  windowDays: number;
}
function vague(slos: Slo[]): string[] {
  const gaps: string[] = []; // targets bounding — SLOs stating, hoping declining

    if (s.sli.length === 0 || !(s.target > 0 && s.target < 100) || !(s.windowDays > 0)) gaps.push('slo');

  return gaps; // windows timing — periods scoping, eternaling declining
}

console.log(vague(crisp).length === 0 && vague(fog).join() === 'slo' ? 'objectives state' : 'promises vibe');

## 2. Budgets spending (errors burning — freezes gating — velocity trading)

**Definition** — spent error budgets: burned errors gating freezes trading velocity (errors burning — bads consuming (budgets depleting — risks pricing (burning proving — hiding declining); freezes gating — releases blocking (deploys pausing — features queuing (gating funding — shipping declining); velocity trading — risks buying (features funding — speed earning (trading owning — stalling declining).

**What problem it solves** — the unlimited-error trio: *errors unburning* (bads unconsumed — budgets undepleted (risks unpriced — recklessness funding (unburning billing — honesty failing); *freezes ungating* (releases unblocked — deploys unpaused (risks unpriced — velocity blind (ungating charging — discipline failing); *velocity untrading* (risks unbought — features unfunded (speed unearned — stalls ruling (untrading costing — product failing). Spent budgets converting hiding to burning (bads consuming — releases blocking (risks buying — honesty earning); reviewers finding burn rates per SLO (spending proving → verifiable; hiding → returned).

**Modern guidance** — the spending lines per SLO (review-enforced): *errors burning* (bads consuming — budgets depleting (risks pricing — hiding declining (burning proving — hoarding refusing (burns earning — honesty keeping); *freezes gating* (releases blocking — deploys pausing (features queuing — shipping declining (gating funding — flowing refusing (gates owning — risk pricing); *velocity trading* (risks buying — features funding (speed earning — stalling declining (trading owning — fearing refusing (trades funding — product earning).

```typescript
// GOOD: budgets spending — burned errors gating freezes (compiled + run live).
function budgetLeft(targetPct: number, bad: number, total: number): number {
  const allowed = (100 - targetPct) / 100; // errors burning — bads consuming, hiding declining
  return allowed * total - bad; // freezes gating — releases blocking, shipping declining
} // velocity trading — risks buying, stalling declining (caller asserts below)
function burnRate(bad: number, total: number, windowHrs: number): number {
  if (total <= 0 || windowHrs <= 0) return 0;
  return bad / total / windowHrs;
}
const left = budgetLeft(99.9, 30, 100000);
console.log(Math.abs(left - 70) < 1e-6 && burnRate(30, 100000, 1) === 0.0003 ? 'budgets spend' : 'errors hide'); // floats compared with tolerance, equality declining
```

// BAD: errors hiding — budgets unburning, velocity untrading (real blind shape).

// // Ship regardless (releases unblocked — velocity blind). Burn errors; gate freezes; trade velocity.)
```

**Common confusion** — *"budgets punish velocity (errors taxing)."* Taxing fining mistakes (errors counting — ships blocking (teams fearing — speed dying (taxing charging — product failing); spending trading risk (bads consuming — releases gating (features funding — speed earning (spending proving — hiding declining). "Punishing" describing fear (mistakes fining — teams fearing); budgets describing honesty (errors burning — risks pricing). Burn openly (bads consuming — honesty keeping); gate explicitly (releases blocking — risk pricing).

**Performance note** — spending economics: burning costing arithmetic (bads consuming — releases blocking (risks buying — honesty earning); hidden equivalents costing recklessness (risks unpriced — velocity blind (surprises scheduling — trust eroding). Burn cheaply (budgets — SLOs); hide never (errors — burns).

**Mentor note** — teach "spend the budget on purpose" (juniors burning one error ledger per SLO design blind-proof reliability on first hearing; unbudgeted SLOs interrogated ("burn rate?" — spending demanding per SLO). Spend one budget once (bads consuming — releases gating tangible (hiding ending — spending proving permanently). Consume bads; block releases — spending discipline in three habits, reviewed per SLO.

// GOOD: pages actioning — alarming thresholds routing owners (compiled + run live).
interface Alert { // thresholds alarming — limits paging, flooding declining
  name: string;
  owner: string;
  runbook: string;
}
function noisy(alerts: Alert[]): string[] {
  const gaps: string[] = []; // owners routing — humans naming, broadcasting declining
  for (const a of alerts) {
    if (a.owner.length === 0 || a.runbook.length === 0) gaps.push(a.name);
  }
  return gaps; // runbooks linking — procedures ordering, improvising declining
}
const owned: Alert[] = [{ name: 'burn-rate', owner: 'ada', runbook: '/runbooks/burn' }];
const loud: Alert[] = [{ name: 'burn-rate', owner: '', runbook: '' }];
console.log(noisy(owned).length === 0 && noisy(loud).join() === 'burn-rate' ? 'pages action' : 'pagers flood');
```
