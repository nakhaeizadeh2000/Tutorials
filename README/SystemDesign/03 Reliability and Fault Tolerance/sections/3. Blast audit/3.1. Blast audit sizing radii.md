# 3.1. Blast audit sizing radii

## 1. Radii measuring (scopes mapping — damages pricing — priorities ordering)

**Definition** — measured blast radii: mapped scopes pricing damages ordering priorities (scopes mapping — failures bounding (zones plotting — users counting (mapping proving — hoping declining); damages pricing — losses costing (downtimes valuing — trust eroding (pricing funding — ignoring declining); priorities ordering — mitigations ranking (fixes sequencing — budgets allocating (ordering owning — scrambling declining).

**What problem it solves** — the unmeasured-blast trio: *scopes unmapping* (failures unbounded — zones unplotted (users uncounted — surprises scheduling (unmapping billing — visibility failing); *damages unpricing* (losses uncosted — downtimes unvalued (trust uneroded-on-paper (reality billing-later — unpricing charging — honesty failing); *priorities unordering* (mitigations unranked — fixes unsequenced (budgets unallocated — scrambling ruling (unordering costing — triage bluffing). Measured radii converting hoping to mapping (failures bounding — losses costing (mitigations ranking — surprises ending); reviewers finding blast tables per design (measuring proving → verifiable; hoping → returned).

**Modern guidance** — the measuring lines per design (review-enforced): *scopes mapping* (failures bounding — zones plotting (users counting — hoping declining (mapping proving — hiding refusing (maps keeping — surprises ending); *damages pricing* (losses costing — downtimes valuing (trust eroding — ignoring declining (pricing funding — bluffing refusing (prices keeping — honesty earning); *priorities ordering* (mitigations ranking — fixes sequencing (budgets allocating — scrambling declining (ordering owning — triaging refusing (orders funding — triage earning).

```typescript
// GOOD: radii measuring — mapped scopes pricing damages (compiled + run live).
interface Blast { // scopes mapping — failures bounding, hoping declining
  scope: string;
  users: number;
  minsDown: number;
}
function unpriced(blasts: Blast[]): string[] {
  const gaps: string[] = []; // damages pricing — losses costing, ignoring declining
  for (const b of blasts) {
    if (!(b.users >= 0) || !(b.minsDown >= 0)) gaps.push(b.scope);
  }
  return gaps; // priorities ordering — mitigations ranking, scrambling declining
}
const mapped: Blast[] = [
  { scope: 'az-loss', users: 300000, minsDown: 20 },
  { scope: 'db-failover', users: 1000000, minsDown: 8 },
];
const fog: Blast[] = [{ scope: 'region-loss', users: -1, minsDown: 0 }];
console.log(unpriced(mapped).length === 0 && unpriced(fog).join() === 'region-loss' ? 'radii measure' : 'blasts fog');
```

```typescript
// BAD: blasts fogging — scopes unmapping, damages unpricing (real surprise shape).
// // "Acceptable loss." (failures unbounded — losses uncosted — honesty failing).
// // No blast table (surprises scheduling — triage bluffing). Map scopes; price damages; order priorities.)
```

**Common confusion** — *"measuring invites fear (numbers depressing)."* Depressing forecasting dooms (losses costing — downtimes valuing (morale dipping — velocity slowing (depressing charging — courage failing); measuring pricing triage (failures bounding — losses costing (mitigations ranking — surprises ending (measuring proving — hoping declining). "Inviting" describing mood (dooms forecasting — morale dipping); radii describing budgets (scopes mapping — damages pricing). Bound failures (zones plotting — surprises ending); rank mitigations (fixes sequencing — triage earning).

**Performance note** — measuring economics: mapping costing rows (failures bounding — losses costing (mitigations ranking — surprises ending); fogged equivalents costing surprises (losses uncosted — triage bluffing (trust eroding — pages multiplying). Map cheaply (radii — scopes); fog never (blasts — damages).

**Mentor note** — teach "every failure names its radius and price" (juniors measuring one blast table per design outage-proof audits on first hearing; unpriced failures interrogated ("users? minutes?" — measuring demanding per failure). Measure one radius once (failures bounding — losses costing tangible (hoping ending — measuring proving permanently). Plot zones; value downtime — measuring discipline in three habits, reviewed per design.

## 2. Dependencies grading (depths counting — fan-outs capping — cycles breaking)

**Definition** — graded dependencies: counted depths capping fan-outs breaking cycles (depths counting — chains measuring (hops tallying — graphs visualizing (counting proving — hiding declining); fan-outs capping — calls bounding (blast multiplying — neighbors shielding (capping funding — exploding declining); cycles breaking — graphs acyclicing (deadlocks ending — deploys sequencing (breaking owning — looping declining).

**What problem it solves** — the ungraded trio: *depths uncounting* (chains unmeasured — hops untallying (graphs undrawn — tangles hiding (uncounting billing — visibility failing); *fan-outs uncapping* (calls unbounded — blast unmultiplied (neighbors unshielded — avalanches scheduling (uncapping charging — containment failing); *cycles unbreaking* (graphs uncycled — deadlocks unended (deploys unsequenced — releases coupling (unbreaking costing — autonomy bluffing). Graded dependencies converting hiding to counting (chains measuring — calls bounding (graphs acyclicing — tangles surfacing); reviewers finding depth grades per design (grading proving → verifiable; hiding → returned).

**Modern guidance** — the grading lines per design (review-enforced): *depths counting* (chains measuring — hops tallying (graphs visualizing — hiding declining (counting proving — obscuring refusing (counts earning — tangles surfacing); *fan-outs capping* (calls bounding — blast multiplying (neighbors shielding — exploding declining (capping funding — hoping refusing (caps keeping — avalanches ending); *cycles breaking* (graphs acyclicing — deadlocks ending (deploys sequencing — looping declining (breaking owning — cycling refusing (breaks funding — autonomy keeping).

```typescript
// GOOD: dependencies grading — counted depths capping fan-outs (compiled + run live).
interface Dep { // depths counting — chains measuring, hiding declining
  name: string;
  depth: number;
  fanout: number;
}
function ungraded(deps: Dep[], depthCap: number, fanCap: number): string[] {
  const gaps: string[] = []; // fan-outs capping — calls bounding, exploding declining
  for (const d of deps) {
    if (d.depth > depthCap || d.fanout > fanCap) gaps.push(d.name);
  }
  return gaps; // cycles breaking — graphs acyclicing, looping declining
}
const graded: Dep[] = [
  { name: 'api', depth: 2, fanout: 3 },
  { name: 'worker', depth: 1, fanout: 1 },
];
const deep: Dep[] = [{ name: 'api', depth: 9, fanout: 40 }];
console.log(ungraded(graded, 4, 5).length === 0 && ungraded(deep, 4, 5).join() === 'api' ? 'dependencies grade' : 'graphs hide');
```

```typescript
// BAD: graphs hiding — depths uncounting, cycles unbreaking (real tangle shape).
// // Unknown depth (chains unmeasured — tangles hiding — visibility failing).
// // Fan-out 40 (blast unmultiplied — avalanches scheduling). Count depths; cap fan-outs; break cycles.)
```

**Common confusion** — *"grading slows design (audits delaying)."* Delaying postponing sketches (audits running — grades assigning (ships waiting — momentum dying (delaying charging — courage taxing); grading surfacing tangles (chains measuring — calls bounding (graphs acyclicing — surprises ending (grading proving — hiding declining). "Slowing" describing fear (audits avoiding — decisions ducking); dependencies describing risk (depths counting — fan-outs capping). Measure chains (hops tallying — tangles surfacing); cap calls (blast multiplying — avalanches ending).

**Performance note** — grading economics: counting costing rows (chains measuring — calls bounding (graphs acyclicing — tangles surfacing); hidden equivalents costing avalanches (tangles hiding — blast unmultiplied (surprises scheduling — trust eroding). Count cheaply (deps — depths); hide never (graphs — fan-outs).

**Mentor note** — teach "depth, fan-out, cycles — every dependency" (juniors grading one triple per dependency design tangle-proof audits on first hearing; ungraded graphs interrogated ("depth? fan-out? cycles?" — grading demanding per dependency). Grade one dep once (chains measuring — calls bounding tangible (hiding ending — grading proving permanently). Visualize graphs; acyclic orders — grading discipline in three habits, reviewed per dependency.

## 3. Mitigations funding (fixes costing — insurance pricing — budgets owning)

**Definition** — funded mitigations: costed fixes pricing insurance owning budgets (fixes costing — patches estimating (works sizing — efforts bounding (costing proving — hoping declining); insurance pricing — standbys valuing (rehearsals funding — drills scheduling (pricing owning — skipping declining); budgets owning — lines funding (owners naming — spends tracking (owning earning — starving declining).

**What problem it solves** — the unfunded trio: *fixes uncosting* (patches unestimated — works unsized (efforts unbounded — backlogs growing (uncosting billing — planning failing); *insurance unpricing* (standbys unvalued — rehearsals unfunded (drills unscheduled — readiness bluffing (unpricing charging — resilience theatering); *budgets unowning* (lines unfunded — owners unnamed (spends untracked — starvation scheduling (unowning costing — sustainability failing). Funded mitigations converting hoping to costing (patches estimating — standbys valuing (lines funding — surprises ending); reviewers finding mitigation budgets per blast (funding proving → verifiable; hoping → returned).

**Modern guidance** — the funding lines per blast (review-enforced): *fixes costing* (patches estimating — works sizing (efforts bounding — hoping declining (costing proving — wishing refusing (costs earning — backlogs clearing); *insurance pricing* (standbys valuing — rehearsals funding (drills scheduling — skipping declining (pricing owning — theater refusing (values keeping — readiness earning); *budgets owning* (lines funding — owners naming (spends tracking — starving declining (owning earning — hoping refusing (funds keeping — sustainability earning).

```typescript
// GOOD: mitigations funding — costed fixes pricing insurance (compiled + run live).
function fundable(fixCost: number, lossIfHit: number, chance: number): boolean {
  return fixCost < lossIfHit * chance; // fixes costing — patches estimating, hoping declining
} // insurance pricing — standbys valuing, skipping declining (caller asserts below)
function drillFunded(drillsPerYear: number): boolean {
  return drillsPerYear >= 4; // budgets owning — lines funding, starving declining
}
console.log(fundable(5, 100, 0.1) && !fundable(50, 100, 0.1) && drillFunded(4) && !drillFunded(1) ? 'mitigations fund' : 'risks hope');
```

// BAD: risks hoping — fixes uncosting, budgets unowning (real gamble shape).

**Performance note** — funding economics: costing mitigations (fixes estimating — standbys valuing (lines funding — surprises ending); hoped equivalents costing gambles (works unsized — rehearsals unfunded (surprises scheduling — trust eroding).
