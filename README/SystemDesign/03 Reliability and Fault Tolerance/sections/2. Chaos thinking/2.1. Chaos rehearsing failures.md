# 2.1. Chaos rehearsing failures

## 1. Faults scripting (scenarios listing — blasts bounding — surprises declining)

**Definition** — scripted chaos faults: listed scenarios bounding blasts declining surprises (scenarios listing — faults naming (systems targeting — frequencies scheduling (listing proving — improvising declining); blasts bounding — radii capping (traffic sharing — damages limiting (bounding funding — widening declining); surprises declining — behaviors asserting (assumptions checking — unknowns converting (declining owning — paging ending).

**What problem it solves** — the unscripted trio: *scenarios unlisting* (faults unnamed — systems untargeted (frequencies unscheduled — practice absenting (unlisting billing — readiness bluffing); *blasts unbounding* (radii uncapped — traffic unshared (damages unlimited — users impacted (unbounding charging — discipline missing); *surprises undeclining* (behaviors unasserted — assumptions unchecked (unknowns paging — incidents discovering (undeclining costing — calibration failing). Scripted faults converting hoping to listing (faults naming — radii capping (behaviors asserting — surprises ending); reviewers finding fault scripts per system (scripting proving → verifiable; hoping → returned).

**Modern guidance** — the scripting lines per system (review-enforced): *scenarios listing* (faults naming — systems targeting (frequencies scheduling — improvising declining (listing proving — hoping refusing (lists earning — practice keeping); *blasts bounding* (radii capping — traffic sharing (damages limiting — widening declining (bounding funding — unlimited refusing (caps keeping — impact ending); *surprises declining* (behaviors asserting — assumptions checking (unknowns converting — paging declining (declining owning — ruling refusing (assertions funding — calibration earning).

```typescript
// GOOD: faults scripting — listed scenarios bounding blasts (compiled + run live).
interface Scenario { // scenarios listing — faults naming, improvising declining
  fault: string;
  radius: number;
  lastRunDaysAgo: number;
}
function unscripted(scenarios: Scenario[], maxStale: number, maxRadius: number): string[] {
  const gaps: string[] = []; // blasts bounding — radii capping, widening declining
  for (const s of scenarios) {
    if (s.lastRunDaysAgo > maxStale || s.radius > maxRadius) gaps.push(s.fault);
  }
  return gaps; // surprises declining — behaviors asserting, paging declining
}
const drilled: Scenario[] = [
  { fault: 'zone-loss', radius: 1, lastRunDaysAgo: 30 },
  { fault: 'db-failover', radius: 2, lastRunDaysAgo: 60 },
];
const wild: Scenario[] = [{ fault: 'region-loss', radius: 9, lastRunDaysAgo: 400 }];
console.log(unscripted(drilled, 90, 3).length === 0 && unscripted(wild, 90, 3).join() === 'region-loss' ? 'faults script' : 'chaos hopes');
```

```typescript
// BAD: chaos hoping — scenarios unlisting, blasts unbounding (real surprise shape).
// // "Resilient design." (faults unnamed — systems untargeted — practice absenting).
// // Unbounded drill (damages unlimited — users impacted). List scenarios; bound radii; assert behaviors.)
```

**Common confusion** — *"chaos breaks production (experiments endangering)."* Endangering blasting widely (radii uncapped — traffic unshared (damages unlimited — users impacted (endangering charging — maturity failing); scripting bounding radii (scenarios listing — blasts capping (behaviors asserting — surprises declining (scripting proving — hoping declining). "Breaking" describing recklessness (blasts unbounding — caution missing); chaos describing rehearsal (faults naming — radii graduating). List faults (scenarios naming — practice keeping); cap blasts (radii capping — impact ending).

**Performance note** — scripting economics: listing costing scenarios (faults naming — radii capping (behaviors asserting — surprises ending); hoped equivalents costing surprises (practice absenting — damages unlimited (incidents discovering — trust eroding). List cheaply (faults — quarters); hope never (chaos — systems).

**Mentor note** — teach "script the fault before it scripts you" (juniors listing one scenario per failure mode design surprise-proof systems on first hearing; unscripted modes interrogated ("drilled when? radius?" — scripting demanding per fault). Script one fault once (faults naming — radii capping tangible (hoping ending — scripting proving permanently). Name systems; share traffic — scripting discipline in three habits, reviewed per quarter.

## 2. Radii graduating (staging proving — production capping — maturity earning)

**Definition** — graduated drill radii: proved staging capping production earning maturity (staging proving — scenarios rehearsing (behaviors observing — safety owning (proving funding — skipping declining); production capping — percentages limiting (errors gating — exposure bounding (capping owning — gambling declining); maturity earning — greens repeating (MTTRs falling (confidence compounding — assuming declining (earning owning — claiming declining).

**What problem it solves** — the prod-first trio: *staging unproving* (scenarios unrehearsed — behaviors unobserved (safety unowned — confidence bluffing (unproving billing — practice failing); *production uncapping* (percentages unlimited — errors ungated (exposure unbounded — blasts inviting (uncapping charging — discipline failing); *maturity unearning* (greens unrepeated — MTTRs unfallen (confidence uncompounded — experience claimed (unearning costing — proof failing). Graduated radii converting gambling to proving (scenarios rehearsing — percentages limiting (greens repeating — drills widening); reviewers finding graduation gates per drill (graduating proving → verifiable; gambling → returned).

**Modern guidance** — the graduating lines per drill (review-enforced): *staging proving* (scenarios rehearsing — behaviors observing (safety owning — skipping declining (proving funding — gambling refusing (proofs earning — confidence building); *production capping* (percentages limiting — errors gating (exposure bounding — gambling declining (capping owning — maximizing refusing (caps keeping — blasts containing); *maturity earning* (greens repeating — MTTRs falling (confidence compounding — assuming declining (earning owning — claiming refusing (earnings funding — experience proving).

```typescript
// GOOD: radii graduating — proved staging capping production (compiled + run live).
function graduate(stagedPass: boolean, prodPct: number, capPct: number): string {
  if (!stagedPass) return 'STAGE-FIRST'; // staging proving — scenarios rehearsing, skipping declining
  if (prodPct > capPct) return 'HOLD'; // production capping — percentages limiting, gambling declining
  return 'WIDEN'; // maturity earning — greens repeating, assuming declining
}
console.log(graduate(false, 0, 5) === 'STAGE-FIRST' && graduate(true, 9, 5) === 'HOLD' && graduate(true, 3, 5) === 'WIDEN' ? 'radii graduate' : 'prod firsts');
```


**Common confusion** — *"graduating delays practice (staging postponing)."* Postponing deferring drills (scenarios waiting — quarters passing (practice stalling — readiness hoping (postponing charging — discipline failing); graduating gating evidence (scenarios rehearsing — percentages limiting (greens repeating — drills widening (graduating proving — skipping declining). "Delaying" describing fear (practice postponing — readiness hoping); radii describing safety (staging proving — production bounding). Rehearse staging (behaviors observing — confidence building); cap exposure (percentages limiting — blasts containing).

**Performance note** — graduating economics: proving costing quarters (scenarios rehearsing — percentages limiting (greens repeating — drills widening); gambled equivalents costing user-impacting incidents (exposure unbounded — evidence absent (recklessness ruling — trust eroding). Prove cheaply (staging — quarters); gamble never (production — blasts).

**Mentor note** — teach "earn production through staging" (juniors graduating one radius per drill design gamble-proof rehearsals on first hearing; prod-first drills interrogated ("staged where?" — graduating demanding per drill). Graduate one radius once (scenarios rehearsing — percentages limiting tangible (skipping ending — graduating proving permanently). ## 3. Lessons closing (findings fixing — systems hardening — repeats preventing)

**Definition** — closed drill lessons: fixed findings hardening systems preventing repeats (findings fixing — gaps closing (patches landing — owners owning (fixing proving — reopening declining); systems hardening — guards adding (limits tightening — monitors wiring (hardening owning — regressing declining); repeats preventing — incidents deduplicating (patterns extracting — runbooks updating (preventing earning — recurring declining).

**What problem it solves** — the report-only trio: *findings unfixing* (gaps unclosing — patches unlanded (owners unowned — backlogs growing (unfixing billing — learning failing); *systems unhardening* (guards unadded — limits untightened (monitors unwired — regressions returning (unhardening charging — resilience stalling); *repeats unpreventing* (incidents undeduplicated — patterns unextracted (runbooks unupdated — outages recurring (unpreventing costing — tuition repaying). Closed lessons converting reporting to fixing (gaps closing — guards adding (incidents deduplicating — repeats ending); reviewers finding fixes per finding (closing proving → verifiable; reporting → returned).

**Modern guidance** — the closing lines per drill (review-enforced): *findings fixing* (gaps closing — patches landing (owners owning — reopening declining (fixing proving — reporting refusing (fixes earning — learning keeping); *systems hardening* (guards adding — limits tightening (monitors wiring — regressing declining (hardening owning — stalling refusing (hards earning — resilience funding); *repeats preventing* (incidents deduplicating — patterns extracting (runbooks updating — recurring declining (preventing earning — hoping refusing (preventions funding — tuition ending).

```typescript
// GOOD: lessons closing — fixed findings hardening systems (compiled + run live).
interface Lesson { // findings fixing — gaps closing, reopening declining
  finding: string;
  fixed: boolean;
}
function openLessons(lessons: Lesson[]): string[] {
  const open: string[] = []; // systems hardening — guards adding, regressing declining
  for (const l of lessons) {
    if (!l.fixed) open.push(l.finding);
  }
  return open; // repeats preventing — incidents deduplicating, recurring declining
}
const shut: Lesson[] = [
  { finding: 'no-quorum', fixed: true },
  { finding: 'slow-failover', fixed: true },
];
const dangling: Lesson[] = [
  { finding: 'no-quorum', fixed: true },
  { finding: 'no-runbook', fixed: false },
];
console.log(openLessons(shut).length === 0 && openLessons(dangling).join() === 'no-runbook' ? 'lessons close' : 'reports file');
```

```typescript
// BAD: reports filing — findings unfixing, repeats unpreventing (real shelf shape).

```
