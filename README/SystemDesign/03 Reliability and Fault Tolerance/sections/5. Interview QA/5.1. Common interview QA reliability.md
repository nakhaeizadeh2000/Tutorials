# 5.1. Common interview QA reliability

## 1. Faults live under pressure (SLOs, copies, scripts — diagnosed with fixes, priced)

**Definition** — the faults answer interviewers grade: given an SLO miss, name the bound with scripts ([1.1](<../../sections/1. Fault thinking/1.1. SLOs bounding reliability.md>)/[1.2](<../../sections/1. Fault thinking/1.2. Redundancy surviving zones.md>)) — SLOs proving (indicators choosing — targets bounding (windows timing — vibing declining (proving owning — bluffing declining); copies proving (replicas provisioning — zones spreading (quorums requiring — singling declining (proving funding — total declining); scripts proving (scenarios scripting — blasts bounding (surprises declining — debuting declining (proving earning — hoping declining). "Live" means diagnosed fixes (objectives stating — copies numbering (faults scripting — proof stating — bluffing declining).

**What problem it solves** — the reciting trio: *SLOs reciting* (nines naming — indicators unmentioned (windows undescribed — budgets unburned (reciting serving — hiring failing (knowledge hoping — depth doubting); *copies confusing* (replicas equating — zones unplaced (quorums unjudged — totals risking (conflating owning — clarity missing (confusion serving — confidence failing (placing hoping — precision doubting); *scripts hoping* (scenarios unlisted — blasts unbounding (surprises ruling — practice absenting (hoping serving — incidents inviting (judgment failing — experience doubting). Pressured faults converting reciting to diagnosing (indicators choosing — replicas provisioning (scenarios scripting — answers holding); interviewers hearing SLOs with scripts, not nine-talk (diagnosing proving → hirable; reciting → passed) — drawing on [1.1](<../../sections/1. Fault thinking/1.1. SLOs bounding reliability.md>) and [1.2](<../../sections/1. Fault thinking/1.2. Redundancy surviving zones.md>).

**Modern guidance** — the faults lines (interview-enforced): *SLOs stating* (indicators choosing — targets bounding (windows timing — vibing declining (stating proving — bluffing refusing); *copies numbering* (replicas provisioning — zones spreading (quorums requiring — singling declining (numbering funding — total refusing); *scripts scheduling* (scenarios listing — blasts bounding (surprises declining — debuting declining (scheduling owning — hoping refusing). Every claim carrying SLO + copy + script (judgment demonstrable — pressure survivable).

```typescript
// GOOD: faults answers — SLOs, copies, scripts with diagnosed fixes (answer shape, hiring-grade).
// "99.9 over 30d with 70-error budget left (objectives stating — burns rating).
//  Tripled across 3 zones, quorum 2 (copies numbering — splits deciding).
//  Zone-loss drilled last quarter (scripts scheduling — surprises declining).")
```

```typescript
// BAD: faults recitals — nines without SLOs, hopes without scripts (real fail shape).
// // "Four nines." (indicators unmentioned — windows undescribed — knowledge hoping).
// // "Redundant." (zones unplaced — scripts unlisted). State SLIs; number zones; schedule scripts.)
```

**Common confusion** — *"nines answer reliability (nines stating)."* Stating quoting targets (digits reciting — windows missing (budgets unburned — drills unscheduled (stating serving — owning failing); answering proving bounds (indicators choosing — replicas provisioning (scenarios scripting — surprises declining (proving funding — reciting declining). "Answering" describing judgments (SLOs stating — copies numbering); nines describing digits (targets quoting — meaning missing). Choose indicators (goods counting — bads excluding); spread zones (regions spanning — blasts limiting).

**Performance note** — faults-answer economics: diagnosing costing triples (SLOs stating — copies numbering (scripts scheduling — answers holding); reciting equivalents costing doubt (nines reciting — judgments missing (depth doubting — hiring failing). State cheaply (triples — faults); recite never (nines — hopes).

**Mentor note** — drill "SLO, copies, scripts" (candidates answering per journey with stated objectives, numbered zones, and dated drills defend faults on first hearing; nines-only answers interrogated ("SLI? zones? drilled?" — faults demanding per claim). Rehearse one bounded fault once (SLO-copy-script tangible (reciting ending — diagnosing proving permanently). Time windows; require quorums — faults answers in three artifacts, reviewed per interview.

## 2. Shifts live under pressure (health, sequence, loss — honesty stated, not hoped)

**Definition** — the shifts answer interviewers grade: given a failover, name the sequence with bounds ([2.1](<../../sections/2. Chaos thinking/2.1. Chaos rehearsing failures.md>)/[2.2](<../../sections/2. Chaos thinking/2.2. Failovers shifting traffic.md>)) — health proving (probes splitting — verdicts acting (routes updating — blindness declining (proving owning — ignoring declining); sequence proving (drains landing — primaries demoting (replicas promoting — cutting declining (proving funding — fumbling declining); loss proving (writes fencing — gaps measuring (recencies proving — diverging declining (proving earning — hoping declining). "Live" means honesty first (splits stating — orders sequencing (bounds quoting — truth proving — cutting declining).

**What problem it solves** — the hand-waving trio: *health waving* (splits unstating — verdicts unacting (routes unupdating — blindness ruling (waving serving — hiring failing (numbers missing — judgment doubting); *sequence forgetting* (drains unlanding — primaries undemoting (replicas unpromoted — cuts fumbling (forgetting owning — safety failing (silence serving — order bluffing); *loss missing* (writes unfencing — gaps unmeasuring (recencies unproving — divergences hiding (missing charging — honesty failing (hope serving — calibration failing). Pressured shifts converting waving to sequencing (probes splitting — drains landing (writes fencing — answers holding); interviewers hearing health with sequence, not adjectives (sequencing proving → hirable; waving → passed) — drawing on [2.1](<../../sections/2. Chaos thinking/2.1. Chaos rehearsing failures.md>) and [2.2](<../../sections/2. Chaos thinking/2.2. Failovers shifting traffic.md>).

**Modern guidance** — the shifts lines (interview-enforced): *health splitting* (probes declaring — verdicts acting (routes updating — blindness declining (splitting proving — merging refusing); *sequence landing* (drains stopping — primaries fencing (standbys elevating — cutting declining (landing funding — fumbling refusing); *loss bounding* (writes fencing — gaps quoting (restores testing — diverging declining (bounding owning — hoping refusing). Every claim carrying split + order + bound (judgment demonstrable — pressure survivable).

```typescript
// GOOD: shifts answers — health, sequence, loss with honest bounds (answer shape, hiring-grade).
// "Live-cheap with deep ready gates (health splitting — traffic gating).
//  Drain-fence-promote in order (sequence landing — splits deciding).
//  Loss bounded at lag cap with fenced writers (loss bounding — gaps quoting).")
```

```typescript
// BAD: shifts waves — adjectives without health, comfort without sequence (real fail shape).
// // "Automatic failover." (splits unstating — drains unlanding — numbers missing).
// // "No data loss." (bounds unquoted — gaps unmeasured). Split probes; sequence shifts; bound losses.)
```

**Common confusion** — *"automation answers shifts (platforms promoting)."* Promoting configuring tools (health checking — standbys elevating (traffic shifting — losses bounding (configuring serving — readiness earning); automatic assuming magic (drills missing — sequences unowned (losses unbounded — evidence failing (assuming charging — calibration bluffing). "Automation" describing tools (platforms configuring — switches flipping); shifts describing rehearsal (probes splitting — drains landing). Split verdicts (live cheaping — ready deeping); fence primaries (writers demoting — splits deciding).

**Performance note** — shifts-answer economics: sequencing costing order (health splitting — drains landing (losses bounding — answers holding); waving equivalents costing doubt (adjectives floating — numbers missing (judgment doubting — hiring failing). Sequence cheaply (shifts — orders); wave never (adjectives — health).

**Mentor note** — drill "split, order, bound" (candidates answering per failover with probe splits, shift orders, and loss bounds defend shifts on first hearing; "automatic" interrogated ("probes? sequence? loss?" — shifts demanding per claim). Rehearse one sequenced shift once (split-order-bound tangible (waving ending — sequencing proving permanently). Land drains; quote gaps — shifts answers in three honesty, reviewed per interview.

## 3. Blasts live under pressure (radii, grades, funds — ownership stated, not hoped)

**Definition** — the blasts answer interviewers grade: given a design, name the radius with funds ([3.1](<../../sections/3. Blast audit/3.1. Blast audit sizing radii.md>)) — radii proving (scopes mapping — damages pricing (priorities ordering — hoping declining (proving owning — fogging declining); grades proving (depths counting — fan-outs capping (cycles breaking — hiding declining (proving funding — tangling declining); funds proving (fixes costing — insurance pricing (budgets owning — hoping declining (proving earning — gambling declining). "Live" means ownership stated (scopes mapping — depths counting (fixes costing — proof stating — fogging declining).

**What problem it solves** — the claiming trio: *radii claiming* (scopes unmapping — damages unpricing (priorities unordering — surprises scheduling (claiming serving — hiring failing (names missing — proof doubting); *grades missing* (depths uncounting — fan-outs uncapping (cycles unbreaking — tangles hiding (missing owning — risk failing (silence serving — visibility bluffing); *funds hoping* (fixes uncosting — insurance unpricing (budgets unowning — gambles scheduling (hoping serving — evidence failing). Pressured blasts converting claiming to mapping (scopes bounding — depths counting (fixes costing — answers holding); interviewers hearing radii with funds, not assurances (mapping proving → hirable; claiming → passed) — drawing on [3.1](<../../sections/3. Blast audit/3.1. Blast audit sizing radii.md>).

**Modern guidance** — the blasts lines (interview-enforced): *radii mapping* (scopes bounding — damages pricing (priorities ordering — hoping declining (mapping proving — fogging refusing); *grades counting* (depths tallying — fan-outs capping (cycles breaking — hiding declining (counting owning — tangling refusing); *funds owning* (fixes costing — insurance pricing (budgets funding — hoping declining (owning earning — gambling refusing). Every claim carrying radius + grade + fund (judgment demonstrable — pressure survivable).

```typescript
// GOOD: blasts answers — radii, grades, funds with owned scopes (answer shape, hiring-grade).
// "AZ-loss bounds 300k users for 20 minutes (radii mapping — damages pricing).
//  Depth 2 with fan-out capped at 3 (grades counting — cycles breaking).
//  Fix funded at 5 against 10 expected loss (funds owning — gambles declining).")
```

```typescript
// BAD: blasts claiming — assurances without radii, scopes without funds (real fail shape).
// // "Fault tolerant." (scopes unmapping — damages unpricing — names missing).
// // "Reviewed." (grades uncounted — funds unowned). Map scopes; count depths; fund fixes.)
```

**Common confusion** — *"pessimism answers blasts (dooms forecasting)."* Forecasting listing disasters (dooms enumerating — morale dipping (velocity slowing — ambition taxing (forecasting charging — courage failing); blasts pricing triage (scopes mapping — depths counting (fixes costing — surprises ending (pricing proving — fogging declining). "Pessimism" describing mood (dooms listing — morale dipping); radii describing budgets (damages pricing — mitigations funding). Bound failures (zones plotting — surprises ending); rank fixes (patches sequencing — triage earning).

**Performance note** — blasts-answer economics: mapping costing rows (scopes bounding — depths counting (fixes costing — answers holding); claiming equivalents costing doubt (assurances floating — artifacts missing (proof doubting — hiring failing). Map cheaply (radii — scopes); claim never (assurances — blasts).

**Mentor note** — drill "radius, grade, fund" (candidates answering per design with mapped scopes, counted depths, and funded fixes defend blasts on first hearing; "fault tolerant" interrogated ("radius? depth? fund?" — blasts demanding per claim). Rehearse one audited blast once (radius-grade-fund tangible (claiming ending — mapping proving permanently). Price damages; sequence patches — blasts answers in three ownerships, reviewed per interview.
