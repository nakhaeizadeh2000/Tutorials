# 4.1. Reliability checklist mentors insist on

## 1. Every fault bounding (objectives stating — copies numbering — faults scripting)

**Definition** — the fault line on every journey: objectives proving (indicators choosing — targets bounding (windows timing — vibing declining (proving owning — bluffing declining); copies proving (replicas provisioning — zones spreading (quorums requiring — singling declining (proving funding — total declining); faults proving (scenarios scripting — blasts bounding (surprises declining — debuting declining (proving earning — hoping declining).

**What problem it solves** — the unbounded trio: *objectives unstating* (indicators unchoosing — targets unbounding (windows untiming — vibes ruling (unstating billing — promises bluffing); *copies unnumbering* (replicas unprovisioning — zones unspreading (quorums unrequiring — totals risking (unnumbering charging — redundancy hoping); *faults unscripting* (scenarios unlisted — blasts unbounding (surprises ruling — practice absenting (unscripting costing — readiness bluffing). Bounded faults converting hoping to proving (indicators choosing — replicas provisioning (scenarios scripting — surprises ending); reviewers finding fault triples per journey (bounding proving → verifiable; hoping → returned).

**Modern guidance** — the bounding lines per journey (review-enforced): *objectives proving* ([1.1](<../../sections/1. Fault thinking/1.1. SLOs bounding reliability.md>) — indicators choosing (targets bounding — windows timing (proving owning — vibing refusing); *copies proving* ([1.2](<../../sections/1. Fault thinking/1.2. Redundancy surviving zones.md>) — replicas provisioning (zones spreading — quorums requiring (proving funding — singling refusing); *faults proving* ([2.1](<../../sections/2. Chaos thinking/2.1. Chaos rehearsing failures.md>) — scenarios scripting (blasts bounding — surprises declining (proving earning — hoping refusing).

```typescript
// GOOD: every fault bounding — objectives, copies, scripts per journey (process shape, reviewed).
// - Objectives stated with timed windows (SLIs naming — SLOs bounding — burns rating).
// - Copies numbered across zones (replicas provisioning — regions spanning — quorums requiring).
// - Faults scripted with bounded blasts (scenarios listing — radii capping — surprises declining.)
```

```typescript
// BAD: faults hoping — objectives unstating, copies unnumbering, faults unscripting (real bluff shape).
// // "Reliable design." (indicators unchoosing — targets unbounding — vibes ruling).
// // Single copy (totals risking — redundancy hoping). State objectives; number copies; script faults.)
```

**Common confusion** — *"bounding faults is pessimism (risks depressing)."* Depressing enumerating dooms (failures listing — morale dipping (velocity slowing — ambition taxing (depressing charging — courage failing); bounding pricing triage (indicators choosing — replicas provisioning (scenarios scripting — surprises ending (bounding proving — hoping declining). "Pessimism" describing mood (dooms listing — morale dipping); faults describing budgets (objectives stating — copies numbering). State SLIs (goods counting — bads excluding); rehearse drills (scenarios scheduling — confidence earning).

**Performance note** — bounding-check economics: stating costing rows (indicators choosing — replicas provisioning (scenarios scripting — surprises ending); hoped equivalents costing bluffs (vibes ruling — totals risking (practice absenting — trust eroding). State cheaply (faults — journeys); hope never (objectives — copies).

**Mentor note** — teach "SLO, copies, scripts — every journey" (juniors bounding per journey design hope-proof faults on first hearing; unbound journeys interrogated ("SLO? copies? drilled?" — bounding demanding per journey). Bound one fault once (indicators choosing — replicas provisioning tangible (hoping ending — bounding proving permanently). Time windows; spread zones — bounding discipline in three habits, reviewed per journey.

**Common confusion** — *"rehearsing slows response (drills delaying)."* Delaying postponing readiness (drills scheduling — quarters passing (practice stalling — incidents surprising (delaying charging — courage taxing); rehearsing proving promotion (health deciding — shifts sequencing (losses bounding — fumbles ending (rehearsing proving — paging declining).
