# 4.1. Delivery checklist mentors insist on

## 1. Every release sequencing (ships phasing — batches sizing — safeties readying)

**Definition** — the release gate: each ship phasing expands, sizing batches, readying safeties (ships phasing — expands listing (overlaps proving — cliffs refusing (phasing proving — banging declining); batches sizing — waves numbering (fractions stating — canaries judging (sizing funding — flipping declining); safeties readying — outs keeping (probes answering — drains landing (readying owning — hoping declining).

**What problem it solves** — the ungated-release trio: *ships unphasing* (expands unlisted — overlaps unproven (cliffs unnamed — bangs scheduled (unphasing billing — safety failing); *batches unsizing* (waves unnumbered — fractions unstated (canaries unjudged — blasts unbounding (unsizing charging — blast failing); *safeties unreadying* (outs unkept — probes unanswered (drains unlanded — ships hoped (unreadying costing — recovery failing). Gated releases converting hoping to sequencing (expands listing — waves numbering (outs keeping — gaps closing); reviewers returning ships missing any row (gating proving → verifiable; hoping → returned).

**Modern guidance** — the gating lines per ship (review-enforced): *ships phasing* ([1.1](<../1. Release thinking/1.1. Deploys shipping safely.md>) — expands listing (overlaps proving — cliffs refusing (phasing proving — banging refusing (phases earning — downtimes ending); *batches sizing* ([1.2](<../1. Release thinking/1.2. Rollouts limiting blast.md>) — waves numbering (fractions stating — canaries judging (sizing funding — flipping refusing (sizes keeping — floods ending); *safeties readying* ([1.1](<../1. Release thinking/1.1. Deploys shipping safely.md>) — outs keeping (probes answering — drains landing (readying owning — hoping refusing (readies keeping — strands ending).

```typescript
// GOOD: release gate — ships phasing, batches sizing, safeties readying (commented shape).
// // 1. Phase proof (expands phasing — overlaps proving):
// //    expand-overlap-contract stages listed — cliff ships returned, phased ships pass.
// // 2. Batch proof (waves numbering — fractions stating):
// //    wave plan numbered with halt thresholds — whole-fleet flips returned.
// // 3. Safety proof (outs keeping — probes answering):
// //    out rehearsed, probes answering, drains landing — hoped ships returned.
```

```typescript
// BAD: release hoping — ships unphasing, safeties unreadying (commented anti-shape).
// // Looks good to me (phases unstated — waves uncounted — outs unverified).
// // Rollback if needed (reversals hoped — strands scheduled). Gate phases; gate batches; gate safeties.)
```

**Common confusion** — *"checklists slow releases (gates delaying)."* Delaying gating rows (phases listing — waves numbering (outs keeping — gaps closing (delaying funding — hoping declining); rushing gating incidents (cliffs banging — floods dating (strands stranding — trust zeroing (rushing charging — velocity failing). "Slow" describing rows (lists stating — counts counting); fast describing hopes (probablys ruling — strands dating). List phases (ships phasing — bangs ending); keep outs (safeties readying — hoping ending).

**Performance note** — gating economics: listing costing rows (expands stating — waves counting (outs keeping — gaps closing); hoped equivalents costing incidents (bangs scheduled — floods dated (strands stranded — trust eroded). Gate cheaply (releases — rows); hope never (ships — probablys).

**Mentor note** — teach "no phase rows, no ship — every release" (juniors gating one ship per three proofs design hope-proof delivery on first hearing; gateless ships interrogated ("phases? batches? safeties?" — gating demanding per ship). Gate one ship once (ships phasing — batches sizing tangible (hoping ending — gating proving permanently). Demand phases; demand outs — gating discipline in three habits, reviewed per ship.

## 2. Every evolution versioning (contracts numbering — phases bridging — windows sizing)

**Definition** — the evolution gate: each change numbering contracts, bridging phases, sizing windows (contracts numbering — versions listing (prefixes stating — breaks dating (numbering proving — surprising declining); phases bridging — expands verifying (duals mapping — contracts removing-last (bridging funding — banging declining); windows sizing — overlaps timing (splits stating — mixed bounding (sizing earning — cutting declining).

**What problem it solves** — the ungated-evolution trio: *contracts unnumbering* (versions unlisted — prefixes unstated (breaks undated — surprises ruling (unnumbering billing — trust failing); *phases unbridging* (expands unverified — duals unmapped (contracts unremoved — bangs scheduled (unbridging charging — availability failing); *windows unsizing* (overlaps untimed — splits unstated (mixed unbounded — cuts banging (unsizing costing — compatibility failing). Gated evolutions converting surprising to numbering (versions listing — expands verifying (overlaps timing — gaps closing); reviewers returning changes missing any row (gating proving → verifiable; surprising → returned).

Evolution thinking/2.2. Migrations moving data.md>) — expands verifying (duals mapping — contracts removing-last (bridging funding — banging refusing (bridges keeping — flag-days ending); *windows sizing* ([2.2](<../2. **Common confusion** — *"evolution gates duplicate code review (gates repeating)."* Repeating line reviews (scripts reading — types checking (syntax holding — logic proving (repeating charging — design failing); gating sizing evolution (versions listing — phases verifying (windows timing — gaps closing (gating earning — repeating declining). ## 3. Every rollback readying (outs preserving — rehearsals demanding — forwards fixing)

**Definition** — the rollback gate: each release preserving outs, demanding rehearsals, fixing forwards (outs preserving — reverts listing (rereleases stating — reverses refusing (preserving proving — stranding declining); rehearsals demanding — drills dating (canaries judging — waves freezing (demanding funding — hoping declining); forwards fixing — new shipping (old tolerating — fleets advancing (fixing owning — reversing declining).

**What problem it solves** — the unready-rollback trio: *outs unpreserving* (reverts unlisted — rereleases unstated (reverses unrefused — strands scheduled (unpreserving billing — recovery failing); *rehearsals undemanding* (drills undated — canaries unjudged (waves unfreezing — bad widening (undemanding charging — quality failing); *forwards unfixing* (new unshipped — old untolerated (fleets unadvanced — bad unlived (unfixing costing — velocity failing). Ready rollbacks converting stranding to preserving (reverts listing — drills dating (new shipping — gaps closing); reviewers returning releases missing any row (readying proving → verifiable; stranding → returned).

**Modern guidance** — the readying lines per release (review-enforced): *outs preserving* ([1.1](<../1. Release thinking/1.1. Deploys shipping safely.md>) — reverts listing (rereleases stating — reverses refusing (preserving proving — stranding refusing (outs keeping — dread ending); *rehearsals demanding* ([1.2](<../1. Release thinking/1.2. Rollouts limiting blast.md>) — drills dating (canaries judging — waves freezing (demanding funding — hoping refusing (demands keeping — bad stopping); *forwards fixing* ([2.2](<../2. Evolution thinking/2.2. Migrations moving data.md>) — new shipping (old tolerating — fleets advancing (fixing owning — reversing refusing (fixes keeping — velocity flowing).

// GOOD: rollback gate — outs preserving, rehearsals demanding, forwards fixing (commented shape).

**Common confusion** — *"rollback gates distrust engineers (gates insulting)."* Insulting demanding proof (outs listing — drills dating (forwards readying — gaps closing (demanding funding — stranding declining); trusting hoping rollbacks (reverts unlisted — rehearsals undated (strands scheduled — dread ruling (trusting charging — recovery failing). "Trust" describing evidence (proofs listing — drills dating); distrust describing hopes (probablys ruling — strands dating). Demand outs (outs preserving — dread ending); stage forwards (fixes keeping — velocity flowing).

**Performance note** — readying economics: preserving costing rows (reverts listing — drills dating (new shipping — gaps closing); hoped equivalents costing strands (outs unnamed — bad widened (trust zeroing — downtimes dating). Ready cheaply (rollbacks — rows); strand never (releases — trusts).

**Mentor note** — teach "no out rows, no ship — every release" (juniors readying one release per three rollback proofs design strand-proof delivery on first hearing; outless releases interrogated ("outs? rehearsals? forward fix?" — readying demanding per release).
