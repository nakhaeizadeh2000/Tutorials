# Databases track (recommended order, September 2026 era)

Postgres & Mongo usage — how to store, query, choose, and operate the two databases behind Node.js services — from zero to hero and beyond (junior to mentor depth). Naming-level vocabulary lives in the [IT Vocabulary track](<../ITVocabulary/README.md>); schema modeling will live in the Database Design track and object mappers in the ORM track (planned sibling tracks per root README — textual forwards, no dead links by design). This track assumes nothing beyond Node.js and teaches *usage*: connecting, querying, choosing between the stores, and operating them. Version-sensitive claims are labeled (as of September 2026: PostgreSQL 18 is Current, 17/16 supported; MongoDB 8.3 stable).
